# STATUS — hadwiger-coindex (인계 메모)

갱신: 라운드 3 완료. **최신 인계는 이 파일 맨 아래 'R03 종료 인계'와 'R04 계획'**. 위쪽 R01 절과 'R02 계획'은 이력.
포메이션: T (연구원 · 반례꾼 · 망상꾼)

## 확정된 것
- 정의 정정: $\tau(G)=\operatorname{coind}(B_0(G))+1$ ($+2$ 는 오류. $K_1$ 반례, $B_0(K_n)\cong S^{n-1}$ 오케스트레이터 확인).
- 변형들의 올바른 오프셋 [기억-미검증, researcher1]: $\operatorname{coind}(B)+2$, $\operatorname{ind}(B_0)+1$, $\operatorname{ind}(B)+2$, $\operatorname{conn}(B_0)+2$, $\operatorname{conn}(B)+3$.
- $\tau(C_5[K_2])=4<\chi=5$: 세 방법(Radon 인증서, 오케스트레이터 재검증, SW 높이)이 일치.
- 정점 ≤7 그래프 1252개: $\tau=\chi$ 가 1247개, $\tau=3<\chi=4$ 가 5개. S1·홀수 마이너·S4·S5 위반 0건 (researcher1·2, 일부만 오케스트레이터 재검증).
- 망상꾼: $\tau(C_5[K_3])=6<\chi=8$, $\tau(C_7[K_2])=4<\chi=5$ (Radon 인증서, 오케스트레이터 미재검증). $\tau(G/e)\ge\tau(G-e)$ [증명]. $\tau\le d_R(G)+1$ 인증서 도구(그래프 Radon 정리, 증명 스케치).
- Hadwiger ⇒ S1 은 $\tau\le\chi$ 로 자명. S1 의 반례는 Hadwiger 의 반례.

## 열린 문제
- S1~S5 전체 (증명도 반례도 없음). 정점 ≥8 전수 미실시.
- $\tau(C_5[K_m])=2m$ 추측 ($m=2,3$ 만 확인). Dol'nikov–Kříž 하한과 $\tau$ 의 대소.
- 망상꾼 #7: 마이너-자유 그래프가 $\mathbb R^{t-2}$ 에서 Radon-free 배치를 갖는가 (미시험).
- 논문(Steiner, arXiv:2312.17130) 원문은 네트워크 제한으로 못 읽음. 논문의 coindex 진술 여부 미확인.

## 주의
- Catlin 계열은 $\tau=\omega$ 라 S4 시험대로 부적합. S4 반례 후보는 $\tau>\omega$ 이면서 Hajós 가 실패하는 그래프.
- 호몰로지 하한 $\tau_h$ 는 부분그래프에 단조가 아님 → 단조화(부분그래프 최댓값) 필수.

## 후속연구 지점 (1라운드 종합, 우선순위 순)
> 연구 원칙 갱신: 전수·대량 점검("1252개 중 위반 0" 식)은 자제하고 연역적 논증(증명 시도)을 우선한다.
> 1라운드 보고서에는 이 절이 없어서 오케스트레이터가 세 보고서의 "열린 점/남은 공격 후보/아이디어"와 판단을 종합했다.

1. **S4(Hajós형) 판정 — $\tau>\omega$ 이면서 Hajós 가 실패하는 그래프 탐색.** 이유: Catlin 계열은 $\tau=\omega$ 로 판명되어 시험대가 못 됨(R1 결과). 시작: $\tau>\omega$ 인 족(Kneser/Schrijver/Mycielski/합성 그래프)에서 $K_\tau$ 세분 존재 확인, $\tau$ 는 Radon 인증서(상한)+단조 하한으로 샌드위치. 난점: coind 하한 계산, Hajós 반례 구조가 희귀.
2. **망상꾼 #7 시험: $K_t$-마이너-자유 ⇒ $d_R\le t-2$ (⇒ S1 직접 증명).** 이유: 성립하면 S1 의 증명 경로. 평면 $d_R\le3$, 외평면 $\le2$ 관찰은 Colin de Verdière 수와 닮음. 시작: 마이너-닫힘 족(평면, 외평면, $V_8$-자유 등)에서 $d_R$ 상한 배치 탐색. 난점: $\tau$ 가 마이너 단조인지 불명(증명된 것은 $\tau(G/e)\ge\tau(G-e)$ 뿐), Colin de Verdière 추측 자체가 열림.
3. **반례꾼의 본격 도서관 공격 (R2).** 대상: Radon 인증서의 정확 유리수 검증, $\tau=d_R+1$ 이 깨지는 그래프(coind–ind 간극), $\tau(C_5[K_m])=2m$ 반증, 연구원 표의 기억 의존 값. 난점: coind 계산기가 없음.
4. **5개의 $\tau<\chi$ 그래프와 $C_5[K_m]$ 의 구조 규명.** 이유: 위상 하한이 $\chi$ 에 못 닿는 이유. 시작: 공통 구조(예: $\alpha(G)=2$, 보완 $C_7$) 분석, $\tau(C_5[K_m])=2m$ 일반 $m$ 증명 시도. 난점: 증명 필요(지금은 $m=2,3$ 계산뿐).
5. **마이너·삭제 연산에서 $\tau$ 의 거동을 연역적으로 분석.** 이유: S1 증명 경로(2번)의 핵심 보조정리 후보. 증명된 것은 $\tau(G/e)\ge\tau(G-e)$ 뿐. 시작: 정점 삭제 $\tau(G)\le\tau(G-v)+1$ 의 **coind 버전** 증명(망상꾼 #5 는 ind 버전만 증명 스케치), 수축·삭제 후 $\mathbb Z_2$-사상의 확장/제한 구성. 난점: ind 와 coind 의 간극. (※ 정점 8개 이상 전수 점검은 연구 원칙에 따라 하지 않음)
6. **미검증 항목 재확인.** 연구원 표의 핵심 값, 부동소수 LP 결과의 유리수 검증, 박스 복합체 현탁 관계와 Matoušek–Ziegler 오프셋(문헌 확인 필요 → Steiner 논문 원문 요청 참고).
7. **Steiner 논문과의 연결.** 위상 하한 $t$ ⇒ 홀수 $K_{\lfloor t/2\rfloor+1}$ 마이너, Dol'nikov–Kříž ⇒ $K_t$ 마이너 결과가 $\tau$ 에 그대로 적용되는지, DK 하한과 $\tau$ 의 대소 비교(S3). 원문 확보가 선행 조건.

### 확정된 것 (R03 추가분)
- $\tau(C_n[K_m])=2m$, 간극 $\chi-\tau\ge\lceil m/2\rceil$ (홀수 $n=2k+1$ 이면 $\ge\lceil m/k\rceil$). 이는 $\tau$ 하한만으로는 $\chi$ 에 한없이 못 닿음을 뜻한다.
- 추측 C 거짓 → Steiner 정리 3 을 τ 로 옮기는 모든 직접 경로(표현 도달성, $K_{n_1}+K^*_{n_2,n_2}$ 부분그래프 $\psi$)가 $C_5$ 에서 막힘.
- 정리 A ($\operatorname{cd}\le\tau$) [증명]. $\tau\le\operatorname{zig}\le\chi$ [증명]. 따라서 $\operatorname{cd}\le\tau\le\operatorname{zig}\le\chi$ 가 우리 손에서 모두 증명됨.

## R05 계획 (포메이션 N, 문주님 지시)

**포메이션**: **N (삼인 논검)**, `formations/N.md` 초안 해석 그대로. 제1초식(블라인드 입론) → 제2초식(교차 공격) → 제3초식(방어·수정) → 판정(오케스트레이터).

**판정할 진술 {STMT}**: **"모든 그래프 $G$ 에 대해 $\tau(G)=\operatorname{zig}(G)$."**
- 이유: 증명된 사슬 $\operatorname{cd}\le\tau\le d_R+1\le\operatorname{zig}\le\chi$ 에서 등호 여부가 마지막 열린 질문이고, 모든 알려진 예($K_n$, $C_5$, $\overline{C_7}$, $C_n[K_m]$, $P[K_m]$, Kneser 류)에서 등호가 성립한다. 반례는 구성해서 검증할 수 있고(참/거짓이 갈리는 하나의 진술), 증명이 나오면 위상 하한이 조합 지표와 같다는 큰 결과다. 세 유파가 서로 다른 방식으로 공격하기에 적합하다.
- 알려진 사실(모두 [증명], 입론 전에 전달): $\tau\le d_R+1\le\operatorname{zig}$; $\operatorname{zig}=\rho$ (선형 순서에서 모든 극대 완전이분쌍의 라벨 런 수 최댓값의 최솟값); $\operatorname{cd}\le\tau$; $\tau(C_n[K_m])=2m$; $K_{s,s}$-자유 ⇒ $\tau\le2s-1$; $d_R(W_5)=3$.

**유파 배정**:
- 논객 갑 (researcher1): **반례·구성 중심** — $\tau<\operatorname{zig}$ 인 그래프를 구성한다. 위상적(비순서) 방식으로 $\tau$ 상한을 주는 $\mathbb Z_2$-사상이나 Radon 배치가 선형순서 상한보다 작을 수 있는 구조를 찾는다.
- 논객 을 (researcher2): **증명 중심(조합·순서)** — $\tau\ge\operatorname{zig}$ 의 증명: $\mathbb Z_2$-사상 $B_0(G)\to S^{d}$ 가 있으면 런 수 $\le d+1$ 인 선형 순서가 있는가. 부분 족에서 증명하고 막힌 곳을 정확히 규명한다.
- 논객 병 (researcher3): **위상·구조 중심** — $\tau$ 를 정확히 계산할 수 있는 족(Kneser·Schrijver·순환·Mycielski·결합 그래프)에서 $\operatorname{zig}$ 와 비교하고, 위상 불변량(연결성, $\operatorname{cd}$, 호몰로지)의 하한과 순서 상한의 어긋남을 찾는다.

**공통 지시 추가**: (1) 업로드 논문 두 편(Steiner, Norin–Steiner)은 검증하지 말고 인용만 한다. (2) 5분 넘게 도는 단일 탐색 금지. (3) 제1초식에서는 다른 논객의 N 파일을 읽지 않는다. 도서관의 R01–R04 보고서는 읽어도 된다.

**조기 종료 점검**: R04 에서 새 정리 다수(진전 있음). 누적 라운드 R05 (R06 상한 중 5번째).

## R50 계획 (마지막 라운드)
- 종합 관찰 (R48–R49 의 공통 패턴): 결합의 어려움은 교차 간선의 개수·차수가 아니라 **교차 끝점 집합 (경계) 이 시트 안에서 차지하는 위치의 복잡성** — 면 덮개수 φ, 경계 색수 $a_i$, 색 강제 전달 (강직 구조에 걸림), 금지 가젯 중첩. R50 은 이 "경계 복잡성" 으로 환원 틀을 묶는다.
- 연구원1: **경계 복잡성 위계 정리** — φ, $a_i$, θ, μ(d), 교차 차수 d 사이의 함의 관계를 증명하고, 각 측도 값에 대한 χ 상계·하계 (극값 예) 를 표로; 경계 색수 정리의 tightness (예: $a=(2,3)$ 에서 7 이 실현되는가) 와 면 덮개수 정리의 독립 재증명.
