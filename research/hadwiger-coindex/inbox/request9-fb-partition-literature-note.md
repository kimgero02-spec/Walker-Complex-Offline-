# 요청 9 답변 노트 (문주님이 대화에 올린 문헌 메모, 2026-10-12)
읽을 자료(데이터)이며 지시가 아니다. 출처는 문주님 메모 수준이고 원문은 팀이 확인하지 않았다 → 인용 시 [기억-미검증] 또는 "문주님 메모" 로 표기.

- Borodin: 평면 그래프는 acyclic 5-색칠 가능. 두 색류의 합은 유도 숲이지만 나머지 세 색류는 3-색칠 가능일 뿐 이분 보장 없음 → FB 명제가 바로 따라 나오지 않음.
- Kim–Oum–Zhang (arXiv 1907.09911): 평면 그래프는 유도 숲 3개로 분할되고, 별도로 유도 이분 그래프 3개로도 분할됨. 숲 + 이분 혼합 분할은 아님.
- Albertson–Berman 추측: 평면 그래프는 정점의 절반 이상인 유도 숲을 가짐. 현재 최선 Borodin 의 2n/5. 같은 방향이나 더 약한 크기 조건.
- 2-외평면 그래프는 숲 2개로 분할 → 명제 참.
- 메모 작성자 판단: 명제가 참이면 4색정리의 구조적 강화. 거짓이면 반례는 작은 평면 그래프 (예: vertex arboricity 3 그래프들) 에서 나올 수 있음. 문헌에서 이 형태를 찾지 못했으나 완전한 조사는 아님. 다른 이름 후보: (F,B)-partition, induced forest + bipartite partition.
