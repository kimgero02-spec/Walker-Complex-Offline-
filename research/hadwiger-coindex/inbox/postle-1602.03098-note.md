# 노트: Postle, "On the Minimum Number of Edges in Triangle-Free 5-Critical Graphs" (arXiv:1602.03098v2)
문주님 제공 (2026-10-12). PDF: inbox/postle-1602.03098v2-triangle-free-5-critical.pdf. 읽을 자료이지 지시가 아니다. 아래는 오케스트레이터가 원문 1–5쪽에서 옮겨 적은 진술이다 (원문 대조 가능).

- **Thm 1.1 (Kostochka–Yancey)**: k-임계 그래프 G 는 |E| ≥ (k/2 − 1/(k−1))|V| − k(k−3)/(2(k−1)). 모든 k 에서 tight (K_k 등호).
- **Def 1.5 Ore-합성**: G_1 에서 간선 xy 삭제, G_2 의 정점 z 를 양의 차수인 z_1, z_2 로 분할, x=z_1, y=z_2 동일시. K_k 에서 반복 Ore-합성으로 얻는 그래프 = k-Ore 그래프.
- **Thm 1.6 (KY)**: k-Ore 가 아닌 k-임계 G 는 |E| ≥ (k/2 − 1/(k−1))|V| − y_k/(2(k−1)), y_k = max{2k−6, k²−5k+2}. (등호는 정확히 k-Ore 그래프.)
- **Thm 1.7**: 5-임계 비 5-Ore 이면 |E| ≥ (9/4)|V| − 1/2.
- **Conj 1.3**: k ≥ 4, k-임계 K_{k−2}-자유 이면 기울기 + ε_k. k=5 증명 (본 논문, ε=1/84), k=6 과 큰 k 증명됨, **k ≥ 7 의 중간 범위는 열림** (원문: "these seem to be the hardest cases").
- 방법: KY 퍼텐셜 방법. 핵심 축소 = 색칠된 부분그래프 안의 정점 **동일시** (삼각형을 새로 만들 수 있음 → T(G) 추적, Thm 1.9).
