# [R38-researcher1] 평면 축약 단계의 조건: 내부 매칭 M 과 G/M 평면성

- 작성자·라운드·역할: researcher1 / R38 / 연구원1 (무인, 방향: 시트 평면 분해 + 렌즈). 선행: R37 (예측 3 의 마이너 판, 따름 3.1).
- 렌즈 예측 단계 표기: **평면 축약 단계** (G/M 이 평면이면 t≤4 를 주는 조건).
- 표기: `[증명]` `[추측]`. 계산 없음.

## 실패 기준 (먼저 적는다)
- **조건이 충분하다고 인정:** 조건 (C) 을 만족하는 $(G,M)$ 에서 $G/M$ 평면 ⇒ $t\le4$ 가 증명되고, (C) 가 "내부 매칭 + 평면 축약" 을 정확히 포착함.
- **조건이 불충분하다고 판정:** (C) 을 만족하는데 $G/M$ 이 평면이고 $t\ge5$ 인 모델이 있는 $(G,M)$ 반례가 나온다. (이 경우 R37 따름 3.1 의 증명에 틀린 단계가 있다.)
- **표본 규칙:** 한두 예의 확인은 조건의 필요성·충분성 증명이 아니다.

## 1. 조건 정식화
- $G$ 에 $K_t$ 모델 $\mathcal X=(X_1..X_t)$ 가 주어졌다고 하자.
- **조건 (C):** $M$ 은 매칭이고, 모든 $e\in M$ 은 어떤 $X_i$ 의 내부 간선 (양 끝점이 같은 $X_i$ 에 있음) 이다.
- **조건 (P):** $G/M$ 이 평면 그래프이다.
- 목표: (C) ∧ (P) 가 $t\ge5$ 와 양립하는지.

## 2. 정리 [증명]
- **정리 2.1.** (C) 이면 $G/M$ 은 $K_t$ 마이너를 가진다. (R37 따름 1.2)
- **따름 2.2.** (C) ∧ (P) ⇒ $t\le4$. 
  *증명.* 정리 2.1 과 평면 그래프의 K_5 마이너 부재. ∎
- **따름 2.3 (t=5 의 경우).** $t=5$ 인 모델이 (C) 를 만족하면 $G/M$ 은 항상 비평면. 즉 (P) 는 $t=5$ 모델에 대해 **자동으로 실패** 한다. 이것은 가정이 아니라 정리 2.1 의 결과이다. [증명]
- **따름 2.4 (평면 $G$).** $G$ 가 평면이면 (P) 는 모든 매칭 $M$ 에 대해 성립 (평면 그래프의 축약은 평면). 이때 $t\le4$ 는 자명 (평면 $G$ 는 K_5 마이너가 없음). [증명]

## 3. 조건 (C) 가 필요함을 보이는 최소 반례 [증명]
- **반례 (내부성 제거).** $G=K_5$, 모델 $X_i=\{v_i\}$ (단일점, $t=5$), 매칭 $M=\{v_1v_2\}$ (이 간선은 두 분기 집합을 잇는 것이며 내부 간선이 아니다, 즉 (C) 위반). $G/M=K_4$ 는 평면. 따라서 (P) 만으로는 $t\le4$ 가 나오지 않는다. 조건 (C) 를 빼면 정리가 깨진다.
- *렌즈 단계 표기:* 평면 축약 단계에서 (C) 가 필요함을 보이는 최소 예 (정점 5).

## 4. 조건 (C) 를 만족하면서 (P) 가 성립하는 $t\le4$ 예 [증명]
- $G=K_4$, 모델 $X_i=\{v_i\}$, $M=\emptyset$: 자명. 조금 더 실질적인 예: $G=K_4$ 에 정점 $w$ 를 $v_1$ 에 매달고 $X_1=\{v_1,w\}$ (내부 간선 $wv_1$), $M=\{wv_1\}$. $G/M=K_4$ 평면, $t=4\le4$ 와 일치. [증명]

## 5. 판정 (질문에 대한 답)
- **K_5 모델에 내부 매칭을 두고 $G/M$ 이 평면인 것은 불가능하다.** 정리 2.1 과 따름 2.2 로 증명됨. [증명]
- **$t\le4$ 를 얻는 조건:** (C) ∧ (P) (즉 내부 매칭 축약 후 평면) ⇒ $t\le4$. 이것이 조건이다.
- **(C) 없이는 실패:** $K_5$ 의 한 간선 축약 (반례 §3).
- **(P) 의 존재 조건 (반대 방향, 즉 (C) ∧ (P) 가 가능한 $G$):** 평면 $G$ 에서 자동 성립 (따름 2.4). 비평면 $G$ 에서는 (P) 가 $t\le4$ 를 뜻하므로 $G$ 가 K_5 모델 (또는 $t\ge5$ 모델) 을 갖는 한 (P) 는 실패한다. 즉 **(C) ∧ (P) 가 가능하려면 $G$ 가 $t\ge5$ 모델을 갖지 않아야 한다.** 이것은 순환이 아니라 정리이다.

## 마지막 절: 후속연구 지점
1. **내부 매칭의 존재 (모델 내부 간선).** 이유: (C) 는 분기 집합 내부에 매칭 간선이 있을 때만 가능하다. 시작: 분기 집합 $X_i$ 의 크기가 $\ge2$ 이고 내부 간선이 있다는 조건 아래 매칭 존재. 난점: 분기 집합이 singleton 이면 (C) 는 빈 매칭만 허용한다.
2. **T7 에의 연결.** 이유: 평면 축약 단계의 결론 $t\le4$ 는 $t=5$ 모델이 있을 때 모순을 준다. 이것을 T7 (χ≥7 ⇒ K_7) 의 축약 논법으로 바꿀 수 있는지: 모델 $K_7$ 의 내부 매칭 $M$ 에서 $G/M$ 이 평면이면 $t\le4$ 가 나오므로 $K_7$ 이 있을 수 없다 → $G/M$ 비평면을 보이는 것이 K_7 의 증명 방향이 된다. 시작: $G/M$ 의 비평면 증인 (K_5 또는 K_{3,3}) 을 블록 구조에서 찾기. 난점: 비평면 증인의 위치가 블록 구조와 무관할 수 있다.
3. **축약 후 평면성 판정 기준.** 이유: (P) 를 확인하는 실용 기준이 없다. 시작: 블록 평면성 + 교차 차수 상계 (C3) 아래 $G/M$ 의 평면성을 블록별로 나누어 판정하는 필요충분 조건. 난점: 교차 간선이 축약 후 어떻게 배치되는지에 따라 달라진다.
