# [R45-researcher1] 교차 포화 구조의 특성화와 분할 구조 겹침: 리프트 막힘을 결합 규칙 조건으로

- 작성자·라운드·역할: researcher1 / R45 (무인 6라운드 중 5) / 연구원1. 방향: 복잡성 환원 $C(G)=(k_V,R)$. 일반 정리만, 계산 없음.
- 입력: R44 (시트 사이 동일시 $\mathrm{Id}_i(u,v)$ 와 조건 (D); 분할 구조 모델 $F$ 는 $K_t$-마이너-자유).
- 표기: `[증명]` `[추측]` `[기억-미검증]`. 층 표기: 특성화 층 / 마이너 층 / 겹침 층 / 결합 규칙 층.
- 기호: $X^{(i)}_v:=N(v)\cap V_i$ ($v\notin V_i$), $\mathrm{CN}_i(S):=\{z\in V_i: S\subseteq N(z)\}$ (공통 이웃, $S$ 자신은 루프가 없으므로 $\mathrm{CN}_i(S)\cap S=\emptyset$).

## 실패 기준 (먼저 적는다)
- **(1) 특성화 성공:** 조건 (D) 가 모든 쌍에서 실패하는 것과 동치인 국소 조건을 증명. **직접 결론 성공:** 그 구조에서 $K_t$ 마이너 또는 χ 상계가 일반적으로 나옴.
- **(2) 겹침 성공:** 분할 구조가 여러 번 걸릴 때 $K_t$ 가 강제되는 조건을 증명. 그렇지 않으면 단일 $F$ 의 반례가 사라지는 **정확한 국소 조건** 을 제시.

## Part 1 — 교차 포화 구조

### 결과 1.1 — 삼각분할 시트에서 (D) 의 동치 조건 [증명]
- **보조정리.** $G[V_i]$ 가 삼각분할 (극대 평면, $|V_i|\ge4$) 이면 비인접 $u\in V_i$, $v\notin V_i$ 에 대해 (D) $\iff X^{(i)}_v\subseteq N(u)$.
  *증명.* 극대 평면 그래프에는 어떤 비간선도 평면성을 유지하며 더할 수 없다. 따라서 $G[V_i]+\{ux:x\in X^{(i)}_v\}$ 가 평면이려면 더하는 간선이 모두 기존 간선이어야 한다 (중복 제거). ∎
- *층:* 특성화 층.

### 결과 1.2 — 포화의 국소 특성화 [증명]
- **정리.** 삼각분할 시트 $V_i$ 와 $v\notin V_i$ 에 대해, "모든 비인접 $u\in V_i$ 에서 $\mathrm{Id}_i(u,v)$ 의 (D) 가 실패" $\iff$ (P1) $X^{(i)}_v=V_i$ ($v$ 가 $V_i$ 에 완전), 또는 (P2) $X^{(i)}_v\ne\emptyset$ 이고 $\mathrm{CN}_i(X^{(i)}_v)=\emptyset$.
  *증명.* (D) 가 어떤 $u$ 에서 성립 $\iff$ $u\in\mathrm{CN}_i(X_v)$ 이고 $u\notin X_v$ (비인접). $\mathrm{CN}_i(X_v)\cap X_v=\emptyset$ 이므로 조건은 $\mathrm{CN}_i(X_v)\ne\emptyset$. $X_v=\emptyset$ 이면 모든 $u$ 가 공통 이웃 (공집합 조건) 이므로 (D) 성립 (R44 의 (D1)). $X_v=V_i$ 이면 비인접 $u$ 가 없다 (공허 실패). ∎
- **교차 포화 구조의 정의 (2 시트, 둘 다 삼각분할):** 모든 $v\in V_j$ 가 $V_i$ 에 대해 (P1) 또는 (P2) 를 만족하고, 대칭으로 모든 $u\in V_i$ 가 $V_j$ 에 대해 (P1) 또는 (P2). (두 배치 방향 모두 실패.)
- **따름 1.3 (교차 차수 하계) [증명].** (P2) 정점의 교차 차수는 ≥2: $|X_v|=1$ 이면 $X_v=\{x\}$, $\mathrm{CN}_i(\{x\})=N_{V_i}(x)\ne\emptyset$ (삼각분할에서 차수 ≥3). $|X_v|=2$ 이면 두 점은 비인접이고 공통 이웃이 없다 (삼각분할에서 인접한 두 점은 공통 이웃 2 개를 가짐). 즉 (P2) 는 교차 이웃이 **분산** 되어 있다는 조건이다.
- *층:* 특성화 층.

### 결과 1.4 — 포화 구조에서 직접 얻는 마이너 [증명]
- **정리.** $Q\subseteq V_j$ 가 클리크이고 모든 $q\in Q$ 가 $V_i$ 에 완전 (P1) 이면 $G$ 는 $K_{4+|Q|}$ 마이너를 가진다.
  *증명.* 삼각분할 ($|V_i|\ge4$) 은 3-연결 평면이므로 $K_4$ 마이너를 가진다 [증명: 3-연결 그래프는 $K_4$ 세분을 가진다, 표준; 여기서는 삼각분할에 대해 바로 확인 가능 — 한 점과 그 링크 사이클의 세 점을 분기 집합으로]. 그 분기 집합 $X_1..X_4\subseteq V_i$ 와 $Q$ 의 점들은 쌍별 인접 ($q$ 는 $V_i$ 전체와 인접, $Q$ 는 클리크). ∎
- **따름.** 완전 정점 클리크의 크기가 $t-4$ 이상이면 $K_t$. 따라서 $K_t$-마이너-자유 극소 반례의 포화 구조에서 완전 정점 (P1) 들의 클리크 수는 $\le t-5$.
- **χ 상계는 얻지 못했다.** (P2) 분산 조건만으로는 블록 색칠 이상의 상계 ($\chi\le8$) 를 주는 논법이 없다 [추측].
- *층:* 마이너 층.

## Part 2 — 분할 구조의 겹침

### 결과 2.1 — 단일 $F$ 의 반례가 사라지는 정확한 국소 조건 (연결점 조건) [증명]
- 분할 구조 $(A,B,Y_2..Y_t,J_A,J_B)$ 에서 다음을 만족하는 **연결점** $s\in Y_m$ 이 있으면 $G$ 는 $K_t$ 마이너를 가진다:
  (C1) $s$ 가 $A$ 와 $B$ 양쪽에 인접,
  (C2) $Y_m\setminus\{s\}$ 가 비공 연결이고 모든 $Y_j$ ($j\ne m$, $j\ge2$) 와 인접하며 $s$ 와도 인접.
  *증명.* $X=A\cup B\cup\{s\}$ 는 연결. $X$ 는 $J_A\cup J_B=\{2..t\}$ 의 모든 $Y_j$ 와 인접 ($A$ 또는 $B$ 를 통해), 특히 $Y_m\setminus\{s\}$ 와는 $s$ 를 통해 인접. $Y_m\setminus\{s\}$ 는 다른 $Y_j$ 와 인접 (C2). 따라서 $\{X,\,Y_m\setminus\{s\},\,Y_j\ (j\ne m)\}$ 은 $t$ 개의 쌍별 인접 연결 집합. ∎
- 이 조건은 모델 그래프 $F$ 의 수준에서는 보이지 않는다 ($F$ 는 $Y_m$ 을 한 점으로 줄인다). 즉 $F$ 의 $K_t$-마이너-자유성 (R44) 은 분기 집합 **내부** 를 보면 깨질 수 있다.
- *층:* 겹침 층.

### 결과 2.2 — 겹침의 효과 [증명 / 추측]
- **정리.** 같은 쌍 $(u,v)$ 에 대해 두 모델 $\mathcal Y,\mathcal Y'$ 의 분할 구조가 걸려도, 두 모델은 분기 집합이 다르므로 $J$ 집합을 합쳐 쓸 수 없다. 겹침이 $K_t$ 를 주는 것은 **한 모델 안에서** 연결점 (결과 2.1) 이나 자유 경로를 만들어 낼 때뿐이다. [증명: 모델 사이 분기 집합 대응이 없으면 인접 정보를 옮길 수 없음]
- **추측.** 서로 다른 쌍 $(u,v)$, $(u,v')$ 의 분할 구조가 같은 $A$-쪽 집합을 공유하면 연결점이 생긴다 [추측, 증명 없음].
- *층:* 겹침 층.

## Part 3 — 리프트 막힘을 결합 규칙 조건으로 바꾸기 [증명 + 추측]
- **결합 규칙 $R$ 의 세 유형 (2 시트, 삼각분할):**
  - $R_D$: 어떤 쌍이 (D) 를 만족 → 측도가 줄어드는 동일시 가능 (R44).
  - $R_{\rm full}$: 포화이고 완전 정점 클리크 $\ge t-4$ → $K_t$ 직접 (결과 1.4).
  - $R_{\rm disp}$: 포화이고 대부분의 정점이 분산 (P2), 완전 정점 클리크 $\le t-5$ → **남는 경우.**
- **정리 3.1.** 2-시트 삼각분할 구조의 극소 반례는 $R_{\rm disp}$ 유형이어야 하고, 리프트를 시도할 쌍에서는 분할 구조가 걸리며 연결점 (결과 2.1) 이 없어야 한다. [증명: $R_D$ 이면 측도 감소 단계가 존재 (리프트는 별도), $R_{\rm full}$ 이면 $K_t$ 가 있어 반례 아님]
- 즉 리프트 막힘은 "결합 규칙이 분산형 ($R_{\rm disp}$) 이고 분할 구조에 연결점이 없음" 이라는 **결합 방식 조건** 으로 환원된다.
- *층:* 결합 규칙 층.

## 마지막 절: 후속연구 지점
1. **$R_{\rm disp}$ 의 χ 상계 (우선순위 1).** 이유: 남은 유일한 결합 유형이다. 시작: (P2) 분산 조건 (교차 이웃이 공통 이웃 없이 퍼짐) 이 색칠 확장에 주는 여유를 리스트 색칠로 세기 — 한 시트를 4-색칠한 뒤 다른 시트 정점의 금지 색이 분산 조건 때문에 몇 개로 제한되는지. 난점: 분산은 공통 이웃 부재이지 색 다양성 제한이 아니다.
2. **연결점의 존재 증명.** 이유: 결과 2.1 은 충분 조건이다. 시작: 극소 반례의 δ≥t−1 과 분할 구조의 분리 성질에서, 분리 집합 $S$ 의 어떤 $Y_m$ 이 $A,B$ 양쪽에 인접한 점을 가지며 그 제거가 $Y_m$ 을 끊지 않는지 판정 (트리인 $Y_m$ 의 잎을 고르는 논법). 난점: 잎이 $A,B$ 양쪽에 닿는다는 보장이 없다.
3. **삼각분할이 아닌 시트의 포화 특성화.** 이유: 결과 1.1 은 삼각분할 전용이다. 시작: 일반 평면 시트에서 (D) 를 면 조건 (교차 이웃이 $u$ 에 접한 한 면에 모임) 으로 쓰고 포화 조건을 같은 방식으로 정식화. 난점: 면 구조가 임베딩에 의존한다 (3-연결이 아니면 임베딩 비유일).
