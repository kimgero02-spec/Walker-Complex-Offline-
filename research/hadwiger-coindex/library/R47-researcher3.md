# [R47-researcher3] d=3 에서 χ=7 두 시트 구성 시도: α-계수 경로의 막힘 특성화 (구성 실패)

- 작성자·역할: researcher3 (망상꾼). 3라운드 중 1. 한 번만 보고. 대량 계산 없음 (손 논증).
- 결론 요약: **χ=7 구성은 찾지 못했다.** α-계수 (χ ≥ n/α) 경로는 d=3 에서 막히는 것으로 보인다 [추측 수준, 증명 스케치 포함]. 독립 색칠 경로 (Hall/리스트) 는 특성화하지 못했다.

## 0. 실패 기준 (먼저)
- **구성 성공:** $G=G_1\cup G_2\cup H$, $G_i$ 평면, $d_H\le3$, $\chi(G)\ge7$, $K_7$ 마이너 없음. 검증은 색칠 불가 증인과 마이너 부재 증명 (두 단계).
- **막힘 특성화:** 구성 시도가 실패하는 정확한 조건을 적는다. 실패 = 여기서 적은 조건을 우회하는 구성이 발견되는 경우.

## 1. α-계수 경로 (χ ≥ n/α)
- χ(G) ≥ n/α(G). χ=7 을 주려면 (α=2 일 때) n ≥ 14, 즉 두 블록 모두 7 정점 이상 (n_i=7).
- **보조정리 1 [증명]:** 평면 $G_1$ 이 α(G_1)≤2 이면 복수 α 조건으로 $G_1$ 의 비인접 쌍 집합 $\bar E_1$ 은 삼각형-없는 그래프이다. 
- **보조정리 2 [증명, 교차 차수]:** 임의 $y\in V_2$ 에 대해 $N_H(y)\subseteq V_1$ 이 $\bar E_1$ 의 **정점 커버** 여야 한다 (그렇지 않으면 $\{x_1,x_2,y\}$ 가 독립 3-집합). 따라서 $|N_H(y)|\le3$ 이면 $\bar E_1$ 은 3 정점으로 커버되고, 나머지 $n_1-3$ 정점은 서로 모두 인접 (클리크) 이다. 평면 클리크는 $\le4$ 이므로 $n_1-3\le4$, $n_1\le7$. 
- **모순 경로 [추측 → 스케치]:** 대칭적으로 $N_H(x)$ 도 $G_2$ 의 비인접 커버여야 하면, 각 $x\in V_1$ 가 $G_2$ 의 세 "커버 정점" 을 포함한다. 그러면 $G_2$ 의 커버 정점 각각의 교차 차수가 $\ge n_1-(\text{커버 밖})$ 이 되어 $d=3$ 과 충돌 (n_1=7 이면 차수 ≥4 가 필요). 따라서 **α-계수 경로는 d=3 에서 막힌다** [추측, 커버 구조가 두 쪽에 동시에 맞아야 한다는 논증의 완성 필요].
- 층: **층 3 (지수) — 색 하한이 교차 차수에 의해 제한됨.**

## 2. 독립 색칠 (Hall/리스트) 경로
- χ≥7 의 독립 증인은 α 가 아니라 **리스트 장애** 여야 한다. 블록 $G_1$ 을 4-색칠 (χ=4 블록) 하면 $G_2$ 의 각 정점 $y$ 는 교차 이웃 색을 빼고 최소 $7-3=4$ 색 리스트를 받는다 (χ 목표 7 기준). 평면 $G_2$ 의 4-리스트 색칠은 일반적으로 불가능 (Voigt 류 반례, [기억-미검증]).
- 따라서 가능한 구성은 "$G_2$ 가 리스트 4 에서 색칠 불가능한 평면 그래프" 를 포함해야 한다. 그러나 $G_1$ 의 4-색칠 선택에 따라 리스트가 바뀌므로 모든 $G_1$ 색칠에 대해 실패해야 한다 (R34 와 같은 색 충돌 구조).
- 이 경로의 막힘: 교차 차수 $d=3$ 이면 각 $y$ 의 리스트 손실이 3 이므로, $G_2$ 를 리스트 4 로 색칠 불가능하게 만드는 평면 구조가 **모든 $G_1$ 색칠 선택에 대해** 살아남아야 한다. 이것은 교차 패턴이 $G_1$ 의 4-색칠 공간 (Kempe 교환 등) 을 충분히 제약하는지의 문제이며, 특성화하지 못했다 [추측].
- 층: **층 3 (지수) — 리스트 장애 (조합).**

## 3. 창의 발상 (표기: [망상])
- [망상] 두 블록을 같은 평면 그래프의 두 "반구" 로 잡고, 교차 차수 3 의 매칭-유사 구조로 $G_1$ 의 4-색칠 공간을 Kempe 사슬로 연결된 단일 등가류로 만들면, 한 번의 교차 장애가 전체 색칠을 막을 수 있다. 실패 요인: Kempe 등가류가 여러 개면 교차 장애가 우회된다.

## 4. 결과 줄 (복잡성 환원의 어느 층)
- §1 α 경로에서 $n_i\le7$, 커버 구조 (보조정리 1–2): 층 3 — 색 하한의 교차 차수 제약.
- §1 두 쪽 커버 모순 (d=3 불가능, 추측): 층 3.
- §2 리스트 경로 (미특성화): 층 3 — 조합 장애 쪽.
- §3 Kempe 등가류 발상 [망상]: 층 3.

## 5. 후속연구 지점
1. **α 경로의 두 쪽 커버 모순 완성 (우선순위 1).** 이유: d=3 에서 χ=7 이 α 로 막힌다는 주장의 유일한 증명 공백. 시작: $\bar E_1$ 의 커버 3 개가 $G_2$ 의 모든 교차 이웃 집합과 맞물리는 최소 차수 조건을 정리 (정의 수준).
2. **리스트 경로의 Kempe 등가류 분석 (우선순위 2).** 이유: 독립 색칠 장애가 χ=7 의 유일한 남은 경로. 시작: 4-색칠 공간의 Kempe 등가류 개수를 블록별로 정의하고 교차 장애가 등가류 전체를 막는 조건 정리.
3. **d=4 구성 대조 (우선순위 3).** 이유: $K_7$ 자체가 d=4 에서 실현되므로 (REFINE-3), α 경로의 최소 d 가 4 인지 확인하면 d 갭 {7} 의 경계를 정확히 줄 수 있다. 시작: $K_7$ 의 4+3 분할에서 α 커버 구조가 d=4 에서만 맞는지 점검 (정의 수준).
