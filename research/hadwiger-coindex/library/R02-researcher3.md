3. [계산 확인] Norin–Steiner Lemma 13 의 $\tau$ 판 덧셈형 $\tau(G)\le\tau(G')+1$ 은 거짓 ($K_4$, 피스 2개 → $K_2$: $4>3$). 곱셈형 $\tau(G)\le 2\tau(G')$ 는 등호로 맞는다. 정확한 S1 은 이 축약으로 나오지 않는다.
4. [증명, 논문 인용 의존] 지점 2 (S1-Radon: $K_t$-마이너-자유 ⇒ $d_R\le t-2$) 는 $t\le 6$ 에서 성립하고 ($d_R\le\chi-1$ 과 논문 p.1 의 $h\le5$ 결과), 따라서 Hadwiger 보다 **약한** 주장이다. $t=7$ 이 새 목표다. 연역 시도(degree-2 확장 스케치)는 장애물이 명확하게 드러났다.

- [증명] $d_R(G)\le\chi(G)-1$: 색류 $c$ 를 단체 꼭짓점 $e_c$ 에 보낸다. 완전이분쌍 $(X,Y)$ 는 색 집합이 서로소이므로 $\operatorname{conv}\{e_c\}_{c\in C_X}$ 와 $\operatorname{conv}\{e_c\}_{c\in C_Y}$ 가 분리된다. 따라서 $\tau\le d_R+1\le\chi$.
- [증명] 삭제 단조: $G-e$ 의 완전이분쌍은 $G$ 의 완전이분쌍이므로 $d_R(G-e)\le d_R(G)$.
- [증명] $d_R(G)\le 1 \iff G$ 이분. ($\Leftarrow$: 한 부류를 왼쪽, 다른 부류를 오른쪽에 두면 모든 완전이분쌍 $(X,Y)$ 가 분리된다. $\Rightarrow$: 홀수 사이클이 있으면 가장 짧은 홀수 사이클 $C$ 는 유도 부분그래프이고 $C_{\ge5}$ 에는 $C_4$ 가 없어서 쌍은 간선과 별(star)뿐. 1차원에서 별 조건은 "각 꼭짓점이 두 이웃 사이에 끼지 않음", 즉 국소 극값. 사이클에서 극대·극소가 교대해야 하므로 길이가 짝수. 삼각형은 자명하게 실패.) [계산 확인] $C_3$: 0/6, $C_5$: 0/120, $C_6$: 96/720 순서가 성공. 코드: r02_oddcycle.py
- [계산 확인] 비마이너 단조성: $C_4$ 는 $K_3$ 를 마이너로 가진다. $d_R(C_4)=1$, $d_R(K_3)=2$ (1차원에서 $K_3$ 는 전 순서 0/6 실패). 따라서 $\tau$ 와 $d_R$ 모두 마이너 단조 아님. [증명 + 계산 확인]
- [계산 확인] 덧셈형 축약 보조정리의 반례: $G=K_4$, 이분 연결 피스 $V_1=\{1,2\}$, $V_2=\{3,4\}$ (각각 간선), 축약 $G'=K_2$. $\tau(K_4)=4$, $\tau(K_2)=2$, 그러므로 $\tau(G)=4>\tau(G')+1=3$. 곱셈형 $\tau(G)\le2\tau(G')$ 는 $4\le4$ 로 등호.
- [증명, 논문 인용] NS 정리 2 ($\chi\le Ch$) 와 $\tau\le\chi$ 로 $\tau(G)\le C\,h(G)$ 가 나온다 (선형 S1). 정확한 상수 1 의 S1 은 얻지 않는다. NS 는 AI 생성 증명이고 Lean 접속 불가로 미검증이다 (논문 p.3–4 자기 고지).

### D. 지점 2 의 연역 시도 (스케치, 장애물 명시)
**목표**: $K_4$-마이너-자유 ⇒ $d_R\le2$ 를 색칠 없이 증명하는 메커니즘 찾기 (t=4 는 이미 $\chi\le3$ 로 알려졌으므로 "방법의 실험"으로만 의미가 있다).
1. Dirac: $K_4$-마이너-자유 그래프 $G$ 는 차수 $\le2$ 인 정점 $v$ 를 가진다 [기억-미검증, 표준 결과].
2. 귀납 가정: $G-v$ 는 $\mathbb R^2$ 에 Radon-free 배치 $y$ 를 가진다 (삭제 단조로 보존되지 않아도 귀납 가정으로 씀).
3. $N(v)=\{a,b\}$ 일 때, $v$ 를 $\mathbb R^2$ 의 어디에 두어야 하는가: 쌍 $(X,Y)$ 에서 $v\in X$ 이면 $Y\subseteq\{a,b\}$. 따라서 금지 영역은 $\bigcup_{X'}\{p:\operatorname{conv}(X'\cup\{p\})\cap\operatorname{conv}(Y)\neq\emptyset\}$ (X' 는 공통이웃의 부분집합).
4. **장애물**: 금지 영역의 여집합이 비어 있지 않음을 보장하려면 $y$ 에 대한 추가 조건이 필요하다 ($a,b$ 가 배치의 외곽에 있거나, 공통이웃이 한쪽 반공간에 몰려 있어야 함). 현재 귀납 가정은 이를 주지 않는다. 즉 **강화된 귀납 가정(외곽 배치 보존)** 을 찾아야 한다.
5. 반증 가능한 예측: $K_4$ 자체에서 $G-v=K_3$ 의 평면 배치 위에 $v$ 를 붙이면 (Radon 정리에 의해) 반드시 실패해야 한다. 이는 $d_R(K_4)=3$ 과 일치한다. 따라서 방법은 $K_4$ 에서 실패를 "올바르게" 감지해야 한다. [망상]

## 후속연구 지점
1. **S1-Radon(7) 의 강화 귀납 찾기 (지점 2 의 $t=7$ 버전).** 이유: Hadwiger(7) 보다 약한 목표이며, 같은 방법이 $K_4$ 에서 실패를 올바르게 감지하는지가 시험. 시작: $K_4$-마이너-자유의 차수 ≤2 정점 확장에서 "외곽 배치" 조건을 명시하는 보조정리 설계, 원뿔 덮개 계산 (rooms/researcher3 에 코드). 난점: 금지 영역의 여집합 존재가 귀납 가정과 무관하게 주어지지 않는다.
2. **클리크합 전이 (#8) 시험.** 이유: 마이너-자유 그래프의 표준 분해를 $d_R$ 에 옮길 수 있는지가 지점 2 의 핵심 질문. 시작: $K_3\cup_{K_2}K_3$, $K_4^{-}\cup_{K_2}K_4^{-}$ 등 소규모에서 $d_R$ 상한을 Radon 쌍 LP 로 검사하고 합성 배치가 붙는지 확인. 난점: 두 배치를 간선 위에서 맞추는 아핀 변환이 교차 쌍을 깨뜨릴 수 있음.
3. **축약 곱셈형 (#10) 과 큰 독립집합 축약 (#11) 의 소규모 시험.** 이유: NS 의 기법이 $\tau$ 의 선형 상한을 넘어 정확한 S1 에 쓰일 수 있는지의 판단 근거. 시작: $C_5[K_2]$ ($\tau=4$, $\chi=5$) 에서 피스 축약 후 $\tau$ 변화 계산. 난점: 곱셈형은 상수 2 를 잃어 정확한 S1 에는 쓰지 못함 (선형 S1 전용).
4. **[기억-미검증] 재확인 목록.** Dirac 의 "$K_4$-마이너-자유 ⇒ 차수 ≤2 정점" (지점 2 D절 1단계), Mader 의 "$K_6$-마이너-자유 ⇒ 5-채색" (지점 2 A절 4번의 $t\le6$ 근거 중 일부). 시작: 원 논문 확인 또는 Norin–Steiner 의 인용 페이지 대조. 난점: 논문 원문 접근 불가 (arXiv 차단, 업로드 PDF 에는 해당 문헌이 없음).
