## 핵심 주장 (공격 대상)
**강화 귀납 가정 P2(H)**: 그래프 $H$ 의 정점들에 원 위의 순환 순서(볼록 위치)가 주어져 있고, **양변 크기가 모두 ≥2 인 모든 완전이분쌍 $(X,Y)$ 가 원형 분리**(두 변이 겹치지 않는 호에 놓임, 즉 $X\cup Y$ 에 제한한 순환 순서의 라벨 런이 2개) 이다. [정의]

**정리 1** [증명, 아래; 의존: "$K_4$-마이너-자유 ⇒ 어떤 2-트리의 생성 부분그래프" = 표준 사실 `[기억-미검증]`]: $K_4$-마이너-자유 ⇒ P2 를 만족하는 순서 존재 ⇒ $d_R\le2$ (색칠 불사용).

증명. (i) 볼록 위치(엄격 볼록) 점들에서 한 변이 한 점이면 나머지의 볼록껍질에 안 든다. 따라서 $|X|,|Y|\ge2$ 쌍만 문제. 서로소 두 점집합의 껍질이 만나면 교차하는 현 $x_1x_2, y_1y_2$ 가 있고 이는 교대(interleave) 이므로, 원형 분리 ⇒ 껍질 분리 [증명]. (ii) 부분그래프 단조: 쌍 집합이 줄어들 뿐, 같은 순서 사용 [증명]. (iii) 2-트리 $H$: 간선 $uv$ 에 새 정점 $w$ 를 붙이며 생성. 귀납: $H$ 에서 P2 성립 가정. $w$ 를 포함한 $H'=H+w$ 의 쌍 $(X,Y)$, $|X|,|Y|\ge2$, $w\in X$: $Y\subseteq N(w)=\{u,v\}$ 이므로 $Y=\{u,v\}$, $X\subseteq C\cup\{w\}$ ($C$=H 에서 $u,v$ 의 공통이웃). 필요한 것은 $C\cup\{w\}$ 가 $u,v$ 가 가르는 두 호 중 **한 호**에 있는 것. $|C|\ge2$ 이면 $(C,\{u,v\})$ 가 $H$ 의 쌍이므로 P2 로 $C$ 는 한 호에 있다($Y=\{u,v\}$ 가 한 블록 ⇔ $C$ 가 한 호). $|C|\le1$ 이면 자명. $w$ 를 $C$ 가 있는 호 안(예: $u$ 바로 뒤)에 삽입. $w\notin X\cup Y$ 인 쌍은 $H$ 의 쌍이고 순서 제한이 같아 P2 유지. $w\in Y$ 는 대칭. ∎

**귀결 (직렬-병렬 합성의 의미)**: 병렬 합성에서 두 조각의 단자 $s,t$ 의 공통이웃들이 한 호에 모여야 하며, 조각 하나를 **뒤집어서(반사)** 맞춘다. 반사가 유일한 자유도이고 충분하다는 것이 $t=4$ 에서 되는 이유(단자 $\{s,t\}$ 의 순열군 $S_2$ = 반사).

**$K_4$ 에서 올바르게 실패**: $K_4$ 의 3개 쌍 $\{ab|cd\},\{ac|bd\},\{ad|bc\}$ 는 4점 원 순서에서 정확히 하나가 교차 → 어떤 순서도 실패 [계산 확인: Q_2(K_4)=False, Q_3 True].
