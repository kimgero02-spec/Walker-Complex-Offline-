# [R15-researcher3] zig 의 마이너·세분 단조성: K_4 세분을 가진 zig≤3 블록은 가능한가

- 작성자·라운드·역할: researcher3 / R15 / 망상꾼 (분야: 대수적 위상수학; 보조로 그래프 세분·축약의 위상 번역)
- 지시: 문주님 (R15, R14 의 1순위 열린 문제 판정 경로).
- 표기: $\operatorname{zig}$ = 팀 정의 (선형 순서의 극대 완전이분쌍 런 수의 최솟값), $\chi$ 색수, $\tau=\operatorname{coind}B_0+1$, $G^{(e)}$ = 간선 $e$ 하나를 세분한 그래프, $G/e$ = 간선 축약, $G-e$ = 간선 삭제.
- 계산: `rooms/researcher3/r15_minor.py`, `r15_b.py` (r06_lib 의 brute-force zig, 정점 $\le 6$ 에서 사용; 정점 7 이상은 시도하지 않음).
- 기존 파일 (R07–R14) 은 수정하지 않았다.

## 요약
1. **판정 (질문의 답). $K_4$ 의 세분은 zig≤3 블록일 수 있다.** $K_4$ 의 간선 하나를 세분한 그래프 $K_4^{(1)}$ 는 $\chi=3$ [증명: 다이아몬드 $u,v,x,y$ ($uv$ 없음) 는 $c(u)=c(v)$ 로 3 색 가능, 세분점 $w$ 는 나머지 색] 이고, $\operatorname{zig}\le\chi$ 이므로 $\operatorname{zig}(K_4^{(1)})\le3$ [증명, 팀 사슬]. 계산 $\operatorname{zig}(K_4^{(1)})=3$ [계산 확인]. 반면 $K_4$ 자체 (또는 $K_4$ 부분그래프를 가진 그래프) 는 $\operatorname{zig}\ge4$ [증명, zig 의 부분그래프 단조성].
2. **zig 는 마이너에 대해 단조가 아니다** [계산 확인]: 축약 $K_{3,3}/e$ 는 $\operatorname{zig}$ 가 2 에서 3 으로 **증가**, 휠 $W_4/e$ 는 3 에서 4 로 증가. 세분 $K_{3,3}^{(1)}$ 도 2 에서 3 으로 증가. 따라서 "$K_4$ 마이너가 있으면 zig 가 크다" 류 논법은 zig 로는 불가능하다.
3. **세분은 zig 를 내릴 수 있다** [계산 확인]: $K_3\to C_4$ (3→2), $K_4\to K_4^{(1)}$ (4→3), $C_5\to C_6$ (3→2). 반면 $K_{3,3}$ 과 $K_3\square K_2$ 는 변하지 않거나 올라간다 (2→3, 3→3).
4. **위상 쪽 대응.** $\tau$ 는 세분에 대해서도 단조가 아니다: $\tau(K_4)=4$, $\tau(K_4^{(1)})=3$ [증명: 상계 $\chi=3$, 하계 삼각형 부분그래프 $\tau\ge3$]. 이것은 $\tau(G/e)\ge\tau(G-e)$ (팀 [증명]) 이 축약 쪽 하계만 준다는 사실과 맞는다. 즉 $B_0$ 의 $\mathbb Z_2$-연결성은 세분 (새 정점의 링크가 $\{u,v\}$ 인 구조) 에서 한 차원 떨어진다.
5. **예측.** 아래 P1–P7. 확인: P1 (K_4 세분 zig 3), P2 (축약 증가), P3 (세분 증가), P4 (변화 폭 ≤1, 시험 6 예), P5 (K_4 세분 zig≤3 조건), P7 (τ(K_4^{(1)})=3). 열린 것: P4 의 일반 증명, zig 의 마이너 단조 (이 방향은 거짓으로 판명: P2).

## 1. 판정 경로 (위상 쪽)

**(a) 세분의 $B_0$ 변화.** $G^{(e)}$ 는 $G$ 에서 $uv$ 를 지우고 $w$ 를 $u,v$ 에 연결한 것이다. $B_0(G^{(e)})$ 의 면은 두 복사본 위의 클리크인데, 새 정점 $(w,1),(w,2)$ 의 링크는 $(u,2),(v,2)$ 와 $(u,1),(v,1)$ 중 자기 복사본의 것이다 (교차 연결은 $w\sim u$, $w\sim v$ 뿐). 즉 $uv$ 의 교차 연결이 사라지고 $w$ 의 교차 연결 두 개가 생긴다. 이 치환은 $\mathbb Z_2$-동변이다 (교환이 $w$ 를 $w$ 로 보냄). 결과: $\tau$ 의 변화는 "교차 면 $\{u,1\}\{v,2\}$ 가 사라지고 $\{w,\cdot\}$ 가 생긴다" 로 번역되며, 그 순 효과는 부호가 정해지지 않는다 (예측 P4 가 다루는 것).

**(b) 축약 $G/e$.** $u,v$ 를 합치면 $N(u)\cup N(v)$ 가 새 정점의 이웃이 되어 새 극대 이분쌍이 생긴다. 런 수는 이 새 쌍 때문에 늘 수 있다 (P2: $K_{3,3}/e$ 에서 2→3, $W_4/e$ 에서 3→4). 이것은 $B_0$ 에서 새 면이 들어오는 것 (교차 면의 추가) 에 해당한다.

**(c) 하계 쪽 (팀 기존).** $\tau(G/e)\ge\tau(G-e)$ [증명]. $\operatorname{zig}$ 는 이 방향을 주지 않는다 (P2 가 zig 의 축약 증가를 보인다).

**(d) 결론.** 마이너 단조성은 $\operatorname{zig}$ 에 대해 **거짓** (축약 쪽), 세분 쪽은 부호가 없다. 따라서 "$K_4$ 마이너 ⇒ zig≥4" 는 성립하지 않는다. 성립하는 것은 "$K_4$ 부분그래프 ⇒ zig≥4" (부분그래프 단조) 뿐이다.

## 4. 판정에 대한 해석

- **질문의 답.** "$K_4$ 마이너를 가져도 되는가" 는 "$K_4$ 부분그래프는 안 되고, $K_4$ 세분 (세분 간선 1 개 이상) 은 될 수 있다" 로 나뉜다. 마이너 (축약 포함) 에 대해서는 zig 가 단조가 아니므로 금지 조건이 되지 못한다.
- **R14 의 $\tau\le3k$ 논법에의 영향.** 블록을 "$K_4$ 부분그래프가 없고 zig≤3" 으로 정의하면 블록 수 $k$ 는 그대로 쓸 수 있다 (증명된 zig 가법). 블록을 "$K_4$ 마이너가 없는" 으로 정의하면 zig 가 그 조건에 단조가 아니므로 $\tau\le 3k$ 가 나오지 않는다. 따라서 블록 조건은 **부분그래프** 기준이어야 한다.
- **Csorba 류 불변성 (참고, [기억-미검증]).** 간선마다 두 번 세분 (길이 3 경로) 하면 $\operatorname{Hom}(K_2,\cdot)$ 의 호모토피형이 보존된다고 알려져 있다. 여기서 본 것은 한 번 세분이므로 이 정리의 대상이 아니다. 한 번 세분에서 $\tau$ 가 4 에서 3 으로 떨어지는 것 (P7) 은 짝수 세분의 불변성과 잘 맞는다 (홀수 세분은 보존되지 않음).

## 후속연구 지점
1. **P4 의 일반 증명 (우선순위 1, 이유: "세분/축약 1 회에 zig 가 1 이하로만 변한다" 가 참이면 zig≤3 블록 정의를 안정적으로 쓸 수 있다).** 시작: 극대 이분쌍 집합의 변화를 한 연산 당 추적한다. 세분에서 $uv$ 를 포함한 쌍 하나가 $w$ 를 포함한 쌍 둘로 바뀌고, 축약에서 새 쌍이 최대 몇 개 생기는지 센다. 난점: 최적 순서가 연산 후 같은 순서로 옮겨지지 않는다.
2. **$K_4$ 세분의 zig≤3 특성화 (우선순위 2).** 시작: $K_4$ 의 모든 세분 (각 간선 $0,1,2,\dots$ 개 세분) 에 대해 $\chi$ 와 zig 를 비교. 정점 $\le 7$ 까지는 계산 가능 (세분 1 개 + 간선 1 개). 예측: 세분 간선 $\ge1$ 이면 zig≤3, 즉 zig≥4 인 $K_4$ 세분은 없다. 난점: 정점 8 이상은 brute-force zig 가 불가능하다.
3. **zig 대신 τ 의 세분 거동 (우선순위 3).** 시작: $\tau(K_4^{(1)})=3$ (P7) 과 $\tau(K_4^{(2,\text{opp})})=2$ 를 $B_0$ 의 $\mathbb Z_2$-연결성으로 확인 (χ 상계와 삼각형 하계는 이미 있다). 이 값들이 Csorba 류 짝수 세분 불변성과 맞는지 본다. 난점: $B_0$ 의 연결성 계산 도구가 없다 (R08 의 r06_lib 호몰로지로 H̃ 는 가능).
4. **블록 정의의 부분그래프 기준 확정 (우선순위 4).** 이유: R14 의 $\tau\le3k$ 는 "K_4 부분그래프 없음" 을 써야 한다. 시작: "zig≤3 & $K_4$-부분그래프-자유" 블록 $k$ 개의 $\tau\le 3k$ 를 R14 §2 의 가법 보조정리로 재확인 (가법은 부분그래프 조건과 무관하므로 그대로 성립해야 함). 난점: 정의 변경 이력을 `problem.md` 에 남겨야 한다 (무인 정책).
