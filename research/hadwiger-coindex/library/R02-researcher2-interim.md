## 1. 확정 (새로 검증)
- **[증명] τ ≤ χ (정의상 반례 없음).** 진색칠 $c:V\to\{1,\dots,k\}$ 에 대해 $f(v^1)=e_{c(v)}$, $f(v^2)=-e_{c(v)}\in\mathbb R^k$. 면 $A^1\cup B^2$ ($A\times B\subseteq E$, 둘 다 비지 않음)에서 $c(A)\cap c(B)=\emptyset$ (인접한 두 점은 색이 다름). 따라서 $\{e_i\}_{i\in c(A)}\cup\{-e_j\}_{j\in c(B)}$ 는 서로소 지지집합을 가져 원점을 볼록껍질에 포함하지 않음 → $\mathbb Z_2$-사상 $B_0(G)\to S^{k-1}$ → coind ≤ k−1 → τ ≤ k = χ.
- **[증명] τ(K_n)=n.** 면 조건은 "$v^1,v^2$ 를 동시에 포함하지 않음" 이므로 $B_0(K_n)$ 은 교차다면체 경계 $S^{n-1}$ (대척 작용 = 두 복사본 교환). 따라서 τ(K_1)=1, τ(K_2)=2, τ(K_3)=3 (정의 +1 확인).
- **[증명] 단조성 τ(G) ≥ ω(G)** (K_ω ⊆ G 이면 B_0(K_ω) 가 Z_2-부분복합체).
- **[계산 확인, 유리수 정확 검증] 인증서 (τ ≤ d+1 방향)**: 각 극대 완전이분쌍의 두 변이 어파인 초평면으로 엄격 분리되는 배치 y. 내 탐색으로 다음을 얻고 Fraction 으로 전부 재확인함.
  - $C_5[K_2]$, R^3: 극대쌍 50개 전부 분리 (τ ≤ 4), ω=4 ⇒ **τ=4**. χ ≥ 5 는 χ_f(C_5[K_2]) = 2·χ_f(C_5) = 5 (클릭 블로업 공식 [기억-미검증]) 에서 나옴.
  - 아틀라스 #1170 = $\overline{C_7}$ (networkx graph_atlas 인덱스 확인), R^2: 극대쌍 28개 분리 ⇒ **τ=3**, ω=3, χ=4. 
  - 아틀라스 #878, #998, #1002, #1101 (모두 n=7, ω=3, χ=4 로 확인), R^2 인증서 각각 존재 (쌍 18/24/20/24 개 전부 정확 검증) ⇒ **τ=3 < χ=4**. 즉 R01 의 5개 목록은 나의 독립 계산과 일치.
  - $C_7[K_2]$, R^3: 극대쌍 70개 분리 ⇒ τ ≤ 4, ω=4 ⇒ **τ=4**. χ ≥ 5 는 χ_f(C_7[K_2]) = 14/3 > 4 로 [증명] 되므로 τ<χ.
- **[증명] 단조 보조정리**: $G\to H$ (준동형) ⇒ $B_0(G)\to B_0(H)$ 가 단체 Z_2-사상 ⇒ τ(G) ≤ τ(H).
- **[증명 스케치] τ(G/e) ≥ τ(G−e)**: 수축 사상 π: B_0(G−e) → B_0(G/e) 가 면을 면으로 보내는 Z_2-사상임 (A∩B=∅, u,v 가 A,B 양쪽에 같이 있는 경우는 G−e 에서 금지되므로 π(A)∩π(B)=∅). R3 의 주장과 일치.

## 2. 쟁점 정리 (S3 전이, 논문 Steiner 2312.17130)
- 원문 p.3 Definition 1: $B_0(G)$ 면 조건은 "두 투영이 완전 이분(한쪽 빈 것 허용)", $B(G)$ 는 공통 이웃 추가. **우리 τ 의 B_0 는 Steiner 의 B_0 와 같다.**
- 원문 p.4: "zig(G) is the strongest of all the lower bounds in Figure 1" 및 "if any one of the known topological lower bounds for χ(G) attains a value of at least t, also zig(G) is of value at least t" → τ 가 그림 1 의 항목 coind(B_0)+1 이므로 **τ ≤ zig**.
- 원문 p.5 Theorem 2: zig(G) ≥ t ⇒ 홀수 $K_{\lfloor t/2\rfloor+1}$ 마이너. 따라서 **S3 은 τ 에 전이된다** ($\tau\ge t \Rightarrow \mathrm{zig}\ge t$). 단, τ ≤ zig 의 증명은 Daneshpajouh–Meunier(인용) 에 있고 우리는 확인 못 함 → [문헌 확인 + 인용 의존].
- 원문 p.5 Theorem 3 은 **cd(H)** 에 대한 것이고 그림 1 에서 cd ≤ τ. 따라서 **Theorem 3 은 τ 로 전이되지 않는다** (τ ≥ t 이어도 cd ≥ t 가 아님). S1(τ 의 Hadwiger 판)에는 직접 쓸 수 없음. 이 점은 R01 orchestrator 의 "cd ≤ τ, 전이 안 됨" 판단과 같다.
- 원문 p.1: Hadwiger 추측은 t ≤ 6 에서 알려져 있다 → S1 은 χ ≤ 6 범위에서 τ ≤ χ 로 자명 [문헌 확인].
