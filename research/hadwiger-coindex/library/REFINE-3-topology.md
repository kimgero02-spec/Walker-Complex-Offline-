## 0. 실패 기준 (먼저)
- 기준은 "정의가 이 기준을 만족하는가" 로 판정하며, 한 개의 반례로 실패가 확정된다.
- (a) 부분그래프 단조: 클래스 𝒞 에 대해 $G\in\mathcal C$, $H\subseteq G$ (부분그래프) ⇒ $H\in\mathcal C$. 실패 = 부분그래프를 떼면 클래스를 벗어나는 $G$ 한 개. (마이너 단조는 요구하지 않는다: τ 는 마이너 단조가 아님, C4≻K3.)
- (b) 조인 가법: 두 정의 가능한 그래프 $G_1,G_2$ 에 대해 $G_1+G_2$ 의 값이 $f(G_1)+f(G_2)$ (또는 클래스 안에 있음). 실패 = 조인 값이 합과 다르거나 조인이 클래스를 벗어남.
- (c) 교차 패턴 무관: 블록 분해 $V=V_1\sqcup V_2$ 와 교차 패턴 $H$ 의 임의 선택에 대해 상계 (또는 클래스 소속) 가 성립. 실패 = 어떤 패턴 $H$ 에서 상계가 깨짐.

## 1. 기준의 위상적 근거 (왜 이 셋인가)
- (a) 는 위상 불변량이 **부분그래프에 대해** 단조인 것 (동변 포함) 에서 온다 (R18 과 R16 에서 확인). 마이너 단조가 아니므로 마이너 질문 (K_t) 은 직접 답하지 않는다. 그래도 (a) 를 만족해야 $\tau\ge t$ 같은 하한이 "부분그래프 $K_t$" 로 전달된다.
- (b) 는 조인이 $B_0$ 의 조인으로 번역되는 것 (R14 C2) 에서 온다. 조인 하한 $\tau(G_1+G_2)\ge\tau_1+\tau_2$ 는 증명되어 있고, 상한 J 는 열림 (R11, R12).
- (c) 는 블록 덮개가 교차 패턴에 독립이라는 점 (R36 §2 (I),(I'): 차수 0/1 정점은 교차 구조에서 inert, 쌍별 인접 위치는 위상이 보지 못함) 에서 온다. 값은 패턴에 따라 다르므로 (c) 는 "상계 무관" 으로 한정한다.

## 2. 현재 정의 (정점 시트, 교차 무제한) 판정

| 기준 | 판정 | 근거 |
|---|---|---|
| (a) 부분그래프 단조 | **만족** | 블록 평면성은 간선 삭제에 닫혀 있고, 부분그래프 $H\subseteq G$ 의 분할을 제한하면 블록이 여전히 평면. 클래스는 부분그래프 닫힘 |
| (b) 조인 가법 | **부분** | 조인 하한 $\tau_1+\tau_2$ 는 증명 (R14 C2); 상한 $\tau(G_1+G_2)\le\tau_1+\tau_2$ (J) 는 열림 (R11, R12). 클래스 자체는 조인에 닫힘 (두 평면 블록의 합으로 분할) |
| (c) 교차 패턴 무관 | **부분** | 상계 $\tau\le4k$ 는 패턴 무관 (R09, χ 논법) ✓. 그러나 값 τ 자체는 패턴에 따라 $\max\tau_i$ 에서 $\sum$ 까지 변함 (R18, R19) ✗ |

## 5. 판정 요약
- 현재 정의는 (a) 를 만족하고 (b),(c) 는 **상계 쪽에서만 부분적으로** 만족한다. 값 쪽 (τ 자체) 은 (b),(c) 에서 열린 부분이 남는다.
- 가장 많은 기준을 만족하는 후보는 **블록 zig≤3 클래스 $\mathcal C_3$** (a ✓, c ✓, b 는 양 (zig 합 상계) 만 ✓). 단, 클래스가 조인에 닫히지 않는 점 (b ✗) 을 정의에 명시해야 한다.
- Hadwiger 질문 (T7, $\chi\ge7\Rightarrow K_7$) 과의 연결: 기준 (a) 는 $K_t$ 부분그래프 쪽만, (b) 는 조인 경우 (R25 증명) 쪽만 보장한다. 마이너 쪽 (인접 위치, R36) 은 세 기준 어디에도 없다. 이것이 정의 기준의 한계이다.
