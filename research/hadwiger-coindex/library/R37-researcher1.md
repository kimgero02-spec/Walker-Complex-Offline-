# [R37-researcher1] 렌즈 예측 3: 매칭 축약 G/M 에서 K_t 의 보존과 평면 축약의 t≤4

- 작성자·라운드·역할: researcher1 / R37 / 연구원1 (무인 라운드, 방향: 시트 평면 분해 + 렌즈). 입력: LENS-3-creative.md §3 예측 3 ("M 이 분기 숲을 포함하면 G/M 이 K_t 부분그래프를 가진다; G/M 이 평면이면 t≤4").
- 표기: `[증명]` `[추측]` `[계산 확인]`. 표본 계산은 근거로 쓰지 않는다.
- 렌즈 단계 표기: 예측 3 은 "축약이 K_t 모델을 보존하는가" 단계, 그리고 "평면 축약에서 t≤4" 단계에 쓰인다.

## 실패 기준 (먼저 적는다)
- **예측 3 참 (보존):** $G$ 의 K_t 모델 $X_1..X_t$ 와 매칭 $M$ 이 "$M$ 의 간선이 모두 어떤 $X_i$ 내부에 있음" 을 만족하면 $G/M$ 이 K_t **마이너** 를 가진다. 이것이 증명되면 보존은 참.
- **예측 3 거짓 (보존 실패):** 같은 가정 아래 $G/M$ 이 K_t 마이너를 잃는 예. 이 경우 보존 판정은 거짓.
- **부분 참 (부분그래프 판정):** "$G/M$ 이 K_t **부분그래프** 를 가진다" 는 문장은 $X_i$ 가 모두 한 점으로 줄어드는 경우에만 나온다 (예측 3 의 문면 "분기 숲 포함" 의 뜻). 매칭으로는 $|X_i|\le2$ 인 모델에서만 가능하다.
- **표본 규칙:** 소형 예 몇 개의 확인은 근거가 아니다.

## 1. 보존 정리 (마이너 수준) [증명]
- **보조정리 1.** $X$ 가 연결 분기 집합이고 $e=uv$ 가 $X$ 내부의 간선이면, $G/e$ 에서 $X/e$ 는 연결이고 다른 분기 집합과의 인접은 유지된다.
  *증명.* 축약은 $u,v$ 를 한 점 $w$ 로 합치고 $N(w)=N(u)\cup N(v)\setminus\{u,v\}$. $X$ 의 연결성은 $w$ 를 통해 유지되고 (내부 경로의 $u$, $v$ 를 $w$ 로 대체), 다른 $Y$ 와 $u$ 또는 $v$ 가 간선으로 이어져 있었다면 $w$ 와 $Y$ 도 이어진다. ∎
- **따름 1.2 [증명].** $M$ 이 모든 분기 집합 내부 간선의 **부분집합** 이면 (매칭이든 아니든), $G/M$ 은 K_t 마이너를 가진다 (보조정리 1 을 $M$ 의 간선마다 반복). 이것이 예측 3 의 마이너 판이며 **참** 이다.
- *렌즈 단계 표기:* 보존 (마이너 수준) 단계. 예측 3 의 "보존" 주장 중 마이너 부분은 증명됨.

## 2. 부분그래프 판정 (문면의 "분기 숲") [증명, 한정]
- $K_t$ **부분그래프** 를 얻으려면 각 $X_i$ 가 한 점으로 줄어야 한다: $M$ 이 $X_i$ 의 스패닝 트리를 포함해야 한다.
- $M$ 이 **매칭** 이면 $X_i$ 의 스패닝 트리 (간선 $|X_i|-1$ 개, 서로 정점 공유) 는 매칭일 수 없다. 따라서 $|X_i|\le2$ 인 $i$ 에 대해서만 가능하다.
- **결론 [증명]:** 매칭 $M$ 아래 "$G/M$ 이 $K_t$ 부분그래프를 가진다" 는 모든 분기 집합 크기가 ≤2 이고 그 쌍 간선이 $M$ 에 있을 때만 성립한다. 예측 3 의 부분그래프 주장은 매칭 가정과 양립하지 않는 일반형이다. 그러므로 예측 3 은 **마이너 판** 으로만 참이다.

## 3. 평면 축약의 t≤4 [증명]
- **따름 3.1.** $M$ 이 K_t 모델의 분기 집합 내부 간선에 포함되고 $G/M$ 이 평면이면 $t\le4$.
  *증명.* 따름 1.2 로 $G/M$ 은 K_t 마이너를 가진다. $G/M$ 이 평면이면 K_5 마이너가 없다 (평면 그래프는 K_5 마이너를 갖지 않음). 따라서 $t\le4$. ∎
- 이것은 "K_5 가 평면 축약에 남을 수 없다" 는 사용 방식을 정식화한 것이다. 조건은 **$M$ 이 모델의 분기 집합 내부에 있다** 는 것이며, 그냥 매칭이라는 것만으로는 부족하다.
- 참고: 일반적으로 $M$ 이 모델 내부에 있지 않으면 $G/M$ 은 K_5 를 잃을 수 있다 (LENS-3 의 확인 B: $K_6$ 의 매칭 축약은 $K_3$ 가 됨 — 여기서 $M$ 은 모델 내부가 아니다).

## 4. 최소 반례 (부분그래프 판정의 한계)
- **반례 R1 (매칭은 부분그래프를 주지 못함).** $K_4$ 모델의 분기 집합 $\{a,x,b\}$ (경로 $a\text{-}x\text{-}b$), $\{c\}$, $\{d\}$, $\{e\}$ 로 이루어진 그래프 — 즉 $K_4$ 를 한 간선 $ab$ 에서 세분한 것에 $e$ 를 추가하지 않은 $K_4$ 세분 (정점 5) 에서, 매칭 $M=\{ax\}$ 를 택하면 $G/M$ 은 4 정점에 $b$–(합쳐진 정점) 간선이 남아 $K_4$ 가 되는지 확인해야 한다. 이 최소 예의 세부 확인은 손으로 한다 (본 보고서에서는 $G/M$ 이 $K_4$ 마이너를 가짐을 보조정리 1 로 얻고, 부분그래프 여부는 구조 조건 §2 에 따라 판정). [추측 수준의 예 제시; 부분그래프 실패의 구체 증인은 미구성]
- 판정: 마이너 판은 반례가 없다 (§1). 부분그래프 판은 매칭 가정에서 구조적으로 실패하며 (§2), 이는 반례라기보다 적용 범위의 한계이다.

## 마지막 절: 후속연구 지점
1. **모델 내부 매칭의 존재 조건.** 이유: 따름 3.1 을 쓰려면 $M$ 이 모델 내부에 있는 매칭이 필요하다. 시작: K_t 모델에서 분기 집합 내부에 최대 매칭을 얻을 수 있는 조건 (분기 집합의 크기, 간선 수) 정리. 난점: 매칭 크기와 평면성 (축약 후 $G/M$ 평면) 의 동시 만족.
2. **$G/M$ 평면 유지 조건.** 이유: 따름 3.1 의 전제는 $G/M$ 이 평면이다. 시작: $M$ 의 축약이 평면성을 보존하는 조건 (예: 평면 그래프의 내부 매칭 축약은 평면을 유지) 을 확인. 난점: 축약 후 다중 간선과 K_5 의 등장 여부.
3. **부분그래프 판의 대안 (스패닝 트리 대신 매칭 분해).** 이유: 예측 3 의 부분그래프 판은 매칭으로 불가능하므로, 분기 집합을 매칭들의 합으로 분해하는 판정 (여러 렌즈의 합) 이 필요할 수 있다. 시작: 렌즈 합집합의 $K_t$ 보존을 정의하고 R07 의 간선 시트와 연결. 난점: 렌즈마다 축약 순서가 다르다.
