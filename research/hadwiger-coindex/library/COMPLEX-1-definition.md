# COMPLEX-1-definition: 복잡성 환원 C(G)=(k,R) 과 χ 상계 (일반 정리)

- 작성: researcher1. 작은 예 없음 (정리와 증명만). 표기: `[증명]` `[기억-미검증]` (4색정리는 외부 정리로 표시).
- 층 표기: 각 결과 옆에 "복잡성 환원의 어느 층" 한 줄.

## 1. 정의
- 규칙 $R\in\{V,E\}$.
  - $R=V$ (정점 시트): $k_V(G)=\min\{k: V=V_1\sqcup\dots\sqcup V_k,\ G[V_i]\text{ 평면}\}$.
  - $R=E$ (간선 시트, 두께): $k_E(G)=\min\{k: E=E_1\sqcup\dots\sqcup E_k,\ (V,E_i)\text{ 평면}\}$.
- 복잡성 쌍 $C_R(G):=(k_R(G),R)$. 
- 단조성: 부분그래프 $H\subseteq G$ 에 대해 $k_R(H)\le k_R(G)$ [증명: 분할을 제한].
- 주의: 축약 규칙은 정의하지 않는다 (축약은 $k$ 를 줄이거나 늘릴 수 있고 분할 구조와 독립이므로, 상계를 주는 규칙으로 쓸 수 없다. R38, R39 의 결과 참고). [증명: R38 §3 의 $K_5\to K_4$ 예는 $k$ 감소를 보임 — 반례로만 인용.]

## 2. 결과 1 — 정점 규칙: $\chi\le4k_V$ (층: 상계 층)
- **정리 2.1 [증명, 4색정리 사용].** $\chi(G)\le4k_V(G)$.
  *증명.* 분할 $V_1..V_k$, 각 $G[V_i]$ 를 4-색칠 $c_i$ (팔레트 $P_i=\{4(i-1)+1..4i\}$). 간선 $uv$ 가 같은 $V_i$ 안이면 $c_i(u)\ne c_i(v)$. 다른 $V_i,V_j$ 이면 팔레트가 서로소이므로 색이 다르다. ∎
- **정리 2.1' [증명, 4색정리 불필요].** $\chi(G)\le5k_V(G)$: 평면 그래프의 5-색칠은 5-퇴화로 초등적 [증명]. 같은 논법.
- *층:* 상계 층 (정점 규칙의 f).
- **정리 2.2 [증명] (최선).** $k_V(K_n)=\lceil n/4\rceil$ (평면 부분은 $K_n$ 의 최대 4 점) 이고 $\chi(K_n)=n$. 따라서 $n=4k$ 에서 $\chi=4k_V$. $f_V(k)=4k$ 는 최선.
  *증명.* $K_m$ 의 유도 부분이 평면이면 $m\le4$ ($K_5$ 비평면). ∎
- *층:* 최선성 층 (f 의 sharpness).

## 3. 결과 2 — 간선 규칙: $\chi\le f_E(\theta)$ (층: 상계 층)
- **정리 3.1 [증명, 4색정리 사용].** $\chi(G)\le4^{k_E(G)}$. 
  *증명.* 각 층 $(V,E_i)$ 의 4-색칠 $c_i$, 정점 $v$ 의 색 $(c_1(v),..,c_\theta(v))\in[4]^\theta$. 간선 $uv\in E_i$ 이면 $c_i(u)\ne c_i(v)$ 이므로 색 벡터가 다르다. 색 벡터 개수 $4^\theta$. ∎
- **정리 3.1' [증명, 초등].** $5^{k_E}$ 로 같은 논법 (5-색칠 사용).
- **정리 3.2 [기억-미검증].** $\chi\le6\,k_E$ (두께 색수 상계). 이것이 선형이며, $f_E$ 를 지수에서 선형으로 낮춘다.
- **정리 3.3 [기억-미검증 + 증명 골격].** $\theta(K_n)\ge (n-c)/6$ 류 하계가 있으면 3.2 는 선형으로 tight. 정확한 상수는 본 문서에서 쓰지 않는다.
- *층:* 상계 층 (간선 규칙의 f). 지수 상계 3.1 은 증명됨, 선형 상계 3.2 는 외부 인용.

## 4. 결과 3 — 상계가 가능한 조건 (일반 판정)
- **정리 4.1 [증명] (곱/합 원리).** 규칙 $R$ 이 다음 중 하나를 만족하면 $\chi\le f_R(k)$ 가 가능하다:
  - (합) 각 정점이 한 조각에 속하고 간선이 조각 내부이거나 서로소 팔레트 사이: $f=\sum c_i$ (정점 규칙).
  - (곱) 각 간선이 한 층에만 속하고 정점 색이 층별 색의 벡터: $f=\prod c_i$ (간선 규칙).
- *증명.* 정리 2.1, 3.1 의 논법 그대로. ∎
- *층:* 상계 층 (어떤 R 이 상계를 주는지의 판정 조건).
- **정리 4.2 [증명] (묶이지 않는 경우).** 규칙 $R$ 이 "조각 내부 색으로 전체 색을 복원할 수 없는" 구조이면 $\chi$ 는 $k$ 로 묶이지 않을 수 있다. 구체 판정: 완전 그래프 $K_n$ 에서 $k_R(K_n)=\lceil n/c\rceil$ 형 (c 는 조각 최대 클리크) 이면 $\chi=n$ 이므로 상계 $f$ 는 $\ge c\cdot k$ 이어야 한다. 즉 상계의 **기울기** 는 조각의 최대 클리크 크기 $\omega_{\max}$ 로 하계가 잡힌다.
  *증명.* 조각 $G[V_i]$ 가 $K_{\omega_i}$ 를 포함할 수 있으면 $K_{\omega_1+\dots}$ 류 한계를 준다 (정리 2.2 의 논법). ∎
- *층:* 최선성 층 (규칙이 상계의 기울기를 정함).

## 6. 복잡성 환원의 층 정리
- 층 A (정의): $C_R(G)=(k_R,R)$, 단조성 [증명].
- 층 B (상계): 정점 $4k$, 간선 $4^\theta$ 및 선형 $6\theta$ [증명 + 인용].
- 층 C (최선성): $K_{4k}$ (정점), $K_n$ 의 두께 [증명 / 인용].
- 층 D (Hadwiger 연결): 이 층은 여기서 쓰지 않는다. 상계 $\chi\le f(k)$ 는 $\chi\ge t \Rightarrow K_t$ 를 주지 않는다 (K_t 마이너는 별도의 층에서만 나온다, GEN-1 참고).

## 마지막 절: 후속연구 지점
1. **층 D 와의 연결 (우선순위 1).** 이유: 상계만으로는 Hadwiger 에 기여하지 않는다. 시작: $\chi\le4k$ 와 GEN-1 의 내부 축약 보존을 결합해, 축약 후 $k$ 가 줄어드는 순서에서 $t$ 를 얻는 정리 (예: $K_t$ 가 나오면 $k\ge t/4$). 난점: 축약이 $k$ 를 줄이는 조건 (R38 §3) 이 일반적이지 않다.
2. **정리 3.2 (선형 두께 색수) 의 증명 또는 인용 확인.** 이유: 지수 $4^\theta$ 는 실용성이 낮다. 시작: 원문 또는 교재에서 $\chi\le6\theta$ 의 정확한 진술 확인 (문주님께 자료 요청 가능). 난점: [기억-미검증].
3. **규칙 조합 $R=V+E$ (정점 분할과 간선 분할의 결합).** 이유: 두 규칙 중 하나만 쓰면 한쪽 상계만 얻는다. 시작: 정점 시트 내부 간선을 층으로 나누는 복합 규칙의 f (합과 곱의 혼합) 를 정리 4.1 로 정식화. 난점: 혼합 규칙의 최선성 판정이 열림.
