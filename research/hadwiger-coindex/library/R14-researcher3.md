# [R14-researcher3] zig≤3 블록 시트 분해의 위상 번역: τ≤3k 논법과 반증 가능한 예측

- 작성자·라운드·역할: researcher3 / R14 / 망상꾼 (분야: 대수적 위상수학, 보조로 조합 최적화 의 선형 순서 인증서)
- 지시: 문주님 (R14, 블록 평면 조건을 zig≤3 로 바꾼 분해). 기존 파일 (R07–R13) 은 수정하지 않았다.
- 표기: $\operatorname{zig}$ = 선형 순서의 극대 완전이분쌍 런 수의 최솟값 (팀 정의, $=\rho$). 사슬 $\operatorname{cd}\le\tau\le d_R+1\le\operatorname{zig}\le\chi$ (R03–R04 [증명], 팀 기존). $\tau=\operatorname{coind}B_0+1$.
- 계산: 손 계산 (K_n 의 zig 는 $n$, 팀 기존 값). 코드 없음.
- 정정 확인: R12 에서 정점 블록 부분가법 $\tau(G)\le\sum\tau(G[V_i])$ 는 열린 문제로 되돌렸다. 이 라운드의 $\tau\le3k$ 논법은 **그 법칙을 쓰지 않는다.** 대신 $\operatorname{zig}$ 의 블록 가법 (조합적 증명, §2) 을 쓴다.

## 요약
1. **zig≤3 블록의 위상 뜻.** 사슬 $\tau\le\operatorname{zig}$ 에 의해 $\operatorname{zig}\le 3$ 이면 $\tau\le3$, 즉 $\mathbb Z_2$-사상 $B_0(G)\to S^2$ 가 존재한다 [증명, 팀 사슬]. 블록 호몰로지 쪽 필요조건은 SW 높이 $h(B_0)\le 2$ (이것은 $\operatorname{coind}\ge h$ 에서) [기억-미검증 출처: Stiefel–Whitney 높이]. $K_4$ 는 zig≤3 블록이 될 수 없다 ($\operatorname{zig}(K_4)=4$, $\tau(K_4)=4$). zig 는 부분그래프에 단조이므로 **zig≤3 블록은 $K_4$ 부분그래프를 갖지 않는다** [증명]. $K_4$ 마이너 (세분) 는 허용될 수 있다 (zig 는 마이너 단조가 증명되지 않았다).
2. **τ≤3k 논법 (블록 덮개 아님, 조합 가법).** $k$ 개 블록 $G[V_i]$ 에 대해 $\operatorname{zig}(G)\le\sum_i\operatorname{zig}(G[V_i])$ 가 **조합적으로** 증명된다 (각 블록의 최적 순서를 이어 붙임, 극대 이분쌍의 런 수는 블록 조각의 런 수 합을 넘지 않는다, §2). 따라서 zig≤3 블록 $k$ 개이면 $\tau\le\operatorname{zig}\le 3k$ [증명]. 위상적으로는 $\mathbb Z_2$-사상 대신 **선형 순서 (인증서)** 를 쓴다. 이 점이 τ 판 가법 (열린 문제) 과 zig 판 가법 (증명됨) 의 차이다.
3. **분기 자리.** 블록 교환 분기 (R13) 는 zig 쪽에서 "교차 간선이 런을 늘리는가" 로 번역된다. 매칭 교차는 런을 늘리지 않는다 (예측 P6).
4. **예측.** 아래 6개. 확인: $K_{3k}$ 등호, $K_4$ (3+1) 등호 $4=4$, $K_5$ (3+2) 등호, $C_5[K_2]$ 의 zig-3 분할 (두 $C_5$) $\le 6$, $K_3\square K_2$ 는 $\operatorname{zig}=3$. 반증 가능한 것은 P3 (Dold 류) 와 P5 (분할 최소 개수).

## 1. zig≤3 블록의 위상 번역

| 조합 쪽 | 위상 쪽 | 비고 |
|---|---|---|
| $\operatorname{zig}(H)\le3$ | $\tau(H)\le3$, 즉 $\mathbb Z_2$-사상 $B_0(H)\to S^2$ 존재 | $\tau\le\operatorname{zig}$ (팀 [증명]) |
| 선형 순서 인증서 | 등변 사상의 조합적 근거 (Borsuk–Ulam moment 류 대신 순서) | 순서 쪽이 가법이 쉽다 |
| $K_4\subseteq H$ | $\tau(H)\ge 4$, $B_0(K_4)=S^3$ 의 부분 | 단조성 $\operatorname{zig}$ (증명) |
| $K_4$ 마이너 | 위상 대응 미확인 | $\operatorname{zig}$ 는 마이너 단조 미증명 |
| 블록 $\operatorname{zig}\le3$ 이면 SW 높이 | $h(B_0(H))\le 2$ | 필요 조건 [기억-미검증] |
| $B_0(H)$ 가 2-연결 | Dold 류: $\operatorname{coind}\ge3$, $\tau\ge4$ | 따라서 zig≤3 이면 $B_0$ 는 2-연결 아님 |

**답 (질문 (1)).** zig≤3 블록은 "$B_0$ 가 $S^2$ 로 등변 사상을 가진다" 는 뜻이다. $K_4$ 부분그래프는 허용되지 않는다 (zig 단조). $K_4$ 마이너 (세분) 는 zig 단조가 증명되지 않아 열려 있다. 블록 호몰로지 조건은 $h(B_0)\le 2$ 이고 $H^3$ 의 Z_2 특성류가 0 이어야 한다.

## 2. τ≤3k 의 조합 가법 논법 (블록 덮개를 쓰지 않음)

**보조정리 (zig 블록 가법) [증명].** $V=\bigsqcup_{i=1}^k V_i$ 일 때 $\operatorname{zig}(G)\le\sum_i\operatorname{zig}(G[V_i])$.
증명 개요: 각 $G[V_i]$ 의 최적 선형 순서 $\sigma_i$ 를 잡고 $\sigma=\sigma_1\sigma_2\cdots\sigma_k$ 를 이어 붙인다. $G$ 의 극대 완전이분쌍 $(A,B)$ 를 잡으면, 각 블록 $i$ 에서 $(A\cap V_i,B\cap V_i)$ 는 $G[V_i]$ 의 완전이분쌍이므로 어떤 극대쌍에 포함되고, 그 런 수는 $\le \operatorname{zig}_i$ (런 수 단조, 부분어의 런 수는 전체 런 수 이하). 런 수는 연결에서 최대 $\sum$ 이다 (두 어의 연결에서 런이 최대 1 합쳐지는 것 말고는 더 늘지 않음 — 런 수 부등식 $\mathrm{runs}(w_1w_2)\le\mathrm{runs}(w_1)+\mathrm{runs}(w_2)$). 따라서 $\mathrm{runs}_\sigma(A,B)\le\sum_i\operatorname{zig}_i$.
R07 B3 과 같은 논법이다. 여기서는 $\tau$ 로 옮기지 않고 zig 에서 끝낸다.

**정리 (zig≤3 블록 $k$ 개) [증명].** $\operatorname{zig}(G)\le 3k$, 따라서 $\tau(G)\le\operatorname{zig}(G)\le 3k$.

**위상 해석.** 블록 가법 보조정리는 선형 순서 (인증서) 의 가법이고 $\mathbb Z_2$-덮개의 가법이 아니다. 이 때문에 τ 쪽 가법 (열린 문제) 과 분리된다. 위상적으로 보면 zig 인증서는 $B_0$ 의 단체를 순서에 따라 나열한 것이고, 블록 순서의 이어붙임이 런 수를 합으로 올린다.

**분기 자리 (R13 과 연결).** 교차 간선이 매칭 (대각) 이면 이어붙임에서 런이 추가로 생기지 않는다: 블록 경계에서 $\pm 1$ 런만 합쳐진다. 예측 P6.

## 3. 확인 (작은 예)

| $G$ | 분할 | 블록 zig | 상계 $\sum\operatorname{zig}_i$ | $\tau$ (또는 $\operatorname{zig}$) | 결과 |
|---|---|---|---|---|---|
| $K_{3k}$ ($k=2$: $K_6$) | $K_3+K_3$ | $3,3$ | $6$ | $\tau=6$, zig $=6$ | 등호 ✓ |
| $K_4$ | $K_3+K_1$ | $3,1$ | $4$ | $\tau=4$ | 등호 ✓ (zig$(K_4)=4$) |
| $K_5$ | $K_3+K_2$ | $3,2$ | $5$ | $\tau=5$ | 등호 ✓ |
| $K_3\square K_2$ (프리즘) | 두 $K_3$ | $3,3$ | $6$ | $\tau=3$, zig $=3$ ($\chi=3$) | 느슨 (6 > 3) |
| $K_{3,3}$ | 편 분할 | $1,1$ | $2$ | $\tau=2$ | 등호 ✓ |
| $C_5[K_2]$ | 두 $C_5$ (교대 정점) | $3,3$ | $6$ | $\tau=4$, zig $=4$ | 느슨 (6 > 4) |

참고: $C_5[K_2]$ 의 두 블록 $\{0,2,4,6,8\}$, $\{1,3,5,7,9\}$ 는 각각 $C_5$ 이다 (블록 $i$ 의 한 정점을 고른 것). 둘 다 zig 3 이다 (C_5 의 zig=3, 팀 기존 값).

## 5. 한계

- $\tau\le 3k$ 는 zig 판이므로 $\tau$ 자체의 가법이 아니다. τ 판 부분가법 (정점 블록) 은 열린 문제 (R12 정정) 이므로, 이 결과는 "τ 가 zig 로 상계된다" 는 사슬 $\tau\le\operatorname{zig}$ 에 의존한다 (팀 [증명]).
- SW 높이 조건 ($h(B_0)\le2$) 은 필요 조건이며 충분하지 않다 (zig 판의 판정은 조합적이다).
- $K_4$ 마이너를 가진 zig≤3 블록의 존재 여부는 미결 (zig 가 마이너 단조인지 미증명).

## 후속연구 지점
1. **zig 의 마이너 단조성 (우선순위 1, 이유: "$K_4$ 마이너 허용 여부" 를 가르는 기초).** 시작: 간선 축약 $G/e$ 에서 zig 가 증가하지 않음을 극대 이분쌍의 상 (축약 후 쌍) 으로 보인다. 난점: 축약이 극대쌍을 보존하지 않는다. 시험: $K_4$ 의 한 간선 세분 (C_5 류 매듭) 의 zig 계산.
2. **$K_4^-$ 와 zig≤3 의 경계 (우선순위 2).** 시작: $K_4^-$ (또는 $K_4$ 의 간선 하나 제거) 의 zig 를 3 이하로 인증서 구성. $\tau(K_4^-)=3$ 과 $\operatorname{zig}$ 의 등호 여부. 난점: zig 의 최적값 계산은 $n\le 7$ 정도까지만 가능.
3. **zig 판 가법과 τ 판 가법의 간극 (우선순위 3).** 이유: 정정 후 τ 가법은 열려 있고, zig 가법은 증명됨. 두 가법이 같은 분할에서 얼마나 떨어지는지 ($C_5[K_2]$: 상계 6 대 τ 4) 가 J 의 핵심 질문과 연결된다. 시작: $\tau$ 와 zig 의 차 $\operatorname{zig}-\tau$ 를 블록 분할마다 계산.
4. **SW 높이 시험 (우선순위 4).** 시작: $h(B_0(H))\le 2$ 를 $C_5$ (τ=3, 높이?) 와 $K_3$ 에서 확인해 zig≤3 과의 관계 점검. 난점: $B_0/\mathbb Z_2$ 의 코호몰로지 환을 손으로 계산해야 한다.
