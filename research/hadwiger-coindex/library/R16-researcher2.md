# [R16-researcher2] 2-시트 평면 클래스에서 Hadwiger 시험 (χ = 7, 8)

- 작성자·라운드·역할: researcher2 / 라운드 16 / 연구원2 (독립, 무인 모드 3 라운드 중 1 라운드). 범위: 정점 시트 블록 (교차 간선 무제한). 연구원1 결과 미참조.
- 클래스: $\mathcal C_2$ = $V=V_1\sqcup V_2$, $G[V_i]$ 평면.
- 목표: $\chi(G)\in\{7,8\}$ 인 $G\in\mathcal C_2$ 에서 $K_\chi$ 마이너 존재를 증명하거나 장애물을 밝힌다.
- 기저 사실 (기억-미검증, 인용만): $t\le6$ 에서 Hadwiger 는 모든 그래프에서 성립 (Robertson–Seymour–Thomas). 따라서 $\chi\le6$ 은 여기서 다루지 않는다.
- 표기: `[증명]` `[계산 확인]` `[추측]` `[망상]` `[기억-미검증]`.

## 요약
1. **[증명] 색수 분해.** $\chi(G)\le\chi_1+\chi_2\le4+4$ (4색정리 [기억-미검증]). $\chi\ge7$ 이면 블록 색수가 $\{3,4\}$ 또는 $\{4,4\}$ 이다. $\chi=8$ 이면 두 블록 모두 $\chi=4$ 이다.
2. **[증명] 완전 교차 (조인) 에서는 증명된다.** 교차가 모든 쌍에서 완전이면 $h(G)\ge h_1+h_2$ (R13 명제 2.2). 블록 Hadwiger 수 $h_i$ 가 $\chi_i$ 와 같으면 $h\ge\chi$. 평면 블록은 $\chi_i=3$ 이면 $h_i=3$ (홀수 사이클 류), $\chi_i=4$ 이면 $h_i=4$ (Dirac: $\chi\ge4\Rightarrow K_4$ 마이너). 따라서 **완전 교차 2-시트 그래프는 $\chi=7,8$ 에서 $K_\chi$ 마이너를 가진다** [증명]. 예: $K_4+C_5$ 는 $h\ge4+3=7$.
3. **[증명] 완전 교차 가정이 $\chi$ 를 떨어뜨리는 방향.** $K_4+C_5$ 에서 교차 간선 하나를 지우면 $\chi\le6$ [증명, 아래 §3]. 즉 $\chi=\chi_1+\chi_2$ 를 유지하는 교차는 이 예에서 완전이어야 한다. 이것이 "χ 큰 그래프는 교차가 빽빽하다" 는 직관을 준다.
4. **[막힘] 일반 패턴.** 교차가 부분적이면 블록 분기 집합 사이의 쌍별 인접이 보장되지 않는다. 분기 집합을 두 블록에 걸치게 만들 수 있지만 (교차 간선으로 연결된 혼합 분기 집합), 필요한 16 쌍 (4×4) 인접을 얻는 조합 정리가 없다. 이것이 $\chi=8$ 의 장애물이다.
5. **가장 가능성 있는 χ=7 후보:** 블록 $K_4$ 와 $C_5$ (또는 $K_4$ 와 임의의 3-색 평면 블록) 사이 교차가 **거의 완전** 인 그래프. 근거: 교차를 한 간선만 빼도 χ 가 6 으로 떨어진다 [증명] — 따라서 χ=7 을 주는 교차 패턴은 최소 밀도를 가지고, 그 밀도가 쌍별 인접을 줄 가능성이 있다. 반면 교차 패턴이 완전인 경우는 이미 증명되었으므로, 반례가 있다면 "거의 완전이지만 한 쌍 빠진" 형태일 것이다 [추측].

## 1. 색수 분해 [증명]
- $\chi(G)\le\chi(G[V_1])+\chi(G[V_2])$ (팔레트 서로소 색칠).
- $\chi(G[V_i])\le4$ (평면, 4색정리 [기억-미검증]).
- 따라서 $\chi\ge7\Rightarrow\{\chi_1,\chi_2\}\in\{\{3,4\},\{4,4\}\}$; $\chi=8\Rightarrow\chi_1=\chi_2=4$. ∎

## 2. 완전 교차에서의 증명 [증명]
- R13 명제 2.2 (완전 교차 분기 집합 조인): $h(G)\ge h(G[V_1])+h(G[V_2])$.
- 평면 블록 Dirac: $\chi_i\ge4\Rightarrow h_i\ge4$ ($K_4$-마이너-자유 $\Rightarrow\chi\le3$, R11 보조정리 C). $\chi_i=3\Rightarrow h_i\ge3$ (홀수 사이클 $\supseteq K_3$ 마이너, 비이분 $\Rightarrow$ 삼각형 마이너 [증명, 표준]).
- 따라서 완전 교차 $G$ 에서 $h\ge\chi_1+\chi_2\ge\chi$, 그리고 $h\le\chi$ 는 아니므로 $h\ge\chi$ 로 충분 (Hadwiger 는 $h\ge\chi$). ∎

## 3. 교차를 하나 지웠을 때 χ 가 떨어짐 [증명]
- 그래프: $K_4=\{1,2,3,4\}$, $C_5=\{v_0,\dots,v_4\}$ 의 완전 교차 (join). $\chi=4+3=7$ (join 색수 합, [증명]).
- 교차 간선 $uv$ ($u=1$, $v=v_0$) 를 지운 $H$. 6-색칠: $K_4$ 에 $1,2,3,4$. $v_1,\dots,v_4$ 는 $K_4$ 의 모든 정점과 인접 → 색 $\in\{5,6\}$. 경로 $v_1v_2v_3v_4$ 를 $5,6,5,6$ 으로 칠한다. $v_0$ 는 $K_4$ 의 정점 $2,3,4$ 와 인접하고 $1$ 과는 인접하지 않으며, $v_1,v_4$ 와 인접 ($v_1=5$, $v_4=6$). $v_0$ 에 색 1 을 주면 $v_0$ 의 이웃 색 $\{2,3,4,5,6\}$ 과 충돌하지 않는다 ✓. 따라서 $\chi(H)\le6$. ∎
- 하한 $\chi(H)\ge\chi(K_4\cup\ldots)\ge4$ 는 필요 없다. 목적은 $\chi(H)<7$ 을 보이는 것.

## 4. 장애물 정리 (χ=8, 일반 패턴)
- $\chi=8$ 이면 두 블록 모두 4-색 임계 (각 $G[V_i]$ 는 χ=4). 평면 4-색 임계 그래프는 $K_4$ 마이너를 가지지만, $K_4$ 의 세분 (topological minor) 을 항상 갖는지는 [기억-미검증] 이고 본 보고서가 쓰지 않는다.
- 교차 패턴 $F\subseteq V_1\times V_2$. $\chi=8$ 을 유지하는 $F$ 의 구조는 미정. §3 의 예는 $F$ 를 한 원소 줄여도 χ 가 떨어지는 경우이므로, "χ=χ_1+χ_2 ⇒ F 가 완전" 이라는 강한 주장은 이 예 하나에서만 성립한다.
- **[추측] 강화 주장:** $\chi(G)=\chi(G[V_1])+\chi(G[V_2])$ 이고 블록이 임계이면 $F$ 가 완전이다. 반례 가능성: 블록 중 하나가 χ=3 이고 다른 블록이 K_4 가 아닌 임계 4-색 평면 그래프 (예: 휠 $W_5$, 색 4) 인 경우. 검증하지 않음.

## 후속연구 지점
1. **χ=7 의 $W_5 + C_5$ 거의 완전 교차 족에서 $K_7$ 마이너 찾기 (우선순위 1).** 이유: 블록 내부에 $K_4$ 가 없어 교차 쌍별 인접에 의존하므로 가장 어려운 후보다. 시작: 교차를 한 쌍씩 제거하며 χ 가 7 을 유지하는 최대 제거 집합을 찾고, 남은 교차에서 분기 집합 (혼합 허용) 으로 $K_7$ 모델을 구성. 난점: 혼합 분기 집합의 선택이 조합적으로 크다.
2. **"χ=χ_1+χ_2 이고 블록 임계이면 교차 완전" 강화 주장의 검증.** 이유: 이 주장이 참이면 $\chi\ge7$ 의 2-시트 그래프는 모두 완전 교차 (증명된 경우) 이므로 Hadwiger 가 $\chi=7,8$ 에서 증명된다. 시작: $W_5$ 와 $C_5$ 에 대해 교차 한 간선 제거 시 χ 변화를 손으로 확인 (§3 과 같은 방식). 난점: 일반 임계 블록에 대한 색칠 구성이 필요하다.
3. **쌍별 인접 조합 정리.** 이유: 장애물의 핵심. 교차 패턴이 "두 블록의 각 분기 집합 쌍을 잇는다" 는 조건을 $\chi$ 에서 유도할 수 있는지 본다. 시작: $K_4$ 모델 두 개 (블록별) 와 교차 패턴 $F$ 에 대해, 16 쌍 인접이 실패하는 최소 $F$ 를 찾고 그 $F$ 가 χ=8 을 줄 수 있는지 판정. 난점: 모델 선택이 자유도가 크다.
