# [R14-researcher1] 블록 교환 대합 σ 의 B_0 위 자유성: 일반 교차 패턴에서는 거짓, 정확한 조건과 최소 반례

## 요약
1. **[증명] σ 의 B_0 작용 정의.** G 의 자기동형 σ 를 B_0(G) 에 바로 올리면 (A,B)↦(σA,σB) 이고, 이 작용은 전체 단체 Δ(V×{2}) = (∅,V) 를 고정하므로 자유가 아니다 (무의미). 의미 있는 작용은 복사 교환 τ 와 합성한 σ̃(A,B) := (σB, σA) 이다 (τ 와 가환).
2. **[증명] 정확한 판정.** σ̃ 가 B_0(G) 위에서 고정점을 가진다 ⇔ G 에 **대각 간선** {v, σv} 가 있다. 즉 B_0 의 자유성은 교차 패턴 전체가 아니라 "σ-짝 간선이 없다" 는 한 조건에만 걸린다.
3. **[증명] 반례 (교차 패턴 무관 주장은 거짓).** 최소 반례 G = K_2, V_1={1}, V_2={2}, σ=(1 2). B_0(K_2) 는 4-사이클 (1,1)–(2,2)–(1,2)–(2,1)–(1,1), σ̃ 는 (1,1)↔(2,2), (1,2)↔(2,1) 의 반사이므로 간선 {(1,1),(2,2)} 의 중점이 고정점이다.
4. **판정.** R13-r3 의 번역 (가) "대각 간선 = 분기 자리 (중점)" 가 옳고, 이는 자유성의 반례 그 자체다. 따라서 R14 의 원 질문 ("교차 패턴이 무엇이든 자유") 에 대한 답은 **아니오**. 올바른 명제는 "대각 간선이 없으면 자유" 이다 (정리 2).

## 1. 설정
- $V=V_1\sqcup V_2$, $\sigma:V\to V$ 고정점 없는 대합, $\sigma(V_1)=V_2$, σ 는 G 의 자기동형이 아니어도 된다 (교차 패턴 임의). 
- $B_0(G)$: 면 $(A,B)$, $A\times B\subseteq E$, 정점 $V\times\{1,2\}$, $\tau(v,i)=(v,3-i)$.
- 작용 $\tilde\sigma(A,B):=(\sigma B,\sigma A)$, 즉 $\tilde\sigma(v,1)=(\sigma v,2)$, $\tilde\sigma(v,2)=(\sigma v,1)$.

## 2. 보조 사실
- **보조정리 1 [증명].** $\tilde\sigma$ 는 면을 면으로 보낸다: $\sigma B\times\sigma A\subseteq E$ 이어야 한다. 이는 σ 가 자기동형일 때만 자명하다. **일반 교차 패턴에서는 σ 가 G 의 자기동형일 필요가 없으므로**, $\tilde\sigma$ 가 $B_0(G)$ 의 단체 사상이 되는지 자체가 조건이다. 따라서 이하 $\tilde\sigma$ 가 $B_0(G)$ 를 보존한다고 가정해야 한다 (정리 2 의 가정). 가장 자연스러운 경우는 σ 가 G 의 자기동형 (대칭 블록 교환, 예: $K_{3,3}$ 의 측 교환).
- **보조정리 2 [증명] (고정 단체 = 고정점).** 단체 사상 $\tilde\sigma$ 의 기하적 고정점 $x$ 는 $x$ 를 내부로 가진 단체 $s$ 가 $\tilde\sigma(s)=s$ 를 만족하게 하고, 그러한 $s$ 의 무게중심은 고정점이다. 따라서 고정점 존재 ⇔ $\tilde\sigma$-불변인 비공집합 단체 존재.

## 3. 정리 (정확한 판정)
**정리 1 [증명].** $\tilde\sigma$ 가 $B_0(G)$ 위에 고정점을 가진다 ⇔ ∃ $v\in V$: $\{v,\sigma v\}\in E$ (대각 간선).
*증명.* (⇒) $\tilde\sigma$-불변 비공집합 면 $(A,B)$ 는 $A=\sigma B$ 를 만족한다 (불변: $(\sigma B,\sigma A)=(A,B)$). $A\ne\emptyset$, $B\ne\emptyset$ 이어야 한다 (한쪽이 비면 다른 쪽도 비어 면이 빈 면). 임의의 $b\in B$ 에 대해 $\sigma b\in A$ 이고 $A\times B\subseteq E$ 이므로 $\{\sigma b, b\}\in E$. (⇐) $v\sim\sigma v$ 이면 $A=\{\sigma v\}$, $B=\{v\}$ 가 면이고 $\sigma B=A$, $\sigma A=B$ 이므로 불변. 보조정리 2 에 의해 고정점. ∎

**따름 2 [증명].** 대각 간선이 없으면 $\tilde\sigma$ 는 $B_0(G)$ 위에서 자유이다. 이때 몫 $B_0(G)/\tilde\sigma$ 는 자유 $\mathbb Z_2$-몫이다 (τ 와 함께 $\mathbb Z_2\times\mathbb Z_2$ 가 아니라 $\tilde\sigma$ 만 본다).

**정리 2 [증명] (고정 부분복합체).** 대각 간선 집합 $D=\{\{v,\sigma v\}\in E\}$ 에 대해 고정 단체는 정확히 $B\neq\emptyset$ 중 "$\sigma b\sim b'$ 가 모든 $b,b'\in B$" 를 만족하는 $(\sigma B,B)$ 이다. 이 면들의 기하적 합집합이 $\operatorname{Fix}(\tilde\sigma)$ 이고, 최소 원소는 대각 간선의 중점이다 (보조정리 2). 따라서 고정집합은 $|D|$ 개 간선의 중점에서 시작하는 작은 부분복합체이다.

## 4. 최소 반례와 시험 그래프
- **최소 반례 $K_2$** (정리 1 의 $v\sim\sigma v$): 위 요약 3. 고정점은 간선 $\{(1,1),(2,2)\}$ 의 중점 (그리고 $\{(2,1),(1,2)\}$ 의 중점도 고정). 즉 $\operatorname{Fix}$ 는 두 점. $B_0(K_2)/\tilde\sigma$ 는 선분이고 두 끝이 분기점이다.
- $K_{3,3}$ 의 측 교환 $\sigma$ (각 측 $\{a_i\}\leftrightarrow\{b_i\}$ 와 같은 번호를 짝짓는 σ): 대각 간선 $\{a_i,b_i\}$ 가 $K_{3,3}$ 에 있으므로 고정점이 있다 [계산 확인, 정리 1].
- $K_{3,3}$ 의 대각 간선이 없는 대합 (예: $\sigma=(a_1b_2)(a_2b_3)(a_3b_1)$, $\sigma$ 가 자기동형인지 확인 필요): 위 판정상 자유 [증명, 정리 1 과 보조정리 1 의 자기동형 조건을 만족할 때].
- $K_6$ 의 대합 $(03)(14)(25)$ 는 $\{0,3\}$ 등이 $K_6$ 의 간선이므로 대각 간선 3 개: 고정점 있음 [증명]. $K_6$ 에서는 대각 간선 없는 블록 교환 (예: $\sigma=(0\,4)(1\,5)(2\,3)$ 중 $\{0,4\}$ 가 간선인 것 제외 불가능, 모든 쌍이 간선) 은 존재하지 않는다 — $K_n$ 의 임의의 고정점 없는 대합은 대각 간선을 가진다 [증명].

## 5. R13-r3 번역에 대한 함의
- 분기 자리는 "블록 교환에 대한 몫 위의 분기점" 이며, 이는 **대각 간선의 중점** 에서 정확히 나온다 (정리 1, 2). 따라서 R13-r3 의 번역 (가) 는 $B_0$ 수준에서 확인된다. 반면 "블록 교환이 $B_0$ 위에 자유" 라는 명제는 대각 간선이 없을 때만 성립한다.
- 이 때문에 R13 의 τ 번역은 **대각 간선이 없는 교차 패턴** 으로 한정하면 확정된다 (따름 2). 대각 간선이 있으면 $\operatorname{Fix}$ 를 분기 자료로 따로 기록해야 한다.
- 주의: $\tilde\sigma$ 는 $\tau$ 와 가환이므로, $\tau\tilde\sigma$ (순수 자기동형 작용 $(A,B)\mapsto(\sigma A,\sigma B)$ 의 짝) 의 고정점도 따로 확인해야 한다. 이것은 $A=\sigma A$, $B=\sigma B$ 를 요구하며 $K_{2,2}$ 형 $\sigma$-불변 4-사이클이 있으면 생긴다. 이 조건은 본 보고서의 판정 범위 밖이다 [추측].

## 후속연구 지점
1. **$\tau\tilde\sigma$ 의 고정점 조건 (우선순위 1).** 이유: 분기 번역이 $\tilde\sigma$ 만 보면 놓치는 고정점이 있다. 시작: $\sigma$-불변 $K_{2,2}$ (두 σ-쌍 $\{v,\sigma v\},\{w,\sigma w\}$ 가 완전 이분을 이루는 경우) 가 $\tau\tilde\sigma$ 의 고정 단체를 만든다는 것을 증명하고, 이것이 $\tilde\sigma$ 의 대각 조건과 독립인지 확인. 난점: 두 작용의 고정 부분복합체 합집합 계산.
2. **대각 간선 중점 제거 (몫 정리).** 이유: 대각 간선이 있어도 $\tilde\sigma$ 의 고정점을 "분기 자리" 로 기록하면 RH 식이 χ 와 어떻게 맞물리는지 알 수 있다. 시작: 정리 2 의 고정 부분복합체를 빼고 얻는 몫 복합체의 호몰로지를 $K_2$, $K_{3,3}$ 에서 손계산. 난점: 대각 간선이 많은 그래프에서 호몰로지가 커진다.
3. **$\sigma$ 선택에 대한 불변성 (R13-r3 후속 4 와 연결).** 이유: 같은 G 에 여러 σ 가 있을 때 "대각 간선 없음" 을 만족하는 σ 가 존재하는지가 번역의 적용 범위를 정한다. 시작: $K_{3,3}$ 과 $C_5[K_2]$ 에서 대각 간선 없는 고정점 없는 블록 교환 존재 여부를 손으로 판정. 난점: $K_n$ 에서는 불가능이므로 (§4) 적용 범위가 $K_n$ 류 밀집 그래프를 제외한다는 점을 먼저 정리해야 한다.
4. **$K_2$ 반례의 가족화.** 이유: 최소 반례가 $K_2$ 이므로 교차 간선이 대각만인 그래프들의 분기 데이터가 어떤 불변량인지 정리할 수 있다. 시작: "대각 간선 집합 $D$ 의 크기 = 분기점 개수" 가 몫 χ 와 맞는지 $\overline{C_7}$, 완전 이분 류에서 확인. 난점: 대량 점검 금지 규칙, 손 계산 소수 예로 제한.
