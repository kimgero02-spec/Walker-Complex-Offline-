# GEN-1-minor-preservation: 내부 축약의 마이너 보존과 평면 임계 (일반 정리, 작은 예 없음)

- 작성: researcher1 (R39, 일반 이론 가공). 가정은 최소로 적는다. 표기: `[증명]`.
- 층 표기: (L0) 마이너 이론, (L1) 시트 블록 구조, (L2) Hadwiger 적용.

## 0. 정의
- 그래프 $G$, 간선 집합 $M\subseteq E(G)$. $G/M$: $(V,M)$ 의 연결 성분을 각각 한 점으로 수축하고 루프와 중복 간선을 제거한 그래프.
- $K_t$ 모델 $\mathcal X=(X_1,\dots,X_t)$: $X_i\subseteq V$ 연결 (유도 연결 아님, $G[X_i]$ 가 연결), 서로소, 모든 $i\ne j$ 에 대해 $X_i$–$X_j$ 간선 존재.
- **내부 집합** $M_{\rm in}(\mathcal X):=\bigcup_i E(G[X_i])$. 
- $M$ 이 $\mathcal X$ 에 대해 **내부적** $\iff$ $M\subseteq M_{\rm in}(\mathcal X)$.

## 1. 층 L0: 마이너 이론

**정리 1.1 (내부 축약은 모델을 보존).** $\mathcal X$ 가 $G$ 의 $K_t$ 모델이고 $M$ 이 내부적이면, $G/M$ 은 $K_t$ 마이너를 가진다. 
*증명.* $(V,M)$ 의 연결 성분 $C$ 는 단일 $X_i$ 안에 있거나 $V\setminus\bigcup X_i$ 안에 있다 (내부 간선은 한 $X_i$ 의 두 끝점만 잇는다). 따라서 성분들은 $X_i$ 를 쪼개지 않으며, $X_i$ 의 상 $X_i/M$ 은 $G/M$ 에서 연결 집합이다 (연결 집합의 수축 상은 연결). $X_i$–$X_j$ 간선의 상도 존재하므로 $\{X_i/M\}$ 은 $K_t$ 모델. ∎
- *단계:* (L0) 보존의 기본 정리. 이후 모든 축약 논법의 근거.

**정리 1.2 (K_t 부분그래프 판정).** 정리 1.1 의 가정에 추가로 각 $X_i$ 의 모든 점이 $M$ 의 한 성분에 들어가면 (즉 $M$ 이 $X_i$ 의 스패닝 연결 구조를 포함) $G/M$ 은 $K_t$ 를 **부분그래프** 로 가진다. 
*증명.* 모든 $X_i$ 가 한 점이 되므로 점들 사이 간선이 곧 부분그래프 간선. ∎
- *단계:* (L0) 부분그래프 판. 매칭 $M$ 에서는 $|X_i|\le2$ 일 때만 (R37 §2).

**정리 1.3 (평면 임계).** 정리 1.1 의 가정 아래 $G/M$ 이 평면이면 $t\le4$.
*증명.* 평면 그래프의 마이너는 평면 (마이너 닫힘), $K_5$ 는 비평면. 정리 1.1 로 $K_t$ 마이너가 있으므로 $t\le4$. ∎
- *단계:* (L0) 평면 임계. 평면 축약 단계 (R38 따름 2.2) 의 일반형.

**보조 [증명] (정리 1.3 의 필요성).** 내부성을 빼면 실패: $G=K_5$, 단일점 모델, $M=\{v_1v_2\}$ (비내부) 이면 $G/M=K_4$ 평면. *단계:* 가정 최소성 확인.

## 2. 층 L1: 시트 블록 구조와 축약

**정리 2.1 (블록 내부 축약은 시트 구조를 보존).** $G=B_1\cup B_2\cup H$ (교차 간선 집합 $H$), $B_i$ 평면, $M\subseteq E(B_1)\cup E(B_2)$. 그러면 $G/M=(B_1/M_1)\cup(B_2/M_2)\cup H'$ 이고 $B_i/M_i$ 는 평면 (평면 그래프의 축약은 평면) 이다. 즉 $G/M$ 은 다시 2-시트 평면 그래프 (블록 평면, 교차 무제한) 이다.
*증명.* 교차 간선은 축약되지 않으므로 상에 살아남고, $B_i$ 의 축약 상은 $B_i/M_i$ (평면). ∎
- *단계:* (L1) 시트 클래스 $\mathcal S_2$ 가 블록 내부 축약 아래 닫힘. 

**정리 2.2 (차수 상계는 보존되지 않는다).** 교차 차수 상계 $d$ (C3) 는 정리 2.1 아래 보존되지 않는다: 합쳐진 점의 교차 차수는 $d_H(x)+d_H(y)$ 이다. 
*증명.* 축약된 점의 교차 간선은 두 원점의 교차 간선의 합. ∎ 
- *단계:* (L1) 차수 클래스 $\mathcal S_d$ 는 축약으로 닫히지 않음 (REFINE-1 M-1 정정과 같은 사실의 일반형).

**정리 2.3 (평면 임계의 시트 버전).** $G\in\mathcal S_2$ 이고 $M$ 이 $\mathcal X$ 에 내부적이며 $G/M$ 이 평면이면 $t\le4$. 
*증명.* 정리 1.3 과 같음. 시트 구조는 여기서 쓰이지 않는다 (필요한 것은 $G/M$ 의 평면성뿐). ∎
- *단계:* (L1)→(L2) 연결: 시트 블록은 $G/M$ 의 평면성 판정에 쓰인다 (정리 2.1 로 $B_i/M_i$ 평면이 보장되면, 남은 것은 교차 $H'$ 의 평면성).

## 3. 층 L2: Hadwiger 적용 형태

**정리 3.1 (금지 마이너 형).** $\mathcal C$ 를 마이너 닫힌 클래스, $K_t\notin\mathcal C$ 라 하자. $G$ 가 $K_t$ 모델 $\mathcal X$ 를 갖고 $M\subseteq M_{\rm in}(\mathcal X)$ 이며 $G/M\in\mathcal C$ 이면 $\mathcal C$ 와 모순. 따라서 **$G/M\in\mathcal C$ 인 내부 $M$ 이 존재하는 $G$ 는 $K_t$ 모델을 가질 수 없다** (단, 이 모델이 내부 $M$ 과 맞을 때).
*증명.* 정리 1.1 로 $G/M$ 이 $K_t$ 마이너를 가짐, $\mathcal C$ 의 마이너 닫힘으로 $K_t\in\mathcal C$. ∎
- *단계:* (L2) K_t 금지의 일반 기준. $\mathcal C$ = 평면 ($t=5$), $\mathcal C$ = $K_t$-마이너-자유 (자기 순환은 쓸 수 없음 주의).
- 주의: 이 정리는 "$G$ 가 $K_t$ 마이너를 갖지 않는다" 를 뜻하지 않는다. 내부 $M$ 과 $G/M\in\mathcal C$ 가 동시에 있을 때만 $K_t$ 모델이 배제된다.

**정리 3.2 (가정 최소형, 평면).** $t=5$, $\mathcal C$ = 평면 그래프 클래스. $\mathcal X$ 가 $K_5$ 모델, $M$ 내부, $G/M$ 평면이면 모순. 따라서 **임의의 $K_5$ 모델에 대해 모든 내부 $M$ 에서 $G/M$ 은 비평면**. 
*증명.* 정리 1.3 의 $t=5$ 경우. ∎
- *단계:* (L2) $K_5$ 에 관한 축약 판정. Hadwiger $t=5$ 는 이미 알려진 (4색정리) 이므로 이 정리는 **방법의 검증** 이며 새 결과가 아니다.

## 4. 가정 목록 (최소)
| 정리 | 가정 | 불필요한 것 |
|---|---|---|
| 1.1 | 내부 $M$ (모델 기준) | 매칭일 필요 없음, 연결성 가정 외 없음 |
| 1.2 | 스패닝 포함 | — |
| 1.3 | 평면 마이너 닫힘 (사실) | 시트 구조 |
| 2.1 | 블록 평면, $M$ 블록 내부 | 교차 차수 |
| 2.2 | 차수 상계 정의 | — (반례 성질) |
| 3.1 | $\mathcal C$ 마이너 닫힘 | 평면성 |

## 5. 결론
- 일반 정리 (내부 축약 보존, 정리 1.1) 는 가정 없이 성립한다 (모델과 내부성만).
- 평면 임계 (정리 1.3) 는 $G/M$ 평면성 한 조건으로 $t\le4$ 를 준다.
- 시트 구조 (정리 2.1, 2.3) 는 블록 평면성을 축약 아래 보존하지만, 차수 상계 (정리 2.2) 는 보존하지 않는다. 따라서 시트 클래스 중 축약 아래 닫힌 것은 $\mathcal S_2$ (차수 무제한) 뿐이다.
- Hadwiger 적용 (정리 3.1) 은 "금지 마이너 클래스의 원소로 축약되는 내부 $M$ 이 있으면 모델이 없다" 는 형태이며, $t=5$ 에서는 정리 3.2 로 주어진다.

## 마지막 절: 후속연구 지점
1. **정리 3.1 을 $t\ge6$ 로 확장할 때 $\mathcal C$ 의 선택.** 이유: 평면이 $t=5$ 에만 맞는다. 시작: $K_6$-마이너-자유 클래스 (예: 외평면 쌍, Robertson–Seymour–Thomas [기억-미검증]) 를 $\mathcal C$ 로 두고 정리 3.1 의 조건을 확인. 난점: $\mathcal C$ 가 시트 블록과 맞물리는지.
2. **내부 $M$ 의 존재 조건 (일반형).** 이유: 정리 1.1 은 내부 $M$ 을 가정한다. 시작: 모델 $\mathcal X$ 의 분기 집합 크기와 내부 간선 수로부터 내부 매칭 (또는 내부 부분집합) 의 존재 조건. 난점: 분기 집합이 단일점이면 내부 간선이 없다.
3. **$\mathcal S_d$ 의 축약 닫힘 대체.** 이유: 정리 2.2 로 차수 상계가 축약에 닫히지 않는다. 시작: 축약 후 교차 차수를 $d_H(x)+d_H(y)$ 로 세며, 어떤 축약 순서가 상계를 보존하는지 정의 (예: 교차 끝점이 없는 내부 간선만 축약). 난점: 극소 반례에서 그런 간선이 있는지.
