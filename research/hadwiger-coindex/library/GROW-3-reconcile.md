# GROW-3-reconcile: d=2 과 d=4 의 역할 조정 (T7 입력 조건)

- 작성자·라운드·역할: researcher3 (망상꾼, 위상 기준). 증명 스케치와 정의 기준만, 계산 없음.
- 대조 대상: `GROW-2-realize.md` 는 **도서관에 없음**. d=2 쪽 내용은 문주님 지시문의 설명 ("리스트 크기 장애의 경계") 에만 의존하며, 아래 d=2 항목은 그 해석으로 적었다.

## 0. 실패 기준 (먼저)
- 조정 결론 A ("d=4 가 T7 입력 조건을 정확히 준다"): 실패 = $K_7$ 을 가지지 않으면서 χ≥7 이고 교차 차수 ≤3 인 클래스 멤버가 존재하여, 입력 조건을 d=4 로 잡은 T7 이 비공허하지 않음을 보장하지 못하는 경우. (또는 χ≥7 멤버가 d=4 밖에만 존재하는 경우.)
- 조정 결론 B ("d=2 는 리스트 장애의 경계"): 실패 = d=3 에서 리스트 장애가 이미 나타나는 예 (한 정점이 상대 블록의 색 4 개 전부를 금지) 한 개.

## 1. 두 값이 답하는 질문
| 값 | 답하는 질문 | 근거 |
|---|---|---|
| d=4 | "$K_7 = K_4+K_3$ 이 $\mathcal C_3(d)$ 에 들어오는 최소 $d$" (T7 의 **비공허 조건**) | 7 정점 두 블록 평면 분할은 4+3 뿐, 교차 차수 최대 4 (K_3 쪽 정점) |
| d=2 (해석) | "교차 차수 $d$ 에서 블록 색 리스트 (크기 $4-d$ 또는 $k-d$) 가 탐욕 색칠 장애를 만드는 경계" (T7 증명의 **색 충돌 조건**) | R20 (Hall 조건, 4 색 전부 금지가 장애), R33 (색 치환 실패) |

둘은 **다른 질문** 이다. d=4 는 "있는가", d=2 는 "색칠이 무너지는가". 같은 $d$ 로 묶으면 혼동된다.

## 2. 위상 기준 (a)(b)(c) 판정

| 기준 | d=4 (비공허 경계) | d=2 (리스트 경계) |
|---|---|---|
| (a) 부분그래프 단조 | ✓ (모든 $d$) | ✓ (모든 $d$) |
| (b) 조인 가법 (불변량) | 멤버십 ✗, 불변량 하계 ✓ (R14 C2) | 멤버십 ✗ (조인 교차 차수 $|V_2|$), 불변량 ✓ 같음 |
| (c) 교차 패턴 무관 | 상계 ✓, 값 ✗ | 상계 ✓ (색 리스트 논법이 패턴 무관하게 $d$ 만 씀, [추측]), 값 ✗ |

위상 기준 (a)(b)(c) 는 $d$ 를 구별하지 못한다. 세 기준 모두 $d$ 와 무관하게 같은 값이다. 따라서 $d$ 의 선택은 위상 기준이 아니라 **질문** (비공허 vs 색 장애) 으로 정해진다. 이것이 두 값이 충돌하는 것처럼 보인 이유다.

## 3. 역할 분담 (둘 다 필요하다)
- **입력 조건 (d=4):** T7 의 진술 "$G\in\mathcal C_3(4)$, $\chi\ge7$ ⇒ $K_7$ 마이너" 는 $d=4$ 에서 **의미 있다** (반례 후보 존재, $K_7$ 실현). $d\le3$ 에서 같은 진술은 $K_7$ 이 빠져 있어 자명하게 $\chi\ge7$ 이 되기 어렵다는 점 (미결) 에서 공허할 수 있다. 따라서 진술의 **범위** 를 정하는 것은 d=4.
- **증명 단계 (d=2 해석):** 색 리스트 장애가 $d\le2$ (리스트 크기 $\ge2$) 에서 사라지면, 탐욕 색칠이 블록 색 합 상계를 달성하는 단계를 쓸 수 있다. 이것은 T7 의 증명 중간 단계 (χ 상계 → $K_7$ 조립) 에 쓰이는 **보조 조건** 이다.
- 즉 T7 의 입력 조건은 **d=4 (범위)** 이고, 증명 단계의 보조 조건은 **d 작음 (리스트)** 이다. 둘 다 필요하다. 하나만 고르면 한쪽 단계가 빈다.

## 4. 제안 (정의 수준)
- 정의 매개변수는 $d$ 하나로 두되, 진술은 두 개로 나눈다: (T7-범위) $\mathcal C_3(4)$ 에서 T7; (T7-보조) $\mathcal C_3(d)$, $d\le2$ 에서 색 리스트 탐욕 보조정리. 후자는 이 정의에서 증명되어야 하며, 현재는 가설이다.
- 확인 필요: $d=3$ 에서 리스트 장애가 한 정점 (교차 이웃 3 + 블록 내 색 1 개 추가 금지) 으로 이미 나타나는지. 이것이 d=2 가 정확한 경계인지 결정한다.

## 5. 결과와 T7 단계 (한 줄씩)
- d=4 비공허 경계: T7 의 **입력 범위** (어느 클래스에서 진술하는가).
- d=2 리스트 경계: T7 증명의 **색 충돌 보조 조건** (탐욕 단계).
- (a)(b)(c) 판정: $d$ 를 구별하지 않음 → 위상 기준은 $d$ 선택에 쓰이지 않는다.

## 6. 후속연구 지점
1. **$d=3$ 리스트 장애 존재 여부 (우선순위 1).** 이유: d=2 가 정확한 경계인지 결정. 시작: 정점 하나가 상대 $K_4$ 의 4 색을 금지하려면 교차 이웃 4 개가 필요 (d=3 으로는 3 색 금지), 따라서 d=3 에서 한 정점 장애는 불가. 그러나 두 정점 쌍의 결합 장애 가능성을 정의 수준으로 점검.
2. **$d\le3$ 에서 χ≥7 실현 여부 (우선순위 2).** 이유: T7 범위 d=4 가 최소인지 결정. `REFINE-3-d-topology.md` §5 와 같은 질문.
3. **GROW-2-realize 대조 (우선순위 3).** 파일이 올라오면 d=2 의 리스트 장애 정의를 §1 해석과 맞추고, 차이가 있으면 §3 의 역할 분담을 수정.
