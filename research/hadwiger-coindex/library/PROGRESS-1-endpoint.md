# PROGRESS-1-endpoint: 끝점 자유도 보조정리 — 조건, 증명 상태, 최소 장애 (연구원1, 계산 없음)

- 입력: GROW-1-model.md 의 반례 B (블록 분기 모델의 끝점 위치가 교차 간선 H 와 맞지 않아 쌍 접촉이 빠짐).
- 표기: `[증명]` `[추측]` `[기억-미검증]`.

## 0. 문제의 정식화
평면 블록 $B$ 와 지정 끝점 집합 $E=\{p_{i,a}\}$ ($i=1..4$, $a=1,2$, 8 점) 에 대해, $K_4$ 마이너 모델 $X_1..X_4$ (연결, 쌍별 인접) 이 $p_{i,a}\in X_i$ 를 만족하는가. 교차 간선이 $E$ 의 점을 끝점으로 쓰므로, 이 조건은 모델 단계의 필요 조건이다.

## 1. 확정 결과
- **[증명] 자명한 경우.** $B=K_4$ 이면 모델은 단일점뿐이므로 $|E|=4$ 점이 정확히 한 점씩 들어가야 한다. 끝점이 8 개이면 $K_4$ 는 부족하다. 즉 $|V(B)|\ge8$ 이 필요하다 ($X_i$ 가 두 끝점을 가지려면 $|X_i|\ge2$ 여야 하므로 $|V(B)|\ge8$).
- **[증명] 쌍 조건.** 같은 $X_i$ 에 있는 두 끝점은 $B$ 안에서 연결 집합으로 묶여야 한다. 따라서 $p_{i,1},p_{i,2}$ 를 잇는 $B$ 의 경로가 $X_i$ 에 속하고, 그 경로가 다른 $X_j$ 의 끝점을 지나면 안 된다. 이는 $E$ 가 블록 안에서 "경로로 얽히지 않음" 을 요구한다.

## 2. 충분 조건 후보 (증명 안 됨)
- **조건 F (공통 면).** $B$ 의 평면 임베딩에서 8 개 끝점이 한 면 (외곽 면) 에 놓이면, 외곽 면 위 끝점을 갖는 $K_4$ 모델은 존재한다. 이것은 평면 그래프의 **근 마이너 (rooted minor) 정리** 의 형태이다 [기억-미검증, Robertson–Seymour 계열]. 
- 상태: 조건 F 는 충분 조건 후보이며 증명하지 않았다. 외곽 면 위의 끝점이 쌍을 이루는 순서 (예: $p_{1,1},p_{2,1},p_{3,1},p_{4,1},\ldots$ 의 순환 순서) 가 모델과 양립하는지는 추가 조건이다 [추측].
- **T7 에서의 쓰임:** 모델 단계 (GROW-1 §3 반례 B 의 해소). 끝점을 외곽 면에 모으면 위치 충돌이 없다.

## 3. 필요 조건과 최소 장애 (장애를 막을 수 없는 예)
- **장애 1 (면 분산).** 끝점이 두 개 이상의 면에 흩어져 있고, 각 면에서 필요한 순환 순서가 모델의 쌍 인접 (다른 $X_j$ 와의 연결 경로) 과 교차하면 모델이 없을 수 있다. 이 장애의 정확한 최소 예는 **구성하지 못했다** [추측].
- **장애 2 (끝점 개수).** $|V(B)|<8$ 이면 장애가 자명하다 (§1). 그러나 T7 의 블록 (χ=4 평면) 은 보통 $|V|\ge8$ 이므로 이 장애는 실제로 작다.
- **결론 (막을 수 있는가).** 현재 증명된 조건은 $|V(B)|\ge8$ 뿐이고, 임의의 끝점 위치에 대해 모델을 보장하는 조건은 증명하지 못했다. 막을 수 없는 최소 예 (끝점 위치가 모델을 완전히 막는 평면 블록) 도 구성하지 못했다. 따라서 **판정: 미결**.

## 4. 정의 쪽 해결 (권장, 결정은 문주님)
끝점 위치를 자유도가 아니라 **정의의 일부** 로 만들 수 있다: "교차 간선의 블록 쪽 끝점은 블록 한 외곽 면 위에 있다" 라는 조건을 C3 에 추가 (C3′). 이 조건 아래 끝점 위치 충돌은 조건 F 로 막힌다 (F 가 증명되면). 비용: 클래스가 좁아지고 정의가 바뀐다. 이 제안은 문주님 결정 사항이다.

## 5. T7 모델 단계에서의 위치 (보고 규칙)
- §1 (끝점 개수, 쌍 경로 조건): 모델 단계의 필요 조건. GROW-1 §1 과 일치.
- §2 (조건 F): 모델 단계의 충분 조건 후보 (반례 B 의 해소). 증명 필요.
- §3 (장애 1): 모델 단계의 실패 지점. 최소 예 미구성.
- §4 (C3′): 모델 단계를 정의에서 해결하는 대안 (문주님 결정).

## 마지막 절: 후속연구 지점
1. **조건 F 의 증명 또는 반례 (우선순위 1).** 이유: 반례 B 를 가장 직접적으로 막는다. 시작: 외곽 면 위 8 끝점에 대한 K_4 근 모델의 존재를 $|V|$ 에 대한 귀납으로 시도 (면 위 정점 삭제·축약). 난점: 근 마이너 정리의 정확한 조건과 인용 확인 필요 [기억-미검증].
2. **장애 1 의 최소 예 구성.** 이유: 조건 F 가 필요 조건인지 (면 분산이 실제로 모델을 막는지) 판정. 시작: 끝점 두 개가 서로 다른 면에 있고 쌍 경로가 교차하는 최소 평면 블록 (정점 ≤10) 을 이론적으로 구성. 난점: 계산 승인 전에는 손 구성만 가능.
3. **C3′ (외곽 면 제약) 의 비용 분석.** 이유: 정의 쪽 해결이 실제로 클래스를 얼마나 줄이는지 알아야 문주님께 결정 자료를 줄 수 있다. 시작: 외곽 면 제약 아래 T7 의 입력 클래스가 여전히 비공허인지 (d=2 와의 교집합) 확인. 난점: 외곽 면 제약과 차수 상계의 상호작용이 불명.
