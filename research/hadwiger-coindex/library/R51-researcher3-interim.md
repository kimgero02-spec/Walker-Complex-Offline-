# [R51-researcher3-interim] 셀로판의 기하: 순서형·볼록 위치·교차 그래프 — 아이디어 목록 (중간)
- 작성자: researcher3 (망상꾼, 분야: 이산·계산 기하) · 라운드 R51 · 중간 보고

## 번역 사전 (초안)
- 셀로판 겹침 (곧은 선) = (점 배치의 순서형 $\omega$, 간선의 층 배정). 두 선분 $ab,cd$ (끝점 공유 없음) 의 교차 여부는 네 방향 $\omega(a,b,c),\omega(a,b,d),\omega(c,d,a),\omega(c,d,b)$ 만으로 정해진다. [증명]
- 그림 $D$ 의 **교차 그래프** $\mathrm{Cr}(D)$: 정점 = 간선, 인접 = 교차. 층 배정 = $\mathrm{Cr}(D)$ 의 올바른 색칠. 고정 그림의 최소 층 수 $=\chi(\mathrm{Cr}(D))$. [증명]
- 층 사이 교차 수 $X$ = 그림의 교차 수 (층 안 교차는 0). [증명]
- 공유 골격 = 볼록 껍질 해밀턴 사이클: $\mathrm{Cr}$ 는 **원 그래프** (현들의 교차 그래프). [증명]

## 아이디어 (모두 [망상] 이며 시험 예정)
1. (제안 C) 볼록 골격 $k$ 층 ⇒ $\chi(G)\le 2k+2$; 더 세게 $\chi(G)\le 4\,\omega(\mathrm{Cr})$ (Capoyleas–Pach [기억-미검증]). 층 수가 아니라 **서로 교차하는 간선 최대 묶음** $\omega(\mathrm{Cr})$ 이 χ 를 제어.
2. 교차 보조정리: $X$ 개 층간 교차 ⇒ $\chi\le\max(8,1+(512X)^{1/4})$.
3. 일반 위치에서는 $\chi(\mathrm{Cr})$ 가 $\omega(\mathrm{Cr})$ 로 유계가 아님 (선분 교차 그래프, Pawlik 외 [기억-미검증]) — 그러나 $\chi(G)$ 는 $\omega(\mathrm{Cr})\le 3$ 이면 유계 (준평면 간선 수). "층 수 ≠ 결합 측도".
4. 볼록 $K_{2p}$ = $p$ 개 삼각분할 층; 층간 교차 행렬 = 삼각분할 사이 교차 (뒤집기 거리와 연결?).
5. 3 페이지 (볼록 3 층) 그래프의 χ 최댓값 7 또는 8? χ=7 예에 $K_7$ 마이너?
6. $K_8$ 은 곧은 선 2 층 (기하 두께 2) [기억-미검증] → 2 층 셀로판으로 χ=8.
7. Hanani–Tutte: 층간 교차의 홀짝 류 (cocycle) 가 0 ⇔ 평면. 결합 복잡성의 $\mathbb Z_2$ 판.
