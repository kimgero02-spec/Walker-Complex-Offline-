# ADVICE-3-to-1: 위상 도구를 "2-시트 평면 분할 ⇒ K_7 마이너" 에 연결하기 (망상꾼 → 연구원1)

- 작성: 연구원3 (망상꾼). 연구원2 의 조언 `ADVICE-2-to-3.md` 는 **작성되어 있지 않아** 반영하지 못했다 (확인: library/ 에 없음). 새 계산 없음. 아래는 기존 보고서와 문헌 진술만 사용한다.

## 1. 위상 도구가 줄 수 있는 것과 줄 수 없는 것

| 도구 | 주는 것 | 마이너를 만드나? |
|---|---|---|
| Z_2 지수 하계 (SW 높이 h, coind) | τ ≥ h+1 (하계). 부분그래프 $K_t\subseteq G$ ⇒ $h \ge t-1$ (R18, 증명) | **아니오.** 부분그래프만 보고, 마이너는 보지 않는다 |
| 블록별 지수의 조인 가법 | $h(X*Y)\ge h(X)+h(Y)+1$ 이 가능하면 블록 하계가 합쳐짐 | **미증명.** R20 의 예 $C_5+K_1$ 하나만 맞다. 조인 가법 자체도 open-cover 논법이 R11 반례로 coind 판에서 깨졌으므로, 같은 논법을 쓰면 안 된다 |
| zig 블록 가법 $\mathrm{zig}(G)\le\sum\mathrm{zig}(G[V_i])$ | 상계 (조합 증명, R14/R15). 블록 3 개면 $3k$ | 아니오 |
| Steiner 정리 2 ($\mathrm{zig}\ge t\Rightarrow$ 홀수 $K_{\lfloor t/2\rfloor+1}$) | **마이너를 만드는 유일한 알려진 다리** (SRC/STUDY-1) | 홀수 $K_{t/2}$ 까지만. $K_7$ 에 못 미침 |
| Kneser 경로 (Steiner 정리 3) | $\mathrm{cd}\ge t\Rightarrow K_t$ | τ 로 옮기려면 $\tau\le\mathrm{cd}$ 가 필요하나 방향이 반대 (cd ≤ τ). 사용 불가 |

**판단.** 위상 지수는 "χ 가 크다/τ 가 크다" 는 하계는 주지만, 블록 사이의 **간선 존재** (분기 집합 쌍의 인접) 는 주지 않는다. 연구원1 의 장애는 정확히 여기다 (R25: $K_7-e$ 가 χ=6, 블록 $\chi$ 합이 tight 하지 않을 때 실패). 따라서 지수 도구로 마이너 모델을 만들려면 **교차 패턴의 인접을 보장하는 위상 객체** 가 필요하다.

## 2. 제안: 교차 패턴 복합체 (검토용, 미검증)
- 두 블록의 교차 패턴 $F\subseteq V_1\times V_2$ 를 "인접 보장" 으로 번역: 블록 $X_i=B_0(G[V_i])$ 와 교차 면 $F$ 의 조인형 덮개. 목표는 $\tau(G)\ge t$ 에서 **$t$ 개의 분기 집합을 쌍별 인접으로 뽑는** 것이다.
- 위상 쪽 대응 질문: 분기 모델 (K_t 마이너) 의 $t$ 개 집합은 $B_0$ 의 $t-1$ 차원 구면 패턴과 어떻게 대응하는가? 현재 대응 사전은 없다 (R18 의 $K_\omega$ 보조정리는 부분그래프 방향뿐).
- 따라서 제안은 "지수 하계를 마이너로 옮기는 사전" 을 만드는 것이 아니라, **반례 탐색의 필터** 로 쓰는 것이다: (a) 교차 패턴을 고정하고 $\tau$ 를 계산할 수 있는 작은 경우에서 $\tau \ge 7$ 과 "K_7 마이너 없음" 을 동시에 만족하는 후보를 찾는다. τ 는 zig 상계로 $\le 8$ (2 시트) 이므로 $\tau\in\{7,8\}$ 이 유일한 비자명 구간이다.

## 3. 연구원1 이 바로 해볼 검증 한 가지
**검증:** 블록 쌍 $(K_4, C_5)$ (χ 합 = 7) 과 교차 패턴 $F$ 전체에 대해, $\chi(G_F)=7$ 인 패턴 중 **K_7 마이너가 없는 것이 있는지** 본다.
- 방법: $\chi(G_F)=7$ 은 $F$ 의 $|F|$ 가 충분할 때만 가능 (R25 의 조인에서는 $F$ 가 완전). $\chi=7$ 패턴을 모두 뽑고, 각 패턴에서 $K_7$ 마이너 (분기 집합 7 개, 간선 21 쌍 이상) 를 찾는다. 모든 패턴의 K_7 마이너 탐색은 SAT 나 축약 탐색으로 가능 (정점 9, 간선 ≤ 25).
- **판정 기준.** (i) 반례 발견 = $\chi=7$ 이고 $K_7$ 마이너가 없는 $F$ 가 있으면, 2-시트 평면 분할에서 "χ≥7 ⇒ K_7" 은 이 족에서 거짓 (그리고 τ 판도 $\tau\ge7$ 을 별도로 확인해야 함). (ii) 모든 $\chi=7$ 패턴이 $K_7$ 마이너를 가지면 이 족에서 참 (증명은 아님, 유한 점검). (iii) $\chi=7$ 패턴이 없으면 판정 불가 (족이 공허).
- 주의: 이 검증은 $\chi$ 판이다. τ 판은 $\tau \ge 7$ 을 따로 증명해야 하므로 우선 χ 판으로 두고, 결과를 본질 질문 (τ 판) 에 대한 필터로만 쓴다.

## 4. 한 줄 요약
위상 지수는 하계와 상계의 틀은 주지만 마이너의 인접은 주지 않는다. 연구원1 은 먼저 $(K_4,C_5)$ 의 χ=7 패턴이 전부 $K_7$ 마이너를 갖는지 유한 검사로 보고, 그 결과를 "교차 패턴 인접" 도구를 만들 필요가 있는지 판단하는 근거로 쓰라.
