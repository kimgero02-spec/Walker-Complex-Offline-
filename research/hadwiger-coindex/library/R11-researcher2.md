# [R11-researcher2] 정점 시트 (평면 블록) 아래 τ 의 쓸모 있는 상계: $\tau\le3k+s$, 그리고 J 의 상태

- 작성자·라운드·역할: researcher2 / 라운드 11 / 연구원2 (독립 연구). 연구원1 결과를 검증하지 않고 기본 정의 [정의-시트] 아래에서 자체 상계를 세웠다. 기존 `R10-researcher2.md` 는 수정하지 않았다.
- 기본 정의: $G$ 가 $k$-시트 평면 $\iff$ $V=V_1\sqcup\cdots\sqcup V_k$, 각 $G[V_i]$ 평면. 교차 간선 무제한.
- 표기: $\tau=\operatorname{coind}B_0+1$, $\iota=\operatorname{ind}B_0+1$, $\chi$. 모든 주장에 `[증명]` `[계산 확인]` `[추측]` `[망상]` `[기억-미검증]`.
- 계산: 새 대량 계산 없음. 소형 확인은 손으로 (대량 점검 금지).

## 요약
1. **[증명] $4k$ 는 $k$ 만의 함수로서 최선이다.** $K_{4k}=kK_4$ (평면 블록 $k$ 개) 에서 $\tau=4k$ 이므로, $k$ 만 주어진 상계 $f(k)$ 는 $f(k)\ge4k$ 이어야 한다. 따라서 $4k$ 를 넘는 개선은 $k$ 외의 파라미터가 필요하다.
2. **[증명] 새 상계 $\tau(G)\le 3k+s(G)$.** 여기서 $s(G)$ 는 블록 중 $K_4$ 마이너를 가진 것의 개수 ($0\le s\le k$). $s<k$ 이면 $4k$ 보다 엄밀히 작다. 증명은 $\iota$ 블록 합 (ind 형, 증명됨) 과 "$K_4$-마이너-자유 $\Rightarrow\chi\le3$" 만 쓴다. 프로젝트의 $\operatorname{coind}$ 조인 상계 J 를 쓰지 않는다.
3. **[증명] 새 상계는 모든 $(k,s)$, $0\le s\le k$ 에서 tight.** $K_{3k+s}$ 를 $s$ 개의 $K_4$ 와 $k-s$ 개의 $K_3$ 로 나누면 $\tau=3k+s$ 이다.
4. **J 의 상태:** 덮개 (레트랙션) 논법은 coind 에 대해 성립하지 않는다는 반례 (아래 4절) 를 얻었다. 조인 상계 J 는 여전히 **열림 [추측]**. J 는 $\iota_i=\tau_i$ 인 조각에서 성립한다 [증명].

## 1. $4k$ 의 최선성 [증명]
- $B_0(K_n)\cong S^{n-1}$ (독립 상 $\{v_1,v_2\}$ 를 피하는 단체들 = $n$ 개의 $S^0$ 의 조인) 이므로 $\tau(K_n)=n$.
- $K_{4k}$ 의 정점 집합을 $k$ 개의 $4$-집합으로 나누면 각 블록은 $K_4$ (평면) 이므로 $p(K_{4k})\le k$. 그리고 $\tau(K_{4k})=4k$.
- 따라서 $\tau\le f(k)$ 이려면 $f(k)\ge4k$. $\square$

## 2. 새 상계 $\tau\le3k+s$

**보조정리 A [증명] (블록 ι 합).** $V=\bigsqcup_iV_i$ 이면 $\iota(G)\le\sum_i\iota(G[V_i])$. (증명: $B_0(G)\subseteq *_iB_0(G[V_i])$ (면 $\sigma$ 의 $W_i$ 제한이 $B_0(G[V_i])$ 의 면), 조인 사상 $*f_i$ 가 동변. ind 는 부분복합체에 단조.)

**보조정리 B [증명] ($\iota\le\chi$).** 진색칠 $c$ 에 $\phi(v,1)=e_{c(v)}$, $\phi(v,2)=-e_{c(v)}\in\mathbb R^\chi$. 면 $(A,B)$ 에서 $c(A)\cap c(B)=\emptyset$ 이므로 $0\notin\operatorname{conv}\phi(\sigma)$. 정규화로 $\mathbb Z_2$-사상 $B_0\to S^{\chi-1}$, 즉 $\iota\le\chi$.

**보조정리 C [증명] (K_4-마이너-자유 $\Rightarrow\chi\le3$).** 최소 차수 $\ge3$ 인 그래프는 $K_4$ 마이너를 가진다 (표준 사실: Dirac). 따라서 $K_4$-마이너-자유 그래프의 모든 부분그래프는 차수 $\le2$ 인 정점을 가진다 (2-퇴화). 2-퇴화 그래프는 탐욕 색칠로 $3$-색칠 가능. $\square$

**정리 D [증명].** $G$ 가 평면 블록 $V=\bigsqcup_{i=1}^kV_i$ 으로 나뉘고, 그중 $s$ 개 블록이 $K_4$ 마이너를 가지면
$$\tau(G)\ \le\ \iota(G)\ \le\ \sum_i\iota(G[V_i])\ \le\ 3(k-s)+4s\ =\ 3k+s.$$
증명: 보조정리 A. $K_4$-마이너-자유 블록은 보조정리 C 와 B 로 $\iota\le3$. $K_4$-마이너 블록은 평면이므로 4색정리 [기억-미검증] 과 보조정리 B 로 $\iota\le4$. $\square$

참고: 4색정리 없이도 $\iota\le\chi$ 는 평면 블록의 $\chi$ 상계가 필요하므로, 정리 D 의 "$\le4$" 항은 4색정리에 의존한다 (프로젝트 기존 가정과 같다).

**따름 E [증명].** $s<k$ 이면 $3k+s<4k$. 즉 $K_4$ 마이너를 가진 블록이 하나라도 적으면 상계가 개선된다. 특히 $s=0$ (모든 블록이 직렬-병렬) 이면 $\tau\le3k$.

**정리 F [증명] (tight).** 임의의 $0\le s\le k$ 에 대해 $K_{3k+s}$ 는 $k$ 개의 블록 ($s$ 개의 $K_4$, $k-s$ 개의 $K_3$; 크기 합 $4s+3(k-s)=3k+s$) 으로 나뉘고, $K_4$ 마이너를 가진 블록은 정확히 $s$ 개다. $\tau(K_{3k+s})=3k+s$ (§1). 따라서 정리 D 는 이 $(k,s)$ 에서 tight. $\square$

**소형 확인 [계산 확인, 손].** $K_5$: $k=2$, 블록 $K_4\sqcup K_1$: $s=1$, 상계 $3\cdot2+1=7$. 실제 $\tau=5$ (상계는 여유). 그러나 같은 $K_5$ 를 $K_3\sqcup K_2$ 로 나누면 $s=0$, 상계 $6$, 여전히 여유. 상계 $3k+s$ 는 *이 분할의 $s$* 로 정의되므로, 그래프의 최선 분할을 고르면 $\min$ 이 더 낮을 수 있다. 정의: $\tau(G)\le\min_{\text{분할}}(3k+s)$.

## 3. 정리 D 의 한계 (정직한 기록)
- 정리 D 는 $\iota$ 블록 합만 쓴다. 그래서 $\tau$ 의 참값과 $\iota$ 의 간극을 그대로 물려받는다. $\iota$ 가 $\tau$ 보다 크면 상계는 여유가 있다.
- $\min$ 을 취한 상계가 실제 $\tau$ 와 같은지는 모른다. $C_5[K_2]$ 는 평면 블록 분할 $\{0,1\}\cup\{2,3,4\}$ 에서 두 블록의 $K_4$-마이너 여부가 있어 $3k+s$ 가 $\ge 4+\ldots$ 로 나온다. 즉 $\tau=4$ 와의 간극은 $\chi$-수준 간극과 같은 종류다 (미결).
- 정리 D 는 평면성을 쓰는 것이 $s$ 의 정의 (K_4 마이너) 에 들어가 있을 뿐이다. 평면성 자체는 블록이 $\chi\le4$ 임을 보장할 때만 쓰인다.

- 소형 기록 [계산 확인, 이전 R08 실행]: Grötzsch 그래프 ($\chi=4$, 삼각형-자유, 11 정점) 에서 $\operatorname{zig}\le4$ 가 성립하고 $\operatorname{zig}\le3$ 은 가지치기 전수 탐색에서 불가능했다 (742 초). 따라서 $\operatorname{zig}=4=\chi$ 이고 Grötzsch 는 $\tau<\chi$ 의 후보가 아니다 (이 판정은 $\operatorname{zig}$ 에만 해당; $\tau$ 는 여전히 $\le4$).

## 4. J (τ 조인 상계) 와 덮개 논법의 한계

**관찰 [증명] (J 와 ι).** 조각 $G_1,G_2$ 에 대해 $\tau(G_1+G_2)\ge\tau_1+\tau_2$ (조인 하한) 이고 $\tau(G_1+G_2)\le\iota(G_1+G_2)\le\iota_1+\iota_2$ (보조정리 A). 따라서 $\iota_i=\tau_i$ 이면 J 성립. 예: $C_5[K_2]+C_5[K_2]$ 에서 $\iota=\tau=4$ 이므로 $\tau=8$ [증명, $\iota(C_5[K_2])\le\operatorname{zig}=4$ 계산 확인].

**반례 [증명] (덮개 논법은 coind 에 대해 불충분).** $S^2$ 를 두 열린 불변 집합 $A=U\sqcup(-U)$, $B=V\sqcup(-V)$ 로 덮을 수 있다. 여기서 $U$ = 경도 $(-10^\circ,100^\circ)$ 의 띠 $\cup$ 북극 근방, $V$ = 경도 $(80^\circ,190^\circ)$ 의 띠. $U,-U$ 는 서로소 열린 집합이므로 $\operatorname{coind}A=0$ (연결 $S^1$ 의 상이 한 성분에 들어가면 대척 대응이 깨진다). 같은 이유로 $\operatorname{coind}B=0$. 그러나 $S^2$ 의 coind 는 2 이다. 따라서 "$S^m=A\cup B$ 이면 $m\le\operatorname{coind}A+\operatorname{coind}B+1$" 류의 덮개 보조정리는 **coind 에 대해 거짓**이다. R09-researcher3 의 J 증명이 쓴 레트랙션 논법은 이 한계에 걸린다 (R09 부록 참고).

**판정 [추측].** J 는 덮개 논법으로는 나오지 않는다. J 의 증명 또는 반례는 조각의 $\operatorname{ind}$ 와 $\operatorname{coind}$ 의 차이 ($\iota_i>\tau_i$ 인 $B_0$) 에 달려 있다. 현재 그런 $B_0$ 는 알려져 있지 않다.

## 후속연구 지점
1. **$\iota>\tau$ 인 $B_0$ 탐색 (J 의 유일한 시험대).** 이유: J 는 $\iota=\tau$ 인 조각에서 성립하므로, 반례는 $\iota>\tau$ 인 조각에서만 나올 수 있다. 시작: 정리 D 의 $s$ 를 줄이려면 블록의 $\iota$ 가 $\chi$ 보다 작아야 하므로, 이 탐색은 두 목표를 동시에 준다. 난점: $\operatorname{ind}$ 의 하계 (Stiefel–Whitney 높이) 는 coind 와 달라 정확한 계산 도구가 없다.
2. **$K_4$-마이너 블록 안의 $\iota$ 개선.** 이유: 정리 D 의 $s$ 항은 평면 $K_4$-마이너 블록에서 $\iota=4$ 를 쓴다. 그 블록이 $\iota\le3$ 이면 $s$ 항이 사라진다. 시작: 평면이면서 $K_4$ 마이너를 가지되 $\tau\le3$ 인 블록 (예: 바퀴 $W_n$ 류는 $\tau=4$ 이므로 제외) 을 찾거나 금지한다. 난점: 평면 $\Rightarrow\tau\le3$ 는 $K_4$ 자체에서 거짓이므로, 블록 조건은 $K_4$ 를 포함하지 않는 클래스로 좁혀야 한다.
3. **분할 최적화: $\min_{\text{분할}}(3k+s)$ 의 계산 가능성.** 이유: 정리 D 의 상계는 분할에 의존하므로, 실제 $\tau$ 와 맞는지 보려면 분할을 고르는 규칙이 필요하다. 시작: $C_5[K_2]$ 와 $K_{3k+s}$ 족에서 최소 분할을 손으로 찾아 $\tau$ 와 비교 (대량 점검 없이 2–3 예). 난점: 최소 분할 탐색은 조합적으로 크다.
4. **덮개 논법을 쓰는 J 증명 시도의 폐기 여부 판정.** 이유: 4절 반례는 덮개 보조정리의 coind 판이 거짓임을 보였다. 남은 길은 $B_0$ 의 구조 (box complex 의 면 조건) 를 쓰는 것뿐이다. 시작: $X=B_0(G_1)$, $Y=B_0(G_2)$ 의 면 구조에서 $\mathbb Z_2$-사상 $X*Y\to S^{\,c_X+c_Y+1}$ 을 직접 만들 수 있는지 (ind 가 아닌 coind 방향으로는 불가능하므로, 역방향 사상 $S^{c_X+c_Y+1}\to X*Y$ 의 존재 가부를 판정) 확인. 난점: 역방향 사상의 존재는 일반적으로 불가능하지 않다는 것 말고는 알려진 도구가 없다.
