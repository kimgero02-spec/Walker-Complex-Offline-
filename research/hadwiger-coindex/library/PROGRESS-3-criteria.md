# PROGRESS-3-criteria: 기준 A (K_7 멤버십, d=4) 와 기준 B (χ=7 멤버 존재, d=2) 의 분리 기록 초안

- 작성자·역할: researcher3 (망상꾼, 위상 기준). 한 번만 보고. 계산 없음.
- 입력: `GROW-2-realize.md` (d=2 에서 χ=7 실현은 미결), `REFINE-1-decision.md` (d*=2 를 "첫 비공허 값" 으로 결정), `GROW-3-reconcile.md` (내 조정 메모). `PROGRESS-1` (연구원1) 은 **도서관에 없음**.
- 표기: $\mathcal C_d$ = 교차 차수 ≤ d 인 2-블록 평면 분할 클래스 (C3(d)).

## 0. 실패 기준 (먼저)
- **기준 A 실패:** $K_7\notin\mathcal C_4$ 이거나, $K_7\in\mathcal C_d$ 가 $d\le3$ 에서 성립하는 분할이 발견됨 (분할 가정 또는 교차 차수 계산이 틀린 경우).
- **기준 B 실패:** $d=2$ 에서 $\chi=7$ 멤버가 **존재하지 않음** 이 증명되면 기준 B 는 "존재 경계" 가 아니라 "증명 기법의 경계" 로 격하된다. 반대로 $\chi=7$ 멤버가 $d=2$ 에서 명시 구성되면 기준 B 는 존재 경계로 확정.

## 1. 두 기준을 나란히
| 항목 | 기준 A (K_7 멤버십) | 기준 B (χ=7 멤버, 리스트 경계) |
|---|---|---|
| 질문 | 가장 작은 $d$ 에서 $K_7$ 이 $\mathcal C_d$ 에 있는가 | 가장 작은 $d$ 에서 $\chi=7$ 인 멤버가 있는가 (색칠 논법이 깨지는가) |
| 값 | $d_A=4$ (4+3 분할, 교차 차수 3·4) [계산 없이 구조 논증] | $d_B=2$ (REFINE-1-decision: $d\le1$ 에서 Thomassen 5-선택으로 χ≤6; $d=2$ 에서 리스트 크기 4 로 논법 실패) |
| 상태 | 구조 논증으로 확정 (분할 유일성은 7 정점 논증) | **존재는 미결** (GROW-2: 실현 구성 없음). $d_B$ 는 "논법이 깨지는 경계" 로만 확정 |
| 위상 기준 (a)(b)(c) | (a) ✓, (b) 멤버십 ✗ / 불변량 ✓, (c) 상계 ✓ | 같음 (위상 기준은 $d$ 를 구별하지 못함, GROW-3) |
| 근거 외부 정리 | 없음 (유한 구조) | Thomassen 5-선택, Voigt 4-선택 불가 [기억-미검증] |

## 2. 각 기준이 T7 의 어느 단계에 쓰이는가
- **기준 A → T7 입력 범위:** "$\mathcal C_4$ 에서 T7 을 진술한다" 는 범위 선택을 정한다. $d<4$ 에서는 $K_7$ 자체가 빠지므로 T7 의 결론 $K_7$ 이 그 클래스에서 자명하게 불가능할 수 있다 (공허 위험). **단계: 진술의 범위.**
- **기준 B → T7 증명 보조 조건:** "차수 2 정점이 반드시 있다" (GROW-2 §2 보조정리) 와 "$d\le1$ 에서 χ≤6" (REFINE-1 (a)) 는 증명 중간 단계 (χ 상계 → 색칠 실패 → 블록 구조 강제) 에 쓰인다. **단계: 증명 보조 조건.**
- **두 기준의 관계:** $d_B=2\le d_A=4$. 기준 B 는 색칠 논법의 경계, 기준 A 는 $K_7$ 실현의 경계다. 이 둘이 같은 질문이 아니므로 하나로 합치면 안 된다.

## 3. 결과 줄 (각 결과 옆 "T7 의 어느 단계")
- $d_A=4$ (K_7 의 4+3 분할 교차 차수 3,4): T7 진술 범위 (입력).
- $d\le1$ 에서 χ≤6 (Thomassen): T7 증명의 보조 색칠 단계 (REFINE-1 §1(a); 출처 [기억-미검증]).
- $d=2$ 에서 리스트 크기 4 로 논법 실패: T7 증명의 경계 (보조 조건의 한계).
- χ=7 존재 (d=2): **미결**, T7 비공허성 (GROW-2 로 열림).

## 4. 제안: 분리 기록 방식
- REFINE-1-decision 에 두 줄로 분리: (i) "진술 범위 $d=4$ (K_7 실현)", (ii) "증명 보조 경계 $d=2$ (리스트, 존재 미결)". 두 값을 한 $d$ 로 쓰지 않는다.

## 5. 갱신 대기
- `PROGRESS-1` (연구원1) 과 `GROW-2` 최종본이 올라오면 §1 상태 행 (기준 B 존재) 과 §3 마지막 줄을 갱신한다. 현재 GROW-2 는 실현 미결이므로 §1 의 기준 B 상태는 "미결" 로 유지.

## 6. 후속연구 지점
1. **기준 B 의 존재 판정 (우선순위 1).** $d=2$ 에서 $\chi=7$ 실현 또는 불가능 증명. 이유: T7 비공허성의 유일한 열린 조건. 시작: GROW-2 §2 의 축소 (K_4 블록, 단사 σ 전부 실패) 에서 $|N(y)|=2$ 정점 부분을 Voigt 류 4-선택 불가능 구조로 구성할 수 있는지 정의 수준으로 점검.
2. **Thomassen 인용 확인 (우선순위 2).** 이유: $d\le1$ 공허성 (χ≤6) 이 이 인용에 의존. 출처 확인 전까지 [기억-미검증].
3. **기준 A 의 분할 유일성 확인 (우선순위 3).** 이유: $d_A=4$ 가 $K_7$ 의 4+3 분할에만 의존한다는 주장을 7 정점 분할 논증으로 정리. 시작: 5 정점 이상 평면 집합이 $K_5$ 를 피하는 조건 (R28 의 5 정점 평면성 보조정리) 을 인용.
