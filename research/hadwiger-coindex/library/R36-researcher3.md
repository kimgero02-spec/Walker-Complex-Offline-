# [R36-researcher3] 교차 차수 0/1 정점의 위상 번역과 쌍별 인접 (T7 의 M+ 병목)

- 작성자·라운드·역할: researcher3 / R36 / 망상꾼 (분야: 대수적 위상수학). 계산 없음, 증명 스케치만.
- 대조 대상: `R36-researcher2.md` (연구원2 가젯 결과) 는 **도서관에 아직 없음**. 대조는 미완이며 아래 판정은 독립 스케치다.
- 표기: 블록 $V=V_1\sqcup V_2$, 교차 간선 $H\subseteq V_1\times V_2$, $d_H(v)=|N_H(v)|$ (v 의 상대 블록 이웃 수), $X=B_0(G)$, 면 $(A,B)$ ($A\times B\subseteq E$).

## 0. 실패 기준 (먼저)
- **Inert 주장 (I)**: $d_H(v)\le1$ 인 정점 v 를 제거하면 τ 가 1 이하로만 변한다 ($\tau(G)\le\tau(G-v)+1$). 실패 = $\tau(G)\ge\tau(G-v)+2$ 인 예 한 개.
- **Adjacency 주장 (A)**: "χ 또는 τ 가 블록 덮개 아래에서 큰 값을 가지면 블록 분기 집합 쌍 사이에 교차 간선이 존재" (쌍별 인접 보장). 실패 = τ (또는 χ) 가 큰데 어떤 두 분기 집합도 교차 간선으로 잇지 못하는 분할 한 개.
- 두 기준 모두 한 개의 반례로 정해진다. 실패 시 M+ 병목의 위치가 바뀐다.

## 1. 번역 (교차 차수 → 위상 데이터)
| 교차 데이터 | 위상 쪽 대응 |
|---|---|
| $d_H(v)=0$ | $v$ 의 모든 면이 $V_1$ 안에 있다: 별 $\mathrm{st}(v,i)\subseteq B_0(G[V_1])$ |
| $d_H(v)=1$, 이웃 $w$ | $v$ 를 포함하는 교차 면은 $(v,1)$ 과 $(w,2)$ 만 가질 수 있음: 교차 링크가 한 점 (펜던트) |
| $d_H(v)\ge2$ | 교차 링크가 $\ge2$ 점; 쌍 $(v,v')$ 의 교차 이웃 집합 비교 (Hall 류 구조, R20) |
| 블록 덮개 $U_i$ | 열린 덮개 (R09); 교차 면은 두 $U_i$ 에 모두 걸린다 |

## 2. 한 단계 스케치

**(I) 차수 0 정점은 교차 구조에서 빠진다 [증명 스케치].** $d_H(v)=0$ 이면 $(v,i)$ 를 포함하는 면 $(A,B)$ 는 $A\cup B$ 가 $N(v)$ 안에 있으므로 $V_2$ 쪽 원소를 가지지 않는다. 따라서 교차 면 (두 블록에 걸친 면) 의 집합 $D$ 는 $(v,\cdot)$ 를 포함하지 않고, $D$ 는 $V_1^{\ast}\cup V_2^{\ast}$ (차수 ≥1 정점) 위에서만 정의된다. 이는 $\mathrm{st}(v,i)$ 를 따라 deformation retraction 을 주므로 $B_0(G)\simeq B_0(G-v)$ 가 **교차 부분에 대해** 성립한다. 결과: 차수 0 정점은 τ 를 바꾸지 않는다 ($\tau(G)=\tau(G-v)$, 단 $v$ 가 블록 안 간선만 가질 때).
- T7 단계: 차수 0 정점은 분기 집합의 교차 연결자가 될 수 없으므로 제거해도 쌍별 인접 논법이 바뀌지 않는다 (K_7 모델은 차수 0 정점을 블록 내부 분기 집합으로만 쓴다).

**(I') 차수 1 정점은 축약형 펜던트 [증명 스케치].** $d_H(v)=1$, $N_H(v)=\{w\}$ 이면 $v$ 를 포함하는 교차 면은 $(v,1)$ 과 $(w,2)$ 를 포함하고 나머지는 블록 내부 원소이다. 이 면들은 "$v$ 를 $w$ 로 붙인" 구조와 같은 호모토피형을 준다 (기본 기초 collapse: $(v,1)$ 의 자유 면 제거). 따라서 $\tau$ 는 $\tau(G/vw)$ 에 의해 제어되며 $|\tau(G)-\tau(G-v)|\le1$ 이 기대된다. 단, $G/vw$ 는 블록 구조를 깨뜨리므로 평면 블록 조건은 보존되지 않는다 (축약 한 번이 블록 평면성을 깨는 경우가 있다, R15 의 축약 증가 계산과 같은 현상).
- T7 단계: 차수 1 정점은 분기 집합 사이의 교차 간선을 **정확히 하나** 만 제공한다. 쌍별 인접에 필요한 교차 간선 수 (K_7 의 21 쌍 중 교차 쌍) 를 셀 때 차수 1 정점은 최대 1 쌍만 기여한다.

**(A) 쌍별 인접은 위상으로 보장되지 않는다 [증명 스케치].** 주장: 위상 불변량 (τ, h, zig) 은 교차 간선의 **존재 집합** 에 대해 단조이지만, "어떤 두 분기 집합이 인접하는가" 라는 특정 쌍을 지정하지 못한다. 근거: τ 는 부분그래프 단조이고 (교차 간선 추가 시 τ 는 증가하거나 같음), 같은 τ 값을 주는 서로 다른 교차 패턴이 쌍 구조에서 다르다 (R18: $(K_4,K_4)$ 의 χ=5 패턴 중 어떤 것은 별, 어떤 것은 매칭). 즉 τ 는 인접 **개수** 의 함수가 될 수는 있지만 인접 **위치** 를 주지 않는다.
- 차수 ≥2 정점의 Hall 조건 (R20): 두 블록 사이 색 충돌은 교차 이웃 집합의 크기 (≥4 가 되면 색 전부 금지) 로 결정된다. 이는 위상이 아니라 리스트 색칠 (조합) 이다.
- T7 단계: 쌍별 인접 보장은 K_7 모델의 "접착" 단계이다. 이 단계는 위상 불변량으로 뒷받침되지 않는다.

## 3. 판정
- **위상으로 본 교차 차수 0/1 정점:** 차수 0 은 τ 에 무관 (inert, 증명 스케치), 차수 1 은 축약형 펜던트 (τ 를 ±1 이내로 제어, 증명 스케치). 따라서 **위상은 차수 0/1 을 구별하지 않고 차수 ≥2 의 교차 구조만 본다** (블록 덮개의 교차 면이 두 블록을 모두 가로지르는 곳).
- **쌍별 인접의 위상 보장:** 없음. τ 는 인접 개수만 제어하고 위치는 제어하지 않는다. M+ 병목 (인접 위치) 은 조합 쪽 (Hall, 리스트 색칠) 에 남는다.
- **K7−e 와의 대응 (R25 §3):** $K_7-e$ 의 교차 쌍 부족은 차수 2 정점 (두 교차 이웃을 가진 정점) 의 짝으로 나타난다. 차수 0/1 정점만으로는 $K_7-e$ 를 만들 수 없다는 점이 병목이 "차수 ≥2 의 Hall 구조" 에 있음을 보인다.
