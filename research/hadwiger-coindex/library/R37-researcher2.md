# [R37-researcher2] 축약 렌즈 G/M: χ(G/M) 와 χ(G) 의 관계 (증명 또는 반례)

- 작성자·역할: researcher2 (R37, 독립). 한 번만 보고. 표본 계산 없음.
- 표기: `[증명]` `[추측]`. 축약 $G/M$ 은 $M$ 의 각 간선을 한 점으로 모으고 평행 간선은 하나로 합친다 (M 은 매칭으로 한정, 루프 없음).
- 렌즈 예측의 단계 표시: (A) 비인접 식별, (B) 간선 축약 하한, (C) 반례, (D) 매칭 축약 하한.

## 0. 실패 기준 (먼저)
- **≥ 보장:** 조건 $\mathcal P$ 아래 $\chi(G/M)\ge\chi(G)$ 가 증명되면 성공. 반례 한 개가 나오면 $\mathcal P$ 는 실패.
- **≤ 보장:** 조건 $\mathcal Q$ 아래 $\chi(G/M)\le\chi(G)$. 반례 나오면 실패.
- 결과: ≥ 는 일반 간선 축약에서 보장되지 않고, 비인접 식별에서만 보장된다. ≤ 는 어떤 조건에서도 보장되지 않는다 (C).

## 1. 결과
**(A) 비인접 식별은 χ 를 내리지 않는다 [증명].** $u\not\sim v$ 이고 $G'$ 가 $u,v$ 를 한 점 $w$ 로 식별한 그래프라 하자. $G'$ 의 진색칠 $c'$ 에서 $c(u)=c(v)=c'(w)$, 나머지는 같게 두면 $G$ 의 진색칠이다 (유일한 새 간선 후보 $uv$ 는 없다). 따라서 $\chi(G)\le\chi(G')$.
- 렌즈 단계 (A): 식별을 "축약의 특수형" 으로 볼 때 χ 하한은 식별에 대해 자동이다.

**(B) 간선 축약은 χ 를 최대 1 만 내린다 [증명].** $e=uv$, $G'=G/e$, $w$ 는 병합점. $G'$ 의 $k$-진색칠 $c'$ 에 대해 $c(u)=c'(w)$, $c(v)=k+1$ 로 두면 $c$ 는 $G$ 의 $(k+1)$-진색칠이다 ($v$ 의 이웃은 색 $k+1$ 을 쓰지 않으므로 충돌 없음, $u$ 의 이웃은 $c'(w)$ 를 쓰지 않음). 따라서 $\chi(G)\le\chi(G')+1$.
- 렌즈 단계 (B): 한 번의 축약은 χ 를 1 이하로만 줄인다.

**(D) 매칭 축약 하한 [증명].** 매칭 $M$ 의 축약은 $|M|$ 번의 간선 축약이므로 (B) 를 반복: $\chi(G/M)\ge\chi(G)-|M|$.
- 렌즈 단계 (D): Hadwiger 형 주장에서 "축약 후에도 χ 가 크다" 를 주는 가장 강한 일반 하한이다. $|M|$ 이 작을 때만 쓸모가 있다.

**(C) 반례: 어느 방향도 일반적으로 보장되지 않는다 [계산 확인 없이 손 확인].**
- 올림: $K_{3,3}$ ($\chi=2$), 간선 $e$ 를 축약하면 병합점 $w$ 가 $a_2,a_3,b_2,b_3$ 와 인접하고 $a_2\sim b_2$ 이므로 삼각형 $w,a_2,b_2$ 가 생겨 $\chi(G/e)\ge3>2$. 따라서 $\chi(G/e)\le\chi(G)$ 는 일반적으로 거짓.
- 내림: $K_6$ ($\chi=6$), 매칭 $M=PM_3$ 축약은 $K_3$ ($\chi=3$). 내림 폭 3 = $|M|$ 로 (D) 의 하한이 정확히 맞는다.
- 렌즈 단계 (C): ≤ 방향은 두 예 모두 "같은 축약이 올리기도 내리기도 함" 을 보인다.

## 2. 조건 정리
| 주장 | 판정 | 근거 |
|---|---|---|
| 비인접 식별: $\chi(G/\{u,v\})\ge\chi(G)$ | 증명 (항상 성립) | (A) |
| 간선 축약: $\chi(G/e)\ge\chi(G)-1$ | 증명 (항상 성립) | (B) |
| 매칭 축약: $\chi(G/M)\ge\chi(G)-|M|$ | 증명 (항상 성립) | (D) |
| 간선 축약: $\chi(G/e)\ge\chi(G)$ | **일반적으로 거짓** (χ=3 인 $C_5$ 의 축약은 $C_4$, χ=2) | 반례 $C_5/e=C_4$ (손 확인) |
| 간선 축약: $\chi(G/e)\le\chi(G)$ | **일반적으로 거짓** ($K_{3,3}/e$) | (C) |
| 매칭 축약: $\chi(G/M)\le\chi(G)$ | 거짓 ($K_{3,3}/e$ 는 매칭 한 간선) | (C) |

- ≥ 보장 조건 후보 (미증명): $e=uv$ 에 대해 $N(u)\setminus\{v\}$ 와 $N(v)\setminus\{u\}$ 가 $\chi(G)-1$ 색 이하로 칠해질 수 있는 "공통 색 여유" 가 있으면 축약 후 χ 가 유지된다. 정확한 조건은 미정 [추측].

## 3. 렌즈 예측의 Hadwiger 연결 (단계 표시)
- (B)·(D) 는 "K_t 마이너 = 축약 + 삭제" 에서 χ 가 얼마나 줄 수 있는지의 상한을 준다. 즉 $K_t$ 마이너를 가진 축약 $H$ 에서 $\chi(H)\ge\chi(G)-|M|$.
- 이 하한은 $|M|$ 이 χ 에 비해 작을 때만 χ 를 보존한다. Hadwiger 를 축약 렌즈로 쓰려면 $|M|<\chi(G)-t$ 같은 조건이 필요하다 [추측].

## 후속연구 지점
1. **간선 축약의 χ 보존 조건 (우선순위 1).** 이유: §2 의 ≥ 보장 조건이 없으면 렌즈 예측은 Hadwiger 에 쓸 수 없다. 시작: $e=uv$ 에서 병합점 색과 $N(u)\cup N(v)$ 색의 충돌을 정식화. 판정: 충돌이 없는 색 여유 조건을 찾으면 (B) 를 등호로 강화.
2. **(D) 의 tight 족.** 이유: $K_6/PM_3$ 은 (D) 의 하한을 정확히 달성한다. 시작: $|M|=\chi-t$ 에서 $K_t$ 를 주는 축약이 tight 인 족을 손으로 찾기.
3. **비인접 식별을 Hadwiger 렌즈에 쓰는 방법.** 이유: (A) 는 항상 성립하므로, 식별형 축약만 쓰는 마이너 개념 (이른바 "contraction of non-edges") 에 대한 Hadwiger 질문은 (A) 로 χ 하한을 자동으로 얻는다. 시작: 식별만으로 $K_t$ 마이너를 만드는 조건 (식별 후 간선 생성) 을 정식화.
