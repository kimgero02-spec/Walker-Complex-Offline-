# [R15-researcher1] 대각 간선이 없는 교차 패턴에서 τ 상계: 몫 준동형, max+1 의 반례, τσ̃ 고정점 처리

- 작성자·라운드·역할: researcher1 / 라운드 15 / 연구원1. 입력 조건: $V=V_1\sqcup V_2$, $\sigma:V_1\to V_2$ 전단사 대합 (고정점 없음, $\sigma(V_2)=V_1$), 대각 간선 없음 ($v\not\sim\sigma v$ 모든 $v$). 교차 패턴 임의. 블록 내부는 R13 과 같이 평면을 가정할 때도 있고 일반인 경우도 있으며, 명시한다.
- 표기: `[증명]` `[계산 확인]` `[추측]` `[망상]` `[기억-미검증]`. 계산은 이 보고서의 최소 반례 확인 (손 계산).
- 기호: $\tilde\sigma(A,B)=(\sigma B,\sigma A)$ (R14), $\rho=\tau\tilde\sigma$, $\rho(A,B)=(\sigma A,\sigma B)$. $G/\sigma$ 는 몫 상 그래프 (정점 $V_1$, $\pi(x)\pi(y)$ 가 $x\ne\pi$-짝인 간선의 상).

## 요약
1. **[증명] 몫 준동형.** 대각 간선이 없으면 몫 사상 $\pi:V\to V_1$ ($\pi|_{V_1}=\mathrm{id}$, $\pi\sigma=\pi$) 은 $G$ 에서 $H:=G/\sigma$ 로 가는 **준동형**이다 (자기동형 가정 불필요). 따라서 $\tau(G)\le\tau(G/\sigma)$, $\chi(G)\le\chi(G/\sigma)$.
2. **[증명] $\tau\le\max_i\tau_i+1$ 은 거짓.** 최소 반례 (정점 8): $V_1=\{0,1,2,3\}$, $V_2=\{4,5,6,7\}$, $\sigma(i)=i+4$, 간선 $\{0,1\},\{6,7\}$ 과 $K_4$ 를 이루는 $\{0,6\},\{0,7\},\{1,6\},\{1,7\}$, 나머지 정점은 고립. 대각 간선 없음, $\tau=4$, $\tau(G[V_1])=\tau(G[V_2])=2$, $\max+1=3$.
3. **[증명] 반례의 최소성.** $K_4$ 가 $2+2$ 로 나뉘어 $\tau_i\le2$ 를 유지하려면 각 블록에 $K_4$ 의 두 정점이 있고, 그 두 정점의 $\sigma$-짝은 $K_4$ 밖에 있어야 하므로 $|V_i|\ge4$, 따라서 $n\ge8$.
4. **[증명] $\tau\le\sum\tau_i$ 는 이 반례에서 성립** ($4\le2+2$). 일반 증명은 얻지 못함 [추측] (R08 의 $J$ 와 같은 문제, 몫 준동형으로 조각 합으로 옮겨지지 않음).
5. **[증명] $\tau\tilde\sigma$ 고정점.** $\rho=\tau\tilde\sigma$ 는 $B_0(G)$ 위에서 **항상** 고정점을 가진다: 전체 면 $(\emptyset,V)$ 가 $\rho$-불변이다 ($n\ge2$). 비자명 고정점은 $\sigma$-궤도 두 개 $P,Q$ (서로소) 가 $P\times Q\subseteq E$ (완전 4-연결, $K_{2,2}$) 를 이룰 때 정확히 생긴다. 표준 $B(G)$ (두 변 모두 비공집합) 에서는 전체 면이 빠지고, 비자명 고정점은 이 $K_{2,2}$ 조건뿐이다.

## 1. 몫 준동형 [증명]
- 정의: $H:=$ 정점 $V_1$, 간선 $\{\pi x,\pi y\}$ ($\{x,y\}\in E$, $\pi x\ne\pi y$). 
- $\pi x=\pi y$ 이면 $y\in\{x,\sigma x\}$, $y\ne x$ 이므로 $y=\sigma x$, 즉 대각 간선. 대각 간선이 없으므로 $\pi$ 는 간선을 보존하고 $H$ 는 단순 그래프이다. 따라서 $\pi$ 는 준동형.
- 따름: $\tau(G)\le\tau(H)$ (준동형 단조, R06·R07 의 D 보조정리), $\chi(G)\le\chi(H)$, $|V(H)|=n/2$.
- 예: $C_6$ 과 $\sigma=$ 회전 $3$ (대각 간선 없음): $H=K_3$, $\tau(C_6)=2\le3$. [계산 확인]

## 2. $\tau\le\max\tau_i+1$ 의 반례 [증명]
- $G$: $V=\{0,\dots,7\}$, $V_1=\{0,1,2,3\}$, $V_2=\{4,\dots,7\}$, $\sigma(i)=i+4 \pmod 8$ (대합, 고정점 없음, $V_1\leftrightarrow V_2$).
- 간선: $K_4$ on $\{0,1,6,7\}$ (즉 $01,67,06,07,16,17$). 나머지 간선 없음.
- 대각 간선 $\{0,4\},\{1,5\},\{2,6\},\{3,7\}$: $K_4$ 에 없으므로 없음 ✓.
- $G[V_1]$: 간선 $01$ 하나 $+$ 고립 2 개: $\tau=2$. $G[V_2]$: 간선 $67$ 하나: $\tau=2$.
- $\tau(G)$: $\tau\ge\omega=4$ ($\tau\ge\omega$ 는 보조 사실 [증명]), $\tau\le\chi=4$ 이므로 $\tau(G)=4$.
- 따라서 $\tau(G)=4>3=\max\tau_i+1$. ∎
- 최소성 (§주 3): $\tau(G)\ge\tau_1+\tau_2$ 가 아닌 한 $\max\tau_i+1$ 반례는 $K_4$ 류의 $2+2$ 분할을 요구하고, 이때 $n\ge8$. $K_6$ 류 (대각 간선 존재) 와 $K_5$ 류 (홀수 $n$) 는 입력 조건에서 제외된다. [계산 확인: 손으로 $K_4$ 의 $\sigma$-짝 위치 분석]

## 3. $\tau\le\sum\tau_i$ 와 몫 경로 [추측]
- 반례 (§2) 는 합 형태와 일치한다 ($4=2+2$). 일반 증명은 준동형 $G\to G/\sigma$ 로 조각 합을 얻지 못한다: $G/\sigma$ 는 $G[V_1]$ 에 교차 유도 간선을 더한 그래프이며 그 $\tau$ 를 $\tau_1,\tau_2$ 로 제한할 도구가 없다 [추측].
- 조각 합 대신 확실한 상계: $\tau(G)\le\iota(G)\le\iota_1+\iota_2$ (R08) — $\iota$ 판이며 $\tau$ 판 아님.

## 4. $\tau\tilde\sigma$ 의 고정점 처리 [증명]
- **(i) 전체 면.** $\rho(\emptyset,V)=(\sigma\emptyset,\sigma V)=(\emptyset,V)$. 따라서 $B_0(G)$ 에서 $\rho$ 는 항상 고정점을 가진다 (무게중심). 이 고정점은 "빈 쪽" 면에서 나오며, 표준 $B(G)$ 에는 없다.
- **(ii) 비자명 고정 단체.** $\rho(A,B)=(A,B)$, $A,B\ne\emptyset$ 이면 $A,B$ 는 $\sigma$-불변이고 ($\sigma A=A$, $\sigma B=B$) $A\times B\subseteq E$. $A$ 는 $\sigma$-궤도의 합이므로 궤도 $P\subseteq A$, $Q\subseteq B$ 를 잡으면 $P\times Q\subseteq E$. 역으로 서로소 궤도 $P,Q$ 에서 $P\times Q\subseteq E$ 이면 $(P,Q)$ 가 $\rho$-불변 면이다. 
  따라서: **$B(G)$ 에서 $\rho$ 의 비자명 고정점 $\Leftrightarrow$ 서로소인 두 $\sigma$-궤도가 완전 이분 $K_{2,2}$ (4 간선) 를 이룸.** 궤도 $P=\{v,\sigma v\}$ 의 내부 간선 $v\sigma v$ 는 조건이 아니다.
- **(iii) 대각 조건과의 독립성.** $\tilde\sigma$ 의 자유성은 대각 간선 조건만, $\rho$ 의 비자명 자유성은 궤도쌍 $K_{2,2}$ 조건만 본다. 두 조건은 독립이다: 대각 간선이 없어도 서로소 궤도 $P,Q$ 가 $P\times Q\subseteq E$ 이면 $\rho$ 에 비자명 고정점이 생긴다. §2 반례에서는 궤도 $\{0,4\},\{1,5\}$ 등 어떤 쌍도 완전 연결이 아니므로 (예: $0\sim1$ 이지만 $4\not\sim5$) 비자명 $\rho$-고정점이 없다 [계산 확인, 손].
- **(iv) 처리.** 두 가지 선택: (α) $B(G)$ (표준) 를 쓰면 전체 면 문제는 사라지고, 남은 고정점은 궤도쌍 $K_{2,2}$ 뿐이다. (β) $B_0$ 를 쓰면 $\rho$ 는 항상 비자유이므로 $\rho$-몫을 쓸 수 없고 $\tilde\sigma$ 만 쓴다. 번역은 $\tilde\sigma$ 기반이 맞다.

## 후속연구 지점
1. **$\tau\le\tau_1+\tau_2$ (대각 없음) 의 증명 또는 반례 (우선순위 1).** 이유: 몫 준동형은 $\tau(G)\le\tau(G/\sigma)$ 까지만 준다. 시작: $G/\sigma$ 의 $\tau$ 를 $G[V_1]$ 의 $\tau$ 와 교차 유도 간선의 기여로 나누는 조인 구조를 찾는다 (R08 의 조인 상계 $J$ 와 같은 문제). 난점: 몫 그래프의 교차 간선은 원래 교차 패턴의 함수이므로 독립 변수가 아니다.
2. **몫 $H=G/\sigma$ 의 $\chi$ 와 $\tau$ 의 관계 (분기 번역).** 이유: $\chi(G)\le\chi(H)$ 가 준동형에서 나오므로, $\chi(H)$ 를 블록 데이터로 상계하면 $\tau$ 상계가 된다. 시작: 평면 블록 $V_1$ 에서 $H$ 가 평면에 가까운지 (교차 유도 간선 수 제한) 확인. 난점: 교차 간선 패턴에 제약이 없다면 $H$ 는 임의 그래프에 가깝다.
3. **$\rho$ 의 궤도쌍 $K_{2,2}$ 가 몫에서 무엇인지.** 이유: $B(G)$ 에서 $\rho$-고정점은 몫 $H$ 의 "중복 간선" (궤도쌍 4 간선) 에 대응할 것으로 예상된다. 시작: $H$ 의 간선 가중치 (원래 교차 간선 수 $0..4$) 와 $\rho$-고정점의 관계를 정리. 난점: 가중치 정보가 $\tau$ 의 위상에 어떻게 들어가는지 불명.
4. **반례 최소성의 일반화.** 이유: §2 반례는 $\tau_i=2$ 블록에서 나왔다. 시작: $\tau_i\le k$ 인 블록에서 $\tau\ge k+2$ 가 가능한 최소 $n$ 을 $k=3$ 에서 손으로 확인 (대량 점검 금지). 난점: 블록이 $K_5$-류가 되면 대각 조건과 충돌한다.
