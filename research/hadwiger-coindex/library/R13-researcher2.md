## 요약
1. **[증명] I-1 은 분리를 준다.** $C(G,\mathcal V)\ge0$ (부분그래프 단조), $C\le\sum_i\iota_i-\tau_{\rm blk}$ (ι 블록 합, 증명됨). 두 경계 모두 tight (완전 교차 $K_{4k}$ 와 $K_4$ 2+2 에서 $C=\sum\iota_i-\tau_{\rm blk}$). 즉 시트 기여는 $\tau$ 에서 블록 최댓값을 뺀 값으로 정의되고, 상계는 블록 값만으로 계산된다.
2. **[증명] 교차 패턴에 따라 $C$ 가 달라진다 (최소 예).** 두 $K_2$ 블록의 교차 패턴 6 종에서 $C\in\{0,1,2\}$ 이다. 매칭 교차는 $C=0$ (C_4), 두 간선이 한 정점을 공유하면 $C=1$ (paw), 완전 교차는 $C=2$ (K_4). 가장 작은 $C>0$ 예는 $K_2$ (두 $K_1$ 블록, $C=1$).
3. **[증명] I-5 의 nerve 는 τ 에 대해 직접 쓸 수 없다.** 블록 덮개 $\{U_i\}$ 는 Z_2-불변이어서 nerve 의 Z_2 작용이 자명하다. 자명 작용에서는 equivariant coind 가 무한대가 되어 정보가 없다. I-5 의 예측 "$K_8$ 에서 $\tau(N)=1$" 은 이 오류 위에 세워졌다.
4. **[증명] I-5 의 마이너 판은 완전 교차에서 성립한다 (조인 보조정리).** 교차가 모든 블록 쌍에서 완전이면 $h(G)\ge\sum_i h(G[V_i])$ ($h$ = 최대 완전 마이너 크기). 따라서 블록들이 Hadwiger 를 만족하면 조인도 만족한다. 일반 교차 패턴에서는 이 보조정리가 깨진다 (쌍별 인접을 보장하지 않음).

## 1. I-1: 교차 기여 $C$ 의 분리

**명제 1.1 [증명].** $C(G,\mathcal V)\ge0$. 증명: 블록만 남긴 $G_{\rm blk}=\bigsqcup G[V_i]$ 는 $G$ 의 부분그래프이므로 $\tau(G)\ge\tau(G_{\rm blk})\ge\max_i\tau(G[V_i])$ (단조성, 후자는 $G[V_i]\subseteq G_{\rm blk}$).

**명제 1.2 [증명].** $C(G,\mathcal V)\le\sum_i\iota_i-\tau_{\rm blk}$. 증명: $\tau\le\iota\le\sum\iota_i$ (ι 블록 합, R08/R11 증명) 에서 빼기.

**tight 예 [증명].** $K_{4k}=kK_4$: $\tau=4k$, $\tau_{\rm blk}=4$, $\sum\iota_i=4k$ (각 $\iota(K_4)=4$). $C=4k-4=\sum\iota_i-\tau_{\rm blk}$. 등호.

**교차 패턴 표 (두 $K_2$ 블록 $\{a,b\}$, $\{c,d\}$, 블록 내 간선 $ab$, $cd$ 는 고정, 교차 간선 집합 $F\subseteq\{ac,ad,bc,bd\}$).** $\tau_{\rm blk}=2$.

| 교차 $F$ | 그래프 | $\tau$ | $C=\tau-2$ | 근거 |
|---|---|---|---|---|
| $\emptyset$ | $2K_2$ | 2 | 0 | 이분, 간선 있음 [증명] |
| $\{ac\}$ | $P_4$ | 2 | 0 | 이분 [증명] |
| $\{ac,bd\}$ (매칭) | $C_4$ | 2 | 0 | 이분 [증명] |
| $\{ac,bc\}$ (별) | paw (삼각형+꼬리) | 3 | 1 | $\tau\ge\tau(K_3)=3$, $\chi=3$ [증명] |
| $\{ac,bc,ad\}$ | $K_4-e$ | 3 | 1 | $\tau\ge3$, $\chi=3$ [증명] |
| $\{ac,ad,bc,bd\}$ | $K_4$ | 4 | 2 | $B_0(K_4)=S^3$ [증명] |

- 해석: 같은 블록에서 교차 패턴만 바꾸어도 $C$ 가 $0,1,2$ 사이를 움직인다. 매칭 교차는 $C$ 를 올리지 못한다. 따라서 "시트 기여" 는 패턴의 함수이며, 블록 값만으로는 정해지지 않는다.
- 상계 확인: 이 표에서 $C\le\sum\iota_i-\tau_{\rm blk}=(2+2)-2=2$ 가 모두 성립한다 (ι 값은 $\iota(K_2)=2$ 이므로 $\tau\le\iota\le\sum$ 에서 $\tau\le4$).

**최소 예.** $K_2$ 를 두 $K_1$ 블록 $\{a\}$, $\{b\}$ 로 나누면 $\tau_{\rm blk}=1$, $\tau=2$, $C=1$. 이것은 교차 간선 하나가 $\tau$ 를 1 올리는 가장 작은 경우다 [증명].

**I-1 의 답.** 블록만 보는 해석 ($\tau_{\rm blk}$) 과 실제 $\tau$ 의 차이 $C$ 는 교차 패턴의 단조 함수로 잴 수 있고, 상계 $\sum\iota_i-\tau_{\rm blk}$ 로 위에서 막힌다 [증명]. 이 상계는 완전 교차에서 tight 이다. 따라서 "시트 쪽이 상계에 기여하는 정도" 는 $C$ 로 분리되고, 그 상한은 ι 블록 합으로 준다. 다만 $\tau_{\rm blk}=\max\tau_i$ 가 블록 합과 어떻게 맞물리는지는 블록 전체의 $\tau$ 값에 달려 있다 (J 일반론은 여기서 쓰지 않는다).

## 2. I-5: nerve 정리의 τ 판과 마이너 판

**명제 2.1 [증명] (τ 판 nerve 는 자명 작용).** 블록 덮개 $U_i=\{x:\operatorname{supp}x\cap W_i\neq\emptyset\}$ 는 각각 Z_2-불변이다 ($W_i=V_i\times\{1,2\}$ 가 대합 $1\leftrightarrow2$ 로 불변). 덮개의 nerve $N$ 의 꼭짓점은 $i$ 이고 간선 $ij$ 등은 교집합 $U_I\ne\emptyset$ 로 정해진다. Z_2 는 각 $U_I$ 를 자기 자신으로 보내므로 $N$ 의 작용은 자명하다. 자명 작용 복합체에서 상수 사상 $S^n\to N$ 은 모든 $n$ 에 대해 동변이므로 equivariant coind 는 무한대가 된다. 따라서 nerve 정리의 동변 판을 τ 에 직접 적용할 수 없다. I-5 의 "$\tau(N)=1$" 예측은 이 오류에 의존하므로 기각한다.

**명제 2.2 [증명] (마이너 판, 완전 교차).** $\mathcal V=\{V_1,\dots,V_k\}$, 모든 $i\ne j$ 에서 $V_i$ 와 $V_j$ 사이 간선이 완전 ($\forall u\in V_i,v\in V_j:uv\in E$). 그러면 $h(G)\ge\sum_i h(G[V_i])$.
증명: 각 $G[V_i]$ 에서 $K_{h_i}$ 마이너의 분기 집합 $B_{i,1},\dots,B_{i,h_i}$ (서로소, 블록 내부 연결) 를 잡는다. 다른 블록의 분기 집합은 서로소이고, 서로 다른 블록의 임의의 두 분기 집합 사이에는 완전 교차 간선이 있으므로 인접하다. 같은 블록 안의 두 분기 집합은 블록 마이너의 인접으로 인접하다. 따라서 $\{B_{i,a}\}$ 는 $K_{\sum h_i}$ 의 분기 모델이다. ∎

**따름 2.3 [증명].** 완전 교차 블록 합에서 $\chi=\sum\chi_i$ 이고, 블록들이 Hadwiger 를 만족하면 ($h_i\ge\chi_i$) 합도 만족한다: $h\ge\sum h_i\ge\sum\chi_i=\chi$.

**명제 2.4 [추측] (부분 교차).** 교차가 완전이 아니면 명제 2.2 는 깨진다. 필요한 것은 "블록 $i$ 의 각 분기 집합과 블록 $j$ 의 각 분기 집합이 인접" 이다. 이는 교차 간선 공리 $\mathrm{A}_c$ 로 명시할 수 있다: 각 블록 쌍에 대해 교차 간선이 두 블록의 임의의 분기 모델에 대해 쌍별 접촉을 준다. $\mathrm{A}_c$ 아래에서는 2.2 가 성립하지만 $\mathrm{A}_c$ 를 만족하는 패턴이 완전 교차보다 얼마나 적은지는 미결이다 (교차 밀도와 분기 모델의 존재 사이의 조합 정리가 필요).

**I-5 의 답.** nerve 를 τ 판으로 쓰면 자명 작용 때문에 실패한다 (2.1). nerve 의 마이너 판 (분기 집합의 교차 접촉 = nerve 의 간선) 은 완전 교차에서만 바로 작동하며 (2.2), 이 경우 Hadwiger 는 블록에서 조인으로 올라간다 (2.3).

## 후속연구 지점
1. **교차 공리 $\mathrm A_c$ 의 최소 밀도 (우선순위 1).** 이유: 명제 2.2 의 마이너 판을 완전 교차보다 약한 패턴으로 옮기면 I-5 가 실제로 마이너를 만든다. 시작: 블록 쌍마다 "모든 분기 집합 쌍을 잇는" 최소 간선 수를 $K_4$ 블록 (분기 모델 $K_4$, 각 점 한 정점) 에서 계산하고 그 패턴이 완전 교차를 요구하는지 확인. 난점: 분기 모델 선택이 패턴마다 다르다.
2. **$C$ 의 교차 패턴 의존성의 단조성 구조.** 이유: 표에서 매칭은 $C=0$, 별은 $C=1$ 이었다. 패턴 격자에서 $C$ 가 어떻게 올라가는지 (예: $C$ 가 정점별 교차 차수의 함수인지) 를 알면 시트 기여를 교차 차수로 쓸 수 있다. 시작: 블록 크기 2 (두 $K_2$) 의 패턴 표를 블록 크기 3 으로 올려 "별 교차" 가 $C=1$ 인 조건을 찾는다. 난점: 패턴 수가 지수적이다 (대량 점검 금지, 구조 정리로만).
3. **블록 τ 의 극값과 $\tau_{\rm blk}$ 의 관계.** 이유: 상계 $\sum\iota_i-\tau_{\rm blk}$ 는 블록 $\iota$ 값을 쓴다. 블록 $\iota$ 가 $\tau$ 보다 크면 상계가 느슨하다. 시작: $\iota(H)=\tau(H)$ 를 보장하는 블록 클래스 (예: $\chi=\tau$ 인 블록) 를 찾아 상계를 $\tau$ 로만 쓴다. 난점: 본 보고서는 블록 ι 가 τ 와 같은지 판정하지 않았다 [추측].
