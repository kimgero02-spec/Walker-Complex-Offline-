## 요약
1. **[증명] 우선 질문 J (τ 조인 상계) 는 이번 라운드에서도 해결되지 않았다.** 시도: 조인 $G_1+G_2$ 의 $B_0$ 이 $B_0(G_1)*B_0(G_2)$ 와 같으므로 J 는 $\operatorname{coind}(X*Y)\le\operatorname{coind}X+\operatorname{coind}Y+1$ 과 같다. 특수형 J$_1$ (한쪽이 $K_1$, 즉 원뿔) 은 "닫힌 불변 $Z\subseteq S^m$ 의 여집합이 $W\sqcup(-W)$ 이면 $\operatorname{coind}Z\ge m-1$" 이라는 분리 보조정리 (Sep) 로 줄어든다. Sep 는 [추측] 이다.
2. **[증명] Hadwiger 쪽:** S1 (τ 판) 과 χ 판 Hadwiger 는 $t\le5$ 에서 모든 그래프에 대해 성립한다 (t=4: $K_4$-마이너-자유 ⇒ 2-퇴화 ⇒ $\chi\le3\Rightarrow\tau\le3$; t=5: Wagner [기억-미검증]). 시트 분해는 $t\le5$ 에 아무것도 더하지 않는다. $k$-시트 평면 그래프에서 $\tau\le4k$ 이므로 S1 은 $t>4k$ 에서 자명하게 성립한다 (비어 있음). 시트로 의미 있는 범위는 $t\le4k$ 이고 여기서 시트 구조만으로는 K_t 마이너를 강제하지 못한다 [추측].
3. **[증명] R11 정리 D 의 $s$ 를 개선한다.** $s$ 를 "$K_4$-마이너를 가진 블록 수" 에서 "$\chi=4$ 인 블록 수" $s_4$ 로 바꿀 수 있다: $\tau\le3k+s_4\le3k+s$. 예: 삼각기둥 $K_3\square K_2$ 는 $K_4$-마이너를 가지지만 $\chi=3$ 이므로 $s_4$ 에 들지 않는다.
4. **판정.** 리포트의 3k+s 항은 "4색 블록의 개수" 이다. 평면 블록이 4색을 요구하는 경우 (예: $K_4$) 에만 한 칸씩 더 든다. $K_{3k+s}$ 족에서 tight (R11 정리 F 가 $s$ 를 $s_4$ 로 써도 그대로 성립).

## 1. Hadwiger 측 (질문 (1))

### 1.1 알려진 범위 (χ 판과 τ 판 공통)
- $t\le4$: $K_4$-마이너-자유 $G$ 는 2-퇴화 (최소 차수 $\ge3$ 인 부분그래프는 $K_4$ 마이너를 가짐, 표준 Dirac 사실 [기억-미검증]) 이므로 $\chi\le3$ 이고 $\tau\le\chi\le3$ [증명, R11 보조정리 C 와 R08 보조정리 3]. 따라서 $\tau\ge4$ 또는 $\chi\ge4$ 이면 $K_4$ 마이너 [증명].
- $t=5$: $K_5$-마이너-자유 ⇒ $\chi\le4$ (Wagner, 4색정리와 동치 [기억-미검증]) ⇒ $\tau\le4$ [증명 조건부]. 따라서 $\tau\ge5$ 이면 $K_5$ 마이너.
- $t=6$: $K_6$-마이너-자유 ⇒ $\chi\le5$ (Robertson–Seymour–Thomas [기억-미검증]). 이것만으로는 $\tau\le5$ 가 나오지 않는다 ($\tau\le\chi$ 는 $\tau$ 가 $\chi$ 와 같은 값이 아닐 수 있음). 그러므로 $\tau$ 판 $t=6$ 은 미결이다 [추측].

### 1.2 시트 구조가 더하는 것
- $k$-시트 평면 그래프에서 $\chi\le4k$, $\tau\le4k$ [증명, 4색정리 인용]. 따라서 $t>4k$ 에서 "$\tau\ge t\Rightarrow K_t$ 마이너" 는 자명하다.
- $k$ 가 주어졌을 때 $t\le4k$ 의 범위에서 시트 구조는 "$K_t$ 마이너를 강제" 하는 데 기여하지 않았다. 반대 방향의 보기: $K_{4k}=kK_4$ 는 시트 $k$ 개와 $K_{4k}$ 마이너 (자기 자신) 로 일관된다 [증명].
- 결론: 시트 분해로 Hadwiger 를 $t\le4k$ 에서 확인하려면, 시트들의 **마이너 구조** (블록 사이 간선의 위치) 를 써야 한다. 기본 정의는 블록 사이 간선을 제한하지 않으므로 이 정보가 없다. 이는 후속연구 1 과 같다.

## 2. J 와 분리 보조정리 (질문 (2), 최우선)

### 2.1 재정식화 [증명]
- $B_0(G_1+G_2)=B_0(G_1)*B_0(G_2)$ (R08 보조정리 1, 교차 간선 전부). 따라서 $\tau(G_1+G_2)\le\tau_1+\tau_2$ 는 $\operatorname{coind}(X*Y)\le\operatorname{coind}X+\operatorname{coind}Y+1$ ($X=B_0G_1$, $Y=B_0G_2$) 와 같다.
- 하한 $\ge$ 는 항상 성립 (구면 사상의 조인).
- 블록 조인 상계 (기본 정의의 $\tau\le\sum\tau_i$) 는 J 와 동치 (R08 정리 4). 그러므로 J 가 참이면 기본 정의의 $\tau$ 판 블록 합이 성립한다.

### 2.2 원뿔 특수형 J$_1$
- J$_1$: $\tau(G+K_1)\le\tau(G)+1$. 즉 $\operatorname{coind}(S^0*Y)\le\operatorname{coind}Y+1$ (여기서 $S^0*Y$ 는 $Y$ 의 대척 원뿔형 이중).
- 분리 보조정리 Sep [추측]: $Z\subseteq S^m$ 닫힌 불변 집합이고 $S^m\setminus Z=W\sqcup(-W)$ (W 열린, $W\cap -W=\emptyset$) 이면 $\operatorname{coind}Z\ge m-1$.
- Sep ⇒ J$_1$ [증명]: $f:S^m\to S^0*Y$ 를 동변 사상이라 하자 ($m=\operatorname{coind}Y+2$ 를 가정해 모순을 구한다). $S^0*Y\setminus Y=C_+\sqcup C_-$ (열린, 서로 대척). $Z:=f^{-1}(Y)$, $W:=f^{-1}(C_+)$ 로 Sep 의 가정이 맞는다. Sep 로 $\operatorname{coind}Z\ge m-1=\operatorname{coind}Y+1$. 그런데 $f|_Z:Z\to Y$ 는 동변이므로 $\operatorname{coind}Z\le\operatorname{coind}Y$ [증명]. 모순.
- Sep 의 상태: 코호몰로지 (Alexander 쌍대) 판은 쉽게 얻어지지만, coindex 판 (구면 사상이 존재) 은 Z 의 연결성 가정이 필요해 보인다. R11 의 $S^2$ 덮개 반례는 "두 덮개 조각 모두 coind 0" 이라는 다른 가정이므로 Sep 를 반박하지 않는다 (Sep 는 여집합의 분할만 본다). 그러나 Sep 의 증명은 얻지 못했다 [추측].
- 작은 확인 [증명, 손]: $Y=B_0(C_5)$ (coind 1): $C_5+K_1=W_5$ 에서 $\tau=4$ (R08 과 일치). $Y=B_0(C_5[K_2])$ (τ=4): $C_5[K_2]+K_1$ 에서 $\tau=5<\chi=6$. 둘 다 J$_1$ 와 일치.

### 2.3 J 가 쉽게 성립하는 범위 [증명]
- $\iota(G_i)=\tau(G_i)$ 이면 J 성립 (R08 정리 3). 예: $\tau=\chi$ 인 블록 (K_n, 이분, 홀수 사이클, 옥타헤드론, $W_5$).
- $\operatorname{zig}$ 가 조인에서 가법이므로 $\tau_i=\operatorname{zig}_i$ 이면 J 성립.
- 따라서 J 의 반례는 $\tau_i<\operatorname{zig}_i$ 이고 $\iota_i>\tau_i$ 인 조각에서만 가능하다. 이런 조각을 알지 못한다 (STATUS 의 열린 문제와 같다).

### 2.4 덮개 논법의 한계 (R11 확인)
R11 의 덮개 반례 ($S^2=(U\sqcup-U)\cup(V\sqcup-V)$, coind 0 + 0 대 coind 2) 는 "덮개 조각의 coind 합 +1" 형 보조정리가 coind 에 대해 거짓임을 보인다 [증명, R11 §4 와 같은 논리]. 따라서 J 증명은 덮개가 아니라 조인 구조 (Sep 같은 분리 성질) 를 써야 한다. 이 점은 R11 의 판정과 같다.

## 3. $\tau\le3k+s$ 와 $s$ 의 의미 (질문 (3))

- R11 정리 D 의 $s$ = $K_4$-마이너 블록 수. 실제 필요한 조건은 **블록의 $\chi$ 가 4 인지** 이다. 블록이 $\chi\le3$ 이면 $\iota\le3$ [R08 보조정리 3], 이는 $K_4$-마이너 유무와 무관하다.
- **개선 정리 3.1 [증명].** $G$ 가 블록 $V=\bigsqcup_iV_i$ 로 나뉘고 $s_4:=\#\{i:\chi(G[V_i])=4\}$ 이면 $\tau(G)\le3k+s_4$. 증명: $\chi_i\le3\Rightarrow\iota_i\le3$, $\chi_i=4\Rightarrow\iota_i\le4$ (평면이므로 $\chi_i\le4$ [4색정리]), 그리고 R08 정리 2.
- 반례 점검: $K_3\square K_2$ (삼각기둥, 평면, $K_4$ 마이너 있음, $\chi=3$): R11 의 $s$ 는 1, $s_4$ 는 0. 실제 $\tau\le\chi=3$. 따라서 $s_4$ 는 $s$ 보다 엄밀히 낫다 [증명].
- $s_4$ 가 항 $s$ 의 의미: "블록 중 4색을 요구하는 것의 개수", 즉 평면 블록이 3색으로 칠해지지 않는 개수. 이것이 $4-3$ 의 추가분에 대응한다. 즉 평면 블록 하나가 "3색 블록보다 한 단계 높은" 값을 준다.
- 조임 (tight): $K_{3k+s}$ 를 $s$ 개의 $K_4$ 와 $k-s$ 개의 $K_3$ 로 나누면 $s_4=s$, $\tau=3k+s$ [증명, R11 정리 F].
- $C_5[K_2]$ 시험: 두 블록 $\{0,1\}\cup\{2,3,4\}$ 식 분할이면 $\chi$ 가 3 또는 4 에 따라 달라진다. 이 분할의 상계는 $\le 3\cdot2+s_4$ 이고 $\tau=4$ 와의 간극은 블록 $\iota$ 합이 $\tau$ 를 넘는 것에서 온다 [계산 확인, 손]. 따라서 $C_5[K_2]$ 에서도 간극은 J 와 같은 종류다.

## 후속연구 지점
1. **Sep 증명 또는 반례 (J$_1$ 의 시험대, 우선순위 1).** 이유: J 의 원뿔 특수형이고, 증명되면 $\tau(G+K_1)\le\tau(G)+1$ 이 나와 기본 정의의 블록 합이 한 칸씩 더 정확해진다. 시작: $Z=\partial W$ 가 $S^{m-1}$ 을 포함하는지, Borsuk-type 논법 (대척 쌍 교차) 으로 $\mathbb Z_2$-사상 $S^{m-1}\to Z$ 를 구성. 난점: $Z$ 가 연결되지 않으면 구면 사상이 없을 수 있고, 그 경우의 반례 (coind 0 인 분리 집합) 를 찾아야 한다.
2. **$\tau$ 가 $\chi$ 와 다른 블록의 J 시험 (Hadwiger 와 연결).** 이유: $\tau<\chi$ 인 블록은 J 의 반례 후보이고, 같은 블록은 Hadwiger 의 $\chi$ 판 간극과도 맞물린다. 시작: $C_5[K_2]$ 과 $\tau=4$ 블록을 조인으로 쌓은 $G_1+G_2$ 의 $\tau$ 하계를 $\sum\tau_i$ 보다 높이는 조건을 찾는다. 난점: $\tau$ 의 정확값은 하한 (coind) 계산 도구가 필요하다.
3. **시트의 마이너 정보 (Hadwiger 측 개선).** 이유: 기본 정의에는 블록 사이 간선 위치가 없어서 $t\le4k$ 의 Hadwiger 를 시트 구조로 확인할 수 없다. 시작: 블록 사이 간선이 "블록 쌍마다 완전 이분" 같은 공리를 가질 때 (R10 의 A_c 형) 마이너를 직접 구성할 수 있는지 $K_{3k+s}$ 족에서 확인. 난점: 공리를 걸면 기본 정의의 결과와 따로 표기해야 한다 (문주님 규칙).
4. **$s_4$ 항의 블록 조건 완화.** 이유: $s_4$ 는 평면 블록이 $\chi=4$ 일 때 올라가므로, 4색을 요구하지 않는 평면 블록 (예: $\tau\le3$ 인 블록) 을 특징지으면 상계가 $3k$ 까지 내려간다. 시작: "평면 $\wedge\ \tau\le3$" 블록 클래스의 구조를 $K_4$, 옥타헤드론, $W_5$ 와 대조. 난점: $\tau\le3$ 인 평면 블록은 $\chi\le3$ 과 같은지 불명이다 (τ 와 χ 의 간극이 평면에서 있는지 미지).
