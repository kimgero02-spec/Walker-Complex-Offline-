# [R37-researcher3] 매칭 축약 렌즈의 "분기 숲" 조건을 nerve 로 번역: K_t 자유도 보존 판정

- 작성자·역할: researcher3 (망상꾼). 한 번만 보고. 계산 없음 (증명 스케치).
- 렌즈 예측의 어느 단계: LENS-3 예측 3 (M 이 K_t 모델의 분기 숲을 포함하면 G/M 에 K_t 부분그래프) 의 **번역 단계**.

## 0. 실패 기준 (먼저)
- **nerve 보존 (N+)** 주장: 어떤 덮개 $\mathcal U$ (G 의 정점 집합 또는 $B_0$ 의 열린 덮개) 의 nerve $N(\mathcal U)$ 가 K_t 모델의 1-골격 (완전 그래프 $K_t$) 을 포함하고, 그 $K_t$ 의 사이클 공간 차원 $\binom{t-1}{2}$ 을 보존한다. 실패 = 어떤 $t$ 모델에서 nerve 가 1-골격을 잃거나 (쌍 교집합 공집합) 2-면이 생겨 사이클 공간이 줄어드는 한 예.
- **숲 번역 (F+)**: "M 이 분기 숲" ⇔ "$G/M$ 의 K_t 부분그래프". 실패 = 숲 M 에서 $G/M$ 의 K_t 가 사라지는 예 (축약 중 다중 간선 제거 등).

## 1. 번역 사전
| 조합 쪽 | 위상 쪽 | 비고 |
|---|---|---|
| 분기 집합 $B_j$ (연결) | 덮개 원소 $U_j$ (B_j 의 닫힌 별/근방) | 연결 → 수축 가능 (G 의 1-복합체 기준) |
| 쌍별 인접 $B_i\sim B_j$ | $U_i\cap U_j\neq\emptyset$ | nerve 의 1-골격 간선 |
| 분기 숲 $M$ (스패닝 숲의 합) | 각 $U_j$ 내부의 수축 | $M$ 이 매칭 (차수 ≤1) 이면 $|B_j|\le2$ 만 허용 — 발상 1 의 제약 |
| K_t 의 자유도 $\binom{t-1}{2}$ | nerve 1-골격의 사이클 공간 차원 | 3-중 교집합이 공집합일 때만 보존 |

**주의 (번역 실패 지점).** 발상 1 의 매칭 $M$ 은 크기 2 이하 분기 집합만 표현한다. 임의 크기 분기 숲을 원하면 축약을 여러 번 (순차 축약) 해야 하며, 그때 중간 단계마다 평면성 조건이 다시 걸린다. 따라서 "분기 숲" 조건은 매칭 렌즈의 **일반화** 가 필요하다 (축약 렌즈 $G/F$, $F$ 는 숲).

## 2. 블록 덮개의 nerve (질문의 직접 대상)
- 블록 덮개 $\{V_1, V_2\}$ 의 nerve 는 두 꼭짓점과 간선 하나 (또는 $V_1\cap V_2=\emptyset$ 이면 두 점) — 어느 쪽이든 **수축 가능 또는 분리** 이다. K_t 의 자유도는 전혀 보이지 않는다.
- R13(I-5) 와 같은 결론: 블록 덮개는 $\mathbb Z_2$-불변이라 등변 nerve 가 자명하고, 위상 정보를 주지 않는다.
- **판정 1: 블록 덮개 nerve 는 K_t 자유도를 보존하지 않는다 (N+ 실패).** 한 단계: nerve 가 1-단체 (간선 하나) 이므로 H_1 = 0, 원래 $K_t$ 의 사이클 공간 $\binom{t-1}{2}\ge1$ (t≥3) 과 불일치. → 블록 nerve 는 K_t 질문의 단계에 쓰이지 않는다.

## 3. 분기 집합 덮개의 nerve (대안, 판정 필요)
- 덮개 $\mathcal U=\{N[B_1],\dots,N[B_t]\}$ (닫힌 이웃 근방) 를 쓰면 nerve 의 1-골격은 "$N[B_i]\cap N[B_j]\neq\emptyset$" 이고, K_t 모델이면 모든 쌍이 교차 (쌍별 인접 ⇒ 교집합 공집합 아님) 이므로 1-골격 $\supseteq K_t$.
- **N+ 판정 (한 단계):** 사이클 공간 보존은 3-중 교집합 $N[B_i]\cap N[B_j]\cap N[B_k]=\emptyset$ 을 요구한다. 그러나 $G$ 의 한 정점이 세 분기 집합 모두에 인접하면 (흔한 경우) 3-중 교집합이 비어 있지 않아 2-면이 생기고 $H_1$ 이 줄어든다. 즉 **N+ 는 "3-중 공통 이웃 없음" 이라는 추가 조건 아래에서만 성립** — 이 조건은 평면성과 무관하게 K_t 를 만족시키기 어렵다 (K_t 의 정점 $v\notin$ 분기 집합이 세 분기 집합에 동시에 인접하는 경우가 흔함).
- 즉 nerve 는 K_t 의 **1-골격 (쌍별 인접) 은 보존** 하지만 **고차 자유도 (사이클 공간) 는 일반적으로 보존하지 않는다.** 쌍별 인접만 필요하다면 1-골격 보존으로 충분하다.

## 4. 판정 요약 (T7 의 단계와 연결)
- 블록 덮개 nerve: K_t 자유도 미보존 (판정 1). **렌즈 예측 3 의 번역 단계에 쓰지 않는다.**
- 분기 집합 근방 nerve: 1-골격 (쌍별 인접) 보존, 고차 자유도는 3-중 공통 이웃 조건부 (판정 2). **예측 3 의 "쌍별 인접 보존" 단계에 쓸 수 있다.** 쌍별 인접은 T7 의 접착 단계가 필요로 하는 것과 같다 (R36 (A)).
- 숲 번역: 매칭 렌즈는 크기 ≤2 분기 집합만 표현. 일반 숲은 축약 렌즈 $G/F$ 로 옮겨야 하며 평면성 재검사가 필요 (발상 1 의 제약).

## 5. 결과 줄 (렌즈 예측의 어느 단계)
- 판정 1 (블록 nerve 실패): 렌즈 예측 3 의 **번역 단계** 에서 제외.
- 판정 2 (근방 nerve 의 1-골격): 렌즈 예측 3 의 **접착 (쌍별 인접) 단계** 에 사용 가능.
- 숲 제약: 렌즈 예측 3 의 **축약 단계** (매칭 → 일반 숲) 에서 평면성 재검사 필요.

## 6. 후속연구 지점
1. **3-중 공통 이웃 조건 아래 사이클 보존 증명 (우선순위 1).** 이유: 판정 2 의 고차 자유도 보존이 성립하는 구조를 찾으면 nerve 가 K_t 질문에 더 강하게 쓰인다. 시작: $N[B_i]\cap N[B_j]\cap N[B_k]$ 가 공집합인 K_t 모델의 존재 조건을 정의 수준에서 정리 (계산 금지).
2. **숲 축약 렌즈의 평면성 보존 조건 (우선순위 2).** 이유: 매칭 렌즈는 $|B_j|\le2$ 로 제한되어 K_t 의 대부분 모델을 표현하지 못함. 시작: 연결 분기 집합 축약이 평면성을 보존하는 조건 (외평면 블록, 또는 분기 집합이 평면 블록의 한 면을 이루는 경우) 을 정의.
3. **블록 덮개 대신 $B_0$ 덮개의 nerve (우선순위 3).** 이유: $\mathbb Z_2$-불변이 아닌 덮개 (단체별 덮개) 는 nerve 가 자명하지 않을 수 있다. 시작: R13(I-5) 의 실패 원인이 덮개의 불변성인지 확인하는 정의 수준 점검.
