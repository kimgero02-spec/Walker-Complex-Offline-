## 요약
1. **B (꼭짓점 분할) [증명+계산 확인]:** 블록 $W_i=V_i\times\{1,2\}$ 는 $\mathbb Z_2$-불변이고 $X(G[V_i])$ 는 $X(G)$ 의 전체 부분 복합체다 (flag 이므로 유도 부분 복합체 = 유도 부분그래프의 $X$). 블록 사이 간선은 면 $(A,B)$ 의 "교차 완전성" 조건을 결정한다. 블록 합 $\bigcup_i X(G[V_i])$ 의 최고 차원은 블록들의 최고 차원의 최댓값이고 (6예 확인), $X(G)$ 의 최고 호몰로지는 교차 면에서 나온다 (6예 중 5예에서 엄격).
2. **B 의 가법 법칙 [증명]:** $\operatorname{zig}(G)\le\sum_i\max(1,\operatorname{zig}(G[V_i]))$. 증명: 블록별 최적 순서를 이어 붙이면 런 수가 블록별 런 수의 합을 넘지 않는다. 6예에서 성립, 4예에서 등호. 같은 식을 $\tau$ 에 대해 쓰면 $\tau(G)\le\sum\tau(G[V_i])$ 가 6예에서 성립 [추측]. 반면 $\tau(G)\le\max_i\tau_i+1$ 은 $K_5$ 의 $(2,3)$ 분할에서 깨진다 ($5>4$).
3. **C (책 두께) [계산 확인]:** 척추 순서 $\sigma$ 와 교차 그래프 $\mathrm{Cr}_\sigma(G)$ 의 색수가 책 두께다, $\mathrm{bt}=\min_\sigma\chi(\mathrm{Cr}_\sigma)$. $\operatorname{zig}$ 와 bt 는 독립 불변량이다: $\operatorname{zig}\le2\,\mathrm{bt}+1$ 은 6예에서 성립 (조건부), $\operatorname{zig}\le\mathrm{bt}+2$ 는 $K_6$ 에서 깨짐, $\operatorname{zig}=2$ 가 $\mathrm{bt}=1$ 을 주지 않음 ($K_{3,3}$).
4. **D (분기 피복) [증명]:** 사상 $f:G\to H$ 가 준동형이면 $X(G)\to X(H)$ 가 $\mathbb Z_2$-동변 단체 사상이어서 $\tau(G)\le\tau(H)$. 평면 기저 $H$ 에서 얻는 것은 $\chi\le4$ 와 같은 수준이고 새 정보가 없다. 리만-후르비츠형 검산 (무분기 $K_{3,3}\to\theta$) 은 성립. 분기 기여는 여기서 계산하지 못했다 ([망상]).

### 가져온 도구
1. ★ **블록 부분 복합체의 유도성** [증명]: 흐름 (flag) 이므로 $X(G)[W_i]=X(G[V_i])$.
2. ★ **런 수의 이어붙임 보조정리** [증명]: 단어 $w=w_1w_2\cdots w_k$ 에 대해 $\mathrm{runs}(w)\le\sum_i\mathrm{runs}(w_i)$ (경계에서 런이 합쳐질 수 있으므로 등호 또는 부등호).
3. ★ **상대 호몰로지와 블록 합** [계산 확인]: $r07x_rel.py` 로 $H_*(X(G),\bigcup_i X(G[V_i]))$ 계산.
4. $\mathbb Z_2$-불변 블록 분해와 상대 호몰로지의 몫 (미실시).

## D. 분기 피복 (평면 기저 위의 k겹)
### 번역 사전
| 피복 쪽 | 이산 호지 쪽 | 어긋나는 점 |
|---|---|---|
| 사상 $f:G\to H$ (준동형, 기저 $H$ 평면) | 단체 사상 $X(f):X(G)\to X(H)$, $\mathbb Z_2$-동변 | 준동형이면 충분, 피복일 필요 없음 |
| 무분기 $k$ 겹 | 국소계 $L_\chi$ 로 분해된 조화 사슬 (아벨 피복이면 $\chi$ 별) | 그래프 수준 (부분 복합체는 아님) |
| 분기점 (섬유 크기 $<k$) | 리만–후르비츠 보정항 $\sum_v(k-|f^{-1}v|)$ | 간선 분기 (간선 뒤집힘) 는 보정이 다르다 |
| 분기점 기여 | $H$ 쪽 상대 호몰로지의 비틀림 | 미실시 |

### 가져온 도구
1. ★ **준동형의 τ 단조성** [증명]: $f:G\to H$ 이면 $X(f)$ 가 동변이므로 $\operatorname{coind}X(G)\le\operatorname{coind}X(H)$, 즉 $\tau(G)\le\tau(H)$.
2. ★ **리만–후르비츠형 오일러 공식** [증명]: 간선 분기가 없으면 $\chi(G)=k\chi(H)-\sum_v(k-|f^{-1}v|)$.
3. ★ **아벨 피복의 조화류 분해** [증명, 표준]: $b_1(G)=k(b_1(H)-1)+1$ (무분기 $k$ 겹 연결 피복).

### 결과
- $K_{3,3}\to\theta$ (두 꼭짓점, 세 간선, $k=3$, 무분기): $\chi(K_{3,3})=-3=3\cdot(-1)-0$ [계산 확인]. $b_1(K_{3,3})=4=3(2-1)+1$ [계산 확인]. 자명한 지표 몫 $b_1(\theta)=2$, 두 비자명 지표가 각각 1 씩 기여 (합 2).
- $\tau(K_{3,3})\le\tau(K_2)=2$ (준동형 $K_{3,3}\to K_2$) [증명]. 평면 기저로 얻는 $\tau$ 상계는 $\chi\le4$ 와 같은 수준이다.

## 도서관 반영: R07-researcher1 (B 증명 시도)
- 연구원1의 `R07-researcher1.md` 와 독립으로 같은 결과에 도달했다: (i) $\chi(G)\le\sum_i\chi(G[V_i])\le4k$ [증명], (ii) $\operatorname{zig}(G)\le\sum_i\operatorname{zig}(G[V_i])$ [증명, 이어붙이기]. 나의 B3 은 연구원1 의 증명과 같은 구조이며, 단지 블록이 비었을 때의 관례 $\max(1,\cdot)$ 를 추가했다.
- 연구원1의 $\tau(G)\le\sum\tau(G[V_i])$ 는 열림 [추측] (그들도 같은 판정). 내 B4 와 같다. 장애물 (교차 복합체가 coind 를 바꿀 수 있음) 도 같은 지점이다.
- 연구원1이 든 "$\tau\le3k$" 는 $d_R$ 의 합 법칙이 필요하고 확인되지 않았다 [추측]. 나의 시험 (B5 반증) 은 $\max\tau_i+1$ 형에 한정되며, $\tau\le3k$ 와 직접 충돌하지 않는다.
- 연구원1의 join 닫힘 정리는 교차가 완전인 결합에 대한 것이고 내 블록 분할과는 다른 경우다. 재검증하지 않았다.
- 반례꾼 (R07-researcher2) 공격 결과는 제출 시점에 없었다.

## 해석 간 비교 (정직한 요약)
- **가법 법칙:** 꼭짓점 분할 (B) 에서 $\operatorname{zig}$ 는 가법 (증명), 간선 분할 (A) 에서는 가법이 깨진다. 같은 "시트" 라는 말이 두 해석에서 정반대 성질을 준다.
- **책 두께 (C)** 는 간선 분할 (A) 에 순서를 얹은 것이고, 상계는 $\chi$ 를 거쳐서만 얻는다. 독자적인 $\operatorname{zig}$ 결과는 없다.
- **분기 피복 (D)** 은 $\tau$ 를 준동형으로 단조하는 것으로 끝난다. 분기 기여의 호몰로지 계산은 하지 못했다.
- **$\tau=\operatorname{zig}$ 에 대한 판정:** 이 세 해석 중 어느 것도 반례를 주지 않았다. B3 (zig 부분가법) 은 $\tau$ 쪽 가법 B4 와 함께 "zig 와 τ 가 같이 가법" 이라는 증거를 준다 (추측 수준).

- 없음. (선택: 책 두께의 χ 상계 $\chi\le2\mathrm{bt}+1$ 원문 출처 확인 — [기억-미검증].)

## 후속연구 지점
1. **B4 (τ 부분가법) 증명 시도 (우선순위 1).** 이유: B3 이 zig 에서 증명됐으므로 같은 블록 이어붙임이 τ 에 되는지가 등호 질문과 직결. 시작: 블록별 $\mathbb Z_2$-사상 $X(G[V_i])\to S^{\tau_i-1}$ 의 조인 $\ast_i S^{\tau_i-1}=S^{\sum\tau_i-1}$ 로 교차 면을 덮을 수 있는지 확인, 또는 $X(G)$ 와 조인 사이의 동변 사상 구성. 난점: 교차 면의 조합 구조가 단순 조인이 아니다 (B 번역 표 참조).
2. **B 의 상대 호몰로지 계산을 $\mathbb Z_2$-몫으로 확장.** 이유: 결함의 위상을 coind 에 연결하는 고리. 시작: $(X(G),\bigcup X_i)/\mathbb Z_2$ 의 F_2 호몰로지, $K_5$ 4+1 과 $K_6$ 3+3 에서. 난점: F_2 계산 구현 필요.
3. **D4 (K_5 의 2겹 분기 피복) 간선 분기 보정 포함 검사.** 이유: 평면 기저 위 피복이 비평면 그래프를 만드는지가 D 해석의 핵심. 시작: $K_5$ 의 모든 대합 (대칭군 원소) 에 대해 몫 다중그래프를 만들고 평면성 확인. 난점: 간선 분기 처리.
4. **C 의 페이지 필터레이션 스펙트럴 열.** 이유: 책 두께가 호지 필터레이션의 층 수를 주는지 보는 가장 직접적 시험. 시작: $K_{3,3}$ (bt 3) 에서 $F_1\subseteq F_2\subseteq F_3$ 의 $E^1$ 항 계산. 난점: 페이지 선택이 비유일 (같은 bt 에 여러 할당).
