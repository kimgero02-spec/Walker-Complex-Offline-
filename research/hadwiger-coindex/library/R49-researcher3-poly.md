## 요약
1. **일반 공식** [증명 + 계산 확인]: 교차 간선이 경계 $W_1,W_2$ 에만 닿으면 $P_G(x)=\tilde a(B_1)^{\!\top}M_H(x)\,\tilde a(B_2)$ 이다. 여기서 $\tilde a_\pi$ 는 "경계 분할 $\pi$ 의 블록에 서로 다른 고정 색을 줄 때의 색칠 수" 이고, $M_H(\pi,\rho)=\sum_\sigma x^{\underline{|\pi|+|\rho|-|\sigma|}}$ 이다 ($\sigma$ 는 $H$-간선이 없는 블록 쌍의 부분 매칭). 결합 없음·클리크 합·조인 공식이 모두 이 공식의 특수형으로 증명된다.
2. **결정성 정리** [증명]: 시트가 경계 밖에 임의의 평면 부분을 가질 수 있을 때, "$P_G$ 가 $P_{B_1},P_{B_2}$ 만으로 정해진다" ⇔ $M_H=\lambda\,uu^\top$ ⇔ **$|H|\le1$**. 결정적 반례도 있다. $P_4$ 와 $K_{1,3}$ 는 색칠다항식이 같다. 같은 2-매칭 결합을 붙이면 $\chi$ 가 2 와 3 으로 갈린다.
3. **계수 측도** [증명 / 계산 확인]: $\operatorname{rank}M_H=r$ 이면 $P_G$ 는 "경계 불변량 곱 $r$ 개의 합" 이다. 계산값은 다음과 같다.
   - 조인 $K_{m,n}$ 은 $\min(m,n)$. 그래서 간선이 많아도 단순하다.
   - 매칭 $m$ 은 $\mathrm{Bell}(m)$ (최대, $m\le5$).
   - 3-정칙 순환 결합 ($m=4,5,6$) 은 13, 48, 169.

   따라서 계수는 **정확한 수 세기의 복잡성**을 잴 뿐 **색칠 난이도** ($\chi$ 상계, 차수 $d$) 를 재지 않는다. 문주님 직관의 대수판으로 쓰려면 계수가 아닌 다른 측도가 필요하다.
4. **Hadwiger·갭 {7}** [증명]: $x=6$ 에서 쌍선형형의 모든 항은 $\ge0$ 이다. 그래서 $\chi\le6$ 은 "지지 호환" 문제와 동치다. 실현 가능한 경계 분할 $\pi,\rho$ 와 $|\pi|+|\rho|-\nu\le6$ 인 매칭 $\nu$ 가 있으면 된다. 다항식 구조 (부호 상쇄, Birkhoff–Lewis) 는 여기서 쓸모가 없다. 부산물: **$B_i[W_i]$ 가 둘 다 이분 그래프이면 교차 차수와 무관하게 $\chi\le6$** [증명, 4CT].

### 1. 기본 대상과 일반 공식
**정의.** 경계를 가진 시트 $(B,W)$ 와 $W$ 의 집합 분할 $\pi$ 에 대해 $a_\pi(B;x)$ 를 "$W$ 위의 같은-색 관계가 정확히 $\pi$ 인 올바른 $x$-색칠 수" 로 둔다. $\tilde a_\pi:=a_\pi/x^{\underline{|\pi|}}$ 이다. 이것은 블록 $i$ 에 색 $i$ 를 고정했을 때의 색칠 수와 같다 (색 치환 대칭).

**보조정리 1.0 (다항식성)** [증명]. $B_\pi$ 를 다음과 같이 만든다: $\pi$ 의 각 블록을 한 정점으로 합치고, 블록 정점들끼리 모두 잇는다. 그러면 $a_\pi(B)=P_{B_\pi}$ 이다 (블록 안에 간선이 있으면 고리가 생겨 0). $B_\pi$ 는 $K_{|\pi|}$ 를 포함하므로 $\tilde a_\pi=P_{B_\pi}/x^{\underline{|\pi|}}$ 는 다항식이다 (아래 정리 1.2 의 클리크 나눗셈). 또 $P_B=\sum_\pi a_\pi=\langle u,\tilde a\rangle$, $u_\pi:=x^{\underline{|\pi|}}$ 이다.

**정리 1.1 (쌍선형 공식)** [증명]. $G=B_1\cup B_2\cup H$ 이고 $H\subseteq W_1\times W_2$ 이면
$$P_G(x)=\sum_{\pi\in\Pi(W_1)}\sum_{\rho\in\Pi(W_2)}\tilde a_\pi(B_1;x)\,M_H(\pi,\rho;x)\,\tilde a_\rho(B_2;x),\qquad M_H(\pi,\rho;x)=\sum_{\sigma}x^{\underline{|\pi|+|\rho|-|\sigma|}}.$$
여기서 $\sigma$ 는 $\pi$-블록과 $\rho$-블록 사이의 부분 매칭이고, 짝지어진 두 블록 사이에는 $H$-간선이 없어야 한다.

*증명.* $G$ 의 올바른 색칠 $c$ 는 다음 다섯 가지로 나뉜다.
1. 시트 색칠 $c_1,c_2$ 의 경계 핵 $(\pi,\rho)$.
2. 블록 색 $\beta$ ($\pi$-블록 위에서 단사).
3. 블록 색 $\gamma$ ($\rho$-블록 위에서 단사).
4. 겹침 $\sigma=\{(i,j):\beta_i=\gamma_j\}$. 두 함수가 단사이므로 $\sigma$ 는 부분 매칭이다.
5. 나머지 정점의 색.

$H$-간선은 경계끼리만 이으므로, $c$ 가 올바르다 ⇔ $c_1,c_2$ 가 올바르고 $\sigma$ 의 어느 짝 사이에도 $H$-간선이 없다. $(\pi,\rho,\sigma)$ 를 고정하면 $(\beta,\gamma)$ 의 수는 $|\pi|+|\rho|-|\sigma|$ 개의 서로 다른 색 선택이므로 $x^{\underline{|\pi|+|\rho|-|\sigma|}}$ 이다. $\beta$ 를 고정했을 때 $c_1$ 의 수는 $\tilde a_\pi(B_1)$ 이고, 이 값은 $\beta$ 와 무관하다 (색 치환). $c_2$ 도 같다. ∎
- 확인: $W_5|K_4$ ($|H|=6$) 와 $P_4|K_2$ 에서 $x=0..7$ 로 직접 센 값과 일치했다 (`t1.py`) [계산 확인].

**정리 1.2 (세 고전 공식)** [증명].
- (a) **결합 없음**: $H=\emptyset$ 이면 $M=uu^\top$ 이다. 이유: 단사 쌍의 수를 겹침 크기별로 더하면 $x^{\underline p}x^{\underline q}$ 이다. 따라서 $P_G=\langle u,\tilde a_1\rangle\langle u,\tilde a_2\rangle=P_{B_1}P_{B_2}$.
- (b) **클리크 합** ($G_1,G_2$ 를 $K_r$ 을 따라 붙임): $P_G=P_{G_1}P_{G_2}/x^{\underline r}$. 증명: $K_r$ 위의 색칠은 단사다. 고정한 단사 색칠 하나로 확장되는 수를 $e_i$ 라 하면, 색 치환으로 $e_i$ 는 그 색칠과 무관하고 $P_{G_i}=x^{\underline r}e_i$ 이다. 따라서 $P_G=x^{\underline r}e_1e_2$. 정팔면체 $\oplus_{K_3}W_5$ 에서 $x=0..8$ 로 확인했다 [계산 확인].
- (c) **조인** (완전 결합): $P_{B_i}=\sum_k a^{(i)}_k x^{\underline k}$ 라 하자. 여기서 $a_k$ 는 독립집합 $k$ 개로의 분할 수이고, 이 낙하 계승 전개는 $P$ 로 유일하게 정해진다. 그러면 $P_{G_1+G_2}=\sum_{i,j}a^{(1)}_ia^{(2)}_jx^{\underline{i+j}}$, 즉 움브랄 곱 $x^{\underline i}\ast x^{\underline j}=x^{\underline{i+j}}$ 이다. 증명: 조인의 독립집합은 한쪽에만 있으므로, 조인의 독립 분할은 두 독립 분할의 쌍이다. 정리 1.1 로 보면 $W_i=V_i$, $\tilde a\in\{0,1\}$ 이고, 모든 블록 쌍 사이에 간선이 있어 $\sigma=\emptyset$ 뿐이다. 따라서 $M(\pi,\rho)=x^{\underline{|\pi|+|\rho|}}$. $C_5+W_4$ 에서 $x=0..9$ 로 확인했다 [계산 확인]. 예: $K_6=K_3+K_3$ 는 $x^{\underline 6}$.

### 2. 결정성: 언제 $P_G$ 가 $P_{B_1},P_{B_2}$ 로 정해지는가
**설정.** 결합 규칙 $R$ = (경계 $W_1,W_2$ 의 라벨, 고정 패턴 $H\subseteq W_1\times W_2$). 시트는 $W_i$ 를 포함하는 임의의 평면 그래프다. "결정적" 이란 $P_G=\Phi(P_{B_1},P_{B_2})$ 인 함수 $\Phi$ 가 있다는 뜻이다.

**보조정리 2.1 (생성)** [증명]. 경계 $W$ 위의 숲 $F$ ($V(F)=W$, 평면) 만으로 $\{\tilde a(F)\}$ 가 $\mathbb Q^{\Pi(W)}$ 전체를 생성한다.
*증명.* $\tilde a_\pi(F)=\prod_{e\in F}c_e(\pi)$ 이고, $c_e=[e$ 가 두 블록을 가름$]$ 이다. 그러면
$$g_F(\pi):=\prod_{e\in F}(1-c_e)=\sum_{F'\subseteq F}(-1)^{|F'|}\tilde a_\pi(F')$$
이고 $g_F=[\pi\ge\pi(F)]$ 이다 ($\pi(F)$ = $F$ 의 성분 분할, $\ge$ 는 더 거침). 모든 분할 $\tau$ 는 어떤 숲의 성분 분할이므로 $\{[\pi\ge\tau]\}_\tau$ 가 모두 생성된다. 이 집합은 세분 순서에 대해 단위 삼각이므로 기저다. ∎

**정리 2.2 (결정성)** [증명]. 결정적 ⇔ $M_H=\lambda\,uu^\top$ ($\lambda\in\mathbb Q(x)$) ⇔ $|H|\le1$. 결정적일 때 $P_G=\lambda P_{B_1}P_{B_2}$ 이고, $|H|=1$ 이면 $\lambda=(x-1)/x$ 이다.

*증명.*
- (⇐) $M=\lambda uu^\top$ 이면 $\tilde a_1^\top M\tilde a_2=\lambda\langle u,\tilde a_1\rangle\langle u,\tilde a_2\rangle$.
- (⇒) 실현 가능한 경계 벡터 $a,a'$ 를 잡는다. 시트 $B_a\sqcup B_{a'}^\circ$ 와 $B_{a'}\sqcup B_a^\circ$ 를 비교한다 ($^\circ$ = 경계를 잊은 사본, 서로소 합이라 평면). 둘 다 $P=P_aP_{a'}$ 이고 경계 벡터는 $P_{a'}a$ 와 $P_aa'$ 이다. 결정성에 의해 모든 실현 가능한 $b$ 에 대해 $(P_{a'}a-P_aa')^\top Mb=0$ 이다. 보조정리 2.1 로 $b$ 는 전 공간을 생성하므로 $(P_{a'}a-P_aa')^\top M=0$ 이다. $a'=a_0$ 를 고정하면 사상 $z\mapsto P_{a_0}z-\langle u,z\rangle a_0$ 는 $P_{a_0}$ 배의 $\ker u^\top$ 위 사영이다. 실현 가능 벡터가 전 공간을 생성하므로 이 사상의 상이 $\ker u^\top$ 전체를 생성한다. 따라서 $\ker u^\top\subseteq$ 왼쪽 핵이고 $M=uv^\top$ 이다. 오른쪽도 대칭으로 $v\propto u$.
- ($\lambda uu^\top$ ⇔ $|H|\le1$) 비율 $M(\pi,\rho)/(u_\pi u_\rho)$ 는 "독립·균등한 단사 블록 색칠에서 $H$ 의 어떤 간선도 단색이 아닐 확률" 이다.
  - 모든 블록이 한 개 ($\pi,\rho$ 각각 한 블록) 이고 $H\ne\emptyset$ 이면 이 비율은 $1-1/x$.
  - 이산 분할에서는 간선마다 단색일 확률이 정확히 $1/x$ 이고, 겹침 항이 $O(x^{-2})$ 이므로 비율은 $1-|H|/x+O(x^{-2})$.

  유리함수로서 둘이 같으려면 $|H|=1$ 이어야 한다. $|H|=1$ 이면 모든 $(\pi,\rho)$ 에서 비율이 $1-1/x$ 로 상수다. ∎ (계산: $3\times3$ 경계에서 빈 결합과 단일 간선은 $\propto uu^\top$, 나머지는 아님 [계산 확인].)

**결정적 반례** [증명 + 계산 확인] (`t1.py`). $B_1=P_4$ (경계 = 두 끝점) 와 $B_1'=K_{1,3}$ (경계 = 잎 둘) 은 둘 다 $P=x(x-1)^3$ 이다. $B_2=K_2$, $H$ = 같은 2-매칭.
- 첫째: $G=C_6$, $P_G=(x-1)^6+(x-1)$.
- 둘째: $G=C_5$ + 매달린 정점, $P_G=((x-1)^5-(x-1))(x-1)$.
- $x=2$ 에서 2 대 0, 즉 $\chi$ 가 2 대 3 으로 갈린다.

**경계가 시트 전체일 때 ($W_i=V_i$)** [증명 / 추측]. 경계 밖 부분이 없으면 위 증명의 서로소 합 기법을 쓸 수 없다. 이때 $M(\pi,\rho)$ 가 $(|\pi|,|\rho|)$ 에만 의존하면 $P_G=\sum_{i,j}a_ib_j\,M(i,j)$ 로 결정된다 [증명]. 빈 결합, 단일 간선, 조인이 이런 예다. 이 조건이 필요조건인지는 [추측].

### 3. 결합 복잡성의 대수적 측도: $M_H$ 의 크기와 계수
**정리 3.1** [증명]. $\operatorname{rank}_{\mathbb Q(x)}M_H=r$ 이면 $P_G=\sum_{k=1}^r\langle p_k,\tilde a(B_1)\rangle\,\langle q_k,\tilde a(B_2)\rangle$ 이다 ($M=\sum p_kq_k^\top$). $r=1$ 이면 "경계 불변량 둘의 곱" 이지만, 그 불변량이 $P_B$ 일 필요조건은 정리 2.2 의 $\propto uu^\top$ 이다. 예: 한 정점에서 여러 경계 정점으로 가는 별 결합은 계수가 1 이지만 결정적이지 않다 [계산 확인]. 계수는 $\le\min(\mathrm{Bell}|W_1|,\mathrm{Bell}|W_2|)$ 이다.

**보조정리 3.2 (쌍둥이 축약)** [증명]. $H$ 에서 이웃이 같은 경계 정점 (쌍둥이) 을 서로 바꾸는 치환에 대해 같은 궤도에 있는 $\rho$ 들은 $M$ 의 같은 열을 준다. 따라서 계수 $\le$ 궤도 수다.

**계산표** [계산 확인] (`t2.py`, `t4.py`; 계수는 $x=6$ 과 일반 점 $x=10^6+3$ 에서 큰 소수를 법으로 계산, 두 값이 같았음).
| 결합 $H$ | $|W_1|,|W_2|$ | Bell 크기 | 계수 |
|---|---|---|---|
| 없음 / 단일 간선 | 3,3 | 5×5 | 1 ($\propto uu^\top$) |
| 별 $a_0\to3$ | 1,3 | 1×5 | 1 (비례 아님) |
| 매칭 $m=2,3,4,5$ | $m,m$ | $\mathrm{Bell}(m)$ | **2, 5, 15, 52 (최대)** |
| 조인 $K_{2,2},K_{3,2},K_{3,3},K_{4,3},K_{4,4}$ | | | **2, 2, 3, 3, 4** = $\min(m,n)$ |
| $K_6=K_3+K_3$ / $K_7=K_4+K_3$ | 3,3 / 4,3 | 5×5 / 15×5 | 3 / 3 (시트가 클리크라 유효 지지는 1×1, 유효 계수 1) |
| 3-정칙 순환 $m=4,5,6$ | $m,m$ | 15, 52, 203 | 13, 48, 169 |
| R48 가젯 성분 ($A$ 6 정점 ↔ $Q_2=K_4$) | 6,4 | 203×15 | 6 (쌍둥이 궤도 7, 보조정리 3.2) / 유효 1 |
| R48 가젯 전체 | 10,10 | 115975² | $x=6$ 실현 지지 3576×3576 (블록 수 4–6) — 계수 계산은 비용 때문에 생략 |

- 조인의 계수 $\le\min(m,n)$ [증명]: $M$ 이 블록 수에만 의존하므로 행이 $|\pi|\in\{1..m\}$ 종류뿐이다. 등호는 [계산 확인].
- 매칭의 계수가 모든 $m$ 에서 최대 ($\mathrm{Bell}(m)$) 라는 것은 [추측] ($m\le5$ 계산).

**판정 (문주님 직관과의 관계)** [증명 + 계산 확인].
- 계수는 $|W|$ 에 대해 지수적으로 커질 수 있다. 그런데 커지는 순서가 색칠 난이도와 반대다. 매칭 ($d=1$, 이미 $\chi\le6$ 증명됨) 은 계수가 최대이고, 조인 (간선 최다, $\chi$ 가 그대로 더해짐) 은 계수가 최소다.
- 따라서 "복잡성 = 중첩성 + 결합" 의 정확한 대수판으로 $\operatorname{rank}M_H$ 를 쓰면, 그것은 **$P_G$ 전체 (모든 $x$ 의 수 세기) 를 계산하는 데 필요한 정보량**이 된다. $\chi$ 상계 (= $P_G(6)>0$ 한 점의 양성) 의 측도가 아니다.
- 그래서 $\chi$ 쪽 측도는 §4 의 **$x=6$ 지지 측도**가 맞다. 그 형태는 연구원1 R49 의 결합 비용 $\kappa$ / 전달 폭 $\theta$ / 강직 정합, 그리고 연구원3(위상) 의 면 덮개수 $\varphi$ 와 같은 층에 있다.

### 4. Hadwiger 와 연결: 갭 {7} 의 쌍선형형
**정리 4.1 (양성 = 지지 문제)** [증명]. 정수 $x$ 에서 $\tilde a_\pi(B;x)\ge0$ 이고 $M_H(\pi,\rho;x)\ge0$ 이다 (모두 수 세기). 따라서
$$\chi(G)\le6\iff P_G(6)>0\iff\exists\,\pi\in S_1,\ \rho\in S_2:\ M_H(\pi,\rho;6)>0.$$
여기서 $S_i=\{\pi:\tilde a_\pi(B_i;6)>0\}$ (6-색칠로 실현되는 경계 핵) 이다. 또 $M(\pi,\rho;6)>0\iff\nu(\pi,\rho)\ge|\pi|+|\rho|-6$ 이고, $\nu$ 는 "사이에 $H$-간선이 없는 블록 쌍" 그래프의 최대 매칭이다.
- 따름 (갭의 정확한 진술): $\mathcal C(2,R_3)$ 에서 $\chi=7$ 인 $G$ 가 있다 ⇔ 모든 $\pi\in S_1,\rho\in S_2$ 에 대해 $|\pi|+|\rho|-\nu(\pi,\rho)\ge7$ 인 $G$ 가 있다.
- 이 식에는 **부호 상쇄가 없다**. 다항식으로서의 정보 (계수, 근, Birkhoff–Lewis 전개) 는 $x=6$ 의 양성에 대해 지지 집합 $S_i$ 이상을 주지 못한다.

**Birkhoff–Lewis 가 쓰이는 범위** [기억-미검증 인용]. "평면 그래프는 실수 $x\ge5$ 에서 $P(x)>0$ (실은 $P\ge x(x-1)(x-2)(x-3)^{n-3}$)" 를 쓰면 $\sum_\pi a_\pi(B;6)>0$, 즉 $S_i\ne\emptyset$ 만 나온다. **어느 $\pi$ 가 $S_i$ 에 있는지는 알려 주지 않는다.** 바로 여기서 막힌다. 필요한 것은 "평면 그래프의 6-색칠로 실현되는 경계 핵" 의 특성화, 즉 경계 사전색칠 확장 문제다.

**정리 4.2 (작은 핵의 실현)** [증명, 4CT]. $\pi$ 가 $B[W]$ 의 독립 분할이고 $|\pi|\le2$ 이면 $\pi\in S$ 이다. 블록에 색 1, 2 를 주고, $B-W$ 는 4CT 로 $\{3,4,5,6\}$ 을 쓰면 된다.

**따름 4.3** [증명, 4CT]. $W_i$ 를 교차 간선이 닿는 정점 집합이라 하자. $B_1[W_1]$ 과 $B_2[W_2]$ 가 둘 다 이분 그래프이면, **교차 차수와 무관하게** $\chi(G)\le6$ 이다. 직접 구성은 이렇다: $W_1\leftarrow\{1,2\}$, $B_1-W_1\leftarrow\{3..6\}$, $W_2\leftarrow\{3,4\}$, $B_2-W_2\leftarrow\{1,2,5,6\}$. 교차 간선은 $\{1,2\}$ 대 $\{3,4\}$ 뿐이다. (R48-r2 의 FB 경로나 R49-r1 의 F2 와 같은 계열의 더 거친 조건이다.)
- 막힌 곳 [증명]: $|\pi|\ge3$ 이면 $B-W$ 의 리스트에 공통 색이 $6-|\pi|\le3$ 개밖에 없어 4CT 를 쓸 수 없다. R48 의 "공통 2 색 리스트" 문제가 그대로 다시 나온다. 7-색수 반례에서는 $W_i$ 가 거의 모든 정점이고 $B_i[W_i]$ 는 삼각형을 가지므로 (삼각분할 정규화), $S_i$ 는 블록 수 $\ge3$ 인 핵만 갖는다. R48 가젯의 실제 지지도 블록 수 4–6 이다 [계산 확인].

### 5. 갭 표에 대한 함의 (한 줄)
$(2,R_3)$ 의 갭 {7} 은 유지된다. 이번 결과는 갭을 $x=6$ 지지 호환 문제 (정리 4.1) 로 정확히 다시 썼다. 이 재정식화로 색칠다항식의 대수 구조나 Birkhoff–Lewis 가 갭을 닫을 수 없음을 보였고 [증명], 닫는 열쇠는 평면 시트의 "6-색칠로 실현되는 경계 핵 (블록 수 ≥3)" 특성화로 좁혀졌다.

### 6. 환원 틀에서의 함의
- 색칠다항식 층에서 결합 $R$ 의 복잡성은 $(|W_1|,|W_2|,\operatorname{rank}M_H)$ 로 정확히 잴 수 있다. "중첩성 + 결합" 은 **$P_G=\sum_{k\le r}(\text{시트 1 불변량})(\text{시트 2 불변량})$** 이라는 정리 (3.1) 가 된다. 그러나 순수한 곱 $P_{B_1}P_{B_2}$ 로 되는 것은 $|H|\le1$ 뿐이다 (2.2).
- 이 측도는 $d$ 와 단조 관계가 아니다 (매칭은 계수 최대, 조인은 최소). 그래서 $\chi$ 환원 틀의 측도로는 부적합하다. $\chi$ 쪽에서는 $x=6$ 의 지지 측도, 즉 "실현 핵 쌍의 최소 $|\pi|+|\rho|-\nu$" 가 정확한 측도다. 이것이 $\le6$ 이면 $\chi\le6$ 이고, 정의상 필요충분이다.

## 후속연구 지점
1. **6-실현 경계 핵의 특성화 (블록 수 3·4) (우선순위 1).**
   - 이유: 정리 4.1 로 갭이 정확히 이 문제가 되었고, $|\pi|\le2$ 는 4CT 로 풀렸다.
   - 시작: 삼각분할 $B$ 와 3-블록 독립 분할 $\pi$ 에 대해, $B-W$ 의 리스트 $\{4,5,6\}\cup(\{1,2,3\}\setminus\text{이웃 블록 색})$ 의 색칠 가능성을 R48 의 $\{5,6,a_v\}$ 판정 ($S$-집합 동치) 으로 옮긴다.
   - 난점: 공통 색이 3 개라 4CT 를 그대로 쓰지 못한다.
2. **"최소 $|\pi|+|\rho|-\nu$" 를 $(2,R_3)$ 에서 6 이하로 누르는 정리 (우선순위 1).**
   - 이유: χ 쪽의 필요충분 측도다.
   - 시작: 4-색칠 핵 ($|\pi|=4$) 둘에서 $\nu\ge2$ 인 쌍을 R42 탈출 논법으로 만든다. 교차 차수 3 이 $\nu$ 를 얼마나 깎는지 센다.
   - 난점: R48 가젯처럼 4-색칠 핵이 강제되는 경우에는 $\nu$ 가 정확히 1 이 모자란다.
3. **매칭 결합의 계수 = $\mathrm{Bell}(m)$ 증명.**
   - 이유: "계수와 색칠 난이도가 반대" 라는 판정의 핵심 사례다.
   - 시작: 이산 분할부터 세분 순서로 삼각화되는지 본다.
   - 난점: 대각 성분이 0 이 아님을 보여야 한다.
4. **$W_i=V_i$ 일 때 결정성의 필요조건.**
   - 이유: 조인·단일 간선 외에 결정적인 결합이 있는지 알아야 한다.
   - 시작: 경계 = 시트 전체에서 실현 가능한 $\tilde a$ ($\{0,1\}$-벡터, 독립 분할 지시) 의 생성 공간을 계산한다.
   - 난점: 서로소 합 기법을 쓸 수 없다.
5. **가젯 전체 유효 계수 계산.**
   - 이유: 3576×3576 지지 행렬로 결합 복잡성의 실제 크기를 확인한다.
   - 시작: 쌍둥이 궤도 (보조정리 3.2) 로 먼저 축약한 뒤 계수를 계산한다.
   - 난점: 비용. 결과는 측도의 크기 확인일 뿐이고 판정 근거로는 쓰지 않는다.
