# [R41-researcher1] 내부 축약과 시트 수 k_V 감소의 결합: Hadwiger 귀납의 판정

- 작성자·라운드·역할: researcher1 / R41 (무인 6라운드 중 1) / 연구원1. 방향: 복잡성 환원 $C(G)=(k,R)$, $R=V$. 일반 정리만, 작은 예 없음, 계산 없음.
- 입력: GEN-1 (내부 축약은 $K_t$ 모델을 보존), COMPLEX-1 ($\chi\le4k_V$, 부분그래프 단조).
- 표기: `[증명]` `[추측]` `[기억-미검증]`. 층 표기: 정의 / 단조 / 리프트 / χ 손실 / 귀납.

## 실패 기준 (먼저 적는다)
- **귀납 가능으로 인정:** $k_V$ 에 대한 귀납 단계 "$k-1$ 에서 Hadwiger 가 성립 ⇒ $k$ 에서 성립" 이 축약 $M$ 하나로 증명된다.
- **귀납 불가로 판정:** 축약으로 귀납 단계를 세울 때 필요한 조건 가운데 하나가 일반적으로 실패함을 증명한다 (이 경우 막히는 지점을 명시한다).

## 결과 0 — 방향 정리: GEN-1 의 보존은 귀납에 쓰이지 않는다 [증명]
- GEN-1 정리 1.1 은 "$G$ 에 $K_t$ 모델이 있으면 내부 $M$ 에 대해 $G/M$ 에도 있다" ($G\to G/M$ 방향) 이다. Hadwiger 의 귀납은 $K_t$ 의 **존재** 를 증명해야 하므로, 모델을 가정하는 이 방향은 순환이다.
- 귀납에 필요한 방향은 반대 ($G/M\to G$) 이며, 그것은 일반적으로 자명하다 (결과 2).
- 따라서 "k_V 감소 + K_t 보존" 의 결합은 **존재 증명에는 쓰이지 않고**, GEN-1 정리 3.1 처럼 모델을 **배제** 하는 대우 논법에만 쓰인다.
- *층:* 정의 층 (어떤 방향이 귀납에 필요한지의 정리).

## 결과 1 — 시트 내부 축약은 k_V 를 늘리지 않는다 [증명]
- **정리 1.1.** $V_1..V_k$ 가 $G$ 의 평면 시트 분할이고 $M\subseteq\bigcup_iE(G[V_i])$ (시트 내부 간선) 이면 $k_V(G/M)\le k_V(G)$.
  *증명.* $(V,M)$ 의 연결 성분은 각각 한 $V_i$ 안에 있다. 따라서 $V_i$ 의 상 $V_i'$ 들은 $V(G/M)$ 의 분할이고, $(G/M)[V_i']=G[V_i]/M_i$ ($M_i=M\cap E(G[V_i])$) 이다. 평면 그래프의 축약은 평면이므로 각 조각이 평면. ∎
- **정리 1.2.** 시트 사이 간선을 축약하면 $k_V$ 는 늘 수 있다는 것을 막는 일반 논법은 없다. 확실한 상계는 $k_V(G/e)\le k_V(G)+1$ (합쳐진 점을 새 조각에 둔다) 뿐이다. [증명]
- **엄밀 감소의 조건.** $k_V(G/M)<k_V(G)$ 이려면 $G/M$ 의 정점 집합이 $k-1$ 개 평면 조각으로 나뉘어야 한다. 정리 1.1 은 감소를 주지 않고 비증가만 준다. 감소에 대한 일반 충분 조건은 찾지 못했다 [추측: 감소는 두 조각의 상 $V_i'\cup V_j'$ 이 축약 후 평면이 되는 경우에만 일어난다].
- *층:* 단조 층.

## 결과 2 — 리프트: $G/M$ 의 $K_t$ 는 $G$ 로 올라간다 [증명]
- **정리 2.1.** 임의의 $M\subseteq E(G)$ 에 대해 $G/M$ 이 $K_t$ 마이너를 가지면 $G$ 도 가진다.
  *증명.* $G/M$ 은 $G$ 의 마이너이고, 마이너 관계는 추이적이다. ∎
- *층:* 리프트 층. 귀납의 결론 쪽은 항상 성립한다. 막힘은 가정 쪽 (χ) 에 있다.

## 결과 3 — χ 손실: 축약은 χ 를 일정 비율로만 보존한다 [증명]
- **정리 3.1.** 간선 하나의 축약: $\chi(G)\le\chi(G/e)+1$.
  *증명.* $G/e$ 의 색칠에서 합쳐진 점 $w$ 의 색을 $u$ 에 주고 $v$ 에 새 색을 준다. ∎
- **정리 3.2.** $M$ 의 연결 성분 크기의 최댓값을 $s$ 라 하면 $\chi(G)\le s\cdot\chi(G/M)$. 특히 매칭이면 $\chi(G)\le2\chi(G/M)$.
  *증명.* $G/M$ 의 색칠 $c$. 성분 $C$ 의 점들에 서로 다른 지표 $1..|C|$ 를 붙이고 $G$ 의 점 $x\in C$ 에 색 $(c(C),\text{지표}(x))$ 를 준다. 같은 성분 안의 두 점은 지표가 다르고, 다른 성분 사이 간선은 $G/M$ 의 간선이므로 첫 좌표가 다르다. 색 개수 $\le s\,\chi(G/M)$. ∎
- **정리 3.3 (손실은 일반적으로 피할 수 없다).** 완전 그래프 $K_n$ 의 모든 간선 축약은 $K_{n-1}$ 을 주므로 $\chi$ 가 정확히 1 줄어든다. 따라서 "$\chi(G/M)\ge\chi(G)$ 인 비공 축약 $M$ 이 항상 있다" 는 거짓이다. [증명]
- *층:* χ 손실 층.

## 결과 4 — 귀납 판정 [증명]
- **정리 4.1 (무손실 귀납의 조건).** $\mathcal H(k)$: "$k_V\le k$ 이고 $\chi\ge t$ 이면 $K_t$ 마이너". $\mathcal H(k-1)$ 을 가정하자. $k_V(G)=k$, $\chi(G)\ge t$ 인 $G$ 에 대해 $M$ 이 (a) $k_V(G/M)\le k-1$, (b) $\chi(G/M)\ge t$ 를 만족하면 $G$ 는 $K_t$ 마이너를 가진다.
  *증명.* $\mathcal H(k-1)$ 을 $G/M$ 에 적용하고 정리 2.1 로 리프트. ∎
- **정리 4.2 (손실 귀납: 절반 정리).** 조건 (b) 대신 $M$ 이 매칭이면 정리 3.2 로 $\chi(G/M)\ge\lceil t/2\rceil$ 이다. 따라서 $\mathcal H(k-1)$ 아래, $k_V$ 를 낮추는 매칭 $M$ 을 가진 $G$ ($k_V=k$, $\chi\ge t$) 는 $K_{\lceil t/2\rceil}$ 마이너를 가진다.
  *증명.* 정리 4.1 과 같은 논법, $t$ 를 $\lceil t/2\rceil$ 로. ∎
- **따름 4.3 (반복의 한계).** 정리 4.2 를 $k\to1$ (평면, 기저) 까지 반복하면 $K_{\lceil t/2^{k-1}\rceil}$ 만 얻는다. 지수적 손실이므로 Hadwiger 에는 쓸 수 없다. [증명]
- **막히는 지점 (판정).** 무손실 귀납 (정리 4.1) 의 조건 (b) $\chi(G/M)\ge\chi(G)$ 는 정리 3.3 에 의해 일반적으로 보장되지 않는다. 조건 (a) ($k_V$ 감소) 에 대해서도 일반 충분 조건이 없다 (결과 1). 따라서 **$k_V$ 에 대한 축약 귀납은 χ 손실 단계에서 막힌다.** 막힘의 정량: 매칭 축약은 χ 를 최대 절반으로, 성분 크기 $s$ 의 축약은 최대 $1/s$ 로 떨어뜨린다 (정리 3.2 가 상계, 완전 그래프에서 간선 하나당 1 감소가 실제로 일어남).
- *층:* 귀납 층.

## 마지막 절: 후속연구 지점
1. **χ 를 잃지 않는 축약의 존재 조건 (우선순위 1).** 이유: 귀납이 막히는 유일한 지점이다. 시작: 축약 대신 Zykov 식 정점 동일시 (비인접 쌍 $u,v$ 에 대해 $\chi(G)=\min(\chi(G+uv),\chi(G/uv))$) 를 쓰면 한쪽 가지에서 χ 가 보존된다. 시트 수 $k_V$ 가 어느 가지에서 줄어드는지를 정리 1.1 의 형태로 판정한다. 난점: $G+uv$ 가지는 $k_V$ 를 늘릴 수 있다.
2. **$k_V$ 엄밀 감소의 충분 조건.** 이유: 조건 (a) 의 일반 충분 조건이 없다. 시작: 두 시트 $V_i,V_j$ 사이에서 내부 축약 후 합집합이 평면이 되는 조건을 블록 구조 (교차 간선의 위치) 로 기술. 난점: 평면성 판정은 전역적이다.
3. **절반 정리 (정리 4.2) 와 Steiner 의 홀수 마이너 절반 정리의 비교.** 이유: 두 결과 모두 $\lceil t/2\rceil$ 를 준다. 시작: 정리 4.2 의 손실이 Steiner 정리 2 (zig ≥ t ⇒ 홀수 $K_{\lfloor t/2\rfloor+1}$) 와 같은 기원 (색 쌍의 축약) 인지 확인. 난점: Steiner 정리는 인용만 하고 검증하지 않는다 (문주님 지시).
