# GEN-3-unified-definition: 시트와 렌즈의 일반 정의 (가공 이론, 정의 수준)

- 작성자·역할: researcher3 (망상꾼). 한 번만 보고. 작은 예·전수 계산 없음. 정의와 기준 판정만.
- 표기: [망상] [추측] [증명] = 이 문서 안에서 "정의에서 바로 나오는 것" 은 [증명], 그 밖의 연결은 [추측].

## 1. 일반 정의

**정의 1.1 (렌즈).** 렌즈 $\lambda$ 는 쌍 $(\mathcal O,\pi)$ 이다. 여기서 $\mathcal O$ 는 아래 네 가지 연산 중 하나이고, $\pi:G\mapsto G_\lambda$ 는 $\mathcal O$ 에 의한 사영이다.
1. (정점 분할) $V(G)=V_1\sqcup\cdots\sqcup V_k$, $G_\lambda=\bigsqcup G[V_i]$ 의 블록들. 사영 = 블록 제한.
2. (간선 분할) $E(G)=E_1\sqcup\cdots\sqcup E_\theta$, $G_\lambda=(V,E_j)$. 사영 = 간선 색 제한.
3. (축약) 숲 $F\subseteq E(G)$ (특히 매칭), $G_\lambda=G/F$. 사영 = 축약.
4. (부분그래프) 간선 집합 $E'\subseteq E(G)$, $G_\lambda=(V,E')$. 사영 = 포함.

**정의 1.2 (시트 족).** 그래프 $G$ 의 시트 족은 렌즈들의 유한 족 $\Lambda(G)=\{\lambda_j\}$ 이며, 조건은 **$G_{\lambda_j}$ 가 모두 평면** 이다. 연산의 종류는 족 안에서 섞어도 된다 (혼합 족).

**정의 1.3 (시트 클래스 $\mathcal S_\Phi$).** $\Phi$ 는 "렌즈 종류와 개수의 규칙" (예: 블록 2 개의 정점 분할, θ 개 간선 분할). $\mathcal S_\Phi=\{G: \exists \Lambda(G)$ 가 $\Phi$ 를 만족$\}$.

## 2. 기준별 판정 (일반 정의 기준)

| 렌즈 종류 | (a) 부분그래프 단조 | (b) 조인 가법 (불변량) | (c) 교차 패턴 무관 |
|---|---|---|---|
| 1 정점 분할 | ✓ [증명] (블록 제한은 블록 평면성 보존) | ✓ 하계 (R14 C2), 상계 열림 | 상계 ✓ (χ 색 합), 값 ✗ |
| 2 간선 분할 | ✓ [증명] (간선 제한) | ✗ (합 법칙 거짓: $K_6=\mathrm{oct}\cup PM_3$) | ✓ 상계 (χ≤4^θ), 값 ✗ |
| 3 축약 (숲 F) | ✓ [증명] (H/F' 는 G/F 의 부분그래프, 평면 minor-closed) | ✗ (축약은 조인 구조를 깨뜨림, R37) | ✗ (χ(G/F) 가 F 에 의존, K_{3,3}/e) |
| 4 부분그래프 선택 | ✓ [증명] (포함 단조) | ✗ (조인에서 간선 빠짐) | ✗ (E' 에 의존) |

**정리 2.1 (일반 단조).** 모든 렌즈 종류 1–4 에 대해 $\mathcal S_\Phi$ 는 부분그래프에 닫혀 있다. [증명: 평면성은 부분그래프와 축약 (minor) 에 닫혀 있다.]
**정리 2.2 (조인 가법은 종류 1 에서만 불변량 수준으로 성립).** 종류 1 만이 조인과 교환한다: $\Lambda(G_1+G_2)$ 를 두 블록 렌즈의 합으로 잡으면 블록 쌍이 조인 블록이 된다. 다른 종류는 조인에서 렌즈가 깨진다. [증명, 정의에서]
**정리 2.3 (교차 무관 상계는 종류 1,2 의 색 상계에서만).** 색 합/곱 논법은 종류 1 (색 합) 과 종류 2 (색 곱) 에 대해 패턴과 무관하다. 종류 3, 4 는 렌즈가 패턴에 의존하므로 무관성이 없다. [증명]

**따라서 일반 정의는 (a) 를 항상, (b) 를 종류 1 에서만, (c) 를 상계 쪽 (종류 1,2) 에서만 만족한다.** 세 기준을 동시에 만족하는 종류는 없다 (종류 1 은 (b),(c) 상계 ✓, (a) ✓ — 그러나 (c) 의 값 쪽 ✗ 는 모든 종류에 공통).

## 3. 위상 쪽 대응 (한 줄씩)
- **정리 3.1 (종류 1 ↔ 덮개):** 정점 분할 렌즈는 $B_0(G)$ 의 열린 불변 덮개 $\{U_i\}$ (지지집합이 $V_i\times\{1,2\}$ 와 만남) 를 준다. 가공 이론의 층: **층 3 (덮개 층)**.
- **정리 3.2 (종류 2 ↔ 부분 복합체 + 결함):** 간선 분할 렌즈는 부분 복합체 $X(G_j)\subseteq X(G)$ 와 결함 $D$ 를 준다. 층 3 (분해 층), 결함은 층 4 (상대 호몰로지).
- **정리 3.3 (종류 3 ↔ 근방 nerve, 1-골격):** 축약 렌즈의 분기 집합 근방 nerve 는 쌍별 인접의 1-골격을 보존하고, 3중 교집합이 생기면 2-면을 만든다 (R37, R38). 층 4 (nerve 층), 단 D1 은 불가 (R38).
- **정리 3.4 (종류 4 ↔ 포함 단조):** $B_0(H)\subseteq B_0(G)$ 가 동변 포함을 주고 $\operatorname{coind}$, $h$ 가 단조 (R18). 층 2 (단조 층).

## 4. 가공 이론의 층 구조 (요약)
- **층 1 (정의):** 렌즈 $(\mathcal O,\pi)$ 와 시트 족 $\Lambda(G)$ (정의 1.1–1.3).
- **층 2 (단조):** 정리 2.1, 정리 3.4. 부분그래프 질문 (τ, h 의 하한) 이 여기서 작동.
- **층 3 (분해/덮개):** 정리 3.1, 3.2. 조인 가법과 상계 (χ 색 합/곱) 가 여기서 작동.
- **층 4 (위상 세부):** 정리 3.3 (nerve), 결함 상대 호몰로지. 쌍별 인접과 고차 자유도가 여기서 갈린다 (R37, R38).
- **층 5 (마이너):** 이 일반 정의 안에서 K_t 마이너를 직접 만드는 층은 없다. 연결은 종류 3 의 "분기 숲 보존" 뿐이며 평면성 충돌로 제한된다 (LENS-3 예측 3, R37 §5).

## 5. 판정 요약
- 일반 정의는 (a) 를 만족 (모든 종류). (b) 는 종류 1 의 불변량 하계에서만, (c) 는 종류 1,2 의 상계에서만.
- 세 기준을 한꺼번에 만족하는 렌즈 종류는 없다. 이것은 GROW-3, PROGRESS-3 의 판정 (멤버십 기준 (b) 불만족) 과 같은 구조이며, 일반 정의로 올려도 바뀌지 않는다.
- 연결 질문 (T7) 은 층 5 에 있고, 현재 일반 정의의 어떤 층도 마이너를 직접 만들지 않는다.

## 6. 후속연구 지점
1. **혼합 족의 단조성 (우선순위 1).** 이유: 종류 1 과 종류 3 을 섞은 족 (블록 분할 + 블록 내부 축약) 이 (b) 를 복원하는지 정의 수준에서 판정. 시작: 혼합 렌즈의 조인 보존 조건 정리.
2. **층 5 (마이너 층) 의 정의 (우선순위 2).** 이유: 현재 일반 정의에 마이너를 출력하는 층이 없다. 시작: "렌즈 족 ⇒ K_t 분기 모델" 의 출력 규칙을 정의 수준에서 적고, 입력 조건 (층 3, 4 의 어떤 데이터) 을 명시.
3. **GROW/PROGRESS 판정과의 통합 (우선순위 3).** 이유: 일반 정의에서 얻은 "(b) 는 종류 1 불변량 하계만" 이 GROW-3 의 d 판정과 같은 내용인지 대조. 시작: 종류 1 의 d (블록 교차 차수) 가 일반 정의의 파라미터로 들어가는 방식.
