# [R16-researcher3] 블록 클래스 𝒞_3 의 위상 불변량: 부분그래프 닫힘, K_4 세분, k 블록 상계

- 작성자·라운드·역할: researcher3 / R16 / 망상꾼 (분야: 대수적 위상수학, Z_2 지수·Stiefel–Whitney 높이)
- 지시: 문주님 (R16, 무인 모드 3라운드 중 1라운드). 범위: 정점 시트 블록 (교차 간선 포함).
- 표기: $X(H)=B_0(H)$, $\tau=\operatorname{coind}X+1$, $h(X)$ = 자유 $\mathbb Z_2$-복합체의 Stiefel–Whitney 높이 (최대 $n$ 에서 $w_1^n\ne0$ in $H^n(X/\mathbb Z_2;\mathbb F_2)$). $\mathcal C_3$ = 블록 클래스. 기존 파일은 수정하지 않았다.
- 계산: 손 계산과 R08 의 호몰로지 기록 재사용. 이번 라운드 새 계산 없음.

## 요약
1. **세 후보.** (a) $\mathcal C_3^\tau=\{H:\tau(H)\le3\}$ (⇔ 등변 사상 $X(H)\to S^2$). (b) $\mathcal C_3^{h}=\{H:h(X(H))\le2\}$. (c) 블록 덮개의 nerve 차원: 블록 개수에 의존하고 블록 자체의 불변량이 아니므로 **제외한다**.
2. **부분그래프 닫힘 [증명].** (a) 와 (b) 는 모두 부분그래프에 대해 닫혀 있다. 부분그래프 $H\subseteq G$ 는 포함 $X(H)\hookrightarrow X(G)$ (동변) 을 주고, 동변 사상 $X\to Y$ 는 $\operatorname{coind}X\le\operatorname{coind}Y$ 와 $h(X)\le h(Y)$ 를 준다. 따라서 $\mathcal C_3^\tau$ 와 $\mathcal C_3^h$ 는 "$G\in\mathcal C$, $H\subseteq G$ ⇒ $H\in\mathcal C$" 를 만족한다.
3. **$K_4$ 판정.** $K_4\subseteq H$ 이면 $\tau(K_4)=4$, $h(X(K_4))=3$ (quotient $\mathbb{RP}^3$, $w_1^3\ne0$) 이므로 (a), (b) 모두 $K_4$ 부분그래프를 **배제**한다 [증명]. $K_4$ 세분 (간선 1 개 세분) 은 $\tau=3$ [R15 P7, 증명] 이므로 (a) 에 **허용**되고, (b) 에도 허용된다 ($h\le\operatorname{coind}\le2$ [증명]). 즉 R15 의 "K_4 세분은 zig≤3 가능" 과 일치한다.
4. **τ≤3k 예측.** 블록 $k$ 개가 $\mathcal C_3^\tau$ 에 있을 때 $\tau\le3k$ 는 **열린 문제**다 (블록 가법 $\tau\le\sum\tau_i$ 는 R12 에서 열린 J 와 같은 법칙). zig 판 (R14) 은 $\mathcal C_3^{\mathrm{zig}}\subseteq\mathcal C_3^\tau$ 이고 가법이 증명되어 있으므로 zig 판의 $3k$ 는 성립한다. τ 판에서는 예측 P1.
5. **SW 높이 가법 예측.** 높이의 join 가법은 표준적으로 $h(X*Y)\ge h(X)+h(Y)+1$ 쪽이 약하게 알려져 있다 [기억-미검증]. 상계 쪽 $h(X(G))\le\sum h_i+(k-1)$ 은 예측 P2 로 둔다.

## 3. 해석

- **K_4 판정은 두 불변량 모두에서 같다.** $K_4$ 부분그래프는 배제하고, $K_4$ 세분은 허용한다. 이는 R15 의 zig 결과와 같은 방향이다. 따라서 "블록에 $K_4$ 가 없다" 를 부분그래프 기준으로 쓰는 것이 안전하다.
- **τ 판과 SW 판의 관계.** $\mathcal C_3^\tau\subseteq\mathcal C_3^h$ 는 확실하다. 역은 P3 (미해결) 가 가른다. 역이 참이면 SW 높이 (계산 가능한 코호몰로지 량) 로 $\tau\le3$ 을 판정할 수 있다.
- **k 블록 상계.** SW 쪽 상계 P2 는 $\tau$ 쪽 상계 P1 과 같은 형태 ($\sum+(k-1)$ 또는 $\sum$) 이고, $K_{3k}$ 에서 둘 다 등호다. 블록 수가 늘면 상계가 선형으로 $3k$ 를 준다.

## 후속연구 지점
1. **P3 반례 탐색: $h\le2$ 이면서 $\tau=4$ 인 블록 (우선순위 1, 이유: 두 후보가 같은 클래스인지 가르는 유일한 질문).** 시작: $C_5[K_2]$ 의 $B_0$ 에 대해 $h$ 를 $H^*(X/\mathbb Z_2;\mathbb F_2)$ 의 $w_1$ 거듭제곱으로 계산 (R08 호몰로지 기록 $\tilde H_2=\mathbb Z$, $\tilde H_3=\mathbb Z^{10}$ 과 대조). 난점: 몫 복합체의 코호몰로지 환 (곱 구조) 계산 도구 필요.
2. **τ 판 블록 가법 (P1) 의 상태 정리.** 이유: zig 판은 증명, τ 판은 열림 (R12 정정). 시작: R14 의 zig 가법 보조정리에서 $\tau$ 로 옮길 수 있는 부분 (블록 사이 조인 $\mathbb Z_2$-사상) 을 확인. 난점: R12 정정 이후 조인 보조정리 자체가 재검토 대상.
3. **SW 가법 (P2) 의 증명 시도.** 시작: $w_1$ 의 조인 공식 (Gysin 열) 으로 $h(X*Y)$ 를 $h(X)+h(Y)+1$ 로 상계. 난점: 몫 공간 $(X*Y)/\mathbb Z_2$ 의 코호몰로지 분해가 표준 Künneth 로 주어지지 않는다 (자유 작용의 몫).
4. **nerve 를 불변량에서 제외하는 근거 정리 (우선순위 4).** 이유: 블록 덮개 의존성을 명시하면 𝒞_3 정의가 덮개에 독립임을 보일 수 있다. 시작: 교집합 $\mathbb Z_2$-수축성 조건이 성립하는 교차 패턴을 특성화 (R12 I-5 의 후속). 난점: 조건 자체가 교차 패턴 전체에 의존.
