# REFINE-2-verify: 독립 정의 후보 2개와 기준별 판정 (증명 없음)

- 작성자·역할: researcher2 (가공 라운드, 독립 검증). 후보는 연구원1 의 REFINE-1 을 읽기 전에 독립적으로 세웠다.
- 기준: (1) χ≥t ⇒ K_t 의 입력이 되는가, (2) 블록 색과 교차 조건이 K_t 모델 구성에 쓰이는가, (3) 기존 결과 (R25 조인, R34 가젯, R35 매칭 χ≤6) 를 살리는가.
- 판정 용어: **입력 되는가** / **막히는가** / **무관한가**. 증명은 하지 않는다.

## 후보 A: 교차 차수 제한 시트 $\mathcal S_d$
- 정의: $G=B_1\cup B_2\cup H$, $B_i$ 평면, 각 정점의 교차 이웃 수 $\le d$ (양쪽 모두).
- 특수: $d=1$ 은 매칭 (R35), $d=\infty$ 는 제한 없음 (기본 정의).

| 기준 | 판정 | 근거 |
|---|---|---|
| (1) χ≥t ⇒ K_t 입력 | **부분 입력.** $d\le1$ 에서 $t=7$ 은 공허하게 참 (χ≤6, R35). $d\ge2$ 에서는 χ=7 구성 미결 (R36 에서 장애 확인). | R35 §1, R36 §2 |
| (2) 블록 색·교차가 K_t 모델에 쓰이는가 | **색은 쓰이고 모델은 안 쓰인다.** 블록 5-색칠과 교차 리스트 (크기 $6-d$) 는 χ 상계에만 쓰인다. K_t 분기 집합은 어디서도 구성되지 않는다. | R35 §1 |
| (3a) R25 조인 증명 | **무관.** $d$ 가 유한하면 완전 조인 (차수 $|B_2|$) 은 제외됨. | R25 |
| (3b) R34 가젯 | **살림 (d=1 에서).** $K_5-e$ 동색 강제는 매칭 쌍에서 성립. 단, 4 색에서만 성립하므로 χ=7 (6 색) 에는 막힌다. | R34, R36 §2(c) |
| (3c) R35 χ≤6 | **살림.** $d\le1$ 의 정리가 그대로 입력. | R35 |

**판정 요약 (후보 A):** 입력 되는가 — 부분 (d≤1 에서만 t=7 공허 참). 막히는가 — K_t 모델 구성 단계 (색이 모델로 번역되지 않음). 가젯 (R34) 은 살아남지만 6 색에서 막힌다.

## 후보 B: 분기-접촉 시트 $\mathcal B_c$
- 정의: 각 블록 $B_i$ 는 $c_i$ 개의 연결 부분집합 (분기 집합) $\{P^i_1,\dots,P^i_{c_i}\}$ 로 나뉘고, 서로 다른 블록의 모든 분기 집합 쌍 $(P^1_a,P^2_b)$ 이 교차 간선으로 접촉한다. 같은 블록 내부 쌍은 블록 마이너로 접촉 (블록 모델이 $K_{c_i}$ 를 가짐).
- 귀결: $K_{c_1+c_2}$ 마이너가 직접 나온다 (R13 명제 2.2 의 분기-접촉 형태).

| 기준 | 판정 | 근거 |
|---|---|---|
| (1) χ≥t ⇒ K_t 입력 | **입력 된다 (조건부).** 블록 $\chi_i=h_i$ 이고 $\mathcal B_c$ 이면 $K_{\chi_1+\chi_2}$ 이 나온다 (평면 블록의 $\chi\le4$ 와 Dirac: $h_i\ge\chi_i$ 는 $\chi_i\le4$ 에서 성립). 그러나 "χ≥t 이면 $\mathcal B_c$ 가 성립" 은 입력 명제가 아니다 (χ 에서 분기 접촉을 유도하는 단계 없음). | R13, Dirac |
| (2) 블록 색·교차가 K_t 모델에 쓰이는가 | **블록 색은 안 쓰인다.** 모델은 블록 마이너와 교차 접촉으로 구성되고, 색은 $h_i=\chi_i$ 를 통해서만 들어간다. 교차 조건 (분기 접촉) 은 색칠 조건과 무관하게 주어진다. | 정의 |
| (3a) R25 조인 증명 | **살림.** 완전 조인은 모든 분기 쌍이 접촉하는 특수형이므로 $\mathcal B_c$ 의 예. | R25 |
| (3b) R34 가젯 | **막힌다.** 매칭 교차는 분기 집합 쌍 접촉을 보장하지 않는다 (대형 분기 집합이 여럿 접촉하려면 교차 차수가 커야 한다). | R34 §1, R35 |
| (3c) R35 χ≤6 | **무관.** χ 상계 정리이며 $\mathcal B_c$ 의 접촉과 무관. 매칭에서 $\mathcal B_c$ 가 깨지는지는 확인되지 않음 (대형 분기 집합에서는 가능할 수 있음). | R35 |

**판정 요약 (후보 B):** 입력 되는가 — 예 (조건부). 막히는가 — 색→접촉 변환 단계 (χ≥t ⇒ $\mathcal B_c$ 를 보장하는 명제가 없음). 가젯 (R34) 과 매칭 (R35) 은 이 후보에서 무관 또는 막힘.

## 요약 비교
| | 입력 되는가 | 막히는가 | 기존 결과 살림 |
|---|---|---|---|
| A ($\mathcal S_d$) | 부분 (d≤1) | K_t 모델 단계 (색→모델 없음) | R35 살림, R34 살림 (4색), R25 무관 |
| B ($\mathcal B_c$) | 조건부 예 | 색 → 분기 접촉 변환 | R25 살림, R34 막힘, R35 무관 |

**공통 판정:** 두 후보 모두 χ≥t 에서 K_t 로 가는 고리를 가지지 않는다. A 는 χ 상계를 주고 모델을 주지 않는다. B 는 모델을 주지만 χ 와 연결되지 않는다. 다음 단계는 "χ 가 큰 것에서 분기 접촉 (B 의 전제) 을 끌어내는 명제" 이다.

## 후속연구 지점
1. **χ→접촉 변환 명제 (우선순위 1).** 이유: B 가 입력이 되려면 χ≥t 에서 분기 접촉을 보장하는 명제가 필요하다. 시작: 4-색 임계 블록 (K_4 류) 에서 색 클래스를 분기 집합으로 쓰는 방법을 확인.
2. **A 와 B 의 교집합 (d 제한 + 분기 접촉).** 이유: A 의 χ 상계와 B 의 모델이 결합하면 χ=7 에서 K_7 이 나올 수 있다. 시작: $d=2$ 와 분기 집합 크기 2 조합에서 접촉 조건을 확인.
3. **REFINE-1 과의 대조.** 이유: 연구원1 의 후보가 올라오면 위 기준으로 판정하여 중복/차이를 기록한다 (아직 읽지 않음).
