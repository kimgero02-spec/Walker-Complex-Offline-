## 요약
1. **[증명] 영역–성분 정리.** 점 집합 위의 삼각분할 층 $T_1,\dots,T_k$ (곧은 선, 극대 층) 에서 **교차되지 않는 간선 = 모든 층의 공통 간선**이고, 공통 간선이 이루는 평면 골격 $H$ 의 각 면 (공통 빈 삼각형 제외) 안에서 나머지 간선들의 교차 그래프는 **정확히 하나의 연결 성분**이다. 곧 셀로판 겹침은 "평면 틀 $H$ + 면마다 하나의 기약 결합 덩어리" 로 표준 분해된다.
2. **[증명] 따름 정리.** 공통 내부 간선이 없는 두 삼각분할 층의 층간 교차 수 $X\ge 6n-4h-7$ ($h$ = 볼록 껍질 점 수; 볼록이면 $2n-7$, $n\le10$ 에서 등호 [계산 확인]). 교차 차수 $(1,c)$ 는 극대 층에서 $(1,1)$ 로 **붕괴**하고 모든 영역이 사각형 → 1-평면 → χ ≤ 6 ($K_6$ 에서 등호 [계산 확인]).
3. **[증명] 교차 보조정리 판 (요구 (a))**: 직선 $k$ 층 겹침에서 $\chi\le\max(8,\,1+(512X)^{1/4})$. **[증명] 제안 C**: 볼록 껍질 공유 시 $\chi\le 2\chi(\mathrm{Cr})+2$, 그리고 $\chi\le 4\,\omega(\mathrm{Cr})$ (Capoyleas–Pach [기억-미검증]). 그러나 $\omega(\mathrm{Cr})$ 는 Hadwiger 수를 제어하지 못함 (뫼비우스 사다리) [증명].
4. **[계산 확인]** $K_8$ 은 곧은 선 2 층 (정확 유리수 검증, $X=25$, 교차 차수 $(7,6)$; 언덕오르기로 $X=22$ 까지) → 2 층 셀로판으로 χ=8. 볼록 $K_{2p}$ 의 $p$ 층 분해는 $p=3,4,5$ 에서 정확히 $2^{p-1}$ 개, 최소 층간 교차 $2n-7$ 은 지그재그 이웃 층에서만.
5. 판정: 볼록 위치에서는 기하가 **클리크 합 ($K_2$-합, 공통 현) 으로 환원**된다 (새것 없음). 일반 위치에서는 영역들이 클리크가 아니라 **평면 틀의 면 경계 (사이클) 를 따라** 붙는다 — 이것이 클리크 합과 다른 결합이며, 팀의 R48–R50 "면 안 가젯" 모형을 **기하가 표준적으로 낳는다.**

## 본문

### 1. 번역 사전 (셀로판 ↔ 이산 기하)
| 셀로판 언어 | 이산 기하 언어 | 비고 |
|---|---|---|
| 카드 위 정점 위치 | 점 배치 $P$ (일반 위치) | |
| 겹침 결과의 교차 패턴 | **순서형** $\omega:P^3\to\{\pm1\}$ (세 점의 방향 = 시계/반시계) | 두 선분 $ab,cd$ (끝점 공유 없음) 의 교차 ⇔ $\omega(a,b,c)\ne\omega(a,b,d)$ 이고 $\omega(c,d,a)\ne\omega(c,d,b)$. [증명] 따라서 교차 패턴은 순서형만의 함수. |
| 층 = 교차 없는 카드 | 평면 직선 그래프; 극대이면 **삼각분할** | |
| 층 배정 | 그림 $D$ 의 **교차 그래프** $\mathrm{Cr}(D)$ (정점 = 간선, 인접 = 교차) 의 올바른 색칠 | 고정 그림의 최소 층 수 $=\chi(\mathrm{Cr}(D))$ [증명] |
| 층간 교차 수 $X$ | $\mathrm{cr}(D)$ (층 안 교차는 0) | [증명] |
| 교차 차수 $(c_1,c_2)$ | 이분 교차 그래프 $\mathrm{Cr}(L_1,L_2)$ 의 양쪽 최대 차수 | |
| 공유 골격 (모든 층 공통 간선) | 극대 층이면 **교차되지 않는 간선 전체** (정리 A(i)) | 볼록 껍질 사이클은 항상 공유 |
| 볼록 껍질 해밀턴 사이클 공유 (제안 C) | **볼록 기하 그래프**; $\mathrm{Cr}$ = **원 그래프** (원 위 현들의 교차 그래프) | $k$ 층 = 고정 순서 $k$-페이지 책 |
| 층 뒤집기 (제안 B) | 현을 원 밖으로 = 책의 다른 페이지 | 위상 판은 $2k$ 페이지 |

용어: **순서형** = 점 배치를 세 점 방향만으로 기록한 조합적 자료. **책 두께** = 정점을 한 줄 (등뼈) 에 놓고 간선을 교차 없는 페이지들로 나눌 때의 최소 페이지 수. **원 그래프** = 원의 현들을 정점으로, 교차를 인접으로 한 그래프. **준평면** (quasi-planar) = 서로 교차하는 간선 3 개가 없는 그림.

### 2. 가져온 정리 (팀이 안 써 본 것 ★)
1. ★ **교차 보조정리** (Ajtai–Chvátal–Newborn–Szemerédi, Leighton) [기억-미검증: 출처]: $m\ge4n$ 이면 $\mathrm{cr}(G)\ge m^3/(64n^2)$. 증명 스케치 (표준 확률 논법, 그래서 부등식 자체는 [증명]): 오일러에서 $\mathrm{cr}\ge m-3n$; 각 점을 확률 $p$ 로 남기면 $p^4\mathrm{cr}\ge p^2m-3pn$; $p=4n/m$.
2. ★ **Capoyleas–Pach** [기억-미검증]: 볼록 기하 그래프에 서로 교차하는 간선 $k+1$ 개가 없으면 $m\le 2kn-\binom{2k+1}{2}$ ($n\ge2k+1$). ($k=1$ 이면 외평면 $2n-3$ 과 일치 [계산 확인, 손]; $K_{2k+1}$ 에서 등호 [증명, 손 계산].)
3. ★ **원 그래프의 χ 유계성** (Gyárfás; 현대 판 $\chi=O(\omega\log\omega)$, Davies 등) [기억-미검증]; 삼각형 없는 원 그래프 χ ≤ 5 (Ageev) [기억-미검증].
4. ★ **선분 교차 그래프는 χ 유계가 아님** (Pawlik–Kozik–Krawczyk–Lasoń–Micek–Trotter–Walczak) [기억-미검증]: 삼각형 없고 χ 가 임의로 큰 선분 교차 그래프.
5. ★ **Erdős–Szekeres** [기억-미검증]: $\binom{2s-4}{s-2}+1$ 개 일반 위치 점 중 $s$ 개는 볼록 위치.
6. ★ **책 두께** (Bernhart–Kainen) [기억-미검증]: $\mathrm{bt}(K_n)=\lceil n/2\rceil$. $k$-페이지 ⇒ $m\le n+k(n-3)$ ⇒ χ ≤ $2k+2$ [증명: 각 페이지는 볼록 다각형의 비교차 현 ≤ $n-3$ 개, 유도 부분그래프도 $k$-페이지라 퇴화도 ≤ $2k+1$].
7. ★ **기하 두께** (Dillencourt–Eppstein–Hirschberg) [기억-미검증]: $\bar\theta(K_8)=2$, $\bar\theta(K_9)=3$. — $K_8$ 부분은 아래 §5 에서 [계산 확인].
8. ★ **Hanani–Tutte** [기억-미검증]: 독립 간선 쌍이 모두 짝수 번 교차하는 그림이 있으면 평면.
9. ★ **Mnëv 보편성** [기억-미검증]: 추상 순서형의 실현 가능성은 ∃ℝ-완전. 
10. Borodin: 1-평면 그래프 χ ≤ 6 [기억-미검증]. Albertson 추측 (χ=r ⇒ cr ≥ cr($K_r$)), 작은 r 에서 증명됨 [기억-미검증]. Hanke–Ottmann–Schuierer: 뒤집기 거리 ≤ 교차 수 [기억-미검증].

### 3. 핵심 결과: 영역–성분 정리 [증명]
**설정.** $P$ = 일반 위치 점 $n$ 개 (껍질 점 $h$ 개). $T_1,\dots,T_k$ = $P$ 의 삼각분할 (곧은 선 극대 층). $H=\bigcap T_i$ (공통 간선; 껍질 간선 포함), $D=\bigcup T_i\setminus H$, $\mathrm{Cr}(D)$ = $D$ 의 교차 그래프.

**정리 A.** (i) $D$ 의 모든 간선은 $D$ 의 어떤 간선과 교차하고, $H$ 의 간선은 아무것과도 교차하지 않는다. (ii) $\mathrm{Cr}(D)$ 의 연결 성분들은 "$H$ 의 유계 면 중 모든 $T_i$ 에 공통인 빈 삼각형이 아닌 것" 과 일대일 대응한다.

*증명.* (i) $e\in T_i\setminus T_j$ 이면 $T_j$ 의 극대성으로 $e$ 는 $T_j$ 의 간선 $f$ 와 교차; $T_i$ 는 비교차라 $f\notin T_i$, 곧 $f\in D$. $H$ 의 간선은 모든 층에 있어 어느 층 간선과도 교차 못 함.
(ii) $D$ 의 간선은 $H$ 와 교차하지 않으므로 $H$ 의 한 면 $R$ 안에 놓이고, 교차하는 두 간선은 같은 면 → 성분 ↦ 면 이 잘 정의. 전사: $R$ 안에 $D$ 간선이 없으면 각 $T_i$ 가 $R$ 을 더 쪼개지 않으므로 $R$ 은 공통 빈 삼각형. 단사가 핵심: $R$ 안의 배치 (간선 조각들) 의 면 $f$ 마다, $f$ 경계의 $D$-변들이 모두 한 성분임을 보인다. 경계의 모서리는 (가) 교차점 — 두 변이 교차하니 같은 성분, (나) 원래 점 $v$ 에서 연속한 두 $D$-변 — 보조정리 1, (다) $H$-변 $uw$ 의 양옆 — 보조정리 2. ($R$ 안에서 $H$-변 두 개가 한 점에서 연속하면 모든 층이 그 각을 같은 삼각형으로 채워 공통 빈 삼각형이 되므로 제외.) 면 $f$ 마다 $D$-변이 있고, $R$ 은 연결 열린 집합이라 배치의 면들은 $D$-조각을 가로질러 이웃하며 연결 → 성분은 하나. ∎

*보조정리 1 (점 모서리).* $v$ 에서 각으로 연속한 $va, vb\in D$ 는 같은 성분. 증명: 사이 각은 어떤 삼각형의 각의 일부라 $<\pi$.
- 같은 층 $T_i$: 삼각형 $vab\in T_i$. $va$ 와 교차하는 간선 중 $v$ 에 가장 가까운 것 $g$, $vb$ 쪽은 $h$. $g$ 는 $vab$ 에 들어가 $vb$ 를 지나면 (그러면 끝) 아니면 $ab$ 를 지나거나 $b$ 에서 끝난다; $h$ 도 대칭. $g,h$ 가 교차하면 끝. 아니면 순서상 $g$ 가 $ab$ 의 점 $q$, $h$ 가 $s$ 로 $a,q,s,b$ 순 (q=b 이면 $h$ 가 $b$ 에서 끝나며 $vb$ 와 교차해야 해서 불가); $ab\in H$ 이면 교차 불가라 모순이고 (그 경우 $g$ 는 $b$, $h$ 는 $a$ 에서 끝나 서로 교차 → 같은 성분), $ab\in D$ 이면 $g,h$ 둘 다 $ab$ 와 교차 → 같은 성분.
- 다른 층 $va\in T_i$, $vb\in T_j$ (각자 상대 층에 없음; 있으면 같은 층 경우): $T_i$ 의 삼각형 $vac$ ($c$ 는 $b$ 너머 다음 $T_i$-이웃) 는 반직선 $vb$ 를 품고 $b$ 는 빈 삼각형 밖이므로 $vb$ 는 $ac$ 와 교차; 대칭으로 $T_j$ 의 $vbd$ 에서 $va$ 는 $bd$ 와 교차. 각 $avb<\pi$ 인 볼록 쐐기 안에서 $ac$ 는 ($a$, 반직선 $vb$ 위 $b$ 보다 가까운 점) 을, $bd$ 는 (반직선 $va$ 위 $a$ 보다 가까운 점, $b$) 를 잇는다 — 볼록 사각형의 두 대각선이라 교차. $ac\sim vb$, $bd\sim va$, $ac\sim bd$ → 같은 성분. ∎
*보조정리 2 ($H$-변).* $R$ 쪽에서 $uw\in H$ 에 붙은 각 층의 삼각형 $uwz_i$. $u$ 에서 첫 간선 $uz_a$, $w$ 에서 첫 간선 $wz_b$. $z_a=z_b=z$ 이면 면은 삼각형 $uwz$ 안이고 다른 모서리는 교차점 또는 $z$ (보조정리 1). $z_a\ne z_b$ 이면 빈 삼각형 조건 ($z_b\notin uwz_a$, $z_a\notin uwz_b$) 과 각 순서로 $uz_a$ 와 $wz_b$ 가 교차하고, 면은 삼각형 ($u,w$, 교차점) 안 → 모서리는 교차점뿐. ∎

[계산 확인] 볼록 $n=7,9,10$, $k=3,4$ 무작위 층 각 3 예, 공통 현을 강제한 $n=10,k=3$ 3 예, 일반 위치 $n=7,8,9$ 두 층 12 예에서 성분 수 = 예측 영역 수 (`c4_regions.py`, `c5_k6.py`). (근거는 위 증명이고, 계산은 증명 단계의 오타 점검용.)

**따름 B (교차 하한) [증명].** 각 영역 $R$ 에서 $X_R\ge |D_R|-1$ (연결 그래프). 두 층이고 공통 내부 간선이 없으면 $|D|=2(3n-3-2h)$, 영역 하나 → $X\ge 6n-4h-7$; 볼록 ($h=n$) 이면 $X\ge 2n-7$. 
[계산 확인] 볼록 $n=5..9$ 에서 서로소 삼각분할 쌍의 최소 $X$ 가 정확히 $2n-7$ (`c1b_tri.py`), 지그재그 이웃 층이 $n=6,8,10$ 에서 등호 (`c1_convex.py`).

**따름 C (교차 차수 붕괴) [증명].** 두 삼각분할 층에서 $c_1=1$ (층 1 의 각 간선이 층 2 와 ≤1 번 교차) 이면: 영역 $R$ (경계 점 $r$, 내부 점 $i$) 에서 두 층의 내부 간선 수는 같고 $s_R=r-3+3i$. $2s_R-1\le X_R\le c_1s_R=s_R$ ⇒ $s_R\le1$ ⇒ $R$ 은 내부 점 없는 사각형, 두 대각선이 한 번 교차. 따라서 $c_2=1$ 도 자동, $G$ = 평면 틀 + 일부 사각형 면에 두 대각선 = 1-평면 ⇒ χ ≤ 6 (Borodin [기억-미검증]). 등호: $K_6$ 을 직선 1-평면으로 [계산 확인] (점 $(0,35),(22,13),(6,9),(5,8),(14,20),(25,13)$, 교차 3 쌍; 껍질 3 점이라 두 층 모두 삼각분할 12 간선, 공통 9). 
**따름 D [증명].** $(c_1,c_2)=(2,2)$ 이면 각 영역의 $\mathrm{Cr}_R$ 은 이분, 최대 차수 ≤2, 간선 수 $2s_R-1$ 또는 $2s_R$ → **경로 또는 짝 사이클**. [계산 확인] 볼록에서 서로소 쌍 중 (2,2) 는 $n=6$ (다윗의 별, 6-사이클) 에만 있고 $n=7..10$ 에는 없음 (`c9_path.py`).

### 4. 요구 (a): 교차 보조정리로 χ 와 $K_t$ 를 묶기
**정리 E [증명, 교차 보조정리 상수는 위 스케치].** 직선 $k$ 층 겹침 (층간 교차 $X$) 이면 $\chi(G)\le\max\bigl(8,\;1+(512X)^{1/4}\bigr)$. 
증명: $t=\chi\ge9$ 이면 $t$-임계 부분그래프 $F$ ($n_F\ge t$, $\delta\ge t-1\ge8$, $m_F\ge 4n_F$). $X\ge\mathrm{cr}(F)\ge m_F^3/(64n_F^2)\ge n_F(t-1)^3/512\ge(t-1)^4/512$. ∎ 
비교: Albertson 류 기대값 $\mathrm{cr}(K_t)\approx t^4/64$ 와 상수 $8^{1/4}\approx1.68$ 배 차이. $K_8$ 의 2 층 그림 ($X=25$) 에 대입하면 상계 11 — 모순 없음.

**$K_t$ 마이너와의 결합 — 정직한 판정.**
- [증명] 교차 수만으로는 $K_t$ 마이너를 강제할 수 없다: 교차 수 $X$ 가 큰 영역에서 χ 는 $X^{1/4}$ 로만 제한되지만, 같은 $X$ 에서 $K_t$-마이너 없는 그래프 (예: 큰 격자의 비평면 그림) 도 있다. 반대로 $X<\mathrm{cr}(K_t)$ 영역에서는 Albertson 추측이 참이면 χ<t 라 Hadwiger 가 **공허**하다. 곧 "X 작음 ⇒ K_t" 형 명제는 Albertson 과 동치 정도의 정보뿐. [추측: 동치성의 정확한 형태는 미정리]
- 대신 정리 A 를 쓰면 **χ ≥ 7 인 두 삼각분할 겹침은 $s_R\ge2$ 인 영역 (오각형 이상이거나 내부 점 포함) 을 반드시 가진다** [증명, 따름 C + Borodin]. 이것이 갭 {7} 문제의 기하판 필요조건이다.

### 5. 요구 (b) 제안 C: 공통 해밀턴 사이클 (볼록 껍질)
**정리 F [증명].** 모든 층이 볼록 껍질 사이클을 공유하면 (볼록 위치): (i) $\chi(G)\le 2\chi(\mathrm{Cr})+2$ — $\chi(\mathrm{Cr})$ 은 고정 순서 책 두께; (ii) 두 층이면 2-페이지라 평면 (제안 B 와 일치); (iii) Capoyleas–Pach [기억-미검증] 를 쓰면 $\chi(G)\le 4\,\omega(\mathrm{Cr})$ (퇴화도 < $4\omega$), 하한 $K_{2\omega+1}$ (볼록 $K_{2\omega+1}$ 의 서로 교차하는 현 최대 묶음 = $\omega$) [증명]. 
**결론:** 결합 복잡성을 층 수 $\chi(\mathrm{Cr})$ 가 아니라 **서로 교차하는 간선 최대 묶음 $\omega(\mathrm{Cr})$** 로 재도 χ 를 선형으로 제어한다. 원 그래프의 χ 유계성이 "층 수 ≤ $f(\omega)$" 를 주므로 두 측도는 볼록에서 동등 (다항 손실). 
**정리 G [증명] — 반대 방향 실패.** $\omega(\mathrm{Cr})$ 이 커도 Hadwiger 수는 작을 수 있다: $2q$-사이클 + 대각 현 $i\,(i+q)$ (뫼비우스 사다리) 는 $\omega=q$ 이지만 경로폭 ≤ 4 (사다리의 경로폭 2 + 꼬인 두 간선의 끝점을 모든 가방에 추가) 라 $K_6$ 마이너 없음, χ ≤ 3. 따라서 "ω(Cr) 큼 ⇒ $K_{f(\omega)}$ 마이너" 는 [망상: 반증됨]. χ 에 대해서도 하한 쪽 제어는 없음 (상계 위계일 뿐, R50 판정과 같은 모양).

### 9. 다른 연구원 보고서와 맞춤 (R51-researcher2 읽음; R51-researcher1 은 제출 전이라 못 읽음)
- r2 정리 3.1 (위상 판 $(1,\infty)$ ⇒ $|E|\le4n-8$, χ ≤ 8) 와 내 따름 C 는 **서로 보완**한다: 층이 극대 (삼각분할) 이면 $(1,c)$ 는 $(1,1)$ 로 붕괴해 χ ≤ 6 [증명]. 따라서 r2 의 열린 칸 "$(1,\infty)$ 에서 χ=7, 8 이 실현되는가" 의 반례는 **극대가 아닌 층**에서만 나올 수 있다 [증명]. (후속 3 과 직결.)
- r2 의 3-페이지 χ=7 없음 ($n\le12$, CEGAR 정확 판정) 은 내가 Gallai 분해 [기억-미검증] 로 얻은 "있다면 $n\ge13$" 과 일치. 내 무작위 시도는 근거로 쓰지 않는다.
- $K_8$ 직선 2 층: r2 는 $(6,6)$·교차 30, 나는 $(7,6)$·교차 25 (탐색 22). 두 독립 점 배치가 $\bar\theta(K_8)=2$ 를 확인 [계산 확인].
- r2 의 "χ 증가는 전부 층간 교차에서 온다" 는 정리 A 의 형태로 정밀화된다: 교차는 공통 틀 $H$ 의 면 안에서만 일어나고, 면마다 교차 그래프가 연결.

## 환원 틀에서의 함의
- **판정 1 (볼록 위치) [증명]:** 공통 간선 = 교차 안 되는 현이 다각형을 영역으로 자르고, 영역끼리는 **현 하나 ($K_2$)** 를 공유한다 → $G$ 는 영역 그래프들의 **2-합 (클리크 합)**. 기하는 클리크 합을 넘는 것을 주지 않는다 (문주님 지적과 일치). 게다가 2 층이면 평면.
- **판정 2 (일반 위치) [증명]:** 영역은 평면 틀 $H$ 의 **면** 이고, 영역 그래프들은 면의 경계 사이클·경로를 따라 붙는다 — 클리크가 아니다. $G$ = (평면 틀 $H$) + (각 면 안에 교차 그래프가 연결인 기약 결합 덩어리). 이것은 팀이 R48–R50 에서 손으로 만든 "평면 시트 + 면 안 가젯" 모형을 **셀로판 기하가 표준적으로 (유일하게) 낳는** 분해다. 
- **새 결합 측도 (클리크 합에 없는 것):** 영역별 (a) 크기 $s_R=r-3+3i$, (b) 교차 그래프 모양 (단일 교차 / 경로·사이클 / 나무 / 일반), (c) $\omega(\mathrm{Cr}_R)$, (d) $X_R\ge s$-기반 하한. 증명된 사실: 모양이 "단일 교차" 뿐이면 χ ≤ 6; χ ≥ 7 은 $s_R\ge2$ 인 영역을 요구. 볼록 + 공유 골격에서는 $\omega(\mathrm{Cr})$ 이 χ 를 선형 제어 (상계 위계), Hadwiger 수는 제어 못 함.
- **갭 문제의 기하판:** 팀의 (2,3) 갭 {7} 은 "평면 틀 + 경로/사이클형 결합 영역 (P4) 들로 χ=7 을 만들 수 있는가" 로 옮겨진다. 이 판은 영역 모양이 유한 종류로 분류되는 쪽 (P4, P5) 이라 공격면이 좁다.

## 후속연구 지점
1. **(최우선) 일반 위치 $(2,2)$·$(2,3)$ 영역의 분류와 χ.** 무엇: 내부 점이 있는 영역에서 교차 그래프가 경로/사이클 (P4) 인 두 삼각분할의 모양을 분류하고, 평면 틀 + 그런 영역들로 χ=7 을 만들거나 χ ≤ 6 을 증명. 왜: 갭 {7} 의 기하판이며 영역 모양이 유한 패턴으로 묶일 가능성. 시작: 따름 C 의 계산 $2s-1\le X\le 2s$ 로 영역 내부 점 수 $i$ 와 경계 $r$ 의 관계를 먼저 증명; 작은 $r,i$ 에서 열거. 난점: 일반 위치는 볼록과 달리 영역 크기가 유계인지 불분명 (P5 의 볼록 증명도 아직 없음).
2. **P5 와 P10 의 연역 증명.** 무엇: 볼록 서로소 (2,2) 쌍은 $n\le6$; 볼록 $K_{2p}$ 의 $p$ 층 분해는 $2^{p-1}$ 개. 왜: 계산으로만 확인; 둘 다 귀 (ear) 논법·지름 현 (서로 교차하는 $p$ 개 지름이 층마다 하나씩) 으로 닿을 듯. 시작: 귀 현 $(v-1,v+1)$ 를 교차하는 상대 층 간선은 모두 $v$ 에서 나온다는 관찰에서 $a\le1$ (교차 차수 1 인 간선 ≤ 1 개) 로 연쇄. 난점: 귀 사이 중간 부분의 사례 분석.
3. **극대가 아닌 층으로 영역–성분 정리 확장.** 무엇: 셀로판 층이 삼각분할이 아닐 때 (희소 층) 교차 안 된 비공통 간선이 생긴다; 이때 분해는? 왜: 실제 겹침 (오각형 + 삼각형) 은 극대가 아님. 시작: 층을 극대화하되 새 간선을 "유령"으로 두고 χ 단조성 이용; 반례 후보는 유령이 영역을 잘못 잇는 경우. 난점: 극대화가 그래프를 바꿔 χ 비교가 한 방향뿐.
4. **기하 Albertson (P7) 과 Hadwiger 결합.** 무엇: 직선 2 층에서 $K_7,K_8$ 의 최소 $X$, 그리고 "χ ≥ 7 인 2 층 겹침은 $K_7$ 마이너" 를 정리 A 의 영역 분해로 공격 (평면 틀 수축 + 영역 덩어리). 왜: 교차 수만으로는 공허하다는 판정 (§4) 을 넘어서는 유일한 경로가 영역 구조. 난점: 영역 덩어리 안의 마이너 경로가 틀의 면 경계를 지나야 함.
5. **볼록 ω ≤ 2 ⇒ χ ≤ 5 (P8) 증명 시도.** 무엇: Capoyleas–Pach 의 구조 (준평면 볼록 그래프 = 두 외평면의 특수 결합?) 로 퇴화도 또는 Kempe 논법. 왜: 성립하면 "ω(Cr)" 측도의 첫 칸이 정확. 난점: 4n−10 간선이면 퇴화도는 7 까지라 셈만으로는 부족.
