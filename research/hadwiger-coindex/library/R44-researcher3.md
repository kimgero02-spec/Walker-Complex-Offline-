# [R44-researcher3] (S2) 의 교차 차수 ≥3 경우 해결: Berge-비순환 K_{2,2} 조건 ⇒ zig≤3, 경계 W_5

- 작성자·역할: researcher3 (망상꾼). 무인 6라운드. 한 번만 보고. 대량 계산 없음 (손 논증).
- 판정 도구 (R06-r1 보조정리 1, R43 §0): $\operatorname{zig}\le3$ ⇔ 어떤 $K_{2,2}$ 도 교대 (ABAB) 하지 않는 선형 순서가 존재. 각 $K_{2,2}$ 는 **자기 네 점의 상대 순서만** 제약한다.

## 0. 실패 기준 (먼저)
- **정리 A** (아래): $K_{2,2}$ 정점 4-집합 족 $\mathcal K(G)$ 가 선형 (두 원소가 정점 ≤1 공유) 이고 Berge-비순환이면 zig≤3. 실패 = 조건을 만족하는데 zig≥4 인 그래프 한 개.
- **경계 B:** 조건을 빼면 zig=4 인 $K_4$-자유 평면 χ=4 그래프가 있다. 실패 = 그런 예의 zig 가 3 이하로 판명.

## 1. R43 막힘의 정정 [증명]
- R43 §2 에서 "공유 정점의 바깥 자리가 둘뿐" 이라 적은 것은 잘못된 걱정이었다. 각 $K_{2,2}$ 의 제약은 자기 네 점에만 걸리므로, 공유 정점 $v$ 를 바깥 끝에 둘 필요가 없다. $v$ 를 지나는 $K_{2,2}$ 들 $Q_1,Q_2,\dots$ 의 나머지 점을 모두 $v$ 의 한쪽에 두고, 각 $Q_j$ 의 세 점을 "$v$ 와 같은 쪽 원소를 먼저" (AABB) 놓으면 각각 교대하지 않는다. 다른 $Q$ 의 점이 사이에 끼어도 무관하다.
- 또한 R43 의 "교차 그래프가 숲" 조건은 한 정점이 세 $K_{2,2}$ 에 속하면 교차 그래프에 삼각형이 생겨 깨진다. 즉 R43 의 "차수 ≥3" 은 한 $K_{2,2}$ 가 서로 다른 정점으로 세 개 이상의 $K_{2,2}$ 와 만나는 경우다. 둘 다 아래 정리 A 가 덮는다.
- 층: 복잡성 환원 **층 2 (결합 규칙 = 순서)**.

## 2. 정리 A (일반화) [증명]
**진술.** $\mathcal K(G)$ 가 (i) 선형: 서로 다른 두 $K_{2,2}$ 가 정점을 최대 1 개 공유, (ii) 길이 ≥3 의 Berge 사이클 없음 (길이 2 의 Berge 사이클은 정확히 (i) 의 위반이므로, (i)+(ii) = 발생 이분그래프가 숲) 이면 $\operatorname{zig}(G)\le3$.
**증명 (귀납).** $|\mathcal K|$ 에 대한 귀납. $\mathcal K=\emptyset$ 이면 임의 순서. 아니면 Berge-비순환 선형 하이퍼그래프에는 **잎 원소** $Q$ 가 있다: $Q$ 의 정점 중 다른 원소와 공유되는 것이 최대 1 개 [증명: 모든 원소가 공유 정점 ≥2 개를 가지면, 공유 정점과 원소를 번갈아 따라가는 경로가 유한성 때문에 되돌아와 Berge 사이클을 만든다]. $Q$ 의 사적 (다른 $K_{2,2}$ 에 없는) 정점 세 개 (공유 정점이 없으면 네 개) 를 잠시 제외하고 나머지 $K_{2,2}$ 족에 귀납 가정을 적용해 순서를 얻는다. 사적 정점들은 다른 $K_{2,2}$ 의 제약에 나타나지 않으므로, 이들을 공유 정점 $u$ 바로 뒤에 "u 와 같은 쪽 원소, 반대쪽 두 원소" 순서 (AABB) 로 끼워 넣으면 $Q$ 는 교대하지 않고 다른 $K_{2,2}$ 의 상대 순서는 바뀌지 않는다. (공유 정점이 없으면 네 점을 AABB 로 연속 배치.) ∎
- 따름: R43 의 (S2) (숲, 차수 무관) 는 정리 A 에 포함되므로 **차수 ≥3 경우도 zig≤3**. (S1) ($C_4$-자유) 는 $\mathcal K=\emptyset$ 인 특수형.
- 층: **층 1–2 (블록 조건과 인증서 구성).**

## 3. 경계 B: 조건 (i)(ii) 를 모두 뺄 수는 없다 [증명]
- $W_5=C_5+K_1$ (허브 $h$, 림 $r_0..r_4$): 평면, $K_4$-자유 (림에 삼각형 없음, 허브 + 림 삼각형 불가), χ=4.
- $\tau(W_5)=4$ [증명, N1-researcher3: 조인 하계 $\tau(C_5)+\tau(K_1)=4$, 상계 χ=4]. 따라서 $\operatorname{zig}(W_5)\ge\tau=4$, $\operatorname{zig}\le\chi=4$, **zig=4**.
- $\mathcal K(W_5)$: $\{h,r_{i+1}\}\times\{r_i,r_{i+2}\}$ (5 개). 인접한 두 원소 $\{h,r_i,r_{i+1},r_{i+2}\}$, $\{h,r_{i+1},r_{i+2},r_{i+3}\}$ 는 정점 3 개를 공유 → 선형 조건 (i) 위반.
- 또 림을 따라 돌면 서로 다른 공유 정점으로 이어지는 길이 5 의 Berge 사이클도 있어 (ii) 도 위반한다.
- 결론: (i), (ii) 를 함께 빼면 zig=4 인 평면 $K_4$-자유 χ=4 블록이 존재한다 (W_5). 정리 A 의 조건이 **필요 없는 것은 아님** 을 보이지만, (i) 와 (ii) 중 어느 쪽이 본질적인지는 이 예로 가르지 못한다 (§6 후속 1).
- 층: **층 1 (블록 조건의 경계).**

## 4. 복잡성 환원 C(G)=(k,R) 에서의 의미 (한 단락)
$k$ = 시트 (정점 블록) 수, $R$ = "각 블록이 평면이고 $\mathcal K$ 가 선형 Berge-비순환" 이라는 결합 규칙이라 하자. 그러면 블록당 zig 상수 3 과 zig 블록 가법 (R15-r2 [증명]) 으로 $\tau(G)\le\operatorname{zig}(G)\le3k$ [증명]. χ 쪽은 블록당 4 (4색정리) 로 $\chi\le4k$ 이고 R 이 χ 를 낮추지 않는다 (Moser 블록은 χ=4). 즉 이 클래스에서 **위상 지표 (τ, zig) 는 3k, 색수는 4k** 로 갈라지고, 간극 $\chi-\tau$ 는 시트당 최대 1 까지 허용된다. 마이너 쪽: Steiner 정리 2 ($\operatorname{zig}\ge t\Rightarrow$ 홀수 $K_{\lfloor t/2\rfloor+1}$) 는 하계에서 마이너를 주는 방향이라, 상계 $3k$ 는 마이너를 출력하지 않는다. 그러나 **τ 판 T7 ($\tau\ge7\Rightarrow K_7$) 은 $k=2$ 에서 이 클래스에 공허** 하다 ($\tau\le6$). 남는 것은 χ 판 T7 (χ 는 8 까지 가능) 이며, 이 클래스에서 χ≥7 그래프는 τ≤6 이므로 반드시 τ<χ 간극 그래프이다 — 즉 χ 판 T7 의 반례 후보는 이 클래스 안에서 "위상이 보지 못하는 색칠 장애" 를 가진 그래프로 한정된다. [증명: τ≤6<7≤χ]. [망상] 이 관찰은 T7 반례 탐색을 "τ 간극 그래프의 2-시트 접합" 으로 좁히는 필터가 될 수 있다.
- 층: **층 3 (지수 상계) 과 마이너 층의 접점.**

## 6. 후속연구 지점
1. **Berge 사이클이 있지만 선형인 $\mathcal K$ (우선순위 1).** 이유: 정리 A 의 (ii) 가 필요한지 아직 모른다. 선형이지만 $K_{2,2}$ 들이 사이클을 이루는 평면 그래프에서 zig 가 3 인지 4 인지 손 논증으로 판정. 4 이면 (ii) 도 정확한 경계, 3 이면 정리 A 를 선형 조건만으로 강화.
2. **χ 판 T7 의 필터 (우선순위 2).** 이유: §4 의 관찰로 $\mathcal S^{(3)}_2$ 의 χ≥7 그래프는 τ≤6 인 간극 그래프다. 시작: 블록 쌍 (Moser 형, χ=4) 과 교차 패턴에서 χ=7 이 가능한지 정의 수준에서 조건화 (블록 χ 합 = 8, 교차가 색 충돌을 강제해야 함; R20 Hall 조건).
3. **정리 A 의 위상 해석 (우선순위 3).** 이유: 순서 인증서는 모멘트 곡선 사상 $B_0\to S^2$ 을 준다. Berge-비순환 조건이 $B_0$ 의 어떤 호모토피 성질 (예: $K_{2,2}$ 부분 복합체들의 트리형 접착) 에 대응하는지 정의 수준에서 적기.
