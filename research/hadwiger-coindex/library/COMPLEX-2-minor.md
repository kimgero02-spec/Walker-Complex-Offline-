# COMPLEX-2-minor: K_t 마이너 입력 질문을 (k,R) 로 환원하기

- 작성자·역할: researcher2 (R 복잡성 환원, 독립). 한 번만 보고. 작은 예 없음.
- 정의: 복잡성 $(k,R)$ = "$k$ 개의 평면 시트 (정점 분할) 가 결합 규칙 $R$ 로 붙은 그래프 클래스 $\mathcal C(k,R)$". 규칙 $R$: 
  - $R_\infty$: 교차 제한 없음,
  - $R_d$ (k=2): 각 정점의 교차 이웃 $\le d$,
  - $R_J$: 모든 시트 쌍의 교차가 완전 (join),
  - $R_M$: 교차가 매칭 ($R_1$ 과 같음).
- 입력 집합: $I(k,R)=\{t:\ \forall G\in\mathcal C(k,R),\ \chi(G)\ge t\Rightarrow G\text{ 는 }K_t\text{ 마이너}\}$.
- 갭 집합: $\Gamma(k,R)=\{t\ge7:\ t\le\chi_{\max}(k,R)\}\setminus I(k,R)$ (χ 범위 안에서 입력이 아직 증명 안 된 t).
- 층 표시: [색 상계 층] [구조 층 (R 의 정의)] [입력 층 (K_t 강제)].

## 결과

**C1 [증명] 모든 $(k,R)$ 에서 $\{1,\dots,6\}\subseteq I(k,R)$.** Robertson–Seymour–Thomas 의 $t\le6$ (모든 그래프, [기억-미검증]) 이므로 클래스와 무관하다.
- 층: [입력 층] — 복잡성과 무관한 기저.

**C2 [증명] 조인 규칙은 모든 $k$ 에서 입력을 만족한다: $\{t\}\subseteq I(k,R_J)$ 모든 $t$.** $G=G_1+\cdots+G_k$, $\chi(G)=\sum\chi_i$. 각 평면 시트 $\chi_i\le4$ 이고 $h(G_i)\ge\chi_i$ (Dirac: $\chi\ge4\Rightarrow K_4$, $\chi=3\Rightarrow K_3$, $\chi\le2$ 는 간선이면 $K_2$). 완전 교차 보조정리 (R13 2.2): $h(G)\ge\sum h(G_i)\ge\sum\chi_i=\chi(G)\ge t$.
- 층: [색 상계 층] ($\chi$ 가 블록 색의 합으로 정확히 계산됨) + [입력 층].
- GEN-2 명제 6 의 $\operatorname{rk}=0$ 특수형, 클래스 $\mathcal K$ = 평면 조인.

**C3 [증명] 매칭 규칙 $R_M$ (k=2) 에서 $I(2,R_M)=\mathbb N$.** R35 에 의해 $\chi\le6$ 이므로 $t\ge7$ 은 공허하게 참, $t\le6$ 은 C1.
- 층: [색 상계 층] (χ ≤ 6 은 리스트 색칠 논법) → [입력 층] (공허).
- 판정: 매칭 복잡성 $(2,R_M)$ 은 입력 질문을 완전히 닫는다.

**C4 [증명] 교차 차수 상계 $R_d$ (k=2) 의 색 범위.** 4색칠 $B_1$ (4CT [기억-미검증]), 팔레트 크기 $d+5$, 교차 리스트 $\ge5$, 평면 5-선택 (Thomassen [기억-미검증]) ⇒ $\chi\le d+5$.
- 층: [색 상계 층].
- 따름: $t\ge d+6$ 이면 $\{G\in\mathcal C(2,R_d):\chi\ge t\}=\emptyset$, 따라서 $t\in I(2,R_d)$ (공허). 즉 $\{t\ge d+6\}\cup\{t\le6\}\subseteq I(2,R_d)$.

**C5 [증명] 갭 집합 (k=2).** $\Gamma(2,R_d)=\{7,\dots,d+5\}$ (C1, C4 와 결합하여 입력 미증명 구간이 정확히 이 구간이다. $d\le1$ 이면 공집합, $d=2$ 이면 $\{7\}$ = T7, $d=3$ 이면 $\{7,8\}$).
- 층: [구조 층 → 입력 층] 복잡성 $d$ 가 입력의 미증명 구간의 길이를 정한다.
- 판정: "$(2,R_d)$ 에서 χ≥t ⇒ K_t" 의 증명 필요 구간은 $d=2$ 에서 $t=7$ 한 점. 이것이 GEN-2 명제 7 의 순환을 피하는 가장 작은 입력 질문이다.

**C6 [증명] 무제한 규칙 $R_\infty$ (k=2).** $\chi\le8$ (두 블록 $4+4$). 갭 $\Gamma(2,R_\infty)=\{7,8\}$. $t=8$: χ=8 이면 두 블록 모두 χ=4 (χ 가 합). 이 부분의 입력 여부는 미결.
- 층: [구조 층] 교차 무제한이 갭을 최대로 만든다.

**C7 [증명] $k$ 시트 일반.** 색 상계는 $\chi\le4k$ (팔레트 분리, 가장 단순). 조인이면 χ 합 $\Rightarrow$ $I=\mathbb N$ (C2). 무제한이면 $\Gamma(k,R_\infty)\supseteq\{7,\dots,4k\}\setminus I$.
- 층: [색 상계 층] + [입력 층].

## 결론 (질문에 대한 답)
- **가능한 (k,R):** 입력 $\chi\ge t\Rightarrow K_t$ 는 $R_J$ (모든 k) 와 $R_M$, $R_{d\le1}$ (k=2) 에서 모든 $t$ 에 대해 증명된다 (C2, C3, C4). 증명 완료.
- **불가능/미결 (k,R):** $R_d$ ($d\ge2$), $R_\infty$, $k\ge2$ 의 자유 규칙에서 갭 $\Gamma$ 가 남는다. 반례는 나오지 않았다 (갭 원소가 실제 반례인지 미정). 즉 "χ≥t⇒K_t" 는 갭 구간에서 **반증도 증명도 되지 않았다.**
- 복잡성 환원의 핵심 수치: $(2,R_d)$ 의 갭은 $[7,d+5]$. $d=2$ 의 갭은 $\{7\}$ 로, T7 과 정확히 같다.

## GEN-2 입력 층과의 연결
- GEN-2 명제 6 ($\chi(G)\ge t+\operatorname{rk}F$, $G/F\in\mathcal K$ ⇒ $K_t$) 에서 $\mathcal K$ 는 이제 "갭 바깥의 클래스" 로 명시된다: $\mathcal K=\mathcal C(k,R)$ with $t\notin\Gamma(k,R)$.
- 즉 축약 $G/F$ 가 복잡성 $(k,R)$ 에서 갭 바깥에 있으면, 명제 6 이 입력을 준다. 축약이 $(k,R)$ 를 $(k',R')$ 로 바꾸는 규칙을 정하면 갭 원소를 다른 (k',R') 의 입력 집합으로 옮길 수 있다.
- 명제 7 의 순환 조건은 "축약 후 복잡성이 갭 바깥" 으로 번역된다.

## 후속연구 지점
1. **$(2,R_2)$ 의 $t=7$ 갭 한 점 (우선순위 1).** 이유: 갭이 최소인 입력 질문이다. 시작: $\chi(G)=7$ 인 $G\in\mathcal C(2,R_2)$ 의 존재 여부 (R36, GROW-2, PROGRESS-2 의 장애 조건). 판정: 존재하지 않으면 $I(2,R_2)=\mathbb N$ 이 증명된다 (갭 소멸).
2. **축약 규칙 $R\mapsto R'$.** 이유: GEN-2 명제 6 과 결합하여 갭을 옮긴다. 시작: 블록 내부 축약 ($R_d$ 보존) 과 교차 축약 ($R_d\mapsto R_{d'}$) 의 차수 변화를 정식화.
3. **$(k,R)$ 의 3 차원화.** 이유: 시트 개수 $k$ 가 χ 상계에 $4k$ 로 들어가므로 갭 길이를 $k$ 로 묶을 수 있는지 확인. 시작: $k$ 시트, 시트당 교차 차수 $\le d$ 에서 $\chi\le f(k,d)$ 의 형태를 세운다.
