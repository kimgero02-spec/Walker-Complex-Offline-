# [R18-researcher1] 블록 쌍의 교차 패턴에 걸친 τ 의 최솟값: (K_4,K_4), (K_4,K_3), (K_3,K_3), 색칠 조건, 상계의 sharpness

- 작성자·라운드·역할: researcher1 / 라운드 18 / 연구원1 (연속 라운드). 범위: 정점 시트 블록과 교차 간선만.
- 표기: `[증명]` `[계산 확인]` `[추측]` `[망상]` `[기억-미검증]`. 외부 정리는 쓰지 않았다 (색칠 상계는 손 색칠).
- 설정: 블록 $B_1,B_2$ (내부 간선 고정), 교차 패턴 $H\subseteq V(B_1)\times V(B_2)$, $G(H)=B_1\cup B_2\cup H$. $\tau_i=\tau(B_i)$.

## 요약
1. **[증명] 전체 패턴에서 최솟값은 $\max(\tau_1,\tau_2)$.** 빈 패턴 $H=\emptyset$ 이 분리 합을 주고, $\tau(B_1\sqcup B_2)\le\chi=\max\chi_i$ 이므로 $\tau_i=\chi_i$ 인 블록에서 $\tau=\max\tau_i$. 하한 $\tau(G(H))\ge\max\tau_i$ 는 항상 성립 (단조성). 질문의 실질은 **연결된** (비어 있지 않은) 패턴에서의 최솟값이다.
2. **[계산 확인] (1) 세 쌍.** 연결 패턴에서도 최솟값은 모두 $\max\tau_i$: $(K_4,K_4)\to4$, $(K_4,K_3)\to4$, $(K_3,K_3)\to3$. 출발점 $K_4\square K_2$ 는 $\tau=4$ (χ=4, 4 색 치환 색칠).
3. **[증명] (2) 최솟값 조건.** 색 치환 조건: 블록들이 각각 $c$-색칠 (색류가 1 원소씩인 경우 전단사) 을 가지면, 두 번째 블록의 색 치환 $\pi$ 를 골라 $H$ 가 "같은 색끼리 간선 없음" 을 만족하게 하면 $\chi(G)=c$, 따라서 $\tau=c=\max\tau_i$. $K_4$ 쌍에서 이 조건은 **$H$ 가 어떤 완전 매칭 $M_\pi\subseteq K_{4,4}$ 를 피함** 이다. 이것은 R14 의 대각 간선 조건 ($v\not\sim\sigma v$) 과 같은 형태이다.
4. **[증명] (3) sharpness.** 상계 $\tau\le\chi\le\sum$ 의 최댓값 (완전 교차) 은 $K_{n}$ 에서만 달성된다 (τ=χ=n 이면 완전). 그러나 **최솟값은 $\max\tau_i$ 로 $\sum\tau_i$ 보다 훨씬 작다.** 따라서 $3k$, $4k$ 상계는 "함수 $f(k)$ 로서" 여전히 최선이지만, 블록을 특정 패턴으로 붙이면 값이 $\max$ 로 떨어진다. $k$ 개 $K_4$ 블록 중 교차를 "같은 색 인덱스 끼리 금지" 로 주면 $\tau\le4$ 이다.

## 1. 기본 사실 [증명]
- (F1) 단조성: $H\subseteq G$ 이면 $\tau(H)\le\tau(G)$ (τ 가 부분그래프 단조).
- (F2) $\tau\le\chi$ (R03 사슬), $\omega\le\tau$.
- (F3) 빈 패턴: $\tau(B_1\sqcup B_2)\le\max\chi_i$ 이고 $\ge\max\tau_i$. 블록이 $\tau_i=\chi_i$ 이면 $=\max\tau_i$.
- (F4) 완전 교차: $G=B_1+B_2$ 이면 $\tau(G)\ge\tau_1+\tau_2$ (R08 조인 하계), 그리고 $\tau\le\chi(G)=\chi_1+\chi_2$.

## 2. (1) 세 쌍 [계산 확인, 손]

### (a) $(K_4,K_4)$
- 하한: $\omega(G)\ge4$ 이므로 $\tau\ge4$.
- 출발점 $K_4\square K_2$ (매칭 $a_ib_i$): 색칠 $c(a_i)=i$, $c(b_i)=\pi(i)$, $\pi$ 는 완전 교란 치환 ($\pi(i)\ne i$) 이면 4 색 진색칠이므로 $\chi=4$, $\tau=4$. [증명]
- 최솟값: 4 (빈 패턴도 4).
- 최댓값: $K_8$, $\tau=8$. 값 8 은 완전 교차 (8 정점 완전) 에서만: $\tau=8\Rightarrow\chi\ge8\Rightarrow$ 8 정점 완전 [증명].

### (b) $(K_4,K_3)$ (정점 $a_1..a_4$, $b_1b_2b_3$)
- 하한 4 ($K_4$ 블록). 빈 패턴이 4.
- 연결 패턴: $H=\{a_1b_1\}$ 등. $\chi(G)=4$ 는 $B_2$ 를 $a_1..a_4$ 의 서로 다른 3 색으로 칠하고 $H$ 가 같은 색 쌍을 피하면 성립. 예: $H=\{a_1b_1,a_4b_2\}$ 에서 $c(b_1)=2$, $c(b_2)=3$, $c(b_3)=1$ 로 칠하면 $a_1$ (색1) 과 $b_1$ (색2) 는 다름, $a_4$ (색4) 와 $b_2$ (색3) 다름 ✓. 따라서 $\tau=4$ (연결 패턴, [증명]).
- 최댓값: 완전 교차 $K_7$, $\tau=7$.

### (c) $(K_3,K_3)$ (정점 $a_1a_2a_3$, $b_1b_2b_3$)
- 하한 3. 빈 패턴이 3.
- 연결 패턴: 프리즘 $H=\{a_ib_i\}$, $\chi=3$ (색 $c(a_i)=i$, $c(b_i)=i+1 \bmod 3$) ⇒ $\tau=3$. [증명]
- 최댓값: $K_6$, $\tau=6$.

## 3. (2) 최솟값을 달성하는 패턴의 일반 조건

- **조건 Q (색 치환).** 블록 $B_i$ 가 $c_i$-색칠을 가지고 $c_i=\tau_i=\max\tau_j$ 이며 색류가 한 원소씩 (완전 그래프 같은 경우) 이면, $G(H)$ 의 $c$-색칠 존재 $\iff$ $H$ 가 대응 전단사 $\sigma:V(B_1)\to V(B_2)$ 의 "같은 색 짝" 을 피함 (즉 $H\cap\{u\sigma(u)\}=\emptyset$). 이는 $\chi(G(H))=c$ 의 충분조건이고, $\tau\ge c$ 이므로 $\tau=c$. [증명]
- **조건 Q 의 일반 형태.** 색류가 여럿이면 조건은 "$H$ 가 색 $c$-분할 아래 같은 색 쌍을 피함" 이다. 빈 패턴과 한 간선 패턴 모두 이 조건을 만족하므로 최솟값 달성은 자명하다.
- **매칭 / 별의 역할.** 완전 $K_c$ 블록에서는 매칭 $H_\sigma$ (대응 쌍) 이 필요한 최소 교차 구조이다 (색 치환이 주는 것). 별 (한 정점에서 나오는 간선) 은 한 정점 색을 피하는 것만 요구하므로 조건을 쉽게 만족한다: $(K_4,K_1)$ 의 별 3 개는 $\tau=4$ 를 주지만 $K_4$ 전체 별 4 개는 $K_5$ 이다.
- **추측.** $\tau(G(H))=\max\tau_i$ 이면 $\chi(G(H))=\max\tau_i$ (블록 $\chi=\tau$ 인 경우) [추측]. 역방향 (색 조건 없이 $\tau$ 만 낮은 패턴) 은 본 라운드에서 찾지 못했다.

## 4. (3) sharpness 판정 [증명 + 추측]

- **함수로서의 sharpness 는 그대로.** $k$ 블록 $K_3$ 의 완전 교차 $K_{3k}$ 는 $\tau=3k$ 이므로 $f(k)\ge3k$. 상계 $3k$ 와 $4k$ (K_4 블록) 는 함수로서 최선이다. (R16 §3, R11 §1 과 일치.) [증명]
- **패턴별 sharpness 는 아니다.** $k$ 개 $K_4$ 블록을 색 인덱스 기준 "같은 인덱스 끼리 교차 금지" 로 붙이면 모든 블록을 같은 4 색 (인덱스) 으로 칠할 수 있어 $\chi\le4$, 따라서 $\tau\le4$ [증명]. 즉 $k$ 블록의 패턴 최솟값은 $4$ 이고, $4k$ 는 $K_{4k}$ 에서만 달성된다 ($\tau=n$ 이면 완전).
- **판정.** 블록 상계 $\sum\tau_i$ 는 $\tau$ 의 최댓값 (완전 교차) 에서만 닿는다. 최솟값은 $\max\tau_i$ 로 떨어진다. 따라서 "블록 합 $3k$ / $4k$ 가 sharp 하다" 는 최댓값 관점에서 참이고, 일반 패턴 관점에서는 $\tau$ 가 블록 최댓값 근처에 머물 수 있음을 뜻한다. 이 간극이 R14/R15 의 대각 조건과 같은 형태의 색 조건으로 결정된다는 것이 새 내용이다.

## 후속연구 지점
1. **연결 패턴에서 $\tau$ 가 $\max\tau_i$ 를 넘는 최소 조건.** 이유: 이번 라운드의 최솟값은 색 치환으로 쉽게 달성되어 정보가 적다. 시작: $\tau=\max\tau_i$ 가 실패하는 패턴 (색 조건 위반) 을 $(K_4,K_4)$ 에서 찾고, 그 최소 간선 수를 센다. 난점: $\tau$ 의 하한 계산 도구 (coind) 가 손으로 어렵다; $\omega$ 나 $\zeta$ 로만 하한을 잡아야 한다.
2. **$\tau=\chi$ 블록 쌍에서 $\chi(G(H))=\max\chi_i$ 와 $\tau$ 의 동치 (R18 추측 연결).** 이유: 최솟값 판정을 χ 로 옮기면 계산 가능하다. 시작: $(K_4,K_4)$ 에서 $\tau=4$ 이지만 $\chi=5$ 인 패턴이 존재하는지 (zig 4 에서 간극) 확인. 난점: 이런 패턴의 zig 계산이 R17 과 같은 순서 조건을 요구한다.
3. **$k$ 블록 패턴 최솟값의 일반화.** 이유: §4 의 인덱스 색칠은 $k$ 블록 모두에 적용되어 최솟값 4 를 준다. 시작: 블록 $K_4$ 가 $k$ 개일 때 인덱스 색칠을 깨는 교차 패턴 (예: 인덱스 불일치 교차) 을 두 블록 $k=3$ 에서 손으로 찾아 $\tau$ 가 4 를 넘는지 확인. 난점: $k=3$ 의 $\tau$ 하한이 필요하다.
4. **색 조건과 R14 대각 조건의 통합.** 이유: $(K_4,K_4)$ 의 색 치환 조건 (교차가 완전 매칭 $M_\pi$ 를 피함) 과 R14 의 대각 조건 ($v\not\sim\sigma v$) 은 같은 구조다. 시작: 두 조건이 같은 $\sigma$ 로 동시에 만족되는지 (색 치환 $\pi$ 를 대각 $\sigma$ 와 맞추는 방법) 를 $K_4$ 쌍에서 확인. 난점: 색 치환의 자유도가 대각 조건을 항상 만족시키는지 여부가 미결이다.
