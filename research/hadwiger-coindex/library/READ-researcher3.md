## 2. 남의 보고서에서 틀렸거나 근거가 약하다고 본 주장 (3개 이하)
1. **R06-researcher2 §1 (반례꾼)**: "$\tau\ge\operatorname{conn}(N(G))+3$" 을 τ 판 하한으로 사용. 이것은 Lovász 의 χ 하한 (χ ≥ conn+3, [기억-미검증]) 을 τ 로 옮긴 것인데, 보고서는 τ 와 χ 관계나 $N(G)$ 와 $B_0$ 의 연결도 전이를 증명하지 않는다. 그래도 τ ≤ χ 와 결합하면 방향이 맞지 않는다 (τ 하한은 χ 하한으로부터 나오지 않는다). **근거 부족으로 판정.**
2. **R06-researcher3 §1 (호지 연구원)**: "$X(G)\simeq\Sigma N(G)$, 따라서 $\tau=\operatorname{coind}N+2$". 현탁 관계는 [기억-미검증] 이고, N1-researcher2 §6 은 포셋 수준에서 $B_0\simeq\Sigma B$ 가 성립하지 않는다고 적었다. 두 보고서가 충돌하며, R06-r3 의 "8 그래프에서 호몰로지 일치" 는 현탁 동형을 증명하지 않는다. **미검증.**
3. **R08-researcher1 §1, R09-researcher2 §1 (정점 블록 부분가법의 ι 판)**: "$\iota(G)\le\sum\iota(G[V_i])$ [증명]". 증명은 덮개 논법과 조인 사상에 의존한다. 같은 구조의 coind 판 주장은 R11-researcher2 §4 의 $S^2=A\cup B$ 반례로 깨졌다 (덮개 논법은 coind 에 거짓). ind 판은 다른 방향 (사상 $S^n\to X$) 이라 자동으로 안전하지 않다. **독립 검증 필요.** 연구원 본인들도 R09 에서 "J 는 열림" 으로 정정했다는 점과 일관되지 않다.

(참고: 내가 한때 틀렸던 것은 R08-P1 과 R13 의 "K_5 는 평면 2겹 분기 피복이 아니다" 였다. 이것은 R13-r3 에서 스스로 정정했다.)

## 4. 본질로 돌아가는 질문과 판정 기준
**질문 Q\*:** 두 시트의 평면 블록으로 된 그래프 $G$ (2-시트 정점 분할, 교차 간선 무제한) 에서 $\tau(G)\ge 7$ 이면 $K_7$ 마이너가 있는가? (τ ≤ 4k = 8 이므로 $\tau\in\{7,8\}$ 만 비자명. 이것은 Hadwiger 의 τ 판 S1 을 시트 클래스에서 $t=7$ 로 본 것이다.)

**판정 기준.**
- **반례**: $\tau\ge7$ 이고 $K_7$ 마이너가 없는 2-시트 평면 그래프가 하나 나오면 Q\* 는 거짓이다. τ 하한은 $\omega$, 부분그래프 $\tau$, 또는 $h$ (부분그래프의 $K_t$ 에서 온 것) 로 확인해야 하고, 마이너 부재는 축약 탐색으로 확인한다.
- **증명**: 시트 구조 (블록 평면성) 에서 $\tau\ge7$ 을 $K_7$ 마이너로 바꾸는 논법이 나오면 참. 현재 알려진 것은 조인 경우뿐이다 (R25).
- **판정 불능**: 두 방향 모두 나오지 않으면 열린 문제로 남긴다.

**위상과 마이너를 잇는 다리 질문을 포함하는가?** 포함하되 주된 질문으로 두지는 않는다. 이유: (a) 알려진 다리 (Steiner 정리 2) 는 $\mathrm{zig}\ge t$ 에서 홀수 $K_{t/2}$ 만 주므로 Q\* 의 $K_7$ 에 미치지 못한다. (b) 지수 하계 (SW, coind) 는 부분그래프 $K_t$ 만 보고 마이너 인접을 주지 않는다 (R18, R20 으로 확인). 따라서 다리 질문 ("위상 하계 ⇒ 마이너") 은 Q\* 를 푸는 **도구** 로만 가치가 있고, 판정 기준은 위의 반례/증명 기준으로 충분하다. 다리 질문 자체는 별도로 "교차 패턴 인접을 보장하는 위상 객체가 있는가" 로 적는 것이 맞다 (ADVICE-3-to-1 §2 참조).
