# [R22-researcher3] 반례 필요 조건 ($H^3(Q;\mathbb F_2)=0$, ω=3, τ=4) 의 구조적 후보 탐색: 1 정점 확장 결과

- 작성자·라운드·역할: researcher3 / R22 / 망상꾼 (분야: 대수적 위상수학, 몫 공간의 F_2-호몰로지, Gysin 열)
- 지시: 문주님 (R22). Moser 방추 (7정점, χ=4, ω=3) 와 $C_7^2$ 에 정점을 하나 더하거나 이웃을 바꾸는 확장으로, $H^3(Q)=0$ 을 유지하며 $\tau=4$ 인 후보를 찾는다.
- 표기: $X=B_0G$, $Q=X/\mathbb Z_2$, $h\le\operatorname{coind}=\tau-1$, $\operatorname{zig}\ge\tau$ (팀 증명 사슬).
- 계산: `rooms/researcher3/r22_ext.py` (1 정점 확장 전수: 이웃 집합 $2^7$ 각각, ω≤3 과 χ≥4 필터, $H^3(Q;\mathbb F_2)$ 계산), `r22_zig2.py` (필터 통과 후보의 정확한 zig 를 r06 brute force 로 계산). 기존 파일은 수정하지 않았다.

## 요약
1. **후보 탐색 결과: 찾지 못했다.** Moser 방추 (85개) 와 $C_7^2$ (71개) 의 1 정점 확장 중 ω≤3, χ≥4 인 것은 총 156 개이며 (정점 8, 중복 포함), 그 중 $H^3(Q;\mathbb F_2)=0$ 인 것은 138 개다. 이 138 개의 정확한 zig 를 계산하니 **모두 zig = 3** 이다 [계산 확인]. zig ≤3 이면 $\tau\le\operatorname{zig}=3$ (팀 사슬) 이므로, 이 138 개는 모두 τ=3 이고 반례가 아니다.
2. **$H^3(Q)=0$ 이 τ=3 을 함의하는지: 미결.** 증명도 반증도 못 했다. 함의하는 것은 $x^3=0$ (따라서 $h\le2$) 뿐이다 (Gysin). τ=4 는 coind=3 을 요구하므로, $h\le2$ 와 양립하려면 SW 류보다 세밀한 장애가 필요하다. 이 장애가 $\mathbb F_2$-호몰로지에서 보이는지는 확인하지 못했다.
3. **탐색의 한계.** (a) 1 정점 확장 두 기저에서만 탐색했다 (두 정점 확장, 다른 기저는 미탐색). (b) zig 는 정확 계산이지만 zig=3 이 τ=3 을 증명하는 것은 팀 사슬 ($\tau\le\operatorname{zig}$) 에 의존한다. (c) $H^3(Q)=0$ 은 필요 조건 탐색의 필터일 뿐이다.
4. **관찰.** ω=3, χ=4, τ=4 로 알려진 두 그래프 $W_5$, $C_5+\overline{K_2}$ 는 모두 $H^3(Q)=1$ (R20, R21). 즉 현재 자료에서 $\tau=4$ 와 $H^3(Q)\ne0$ 이 함께 나타난다. 이 관찰은 P2 의 근거다.

## 3. 해석

- **반례 후보는 "작은 Moser 확장" 에서 나오지 않는다.** 가장 가까운 후보들도 zig=3 이므로 τ=3 이고 $h\le2$ 와 일치한다. P3 반례를 원하면 zig 가 3 을 넘는 (즉 τ 가 4 일 수 있는) 구조가 필요하다.
- **$H^3(Q)=0$ 의 의미.** $H^3(Q;\mathbb F_2)=0$ 은 몫 복합체의 3차원 호몰로지가 없다는 뜻이다. 그러면 $x^3=0$ 이지만, 이것이 τ 의 상계 3 을 강제한다는 근거는 없다. 본 탐색은 "작은 확장에서는 강제되는 것처럼 보인다" 는 수준의 관찰이다.
- 정직한 결론: $H^3(Q)=0$ 가 $\tau=3$ 을 함의하는지는 열린 문제 (P2 의 역).

## 후속연구 지점
1. **zig≥4 를 주는 구조 탐색 (우선순위 1, 이유: P1 의 138 개는 zig=3 이므로 반례는 zig≥4 인 $H^3=0$ 그래프여야 한다).** 시작: $\omega=3$, $\chi=4$ 인 8 정점 그래프 중 zig=4 인 것을 찾는다 (zig 는 정확 계산 가능: 8! 순열 brute force, 약 0.1초/그래프). 그 중 $H^3(Q)=0$ 을 찾는다. 난점: zig=4 인 ω=3 8 정점 그래프가 존재하는지 자체가 모름 (팀 ≤7 전수 자료에서 τ=χ 인 ω=3 그래프 중 zig 분포 확인 필요).
2. **2 정점 확장 (Moser, $C_7^2$) 의 zig 계산 (우선순위 2).** 시작: 정점 9 의 zig 는 9! 순열 brute force 가 느리므로 SAT 순서 (팀 `zig_le` 재사용) 로 $\operatorname{zig}\le3$ 여부만 판정 (zig≤3 이면 τ≤3 으로 종결). 난점: SAT 인코딩 비용.
3. **$H^3(Q)=0$ 과 τ 의 관계 (P2 역) 의 증명 시도 (우선순위 3).** 시작: coind 3 의 장애가 Gysin 열의 $H^3(X)\to H^3(Q)$ 와 어떻게 연결되는지 (τ=4 면 $\operatorname{coind}X\ge3$ 이므로 $X$ 의 3차 호몰로지 또는 연결성 장애가 있어야 함). 난점: 연결성과 Z_2-coind 의 관계는 Dold 류 (충분 조건) 뿐이다.
4. **Gysin 을 $H^*(X)$ 쪽에서 읽는 판정 규칙 (우선순위 4).** 이유: 몫 호몰로지 $H^3(Q)$ 가 0 이면 $h\le2$ 인데, 이것이 $\tilde H^*(X)$ 의 차원들로 결정되는지 (Gysin 열의 완전열) 를 확인. 시작: $\tilde H_2(X)$ 가 Moser 에서 $\mathbb F_2^5$ 임을 이용해 $H^2(Q)$ 의 차원을 예측 (이미 $H^2(Q)=3$ 과 맞음).
