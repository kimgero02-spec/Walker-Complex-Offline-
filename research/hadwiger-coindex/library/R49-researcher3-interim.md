## 아이디어 (모두 [망상] 단계, 검증 계획 포함)
1. **관 종수 $g_{\rm tube}$**: 시트마다 구면 하나, 교차 간선은 B_1 의 면과 B_2 의 면을 잇는 관(원통)으로만 지나간다. 관 $t$ 개 → 곡면 종수 $t-1$. $g(G)\le g_{\rm tube}$. 손 증명 + 회전계 면 추적 코드(`rooms/researcher3/r49_tube.py`)로 작은 예 확인 예정.
2. **오일러 + KY ⇒ 종수 하한**: $\mathcal C(2,R_3)$ 의 7-색수 원소는 $g(G)\ge (n+11)/18$, R45 의 $n\ge48$ 과 합치면 $g\ge4$. 즉 관 종수 ≤3 인 결합은 갭 {7} 밖.
3. **원환면 (g≤1) 은 Brooks 로 닫힘**: 7-임계 원환면 그래프는 6-정칙 삼각분할 → Brooks → $K_7$. $K_7\notin\mathcal C(2,R_3)$ 이므로 χ≤6 (d 와 무관하게 t=7 Hadwiger 성립). 리스트판 (ERT 차수 선택성) 으로 6-선택성까지 — 예측 C 의 종수 ≤1 판.
4. **종수 2 에서 χ=8 ⇒ $K_8$** (KY + Gallai 의 보완 비연결 정리) → d=4 칸의 t=8 이 종수 ≤2 에서 닫힘.
5. **면-직사각형 덮개수** $\mathrm{cov}_F(H)$: 한 관은 $\partial f\times\partial f'$ 안의 사다리만 실을 수 있음 → $g_{\rm tube}\ge \mathrm{cov}_F(H)-1$. R48-r1 의 결합 산포도 σ 의 전역판.
6. **d 와 g 의 독립성**: 두 삼각분할 + 완전 매칭 (d=1) 은 $g\ge n/12-1$; 바퀴형 (관 1 개) 은 d 무한, $g_{\rm tube}=0$.
7. **관 매장의 면폭 ≤ 3** (삼각분할 시트): Thomassen 류 "큰 면폭 ⇒ 5-색칠" 은 관 매장에 쓸 수 없음.
