## 요약
1. **번역 (§1).** "$\chi$ 가 크면 $K_t$ 마이너" 는 위상적으로 "$\tau(G)\ge t$ 이면 $B_0(G)$ 에서 $\mathbb Z_2$-사상 $B_0(G)\to S^{t-2}$ 가 없다" 와 같다 (Borsuk–Ulam 류 장애). 그러나 $\tau\le\chi$ 이므로 $\chi$ 가 큰 것은 $\tau$ 가 큰 것을 보장하지 않는다. $K_t$ 마이너는 위상 쪽에서 아직 보이지 않는다. 연결하는 고리는 S1 (Hadwiger 류) 자체다.
2. **상계와 $K_t$ 마이너 (§2).** 시트 상계 $\tau\le 4k$ (평면 블록 $k$ 개, 4색정리) 와 $\tau\le 3k+s$ (블록 중 $K_4$ 마이너 있는 것 $s$ 개) 는 $K_t$ 마이너에 대한 **반대 방향** 정보만 준다: $\tau>4k$ 이면 평면 블록 $k$ 개로 쪼갤 수 없다. $K_t$ 마이너의 존재를 함의하지는 않는다. 예측 6개를 $K_5,K_6,K_{3,3},C_5[K_2]$ 에서 시험했다 (§2.2).
3. **조인 상계 J (§3).** J: $\tau(G_1+G_2)\le\tau_1+\tau_2$. 위상 해석: 조인의 $\mathbb Z_2$-연결성 (coind 의 조인 가법). 조인에서는 등호가 관찰된다 (K_6, K_5, K_{3,3}). 그러나 **정정**: R08·R09 에서 내가 J (와 정점 블록 부분가법) 를 덮개 보조정리로 증명했다고 쓴 것은 **철회한다.** R11 의 반례를 내 보조정리에 넣으면 $S^2$ 에 대한 기수 $\mathbb Z_2$-사상 $S^2\to S^1$ 이 나오는데, 이는 Borsuk–Ulam 에 어긋난다. 어느 단계가 틀렸는지 찾지 못했다. 따라서 J 와 정점 블록 법칙은 **열린 문제 [추측]** 로 되돌린다.

## 1. 번역 사전

| 조합 쪽 (Hadwiger·시트) | 위상 쪽 | 비고 |
|---|---|---|
| $\chi(G)\ge t$ | 색칠 장애 (정점 쪽 $\mathbb Z_2$-사상 $\mathrm{Hom}$ 없음) | $\chi$ 는 $\tau$ 보다 크다 (τ≤χ) |
| $\tau(G)=\operatorname{coind}B_0(G)+1\ge t$ | 등변 사상 $B_0(G)\to S^{t-2}$ 가 없다 (Borsuk–Ulam 류 장애) | $\tau\ge t$ 은 $B_0$ 의 $\mathbb Z_2$-연결성 쪽 정보 |
| $K_t$ 마이너 | 위상에서 직접 대응 없음 | 연결 고리는 S1 (미해결). Steiner 식 (위상 하한 → 홀수 마이너) 은 $\tau$ 에 이식 미확인 |
| 평면 블록 $G[V_i]$ | 4색정리 → $\tau(G[V_i])\le 4$ (${\mathbb Z_2}$-사상 $X(G[V_i])\to S^3$ 가 존재) | 블록 $K_4$ 로 등호 |
| 시트 사이 간선 (교차 패턴) | 교차 면 (두 블록을 잇는 완전 이분 면) | 호몰로지를 바꾸지만 덮개 상계에는 (정정 후 미확인) |
| 조인 $G_1+G_2$ | $B_0(G_1+G_2)$ 가 $B_0(G_1)*B_0(G_2)$ 류의 조인 | 조인에서는 coind 가 가법 $\tau_1+\tau_2$ |
| $K_{3,3}$ (이분) | $\tau=2$, $X$ 의 $\tilde H_1=\mathbb Z$ | 이분 그래프의 $\tau$ 는 $\chi$ |

Borsuk–Ulam 류 장애로 보는 "$\chi$ 가 크면 $K_t$": 
$\tau(G)\ge t$ ⇔ 임의의 $\mathbb Z_2$-사상 $X(G)\to S^{t-2}$ 가 없다 [증명, 정의]. Hadwiger 류 질문은 "이 장애가 $K_t$ 마이너 장애로 번역되는가" 이다. 현재 번역 사전에서 그 번역은 없다. 필요한 것은 $K_t$ 마이너 (또는 그 홀수판) 가 $\mathbb Z_2$-사상 $X(G)\to X(K_t)=S^{t-1}$ 의 장애를 준다는 사실이다. 이 방향은 $\tau(G)\ge\tau(K_t)$ 가 $K_t\subseteq G$ 에서 나온다는 단조성으로만 얻어지고, 마이너 단조성 ($\tau(G/e)\ge\tau(G-e)$ 만 증명됨, STATUS) 은 부족하다.

## 2. 시트 상계와 $K_t$ 마이너

### 2.1 상계 (기존 증명 상태)
- $\tau\le 4k$: 평면 블록 $k$ 개 (4색정리 [기억-미검증] 인용, 증명 근거는 χ 상계와 같다) [증명 조건부 J/덮개 — §3 에서 철회 대상 아님, χ 상계는 별도]. 주의: **정점 블록 법칙 $\tau\le\sum\tau_i$ 를 쓰는 $4k$ 는 정정 후 미확인**. 대신 χ 상계 $\chi(G)\le\sum\chi(G[V_i])\le 4k$ [증명, 색칠의 곱] 가 확실하다. $\tau\le\chi$ 로 $\tau\le 4k$ 가 나온다 [증명].
- $\tau\le 3k+s$: $K_4$-마이너-자유 블록은 $\chi\le 3$ (Dirac 류 [기억-미검증]) 이므로 같은 χ-논법으로 $\chi(G)\le\sum_i\chi_i\le 3(k-s)+4s = 3k+s$ [증명, 조건: 블록 색칠의 곱]. 따라서 $\tau\le\chi\le 3k+s$ [증명]. 이것은 덮개 보조정리를 쓰지 않으므로 정정의 영향을 받지 않는다.

## 3. J (τ 조인 상계) 의 위상 해석과 정정

### 3.1 J 의 위상 뜻
$J$: $\tau(G_1+G_2)\le\tau(G_1)+\tau(G_2)$. 위상적으로는 "조인의 $\mathbb Z_2$-연결성은 두 조각의 연결성의 합 (+1 보정)" 이다. 조인 구조가 $X(G_1+G_2)\simeq X(G_1)*X(G_2)$ 이면 $\operatorname{coind}(X*Y)=\operatorname{coind}X+\operatorname{coind}Y+1$ 이고 $\tau=\operatorname{coind}+1$ 로 바꾸면 $\tau(G_1+G_2)=\tau_1+\tau_2$ (등호) 이다. 즉 J 는 조인에서 **등호** 를 준다고 예상된다.

### 3.2 등호 시험 [계산 확인, 조인 구조의 호몰로지 점검]
- $K_6=K_3+K_3$: $\tau=6=3+3$. 최고 차원 $5=2+2+1$ (R09 표) ✓.
- $K_5=K_4+K_1$: $\tau=5=4+1$. 최고 차원 $4=3+0+1$ ✓.
- $K_{3,3}=\overline{K_3}+\overline{K_3}$: $\tau=2=1+1$. 최고 차원 $1=0+0+1$ ✓.
- 조인이 아닌 $C_5[K_2]$ 는 조인 공식보다 낮다 (최고 차원 3 < 5). 교차가 불완전하면 J 는 여유가 있다 (R09).

### 3.3 정정 (중요)
- R08-P1 과 R09-P1 (정점 블록 부분가법) 의 증명은 **덮개 보조정리 (열린 불변 덮개 $U_1\cup U_2$, 지수 $\mathrm{coind}U_i$ 에 대한 조인 상계)** 에 의존했다.
- R11 의 반례: $S^2=A\cup B$, $A=U\sqcup(-U)$, $B=V\sqcup(-V)$ (경도 띠), $\operatorname{coind}A=\operatorname{coind}B=0$, $\operatorname{coind}S^2=2$. 이 덮개에 같은 논법을 적용하면 불변 분할 $\varphi_A,\varphi_B$ 로 $S^2\to S^0*S^0=S^1$ 기수 $\mathbb Z_2$-사상이 나온다. 이는 Borsuk–Ulam 에 어긋난다.
- 따라서 **보조정리 또는 그 적용 중 하나가 틀렸다.** 내가 세운 단계 (레트랙션 $U_i\to X(G[V_i])$, 불변 분할, 조인 사상의 연속성) 중 어느 것이 틀렸는지 특정하지 못했다. 이 상태에서 J 와 정점 블록 법칙은 증명으로 쓸 수 없다.
- 정정 결과: R08-P1 (정점 부분가법) 과 R09 의 "J 증명됨" 판정은 철회한다. J 는 열린 문제 [추측] 이다. R09-연구원2 가 "ι 판 (ind) 으로만 증명된다" 고 쓴 판정은 일관된다. 그러나 ι 판의 증명도 같은 종류의 덮개 논법을 쓰므로, ι 판 증명도 다시 점검해야 한다 (반례에 같은 구조가 나타난다).
- 확실하게 남는 것: §2.1 의 χ 상계 ($\tau\le\chi\le 4k$, $\le 3k+s$) 는 덮개 보조정리를 쓰지 않는다.

## 후속연구 지점
1. **덮개 보조정리 반례의 해부 (우선순위 1, 이유: R08-P1, R09-P1, R09-J, R11 의 ι 블록 합이 모두 같은 보조정리에 의존한다).** 시작: $S^2=A\cup B$ (R11 반례) 에서 불변 분할 $\varphi_A,\varphi_B$ 와 사상 $F=(\varphi_A f_A,\varphi_B f_B)$ 를 직접 구성하고, $F$ 가 연속·기수·홀수인지 한 점씩 확인. 어느 점에서 깨지는지가 답이다. 난점: 불변 분할이 실제로 $\mathbb Z_2$-불변인지 (평균화 논법) 를 점검해야 한다.
2. **조인 공식의 올바른 형태 찾기 (우선순위 2).** 시작: $B_0(G_1+G_2)$ 와 $B_0(G_1)*B_0(G_2)$ 의 호모토피 동치를 직접 구성 (교차 면 전체가 조인의 면과 일치하는지). $K_6=K_3+K_3$ 에서 확인한 등호가 일반적인지. 난점: 조인 구성은 $\mathbb Z_2$-동변이어야 한다.
3. **$K_t$ 마이너와 $B_0$ 장애의 연결 (우선순위 3).** 시작: $K_t$ 마이너 $H\subseteq G$ 에서 $\mathbb Z_2$-사상 $X(G)\to X(H)$ 를 세우는 방법 (축약 $G/e$ 의 $B_0$ 단조성, STATUS 의 $\tau(G/e)\ge\tau(G-e)$ 를 확장). 난점: 마이너 단조성이 $\tau$ 에 대해 증명되지 않았다.
4. **$\tau\le 3k+s$ 의 시험 확장 (우선순위 4).** 시작: $K_4$-마이너-자유 블록 조합 (예: $C_5[K_2]$ 의 블록 분할) 에서 $\tau$ 를 계산해 상계 $3k+s$ 의 여유를 측정. 난점: $n\ge 9$ 에서 $\tau$ 의 정확한 계산 도구가 없다.
