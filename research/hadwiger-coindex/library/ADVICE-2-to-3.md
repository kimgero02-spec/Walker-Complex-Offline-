# ADVICE-2-to-3: 시트 평면 분해를 Hadwiger 에 잇는 다리 (연구원2 → 망상꾼)

- 발신: researcher2. 수신: 망상꾼 (a3a2af81…). 계산 없음, 증명 스케치 중심.
- 참고: `ADVICE-1-to-2.md` 는 도서관에 없다 (확인: 파일 목록에 부재). 연구원1 의 조언은 반영하지 못했다. 파일이 올라오면 그때 이 조언을 수정한다.
- 근거 문서: `READ-researcher2.md` (도서관 읽기 기록), `R25-researcher1` (χ=7 ⇒ K_7 의 조인 증명과 미해결 부분), `R13-researcher2` (완전 교차에서 h ≥ Σh_i).

## 1. 다리 후보 두 개와 판정 기준

**(A) SW 높이를 Steiner 정리 2 의 입력으로.** $h(X)=\max\{n:w_1^n\ne0\in H^n(X/\mathbb Z_2;\mathbb F_2)\}\le\operatorname{coind}X$. 따라서 $\tau\ge h+1$. Steiner 정리 2 는 $\operatorname{zig}\ge t$ 를 입력으로 받아 홀수 $K_{\lfloor t/2\rfloor+1}$ 마이너를 준다. 연결: $h\ge t-1 \Rightarrow \tau\ge t \Rightarrow \operatorname{zig}\ge t\Rightarrow$ 마이너. 즉 **하계만 필요하므로 방향은 맞다.**
- 한계: 결론은 홀수 마이너 크기 $\lfloor t/2\rfloor+1$ 로 Hadwiger 의 $t$ 보다 약하다. 그리고 $h$ 의 시트 블록 단조성 (부분그래프, 조인) 은 아직 증명되지 않았다 (R18-researcher3 의 단조 가정이 이 점에서 의심된다, READ 참조).

**(B) 마이너에 단조인 불변량.** 예: 홀수 마이너 크기 $\operatorname{om}(G)$ 또는 완전 마이너 크기 $h(G)$ 자체. 마이너 단조이므로 Hadwiger 질문과 직접 맞는다.
- 한계: 블록 합에서 값을 제어하는 법칙이 없다. 완전 교차에서만 $h\ge\sum h_i$ 가 증명되어 있다 (R13-researcher2).

**시트 블록에서 살아남는 판정 기준 (둘 다에 적용):**
1. 마이너 단조 (부분그래프와 마이너 모두에서 값이 줄지 않음): (B) 는 만족, (A) 는 불만족 (τ 는 마이너 비단조, $C_4 \succ K_3$ 이며 $\tau=2<3$).
2. 완전 조인에서의 가법성 (두 블록의 값이 더해짐): 둘 다 $\tau$/$h$ 쪽은 $\ge$ 로 증명됨, 상계 쪽은 열림.
3. 교차 패턴 무관의 상계 (블록 값만으로 상계): (A) 는 $\iota$ 판 상계가 있으나 $h$ 의 상계는 없다. (B) 는 상계 쪽이 필요 없다 (하계만으로 Hadwiger 가 나온다).

**결론:** 판정 기준 1 을 만족하는 (B) 가 Hadwiger 와 직접 맞는다. (A) 는 τ 하계를 거쳐 약한 홀수 마이너만 준다. 시트 블록에서 살아남는 것은 (B) 이다. 다만 (B) 는 블록 합 법칙이 없으므로 "조인 가법 + 교차 패턴에 무관한 하계" 를 새로 세워야 한다.

## 2. 망상꾼이 바로 해볼 한 가지 (계산 없이, 증명 스케치)

**목표:** 조인에 대한 SW 높이 초가법성의 반대 방향, 즉 $h(B_0(G_1+G_2))\ge h(B_0G_1)+h(B_0G_2)+1$ 을 증명하거나 막는 지점을 적는다.

**스케치 방향:**
1. $B_0(G_1+G_2)=B_0(G_1)*B_0(G_2)$ (R09 번역, 증명됨). 몫 $Q=X/\mathbb Z_2$ 에서 조인의 몫은 $X*Y$ 의 대각 대합 몫이다.
2. 이중 피복 $X\to Q$ 의 Gysin 열 (R20 보조정리 G) 을 조인에 적용하여, $w_1^a\ne0$ (in $X$) 와 $w_1^b\ne0$ (in $Y$) 에서 $w_1^{a+b+1}\ne0$ (in $X*Y$) 을 얻는 Künneth 형 논법을 세운다.
3. 막히는 지점을 적는다. 예상되는 장애: 조인의 몫에 대한 Künneth 가 $\mathbb F_2$ 에서 대합의 고정점이 없을 때만 성립할 것이다. 대합이 자유하므로 성립 가능성이 있다.
4. 성공하면 (B) 와 결합: 완전 조인 $h\ge\sum h_i$ 의 SW 버전이 얻어진다.

**판정:** 3 단계 이전에 장애가 명확하면 그 자체가 결과다 (위상 쪽 다리 (A) 의 가법성 불가 증명). 4 단계까지 가면 Hadwiger 완전 조인 경우의 위상 증명이 된다.

## 3. 주의
- τ 판 J (조인 상계) 는 열린 문제다 (R09 부록, R11 반례). 이 조언은 J 를 쓰지 않는다.
- 모든 상계·하계 결과는 시트 블록에서 완전 교차에만 증명되어 있다. 일반 교차 패턴은 열려 있다.
