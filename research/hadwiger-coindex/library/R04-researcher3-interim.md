## 핵심 (공격 요청 항목에 ★)
1. **쌍 환원 [증명]** (R03 #9 의 단계별 증명): $K_{3,3}$-자유 그래프에서 $Q_3$ ⇔ 모든 쌍 $\{a,b\}$ 의 공통이웃 $C(a,b)$ 가 (앞/사이/뒤) 세 구간에 모두 걸치지 않음. 120개 (그래프, 순서) 쌍에서 전체 이분쌍 검사와 불일치 0 [계산 확인].
2. ★**5색칠 환원 [증명]**: 진색칠 5색 + 색 클래스 순서 $\pi$ 로 놓으면, $Q_3$ 위반은 오직 "색이 모두 다른 $K_{2,3}$ 로서 2변 쪽 색이 $\pi$ 의 2·4번째" 일 때뿐. 즉 어떤 색쌍 $\{p,q\}$ 에 대해 "$a\in V_p,b\in V_q$ 가 나머지 세 색의 공통이웃을 모두 가진다" 가 없으면 $Q_3$. (4색이면 빈 클래스로 자명.) 하지만 **조심 없이 고른 5색칠에서는 10개 색쌍이 전부 위험할 수 있음** (SAT 로 8개 그래프 모두 존재 확인) [계산 확인] → 색칠을 골라야 하며, 이는 4색정리와 무관한 약한 목표 "다리 없는 색쌍을 가진 5색칠"을 준다.
3. ★**접합 보조정리 (K₃-합) [증명]**: $G_1,G_2$ 가 삼각형 $T=\{a,m,b\}$ 위에서 "T-덩어리 순서" (T 가 연속, 가운데 $m$, $C(a,b)\setminus\{m\}$ 가 전부 $a$ 앞 또는 전부 $b$ 뒤) 를 가지면 합 $G_1\cup_T G_2$ 도 같은 프로필의 순서를 가진다. 24쌍 접합 실험에서 위반 0 [계산 확인].
4. ★**가설 C3 [망상 → 가설]**: 평면 삼각분할과 삼각형 $T$(면 또는 분리삼각형)마다, 6개 프로필 $(m,\text{side})$ 모두 T-덩어리 순서가 존재. 8개 족 264개 $(T,m)$ 에서 반례 0 [계산 확인, 증명 아님]. 같은 방식의 "$T$ 가 맨 끝" 은 **반증됨**: 7정점 반례 [증명 by 전수 144].
5. **반증된 순서들 [망상: 반증됨]**: BFS 층 순서(층 안 자유, SAT: 6/8 족에서 불가능), Tutte 임베딩 방향 정렬(모든 방향·6 외곽면에서 최소 위반 1–12), 슈나이더 나무 전위순회(위반 8–30), 정준 순서. 차수 ≤5 정점 삭제-삽입 귀납(임의의 유효 순서에서 삽입 자리 0개인 경우 존재).
6. ★**$W_5$ [증명]**: $d_R(W_5)=3$ ($\mathbb R^2$ 불가능). 조건 (1) $h\notin\operatorname{conv}C$, (2) $hc_i\cap c_{i-1}c_{i+1}=\emptyset$, (3) $c_i\notin\triangle hc_{i-1}c_{i+1}$ 에서 "$h$ 에서 본 각도 순서에서 어떤 $c_i$ 도 이웃 둘 사이에 없다" → 각도 순서 위 국소 최대/최소가 $C_5$ 의 진 2색칠 → 모순.
