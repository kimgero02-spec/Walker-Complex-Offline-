## 요약
1. **(a) 정리 2 의 증명에서 틀린 단계를 찾지 못했고, 외부 의존도 없앴다.** 인용인 보조정리 5 ([25] Lemma 4)는 "극대 연결 이분 유도부분그래프를 차례로 뗀다"는 탐욕 논증으로 6줄에 직접 증명된다 [증명]. 관찰 1 은 홀수 마이너의 정의에 가까운 folklore 이고, 우리는 "확장 ⇒ 마이너" 방향만 쓴다. 증명을 알고리즘으로 구현해 $K_4$ ($t=4$, $K_3$), $K_6$ ($t=6$, $K_4$), $C_5[K_2]$, $C_5[K_3]$ 등에서 사례 1·2 가 실제로 홀수 확장을 낳음을 확인했다 [계산 확인]. **S3(τ판)은 이제 완전히 자립한다** ($\tau\le\operatorname{zig}$ [증명, R03-r2 정리 D 재검증] + 정리 2 [증명]).
2. **(b) 사실 F 는 필요 없다.** Dirac 의 "$K_4$-마이너-자유 ⇒ 차수 ≤2 정점"만으로 삽입 귀납이 완성된다 (이웃 $u,v$ 의 인접 여부는 무관, 쌍 $(C,\{u,v\})$ 는 그대로 쌍) [증명]. Dirac 의 사실 자체도 Menger 의 부채 보조정리만 쓰는 귀납으로 증명했다 ($T/U$ 동시 귀납) [증명]. R03-r3 정리 1 의 `[기억-미검증]` 의존이 사라졌다.
3. **(c) R03 의 새 정리 6건을 공격했으나 모두 방어.** 결정적 반례 없음. 막은 불변량: (i) 간선 하나가 양 변의 색을 갈라 같은 점이 두 변에 못 있음(루프 없음), (ii) 한 변이 빈 면은 마지막 좌표가 부호 일정, (iii) $d+1$ 개 점은 모멘트 곡선 위에서 항상 분리, (iv) $n=5$ 에서 $N[c-1]\cap N[c+1]=\{c\}$, (v) Helly 형 정보 ($\alpha\le2$) 를 $\tau$ 가 못 봄.
4. 부산물 [증명]: 색 순서의 런 수 논법으로 $d_R(G)\le\operatorname{zig}(G)-1$, 따라서 $\tau\le d_R+1\le\operatorname{zig}$. R03-r2 의 정리 D 와 R03-r3 의 $Q_d$ 는 같은 도구다.

### B. (b) 사실 F 의 제거: Dirac 만으로 $Q_2$ 귀납

**$Q_2$ (원형).** 원형 순서 $\sigma$ 가 $G$ 에서 $Q_2$ ⇔ 모든 완전이분쌍 $(X,Y)$ 에서 $X\cup Y$ 의 원형 라벨열의 런이 $\le2$. ($|X|=1$ 또는 $|Y|=1$ 이면 자동.) 원을 한 점에서 끊으면 선형 런 $\le3$ (원형 런 2 → 선형 2 또는 3) → 포물선 $(t,t^2)$ 에서 보조정리 G 로 엄격 분리 → $d_R\le2$, $\tau\le3$ [증명, R03-r3 보조정리 1·2 재검증].

**정리 1′** (사실 F 없이) [증명]. $K_4$-마이너-자유 $G$ 는 $Q_2$ 원형 순서를 가진다.

*증명* ($\lvert V\rvert$ 에 대한 귀납. 사용: (D) 모든 $K_4$-마이너-자유 그래프는 차수 $\le2$ 정점을 가진다 — §B.2.) $\lvert V\rvert=1$ 자명. $w$ 를 차수 $\le2$ 정점, $G'=G-w$ ($K_4$-마이너-자유, 부분그래프). 귀납으로 $G'$ 의 원형 순서 $\sigma'$ 가 $G'$ 에서 $Q_2$.
- $\deg w=0$: $w$ 는 쌍에 안 들어간다 ($Y\ne\emptyset$, $Y\subseteq N(w)$). 아무 곳에 삽입.
- $\deg w=1$: $w\in X$ 면 $Y=\{u\}$, $|Y|=1$ 이라 자동. 아무 곳에 삽입.
- $\deg w=2$, $N(w)=\{u,v\}$ ($u\sim v$ 여부 **무관**). $C'=N_{G'}(u)\cap N_{G'}(v)$. $|C'|\ge2$ 이면 $C'\times\{u,v\}\subseteq E(G')$ 이고 $u,v\notin C'$ (루프 없음) 이므로 $(C',\{u,v\})$ 는 $G'$ 의 쌍. 귀납 가정의 원형 런 $\le2$ 로 $C'$ 는 $u,v$ 가 가르는 두 열린 호 중 **한 호**에 있다. $w$ 를 그 호 안(없으면 아무 호)에 삽입.
- 검증: $w\notin X\cup Y$ 인 쌍은 $G'$ 의 쌍이고 제한된 순서가 $\sigma'$ 라 유지. $w\in X$ 이면 $Y\subseteq\{u,v\}$. $|Y|=1$ 은 자동. $Y=\{u,v\}$ 이면 $X\setminus\{w\}\subseteq C'$ 이므로 $X$ 는 $w$ 를 둔 호 안 → 런 2. $w\in Y$ 는 $X,Y$ 이름 교환. ∎

이웃 $u,v$ 가 비인접일 때 $(C',\{u,v\})$ 가 쌍이라는 근거는 **인접성을 전혀 쓰지 않는다** (완전이분 조건은 $C'$–$\{u,v\}$ 사이 간선뿐). R03-r3 후속 1번이 요청한 확인은 성립.

[계산 확인] `r4_dirac.py`: 무작위 $K_4$-마이너-자유 그래프 40개(7~10정점, 가지·세분·2-트리 삽입·간선 삭제로 생성)에서 위 알고리즘(차수 ≤2 정점 제거 → 역순 삽입)이 만든 순서가 극대쌍 전수에서 $Q_2$ 만족, 위반 0. $K_{2,3},K_{2,5}$ 에서 성공. $W_5$ 는 $Q_2$ 가 없고 $W_6$ 은 있음(R03-r3 #12·13 독립 재확인). (구현 점검이지 근거 아님.)

**B.2 Dirac 의 사실 (D) 의 증명** [증명]. 보조정리 L1: 3-연결 그래프(정점 ≥4)는 $K_4$ 의 세분을 가진다. 증명: $v$ 를 잡으면 $G-v$ 는 2-연결이므로 사이클 $C$ 가 있고 $\lvert C\rvert\ge3$. $G$ 가 3-연결이므로 Menger 부채 보조정리(Diestel Prop. 3.3.1 의 fan 형)로 $v$ 에서 $V(C)$ 로 가는, $v$ 외에 서로소이고 끝점에서만 $C$ 를 만나는 경로 3 개가 있다. $C$ 와 합치면 $K_4$ 세분. ∎

**정리 T, U** (동시 귀납, $n=\lvert V\rvert$):
- **T**: $K_4$-마이너-자유 $G$, $n\ge2$ ⇒ 차수 $\le2$ 정점이 **둘 이상**.
- **U**: $K_4$-마이너-자유 $H$, $n\ge3$, 간선 $xy$ ⇒ $\{x,y\}$ **밖에** 차수 $\le2$ 정점이 있다.

*T($n$).* $n=2,3$ 자명. $n\ge4$: (i) 비연결: 성분 중 1점짜리는 차수 0 하나, 2점 이상은 T 로 둘 이상. (ii) 절단점 $z$: $G-z$ 의 성분 $C_1,C_2,\dots$ 마다 $G[C_i\cup\{z\}]$ 에 T → 낮은 정점이 둘 이상이고 하나는 $z$ 가 아님. 그 정점의 차수는 $G$ 에서 같고 $i$ 마다 다르다. (iii) 2-연결: L1 때문에 3-연결이 아니므로 크기 2 의 절단 $\{x,y\}$, 성분 $D_1,D_2,\dots$. 2-연결이라 각 $D_i$ 는 $x,y$ 모두와 이웃. $G_i=G[D_i\cup\{x,y\}]+xy$ 는 $G$ 의 마이너 (다른 성분 $D_j\cup\{x\}$ 를 수축하면 $xy$ 가 생김) 이고 $3\le n_i<n$. U($n_i$) 로 $D_i$ 안에 낮은 정점 (차수는 $G$ 와 같음). $i=1,2$ 로 둘.
*U($n$).* $n=3$ 자명. $n\ge4$: (i) 비연결: $x,y$ 는 같은 성분. 다른 성분에 T(또는 1점) → 낮은 정점. (ii) 절단점 $z$: $G-z$ 의 성분 중 $\{x,y\}$ 를 안 품은 것 $C_1$ 이 있다 ($x\sim y$ 이므로 $\{x,y\}\setminus\{z\}$ 는 한 성분 안). $H[C_1\cup\{z\}]$ 에 T → $C_1$ 안에 낮은 정점. (iii) 2-연결: 2-절단 $\{a,b\}$. $x\sim y$ 이므로 $\{x,y\}\setminus\{a,b\}$ 는 한 성분 안. 그것을 안 품은 성분 $D_j$ 를 고르고 $H_j=H[D_j\cup\{a,b\}]+ab$ (마이너, $3\le n_j<n$) 에 U($n_j$) → $D_j$ 안에 낮은 정점 (차수 불변). ∎

T 로 (D) 가 나온다 ($n=1$ 은 차수 0). 사용한 외부 사실은 Menger 의 부채형뿐. **정리 1 (K_4-마이너-자유 ⇒ $Q_2$ ⇒ $d_R\le2$ ⇒ $\tau\le3$) 의 의존이 모두 증명으로 닫혔다.**

[계산 확인 아님, 연역 결과] 이 증명은 Dirac(1952, 논문 참고문헌 [5])의 정리와 같은 내용이다. 문헌 대조는 못 했다.

**(b) 결론**: 귀납은 돈다. 막은 불변량은 "삽입 정점의 공통이웃 $C'$ 가 한 호에 모인다"는 귀납 가정 하나뿐이고, 이는 $C'$ 와 $\{u,v\}$ 의 완전이분성에서 나온다.

**C.1 모멘트 곡선 논법의 경계 사례 (요청 사항)**
1. *같은 점이 두 변에 속함*: 그래프에서는 루프가 없어 불가능($v\in A\cap B$ 이면 $(v,v)\in E$). 다만 **초그래프 쪽(정리 A)** 에서는 같은 점이 $P,Q$ 에 못 속하는 것이 $z_i$ 의 부호로 보장된다. 모멘트 점들도 서로 다른 $t$ 이므로 곡선 위에서 점이 겹치지 않는다. 이 불변량이 깨지는 곳은 없다.
2. *한 변이 빈 면*: $B_0$ 의 면에 포함되지만 마지막 좌표 $\pm1$ 때문에 0 을 안 지난다. 정리 D 에서는 $S^-=0$, $\mu_0\ne0$.
3. *점 수가 $d+1$*: $(Q)$ 형이 정확히 이 경우. $d+1$ 개 점의 임의 이분할은 어파인 독립이라 분리됨 — 부호변화 $\le d$ 와 같은 말이다. 여유 없이 경계에 닿지만 성립. (이것이 $\mathbb R^{2m-2}$ 불가능성, 즉 $\tau\ge\omega$ 와 일치.)
4. *$n=5$*: $N[c-1]\cap N[c+1]=\{c\}$ 는 $n\ge5$ 에서 참, $n=4$ 에서 거짓. $n=5$ 의 $C_5[K_m]$ 은 바로 정리가 의미 있는 가장 작은 경우이고, 오케스트레이터의 폐포 전수(25/125/565)가 분류와 일치.

**C.2 정리 D ($\tau\le\operatorname{zig}$) 의 두 번째 증명 및 부산물** [증명]. 고정 진색칠 $c$ 와 모든 완전이분쌍 $(X,Y)$: $c$ 로 정렬하면 같은 색은 한쪽에만 있으므로 라벨열의 런마다 대표 한 정점을 뽑으면 길이 = 런 수의 지그재그. 따라서 런 수 $\le L(c)$ (=$c$ 의 최대 지그재그). 색 순서가 $Q_{L(c)-1}$ 을 만족하고, 모멘트 곡선(보조정리 G)으로 $d_R\le L(c)-1$. $c$ 를 최적으로 잡으면
$$\tau(G)\le d_R(G)+1\le\operatorname{zig}(G)\le\chi(G).$$
즉 R03-r2 의 $B_0$ 위 모멘트 사상과 R03-r3 의 $Q_d$ 는 같은 구성이다. 이 부등식은 증명되었고, $d_R+1$ 이 $\tau$ 와 $\operatorname{zig}$ 사이에 낀다는 새 정보다. ($\overline{C_7}$: $d_R=2$, $\tau=\operatorname{zig}=3$.)

**C.3 막힌 곳(방어의 의미)**: 이번에 전부 방어되었다는 것은 $\tau$ 를 올리는 "위상 지표 vs 조합 지표" 간극이 이 모든 증명을 우회하지 못한다는 뜻이 아니라, R03 정리 자체에는 구멍이 없다는 뜻이다. 가장 약한 고리는 정리 A 의 극대쌍 분류가 **블롭 이웃 구조가 순환일 때만** 성립한다는 점(R03-r1 후속 1)이고, 이는 정리의 결함이 아니라 적용 범위다.

## 후속연구 지점
1. **삽입 귀납을 $t=5$ 로: 차수 ≤3 정점과 $Q_3$.** 무엇: 평면 그래프(또는 $K_5$-마이너-자유)에서 차수 ≤3 정점 $w$ ($N(w)=\{u,v,x\}$) 를 삽입해 $Q_3$ 를 유지하는 규칙. 이유: 정리 1′ 는 "차수 ≤2" 만 쓰며 같은 구조가 $K_5$-마이너-자유에서는 차수 ≤5 정점이라 막힘; 차수 ≤3 로 환원되는 부분족(평면에서 Kempe/환원 가능 배치가 있는 경우)부터 확인. 시작: $|Y|=3$ 쌍의 $X\subseteq C'(u,v,x)$ 가 선형 런 ≤4 가 되도록 하는 삽입 위치의 존재 조건을 R03-r3 의 "공통이웃이 한 호" 를 일반화해 쓴다. 난점: 세 정점이 가르는 3 구간 중 $C'$ 가 두 구간에 걸칠 수 있고 이웃들 사이 인접이 영향을 준다.
2. **$d_R$ 의 의미 있는 대조: $\tau<d_R+1$ 인 그래프 찾기 (ind–coind 간극).** 이유: 부산물 $\tau\le d_R+1\le\operatorname{zig}$ 가 세 값의 구분을 요구. 시작: $C_n[K_m]$ 에서 $d_R=2m-1$ 인지(하한은 $\omega-1$ 만 알려짐), $\overline{C_7}$ 과 $C_5$ 에서 $d_R=2$ 인지 조합적 증명. 난점: $d_R$ 하한 기술이 없음.
3. **정리 2 의 상수 개선 가능성 점검.** 이유: 증명은 보조정리 5 색칠 한 개의 최대 지그재그 $L(c)$ 만 쓰므로 $\lfloor L(c)/2\rfloor+1$ 을 준다. $\tau$ 의 경우 $L(c)$ 와 $\tau$ 의 비교로 손실 "절반"이 줄어드는지. 시작: $C_5[K_m]$ 에서 $L(c)$ 를 보조정리 5 의 여러 선택으로 계산해 $\tau=2m$ 과 비교(이미 $C_5[K_3]$ 에서 6 과 7). 난점: 손실의 원인(사례 2 에서 한 쌍 $x_{k-1}y_{k-1}$ 만 쓰는 점)이 구조적.
4. **S1(τ판) 새 경로의 첫 구체 단계**: 정리 3 의 증명처럼 "최소성"으로 구조를 뽑는 방식을 $\mathbb Z_2$-사상의 상(像)에 적용. 시작: 정리 A 의 사상 $\Phi$ 가 주는 $U$ 대신, $\tau$ 의 극소 인증서(모멘트 사상의 영점 구조)에서 마이너를 읽기. 난점: 추측 C 반증으로 정리 3 직접 경로는 닫혔고 $\tau$ 는 마이너 단조가 아님.
5. **`[기억-미검증]` 재확인**: (i) Menger 의 부채 보조정리의 쪽(Diestel *Graph Theory*), Dirac(1952) 원문과 T/U 증명의 대조; (ii) 관찰 1(홀수 마이너 정의 동치)의 출처 [8]; (iii) "$k$-연결 ⇒ coind ≥ $k+1$" (Matoušek) 은 이번 증명에 쓰지 않았으나 R03-r2 의 $\tau(C_5)$ 하한에 쓰임 — 증명 가능한 대안(예: $B_0(C_n)$ 이 $S^1$ 두 개가 아니라 단일 $S^1$ 이 아님을 직접 보이는 등 $\tau(C_{2k+1})=3$ 의 연역적 하한)이 필요; (iv) Wagner 분해와 Hajós 상태는 그대로 미검증.
