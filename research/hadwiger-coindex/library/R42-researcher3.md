# [R42-researcher3] ι < χ 인 평면 블록은 존재한다: Moser 방추 (χ=4, ι=3)

- 작성자·역할: researcher3 (망상꾼). 무인 6라운드 중 2. 한 번만 보고. 계산 없음 (손 논증과 팀의 기존 증명·기록 인용).
- 표기: $\iota=\operatorname{ind}B_0+1$, $\tau=\operatorname{coind}B_0+1\le\iota$. 팀 사슬: Radon 인증서는 등변 사상 $B_0\to S^{d_R}$ 을 주므로 $\operatorname{ind}\le d_R$, 그리고 $d_R\le\operatorname{zig}-1$ (R03-r2, R04-r2 [증명]). 따라서 $\iota\le d_R+1\le\operatorname{zig}$.

## 0. 실패 기준 (먼저)
- **존재 주장 (E):** 평면 그래프 $P$ 로 $\chi(P)=4$, $\iota(P)=3$ 인 것이 있다. 실패 = 후보가 비평면이거나, $\operatorname{zig}(P)\ge4$ (그러면 ι 상계 3 이 나오지 않음), 또는 $\chi(P)\ne4$.
- **비교 주장 (C):** 짝 덮개 상계 $\sum\iota_i$ 는 이런 블록에서 $\sum\chi_i$ 보다 엄밀히 작다. 실패 = 개선이 다른 상계 (zig 가법) 에 이미 포함되어 새 정보가 없는 경우 — 이 경우는 "개선은 있으나 새롭지 않음" 으로 기록.

## 1. 후보: Moser 방추 $M$
- 정의: 정점 $0,\dots,6$; 마름모 A = 삼각형 $\{0,1,2\}$, $\{1,2,3\}$ (공통 간선 12); 마름모 B = 삼각형 $\{0,4,5\}$, $\{4,5,6\}$ (공통 간선 45); 그리고 간선 36. 간선 11 개.
- 층: **층 1 (블록 정의).**

## 2. 세 성질
**(i) 평면 [증명, 명시 그림].** 0 을 위에 두고 마름모 A 를 왼쪽 아래로, 마름모 B 를 오른쪽 아래로 그린다 (각 마름모는 두 삼각형이 한 간선을 공유한 평면 사각형). 두 마름모는 꼭짓점 0 만 공유한다. 아래쪽 끝 3 (A) 과 6 (B) 을 두 마름모 아래로 지나는 곡선으로 잇는다. 교차가 없다. 층: **층 1.**

**(ii) χ=4 [증명, 표준 논법].** 3-색칠을 가정하면 마름모 A 에서 0 과 3 은 같은 색 (삼각형 012, 123 에서 1,2 가 두 색을 쓰고 0, 3 은 셋째 색). 마름모 B 에서 0 과 6 도 같은 색. 따라서 $c(3)=c(0)=c(6)$ 인데 36 이 간선이라 모순. 4-색칠은 존재 (평면, 또는 직접). 따라서 $\chi=4$. 층: **층 1.**

**(iii) ι=3 [증명 + 팀 기록].** 상계: 팀 기록 $\operatorname{zig}(M)=3$ (N1-researcher2 §4.2, SAT 순서; N1-researcher1 Moser 언급 동일) 과 사슬 $\iota\le\operatorname{zig}$ 로 $\iota\le3$. 하계: 삼각형 $\subseteq M$ 이므로 $\tau\ge3$, 따라서 $\iota\ge\tau\ge3$. 그러므로 $\iota(M)=\tau(M)=3<4=\chi(M)$. 층: **층 3 (지수).**
- 주의: zig=3 은 팀의 SAT 순서 기록에 의존한다 (본 라운드는 계산하지 않음). 독립 확인 수단: R22-r3 / R21-r3 의 Moser 계산 (내 기록: 몫 F_2-호몰로지 (1,1,3), $h=2$) 과 모순 없음. $h=2\le\operatorname{coind}=2$.

## 3. 판정
- **(E) 성립:** Moser 방추는 평면, χ=4, ι=3. 따라서 ι<χ 인 평면 블록은 **존재한다.** 층: **층 1–3.**
- **(C) 비교:** 블록 $k$ 개가 모두 Moser 형이면 짝 덮개 상계 $\tau\le\sum\iota_i=3k$ 로 χ 상계 $4k$ 보다 엄밀히 작다. 그러나 같은 $3k$ 는 zig 블록 가법 ($\operatorname{zig}\le\sum\operatorname{zig}_i=3k$, R14/R15) 로도 나온다. 즉 **개선은 있으나 위상 쪽만의 새 정보는 아니다** ($\iota\le\operatorname{zig}$ 이므로 짝 덮개 상계는 zig 상계보다 약하거나 같다). 층: **층 3 (비교).**
- 위상 상계가 zig 상계보다 엄밀히 나으려면 $\iota_i<\operatorname{zig}_i$ 인 블록이 필요하다. 이것은 R06 이래의 열린 문제 ($\tau=\operatorname{zig}$ 판정) 와 같은 종류이며, 알려진 예가 없다.

## 4. 시트 쪽 함의 (한 줄)
평면 시트 블록이 Moser 형이면 τ 상계는 4k 에서 3k 로 내려가지만, 이 개선은 zig 가법에서 이미 얻어지므로 짝 덮개 (위상) 는 새 상계를 주지 않는다.

## 5. 결과 줄 (복잡성 환원의 어느 층)
- Moser 평면성·χ=4 (§2 i, ii): 층 1 (블록 정의).
- ι(Moser)=3 (§2 iii): 층 3 (지수).
- 상계 3k 개선과 zig 와의 동등 (§3): 층 3 (비교).

## 6. 후속연구 지점
1. **zig(Moser)=3 의 독립 확인 (우선순위 1).** 이유: (iii) 의 상계가 팀 SAT 기록 하나에 의존. 시작: 명시 순서 하나를 손으로 제시하고 극대 완전이분쌍의 런 수 ≤3 을 확인 (계산 허용 라운드에서). 
2. **ι<zig 인 블록 탐색의 정의 (우선순위 2).** 이유: 짝 덮개 상계가 zig 보다 나은 유일한 경우. 시작: R06 의 "τ<zig 후보" 와 같은 질문을 ι 로 바꿔 정의 수준에서 정리 (τ ≤ ι ≤ zig 사슬의 가운데 간극).
3. **평면 χ=4, ι=3 블록의 족 (우선순위 3).** 이유: Moser 외에 R21-researcher2 의 평면 간극 후보 4 개가 같은 성질을 갖는지 (모두 χ=4, zig≤3 이면 ι=3). 시작: 그 기록의 평면성·zig 값을 정리해 표로 묶기 (새 계산 없이 인용).
