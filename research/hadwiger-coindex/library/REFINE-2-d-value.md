# REFINE-2-d-value: 교차 차수 상계 d 와 χ 의 관계, 독립 판정 d = 2

- 작성자·역할: researcher2 (독립 판정). 연구원1 의 `REFINE-1-decision.md` 는 아직 없다 (확인 필요 시 비교 후 기록).
- 설정: $\mathcal C_d$ = $G=B_1\cup B_2\cup H$, $B_i$ 평면, 양쪽 모두 교차 이웃 수 $\le d$.
- 표기: `[증명]` (조건부 외부 정리 명시) `[추측]`.

## 1. 결과: $\chi\le d+5$ on $\mathcal C_d$ [증명, 외부 정리 2개 인용]
- 인용: 4색정리 [기억-미검증], 평면 그래프 5-선택 가능 (Thomassen) [기억-미검증].
- 증명: $B_1$ 을 4-색칠 (4CT). 팔레트 $P=\{1,\dots,d+5\}$ (크기 $d+5$), $B_1$ 은 $\{1..4\}$ 만 사용.
  $y\in B_2$ 의 리스트 $L(y)=P\setminus C(y)$, $|C(y)|\le d$, 따라서 $|L(y)|\ge 5$.
  $B_2$ 는 평면이므로 리스트 크기 5 로 색칠된다 (Thomassen). 교차 간선 $xy$ 에서 $c(y)\ne c(x)$ 이므로 $G$ 의 $(d+5)$-색칠. ∎
- 검산: $d=1$ 은 $\chi\le6$ (R35 와 일치). $d=3$ 은 $\chi\le 8$ (완전 조인 $K_4+K_4$ 와 일치).

## 2. 독립 판정: $d^*(t)=t-5$, 따라서 $d^*(7)=2$
- $\chi\ge t$ 가 가능하려면 $t\le d+5$, 즉 $d\ge t-5$. 이것이 **필요 조건**이다 (§1).
- $t=7$: 필요 $d\ge2$. $d=1$ 은 불가능 (R35). 따라서 $d^*(7)\ge2$ 이고, §1 의 상계 $d+5=7$ 이 $d=2$ 에서 맞는다.
- 충분성 (χ=7 이 $d=2$ 에서 실제로 실현되는가): 미결 (R36 의 장애 분석과 일치). 따라서 **d=2 는 하한이며, 독립 판정값은 $d=2$ (= 필요 최소)**.

## 3. 분기 접촉과의 관계 (REFINE-2 의 빈칸)
- §1 은 χ 의 상계만 준다. χ≥t 에서 분기 접촉을 강제하는 명제는 아니다.
- 그러나 $d$ 가 $t-5$ 에 맞으면, 색칠이 "모든 교차 이웃의 색을 피한다" 는 단계가 정확히 $d$ 개의 색을 소모한다. 따라서 접촉이 강제되는 최소 조건은 "$d = t-5$ 에서 리스트 크기가 정확히 5 가 되는 정점" 이다 (리스트 5 의 장애가 발생하는 지점). 이 지점의 분기 접촉 구조는 아직 증명되지 않았다 [추측].

## 4. 연구원1 과의 비교 (기록 틀)
- 같으면 (d=2): 지지. 독립 근거는 §1 (4CT + 5-선택) 과 §2 (필요 조건 $d\ge t-5$).
- 다르면: 차이의 원인을 다음 중에서 적는다: (a) 교차 차수의 정의 (양쪽 vs 한쪽), (b) 블록 색칠 도구 (4CT 사용 여부), (c) 리스트 크기 계산 (팔레트 $d+5$ vs $d+4$).
- 연구원1 파일 도착 시 이 절을 채운다.

## 후속연구 지점
1. **$d=2$ 에서 χ=7 의 실현 (우선순위 1).** 이유: §2 의 $d^*(7)=2$ 가 하한이므로 상한 (실현) 이 확정되어야 값이 정해진다. 시작: 5-선택 장애를 만드는 교차 차수 2 구성 (R36 §2(b)). 난점: 6 색 강제 가젯 부재 (R36).
2. **4CT 와 5-선택의 제거.** 이유: §1 증명이 외부 정리 2 개에 의존한다. 시작: $B_1$ 을 5-색칠 (Heawood, 초등) 로 바꾸면 팔레트가 $d+6$ 이 되어 상계가 1 증가하는지 확인 (비교 기준).
3. **접촉 강제 최소 조건.** 이유: REFINE-2 의 χ→접촉 빈칸. 시작: $d=t-5$ 에서 리스트 크기 5 장애 지점의 분기 집합 구조를 K_4+K_3 류 블록에서 손으로 확인.
