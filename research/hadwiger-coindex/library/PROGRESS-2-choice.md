# PROGRESS-2-choice: 공통 2색 리스트 Q 의 4-리스트 장애 구조 (결과: 미결, 환원과 부분 보조정리)

- 작성자·역할: researcher2 (GROW-2 의 핵심 미결). 한 번만 보고. 열거 없음.
- 설정 (GROW-2 §2 재사용): $B_1=K_4$, 6 색 팔레트 $P$. 6-색칠은 $(Q,\sigma)$ 로 기술: $Q\subset P$ 는 미사용 2 색, $\sigma:K_4\to P\setminus Q$ 단사 (전단사). $y\in B_2$ 의 리스트 $L_{Q,\sigma}(y)=P\setminus\sigma(N(y))$.
- 표기: `[증명]` `[추측]`. 외부 정리 (Thomassen 5-선택) `[기억-미검증]`.

## 0. 실패 기준 (먼저)
- **실현:** 평면 $B_2$ 와 $N:V(B_2)\to\binom{K_4}{\le2}$ 가 있어, 모든 $(Q,\sigma)$ 에 대해 $B_2$ 가 $L_{Q,\sigma}$ 로 색칠되지 않음. 최소 정점 수와 증인 (모든 (Q,σ) 에서의 장애 정점 부분집합).
- **불가:** 임의의 $(B_2,N)$ 에 대해 어떤 $(Q,\sigma)$ 가 색칠을 허용함을 증명 (장애 = 그런 $(Q,\sigma)$ 의 존재).
- 결과: 둘 중 어느 것도 완결하지 못했다. 아래는 환원과 두 보조정리.

## 1. 환원 (GROW-2 §2 의 정리화) [증명]
- $y$ 의 리스트 종류: $|N(y)|=0$ → 6 색, $|N(y)|=1$ → $P\setminus\{\sigma(a)\}$ (5 색), $|N(y)|=2$ → $Q\cup\{\sigma(b),\sigma(b')\}$ (4 색, $\{b,b'\}=K_4\setminus N(y)$).
- 따라서 $|N|=2$ 정점의 리스트는 항상 $Q$ 를 포함한다. 같은 $(Q,\sigma)$ 아래에서 $Q$ 는 모든 $|N|=2$ 정점에 공통이다.
- T7 단계: χ=7 조건을 "모든 $(Q,\sigma)$ 에서의 실패" 로 환원 (GROW-2 와 같은 단계).

## 2. 보조정리 A: 2-부분 구조는 항상 색칠됨 [증명]
$B_2$ 가 이분 그래프이면 모든 $(Q,\sigma)$ 에서 색칠된다: 한쪽 부류 전체에 $q_1$, 다른 쪽 전체에 $q_2$ ($Q=\{q_1,q_2\}$). 모든 정점의 리스트가 $Q$ 를 포함하므로 (|N|=2 정점) 또는 6/5 색 리스트 (다른 정점) 는 $Q$ 를 포함한다 — **단, $|N|=1$ 정점의 리스트 $P\setminus\{\sigma(a)\}$ 는 $q_i$ 를 포함할 때만 가능하므로 $\sigma(a)\in Q$ 가 아닌 한 포함**. $\sigma(a)\in P\setminus Q$ 이므로 $Q\subseteq P\setminus\{\sigma(a)\}$ 가 성립 [증명]. 따라서 $Q\subseteq L(y)$ 가 모든 y 에서 성립하고 이분 색칠이 된다. ∎
- T7 단계: 장애는 $\chi(B_2)\ge3$ 인 구조에서만 가능 (B_2 의 홀수 사이클 필요).

## 3. 보조정리 B: 3-색칠 가능 $B_2$ 의 환원 [증명]
$B_2$ 가 3-색칠 $(C_1,C_2,C_3)$ 을 가지면 각 $C_i$ 에 리스트의 공통 색 $c_i$ 가 있으면 충분하다. $Q$ 는 $Q\subseteq L(y)$ 이므로 $C_1\to q_1$, $C_2\to q_2$ 가능. 장애는 $C_3$ 에서만: $\bigcap_{y\in C_3}L(y)=\emptyset$ 이어야 한다. 그런데 $C_3$ 의 리스트는 $Q\cup$ (두 색 쌍) 이므로, $\bigcap_{y\in C_3}L(y)\supseteq Q$ 가 공집합이 될 수 없다. 즉 **$C_3$ 는 $Q$ 의 색을 쓸 수 없지만, $Q$ 가 이미 $C_1,C_2$ 에 쓰였다**. 따라서 3-색칠 가능 $B_2$ 에서도 재배치가 필요하며, 이 재배치가 장애의 핵심이다 [추측: 재배치 실패 조건 미정].
- 정확한 환원: 색칠 가능 ⇔ $B_2$ 의 어떤 색칠이 $\{$색 클래스 $\to$ 색$\}$ 로 리스트를 만족. 이 결정 문제는 4-리스트 색칠 문제 그 자체이다.
- T7 단계: 3-색칠 구조를 쓸 때의 재배치 장애 (구성에 필요한 최소 색 수).

## 4. 장애의 정량 형태 (추측)
- 장애 $(B_2,N)$ 는 "모든 $(Q,\sigma)$ 에서 4-리스트 색칠 불가" 이며, 리스트는 전체 $6\cdot\binom{4}{...}$ 가지의 상수 범위 안에서만 변한다 (유한 가족). 따라서 장애가 존재한다면 유한 크기 (상수 상계) 의 최소 구조가 있다 [추측].
- 그러나 최소 정점 수는 본 보고서에서 정하지 못했다 (열거 금지).

## 5. 결과 요약
| 결과 | 판정 | T7 단계 |
|---|---|---|
| 리스트 종류 환원 (|N|=0,1,2) | 증명 | χ=7 조건의 (Q,σ) 환원 |
| $Q\subseteq L(y)$ 공통 | 증명 | 이분 색칠 (보조정리 A) |
| 이분 $B_2$ 는 항상 색칠 | 증명 | 장애는 χ(B_2)≥3 에서만 |
| 3-색칠 $B_2$ 의 재배치 장애 | 미결 | 핵심 |
| 장애 구조 존재 / 최소 n | 미결 | 실현 여부 (GROW-2 의 d=2 실현) |

## 후속연구 지점
1. **$C_3$ 재배치 조건 (우선순위 1).** 이유: §3 의 핵심. 시작: $C_1, C_2$ 가 $q_1,q_2$ 를 쓸 때 $C_3$ 의 리스트 교집합이 공집합이 되는 조건 (쌍 $\{b,b'\}$ 의 구조) 을 손으로 정식화. 판정: 조건이 $B_2$ 의 평면성과 양립하면 실현 후보.
2. **$\chi(B_2)=4$ 인 경우.** 이유: 4-색 임계 평면 블록 (K_4 류) 은 3-색칠 환원을 쓰지 못한다. 시작: $B_2=K_4$ 에서 $|N|=2$ 를 다 주었을 때 색칠 불가능성 확인 (손, 열거 없이). 결과: R36 (a) 에 따라 K_4 는 항상 색칠됨 → 4-색 임계 블록은 다른 구조가 필요.
3. **$B_1$ 을 $K_4$ 이외로.** 이유: 위 환원은 $B_1=K_4$ 에 특화. 시작: $B_1$ 의 6-색칠 자유도와 교차 차수 합의 관계를 정식화 (GROW-2 후속 2 와 같은 질문).
