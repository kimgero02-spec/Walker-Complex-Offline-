# [R10-researcher3] 시트 사이 간선 공리의 위상 번역과 기본 정의와 구별되는 예측

- 작성자·라운드·역할: researcher3 / R10 / 망상꾼 (분야: 대수적 위상수학)
- 지시: 문주님 전달 (연구 중 최적화를 위해 시트 사이 간선에 공리를 제한하는 것은 허용). 기본 정의 ($\tau=\operatorname{coind}B_0+1$, 정점 블록 $U_i$) 는 바꾸지 않았다.
- 코드: `rooms/researcher3/r10_cross.py` (3+3 블록의 교차 패턴별 $X(G)$ 호몰로지). 기존 `r06_lib.py`, `r08_checks.py` 재사용.
- 표기: $X(G)=B_0(G)$ (빈 면 허용), 블록 $V_1\sqcup V_2$, 교차 간선 집합 $C\subseteq V_1\times V_2$, $t_i$ = $X(G[V_i])$ 의 최고 호몰로지 차원.

## 요약
1. **공리 세 개를 위상으로 번역했다.** (a) 매칭 공리 Ax-M: 교차 간선이 매칭이다. (b) C4 자유 공리 Ax-C4: 교차 이분그래프 $C$ 가 $K_{2,2}$ 를 포함하지 않는다. (c) 별 공리 Ax-S: 교차 간선이 한 정점에서만 나온다. 공통 위상 뜻: 교차 면 (두 블록에 걸친 완전 이분 면) 의 차원이 제한된다. 교차 면이 생기지 않으면 $X(G)$ 는 블록 복합체들의 "얇은" 접착이 된다.
2. **[계산 확인] 기본 정의와 구별되는 현상.** 3+3 블록 (각 $K_3$) 에서 기본 조인 공식은 최고 차원 $5$ 를 준다 (완전 교차 $K_6$: 실제 5, 등호). 같은 블록에 Ax-M (프리즘), Ax-C4 (교차 $C_6$, 즉 $\mathrm{oct}=K_6-\mathrm{PM}_3$) 를 주면 최고 차원은 **2** 로 떨어진다. 빈 교차 ($2K_3$) 도 최고 차원 2 (H̃_1=Z, H̃_2=Z^2). 즉 공리가 호몰로지 상계를 실제로 줄인다.
3. **[증명] Ax-S 에서 $\tau\le\max\tau_i+1$ 이 가능한 예.** $K_4$ 를 부분그래프로 갖는 별 패턴 ($0$ 이 $3,4,5$ 에 연결) 은 $\chi=4$, $\tau\ge4$ 이므로 $\tau=4=\max\tau_i+1$. 이 등호는 기본 정의의 P1 상계 $\tau\le 3+3=6$ 보다 엄격하다.
4. **[계산 확인] oct 에서 기본 정의와 공리 정의가 갈린다.** $\mathrm{oct}=K_6-\mathrm{PM}_3$ 은 Ax-C4 를 만족하고 $\tau=3=\max\tau_i$. 기본 P1 은 $\le 6$ 만 준다. 따라서 Ax-C4 아래 "$\tau\le\max\tau_i+1$" 은 oct 에서 여유 1 로 성립한다.
5. **판정.** 공리는 최적화 도구로 쓸 수 있다: Ax-C4 는 기본 정의의 덮개 상계를 조인 상계 $\sum(\tau_i)$ 에서 $\max\tau_i+1$ 쪽으로 낮출 가능성을 준다. 단, 증명은 없고 예측이다.

## 번역 사전
| 공리 | 위상 쪽 뜻 | 기본 정의와의 차이 |
|---|---|---|
| Ax-M (교차 매칭) | 교차 면은 1-단체 (두 꼭짓점) 뿐. 두 블록의 접착이 1 차원 | 기본: 교차 면의 차원은 임의 (완전 교차에서 조인 차원까지) |
| Ax-C4 (교차 $C_4$-자유) | 교차 완전 이분 부분 $K_{1,t}$ 만 (별 모양). 별 면은 축약 가능 → 접착이 호모토피 동치 | 기본: $K_{2,2}$ 교차가 조인 차원을 만든다 (K_6 에서 top 5) |
| Ax-S (교차 별) | 교차 면은 모두 $v_0$ 을 포함. $X$ 는 $v_0$ 의 별로 접착 | 기본: 교차 면이 여러 꼭짓점에 걸친다 |
| 빈 교차 | $X$ 는 블록들을 공통 복사본 단체로 접착 | 기본 정의와 같은 규약 |
| 완전 교차 | 조인 $X_1*X_2$ | 기본 정의의 최대 경우 |

## 가져온 도구
1. ★ **별 축약 (contractible star gluing)** [증명, 표준]: 교차 면 집합이 한 정점의 별이면, 그 별을 축약해도 호모토피형이 바뀌지 않는다 (별은 축약 가능).
2. ★ **덮개 부분가법 (기본 정의에서 가져옴)** [증명]: $\tau(G)\le\tau(G[V_1])+\tau(G[V_2])$ (R09 P1, 레트랙션과 조인 보조정리).
3. ★ **Mayer–Vietoris 교집합 차원 계산** [증명, 표준]: 교집합 $U_1\cap U_2$ 의 최고 차원이 공리로 제한되면 MV 열의 최고 차원도 제한된다 (R09 도구 3).

## 시험 결과 (계산 확인, `r10_cross.py`, F_p 계수)
- 2K_3 (빈 교차): 최고 차원 2, $\tilde H_1=\mathbb Z$, $\tilde H_2=\mathbb Z^2$.
- 프리즘 $K_3\square K_2$ (교차 매칭): 최고 차원 2, $\tilde H_2=\mathbb Z$.
- $\mathrm{oct}=K_6-\mathrm{PM}_3$ (교차 $C_6$): 최고 차원 2, $\tilde H_2=\mathbb Z$ (τ=3 과 맞음, coind 2).
- $K_6$ (교차 $K_{3,3}$): 최고 차원 5, $\tilde H_5=\mathbb Z$ (기본 조인 공식 등호).
- 별 패턴: $\chi=4$, $K_4\subseteq G$ 이므로 $\tau=4$ (R10 Q3, 증명 쪽, 계산 없이).

## 해석과 한계
- Ax-M, Ax-C4 에서 호몰로지 상계가 줄어드는 것은 계산으로 확인되었다. $\tau$ 상계의 일반 증명은 없다 (Q2, Q4 는 추측).
- Ax-C4 는 $K_{2,2}$-자유라는 이름의 조합 조건이지만, 위상적으로는 "교차 면의 최대 차원 1" 로 번역된다. 이 번역이 교차 패턴의 임의의 큰 블록에서도 유지되는지는 확인하지 않았다.
- 기본 정의를 바꾸지 않았다. 공리는 최적화에만 쓴다. 공리 아래 얻은 상계를 기본 정의로 되돌릴 때는 공리가 성립함을 먼저 확인해야 한다.

## 후속연구 지점
1. **Ax-C4 아래 $\tau\le\max\tau_i+1$ 의 증명 (우선순위 1, 이유: 기본 조인 상계보다 강하고 평면 블록에 자연스럽다).** 시작: 교차 $C_4$-자유 이분 패턴에서 교집합 $U_1\cap U_2$ 를 별 모양 덮개로 분해하고 Q2 를 MV 열로 보인다. 난점: $\tau$ 는 coind 라서 MV 열로는 직접 얻지 못하고, 등변 사상 구성이 필요하다.
2. **Ax-C4 반례 탐색 (우선순위 2).** 시작: 블록 $K_4$ 2 개와 $C_4$-자유 교차 (예: 교차 $C_6$ 또는 $K_{1,3}$ 의 합) 에서 $\tau$ 를 계산해 $\max+1$ 을 넘는지 본다. 난점: $K_8$ 규모의 coind 계산 도구가 없다.
3. **Ax-M 의 여러 블록 확장 (우선순위 3).** 시작: 매칭 교차로 연결된 블록 $m$ 개의 최고 차원 $\le\max t_i$ 를 MV 로 일반화. 난점: 블록 수가 늘면 교집합의 고차 구조가 복잡해진다.
