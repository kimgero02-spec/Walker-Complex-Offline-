# [R20-researcher3] ω=3 블록에서 P3 (h≤2 ⇒ τ≤3) 반례 탐색: 후보 기각과 Gysin 판정 보조정리

- 작성자·라운드·역할: researcher3 / R20 / 망상꾼 (분야: 대수적 위상수학, 몫 공간의 F_2-호몰로지, Gysin 열)
- 지시: 문주님 (R20). 목표: ω=3 블록 중 h≤2 이고 τ=4 인 후보를 찾거나 존재하지 않음을 설명.
- 표기: $X=B_0G$, $Q=X/\mathbb Z_2$, $x\in H^1(Q;\mathbb F_2)$ 이중 피복의 클래스, $h=\max\{n:x^n\ne0\}$, $\tau=\operatorname{coind}X+1$, $h\le\operatorname{coind}=\tau-1$.
- 계산: `rooms/researcher3/r20_groetzsch.py`, `r20_w5.py` (`r17_quot.py` 의 F_2 몫 호몰로지 재사용, `r06_lib` 의 B_0 와 축소 호몰로지).
- 기존 파일은 수정하지 않았다.

## 요약
1. **결론: ω=3 반례를 찾지 못했다. 후보 두 개 (W_5, Grötzsch) 는 P3 을 만족한다 (h=3=τ−1).** 두 후보 모두 $\tau=4$ 이고 $h=3$ 이므로 반례가 아니다. 일반적 존재 여부는 미결 (P4).
2. **판정 보조정리 (Gysin 판정) [증명].** $X$ 가 자유 $\mathbb Z_2$-복합체이고 $\tilde H_*(X;\mathbb F_2)$ 가 차원 $d$ 에서만 $\mathbb F_2$ 이며 ($\tilde H_d=\mathbb F_2$, 나머지 0), $Q$ 의 $\mathbb F_2$-호몰로지 차원이 각 $0\le j\le d$ 에서 1 이고 그 밖에서 0 이면, $h(X)=d$. 증명: 이중 피복의 Gysin 열 $\cdots\to H^k(Q)\xrightarrow{\cup x}H^{k+1}(Q)\to H^{k+1}(X)\to\cdots$ 에서 $k=0,1$ 은 $x,x^2\ne0$, $k=2$ 는 $\cup x: H^2\to H^3$ 가 단사이며 차원이 같으므로 동형이고 $x^3\ne0$. 같은 방식으로 $d$ 까지. (차원 $d$ 가 $\mathbb{RP}^d$ 의 몫 패턴과 맞는 경우.)
3. **후보 1: $W_5=C_5+K_1$ ($\omega=3$, $\chi=4$, $\tau=4$).** 계산: $\tilde H_*(B_0W_5;\mathbb F_2)$ 는 차원 3 에서만 1 (계산 확인), $Q$ 의 $\mathbb F_2$-차원 $(1,1,1,1)$ (계산 확인). 보조정리로 $h=3=\tau-1$ [증명]. 따라서 **반례 아님**. 구조적 설명: $B_0(C_5+K_1)\supseteq B_0(C_5)*B_0(K_1)$ (조인 부분복합체, 동변), $B_0(K_1)=S^0$; $B_0(C_5)$ 는 $\tilde H_2$ 만 가지고 몫 패턴 $(1,1,1)$ 이므로 $h(C_5)=2$, 그리고 $S^0$ 와의 조인이 높이를 1 올린다 (예측 P5).
4. **후보 2: Grötzsch $M_4$ ($\omega=2$, $\chi=4$, $\tau=4$ [팀 계산 확인]).** 계산: $\tilde H_*(B_0;\mathbb F_2)$ 는 차원 3 에서만 1, $Q$ 의 $\mathbb F_2$-차원 $(1,1,1,1)$. 보조정리로 $h=3=\tau-1$ [증명]. **반례 아님** (ω=2 에서도).
5. **일반 원리 (정리 아님, 관찰).** 반례 (h≤2, τ=4) 는 $B_0$ 의 $\mathbb F_2$-호몰로지가 구면 패턴을 벗어나거나 몫 패턴이 $\mathbb{RP}^3$ 와 다를 때만 가능하다. 위의 두 후보는 둘 다 구면 패턴이므로 막혔다. 이것이 ω=3 반례 탐색을 "구면 패턴이 아닌 $B_0$" 로 좁히는 근거다.

## 3. 해석과 한계

- **ω=3 반례는 후보 둘에서 나오지 않았다.** W_5 는 조인이라 P5 로 높이가 정상적으로 올라가고, Grötzsch 는 ω=2 라 조인 구조가 없다. 두 경우 모두 $B_0$ 가 구면 패턴이다. 즉 "$\tau=4$ 인데 $h\le2$" 는 $B_0$ 가 $\mathbb F_2$-구면이 아닐 때만 가능하다고 보는 것이 자연스럽다.
- 보조정리 G 는 $\mathbb F_2$-구면 $X$ 에서만 적용된다. 일반 $X$ 에서 $h$ 는 $\mathbb F_2$-호몰로지보다 세밀한 정보 (컵곱) 에 달려 있다. 그래서 P4 는 여전히 열려 있다.
- 한계: W_5, Grötzsch 의 $\mathbb F_2$-호몰로지는 수치 계산 (축소 호몰로지와 몫 호몰로지, 랭크 mod 2) 이고 증명 수준의 검증은 아니다. 다만 Gysin 판정 자체는 증명이다.

## 후속연구 지점
1. **비구면 $B_0$ 를 가진 ω=3 그래프 탐색 (우선순위 1, 이유: P3 반례의 필요 조건을 만족하는 후보는 비구면 $\mathbb F_2$-호몰로지뿐이다 (P4)).** 시작: $\omega=3$, $\chi\ge4$ 인 소형 그래프 (예: Moser spindle 류, 4-색 필요 삼각형 그래프, $C_7$ 의 보 확장) 에서 $\tilde H_*(B_0;\mathbb F_2)$ 를 계산해 구면이 아닌 것을 고른다. 난점: 정점 9 이상은 B_0 가 커서 B0_empty 열거가 무거워진다.
2. **조인 높이 법칙 P5 의 증명 (우선순위 2).** 시작: $X*S^0$ 의 몫 $(X*S^0)/\mathbb Z_2$ 의 Gysin 열이 $h$ 를 1 올림을 보인다 (suspension 의 Thom 동형). 성립하면 $W_5$ 류 조인 후보는 모두 $h=\tau-1$ 로 막힌다 (반례 후보에서 제외).
3. **구면 패턴 판정 자동화 (우선순위 3).** 시작: 임의 $G$ 에 대해 $\tilde H_*(B_0;\mathbb F_2)$ 와 몫 패턴을 계산하고, 구면 패턴이면 P3 을 자동 판정. 비구면이면 후보로 남긴다. 난점: 몫 패턴 판정은 $\mathbb F_2$ 차원만 보므로 $x^n$ 을 직접 계산하지 않는다 (필요 조건 아님, 충분 조건 아님 주의).
4. **Grötzsch 의 $\tau$ 확인 (우선순위 4).** 이유: P2 와 P3 의 Grötzsch 항목은 팀 계산 ($\tau=4$) 에 의존한다. 시작: 호몰로지 기반 하계 ($\tau\ge d+1$ 은 구면 패턴에서 $\operatorname{coind}\ge d$ 가 $\tilde H_d$ 와 연결성으로 나옴) 로 독립 확인.
