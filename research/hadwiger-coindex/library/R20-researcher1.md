# [R20-researcher1] k 개 K_4 블록의 교차 패턴에 걸친 min χ: 항상 4 이다 (k 에 무관), 그리고 4k 상계의 패턴 수준 sharpness

- 작성자·라운드·역할: researcher1 / 라운드 20 / 연구원1 (연속 라운드). 범위: 정점 시트 블록과 교차 간선만.
- 표기: `[증명]` `[계산 확인]` `[추측]` `[망상]` `[기억-미검증]`. 외부 정리 없음 (König 은 R19 에서 이미 사용한 표준 사실로만 쓰고, 이번 결과는 직접 구성으로 증명한다).
- 대조: R19 (k=2 의 임계 |H|=4, 완전 별), R18-r2.

## 요약
1. **[증명] 질문의 문자 그대로의 min 은 자명하게 4 이다.** 교차 패턴 $H=\emptyset$ 이면 $k$ 개의 $K_4$ 의 분리 합이고 $\chi=4$. 따라서 "전체 패턴의 min" 은 k 에 의존하지 않는다. 의미 있는 질문은 **연결된 패턴, 또는 블록 쌍마다 간선이 있는 패턴 (블록 quotient 가 완전)** 에서의 min 이다.
2. **[증명] 이 제약 아래에서도 min χ = 4 이고 k 에 무관하다.** 구성: 블록 $p$ 의 꼭짓점을 $x_{p,1..4}$ 로 두고, 교차 패턴을 "인덱스가 다른 쌍 전부" 로 잡는다. 결과 그래프는 완전 4-부분 그래프 $K_{k,k,k,k}$ 이며 $\chi=4$, $\omega=4$, $\tau=4$. 이 패턴은 블록 쌍마다 $12$ 개의 교차 간선을 가진다.
3. **[증명] 4-색칠의 구조 조건.** $K_4$ 블록을 가진 그래프 $G$ 에 대해 $\chi(G)=4$ $\iff$ $V(G)$ 가 4 개의 독립 집합 $C_1..C_4$ 로 나뉘고 각 $C_c$ 가 모든 블록과 정확히 한 점씩 만난다 (블록-횡단). 동치로, 여집합 $\overline G$ 의 교차 부분에 서로소인 "횡단 클리크" 4 개가 있다.
4. **[증명] (3) 판정.** 4k 는 K_{4k} 에서만 달성된다 (τ=χ=n 이면 완전). 패턴 수준에서 K_4 블록 $k$ 개의 τ 는 $[4,4k]$ 에 걸쳐 있으나, 최댓값에 가까운 패턴을 제외하면 4 로 떨어질 수 있다. 상계 4k 는 함수적으로 최선이지만 패턴적으로는 극단적이다.

## 1. 자명한 min 과 의미 있는 min [증명]
- $H=\emptyset$: $\chi=4$ (분리 합). 따라서 전체 패턴의 min χ = 4, min τ = 4 (τ ≥ ω = 4).
- 그러므로 R18·R19 의 "연결 패턴" 조건이 필요하다. 아래에서는 (a) 연결 패턴 (b) 블록 쌍마다 간선이 있는 패턴 (블록 quotient 가 $K_k$) 둘 다 본다.

## 2. 구성: 완전 4-부분 패턴 [증명]
- 정점 $x_{p,i}$ ($p\in[k]$, $i\in[4]$), 블록 $B_p=\{x_{p,1},\dots,x_{p,4}\}$.
- 간선: $x_{p,i}x_{q,j}\in E$ $\iff$ $i\ne j$ (블록 내부 $p=q$ 포함). 
- 블록 내부: $i\ne j$ 이면 간선이므로 $B_p\cong K_4$ ✓. 교차: $p\ne q$ 에서 $i\ne j$ 인 쌍 (12 개) 이 교차 패턴.
- 이 $G$ 는 완전 4-부분 그래프 $K_{k,k,k,k}$ (부분 $\{x_{p,i}:p\}$ 가 $i$ 번째 부분).
- $\chi(G)=4$ (부분 $i$ 를 색 $i$ 로) , $\omega=4$ (각 블록, 그리고 서로 다른 인덱스의 횡단 4 점). 따라서 $\tau=4$. [증명]
- 연결 패턴이다 (블록 쌍마다 교차 간선). 따라서 (b) 조건에서도 min χ = 4. 또 블록 쌍마다 **최소 한 개** 의 간선만 있는 패턴도 같은 인덱스 규칙 (인덱스가 다른 쌍 하나씩) 으로 χ=4 를 준다 [증명: 부분 집합 제거 단조성 — 간선을 줄이면 χ 는 늘지 않음].

## 3. 색칠 구조와 교차 패턴의 충돌 [증명]
- $\chi(G)=4$ 인 $G$ 에서 각 블록은 4 색 전부를 한 번씩 쓴다 (블록 $K_4$). 색 클래스 $C_c$ 는 독립 집합이며 각 블록과 정확히 한 점씩 만난다 (**횡단 독립 분할**).
- 따라서 교차 패턴의 "충돌" 은 다음이다: 블록 $p$ 와 $q$ 의 $\pi_{pq}$ (색 정렬 전단사) 가 존재하려면 $\overline G$ 에 완전 매칭 (정렬) 이 있어야 하고, 이 정렬들이 $k$ 개 블록에서 **일관** (삼각 조건 $\pi_{pr}=\pi_{qr}\pi_{pq}$) 이어야 한다.
- **완전 패턴 $K_{4k}$:** $\overline G$ 의 교차 부분이 비었으므로 정렬이 없다 — 충돌이 즉시 난다 ($\chi=4k$).
- **$k=2$, 완전 별 (R19 임계):** 별 중심 $b_j$ 가 $B_1$ 전체와 이어지면 $b_j$ 의 허용 색이 없다 (금지판의 한 열 전체) — 같은 충돌의 최소 형태.
- **$K_{k,k,k,k}$:** 정렬이 일관된다 (모든 $\pi_{pq}=\mathrm{id}$ 를 인덱스로 맞춤). 충돌 없음.
- 즉 충돌은 "교차 패턴이 정렬 전단사를 막는 금지 블록을 만들 때" 생기며, 금지 블록의 최소 크기는 $r+s=5$ ($k=2$ 에서 $1\times4$, R19 §2) 이다. 일반 $k$ 에서는 쌍마다 독립적으로 $\overline G$ 의 정렬 전단사 존재 + 삼각 일관성이 필요하다.

## 4. (2) 존재하지 않는 k 의 판정 [증명]
- 어떤 $k\ge2$ 에서도 $\min\chi=4$ 가 달성된다 (§2 의 구성은 모든 $k$). 따라서 "min χ=4 를 달성하지 못하는 $k$" 는 존재하지 않는다. 즉 **min χ 는 k 에 따라 올라가지 않는다.** (상한 없음.)
- 주의: 이것은 블록 쌍마다 간선을 요구하는 최소 조건 하에서이다. "모든 쌍이 완전 교차" 같은 강한 조건에서는 min 이 $4k$ 이다 (그 패턴이 강제됨).

## 5. (3) 4k sharpness 의 패턴 수준 판정
- **함수적 sharpness 유지.** $K_{4k}$ 가 $\chi=4k$ 를 준다 (R16 과 같은 논법: $\chi=n$ 이면 완전). 따라서 $f(k)\ge4k$ 이고 $4k$ 는 최선. [증명]
- **패턴 수준.** K_4 블록 $k$ 개 패턴의 χ 는 $\{4,\dots,4k\}$ 의 어떤 부분에 있고, 최댓값 $4k$ 는 완전 패턴에서만, 최솟값 4 는 빈 패턴과 $K_{k,k,k,k}$ 에서 달성된다. 완전 패턴과 $K_{k,k,k,k}$ 는 모두 블록 쌍마다 교차 간선이 많지만 (16 대 12) 결과는 4 대 $4k$ 로 극단적으로 다르다.
- **따라서** 시트 상계 $4k$ 는 "블록 합" 으로서 최선이지만, 교차 패턴이 $K_{4k}$ 에 가까울 때만 닿는다. 일반 패턴에서 실제 χ, τ 는 4 근처에 머물 수 있다.
- 주의 (R13 연결): $K_{k,k,k,k}$ 는 블록 간 교차가 "인덱스 다름" 이라는 공리를 가지며, 이 공리 아래 상계는 4 이다. 이는 R13 의 "공리가 상계를 바꾸는가" 질문에 대해 교차 패턴 공리 (정렬 가능성) 가 실제로 상계를 바꿀 수 있음을 보인다 — 다만 공리 $X_M$ 등과 다른 종류 ("정렬 일관성") 이다.

## 후속연구 지점
1. **$\tau$ 의 패턴 최솟값 (K_4 블록, 연결).** 이유: 여기서 χ=4 를 보았으므로 τ=4 도 같다 (τ≥ω=4, τ≤χ=4). 그러나 $K_{k,k,k,k}$ 가 아닌 다른 조건 (예: 블록 쌍마다 정확히 한 간선) 의 τ 최솟값은 확인하지 않았다. 시작: 쌍당 한 간선 패턴 (k=3) 의 χ 를 정렬 조건으로 확인 — 이미 χ=4 이므로 τ=4 로 확정된다. 난점: 없음 (χ 쪽에서 정리됨). 남은 과제는 블록이 $K_4$ 가 아닌 경우로 일반화.
2. **블록이 $K_3$ 인 경우의 $K_{k,k,k}$ 구성.** 이유: $K_3$ 블록 $k$ 개에서 $K_{k,k,k}$ (3-부분) 은 χ=3 이고 블록 구조와 같다. 이것이 3k 상계에 주는 의미는 4k 와 평행하다. 시작: $K_{k,k,k}$ 의 τ=3 과 블록 수 $k$ 를 대조 (R16 의 3k 최선 $K_{3k}$ 와 비교). 난점: 없음 (손 확인 가능).
3. **정렬 일관성 조건의 일반 판정.** 이유: §3 의 "삼각 일관성" 이 $k\ge3$ 에서 실제 제약이 되는지 (즉 금지 블록이 있어도 일관 정렬이 가능한 경우) 를 가르는 조건이 필요하다. 시작: 쌍마다 정렬 가능하나 삼각 불일관인 $k=3$ 구성을 찾는다 (존재하면 χ=5 를 강제하는 패턴 족의 최소 예). 난점: 대량 점검 금지, 손 구성 몇 개.
4. **$K_{k,k,k,k}$ 의 τ 가 아닌 zig 와 ι.** 이유: 이번 결과는 χ 와 τ 만 다루었다. zig($K_{k,k,k,k}$) 를 계산하면 zig 판의 sharpness 도 같은 방향인지 (zig ≤ 4 인가) 알 수 있다. 시작: $k=2$ ($K_{2,2,2,2}$) 에서 zig 인증서를 탐색 (8 정점, 소형). 난점: 탐색 크기가 작아 가능하나 대량 확대는 금지.
