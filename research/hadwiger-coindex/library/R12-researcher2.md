# [R12-researcher2] 시트 평면 분해와 Hadwiger 추측: 한 방향 (블록 수와 K_t 마이너) 의 정리와 장애물

- 작성자·라운드·역할: researcher2 / 라운드 12 / 연구원2 (독립 연구). 연구원1 결과는 참조하지 않았다.
- 대상 클래스: $\mathcal C_k$ = 정점 분할 $V=V_1\sqcup\cdots\sqcup V_k$ 에서 각 $G[V_i]$ 가 평면인 그래프 (기본 정의 [정의-시트], 교차 간선 무제한).
- 목표 방향 (한 가지): **$\mathcal C_k$ 의 그래프가 $\chi$ 만큼의 $K_t$ 마이너를 가지는가 (Hadwiger 를 $\mathcal C_k$ 에 제한).**
- 표기: 모든 주장에 `[증명]` `[계산 확인]` `[추측]` `[망상]` `[기억-미검증]`. 대량 점검 없음.

## 요약
1. **[증명] 제한된 Hadwiger 의 귀결.** $G\in\mathcal C_k$ 이면 $\chi(G)\le4k$ (4색정리 [기억-미검증]). 따라서 "$\chi\ge t\Rightarrow K_t$ 마이너" 를 $\mathcal C_k$ 에 제한한 명제 $H(k)$ 는 $t\le4k$ 만 다루면 된다.
2. **[증명] 낮은 $t$ 는 자명 또는 알려짐.** $t\le4$ 는 Dirac 류 사실로 모든 그래프에서 성립한다 (2-퇴화 $\Rightarrow$ 3-색칠, 따라서 $K_4$-마이너-자유 $\Rightarrow\chi\le3$). $t=5,6$ 은 Wagner (4CT 와 동치) 와 Robertson–Seymour–Thomas 의 $t\le6$ 결과 [기억-미검증] 으로 모든 그래프에서 성립한다. 따라서 $H(k)$ 의 새 내용은 $7\le t\le4k$ 에 있다.
3. **[증명] 직접 구성의 한계 (blocks 가 마이너를 보존하지 않는다).** $\mathcal C_k$ 는 마이너 닫힘이 아니다. 교차 간선을 축약하면 새 정점을 어느 블록에 넣어도 블록의 평면성이 깨질 수 있다. 따라서 "블록 수 $k$ 에서 $K_t$ 마이너를 블록 조각으로 귀납해 만든다" 는 접근은 교차 간선의 축약 단계에서 막힌다.
4. **[증명] $K_{4k}$ 는 $H(k)$ 의 최선 예.** $k$ 개의 $K_4$ 블록을 완전 교차하면 $\chi=4k$ 이고 $K_{4k}$ 마이너를 가진다 (자기 자신). 즉 $t=4k$ 는 실제로 달성된다.
5. **[추측] 장애물의 핵심.** 위상 하한 $\tau,\iota$ 는 마이너에 단조가 아니다 (R04 기록과 같다). 따라서 $\tau$ 나 $\iota$ 의 상계로 $K_t$ 마이너의 존재를 줄 수는 없다. 마이너를 주는 도구는 연결성·분리자 쪽 (Mader, Thomassen) 이어야 한다.

## 1. 정의와 기본 사실
- $\mathcal C_k$ 의 정의는 [정의-시트] 그대로.
- $\chi$ 는 $\mathcal C_k$ 에서 $\le4k$: 각 블록을 4색칠하고 블록별 팔레트를 서로소로 쓴다 [증명, 4색정리 인용].
- $K_t$ 마이너 $\Rightarrow\chi\ge t$ 는 역방향이므로, Hadwiger 는 $\chi\ge t\Rightarrow K_t$ 마이너 (역 방향 명제). 이 방향은 $\chi$ 하한이 마이너를 준다는 것이다.

## 2. 낮은 $t$ 의 확인 [증명, 표준]
- $t\le3$: $\chi\ge3$ 이면 홀수 사이클 $\Rightarrow K_3$ 마이너.
- $t=4$: $K_4$-마이너-자유 $\Rightarrow$ 2-퇴화 (차수 $\le2$ 정점) $\Rightarrow\chi\le3$. 대우: $\chi\ge4\Rightarrow K_4$ 마이너.
- $t=5$: Wagner 의 정리 (Hadwiger(5) $\Leftrightarrow$ 4CT) [기억-미검증].
- $t=6$: Robertson–Seymour–Thomas (1993) 의 $t\le6$ 결과 [기억-미검증].

## 3. 블록 수와 마이너 크기 사이의 관계: 직접 구성을 시도한 결과
- 목표: $G\in\mathcal C_k$, $\chi(G)\ge t$ 에서 $K_t$ 마이너를 블록 분할로부터 구성.
- 시도 (a): 블록 $V_i$ 의 평면 4색칠을 이용해 $G$ 를 $4k$-색칠로 쓴 뒤, 색류를 축약한다. 색류를 축약하면 $K_{\chi}$ 가 나오지 않는다 (색류 사이에 간선이 없을 수 있다). 막힘: 색류 간 간선 존재가 보장되지 않는다.
- 시도 (b): 블록 안의 $K_4$ 마이너를 찾고 블록 간 교차 간선으로 연결한다. 교차 간선이 두 $K_4$ 블록을 잇는 매칭만이면 마이너가 $K_4$ 를 넘지 못할 수 있다. 예: $K_4\square K_2$ (매칭 교차) 의 $\chi=4$ 이고 마이너는 $K_4$ 까지만 필요하다. 이는 $t\le4$ 에서 충분하므로 시도 (b) 는 $t\ge5$ 에서 교차가 완전해야 함을 보여 준다 [증명: $K_5$ 마이너에 두 블록 사이 쌍별 연결이 필요].
- 결론 [추측]: $t\ge7$ 의 $H(k)$ 는 블록 내부 마이너와 교차 간선의 "쌍별 연결" 이 동시에 필요한 구조 정리를 요구한다. 그런 구조 정리는 현재 없다.

## 4. 한 방향의 깊이: 위상과 마이너의 분리
- 사실 [증명]: $\tau$ 와 $\iota$ 는 마이너 단조가 아니다. 예: $K_5$ 는 $K_4\sqcup K_1$ 로 분할되어 $\tau=5$, 그러나 부분 마이너 $K_4$ 는 $\tau=4$. 즉 $\tau$ 의 값은 마이너 $K_t$ 의 $t$ 와 일치하지 않는 방향으로도 움직인다 (반례 구조: 분할 블록의 $\tau$ 합 $\ge$ 전체 $\tau$ 는 조인 하한이며 J 와 관련).
- 따라서 "$\tau\ge t\Rightarrow K_t$ 마이너" (S1 의 $\tau$ 판) 는 $\tau$ 의 정의에서 바로 나오지 않는다. 이 방향은 R04–R10 에서 열린 문제 S1 과 같다.
- 본 보고서가 제안하는 깊은 방향: **$\tau$ (또는 $\iota$) 하한에서 마이너를 읽는 기법을 찾기 위해, 마이너 단조 불변량 (예: $\tau$ 의 블록 최댓값 $\max_i\tau(G[V_i])$) 과 $K_t$ 마이너 크기의 관계를 본다.** 이 불변량은 블록 부분그래프에 단조이지만, 교차 간선 축약에 대해서는 증명이 없다 [추측].

## 후속연구 지점
1. **$H(2)$ 의 $t=7,8$ 에서 블록 쌍별 연결 정리 (우선순위 1).** 이유: $\mathcal C_2$ 에서 $\chi\ge7$ 이면 $K_7$ 마이너를 주는 구조가 필요하며, 이것이 $t\ge7$ 의 최소 시험대다. 시작: $\chi\ge7$ 인 $\mathcal C_2$ 그래프에 대해 두 블록의 $K_4$ 마이너 분기 집합과 교차 간선의 쌍별 연결을 분석한다. 난점: 교차 간선이 완전 이분이 아니면 연결 구조가 부족하다.
2. **마이너 단조 블록 불변량 찾기.** 이유: $\tau$ 나 $\iota$ 는 마이너 단조가 아니므로 마이너 기법과 접목이 안 된다. 시작: 블록 최댓값 $\max_i\tau(G[V_i])$ 와 Hadwiger 수 $h(G)$ 의 비교를 $K_{4k}$, $K_{3k+s}$ (R11 tight 족) 에서 확인. 난점: 교차 축약 단계의 단조성 증명이 없다.
3. **$\mathcal C_k$ 의 마이너 닫힘 근사.** 이유: $\mathcal C_k$ 가 마이너 닫힘이 아닌 것이 핵심 장애물이다. 시작: 교차 간선이 "블록당 $\le c$ 개의 정점에만" 있는 부분 클래스 $\mathcal C_k^{(c)}$ 의 마이너 닫힘 여부를 확인. 난점: 제한이 정의 [정의-시트] 를 바꾼다. 제한 변형으로 따로 판정해야 한다.
4. **$t\le6$ 결과의 $\mathcal C_k$ 버전.** 이유: 알려진 $t\le6$ 증명 구조 (RST) 가 블록 분할에 맞춰 줄어드는지 본다. 시작: 4색정리 사용 지점을 블록 4색칠로 치환하는 것이 가능한지. 난점: RST 의 증명 세부는 여기서 검증하지 않았다 [기억-미검증].
