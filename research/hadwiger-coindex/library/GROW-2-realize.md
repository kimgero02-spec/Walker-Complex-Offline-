# GROW-2-realize: d=2 에서 χ=7 의 실현 시도 (결과: 미결, 축소된 문제와 부분 보조정리)

- 작성자·역할: researcher2 (가공, 구성 시도). 한 번만 보고. 계산 없음 (표본 계산 근거 금지).
- 문제: $\mathcal C_2$ 에 $\chi=7$ 인 그래프가 있는가 (T7 의 비공허성). 망상꾼 (REFINE-3-d-topology §3) 의 $d_{\min}=4$ 와 대조.
- 표기: `[증명]` `[추측]` (외부 정리 Thomassen, Voigt 는 `[기억-미검증]`).

## 0. 실패 기준 (먼저)
- **실현:** $G\in\mathcal C_2$, $\chi(G)=7$ 의 명시 구성과 6-색칠 불가 증인.
- **불가:** 모든 $G\in\mathcal C_2$ 에서 $\chi\le6$ 의 증명, 또는 $\chi=7$ 이 $\mathcal C_2$ 에서 가능함을 막는 장애의 증명.
- 결과: 둘 다 달성하지 못함. 아래는 문제를 축소한 결과.

## 1. 상계와 필요조건 (사용 가능한 것)
- $\chi\le d+5$ on $\mathcal C_d$ (REFINE-2-d-value §1, 4CT·Thomassen 인용). $d=2$ 에서 $\chi\le7$. [증명 조건부]
  - T7 단계: 이 상계는 "χ≥8 이면 $K_8$ 류" 를 $\mathcal C_2$ 에서 배제한다 (χ=8 불가능).
- $\chi=7$ 이면 두 블록 중 하나는 4-색 블록, 다른 하나는 χ≥3. [증명, 블록 색 상계]
  - T7 단계: 블록 종류 분류 (K_4 쪽이 필요).

## 2. 축소된 문제 (K_4 블록 경우) [증명 (재서술)]
- $B_1=K_4$ 라 하자. 6-색칠은 $K_4$ 의 정점을 6 색 중 서로 다른 4 색에 대응시키는 단사 $\sigma$ 로 기술된다. $Q=P\setminus\sigma(K_4)$ (크기 2).
- $y\in B_2$ 의 교차 이웃 집합 $N(y)\subseteq K_4$, $|N(y)|\le2$. 리스트는 $L(y)=P\setminus\sigma(N(y))=Q\cup\sigma(K_4\setminus N(y))$.
- 따라서 $\chi(G)=7$ ⇔ 모든 단사 $\sigma$ 에 대해 $B_2$ 가 리스트 $L_\sigma$ 로 색칠되지 않는다. $L_\sigma$ 의 모든 리스트는 공통 2-집합 $Q$ 를 포함한다.
  - T7 단계: K_4 블록 쌍에서의 χ=7 조건을 "단사 σ 에 대한 전부-실패" 로 환원.
- 보조정리 [증명]: $B_2$ 의 정점 $y$ 중 $|N(y)|=0$ 이면 리스트 6, $|N(y)|=1$ 이면 리스트 5, $|N(y)|=2$ 이면 리스트 4 (Q 포함). $|N(y)|\le1$ 인 정점만 있으면 Thomassen (5-선택) 으로 항상 색칠됨 → 실현 불가 (R35 와 일치).
  - T7 단계: 구성에 "차수 2 정점이 반드시 있어야 한다" 는 필요조건.

## 3. 장애 후보와 결론
- 장애는 $|N(y)|=2$ 인 정점들의 부분 $S\subseteq B_2$ 가 4-리스트 (공통 Q 포함) 로 색칠되지 않을 때 생긴다. 평면 그래프가 4-선택 가능하지 않은 예 (Voigt) 가 존재하므로 $S$ 를 그런 그래프로 잡을 수 있는지가 핵심이다 [기억-미검증].
- 그러나 리스트가 공통 Q 를 포함하는 특수 구조에서, Q 두 색으로 $S$ 를 2-분할 가능한지를 먼저 봐야 한다. 이 특수성은 일반 4-선택 불가능과 같지 않다 [추측].
- 미해결: (i) Q-공통 리스트에서의 4-선택 불가능 구조가 존재하는가, (ii) 존재한다면 $|N(y)|=2$ 교차 구조 (B_1 쪽 정점 차수) 가 $B_1=K_4$ 와 양립하는가. $B_1=K_4$ 에서는 $B_1$ 의 정점당 교차 차수 합이 제한되어, (ii) 가 $K_4$ 를 $B_1$ 으로 쓰는 한 불가능할 수 있다 [추측].

## 4. 망상꾼 d=4 와 대조
- 망상꾼 $d_{\min}=4$ (REFINE-3-d-topology §3) 는 **$K_7$ 자체가 $\mathcal C_d$ 의 멤버가 되는 최소 d** 이다. $K_7$ 의 유일한 평면 분할 (4+3) 에서 교차 차수는 3 또는 4 이므로 d=4 가 필요하다. 이 기준은 정확하다.
- 우리 기준 (χ=7 멤버가 존재하는 최소 d) 은 $K_7$ 이 아닌 다른 χ=7 그래프까지 본다. 차이의 원인: 망상꾼은 특정 극값 그래프 (K_7) 의 멤버십을, 우리는 χ 값의 실현을 기준으로 삼았다. 두 기준은 다른 질문에 답하므로 $d=4$ 와 $d=2$ 의 불일치는 모순이 아니다.
- 따라서 "d=2 에서 χ=7 실현" 이 참이면 T7 은 $d=2$ 에서 비공허이고, $d=4$ 는 K_7 의 멤버십 값일 뿐이다. 이 구분을 REFINE-1-decision 에 명시할 것을 제안한다.

## 후속연구 지점
1. **Q-공통 리스트의 4-선택 불가능 구조 (우선순위 1).** 이유: §3 의 핵심. 시작: $B_2$ 의 정점을 $|N|=2$ 로 제한한 부분그래프에서, 공통 2-색 Q 를 쓰지 않고 4-리스트 색칠이 불가능한 최소 구조 확인 (손). 판정: 존재하면 d=2 실현 후보.
2. **$B_1=K_4$ 대신 일반 $B_1$.** 이유: §3 (ii) 의 "K_4 와 양립" 문제가 $B_1$ 을 바꾸면 해소될 수 있다. 시작: $B_1$ 의 정점 교차 차수 합 제한 하에서 6-색칠 σ 의 자유도를 셈.
3. **REFINE-1-decision 에 두 기준 명시.** 이유: 망상꾼 d=4 와 d=2 의 차이를 기준 차이로 정리해야 결정이 흔들리지 않는다. 시작: "K_7 멤버십 d" 와 "χ=7 실현 d" 를 별도 항목으로 기록.
