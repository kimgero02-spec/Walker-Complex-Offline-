# [R13-researcher3] 시트 교차 간선의 분기 피복 번역: 분기 자리 대 접착 차수, 교차 패턴별 예측

- 작성자·라운드·역할: researcher3 / R13 / 망상꾼 (분야: 대수적 위상 · 대수 기하의 분기 피복, Riemann–Hurwitz)
- 지시: 문주님 재배정 (시트 교차 간선을 위상 쪽에서 번역, I-4 분기 피복 우선).
- 표기: 정점 시트 $V=V_1\sqcup V_2$ (블록), 교차 간선 $C\subseteq V_1\times V_2$, 블록 교환 대합 $\sigma$ (고정점 없는 대합, $\sigma(V_1)=V_2$). 몫 그래프 $H=G/\sigma$. 분기 개수 $b$. $\tau=\operatorname{coind}B_0+1$.
- 계산: 이번 라운드는 RH 셈을 손으로 했다 (χ 는 1-복합체의 꼭짓점 − 변). 코드는 쓰지 않았다. 기존 파일 (R07–R12) 은 수정하지 않았다.

## 요약
1. **번역 (§1).** 블록 교환 대합 $\sigma$ 을 고르면 교차 간선은 두 종류로 갈린다. (가) **대각 간선** $\{u,\sigma u\}$: $\sigma$ 가 간선을 뒤집는다 (flip). 몫에서는 **분기 자리** (중점, 분기 지수 2) 가 된다. (나) **비대각 간선** $\{u,\sigma w\}$, $w\ne u$: 짝 $\{w,\sigma u\}$ 와 함께 한 궤도를 이루며, 몫에서 **접착 차수 2** 의 변 (두 시트가 같은 몫 변 위에 겹친다) 이 된다. 블록 내부 간선은 $\sigma$ 에 의해 다른 블록으로 가므로 분기가 없다.
2. **분기 공식 [증명, 1-복합체의 RH].** $\sigma$ 가 고정점이 없으면 $\chi(G)=2\chi(H)-b$, $b=|\{$대각 간선$\}|$. 고정 꼭짓점이 있으면 그것도 분기로 센다. 세 예 ($K_6$, $K_{3,3}$, $C_5[K_2]$) 에서 이 공식이 맞는다 (§3).
3. **중요한 부정 결과 [계산 확인].** 몫 $H$ 가 평면이라도 $\tau(G)\le 4$ 는 나오지 않는다. $K_6$ 는 $\sigma=(03)(14)(25)$ 로 평면 몫 (이중 변 삼각형) 을 가지지만 $\tau(K_6)=6$. 따라서 "평면 기저 위 분기 피복 ⇒ $\tau\le\tau(\text{기저})$" 는 거짓이다 (준동형 단조성은 분기 피복에 적용되지 않는다: 몫의 변이 루프가 되므로 $G\to H$ 가 준동형이 아니다).
4. **이전 예측의 정정.** 앞서 제안된 "$K_5$ 는 평면 기저 위 2겹 분기 피복이 아니다" 는 **거짓**이다. $K_5$ 는 $\sigma=(01)(23)$ (꼭짓점 4 고정) 로 평면 몫을 가진다 (§3, 예측 Q1). 이 정정은 "분기 피복 = 준동형" 이라는 오해를 막는다.
5. **교차 간선이 4k 를 낮추는가 [추측].** 대각 간선만 (매칭) 이면 낮출 수 있다 ($K_4\square K_2$: 8 → 4, R10 과 일치). 비대각 간선이 섞이면 (완전 교차 $K_{4k}$ 처럼) 4k 가 그대로 나온다. 위상적으로는 **대각 간선 = 분기 자리 (새 시트를 만들지 않음), 비대각 간선 = 몫 변의 중복도 (시트를 겹침)** 이고, $\tau$ 를 올리는 것은 중복도이지 분기 자리가 아니다. 단 분기 자리도 $K_6$ 에서 비용 3 을 낸다 (예측 Q7 반증).

## 1. 번역 사전

| 시트·그래프 쪽 | 분기 피복 쪽 | 비고 |
|---|---|---|
| 블록 교환 대합 $\sigma:V_1\leftrightarrow V_2$ | 자유 (또는 분기) $\mathbb Z_2$ 작용 on $G$ | 고정점 없으면 꼭짓점 분기 없음 |
| 대각 교차 간선 $\{u,\sigma u\}$ | 분기 중점 (분기 지수 2, $\sigma$ 가 간선 뒤집기) | RH 의 $b$ 에 해당 |
| 비대각 교차 궤도 $\{u\sigma w,\,w\sigma u\}$ | 몫 $H$ 의 변 1 개 위에 놓인 접착 차수 2 (두 시트) | 몫에서 $\{u,w\}$ 변의 중복도 |
| 블록 내부 간선 $E(G[V_1])$ | 몫의 변 (블록 2 의 대응 변과 짝) | 분기 없음 |
| 몫 $H$ 의 단순화 $H_s$ | 기저 그래프 (평면성 질문의 대상) | $H_s=G[V_1]\cup T_\sigma(C)$, $T_\sigma(C)=\{uw:u\sigma w\in C,\,u\ne w\}$ |
| 평면 블록 $G[V_1]$, $G[V_2]$ | 몫 $H$ 의 평면 부분 (블록 1 과 같은 복사) | 블록 2 는 $\sigma$ 로 블록 1 과 같은 상 |
| 블록 평면성 | $H_s$ 평면성 (필요충분은 아님: 중복도가 $\tau$ 를 올림) | §2 Q2 |

**분기 자리 대 접착 차수 (질문에 대한 답).** 교차 간선은 둘 다다. 대각 간선은 **분기 자리** (ramification, $e=2$ 인 중점), 비대각 간선은 **접착 차수 2** (몫 변의 중복도, unramified). 위상 쪽의 자연스러운 대응은 "대각 = 분기 (B_0 에서 $\sigma$ 고정 단체), 비대각 = 면 (두 시트의 면이 한 몫 면을 덮음)" 이다. 실제로 B_0 에서 고정 단체는 없다 (R08 계산: 고정 비공집합 단체 0), 즉 $\sigma$ 는 $B_0$ 위에 자유 작용한다. 따라서 $B_0$ 의 분기는 0 이고, 분기 자리는 **그래프** 쪽 (몫 1-복합체) 에만 나타난다. 이 구분이 중요하다: 분기 자리는 $\tau$ 를 직접 바꾸지 않을 수 있다 (예측 Q7 이 이를 시험).

## 3. RH 셈 (재확인용 표)

| $G$ | 대합 $\sigma$ | 몫 정점 (블록+고정) | 분기 $b$ | $\chi(G)$ | $2\chi(H)-b$ |
|---|---|---|---|---|---|
| $K_5$ | $(01)(23)$, 4 고정 | 3 + 중점 2 = 5 | 2 중점 + 1 고정 = 3 | $-5$ | $2(-1)-3=-5$ ✓ |
| $K_6$ | $(03)(14)(25)$ | 3 + 중점 3 = 6 | 3 | $-9$ | $2(-3)-3=-9$ ✓ |
| $K_{3,3}$ | $a_i\leftrightarrow b_i$ | 3 + 중점 3 = 6 | 3 | $-3$ | $2\cdot0-3=-3$ ✓ |
| $C_5[K_2]$ | $2i\leftrightarrow 2i+1$ | 5 + 중점 5 = 10 | 5 | $-15$ | $2(-5)-5=-15$ ✓ |

(몫 $\chi$ 은 "정점 − 변" 로 셈, 중점은 정점으로 포함, 펜던트 변은 변으로 포함.)

## 4. 4k 상계에 대한 위상적 예측 (교차 간선의 영향)

- **기본 정의**: 평면 블록 $k$ 개 ⇒ $\tau\le 4k$, 등호 $K_{4k}=kK_4$ (교차 완전). 교차 패턴이 어떤 것이든 $4k$ 는 유지된다 (χ 논법).
- **교차 패턴을 제한하면**: 분기 자리 (대각) 만 있고 중복도 없으면 몫이 블록과 같은 평면 복사이므로 $\tau$ 는 블록 최댓값 쪽으로 간다 (Q5). 이 경우 $4k\to\max\tau_i\le 4$.
- **중복도가 있으면**: 몫 변의 중복도 2 는 두 시트를 같은 몫 변 위에 겹친다. $K_6$ 에서 중복도 2 인 변 3 개가 $\tau$ 를 $3\to 6$ 로 올린다. 즉 **4k 를 낮추는 것은 중복도 제거이고, 분기 자리 제거가 아니다.**
- 예측 (추측): 교차 간선 중 중복도 2 인 몫 변 수 $d_2$ 에 대해 $\tau\le\max_i\tau_i+d_2$ (블록 $K_4$ 2 개 기준). 반증: $d_2=0$ 인데 $\tau>\max_i\tau_i$ 인 교차 패턴. 현재 예: $K_{3,3}$ ($d_2=0$, $\tau=2\le3$) 성립.

## 후속연구 지점
1. **B_0 의 분기 부재 증명 (우선순위 1, 이유: 분기 자리가 $\tau$ 에 비용을 주는지의 기초).** 시작: 블록 교환 $\sigma$ 가 $B_0(G)$ 위에 자유임 (고정 비공집합 단체 없음, R08 계산) 을 일반 그래프에서 증명하고, 이로부터 몫 $B_0/\sigma$ 의 $\chi$ 를 RH 식 $\chi(B_0)=2\chi(B_0/\sigma)$ 로 옮긴다. 난점: $B_0$ 의 면이 $\sigma$ 아래 자유임을 모든 $(A,B)$ 에 대해 확인 (교환이 면을 보존하는지는 $A\times B\subseteq E$ 의 대칭성에서).
2. **Q7 의 반례 탐색 (우선순위 2).** 이유: "분기 비용 1" 이 거짓이면 분기 자리의 $\tau$ 비용이 무엇인지 (블록 수, 중복도?) 가 핵심. 시작: $K_6$ 의 대각 3 개를 하나씩 추가/제거하며 $\tau$ 변화를 측정 (중복도를 고정한 채). 난점: $\tau(\mathrm{oct}+\text{일부 대각})$ 의 값이 필요하다.
3. **중복도 법칙 Q6 의 일반화 (우선순위 3).** 시작: $H_s=K_m$ 에서 이중 변 $d_2=\binom m2$ 인 $G$ (몫이 완전이고 모든 변이 이중) 를 만들어 $\tau=2m$ 인지 확인 ($m=3$: $K_6$, 등호). $m=4$ 는 $K_8$ 과 $\tau=8$ 대조. 난점: $H_s=K_4$ 의 이중화가 블록 평면성 (블록 2 개 $K_4$ 가 평면) 을 유지하는지 점검.
4. **$\sigma$ 선택에 대한 불변성 (우선순위 4).** 이유: 같은 $G$ 에 여러 $\sigma$ 가 있으면 분기 데이터가 다르다 ($K_6$: $(03)(14)(25)$ 와 다른 대합). $\tau$ 는 $\sigma$ 와 무관하므로, 분기 데이터의 최소 $b$ 가 어떤 그래프 불변량인지 (예: $b_{\min}\ge \chi-?$) 를 본다. 난점: 대합의 완전 열거 (정점 $\le 6$ 은 가능, 전수 점검은 연구 원칙상 피함).
