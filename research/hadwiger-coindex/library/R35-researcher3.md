# [R35-researcher3] T7 의 위상 쪽 두 가설: M+ (χ≥7 ⇒ K_7 마이너) 와 M− (반례 존재)

- 작성자·라운드·역할: researcher3 / R35 / 망상꾼 (분야: 대수적 위상수학). 계산 없음 (증명 스케치와 문헌 진술만).
- 대상: 클래스 𝒮 = {G = G_1 ∪ G_2 ∪ H : V = V_1 ⊔ V_2, G[V_1], G[V_2] 평면, H 교차 간선 임의}. 질문 T7: $G\in\mathcal S$, $\chi(G)\ge7$ ⇒ $K_7$ 마이너?
- 표기: τ = coind(B_0)+1, h = SW 높이 (h ≤ coind), $K_t\subseteq G$ ⇒ $h(B_0G)\ge t-1$ (R18, 증명).

## 0. 실패 기준 (먼저)
- **M+ 의 실패**: $G\in\mathcal S$ 에서 $\chi(G)\ge7$ 이고 $K_7$ 마이너가 없는 예가 하나 있으면 M+ 거짓. 증명 수단: 마이너 부재를 보이는 증명 (분기 집합의 불가능성 논법) 과 χ 하한 (색칠 장애) 이 함께 필요.
- **M− 의 실패**: 𝒮 의 모든 χ≥7 그래프가 K_7 마이너를 가진다는 증명이 나오면 M− 거짓 (M+ 참). 위상 쪽에서는 "χ≥7 ⇒ 위상 하계 ≥ 6" 같은 연결이 필요하다.
- 이 기준은 두 가설 모두에 대해 "반례 한 개" 또는 "일반 증명 한 개" 로 정해진다. 통계적 근거는 쓰지 않는다.

## 1. 위상 불변량이 마이너에 대해 주는 것 (사실 목록)
| 불변량 | 주는 것 | 마이너를 함의? |
|---|---|---|
| τ, coind | 부분그래프 단조 (동변 포함), $\tau\le\chi$ | 아니오. 부분그래프 $K_t$ 만 본다 |
| SW 높이 h | $h\le\operatorname{coind}$, $K_t\subseteq G\Rightarrow h\ge t-1$ (R18) | 아니오 (부분그래프만) |
| 블록 Z_2 구조 (B_0(G_i)) | 교차 패턴 없이 블록의 coind 상계 (τ(G_i) ≤ 4 평면) | 아니오 |
| zig (순서 인증서) | $\tau\le\operatorname{zig}\le\chi$, zig 블록 가법 (R14/R15) | 아니오 (zig 는 마이너 단조 아님, R15) |
| Steiner Thm 2 | $\operatorname{zig}\ge t\Rightarrow$ 홀수 $K_{\lfloor t/2\rfloor+1}$ 마이너 | 홀수 $K_4$ 까지 (t=7). $K_7$ 에 미달 |
| Kneser (Steiner Thm 3) | $\operatorname{cd}\ge t\Rightarrow K_t$ 마이너 | τ 로 옮기려면 τ ≤ cd 필요, 방향 반대. 사용 불가 |

결론: 알려진 위상 불변량 중 **K_t 마이너를 직접 만드는 것은 Kneser 경로뿐이고, 그것은 τ 에 쓸 수 없다.** 나머지는 부분그래프 또는 순서 인증서를 통해서만 작동하며 $K_7$ 을 주지 않는다.

## 2. 가설별 한 단계 스케치

**(M+) 의 한 단계 시도.** 목표: $\tau(G)\ge7$ (또는 $h\ge6$) ⇒ $K_7$ 마이너 in 𝒮.
- 단계 A: 완전 교차 (조인) 에서 $\tau=\tau_1+\tau_2$ 가 성립한다고 가정하면 (R14 C2, 조인 하한은 증명, 상한 J 는 열림), 블록 τ 합 ≥ 7 이므로 $(\tau_1,\tau_2)\in\{(4,3),(3,4),(4,4)\}$. 블록 τ=4 는 $K_4$ 마이너 (Dirac, χ≥4 ⇒ K_4 마이너), τ=3 은 홀수 사이클 $K_3$. 조인이므로 $K_7$ (R25). **조인 경우 M+ 성립** [증명, 단 "조인 하한 = 상한" 은 J 에 기대지 않고도 χ 판으로 증명됨 (R25)].
- 단계 B (일반 H 로 확장): 부분 H 에서는 $B_0(G)\subseteq B_0(G_1+G_2)$ (동변 포함) 이므로 τ(G) ≤ τ(조인). 하계 τ(G) ≥ 7 을 블록 값에서 끌어내려면 **교차 패턴이 블록 분기 집합 사이의 인접을 보장** 해야 하는데, 위상 불변량은 그 인접을 보지 못한다 (§1). 따라서 단계 B 는 막힌다.
- 판정: M+ 의 위상 쪽 증명 경로는 "τ 큰 ⇒ 인접 분기 모델" 이라는 **위상-마이너 사전** 이 필요한데, 현재 없다.

**(M−) 의 한 단계 시도.** 목표: $G\in\mathcal S$, χ≥7, $K_7$ 마이너 없음.
- 단계 A: 반례 후보는 χ=7 이면서 블록 χ 합이 tight 하지 않은 교차 패턴 (R25 의 $K_7-e$ 형). 위상 쪽에서는 τ 가 χ 보다 작은 간극 (τ < χ) 을 만들어야 한다. 그러나 χ ≥ 7 이 τ ≥ 7 을 주지 않으므로, 위상 불변량으로 반례를 구성할 수 없다 (M− 의 반례는 χ 판에서 나와야 함).
- 단계 B: χ 판 반례의 마이너 부재 증명은 위상 불변량 밖 (분기 집합 조합론). 위상은 이 부재를 증명하지 않는다.
- 판정: M− 도 위상으로 뒷받침되지 않는다. 다만 τ 판 질문 (τ≥7 ⇒ K_7) 으로 바꾸면 반례는 τ 간극 (τ=7 이면서 마이너 없음) 이어야 하는데, 이 역시 위상 불변량이 마이너를 보지 못하므로 구성 도구가 없다.

## 3. 판정: 어느 쪽이 위상으로 뒷받침되는가
- **둘 다 뒷받침되지 않는다.** 위상 불변량은 부분그래프 단조이고 마이너를 보지 못한다 (§1). 두 가설 모두 "마이너 존재/부재" 를 결정하는 조합 논법이 필요하다.
- **상대 평가.** 위상 쪽에서 보면 M+ 가 더 가깝다: 조인 경우의 M+ 는 위상 (조인 하계, 블록 τ 합) 과 조합 (분기 집합) 이 결합해 증명된다 (R25). M− 를 위상으로 지지하는 근거는 없다. 따라서 **M+ 가 위상과의 접점을 가진 쪽** 이지만, 일반 H 의 M+ 는 여전히 위상 사전의 부재로 막혀 있다.
- 권고: 다음 단계는 "τ 하계가 인접 분기 모델을 만든다" 는 위상-마이너 사전의 존재 여부를 묻는 것이다 (Kneser 경로의 일반화 시도). 이것이 없으면 M+ 도 M− 도 위상 쪽에서는 진행되지 않는다.

## 후속연구 지점
1. **위상-마이너 사전 시도 (우선순위 1; M+ 의 유일한 위상 경로).** 이유: 단계 B 가 막힌 곳이 정확히 이 사전이다. 시작: τ 하계 (또는 h) 가 큰 블록 쌍 조인 아래에서 분기 집합 모델이 교차 간선을 따라 생기는지 조사하는 것을 **정의 수준** 에서 적는다 (계산 없이). 난점: 위상 불변량과 인접 사이의 대응이 정의되어 있지 않다.
2. **Kneser 경로 τ 판 일반화 (우선순위 2).** 이유: Steiner Thm 3 는 $\operatorname{cd}\ge t \Rightarrow K_t$ 로 유일하게 $K_t$ 를 준다. τ 와 cd 의 방향 (cd ≤ τ) 을 뒤집는 조건을 찾을 수 있는지 본다 (특수 족에서만 가능할 수 있음). 난점: 일반 τ ≤ cd 는 거짓으로 보이므로 족 한정이 필요.
3. **M+ / M− 판정 기준의 조합 측 정리 (우선순위 3).** 이유: 두 가설의 반례/증명이 모두 조합 논법을 요구하므로, 위상 쪽에서 확인할 것은 "χ 하계 증인 (색칠 장애) 이 블록 쌍에서 어떤 분기 집합을 강제하는가" 라는 조합 질문으로 넘어간다. 난점: 위상 쪽 담당 범위를 벗어난다. 연구원1 (R25–R26) 과 역할을 나눠 맡는 것이 맞다.
