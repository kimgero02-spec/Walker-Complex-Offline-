## 요약
1. **방법적 정정 [증명].** SW 높이 $h(X)=\max\{n:w_1^n\ne0\}$ 는 $h(X)\le\operatorname{coind}X$ 를 준다 (동변 사상 $X\to S^m$ 이 있으면 $w_1^{m+1}$ 이 0 으로 죽는다 [기억-미검증 표준]). 즉 $h$ 는 $\tau$ 의 **하계**다. 따라서 "SW 판 상계 $2k$" 는 **상계가 아니다**. 블록의 $h_i$ 를 합해도 $\tau$ 의 상계가 나오지 않는다. R16 P2 의 $h\le\sum h_i+(k-1)$ 은 $h$ 의 상계이므로 $\tau$ 에 대한 정보가 없다. 이 점을 R16 의 "k 블록 상계" 해석에서 정정한다.
2. **P3 의 정확한 질문.** P3 = "$h(X(G))\le2$ 이면서 $\tau(G)=4$ 인 $G$ 가 있는가". $h\le\operatorname{coind}=\tau-1=3$ 이므로 $\tau=4$ 와 $h\le2$ 는 **양립한다**. 즉 $C_5[K_2]$ 에서 $h=2$ 가 나오면 "SW 높이 클래스가 $\tau$ 클래스와 다름" 의 반례가 된다. $h=3$ 이면 반례가 아니다.
3. **결정하는 계산 (미완).** $h=3$ 은 $w_1^3\ne0$ in $H^3(X/\mathbb Z_2;\mathbb F_2)$ 을 요구한다. 몫 공간의 $\mathbb F_2$-호몰로지 차원은 $\dim H_3=6\ne0$ (계산 확인), 따라서 "$H^3=0$ 이면 $h\le2$" 같은 값싼 판정은 **결정적이지 않다**. 컵곱 구조 (또는 $x=w_1$ 과 Bockstein 관계 $x^2=\beta x$) 를 셀 수준에서 계산해야 한다. 이번 라운드에서는 구현하지 못했다.
4. **몫 호몰로지 패턴 [계산 확인].** $\dim H_{\tau-1}(X/\mathbb Z_2;\mathbb F_2)\ge1$ 이 $K_3$ ($\tau-1=2$ 에 대응하는 $C_5$ 의 $H_2=1$), $K_{3,3}$ ($H_1=1$), $K_5$ ($H_4=1$), $K_6$ ($H_5=1$), $C_5[K_2]$ ($H_3=6$) 에서 모두 성립. 이것은 P1 로 기록한다.
5. **2-시트 분할 (질문 (2)).** $C_5[K_2]$ 를 두 $C_5$ 블록 (교대 정점) 으로 분할하면 블록 $\tau$ 는 각각 3 이고 블록 SW 높이 (둘 다 $H_2(\text{몫})=1$ 로 $\tau-1=2$ 와 맞음, $h\le2$) 는 2 이다. 블록 합은 $\sum\tau_i=6$ (상계 $3k$), $\sum h_i=4$ (SW 합, 하계 쪽). $\tau(C_5[K_2])=4$ 는 $\sum h_i$ 와 같다. 그러나 $h$ 는 하계이므로 이 일치는 상계 증거가 아니다 (P3, P4).

## 3. 2k 대 3k 에 대한 해석 (질문 (2))

- $C_5$ 블록은 $\tau=3$ (zig 3) 이므로 블록 $\tau$ 합 상계는 $3k$ 다 (R14 zig 가법 [증명] 과 같은 상계). 실제 $\tau(C_5[K_2])=4$ 는 $3k=6$ 보다 작다.
- SW 높이 쪽 값 $\sum h_i=2k=4$ 는 $\tau$ 와 우연히 일치한다. 그러나 $h$ 가 $\tau$ 의 하계이므로 이 일치로 $2k$ 가 상계라고 말할 수 없다. 만약 P2 가 참 ($h=3$) 이면 $\sum h_i=4<h+1$ 이므로 블록 SW 합이 전체 $h$ 를 주지 못한다는 뜻이고, 이는 SW 블록 가법이 실패함을 보인다.
- 결론: 질문 (2) 의 "2k 대 3k" 는 **상계 비교로서는 잘못된 문제다**. 상계 쪽은 블록 $\tau$ 합 ($3k$) 만 있고, 하계 쪽 SW 합 ($2k$) 은 $\tau$ 를 올려 주지 못한다.

## 후속연구 지점
1. **P2 의 컵곱 계산 (우선순위 1, 이유: P3 의 반례 여부를 가르는 유일한 질문).** 시작: $C_5[K_2]$ 의 몫 공간 $Q=X/\mathbb Z_2$ 의 $\mathbb F_2$ 셀 복합체에서 $x\in H^1(Q)$ (이중 피복의 클래스) 를 셀 수준으로 구성하고, $x^3$ 을 Alexander–Whitney 식의 셀 컵곱으로 계산해 $H^3$ 에서 0 인지 본다. 난점: 궤도 셀 복합체의 컵곱 구현 (정렬된 단체 필요). 대안: 바리센트릭 세분 후 불변 정렬이 없으므로 몫 위 $\mathbb Z_4$-계수 Bockstein 으로 간접 판정.
2. **$h$ 의 블록 가법을 쓰지 말 것 (정정 확인, 우선순위 2).** 이유: R16/R17 의 "SW 판 상계" 해석이 상계가 아니라는 정정을 `R16`, `R17` 의 결론에 반영하고, τ 상계는 블록 zig 가법 (R14) 에서만 가져온다. 시작: R16 P2 를 "하계 가법의 상계" 로 재서술.
3. **$h=\tau-1$ 이 되는 그래프 클래스 찾기 (우선순위 3).** 이유: $K_n$ 에서는 $h=\tau-1$ (quotient $\mathbb{RP}^{n-1}$) 이다. 다른 족 (C_5, K_{3,3}) 에서 몫 최고 호몰로지 차원과 $\tau-1$ 이 일치하는지 (P1) 를 넓힌다. 시작: C_7, $\overline{C_7}$ (τ=3 과 4 의 경계) 에서 $H_{\tau-1}(Q)$ 계산.
4. **몫 호몰로지 판정 P1 의 반례 탐색 (우선순위 4).** 시작: $\tau(G)=t$ 가 알려진 작은 그래프 중 $H_{t-1}(Q;\mathbb F_2)=0$ 인 것이 있는지. 전수 점검은 피하고 구조적 후보 (블록 분할 2-3 개, 대칭 그래프) 로 한정.
