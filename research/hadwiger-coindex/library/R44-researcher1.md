# [R44-researcher1] 두 막힘의 처리: 시트 사이 동일시 (측도) 와 분할 구조의 모델 그래프 (리프트)

- 작성자·라운드·역할: researcher1 / R44 (무인 6라운드 중 4) / 연구원1. 방향: 복잡성 환원 $C(G)=(k_V,V)$. 일반 정리만, 계산 없음.
- 입력: R43 (막힘 1: 분할 구조, 막힘 2: 삼각분할 시트).
- 표기: `[증명]` `[추측]`. 층 표기: 연산 층 / 측도 층 / 리프트 층 / 귀납 층.

## 실패 기준 (먼저 적는다)
- **(1) 측도 막힘 해소로 인정:** 시트 평면성과 $k_V$ 를 유지하며 엄밀히 줄어드는 측도와, 그것을 주는 시트 사이 연산의 존재 조건이 증명된다.
- **(2) 분할 구조가 K_t 를 강제한다고 인정:** 분할 구조의 분기 집합만으로 $K_t$ 모델이 구성됨이 증명된다. 반대로 분할 구조의 모델 그래프가 $K_t$-마이너-자유이면 "강제하지 않는다" 로 판정.

## Part 1 — 측도 막힘: 시트 사이 동일시

### 결과 1.1 — 연산의 정의 [증명]
- $u\in V_i$, $v\in V_j$ ($i\ne j$), 비인접. **연산 $\mathrm{Id}_i(u,v)$:** $G/uv$ 를 만들고 합쳐진 점 $w$ 를 시트 $V_i$ 에 둔다 ($V_i'=(V_i\setminus\{u\})\cup\{w\}$, $V_j'=V_j\setminus\{v\}$, 다른 시트 불변).
- 새 시트: $G'[V_i']$ 는 $G[V_i]$ 에서 $u$ 에 간선 $\{ux: x\in N(v)\cap V_i\}$ 를 더한 것과 같다. $G'[V_j']=G[V_j]-v$ (평면). 
- 교차 간선: $v$ 의 $V_j$ 쪽 간선은 $w$–$V_j$ 교차 간선이 되고, $v$ 의 $V_i$ 쪽 교차 간선은 $V_i'$ 의 내부 간선 (또는 $u$ 의 기존 간선과 중복되어 제거) 이 된다.
- *층:* 연산 층.

### 결과 1.2 — 평면성 조건 (D) [증명]
- **조건 (D):** $G[V_i]+\{ux: x\in N(v)\cap V_i\}$ 가 평면.
- **정리.** (D) 이면 $\mathrm{Id}_i(u,v)$ 는 모든 시트를 평면으로 유지하고 $k_V$ 를 늘리지 않으며 정점 수를 1 줄인다. 따라서 사전식 측도 $(k_V,n)$ 이 엄밀히 줄어든다. 또한 χ 는 줄지 않는다 (R42 정리 1.1). ∎
- **충분 조건 [증명].** (D1) $N(v)\cap V_i=\emptyset$ ($v$ 가 $V_i$ 에 교차 이웃이 없음): 추가 간선이 없어 (D) 자명. (D2) $N(v)\cap V_i\subseteq N(u)$: 추가 간선이 모두 기존 간선과 중복되어 (D) 자명.
- **측도 $(k_V,|H|,n)$ 의 필요성 판정 [증명].** $(k_V,n)$ 만으로 충분하다 (n 이 매번 감소). $|H|$ 성분은 필요 없다. (D2) 아래에서는 $|H|$ 도 줄지만 ($v$ 의 $V_i$ 쪽 교차 간선이 사라짐) 측도로 쓸 필요는 없다.
- *층:* 측도 층. R43 막힘 2 (삼각분할 시트) 는 이 연산으로 우회된다 — 단, (D) 가 성립하는 쌍이 있을 때.

### 결과 1.3 — 남는 막힘: 교차 포화 구조 [증명]
- (D) 가 어떤 $(u,v,i)$ 에도 성립하지 않는 경우가 새 막힘이다: 모든 비인접 $u\in V_i$, $v\in V_j$ 와 두 배치 방향 ($w$ 를 $V_i$ 또는 $V_j$ 에) 에 대해, 추가 간선이 시트 평면성을 깬다. 특히 (D1) 이 실패하려면 **모든 정점이 다른 시트에 교차 이웃을 가진다** (교차 지배). 
- 극소 반례가 이 구조를 가질 수 없다는 증명은 없다. 삼각분할 시트는 간선 추가로 평면성이 깨지기 쉬우므로 (D) 의 실패와 정합한다 [추측].
- *층:* 측도 층 (새 막힘).

## Part 2 — 리프트 막힘: 분할 구조는 K_t 를 강제하지 않는다

### 결과 2.1 — 분할 구조의 모델 그래프 [증명]
- R43 정리 2.2 의 분할 구조: 분기 집합 $A$, $B$, $Y_2..Y_t$; $Y_j$ 끼리 쌍별 인접; $A\not\sim B$; $A$ 는 $J_A$ 의 $Y_j$ 와, $B$ 는 $J_B$ 의 $Y_j$ 와 인접; $J_A\cup J_B=\{2..t\}$; $J_A,J_B$ 진부분집합.
- 분기 집합을 점으로 줄인 **모델 그래프** $F$: 정점 $a,b,y_2..y_t$; $y$ 끼리 완전 ($K_{t-1}$); $a\sim y_j \iff j\in J_A$; $b\sim y_j\iff j\in J_B$; $a\not\sim b$. $|V(F)|=t+1$.
- *층:* 리프트 층.

### 결과 2.2 — $F$ 는 $K_t$-마이너-자유 [증명]
- $t+1$ 정점 그래프의 $K_t$ 마이너는 (i) 한 점 삭제 후 나머지가 $K_t$, 또는 (ii) 한 간선 (크기 2 분기 집합) 축약 후 $K_t$ 중 하나이다.
  - (i) $a$ 삭제: $b$ 가 모든 $y$ 와 인접해야 함 → $J_B$ 전체, 모순. $b$ 삭제 대칭. $y_m$ 삭제: $a,b$ 가 남아 비인접 → 불가.
  - (ii) 쌍 $\{a,b\}$: 간선 아님. 쌍 $\{a,y_m\}$: 나머지 $b$ 가 모든 $y_j$ ($j\ne m$) 와 쌍 $\{a,y_m\}$ 에 인접해야 함. $J_B$ 가 진부분집합이므로 $J_B=\{2..t\}\setminus\{m\}$ 이어야 하고, 그러면 $b\not\sim y_m$, $b\not\sim a$ 이므로 쌍과 인접 불가. 쌍 $\{b,y_m\}$ 대칭. 쌍 $\{y_m,y_l\}$: $a,b$ 가 남아 비인접 → 불가.
  - 따라서 $F$ 는 $K_t$ 마이너를 갖지 않는다. ∎
- **따름 2.3 [증명].** $\chi(F)=t-1$: $a$ 는 $J_A$ 밖의 $y$ 색을, $b$ 는 $J_B$ 밖의 $y$ 색을 쓸 수 있다. 따라서 $F$ 는 χ 쪽으로도 모순을 주지 않는다.
- **판정.** 분할 구조는 **스스로 $K_t$ 를 강제하지 않는다.** 분할 구조의 분기 집합만으로 만든 그래프는 $K_t$-마이너-자유이고 $(t-1)$-색칠 가능하다. 리프트를 얻으려면 분할 구조 밖의 $G$ 의 정보 (분리 집합의 내부 구조, 다른 공통 면 쌍) 를 써야 한다.
- *층:* 리프트 층.

### 결과 2.4 — 분할 구조에서 얻을 수 있는 최선 [증명]
- $m\in J_A\cap J_B$ 이면 $X=A\cup B\cup Y_m$ 은 연결이고 모든 $Y_j$ ($j\ne m$) 와 인접하므로 $\{X\}\cup\{Y_j\}_{j\ne m}$ 은 $K_{t-1}$ 모델이다. $J_A\cap J_B=\emptyset$ 이어도 $Y_2..Y_t$ 자체가 $K_{t-1}$ 이다. 따라서 분할 구조는 $K_{t-1}$ 만 보장한다 (정리 2.2 와 정합). 
- *층:* 리프트 층 (손실 1).

## Part 3 — 귀납 층 판정 [증명]
- (1) 측도 막힘은 조건 (D) 가 있는 쌍에서 해소된다 (결과 1.2). 남는 막힘은 교차 포화 구조 (결과 1.3).
- (2) 리프트 막힘은 분할 구조만으로 해소되지 않는다 (결과 2.2). 리프트에는 $G$ 의 추가 구조가 필요하다.
- 따라서 무손실 귀납은 여전히 **리프트 단계에서 막힌다.** 분할 구조가 나타나면 $K_{t-1}$ 까지만 보장된다 (결과 2.4, 손실 1).

## 마지막 절: 후속연구 지점
1. **분할 구조 + 분리 집합의 내부 (우선순위 1).** 이유: 결과 2.2 로 분할 구조만으로는 부족하다. 시작: 분리 집합 $S=\bigcup_{j\ge2}Y_j$ 의 정점들 가운데 $A$ 와 $B$ 양쪽에 인접한 정점 $s\in Y_m$ ($m\notin J_A\cap J_B$ 인 경우 포함) 을 찾아 $Y_m$ 을 쪼개는 재배치가 $K_t$ 를 주는 조건 판정. 난점: $Y_m$ 을 쪼개면 $Y_m$ 의 인접이 깨질 수 있다.
2. **다른 쌍 선택으로 분할 구조 회피.** 이유: 리프트 실패는 특정 $(u,v)$ 에 대한 것이다. 시작: 분할 구조가 모든 공통 면 쌍 (및 (D) 를 만족하는 시트 사이 쌍) 에서 동시에 나타날 수 있는지, 두 쌍의 분할 구조를 겹치는 논법으로 판정. 난점: 쌍마다 모델 $\mathcal Y$ 가 다르다.
3. **교차 포화 구조의 χ.** 이유: (D) 가 모두 실패하는 구조가 χ≥t 와 양립하는지가 측도 막힘의 핵심이다. 시작: 교차 지배 (모든 정점이 다른 시트에 이웃) 와 시트 평면성에서 색칠 상계를 유도 (리스트 색칠, REFINE-1-decision §1 형). 난점: 교차 차수가 무제한이면 리스트 크기가 줄어든다.
