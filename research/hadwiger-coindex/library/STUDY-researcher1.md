## 요약

2. **정리 3 (cd ≥ t ⇒ K_t 마이너) 는 τ 로 옮겨지지 않는다 [증명 + 문헌 확인]**: 증명은 Kneser 표현 (정점 = 초변, 인접 = 서로소) 의 조합 구조에만 의존한다. 방향상 τ ≥ t 는 cd ≥ t 를 주지 않으므로, τ 에 쓰려면 반대 방향 부등식 τ ≤ cd 가 필요한데 그림에는 없다.
3. **정리 2 (zig ≥ t ⇒ 홀수 K_{⌊t/2⌋+1}) 는 τ 에 적용된다 [문헌 확인 + 인용 의존]**: 그림 1 의 사슬에서 τ ≤ zig ≤ χ. 다만 결론은 K_t 가 아니라 **홀수 K_{⌊t/2⌋+1}** 이다. 사슬의 각 부등식 자체는 논문이 증명하지 않고 [3], [14] 에서 인용한다.

### A. 정의 (Definition 1, 3쪽) [문헌 확인]

- B_0(G): 정점 집합 V(G)×{1,2}. X ⊆ V(G)×{1,2} 가 B_0(G) 의 면 ⇔ 두 투영 X_1, X_2 가 서로 완전 연결 (한쪽이 비어도 됨).
- B(G): B_0(G) 의 면이면서, 추가로 X_1 과 X_2 각각이 공통 이웃을 가짐.
- 우리 `problem.md` 의 작업 정의 (A×B ⊆ E, A 또는 B 공집합 허용, Z_2 는 두 복사본 교환) 와 **B_0 는 같다**. 사소한 점: 논문은 X_1 ∩ X_2 = ∅ 를 명시하지 않는데, 그래프에 루프가 없으므로 자동으로 성립한다 [증명].
- τ 는 B(G) 를 쓰지 않는다.
- 논문은 coind, ind 의 부호 규약을 정의하지 않는다 [확인 불가]. τ(K_n)=n 과 맞으려면 coind(S^d)=d 규약 (Z_2-사상 S^d → X 가 존재하는 최대 d) 이 필요하다 [기억-미검증]. `problem.md` 의 B_0(K_n) ≅ S^{n-1} 계산이 이 규약과 맞는다.

### C. 정리 3 (Kneser 표현 cd ≥ t ⇒ K_t) 의 증명 재구성 (8–9쪽) [증명]

전제: 𝓗 = (V, E) 가 G 의 Kneser 표현 (G = KG(𝓗), 즉 G 의 정점 = 𝓗 의 초변 E, G 에서 두 초변이 인접 ⇔ 서로소), cd(𝓗) ≥ t.

- **단계 1 (8쪽 하단)**: U ⊆ V 를 H−U 가 2-색칠 가능인 최소 집합으로 잡는다. 그러면 |U| = cd(𝓗) ≥ t. 색 류를 X_1, X_2 라 한다.
- **단계 2 (Claim 1, 8쪽)**: 모든 u ∈ U, i ∈ {1,2} 에 대해 u ∈ e ⊆ X_i ∪ {u} 인 초변 e 가 존재한다.
  - 반증: 없다면 색 류 (X_i ∪ {u}, X_{3−i}) 가 V∖(U∖{u}) 의 2-색칠이 되어 최소성에 모순 [증명 — 직접 점검함].
- **단계 3**: U_1 = {u ∈ U : {u} ∈ E}, U_2 = U∖U_1. u ∈ U_2 에 대해 e(u,i) ⊆ X_i ∪ {u} (u ∈ e(u,i)) 를 고른다. {u} ∉ E 이므로 e(u,i) ∩ X_i ≠ ∅ [증명].
- **단계 4**: 집합 S = {{u} : u ∈ U_1} ∪ {{u,u'}: u≠u' ∈ U_1} ∪ {e(u,i): u ∈ U_2, i} 의 원소들은 서로 다르다 [증명: e(u,1) 은 X_1 의 원소를 갖고 e(u,2) 는 갖지 않는다 등].
- **단계 5 (H ⊆ G 간선 확인)**: 아래 쌍이 모두 서로소이므로 G 에서 인접하다 [증명]:
  - (a) U_1 의 원소끼리: {u}, {u'} 및 {u,u'} 관계 (U_1 은 클리크).
  - (b) u_1 ∈ U_1, u_2 ∈ U_2, i: {u_1} ∩ e(u_2,i) ⊆ U_1 ∩ (X_i ∪ {u_2}) = ∅.
  - (c) u ≠ u' ∈ U_2, i ≠ j: e(u,i) ∩ e(u',j) ⊆ (X_i ∪ {u}) ∩ (X_j ∪ {u'}) = ∅.
  - 결과: H ⊆ K_{|U_1|} + K*_{|U_2|,|U_2|} (K* 는 완전 이분 그래프에서 완전 매칭을 뺀 것, + 는 join).
- **단계 6 (Claim 2, 9쪽)**: n_1 + n_2 ≥ t 이면 K_{n_1} + K*_{n_2,n_2} 는 K_{n_1+n_2} 마이너를 갖는다 [증명].
  - n_2 ≥ 3: 매칭 M = {(x,1)(x+1,2)} ∪ {(n_1+n_2,1)(n_1+1,2)} 를 축약하면 K_{n_2} 가 나온다 (두 병합 정점 m_x, m_y 사이에는 (x,1)~(y+1,2) 또는 (y,1)~(x+1,2) 중 하나가 항상 있다).
  - n_2 = 2: K*_{2,2} 는 간선 2개이므로 각각 축약하면 K_2 이다.
  - n_2 = 1: K*_{1,1} 는 독립 2점이고, 한 점을 다른 점의 이웃에 축약하면 K_{n_1+1}.
  - K_{n_1} + K_{n_2} = K_{n_1+n_2}.
- **결론**: |U_1| + |U_2| = |U| ≥ t 이므로 H ⊆ G 에 K_t 마이너.

**Kneser 전용 부분 (τ 로 옮길 수 없는 부분)**:
1. 단계 1–2 의 "최소 U" 와 "2-색칠" 은 hypergraph 의 조합 정의이다. cd 는 조합적 최솟값이고, τ 는 위상적 불변량 coind(B_0) 이다. 둘을 잇는 것은 그림 1 의 cd ≤ τ 뿐이다.
2. 단계 2–5 는 "G 의 정점 = 초변, 인접 = 서로소" 를 전제한다. 그래서 임의의 G 에 대해서는 이 틀을 만들 수 없다. 임의 G 에서 τ(G) ≥ t 로부터 Kneser 표현 𝓗 를 얻어 cd(𝓗) ≥ t 를 보장하는 방법이 필요하지만, 논문에도 우리 쪽에도 없다.
3. 따라서 **τ ≥ t ⇒ K_t 는 이 증명 경로로 나오지 않는다** [증명]. 필요한 것은 τ ≤ cd 인데 그림 1 은 반대 방향을 준다.

### D. 정리 2 (zig ≥ t ⇒ 홀수 K_{⌊t/2⌋+1}) 의 증명 (7–8쪽)

- 입력: 적절 색칠 c 의 zigzag z_1,…,z_{2k−2} (t = 2k−2 로 축소 가능, t 가 홀수면 ⌊t/2⌋+1 이 같으므로 짝수 경우로 충분 [증명]).
- Lemma 5 (논문 [25] 의 Lemma 4 에서 가져옴, 본문에서 "그대로 성립" 이라 함): V(G) 의 분할 X_1,…,X_n, 각 G[X_i] 는 연결 이분, 그리고 v 가 X_j 에 이웃이 있으면 X_i 의 두 측 모두에 이웃이 있다 [세부 증명 생략, 인용].
- 색 c(x) = 2η(x)−1 (x ∈ A_η) 또는 2η(x) (x ∈ B_η) 는 적절 색칠 [증명 — 같은 X_i 내 인접은 다른 측, 다른 X_j 간 인접은 측이 다르면 색 차 ≥ 1 이지만 서로 다른 색 집합이므로 확인은 논문 정의에 따름].
- 매칭 M = {z_i z_j : η(z_i) = η(z_j)} 는 Z_1–Z_2 사이 이분 간선이고, j = i+1 이며 서로 겹치지 않는다 [증명 — 엄격 증가 색 때문에 한 η 당 연속 두 정점 이하].
- Case 1 (|M| ≤ k−2): M 을 완전 매칭 M' 으로 확장하고 트리 T'_1, …, T'_k 를 조립한다. 세부 색인 (각 쌍의 단색 간선 존재) 은 **[추측: 세부 미검증]**. 구조는 Claim (*) 과 Obs 1 로 정리된다.
- Case 2 (|M| = k−1): T'_1,…,T'_k 중 두 개는 단일 정점, 나머지는 트리. 단색 간선을 직접 확인 [구조 확인 — 8쪽 상단 본문 읽음].
- 결론: 홀수 K_k-확장 → Obs 1 로 홀수 K_k 마이너, k = ⌊t/2⌋+1 [증명 (구조)].
- 주의: 이 증명은 zigzag (순수 조합) 에만 의존한다. 위상은 "τ ≤ zig" 사슬에만 쓰인다.

### E. 정리 4 (Schrijver S(n,k) 의 홀수 K_{n−2k+2}) 와 n=14, k=4 예시 [증명 + 계산 확인]

- 정의 (6쪽): S(n,k) 는 K(n,k) 의 부분그래프, 정점은 [n] 의 순환 안정 k-부분집합 (연속 원소 쌍 없음, 순환 기준 1 과 n 도 연속), 인접 = 서로소.
- 증명 구성 (9–11쪽):
  - 𝒜 = S(2k−1,k−1) 의 정점 (2k−1 개 [증명: (2k−1)/k · C(k,k−1) = 2k−1], 2-정칙 연결이므로 홀수 사이클 C_{2k−1}).
  - 색: c(A_0) = 1 (A_0 = {2,4,…,2k−2}), A ≠ A_0 이면 1 ∈ A 이고 2k−1 ∉ A 일 때 1, 1 ∉ A 이고 2k−1 ∈ A 일 때 2.
  - 트리: T_i (i = 1,…,n−2k) 는 정점 {A ∪ {i+c(A)+2k−2}} 로 된 경로 (2k−1 정점). 1-색과 2-색은 c 로 준다.
  - 추가 단일 정점 트리: T_{n−2k+1} = {1,3,…,2k−1}, T_{n−2k+2} = {2,4,…,2k−2, n}.
  - 쌍별 단색 간선: 서로 다른 i<j 에 대해 A_0∪{i+2k−1} (T_i, 색 1) 과 A_1∪{j+2k−1} (T_j, 색 1) 이 서로소 [증명]. 단일 정점 트리와의 간선도 같은 식으로 확인된다 [증명].
- **n=14, k=4 수치 확인 [계산 확인, 손계산]**:
  - 𝒜 = S(7,3) 의 7 정점: {2,4,6}(A_0, c=1), {3,5,7}(c=2), {1,4,6}(c=1), {2,5,7}(c=2), {1,3,6}(c=1), {2,4,7}(c=2), {1,3,5}(c=1). 논문 10쪽 목록과 일치.
  - n−2k = 6 개의 경로 T_1,…,T_6 (각 7 정점), 추가로 T_7 = {1,3,5,7}, T_8 = {2,4,6,14}. 총 8 트리, 홀수 K_8 확장 → χ(S(14,4)) = 8 과 일치 [계산 확인].
  - T_1: {2,4,6,8}–{3,5,7,9}–{1,4,6,8}–{2,5,7,9}–{1,3,6,8}–{2,4,7,9}–{1,3,5,8}. 인접 쌍은 서로소, 경로 모양 확인 [계산 확인]. 색 1 의 정점은 {2,4,6,8}, {1,4,6,8}, {1,3,6,8}, {1,3,5,8} (1+c+6 = 8).
  - T_6 의 색 예: {2,4,6,13} (c=1: 6+1+6=13), {3,5,7,14} (c=2: 6+2+6=14).
  - 간선 예: T_1 의 {2,4,6,8} 과 T_2 의 {1,3,5,9} (색 1 끼리) 서로소 → 단색 간선 [계산 확인].
  - T_7 과 T_8: {1,3,5,7} 과 {2,4,6,14} 서로소, 둘 다 색 1 → 단색 간선 [계산 확인].
  - 논문 Figure 2 (10쪽) 의 T_i 목록과 색 (빨강 = 2, 파랑 = 1) 이 위 계산과 일치 [문헌 확인].
- 결과: 8 트리가 서로소, 쌍별 단색 간선 → 홀수 K_8 확장 → 홀수 K_8 마이너 [증명 by Obs 1].
- 소소한 점: 증명은 k ≥ 2 를 암묵 전제한다. k = 1 은 S(n,1) = K_n 이므로 자명하다 [증명].
- 이 정리는 odd K_{χ(S(n,k))} 를 준다 (χ(S(n,k)) = n−2k+2 는 Lovász, Schrijver [21] 로 인용) [문헌 인용]. 그러나 τ(S(n,k)) 이 n−2k+2 인지는 이 논문이 주지 않는다.

## 우리 τ 과제와의 관계

| 명제 | 이 논문으로 | 근거 |
|---|---|---|
| S1: τ ≥ t ⇒ K_t 마이너 | **얻어지지 않음** | 정리 3 은 cd 에 대해서만. τ ≤ cd 가 필요하나 그림은 반대 방향 [증명 + 문헌 확인] |
| S2: τ ≥ t ⇒ 홀수 K_t | **얻어지지 않음** | 정리 2 는 홀수 K_{⌊t/2⌋+1} 까지 [증명] |
| S3: τ ≥ t ⇒ 홀수 K_{⌊t/2⌋+1} | **성립 (인용 의존)** | τ ≤ zig (그림 1 사슬) + 정리 2 [문헌 확인 + 인용] |
| S4 (Hajós형), S5 (이머전) | 이 논문에 없음 | — |
| S6 (변형 비교) | 그림 1 로 부분 답: τ ≤ ch-ind(B_0)+1 ≤ ind(B_0)+1 ≤ … ≤ zig ≤ χ; τ ≥ coind(B)+2, conn(B_0)+2 | 그림 1 판독 [문헌 확인] |
| Schrijver/Kneser 에서 odd Hadwiger | 정리 4 로 odd K_{χ} 성립 | 증명 직접 확인 [증명] — 단 τ 가 χ 와 같은지는 별개 |

- `problem.md` 의 "Dol'nikov–Kříž 하한이 ≥ t 이면 K_t (정리 1, 정리 3)" 는 맞지만, τ 와는 직접 연결되지 않는다.
- Kneser 표현 아래 cd = τ 가 되는 그래프족이 있으면 정리 3 이 τ 에 적용된다 (그 경우 S1 이 Kneser 형태 그래프에서 성립). 이것이 이 논문이 우리 과제에 줄 수 있는 가장 직접적인 수단이다 [추측].

## 문주님께 요청

- **[보통, 낮은 긴급도] Daneshpajouh–Meunier, "Box complexes: at the crossroads of graph theory and topology", arXiv:2307.00299 원문 (PDF)**. 이유: 그림 1 의 사슬 부등식 (특히 τ ≤ ch-ind_{Z_2}(B_0)+1 ≤ ind(B_0)+1 와 대각 화살표) 은 여기서 인용되므로 원문 확인이 필요하다. 없을 때 대안: 이 논문 3쪽 Figure 1 과 4–5쪽 본문 (zig 가 가장 강함) 으로 S3 의 근거는 이미 확보되어 있다. 사슬의 세부 인용만 [문헌 인용]으로 남는다.
- **[보통, 낮은 긴급도] Matoušek–Ziegler, "Topological lower bounds for the chromatic number: a hierarchy", Jahresberichte DMV 106 (2004) 의 coind, ind 부호 규약 발췌**. 이유: 논문은 coind 를 정의하지 않는다. 우리의 τ(K_n) = n 과 규약을 맞추려면 확인이 필요하다. 없을 때 대안: `problem.md` 의 B_0(K_n) ≅ S^{n−1} 계산을 규약 coind(S^d)=d 로 가정 (기억-미검증으로 표시).

## 후속연구 지점

1. **[우선순위 높음] τ = cd 가 되는 그래프족 탐색 (정리 3 의 τ 판 가능성)**
   - 이유: 정리 3 의 증명은 Kneser 표현의 cd 에만 쓰인다. τ 가 이 증명으로 K_t 를 주려면 τ(G) ≥ t 에서 cd(𝓗) ≥ t 인 Kneser 표현 𝓗 를 얻어야 하고, 그러려면 τ ≤ cd 가 필요하다. 그림 1 은 반대만 준다.
   - 시작 방법: Kneser 그래프 K(n,k) 의 작은 경우 (예: K(4,1), K(5,2)) 에서 Dol'nikov–Kříž 값 cd(𝓗) 와 coind(B_0) 를 손계산으로 비교. 두 값이 같은 경우와 다른 경우를 찾는다. 이 계산은 반례 탐색 목적이며 대량 점검으로 쓰지 않는다.
   - 난점: τ ≤ cd 를 일반적으로 기대하기 어렵다 [추측]. 특정 족에서 등호를 보이는 것도 위상 계산이 필요하다.
2. **[우선순위 높음] 정리 2 의 τ 판에서 K_t 를 얻는 방향의 한계 확인**
   - 이유: 정리 2 는 홀수 K_{⌊t/2⌋+1} 까지만 준다. 논문의 Problem 1 (zig 에서 홀수 K_{ct} 를 줄 수 있는지) 은 논문 5쪽에서 제기되었고 이 논문이 c=1/2 만 답했다. τ 는 zig 보다 약하므로 같은 한계가 있다.
   - 시작 방법: 정리 2 의 Case 1 과 Case 2 를 보고, 어떤 단계에서 절반이 되는지 (𝒵_1, 𝒵_2 가 K_{k−1,k−1} 이고 매칭 M 이 크기 k−1 까지) 를 확인한다.
   - 난점: 개선이 Steiner 의 zigzag 방법 밖에서 필요할 수 있다 [추측].
3. **[우선순위 중간] τ(S(n,k)) 계산 (Schrijver 그래프)**
   - 이유: 정리 4 는 odd K_{n−2k+2} 를 준다. τ(S(n,k)) = n−2k+2 이면 S1 과 S2 가 S(n,k) 에서 성립한다. 논문은 τ 에 대해 말하지 않는다.
   - 시작 방법: 가장 작은 경우 S(2k−1,k−1) = C_{2k−1} 에서 τ 를 계산 (τ(C_{2k+1}) = 3 점검과 같은 계열). 그다음 S(n,k) 에서 B_0 의 coindex 를 확인.
   - 난점: coindex 계산은 위상 계산이 필요하고 손계산이 어렵다 [추측].
4. **[우선순위 중간] 정리 3 의 Claim 1 에 해당하는 τ 쪽 구조 찾기**
   - 이유: Claim 1 은 "최소 U 의 각 원소가 X_i 와 함께 초변을 만든다" 는 조합 사실이다. τ 에 대응하는 "최소 원소" (예: B_0 의 면 구조에서 Z_2-불가능성을 깨는 최소 정점 집합) 를 정의할 수 있으면 같은 골격을 쓸 수 있다.
   - 시작 방법: 작은 G (C_5, K_4 등) 에서 B_0(G) 의 Z_2-위상 조건을 나열하고, 정리 3 의 U 에 해당하는 것이 무엇인지 확인한다.
   - 난점: τ 는 위상 불변량이어서 Claim 1 의 조합 논증이 그대로 옮겨지지 않을 가능성이 크다 [추측].
5. **[즉시, 오케스트레이터 작업] `problem.md` 31행 (S6) 의 옛 오프셋 정정**
