# [R38-researcher3] "3중 공통 이웃 없는" K_t 모델 정의: 판정 (자기모순)

- 작성자·역할: researcher3 (망상꾼). 한 번만 보고. 계산 없음 (논리 판정).
- 렌즈 예측의 어느 단계: LENS-3 예측 3 / R37 §3 의 **접착 (쌍별 인접) 단계** 에 쓸 모델 정의의 존재 판정.

## 0. 실패 기준 (먼저)
- 정의 후보 **D1** ("쌍별 인접 + 3중 공통 이웃 없음") 이 성립하려면, 그 정의를 만족하는 K_t 모델이 **임의의 K_t 부분그래프 (t≥3) 에 대해서도** 존재해야 한다. 실패 = K_t 자체 (분기 집합 = 단일 정점) 가 D1 을 만족하지 않는다는 증명 한 개.
- D1 이 깨지면 R37 §3 의 "근방 nerve 의 1-골격 보존 + 고차 자유도 조건부" 판정은 **실질적으로 쓸 수 없는 조건** 으로 판정된다.

## 1. 정의 (D1)
모델 $(B_1,\dots,B_t)$ (분기 집합, 연결, 쌍별 인접) 에 대해 "3중 공통 이웃 없음": 모든 정점 $x\in V(G)$ 에 대해 $x$ 가 $N[B_i]$ 에 속하는 $i$ 의 개수가 $\le2$. (닫힌 근방 $N[B_i]=B_i\cup N(B_i)$ 의 세 교집합이 공집합.)

## 2. 판정: D1 은 모든 $t\ge3$ 에서 실패 [증명, 한 단계]
- 모델을 **단일 정점 분기 집합** 으로 잡은 K_t 자체 (G = K_t, $B_i=\{v_i\}$) 를 생각한다.
- 세 정점 $v_1,v_2,v_3$ (t≥3) 에 대해 $v_1\in N[B_1]$, $v_1\in N[B_2]$ (v_1 ∼ v_2), $v_1\in N[B_3]$ (v_1 ∼ v_3). 즉 $v_1$ 은 세 근방 모두에 속한다. 따라서 D1 의 "x 가 ≤2 개의 근방에만 속함" 이 깨진다.
- 일반 모델에서도: 분기 집합 $B_1,B_2,B_3$ 가 pairwise 인접이므로, $B_1$ 의 한 원소와 $B_2$ 의 원소를 잇는 간선이 있고 그 $B_1$ 원소 $x$ 는 $N[B_1]$ 과 $N[B_2]$ 에 속한다. $x$ 가 $B_3$ 에도 인접하지 않는 한 셋째 근방에는 속하지 않지만, K_t 의 단일 정점 모델에서는 항상 인접하므로 실패.
- 결론: **D1 은 단일 정점 모델 (즉 K_t 자체) 에서 항상 실패한다.** 따라서 "K_t 마이너를 D1 모델로 찾는다" 는 정의 자체가 모순. 3중 공통 이웃 조건은 쌍별 인접과 양립하지 않는다 (인접한 세 분기 집합의 각 원소가 서로를 이웃으로 가지므로).

## 3. 왜 고차 자유도가 깨지는가 (질문의 "이유")
- 쌍별 인접은 근방 nerve 의 **1-골격** 을 준다 (교집합 ≠ ∅). 그러나 세 근방이 공통 원소를 가지면 nerve 에 2-면이 생기고, K_t 의 사이클 공간 $\binom{t-1}{2}$ 이 2-면으로 채워진다. 
- 세 근방의 공통 원소는 보통 **분기 집합들 자신의 원소** (인접 때문에 생김) 이므로, K_t 류 모델에서는 2-면이 구조적으로 불가피하다. 이것이 "쌍별 인접은 보존되지만 고차 자유도가 깨진다" 는 현상의 이유다. 즉 깨짐은 우연이 아니라 인접과 공통 이웃의 정의에서 나온다.

## 4. 대체 정의 제안 (검토용, 미검증)
- **D2 (교차 간선 유일성):** 각 쌍 $(B_i,B_j)$ 사이 간선이 정확히 하나 (또는 $\ge1$ 이면서 특정 원소가 고정). 이는 쌍별 인접을 보존하고, 근방 교집합을 **간선 단위** 로 세면 (edge-cover nerve) 2-면이 생기지 않을 수 있다. 검증 필요: edge-cover 의 세 간선이 공통 정점을 가지면 2-면 — K_t 의 삼각형 $v_1v_2v_3$ 이 그 예이므로 D2 도 같은 문제에 부딪힐 가능성이 있다. [추측]
- **D3 (1-골격 정의):** 고차 자유도를 포기하고 "쌍별 인접 = 1-골격 보존" 만 요구. 이것은 T7 이 필요로 하는 최소 조건 (접착) 과 같다 (R36 (A)). 정의는 가능하지만 위상 정보 (사이클 공간) 는 쓰지 않는다.

## 5. 판정 요약
- **D1 (쌍별 인접 + 3중 공통 이웃 없음): 정의 불가 — K_t 자체가 실패.** 답: 아니오.
- 질문의 "쌍별 인접 + 공통 이웃 조건으로 쓸 수 있는가": 공통 이웃 조건을 세 근방 전체에 걸면 쌍별 인접과 모순. 조건을 다른 형태 (D2) 로 바꾸면 검토 가능하나 미증명.
- **실질 판정:** nerve 기반 자유도 보존은 K_t 질문에 쓰이지 않는다. 쌍별 인접 (1-골격) 만이 쓸 수 있는 위상 데이터이며, 그것은 R36 (A) 에서 이미 "위상으로 보장되지 않는다" 로 판정된 것과 같은 질문이다. 즉 이 경로는 R36 의 병목으로 되돌아온다.

## 6. 결과 줄 (렌즈 예측의 어느 단계)
- D1 불가 (§2): 예측 3 의 **접착 단계 정의** 에서 D1 을 쓰지 않는다.
- 고차 자유도 깨짐의 이유 (§3): 예측 3 의 **번역 단계** 의 설명 (nerve 2-면이 불가피).
- D3 (1-골격 정의) 만 쓸 수 있음 (§4): 예측 3 의 **접착 단계** 가 R36 (A) 병목에 머묾을 명시.

## 7. 후속연구 지점
1. **D2 (교차 간선 유일성) 의 2-면 검사 (우선순위 1).** 이유: 간선 단위 nerve 가 K_t 삼각형에서 2-면을 만드는지 정의 수준 점검이 판정 근거를 바꿀 수 있다. 시작: 간선 덮개 (각 간선의 닫힌 근방) 의 nerve 에서 삼각형 $v_1v_2v_3$ 의 세 간선이 공통 정점을 갖는 경우를 확인 (계산 금지, 정의 수준).
2. **D3 로 쌍별 인접 보장 정의 (우선순위 2).** 이유: T7 접착 단계가 최소로 필요로 하는 것은 D3. 시작: "분기 집합 쌍이 교차 간선으로 연결" 을 렌즈 축약 $G/F$ 의 K_t 부분그래프 존재와 같은 조건으로 재기술.
3. **R36 (A) 병목과의 연결 (우선순위 3).** 이유: 이 판정은 쌍별 인접의 위상적 보장 부재를 다시 확인한다. 시작: 어떤 위상 객체가 쌍별 인접을 **강제** 하는지 (Z_2 등변 사상의 원소 쌍) 를 정의 수준에서 탐색.
