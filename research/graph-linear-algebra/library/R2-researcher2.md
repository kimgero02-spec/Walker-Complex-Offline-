### 2. 정리 A (제곱무인수 섬유의 완전한 기술) [증명]
**정리 A.** q 홀수, f 가 F_q 위 제곱무인수 monic 삼차식, r=기약인수 수. 그러면
(a) S_f(F_q)≠∅.
(b) O(A)(F_q)-궤도는 정확히 2^{r−1}=1+#{f 의 F_q-근}=|E[2](F_q)| 개이다.
(c) 점 M 의 O-안정자군은 L[2]={u∈L*: u²=1}≅(Z/2)^r (위수 2^r, −I 포함); SO-안정자군은 {u∈L[2]: N(u)=1}, 위수 2^{r−1}, 갈루아 가군으로 E[2](F_q) 와 같다.
(d) 모든 궤도의 크기는 |O(A)|/2^r = q(q²−1)/2^{r−1}. 따라서 |S_f(F_q)| = q(q²−1) = q³−q = |SO₃(F_q)|.

*증명.* (i) 사전. M∈S_f 에 대해 N=A⁻¹M 은 ⟨u,v⟩:=uᵀAv 에 대해 자기수반: ⟨Nu,v⟩=uᵀMᵀ... =uᵀMv=⟨u,Nv⟩ (M 대칭). f 가 제곱무인수라 N 의 최소다항식=특성다항식=f, 따라서 F[x]-가군 (F³,N) ≅ L (순환가군). 동형 ψ:(F³,N)→L 를 하나 고른다. ψ 로 옮긴 형식 B(a,b)=⟨ψ⁻¹a,ψ⁻¹b⟩ 는 L 위에서 B(xa,b)=B(a,xb) 를 만족하므로 B(a,b)=λ(ab), λ=B(1,·) 선형범함수. L 이 분리가능이라 Tr 쌍선형형식이 비퇴화 ⇒ λ=Tr(c·) 인 c∈L 유일. B 비퇴화 ⇔ c∈L*. ψ 를 ψ'=uψ (u∈L*) 로 바꾸면 B'(a,b)=B(u⁻¹a,u⁻¹b)=Tr(c u⁻² ab) 이므로 c→cu⁻². 그러므로 κ(M):=[c]∈L*/L*² 는 M 만의 함수.
(ii) 궤도 = κ 의 올. Q^TAQ=A 인 Q 로 M'=QᵀMQ 이면 N'=A⁻¹QᵀMQ=Q⁻¹NQ (QᵀAQ=A 로부터 A⁻¹Qᵀ=Q⁻¹A⁻¹). 따라서 Q 는 가군동형이고 형식 A 를 보존하므로 κ(M')=κ(M). 역으로 κ(M)=κ(M') 이면 ψ,ψ' 를 조정해 같은 c 를 얻고 Q=ψ⁻¹∘ψ' 가 형식 A 를 보존하는 가군동형이며, 이것이 M'=QᵀMQ 를 준다. (P=Qᵀ 로 O(A) 와 동일한 군.)
(iii) 상. c∈L* 가 어떤 M 의 κ 가 되려면 (L,Tr(c xy))≅(F³,A) 이어야 한다. 유한체 위 같은 차원·같은 판별식의 비퇴화 이차형식은 동형(q 홀수). disc Tr(c xy)=N_{L/F}(c)·disc Tr(xy) (L 의 기저 e_i 에 대해 Gram 행렬 [Tr(c e_ie_j)] = (c 곱의 행렬)·[Tr(e_ie_j)], det=N(c)·det). 따라서 조건은 N(c)≡δ (F*/F*²), δ=disc A/disc Tr_L. N:L*/L*²→F*/F*² 는 전사(∏F_{q^d}* 에서 노름이 F* 로 전사)이므로 이 조건을 만족하는 c 의 집합은 ker N 의 공집합 아닌 코셋이고 |ker N|=|L*/L*²|/2=2^r/2. 이것이 (a),(b). 근 개수와의 관계: 삼차 제곱무인수에서 r=1,2,3 ⇔ 근 0,1,3 이므로 2^{r−1}=1+#근. 2-분점 쪽: |E[2](F_q)|=1+#{f 의 F_q 근} (점 (e,0)) 은 정의. 
(iv) 안정자군. Q 가 M 을 고정 ⇔ Q 가 가군 자기동형 u∈L* 이고 Tr(c u² ab)=Tr(c ab) ∀a,b ⇔ u²=1. 즉 L[2]. det(u 곱)=N(u). 크기 2^r, SO 에서는 N(u)=1 이라 2^{r−1}. (d): 궤도 크기=|O|/2^r, 곱하기 2^{r−1} 개 = |O|/2 = q(q²−1). ∎
- 이 증명은 q 가 홀수이기만 하면 된다. 표수 3 에서도 A 가 비퇴화이므로 그대로 성립; 표수 3 의 특수성(영점 (1,1,1))은 개입하지 않는다.
- Lang 정리와의 대응: κ 가 H¹(F_q,Stab)=H¹(F_q,Rμ₂)_{N=1 꼴}=ker(N:L*/L*²→F*/F*²) 이고 H¹(F_q,SO₃)=0 (연결) 에 대응한다. 위는 Lang·Kostant 단면 없이 같은 결론을 낸 직접 증명이며(비어있지 않음은 (iii) 의 노름 전사성이 대신함), 조건 "q 홀수" 가 정확히 필요한 가정이다. [researcher1 의 일반 증명과 대조 대상]
- 부산물: 섬유 크기가 q³−q 로 근 구조와 무관하다는 것은 궤도 수 변화(1,2,4)와 안정자군 크기 변화(2,4,8)가 정확히 상쇄된다는 뜻 (질량 공식).

### 3. 비제곱무인수 f, O vs SO (항목 3)
- [증명] O vs SO: O(A)(F_q)=SO(A)(F_q)×{±I}, −I 는 자명 작용 ⇒ 궤도 동일. 전수 열거로 |O|=2|SO| (q=3,5) 확인 [계산 확인].
- (x−a)³ [계산 확인 q=3..13; 일부 증명 스케치]: M−aA 가 영 또는 영멱. (1) M=aA (크기 1). (2) M−aA=c wwᵀ 계수 1: N−a 영멱 ⇔ wᵀA⁻¹w=0 (A⁻¹=J/2−I 검증: A(J/2−I)=I). 비영 등방벡터 q²−1 개, 직선 q+1 개 × 비영 스칼라 q−1 → 행렬 q²−1 개, c 의 제곱류로 두 궤도 각 (q²−1)/2 (데이터 일치; 위트 정리로 각 클래스 전이 [기억-미검증]). (3) 정칙 영멱 (Jordan 블록 3): 크기 q(q²−1)=|SO|, 안정자군 ±I 뿐 (데이터). 합: 1+(q²−1)+q(q²−1)=q³+q²−q.
- (x−a)²(x−b), a≠b [계산 확인]: 반단순형 N=a+(b−a)π (π=직선 ⟨v⟩ 로의 직교사영, v 비등방): 비등방 직선 q² 개가 v^⊥ 가 쌍곡평면이냐 아니냐에 따라 q(q+1)/2, q(q−1)/2 두 궤도 (데이터와 일치). 비반단순형(a 에 크기 2 블록): 두 궤도 각 q(q²−1)/2, 안정자군 위수 4. 합 q²+q(q²−1)=q³+q²−q.
- [증명(위 개수 사용)] 총합 항등식: Σ_f|S_f| = (q³−q²)(q³−q)+q²(q³+q²−q)=q⁶ = #Sym₃(F_q) ✓ (제곱무인수 monic 삼차식 수 q³−q², 아닌 것 q²). 두 비제곱무인수 유형의 크기가 같다는 사실과 합쳐 일관.
- 궤도 수 4 가 q 에 무관하다는 것은 관찰 [계산 확인] 이며 증명은 위 개수 논증 (스케치) 에 의존.

- [증명] **정리 B.** 정리 A 의 증명은 n 에 무관하다. 비퇴화 A (n×n), q 홀수, f monic 제곱무인수 차수 n 이고 det(tA−M)=det A·f 인 섬유에 대해 궤도 수 = |ker(N:L*/L*²→F*/F*²)| = 2^{r−1} (n≥1 에서 N 전사), 안정자군 L[2], 섬유 크기 |O(A)|/2. (증명은 위와 한 줄도 다르지 않다. 단 n 짝수에서 O 는 SO×{±I} 가 아니므로 SO-궤도로 쪼개지는 문제는 별개 — 시험하지 않음.) 위 표는 이 정리의 [계산 확인].
- **H¹(E[2]) 와의 비교 (n=4).** 2^{r−1} 은 |E[2](F_q)| (표의 마지막 열)와 같지 않다: 비 8:4, 4:2, 2:4, 2:1, 1:2. 올바른 코호몰로지 서술: 궤도 ↔ ker(H¹(F_q,Rμ₂)→H¹(F_q,μ₂)) (H¹(F_q,O₄)=Z/2 가 판별식 클래스). K=ker(N: Rμ₂→μ₂) 라 하면 |H¹(K)|=|K(F_q)|=2^{r−1}·(모든 인수 차수가 짝이면 2, 아니면 1) 이고 궤도 수 = H¹(K) 의 Rμ₂ 로의 상 = |K(F_q)|/(그 보정). E[2]=K/μ₂ 이므로 H¹(μ₂)→H¹(K)→H¹(E[2])→H²(μ₂)=0 (유한체의 브라우어군 0). 즉 H¹(E[2]) 는 궤도 집합의 μ₂-몫일 뿐 그 자체가 아니다. n=3 에서는 홀수 차원이라 Rμ₂=K×μ₂, K≅E[2] 이므로 일치하는 것이 우연이 아니다. [증명]
