# 그래프의 정준 점 Q 와 타원곡선 E_G (오케스트레이터 직접 연구, R4 이후)

## 설정과 기호
- G: 정점 n 개(n 짝수), A_G 의 rank ≤ 4 인 연결 그래프. P_G(t)=det(tA_G−I)=1−m t²−2T t³+c₄ t⁴ (t 의 1차 계수는 trace A=0 이라 0).
- m=간선 수, T=삼각형 수, c₄=(서로 만나지 않는 간선 쌍의 수)−2·(4-사이클 수) (Sachs 정리).
- 곡선 w²=P_G(t) 의 점 (0,1), (0,−1); (0,1) 을 원점으로 두고 Q=[(0,−1)]−[(0,1)] 이 정준 점.

## 정리 1 (닫힌 식) [증명: sympy 기호 계산 + Connell 변환]
E_G : Y² = x³ + 2m x² + (m²−4c₄) x + (2T)²,  Q = (0, 2T).
확인: P₄ (m,T,c₄)=(3,0,1) j=148176/25; paw (4,1,1) j=351232/37; 다이아몬드 (5,2,0) j=62500/17 — 이전 j 와 일치.

## 정리 2 [증명]
- 이분 그래프(T=0)이면 Q=(0,0) 으로 위수 2.
- T>0 이면 Q 는 위수 2 가 될 수 없다 (Y=2T≠0).
- Q 가 위수 3 ⇔ (m²−4c₄)² = 32 m T²  (⇔ 2m=k² 이고 m²−4c₄=±4kT).  [접선의 변곡 조건 b²=4ar²]
  - 무한 가족: 완전3분 K_{t,2t,2t} (c₄=0, m=8t², T=4t³, m³=32T²), t 짝수일 때 n=5t 짝수. 예 K_{2,4,4}(n=10).
  - 최소 예: 집 그래프에서 지붕 꼭짓점을 비인접 쌍둥이로 복제한 6정점 그래프 (m,T,c₄)=(8,2,8).
- 위수 4 ⇔ u³−32 m T² u+128 T⁴=0, u=m²−4c₄.

## 계산 (n 짝수 ≤ 30, rank≤4 연결 그래프 = 10개 기약 그래프의 부풀림)
- 매끈한 곡선, 삼각형 있음: 845,059 개. Q 가 토션인 것 232 개: 위수 3 이 226 개, 위수 4 가 6 개, 그 외 위수(5,6,7,8,9,10,12) 는 없음 (큰 소수 환원 + 정확 산술; 위수 ∞ 는 마주르 정리로 증명).
- 이분 그래프: 1792 개(n≤14) 전부 위수 2.
- 위수 4 예: 황소(bull) 를 크기 (4,4,6,2,2) 로 부풀린 18정점 그래프, (m,T,c₄)=(80,96,448), 2Q=(−16,0), 4Q=O (그래프를 직접 만들어 독립 확인).
- 정수 삼중 (m,T,c₄) 만으로 보면 위수 4 해는 많지만 (예 (4,4,−4)), 대부분은 그래프로 불가능 (4 간선에 삼각형 4 개 등).

## 정리 3 (정칙 그래프와 여그래프) [증명: 기호 항등식 + 점 개수]
- 정칙 G (차수 k): P_Ḡ(−t/(1+t))(1+t)ⁿ = −P_G·((n−k)t+1)/(kt−1) — 분기점 하나(1/k → −1/(n−k))만 이동 (R4 researcher3 증명, 오케스트레이터 4개 그래프 확인).
- 강정규 srg(n,k,λ,μ) (정수 고윳값 k,r,s, 중복도 모두 홀수): 레전드르 매개변수 λ_Ḡ = 1/λ_G (k,r,s 에 대한 항등식) ⇒ j(G)=j(Ḡ).
- 두 곡선은 이차 꼬임 관계이고 꼬임 인자 d ≡ (r+1)(s+1)(k+rs) ≡ −μ(k−λ−1) (제곱류). GQ(2,2)=srg(15,6,1,3): d=−3, 모든 소수 7≤p<80 에서 a_p(Ḡ)=χ_p(−3)a_p(G) 확인. d<0 이므로 Q 위에서 항상 비동형(꼬임 −1 이면 Q(i) 위 동형).

## 정직한 한계
- Q 가 무한 위수 ⇒ E_G(Q) 의 랭크 ≥ 1 이지만, 이는 rank≤4, n≤30 의 계산 범위에서 확인된 것이고 일반 증명은 없음 (위수 3 의 닫힌 조건만 증명).
- "위수 4 가 나오고 5 이상은 안 나온다"는 범위 내 관찰 [추측].

## 추가 결과 (1시간 제한 탐색, R4 이후)
### 위수 3·4 의 정확한 조건 [증명]
- 곡선 E: Y²=x³+2m x²+u x+(2T)², u=m²−4c₄, Q=(0,2T) 는 임의의 (E,Q) 의 표준 꼴 (Q 를 x=0 으로 옮김).
- 위수 3 ⇔ u²=32 m T²  (⇔ 2m=k², u=±4kT).
- 위수 4 ⇔ 2Q 가 2-분점 ⇔ ∃ κ>0 (정수): κ³−2mκ+2T=0 이고 u=4κT. 동치로 ε=2T/κ, m=(ε+κ²)/2, T=εκ/2, c₄=(m²−4κT)/4.
- 완전3분 K_{a,b,c}: c₄=0. 위수 3 ⇔ (ab+bc+ca)³=32(abc)², a,b,c≤120 의 해는 (t,2t,2t) 뿐 [계산 확인]. 위수 4 는 z²−32z+128=0 (z=m³/T²) 이 무리근이라 불가능 [증명].
### 균일 부풀림 불변 [증명]
- 모든 가중치를 s 배 하면 (m,T,c₄)→(s²m,s³T,s⁴c₄) 이고 x→s²x, Y→s³Y 로 곡선과 Q 가 그대로 (고윳값이 s 배 → t 를 재척도). 위수는 균일 부풀림에서 불변. 그러므로 본질적 해는 서로소 가중치.
### 전수 (n≤40, 기약 그래프 10종의 부풀림, 삼각형 있음, 매끈) [계산 확인]
- 짝수 n: 4,947,770 개; 서로소 해: 위수 3 이 287 개 (paw 2, bull 17, house 10, (6a) 108, (6b) 150), 위수 4 가 11 개 (bull 3, house 2, (6a) 6). K₃, K₄(특이), P₄, K₂, P₅ 에서는 위수 4 없음.
- 홀수 n≤39: 4,236,549 개; 서로소 해: 위수 3 이 231 개, 위수 4 가 6 개. (홀수 n 에서는 Γ_G 가 E_f 의 −1 꼬임이고 Q 는 E_f 의 점.)
- 위수 5~12 는 어느 범위에서도 없음 (n≤30 전수에서 큰 소수 환원 + 정확 산술).
### 종수 2 확장 [계산 확인]
- rank 5 (deg P=5, n=6): 칸토어 알고리즘(결합법칙 시험 통과)으로 D=[2(0,−1)−2∞]=(u,v)=(X²,−c₅²) 의 위수를 소수 3개 (10007, 10009, 10037) 에서 검사: 매끈한 22종 전부에서 위수 >80. 즉 토션 후보 없음. (이분 그래프는 rank 가 짝수이므로 rank 5 는 모두 비이분.)

## 수론으로 풀린 하나: 완전3분 그래프의 위수 3 조건 (정리 후보)
K_{a,b,c} 에서 Q 가 위수 3 ⇔ (ab+bc+ca)³=32(abc)² ⇔ (x,y,z)=(1/a,1/b,1/c) 에서 평면 3차곡선 (x+y+z)³=32xyz.
- 유리 변곡점 (0,1,−1) 의 접선을 무한선으로 두면 y²=x³+4x²+4x+1 (판별식 2⁴·5). 유리점 6개: 변곡점 3개 (0,1,−1),(1,0,−1),(1,−1,0) 과 (2,1,1) 순열 3개 (토션 Z/6).
- **명시적 쌍유리사상 [증명]**: 좌표 (s:x:y), s=x+y+z (원래 x,y,z) 에서 y=1 로 두면 s³=32x(s−x−1). x 에 대한 이차식의 판별식을 정리하고 ξ=−s/2 로 놓으면 (y/·)²=ξ³+4ξ²+4ξ+1. 즉 ξ=−(x+y+z)/(2y).
- **PARI(cypari) 검증 [계산 확인, 알고리즘 증명]**: 도체 20, 토션 Z/6, `ellrank` = [0,0,0,[]] (2-하강으로 랭크 0 확정), 동종사상류 곡선 4개. 앞의 "이소제니·최소 도체 37 가정" 은 필요 없다.
- **정리 4 [증명] (무조건)**: 양의 정수 a,b,c 에 대해 K_{a,b,c} 의 Q 가 위수 3 ⇔ (a,b,c)=t·(1,2,2) 의 순열. (유리점 6개 중 양의 점은 (2,1,1) 순열뿐.)

## 정리 5: 파우 (paw) 의 위수 3 곡면은 유리곡면 [증명: 기호 계산]
파우 H(꼭짓점 1,2,3 삼각형 + 3-4 변), 가중치 (w₁,w₂,w₃,w₄) 의 독립집합 부풀림: m=w₁w₂+w₃(w₁+w₂+w₄), T=w₁w₂w₃, c₄=T·w₄ (c₄ 가 w₄ 에 일차).
- 위수 3 ⇔ (m²−4c₄)²=32mT². c₄=T·w₄ 이므로 √(32m) 가 유리수여야 하고 m=2k². 그러면 w₄=k⁴/T−2k (다른 부호 가지는 양의 해 없음), 그리고 m=2k² 는 **(k²−w₁w₂)² = w₁w₂w₃(2k−w₁−w₂)** 와 동치.
- 따라서 유리수 (w₁:w₂:k) (2k>w₁+w₂) 를 임의로 주면 w₃=(k²−w₁w₂)²/(w₁w₂(2k−w₁−w₂)), w₄=k⁴/(w₁w₂w₃)−2k 가 유리수로 정해지고, 통분하면 정수 가중치. w₄>0 ⇔ k³(2k−S)>2(k²−P)² (열린 조건). 균일 부풀림 불변이므로 짝수 n 으로 맞춘다. **위수 3 파우 부풀림은 무한히 많다 (유리곡면, 양의 영역에서 조밀).**
- 명시적 무한 가족 A: **(w₁,w₂,w₃,w₄)=(k,k,y,k²/y−2k)**, y | k², k>2y. m=2k², T=k²y, c₄=k⁴−2k³y, m²−4c₄=8k³y ⇒ (8k³y)²=64k⁶y²=32·2k²·(k²y)² ✓. 예: (a,a,1,a(a−2)), a 홀수 ≥3 (n=a²+1): (3,3,1,3), (5,5,1,15), (7,7,1,35)…; (21,21,9,7). 이 가족은 고윳값 −k 를 정확히 가진다.
- 대조: **K₃ 부풀림(3 가중치)은 지수 1 곡선(유한 개)**, 파우(4 가중치)는 유리곡면(무한). 가중치 수 −1 = 사영 차원, 조건 1개 → 곡선이면 곡선의 종수가, 곡면이면 유리성이 결정.

## 정리 6: 파우의 위수 4 도 존재 (n≤40 탐색은 너무 작았다) [계산 확인: 실제 인접행렬 + PARI]
- 위수 4 ⇔ ∃ 정수 κ>0: κ³−2mκ+2T=0, m²−4c₄=4κT. κ 는 모닉 정수 3차식의 유리근이라 **정수** ⇒ (T,κ) 를 주면 m=(κ³+2T)/(2κ), c₄=(m²−4κT)/4 가 결정 (2-매개 족, X₁(4) 의 정수판).
- 파우 서로소 해 11개 발견 (κ<160 영역): (16,18,9,14) n=57, (18,21,14,6), (36,39,13,69), (50,55,22,70), (64,68,17,188), … (n 홀수; 2배하면 짝수). 실제 인접행렬로 m,T,c₄ 계산 후 PARI `ellorder` = 4 확인 (n=114 와 n=157 포함). 앞서 "파우는 위수 4 없음" 은 n≤40 한계 때문이었음 → **정정**.
- 위수 4 다항식은 기약 (6차) — 위수 3 의 인수분해된 가족 A 같은 단순 족은 없음.

## 정리 7 (개념적 재해석): 위수 N ⇔ 다항식 Pell–Abel 방정식 [증명: Abel; 예 계산 확인]
- χ(s)=s⁴−ms²−2Ts+c₄ (= 비영 스펙트럼의 특성다항식, 모닉 4차). 곡선 w²=χ(s) 의 무한원점 ∞±, Q=[∞₊−∞₋]. Q 위수 N ⇔ **X²−χY²=1 이 deg X=N, deg Y=N−2 인 유리계수 다항식 해**를 가진다.
- 예: paw(3,3,1,3): χ=s⁴−18s²−18s+27, X=−s³/9+s²/3+s−2, Y=(s−3)/9 (X²−χY²=1, sympy 확인); (5,5,1,15) 도 같은 꼴.
- 위수 2 ⇔ T=0 (χ=(s²+β)²−δ). 실수 근이면 E={χ≤0} 는 두 구간, 위수 N ⇔ E 가 차수 N 다항식의 [−1,1] 원상 (제비체프형), 즉 평형측도(조화측도)가 j/N. **그래프 스펙트럼의 조화측도가 유리수일 조건**이 위수 조건.
## 한계
- 우리 곡선족 {Y²=x³+2m x²+u x+(2T)²} 은 "유리점이 있는 모든 타원곡선"의 일반 꼴과 같아서, 그래프는 정수 매개변수에 조합적 제약을 줄 뿐이다. BSD, 랭크 분포, 합동수 같은 일반 문제에는 새 도구가 아니다.

## 후속연구 R5 (위수 ≥5 는 왜 안 나오는가) — 수치 탐색, 증명 아님
- **θ 불변량**: θ(G)=z(Q)/ω₁ (E_G 의 실수 타원로그를 실주기로 나눈 값, PARI `ellpointtoz`/`ellperiods`). 위수 N ⇔ θ=j/N. 확인: 파우 위수 3 → 2/3, 파우·황소 위수 4 → 3/4 (소수 12자리 이상 일치). [계산 확인]
- **실수 제약만으로는 위수 ≥5 가 배제되지 않는다** [계산 확인, 수치]: 고윳값 합 0, 페론–프로베니우스(λ₁≥|λ_min|), T≥0 을 만족하는 임의의 실수 4중쌍 1204개에서 θ∈[0.5000, 0.9416], 분포는 [1/2,1) 전체에 퍼짐. K₃ 부풀림(실수 가중치 800개) θ≤0.773, K₄ 부풀림(1500개) θ≤0.899. 따라서 3/5, 4/5 등도 범위 안.
- **위수 5 삼중쌍은 그래프 필요조건을 통과한다** [계산 확인]: X₁(5) Tate 매개화로 m=(r²−6rs+s²)/2·…, T=2rs², c₄=(m²−8r²s²+8rs³)/4 (r,s 서로소 같은 홀짝). |r|,s≤120 의 3417개 전부 PARI 위수 5 확인. 그 중 4실근·PF·크루스칼–카토나(9T²≤2m³)를 모두 통과한 것이 268개. 스펙트럼은 "양 1개 + 음 3개" (예 (−46,−34.5,−27.6,108.0)) — 완전 4분 그래프의 부호 구조. 따라서 위수 ≥5 부재는 정수성·그래프성(정점 가중치가 정수 근) 같은 산술적 이유여야 한다.
- **완전 4분 그래프 K_{a,b,c,d}** (c₄=−3abcd, m=e₂, T=e₃): 서로소 가중치 ≤20 (약 8000개) 에서 **유한 위수가 단 하나도 없음** (7737개 무한 위수, 255개 특이). K₃ 에서는 (1,2,2) 로 위수 3 이 있었던 것과 대조. [계산 확인, 범위 한정; 증명 없음]
- 도구 메모: cypari 에서 파이썬 루프로 PARI 객체를 대량 생성하면 SIGBUS 가능 → 루프를 PARI 코드 안에서 실행.

### 후속연구 지점 (갱신)
1. K_{a,b,c,d} 의 위수 3/4 조건이 해를 가지는지: (m,T,c₄)=(e₂,e₃,−3e₄) 이므로 4개 정수근을 갖는 4차식 조건. 위수 3 은 4변수 사영 3차원 속 초곡면 — 유리성/유한성 판정 (시작: 파우처럼 √(32m) 유리성 이용).
2. 위수 ≥5 불가를 증명할 수 있는 정수성 장애: 위수 5 삼중쌍(268개 통과)에 실제 그래프가 없음을 보이는 것. 난점: 일반 그래프(부풀림 아님) 전체를 다뤄야 함.
3. θ 의 정확한 상한(K₃: ≈0.773?)을 닫힌 식으로 — K₃ 에서 위수 4(θ=3/4) 불가 증명과의 관계.
