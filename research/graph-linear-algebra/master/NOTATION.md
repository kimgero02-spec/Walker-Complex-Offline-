# 기호 사전 (graph-linear-algebra)

그래프 → 군의 순서:
1. A_G : 인접행렬 (간선이면 1, 아니면 0). K₃ = [[0,1,1],[1,0,1],[1,1,0]].
2. P_G(t) = det(t·A_G − I) : 고윳값 λ 마다 인수 (λt−1). K₃: (t+1)²(2t−1).
3. C_G : 곡선 w² = P_G(t).
4. Γ_G : C_G 의 일반화 야코비안(Pic⁰) = 곡선의 매끈한 점들이 이루는 군 ("G 의 타원군").

부품:
- G_m: 0 이 아닌 수의 곱셈군 (곡선의 마디에서 나옴).
- G_a: 수의 덧셈군 (곡선의 첨점에서 나옴).
- R¹_{Q(√d)/Q} G_m (노름 1 토러스): a+b√d 중 a²−d·b²=1 인 것들의 곱셈군. F_q 위 위수 q−(d/q).
- (d/q): 르장드르 기호 (d 가 mod q 제곱수면 +1, 아니면 −1).
- Res_{K/Q}: K 위의 군을 Q 위의 군으로 바꾸는 조작 (차원이 [K:Q] 배).
- A_G (아벨 부분): 정규화 곡선의 야코비안 (종수 1 이면 타원곡선).
- L_G (선형 부분): 토러스 × 덧셈군.
- 0→L_G→Γ_G→A_G→0 : 확장 (Γ_G 가 L_G 를 부분군으로 갖고 몫이 A_G).
- g̃: 정규화 곡선의 종수. p_a=⌊(deg P−1)/2⌋: Γ_G 의 차원 (= g̃ + 토러스 차원 + 덧셈군 차원).
- j-불변량: 타원곡선의 분류수. I=12ae−3bd+c², J=72ace+9bcd−27ad²−27b²e−2c³, j=6912·I³/(4I³−J²).
- |Γ(F_q)|: 소수 q 에서 군의 원소 수.
