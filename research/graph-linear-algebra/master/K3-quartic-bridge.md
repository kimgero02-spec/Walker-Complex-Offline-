# K₃-행렬 ↔ 이진 사차식 ↔ 타원곡선 (오케스트레이터 직접 연구)

## 설정
A = J−I (3×3), q_A(x)=2(xy+yz+zx). 원뿔곡선 q_A=0 의 매개화 P(a,b)=(a(a+b), −ab, b(a+b)) (q_A(P)≡0). 대칭 M 에 대해
- 이진 사차식 f(a,b)=P(a,b)ᵀ M P(a,b) = c0 a⁴+c1 a³b+c2 a²b²+c3 ab³+c4 b⁴,
  c0=m11, c1=2m11−2m12+2m13, c2=m11+m22+m33−2m12+4m13−2m23, c3=2m13−2m23+2m33, c4=m33. (M↦f 의 핵 = span{A})
- 삼차식 g(t)=det(tA−M) = 2t³+(2trM−1ᵀM1)t²+h(M)t−det M, g/2 의 눌린 삼차식 X³+pX+q.

## 정리 1 [증명: sympy 기호 계산, 6변수 다항식 항등식]
고전 불변량 I=12ae−3bd+c², J=72ace+9bcd−27ad²−27b²e−2c³ (f=ax⁴+…)에 대해
I(f) = −12 p,  J(f) = −216 q,  Δ(f)=(4I³−J²)/27 = 64·Δ(g/2).
고유값 말로: ν_i (g 의 근) 에 대해 I=4(τ1²−3τ2)=2Σ_{i<j}(ν_i−ν_j)², J=8(27τ3−9τ1τ2+2τ1³).

## 따름 [고전 야코비안 공식 Y²=X³−27IX−27J 는 기억-미검증]
Jac(C_M : u²=f(a,b)) ≅ E_M : w² = det(tA−M) (뒤틀림 없음). 점 개수 독립 검증 [계산 확인]: 좋은 환원 82쌍 (M 12개 × p∈{5,…,29}) 모두 #C_M(F_p)=#E_M(F_p); 뒤틀림 c=2 는 43/82 쌍에서 어긋남.

## 사전
| G-행렬 쪽 | 타원곡선 쪽 |
|---|---|
| 일반화 고윳값(det(tA−M)=0 의 근) | 2-분점의 x좌표 |
| 겹친 고윳값 | 특이곡선 (두 원뿔곡선이 접함) |
| M→M+λA | t→t+λ (같은 곡선) |
| M→σMσᵀ (σ∈S₃) | 같은 E_M, C_M 은 세 점 {0,−1,∞} 을 순열하는 뫼비우스 변환으로 동형 |

예: M=[[−1,2,−1],[2,−1,−1],[−1,−1,2]] → g=2t(t−3)(t+3), I=108,J=0,j=1728.  M=diag(1,2,3) → g=2(t³+3t²−3), I=36,J=216,j=2304.  M=e1e1ᵀ → f=a²(a+b)², Δ=0.

## K₄ 일반화 [계산 확인]
C={xᵀAx=0, xᵀMx=0}⊂P³ (A=J−I, 4×4) 와 E: w²=det(tA−M) (사차, 최고차 계수 det A=−3): 좋은 환원 20쌍 모두 #C=#E (c=1). 다른 뒤틀림 c∈{−1,±3,±2,±6} 는 8~16쌍만 맞음. 고전 사실: 두 이차곡면 교차곡선의 야코비안은 y²=det(tQ1−Q2) [기억-미검증].

## 한계 (정직)
- 이 대응은 비퇴화 대칭 A 에 대한 이차곡면 다발의 고전 이론(케일리, 아론홀드, 2-하강)이다. K₃ 에 고유한 것은 S₃ 대칭과 정수 구조(점 0,−1,∞ ↔ 레전드르 λ-직선 X(2))이다 [추측].
- 일반 K_n: n=5 이상은 곡선이 아니라 곡면/Fano 다양체 [기억-미검증].

## 추가 검증: G-소거 궤도 분류 = 사차식 분류 = H¹(E[2]) [오케스트레이터 계산]
1. [계산 확인] K₃ 의 G-기본연산군 O(A_{K₃}) 가 M mod A (=이진 사차식) 에 작용할 때의 궤도 수 = 이진 사차식의 PGL₂ 궤도 수: F₃ 에서 24=24, F₅ 에서 56=56. (|O(A)|=2q(q²−1), F₃ 48, F₅ 240.)
2. [계산 확인] F₅ 위 제곱무인수 monic 삼차식 f 100개 전부(근 0개 40, 근 1개 50, 근 3개 10)에서, det(tA−M)/2 = f 인 M 들의 O(A)-궤도 수 = 1+(F₅ 근의 수) = |E[2](F₅)|, 어긋남 0. (정정: 제곱무인수 f 의 섬유 크기는 q(q²−1)=120 이고 145 는 비제곱무인수 f 의 값 q³+q²−q. R2 researcher1 이 지적, 오케스트레이터가 F₅ 에서 재확인.)
   해석: 고정된 Det_G 를 갖는 K₃-행렬의 소거 동치류 ↔ H¹(F_q, E[2]) (크기 |E[2](F_q)|). 이는 Bhargava–Gross 의 2-Selmer 매개화(SO₃ 의 자기수반 연산자 궤도 ↔ H¹(k, J[2]))와 같은 구조로 보인다 [기억-미검증]. 유리수체 위에서는 지역조건을 만족하는 궤도가 Selmer 원소가 될 것 [추측].

## R2 researcher1 결과 (오케스트레이터 부분 재확인)
- [증명, researcher1] 추측 1 은 참: q 홀수(표수 3 포함), f 제곱무인수일 때 #(O(A)(F_q)-궤도 on S_f(F_q)) = |E[2](F_q)|. 두 증명: (A) Lang 정리 경로, (B) 초등 경로(궤도 ↔ c∈L^×/L^{×2}, Nm(c)·disc(f)≡2 (제곱류), 개수 2^{r−1}, r=f 의 기약인수 수).
- [재확인] 명시적 단면 M(a,b,c)=[[2c,b+2c,0],[b+2c,2(a+b+c+1),1],[0,1,0]] 이 det(tA−M)/2=t³+at²+bt+c 를 줌 (기호 계산).
- [재확인] F₅: 제곱무인수 f 100개 섬유 크기 120, 비제곱무인수 25개 섬유 크기 145, 합 5⁶.
- [추측] 비제곱무인수 f 의 섬유 크기 q³+q²−q (q=3,5,7 계산).

## 종합: 타원곡선과 행렬대수의 만남에서 나온 것 (R3 이후, 문주님 질문에 대한 정리)
번역을 넘는 것이 목적이 아니라 두 이론이 만나 무엇이 나오는지의 정리.
한 문장: 타원곡선은 대칭행렬 두 개의 다발 (A, M) 이고, 그 산술(2-분점, 2-피복, 2-Selmer)은 일반화 고윳값 문제를 A-등거리 변환까지 분류하는 일이다.
1. [증명] det(tA−M)=Weierstrass, ν_i=2-분점 x좌표, I=4(τ₁²−3τ₂), J=8(27τ₃−9τ₁τ₂+2τ₁³), Δ(f)=64Δ(g/2). Jac(u²=f_M)≅{w²=det(tA−M)} (점 개수 82/82, K₄ 20/20).
2. [증명] 소거 동치류(O(A)-궤도) ↔ E[2]-토서; 개수 2^{r−1}=|E[2](F_q)| (F₃~F₁₃ 검증).
3. [증명/기억-미검증] 지역: ε 은 H=H¹(k,E[2]) 위 이차형식, ker ε 은 쌍곡형의 영점집합, 쿠머상은 라그랑지안. 기약 삼차식 3개: Sel₂=1,2,1 ⊊ (모든 장소 ε=0) 2,3,3.
4. [증명] n 홀수: 안정자군=E[2]; n 짝수: E[2] 의 비분리 확대 → GSO 필요. (K₃ 의 일치는 n=3 이 홀수이기 때문.)
5. [증명] 분류 개수 N(q)=2q³+q²+q; 사차식 PGL₂ 궤도 2q²+q+1 (3∤q).
6. [계산 확인] 정수 위 연산군은 무한군(뫼비우스 평행이동 실현, 위수 무한): 정수 소거 = PGL₂(Z) 작용 [동형은 기억-미검증].
7. [관찰] S₃-불변 M 은 중근(특이곡선) 위에만 존재.
나오지 않은 것: 고전적 난점의 해결, 새 타원곡선/새 정리. 열린 질문: K₃ 의 S₃ 와 GL₂(F₂)≅S₃ 의 구조적 연결 [추측]; K₄ (4-피복), K₅ (종수 2).
