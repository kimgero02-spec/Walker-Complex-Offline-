# [R09-researcher2] q=3 위험 수축의 Kempe·다이아몬드·삼각형 기준

- 작성자·라운드·역할: researcher2 · R09 · 연구원 (q=3 특성화 시도, 충분조건·필요조건 증명, 소형 결정적 예)
- 계산: `rooms/researcher2/r09_check.py`, `rooms/researcher2/r09_kempe.py` (정선된 예 3개: $H_8$, $W_4$ 의 두 간선. 전수 점검 아님)
- 참고: R08-researcher2 (분리 기준 정리 2.1, 고정 기준 3.1·3.2, $H_8$), R07-researcher1 (보조정리 C)

## 요약
- **Kempe 증인 (안전 쪽, 증명).** $c\in\mathrm{Col}_3(H)$ 에서 $c(u)\ne c(v)$ 이고 $u,v$ 가 $H[c(u),c(v)]$ 의 같은 성분에 없으면, 그 성분을 두 색 맞바꿈으로 $c(u)=c(v)$ 를 만든다. 따라서 $e$ 는 안전하다.
- **위험의 필요조건 (증명).** $e$ 가 위험하면 모든 $c\in\mathrm{Col}_3(H)$ 에서 $u,v$ 를 잇는 두 색 교대 경로가 있고, 그 길이는 홀수이다. 결과로 **위험한 $e$ 는 $G$ 에서 짝수 사이클 위에 있다.**
- **위험의 충분조건 두 개 (증명).** (T4) 다이아몬드로 강제된 쌍 $p\equiv u$, $r\equiv v$ 에 $p\sim r$ 이면 위험하다 (R08 명제 3.2 의 구체형). (T5) $G/e$ 가 $K_4$ 를 부분그래프로 가지면 (즉 $H-\{u,v\}$ 의 삼각형 $xyz$ 가 각 점이 $u$ 또는 $v$ 와 인접) 위험하다.
- **결정적 예 (3-연결).** 바퀴 $W_4$: 살 $hv_1$ 은 안전 (명시 색칠), 테두리 $v_1v_2$ 는 위험 (T5, 손으로 검증). 
- **$T_5$ 는 필요조건이 아니다.** $H_8$ (2-연결) 은 위험이고 $G/e$ 는 4-색칠가능하나 $K_4$ 부분그래프를 갖지 않는다 `[계산 확인]`. 따라서 "위험 $\iff$ $K_4$ minor/삼각형 피복" 은 거짓이다. **완전 특성화는 얻지 못했다** `[추측]`.

## 본문

### 0. 표기와 출발점
$H=G-e$, $u,v$ 는 $e$ 의 끝점, $\mathrm{Col}_3(X)$ 는 $X$ 의 3-색칠 집합이다. $\chi(G)=3$ 을 가정한다. 보조정리 C (= R08 보조정리 1.1) 에 의해
$$e\text{ 위험}\iff \forall c\in\mathrm{Col}_3(H):\ c(u)\neq c(v)\iff \chi(G/e)\ge 4 .$$
(마지막 동치는 $G/e$ 의 3-색칠이 $c(u)=c(v)$ 인 $\mathrm{Col}_3(H)$ 의 원소와 같다는 사실에서 나온다. $\chi(G/e)\le 4$ 는 R08 명제 1.2.)

### 1. Kempe 스왑 (안전 증인)

**보조정리 1.1 (Kempe 스왑) `[증명]`.** $c\in\mathrm{Col}_3(H)$, $a=c(u)\neq b=c(v)$, $K$ 를 $H[c^{-1}\{a,b\}]$ 에서 $u$ 를 담은 성분이라 하자. $v\notin K$ 이면 $e$ 는 안전하다.
- 증명. $c'$ 를 $K$ 위에서만 $a\leftrightarrow b$ 로 바꾸고 나머지는 그대로 둔다. $K$ 안의 변은 두 끝점이 모두 $\{a,b\}$ 의 서로 다른 색을 유지하므로 적정하다. $K$ 와 밖을 잇는 변의 밖쪽 끝점은 색이 $\{a,b\}$ 에 있을 수 없다 (그러면 $K$ 의 성분이 됨). 따라서 밖쪽 끝점은 셋째 색 $t$ 이고, $K$ 쪽 끝점은 $a$ 또는 $b$ 이므로 바꾼 뒤에도 $t$ 와 다르다. 그러므로 $c'$ 는 $H$ 의 적정 3-색칠이다. $c'(u)=b=c(v)=c'(v)$ 이므로 $c'(u)=c'(v)$ 이다. $\square$

**따름 1.2 (위험의 필요조건) `[증명]`.** $e$ 가 위험하면 모든 $c\in\mathrm{Col}_3(H)$ 에서 $v\in K_c(u)$ 이다. 즉 $u$–$v$ 경로 $P$ 가 $H$ 안에 있고 $P$ 의 색은 $c(u),c(v)$ 로 교대한다. 끝색이 다르므로 $|P|$ 는 홀수이다.

**따름 1.3 (짝수 사이클) `[증명]`.** 따름 1.2 의 $P$ 와 $e$ 를 합치면 길이 $|P|+1$ 짝수인 사이클이 된다. 따라서 **$e$ 가 $G$ 의 어떤 짝수 사이클에도 없으면 $e$ 는 안전하다.** ($q=2$ 에서는 이분 그래프의 모든 사이클이 짝수이므로 이것이 "다리가 아님" 과 맞는다.)

### 2. 다이아몬드 강제 (위험 쪽)

**정의.** $H$ 에서 $p\equiv u$ 는 모든 $c\in\mathrm{Col}_3(H)$ 에 대해 $c(p)=c(u)$ 인 것이다. 이것은 동치관계이다 (정의에서 바로).

**보조정리 2.1 (다이아몬드) `[증명]`.** $x\sim y$ 이고 $v,r\in N(x)\cap N(y)$ 이면 모든 $c\in\mathrm{Col}_3(H)$ 에서 $c(v)=c(r)$ 이다.
- 증명. $c(x)\ne c(y)$ 이므로 $v,r$ 의 색은 $c(x),c(y)$ 와 다르고, 3색 중 남은 색 하나뿐이다. $\square$
- (주석: $v\sim r$ 이면 $\{x,y,v,r\}$ 이 $K_4$ 가 되어 $\mathrm{Col}_3(H)=\varnothing$ 이므로, $\chi(G)=3$ 에서는 $v\not\sim r$ 이 자동이다.)

**정리 2.2 (T4: 다이아몬드 연쇄 $\Rightarrow$ 위험) `[증명]`.** $p\equiv u$, $r\equiv v$, $p\sim r$ (in $H$) 이면 $e$ 는 위험하다.
- 증명. 모든 $c\in\mathrm{Col}_3(H)$ 에서 $c(u)=c(p)\ne c(r)=c(v)$. $\square$
- 이것은 R08 명제 3.2 (연쇄 고정) 의 특수형이다. 새로운 것은 강제의 원천을 다이아몬드 보조정리 2.1 로 명시한 점이다. 여기에 R08 명제 3.1 (고정 $p\in N(v)$) 도 포함된다.

### 3. 삼각형 피복 (위험 쪽, $K_4$ minor)

**정리 3.1 (T5) `[증명]`.** $H-\{u,v\}$ 에 삼각형 $xyz$ 가 있고, $x,y,z$ 각각이 $H$ 에서 $u$ 또는 $v$ 와 인접하면 $e$ 는 위험하다.
- 증명. $G/e$ 에서 합쳐진 점 $w$ 는 $x,y,z$ 와 모두 인접하고 $xyz$ 는 삼각형이므로 $\{w,x,y,z\}$ 는 $K_4$ 이다. 따라서 $\chi(G/e)\ge 4$ 이고 위험하다 (§0). $\square$

### 4. 예 (결정적 검증)

**예 A: 바퀴 $W_4$ (3-연결) `[계산 확인: 연결도 3]`.** 허브 $h$, 테두리 $v_1v_2v_3v_4$. $\chi(W_4)=3$ 이다 (테두리는 짝수 사이클이므로 두 색, 허브는 셋째 색).

- **살 $e=hv_1$ (안전), 손으로 검증 `[증명]`.** $c(h)=c(v_1)=1$, $c(v_2)=c(v_4)=2$, $c(v_3)=3$. $H=W_4-hv_1$ 의 변은 $v_1v_2,\,v_2v_3,\,v_3v_4,\,v_4v_1,\,hv_2,\,hv_3,\,hv_4$ 이고 모두 색이 다르다. 따라서 $c(h)=c(v_1)$ 인 적정 3-색칠이 있고 $e$ 는 안전하다. (계산 확인: $H$ 의 3-색칠 12개 중 $c(h)=c(v_1)$ 인 것과 $c(h)\ne c(v_1)$ 인 것이 모두 있다.)

- **테두리 $e=v_1v_2$ (위험), 손으로 검증 `[증명]`.** $u=v_1$, $v=v_2$ 로 두면 삼각형 $\{h,v_3,v_4\}$ 가 T5 의 조건을 만족한다: $h\sim v_1$, $v_3\sim v_2$, $v_4\sim v_1$ (그리고 $h\sim v_3,v_4$, $v_3\sim v_4$). $G/e$ 는 $K_4$ 를 가지므로 위험하다. 직접 확인도 된다: $G/e$ 에서 합쳐진 점 $w$ 와 $\{h,v_3,v_4\}$ 가 완전그래프 $K_4$ 를 이룬다 `[계산 확인: $G/e$ 3-색칠 불가, $H$ 의 3-색칠 6개 모두 $c(v_1)\ne c(v_2)$]`.
- 따름 1.2 와 맞다: $H$ 의 모든 3-색칠에서 $v_1$–$v_4$–$v_3$–$v_2$ 경로가 두 색으로 교대한다 `[계산 확인]`.

**예 B: $H_8$ (2-연결만; 연결도 $\kappa(G)=2$ `[계산 확인]`).** R08 의 $H_8$: 다이아몬드 $D_1=(x,y;v,r)$, $D_2=(x',y';u,p)$, 변 $rp$, $e=uv$.
- 위험 `[증명]`: 보조정리 2.1 로 $v\equiv r$, $u\equiv p$. $r\sim p$ 이므로 정리 2.2 (T4) 로 위험.
- $G/e$ 는 4-색칠가능하지만 3-색칠 불가 `[계산 확인]`. $\mathrm{Col}_3(H_8)$ 는 24개이고 모두 $c(u)\ne c(v)$ `[계산 확인]`.
- **T5 는 적용되지 않는다** `[증명, 손으로]`. $H_8-\{u,v\}$ 의 삼각형은 $xyr$ 와 $x'y'p$ 뿐이다. $r$ 은 $u,v$ 와 인접하지 않고 ($r\sim x,y,p$), $p$ 도 $u,v$ 와 인접하지 않는다. 따라서 $G/e$ 는 $K_4$ 부분그래프를 갖지 않는다 `[계산 확인]`.
- 결론: $K_4 \subseteq G/e$ 는 위험의 필요조건이 아니다. 강제 연쇄 (T4) 가 T5 가 못 잡는 위험을 잡는다.
- 따름 1.2 확인: 모든 $c\in\mathrm{Col}_3(H_8)$ 에서 $u,v$ 가 Kempe 연결 `[계산 확인]`.

### 5. 상태 정리

| 메커니즘 | 역할 | 상태 |
|---|---|---|
| 분리 충돌 (R08 정리 2.1) | 위험/안전 판정 (주어진 분리에 대해 정확) | R08 (증명) |
| 고정 $p\equiv u$ (R08 명제 3.1, 3.2) | 위험 충분 | R08 (증명) |
| 다이아몬드 강제 (보조정리 2.1, 정리 2.2) | 위험 충분, 강제 원천의 구체형 | 본 보고서 (증명) |
| 삼각형 피복 (정리 3.1) | 위험 충분 ($G/e \supseteq K_4$) | 본 보고서 (증명) |
| Kempe 스왑 (보조정리 1.1) | 안전 증인 | 본 보고서 (증명) |

- **얻은 것.** 위험 쪽은 충분조건 (고정, 다이아몬드 연쇄, 삼각형 피복) 과 필요조건 (Kempe 홀수 경로) 으로 둘러싸였다. 안전 쪽은 Kempe 증인이 있으면 충분하다.
- **얻지 못한 것.** 위험의 완전 특성화. 위 충분조건 셋 중 어느 것이든 $H_8$ 처럼 $\chi(G/e)=4$ 인 위험을 모두 잡지는 못한다 (T5 는 $H_8$ 을 놓친다). T4 가 $H_8$ 을 잡지만 T4 가 모든 위험을 잡는지는 모른다 `[추측]`.

### 6. 장애물
1. **Kempe 조건은 필요조건일 뿐이다.** 모든 $c$ 에서 $u,v$ 가 Kempe 연결이라도 위험이 보장되지 않는다. 필요충분 판정에는 "모든 $c$" 라는 전역 조건을 다뤄야 한다.
2. **강제 관계 $\equiv$ 는 색칠 집합의 교집합에서 나오므로 전역이다.** 다이아몬드는 국소 원천이지만, 강제가 긴 사슬로만 생기는 경우 (예 $W_4-v_1v_2$ 의 $v_3\equiv v_1$ 은 테두리 경로의 교대에서 나옴) 를 놓칠 수 있다. 이것도 R07-researcher1 의 홀로노미 장애물과 같은 종류이다 `[추측]`.
3. **색의 대칭.** 3색에서 두 색 교대 경로는 셋째 색이 어디 있는지에 따라 달라진다. 그래서 $W_4-v_1v_2$ 의 $v_3\equiv v_1$ 은 셋째 색을 바꾸어도 유지되는 것을 확인해야 했다 `[계산 확인]`.

## 문주님께 요청
없음. 문헌 확인은 하지 못했다. $H_8$ 과 다이아몬드 연쇄가 Hajós 구성이나 Kempe 체인 문헌의 알려진 결과와 같은지는 `[기억-미검증]` 이다.

## 후속연구 지점
1. **위험의 완전 특성화 후보 검증 (우선순위 최상).** 무엇을: "위험 $\iff$ (다이아몬드 연쇄 T4) 또는 (삼각형 피복 T5) 또는 (R08 분리 충돌/고정)" 이 맞는지, 3-연결 소형 후보에서 반례를 찾는다. 왜: 현재 충분조건 여럿과 필요조건 하나뿐이며, $H_8$ 은 T5 가 필요조건이 아님을 보인다. 시작: $H-\{u,v\}$ 의 삼각형과 다이아몬드를 세는 대신, 3-연결 $G$ 에서 $e$ 가 위험인 예 (예: $W_4$ 테두리 는 T5 로 잡힘) 중 T4·T5 어느 것도 아닌 것을 손으로 찾는다. 난점: 전수 점검으로 흐르면 안 된다. 손으로 구성한 후보만 쓴다.
2. **Kempe 조건을 "모든 $c$" 에서 "하나의 $c$" 로 줄이는 조건.** 무엇을: 따름 1.2 는 모든 $c$ 에 대해 성립해야 하므로 필요조건으로 약하다. 어떤 $c$ 하나에서 $u,v$ 가 Kempe 연결이면 위험인지, 또는 위험이 아닌 $c$ 를 쉽게 구성하는 규칙이 있는지 본다. 왜: 안전 증인이 Kempe 스왑이므로, 위험 판정은 "증인이 없다" 를 보여야 한다. 시작: $H_8$ 과 $W_4-v_1v_2$ 에서 Kempe 연결 색칠 집합의 구조를 적는다. 난점: 3색 Kempe 체인은 셋째 색과 얽혀 조합적으로 복잡하다.
3. **홀수 교대 경로와 짝수 사이클의 관계 강화.** 무엇을: 따름 1.3 (위험 $\Rightarrow$ 짝수 사이클 위) 을 강화하여 "위험 $\Rightarrow$ $e$ 를 포함하는 짝수 사이클이 특정 구조 (예: 삼각형 쌍으로 된 사이클)" 를 증명할 수 있는지 본다. 왜: 현재 필요조건이 약하다 (짝수 사이클은 대부분의 간선이 가진다). 시작: $W_4$ 의 살과 테두리에서 짝수 사이클의 개수를 세고 강화 후보를 적는다. 난점: 짝수 사이클 조건은 2-색칠 (q=2) 에서만 깨끗하다.
4. **다이아몬드 강제의 일반화 (q=3 강제 원천 목록).** 무엇을: 다이아몬드 외에 $q=3$ 에서 강제를 만드는 소형 부분그래프 (예: 5-사이클에 허브를 더한 것, 두 삼각형의 공유 변) 를 목록화하고, 각각의 강제 쌍을 증명한다. 왜: T4 의 원천이 다이아몬드뿐이면 특성화 후보가 좁다. 시작: $K_4$-subdivision 과 odd wheel 에서 색칠 공간의 강제 쌍을 손으로 계산. 난점: 강제 쌍이 교대 사슬로 생기면 보조정리 2.1 같은 국소 증명이 안 된다.
5. **문헌 대조 (Hajós, Kempe 체인).** 무엇을: $H_8$ 과 T4 구조가 Hajós 구성, Kempe 체인에 관한 알려진 결과인지 확인한다. 왜: 신규성 판단이 필요하다. 시작: Hajós 합의 3-색칠 조건 정리를 찾는다. 난점: 인터넷이 막혀 있어 확인하지 못했다 `[기억-미검증]`.
