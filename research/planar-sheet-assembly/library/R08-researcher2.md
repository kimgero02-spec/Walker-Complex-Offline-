## 요약
- **설정.** $G$ 의 간선 $e=uv$, $q=\chi(G)$, $H=G-e$ 로 둔다. $e$ 가 **안전**하다는 것은 $\chi(G/e)\le q$ 이고, 이는 $\mathrm{Col}_q(H)$ 에 $c(u)=c(v)$ 인 색칠이 있다는 것과 동치이다 `[증명]` (보조정리 C 의 재기술). 이것은 필요충분 조건이지만 구조를 주지 않는다. 아래 두 기준이 구조이다.
- **분리 기준 (동치, 주어진 분리에 대해) `[증명]`.** $H=A\cup B$, $A\cap B=T$, $u\in A\setminus T$, $v\in B\setminus T$ 이면, 안전 $\iff$ $A$ 의 $q$-색칠이 $T\cup\{u\}$ 에 유도하는 분할 집합과 $B$ 의 것이 $T\cup\{v\}$ 에서 겹친다. 다리($T=\varnothing$) 는 항상 안전하다. 절단점 $T=\{w\}$ 에서는 **한 쪽은 $c(u)=c(w)$ 를 강제하고 다른 쪽은 $c(v)\ne c(w)$ 를 강제할 때에만** 위험하다.
- **고정 기준 (충분조건, 위험 쪽) `[증명]`.** $p\in N_H(v)$ 가 모든 $q$-색칠에서 $c(p)=c(u)$ 를 강제하면 $e$ 는 위험하다. 강제 쌍의 연쇄로 일반화해도 된다.
- **안전 쪽 충분조건 `[증명]`.** 다리이거나 $\chi(H)<q$ (임계 간선) 이면 안전하다. 두 쪽 모두 $u$ (또는 $v$) 를 절단점과 다른 색으로 칠할 수 있으면 안전하다.
- **완전 특성화 (q=2).** $\chi(G)=2$ 이면 안전 $\iff$ 다리 `[증명]`.
- **부정 결과.** 공통 이웃 수나 "공통 이웃 없음" 은 안전성을 가르지 못한다. 고정 기준은 필요조건이 아니다 (예 $H_8$). 분리 기준과 고정 기준이 위험을 모두 잡는지는 **미해결** `[추측]`.

## 본문

### 0. 표기
$H=G-e$, $q=\chi(G)$, $\mathrm{Col}_q(X)=\{c:V(X)\to[q]\ \text{적정}\}$. "$e$ 안전" 은 $\chi(G/e)\le\chi(G)$ 로 정의한다. $\chi(G/e)$ 는 $u,v$ 를 한 점으로 합친 그래프의 색칠수이다.

### 1. 기본 사실

**보조정리 1.1 (= 보조정리 C 의 재기술) `[증명]`.** $e$ 안전 $\iff$ $\exists\,c\in\mathrm{Col}_q(H)$ 에 대해 $c(u)=c(v)$.
- 증명. $G/e$ 의 $q$-색칠은 $c(u)=c(v)$ 인 $H$ 의 $q$-색칠과 같다. $\square$

**명제 1.2 `[증명]`.** $\chi(G/e)\le\chi(H)+1$. 따라서 $e$ 가 위험하면 $\chi(H)=q$ 이고 $\chi(G/e)=q+1$ 이다.
- 증명. $H$ 의 $k=\chi(H)$ 색칠에서 $u,v$ 에 새 색 $k+1$ 을 준다. $u,v$ 의 이웃은 모두 $\le k$ 색이므로 적정하다. 이것은 $G/e$ 의 적정 색칠이다. 위험하면 $\chi(G/e)>q\ge\chi(H)$ 이므로 $\chi(H)=q$ 이다. $\square$

**주의.** 수축은 $\chi$ 를 줄일 수도 있다. $W_5$ (허브 $h$ + 5-사이클) 에서 살 $hv_1$ 을 수축하면 팬 (fan) 이 되어 $\chi$: 4 → 3 이다 `[증명]`. 그래서 "안전" 은 $\le$ 방향만 본다.

### 2. 분리 기준

**설정.** $H=A\cup B$ 이고 $A\cap B=T$, $u\in A\setminus T$, $v\in B\setminus T$, 그리고 $A\setminus T$ 와 $B\setminus T$ 사이에 변이 없다. $A$ 의 $q$-색칠 $c$ 에 대해 $\pi_c^u$ 를 $T\cup\{u\}$ 위에서 "같은 색" 관계가 만드는 분할로 둔다. 같은 방식으로 $\pi_c^v$ 를 $T\cup\{v\}$ 위에서 정의한다. 
$$\Pi_A(u)=\{\pi^u_c:c\in\mathrm{Col}_q(A)\},\qquad \Pi_B(v)=\{\pi^v_c:c\in\mathrm{Col}_q(B)\}.$$
두 분할이 "같다" 는 것은 $T$ 위의 분할이 같고, $u$ 와 $v$ 가 같은 블록에 속하는 $T$ 의 원소가 같다는 뜻이다 (즉 $u$ 를 $v$ 로 바꾸어 비교).

**정리 2.1 `[증명]`.** 위 설정에서 $H$ 에 $c(u)=c(v)$ 인 $q$-색칠이 있다 $\iff$ $\Pi_A(u)\cap\Pi_B(v)\neq\varnothing$.
- ($\Rightarrow$) $c$ 가 그런 색칠이면 $c|_A$, $c|_B$ 에서 $T\cup\{u\}$ 와 $T\cup\{v\}$ 의 분할은 $c(u)=c(v)$ 이므로 같다.
- ($\Leftarrow$) $\pi\in\Pi_A(u)\cap\Pi_B(v)$ 를 실현하는 $c_A\in\mathrm{Col}_q(A)$, $c_B\in\mathrm{Col}_q(B)$ 를 잡는다. 부분 함수 $\sigma$ 를 $c_B(t)\mapsto c_A(t)$ ($t\in T$), $c_B(v)\mapsto c_A(u)$ 로 정의한다. 분할이 같으므로 well-defined 이고 단사이다. 이를 $[q]$ 의 순열로 확장한다. $c:=c_A$ (on $A$), $\sigma\circ c_B$ (on $B$) 는 $T$ 위에서 일치한다. 모든 변은 $A$ 또는 $B$ 안에 있으므로 $c$ 는 적정이고, $c(u)=c(v)$ 이다. $\square$

**계 2.2 (다리) `[증명]`.** $T=\varnothing$ 이면 두 분할은 모두 한 블록짜리이므로 항상 겹친다. 따라서 $u,v$ 가 $H$ 의 다른 성분에 있으면 $e$ 는 안전하다. (이 경우 $\chi(G)=\max$ 이고, 한 성분의 색 이름을 바꾸어 맞추는 것과 같다.)

**계 2.3 (절단점) `[증명]`.** $T=\{w\}$ 이면 $\Pi_A(u)\subseteq\{S,D\}$ 이다. 여기서 $S$ 는 $c(u)=c(w)$, $D$ 는 $c(u)\ne c(w)$ 이다. 그러면
- 두 쪽이 모두 $D$ 를 가지면 (또는 모두 $S$ 를 가지면) 안전하다.
- 위험 $\iff$ $\{\Pi_A(u),\Pi_B(v)\}=\{\{S\},\{D\}\}$. 
- $\Pi_A(u)=\{S\}\iff\chi(A+uw)>q$ (단 $uw\notin E(A)$). $\Pi_B(v)=\{D\}\iff \chi(B/vw)>q$ (단 $vw\notin E(B)$; $vw\in E(B)$ 이면 $\Pi_B(v)=\{D\}$ 자동).

### 3. 고정 기준 (위험 쪽 충분조건)

**정의.** $H$ 에서 $p$ 가 $u$ 에 **고정** 되었다는 것은 모든 $c\in\mathrm{Col}_q(H)$ 에 $c(p)=c(u)$ 인 것이다. 동치로 $\chi(H+up)>q$ 이다.

**명제 3.1 `[증명]`.** $p\in N_H(v)$ 가 $u$ 에 고정되어 있으면 $e$ 는 위험하다.
- 증명. 임의의 $c\in\mathrm{Col}_q(H)$ 에 대해 $c(u)=c(p)\ne c(v)$ 이다. 보조정리 1.1 에 의해 위험하다. $\square$

**명제 3.2 (연쇄) `[증명]`.** $p$ 가 $u$ 에 고정되고 $r$ 이 $v$ 에 고정되고 $p\sim r$ (in $H$) 이면 $e$ 는 위험하다. 증명은 $c(u)=c(p)\ne c(r)=c(v)$ 이다. $\square$

**고정 기구 (보조 補題) `[증명]`.** $K$ 가 $(q-1)$-클리크이고 $a,b$ 가 모두 $K$ 와 완전 연결이며 $a\not\sim b$ 이면, 모든 $q$-색칠에서 $c(a)=c(b)$ 이다. ($K$ 의 $q-1$ 색을 뺀 나머지 색은 하나뿐이다.) 이 기구로 $q=3$ 에서 "다이아몬드" (두 삼각형을 변 공유) 의 꼭짓점 두 개를 고정할 수 있다.

### 4. 안전 쪽 충분조건 정리

**명제 4.1 `[증명]`.** (a) $e$ 가 다리이면 안전 (계 2.2). (b) $\chi(H)<\chi(G)$ 이면 안전 (명제 1.2, $\chi(G/e)\le\chi(H)+1\le q$). (c) 절단점 $w$ 에서 $\Pi_A(u)\cap\Pi_B(v)\ni D$ 이면 안전 (정리 2.1).

### 5. 완전 특성화: $q=2$

**명제 5.1 `[증명]`.** $\chi(G)=2$ 이면 $e$ 가 안전 $\iff$ $e$ 가 다리.
- 증명. $G$ 는 이분 그래프이고 $e$ 는 두 부분 사이를 잇는다. $e$ 가 다리가 아니면 $H$ 에서 $u,v$ 는 같은 연결 성분에 있다. 연결된 이분 그래프의 2-색칠은 두 가지뿐이고 $u,v$ 는 다른 부분에 있으므로 $c(u)\ne c(v)$ 가 강제된다. 위험하다. 다리이면 계 2.2 로 안전. $\square$
- 이 경우 고정 기준은 완전하다. $u,v$ 의 최단 경로에서 $v$ 의 전 이웃 $p$ 는 짝수 거리이므로 $u$ 에 고정된다.

### 7. 장애물과 부정 결과

1. **공통 이웃 기준은 실패한다.** $C_3$ 은 공통 이웃이 있고 안전하다 (임계 간선). $C_4$ 는 공통 이웃이 없고 위험하다. $W$ 는 공통 이웃 $z$ 가 있고 위험하다. 따라서 "$N(u)\cap N(v)=\varnothing$" 같은 국소 조건은 안전을 보장하지 않는다 `[증명]`.
2. **고정 기준은 필요조건이 아니다.** $H_8$ 이 반례이다 `[계산 확인 + 증명]`. 연쇄 (명제 3.2) 도 충분하지 않다는 것은 보이지 못했다.
3. **분리 기준은 분리가 있을 때만 정보를 준다.** 3-연결에 가까운 $H$ 에서는 정리 2.1 이 쓸 수 있는 $(A,B;T)$ 가 없다. 이 경우의 위험 판정은 미해결이다.
4. **"위험 $\iff$ 분리 충돌 또는 고정 연쇄" 는 증명하지 못했다** `[추측]`. $q=2$ 에서는 성립한다 (명제 5.1). $q\ge 3$ 에서는 Kempe 사슬 류 논법이 필요할 것으로 보인다.
5. **모든 $q$-색칠 강제는 전역 성질이다.** 정리 2.1 은 분리 쌍마다 $\Pi$ 를 계산하므로, 여러 분리가 겹치면 $\Pi$ 들이 사슬을 이루며 합성되는지는 확인하지 못했다 (R07-researcher1 의 홀로노미 장애물과 같은 종류).

### 8. 관련 문헌 (확인 불가)
$H_8$ 과 $K_4$ 한 변 세분의 구조는 Hajós 구성 (두 $k$-임계 그래프의 변 삭제 후 한 점 동일시와 교차 변) 과 닮았다 `[기억-미검증]`. 확인하지 못했다. 신규성은 주장하지 않는다.

## 후속연구 지점
1. **$q=3$ 에서 위험 판정의 완전 특성화 시도** (우선순위 최상). 무엇을: "모든 3-색칠에서 $c(u)\ne c(v)$" 가 분리 충돌이나 고정 연쇄로 설명되는지 본다. 왜: 현재 충분조건 두 개뿐이고, $H_8$ 은 단순 고정 기준이 실패하는 예다. 시작 방법: $H$ 가 3-연결이고 분리가 없는 작은 후보 (Moser 류, Mycielski 류의 4-5 점 소형) 중에서 위험인 것을 하나 찾고, 그 색칠 공간을 Kempe 사슬로 정리한다. 난점: 소형 반례 찾기가 전수 점검으로 흐르지 않도록 손으로 정선해야 한다.
2. **안전 수축의 합성 정리** (우선순위 높음). 무엇을: 안전 간선만 수축하는 열 $G\to G/e_1\to G/e_1e_2\to\cdots$ 가 $\chi$ 를 올리지 않는다는 것은 자명하다. 하지만 연쇄 수축 $G\to G/T$ (연결 집합 $T$) 는 단계별 안전성과 어떻게 관계하는가? 왜: 예 $\Pi/\{a,b,c\}=K_4$ 에서 첫 단계 $\Pi/ab$ 는 안전하고 둘째 단계 $mc$ 는 위험하다 (표). 시작 방법: $T$ 가 삼각형일 때 단계별 안전 순서가 $K_4$ 의 발생을 막는지 조사. 난점: 단계마다 $\Pi$ 가 달라진다.
3. **분리 기준의 $\Pi$ 대수화.** 무엇을: 분리 $(A,B;T)$ 의 분할 집합 $\Pi$ 가 합성 (두 분리를 이어 붙이기) 에서 닫히는 대수 구조를 정의한다. 왜: 정리 2.1 은 두 분리 사이의 $\Pi$ 만 본다. 여러 분리가 사슬을 이루면 R07-researcher1 의 홀로노미 문제가 된다. 시작 방법: $T=\{w\}$ 인 경우 $\{S,D\}$ 의 합성표를 적고 $C_5$ 같은 사슬 예에 적용. 난점: 분할 집합의 합성이 교환 법칙을 가지는지 불명.
4. **$\chi$ 를 올리지 않는 마이너 관계 $\preceq_{\text{안전}}$ 의 정의와 성질.** 무엇을: 안전 수축만 허용하는 관계가 $R07$ 의 $\preceq_1$ (다리 수축) 을 포함하는지, 또 추이적인지 확인한다. 왜: R07-researcher2 는 마이너 관계가 단조가 아님을 보였다 (예 $C_4\to C_3$). 안전 수축을 쓰면 단조성이 자동으로 나오는지 궁금하다. 시작 방법: $\preceq_1$ 의 간선 수축을 안전 수축으로 바꾸고 명제 4.1 로 충분 조건을 정리. 난점: 안전 여부가 그래프마다 전역적이라 정의가 순환할 수 있다.
5. **문헌 대조 (Hajós 구성).** 무엇을: $H_8$ 과 $K_4$ 세분의 위험 구조가 Hajós 구성의 알려진 성질인지 확인한다. 왜: 신규성 판단이 필요하다. 시작 방법: Hajós 합의 정의에서 $\chi$ 의 공식을 확인. 난점: 인터넷이 막혀 있어 문헌을 확인하지 못했다 `[기억-미검증]`.
