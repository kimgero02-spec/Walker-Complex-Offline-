# [N-T1-researcher1] 식별 간선 설명서 $\Gamma$: 복원은 참, "$\chi$ 결정"은 데이터를 분할 프로필로 올려야 참

논객 갑 (researcher1, 증명 중심). 포메이션 N 턴 1, 블라인드 입론. 계산 스크립트: `rooms/researcher1/nt1.py`.

## 결론

**조건부.** STMT 는 세 부분으로 나뉘고 판정이 서로 다르다.

1. **복원 (사상 없이 $G=\Gamma/E_J$):** 조건 (W) "$E_J$ 의 각 연결 성분은 각 조각과 많아야 한 점에서 만난다" 아래에서 **참** [증명]. (W) 가 깨지면 고리(loop)가 생기거나 조각이 접혀서 부분그래프가 되지 않는다. 사상 데이터는 사라진 것이 아니라 $E_J$ 의 성분 구조로 옮겨 적힌 것이다. 이 옮겨 적기는 정보 손실 없이 서로 바꿀 수 있다 [증명].
2. **$\chi(G)$ 가 $\Gamma$ 로 결정됨:**
   - 글자 그대로 읽으면 **참이지만 동어반복**이다. $\Gamma$ 가 $G$ 를 복원하므로 $G$ 의 모든 불변량이 결정된다. 이 경우 $\chi(G)=\chi_{\rm mix}(\Gamma)$ 로, 조각 간선에서는 "다른 색", $E_J$ 간선에서는 "같은 색"을 요구하는 $\Gamma$ 의 혼합 색칠수가 된다 [증명].
   - 문주님 요구("조각들의 그래프적 정보, 예: 색칠수 + 설명서의 구조")로 읽으면 **거짓**이다 [증명 + 계산 확인]. $\chi(P_k)$, 조각의 평면성, 점·변 수, $E_J$ 의 모양, 접합 쌍의 간선 비트까지 모두 같은데 $\chi(G)$ 가 3 과 4 로 갈리는 쌍이 있다 (예 2). 보통 색칠수 $\chi(\Gamma)$ 도 $\chi(G)$ 를 주지 못한다 ($K_4$ 예: $\chi(\Gamma)=3$, $\chi(G)=4$).
   - **올바른 데이터로 바꾸면 참:** 조각별 **분할 프로필** $\Pi_q(P_k,J_k)$ 와 $E_J$ 의 성분 구조만으로 $\chi(G)$ 가 결정된다 (정리 2) [증명]. 또 이 데이터는 줄일 수 없다. 프로필이 다른 두 조각은 어떤 상대 조각을 붙이면 반드시 구별된다 (정리 3) [증명]. 다만 상대 조각을 평면으로 제한하면 $q\ge4$ 에서 최소성 증명이 막힌다.
3. **평면성이 $\Gamma$ 로 결정됨:** 글자 그대로는 동어반복으로 참이다. 굵은 데이터(조각의 평면성 플래그, 점·변 수, 차수열, $E_J$ 모양, 간선 비트)로는 **거짓**이다 [증명 + 계산 확인, 예 4]. 한 방향은 성립한다: $\Gamma$ 가 평면이면 $G$ 도 평면이다 [증명]. 평면성의 "프로필"을 명시적으로 쓰는 것은 아직 못 했다 [추측, 장애물 적음].

한 줄로: **$\Gamma$ 는 $G$ 를 복원한다. 하지만 $\chi(G)$ 를 읽으려면 "조각의 색칠수"가 아니라 "조각이 접합점에 허락하는 색 분할의 집합"이 필요하다.**

## 근거

### 0. 정의 (사상 없는 설명서)
$\Gamma=(V,\ E_P\sqcup E_J)$ 이고 $V=\bigsqcup_k V(P_k)$ 이다. $E_P$ 는 각 조각 안의 간선, $E_J$ 는 서로 다른 조각의 점을 잇는 식별 간선이다. $[x]$ 는 그래프 $(V,E_J)$ 에서 $x$ 가 속한 성분(**식별류**)이다.
- (W) 각 식별류 $C$ 와 각 $k$ 에 대해 $|C\cap V(P_k)|\le1$.
- $G:=\Gamma/E_J$. 점은 식별류이고, 간선은 $\{[x][y]: xy\in E_P\}$ 이다 (중복은 합친다).
- $J_k:=\{x\in V(P_k): x \text{ 가 } E_J \text{ 의 끝점}\}$ 이고, $\mathcal J$ 는 두 조각 이상과 만나는 식별류의 집합이다.

### 1. 복원 [증명]
**보조정리 1.** (W) 아래에서 다음이 성립한다.
(a) $G$ 는 고리가 없는 단순 그래프다.
(b) $\iota_k: x\mapsto[x]$ 는 $P_k\to G$ 로의 단사 준동형이고 $G=\bigcup_k\iota_k(P_k)$ 이다.
(c) $\iota_k(V(P_k))\cap\iota_l(V(P_l))$ 은 $P_k$ 와 $P_l$ 을 함께 만나는 식별류들이다.
(d) $G$ 는 $E_J$ 자체가 아니라 식별류 분할에만 의존한다.

*증명.* (a) $xy\in E_P$ 이면 $x$ 와 $y$ 는 같은 조각에 있는 서로 다른 점이다. (W) 에 의해 같은 식별류에 들 수 없으므로 $[x]\ne[y]$ 이다. (b) 단사성은 (W) 에서 나오고, 간선이 간선으로 가는 것은 정의에서 나온다. $G$ 의 점과 간선은 모두 어느 조각의 상이므로 합집합이 $G$ 다. (c) 정의에서 바로 나온다. (d) 몫은 성분에만 의존한다. $\square$

**사상판과 같은 정보.** 스팬 설명서(조각 + 공유 그래프 + 단사 쌍, R01)가 주어지면, 각 식별류에 아무 생성 나무를 골라 $E_J$ 로 쓴다. (d) 에 의해 어떤 나무를 골라도 $G$ 는 같다. 거꾸로 $\Gamma$ 가 주어지면 식별류가 공유 점이 되고, 공유 간선은 $G$ 에서 겹치는 간선의 원상으로 읽힌다. 따라서 "사상 없이"는 정보를 잃지 않는 재부호화다. 단, $\Gamma\mapsto G$ 는 단사가 아니다 (같은 식별류에 경로를 쓰든 별을 쓰든 $G$ 는 같다). 따라서 $\Gamma$ 는 $G$ 의 불변량이 아니라 $G$ 의 **표현**이다.

**주의 (빈틈의 정체).** $\iota_k(P_k)$ 는 $G$ 의 **유도** 부분그래프가 아닐 수 있다. $K_4$ 예에서 $uv$ 는 $P_1$ 에서는 간선이 아닌데 $G$ 에서는 간선이다. 이 "간선 비트"는 $\Gamma$ 에서 읽을 수 있다 ($[u][v]\in E(G)$ 인지 보면 된다). 하지만 아래 예 2 처럼 간선 비트만으로는 모자란다.

### 2. $\chi(G)$ 의 결정
**정의.** $\Pi_q(P,J)=\{\ker(c|_J) : c \text{ 는 } P \text{ 의 올바른 } q\text{-색칠}\}$ 이다. $\ker$ 는 $J$ 를 "같은 색끼리" 묶은 분할이다 (색 이름은 잊는다).

**정리 2.** (W) 아래에서 $G$ 가 $q$-색칠 가능할 필요충분조건은, 함수 $f:\mathcal J\to[q]$ 가 있어 모든 $k$ 에 대해 $\ker\bigl(f\circ[\cdot]\,|_{J_k}\bigr)\in\Pi_q(P_k,J_k)$ 인 것이다. 따라서
$$\chi(G)=\min\{q:\ \text{위의 } f \text{ 가 존재}\}$$
이고, 이것은 $\bigl(\Pi_q(P_k,J_k)\bigr)_{k,q}$ 와 사상 $J_k\to\mathcal J$ (곧 $E_J$ 의 식별류 구조) 만으로 정해진다. $G$ 를 만들 필요가 없다.

*증명.* (⟹) $G$ 의 $q$-색칠 $c$ 에서 $f=c|_{\mathcal J}$ 로 둔다. $c\circ\iota_k$ 는 $P_k$ 의 올바른 색칠이고 (보조정리 1(b)), 그 $J_k$ 위 분할이 바로 $\ker(f\circ[\cdot]|_{J_k})$ 다.
(⟸) 각 $k$ 에 대해, 프로필 원소 $\pi_k=\ker(f\circ[\cdot]|_{J_k})$ 를 실현하는 $P_k$ 의 색칠 $c_k$ 를 잡는다. $c_k|_{J_k}$ 와 $f\circ[\cdot]|_{J_k}$ 는 같은 분할을 이루므로, 블록 대응 $c_k(B)\mapsto f(B)$ 는 단사다. 이를 $[q]$ 의 순열 $\sigma_k$ 로 늘려 $c_k':=\sigma_k\circ c_k$ 로 둔다. 그러면 $c_k'=f\circ[\cdot]$ 가 $J_k$ 위에서 성립한다. $G$ 의 점 $[x]$ 에서 $c([x])$ 를 이렇게 정한다. $[x]\in\mathcal J$ 이면 $f([x])$ 이고, 아니면 $x$ 를 담은 유일한 조각 $k$ 의 $c_k'(x)$ 다. 이 값은 잘 정의된다. 모든 간선 $[x][y]$ 는 어느 $xy\in E(P_k)$ 의 상이고 $c_k'$ 가 올바른 색칠이므로 $c([x])\ne c([y])$ 다. $\square$

**따름 정리.**
- $\chi(P_k)=\min\{q:\Pi_q(P_k,J_k)\ne\emptyset\}$ 이다. 따라서 조각의 색칠수는 프로필의 그림자에 불과하다.
- 간선 비트 "$xy\in E(P_k)$" 는 "$x,y$ 를 한 블록에 넣는 분할이 $\Pi_q$ 에 없음" 의 특수한 경우다. 그 역은 성립하지 않는다 (예 2 의 $A_2$: $u,v$ 는 간선이 아닌데 강제로 다른 색).
- 접합 집합이 하나인 경우가 R03 정리 1 ($\chi=\min_\pi\max_k\chi_\pi$) 이다. R04 나무 공식은 나무형 식별 구조에서 $f$ 의 존재를 메시지 전파로 푼 것이다. 정리 2 는 이 둘을 임의의 $E_J$ (사이클 포함) 로 넓힌 판이다 [증명].
- $\chi(G)=\chi_{\rm mix}(\Gamma)$ 이다. 여기서 $\chi_{\rm mix}(\Gamma)$ 는 $E_P$ 에서 $\ne$, $E_J$ 에서 $=$ 를 지키는 최소 색 수다. 이것은 동어반복이지만, 사상 없는 간선 2-색 그래프 $\Gamma$ 의 그래프 불변량이라는 점에서 문주님 요구의 글자 그대로의 형태를 만족한다.

**정리 3 (프로필의 최소성).** $|J|=s$ 를 고정하고 $\Pi_q(P,J)\ne\Pi_q(P',J)$ 라 하자. 그러면 $J$ 에서 붙이는 조각 $Q$ 가 있어서, $P\cup_JQ$ 와 $P'\cup_JQ$ 중 정확히 하나만 $q$-색칠 가능하다.

*증명.* $\pi\in\Pi_q(P)\setminus\Pi_q(P')$ 라 하자 (반대 경우도 대칭이다). $\pi$ 의 블록을 $B_1,\dots,B_r$ ($r\le q$) 이라 한다. $Q_\pi$ 를 다음과 같이 만든다: 새 클릭 $z_1,\dots,z_q$ 를 두고, $x\in B_i$ 를 모든 $z_j$ ($j\ne i$) 에 잇는다. $Q_\pi$ 의 $q$-색칠에서 $z$ 들은 모든 색을 쓰므로 $c(x)=c(z_i)$ 가 강제된다. 따라서 $\Pi_q(Q_\pi,J)=\{\pi\}$ 다. 정리 2 를 적용하면, $P\cup_JQ_\pi$ 는 $\pi\in\Pi_q(P)$ 이므로 $q$-색칠 가능하고, $P'\cup_JQ_\pi$ 는 $\pi\notin\Pi_q(P')$ 이므로 불가능하다. $\square$

따라서 "$\chi$ 를 읽는 데 필요한 조각의 정보"는 정확히 $(\Pi_q)_q$ 다. 그보다 굵은 어떤 데이터 ($\chi(P_k)$, 간선 비트, 평면성 등) 도 모든 상대 조각에 대해 $\chi$ 를 정하지 못한다. 이것은 Myhill–Nerode 꼴의 진술이다.

**장애물 (평면 상대 조각).** $q=3$ 에서는 $Q_\pi$ 가 평면이다 (삼각형 $z_1z_2z_3$ 의 각 변에 차수 2 점을 여럿 붙인 꼴, $K_{2,n}$+변 형). $q=4$ 에서는 같은 $B_i$ 에 두 점이 있으면 $\{z_j\}_{j\ne i}$ 세 점과 그 두 점, 그리고 $z_i$ 가 $K_{3,3}$ 을 이루어 비평면이 된다. 그래서 "조각을 평면으로 제한한 세계"에서 $\Pi_4$ 가 최소 데이터인지는 증명하지 못했다. 4색 정리 때문에 평면 세계의 $\Pi_4$ 는 항상 비어 있지 않다. 따라서 평면 세계에서는 더 굵은 데이터로 충분할 가능성이 있다 [추측].

### 3. 평면성
- **명제 4a [증명].** $\Gamma$ 가 평면이면 $G$ 도 평면이다. 축약은 평면성을 보존하고, $G$ 는 $\Gamma$ 에서 $E_J$ 를 축약하고 중복 간선을 지운 마이너다.
- **명제 4b [증명 + 계산 확인].** 굵은 데이터로는 결정되지 않는다. 두 설명서를 비교한다.
  - 갑: $P_1=K_{3,3}-xy$, $P_2=K_2=xy$.
  - 을: $P_1'=$ 프리즘 $C_3\times K_2$ 에서 가로대 하나 $xy$ 를 뺀 것, $P_2=K_2$.

  두 $P_1$ 은 모두 평면이고, 6점 8변, 차수열 $(2,2,3,3,3,3)$ 이다. $x,y$ 는 둘 다 간선이 아닌 차수 2 점이다. $E_J$ 도 같다 (두 식별 간선). 그런데 $G$ 는 갑이 $K_{3,3}$ 으로 비평면이고, 을이 프리즘으로 평면이다.
- **차이를 만드는 데이터 [기억-미검증, 2-합 표준 사실].** 접합점이 둘인 경우 판정 비트는 "$P_k+xy$ 가 평면인가" 다. 일반적인 대응물은 "접합점들이 놓일 수 있는 면 배치의 집합"인 매장 프로필 $\mathrm{Emb}(P_k,J_k)$ 일 것이다 [추측]. 장애물은 둘이다. $E_J$ 의 식별 구조에 사이클이 있으면 종수가 붙임 방식 자체에서 생긴다 (R01 홀로노미, $\chi(X)$ 항). 또 정리 2 의 "$f$ 의 존재" 같은 국소 조건으로 쪼개지지 않는다. 대신 R02 정리 R2-A (3-연결 조각이면 $[\varepsilon]=0$ 이고 오일러 지표 조건) 가 사이클이 있는 경우의 조건부 답이다. 그 정리는 레이블 $\varepsilon$ 을 쓰고, $\varepsilon$ 은 $\Gamma$ 의 식별 간선과 조각의 회전에서 읽어야 한다. 이 번역은 아직 하지 않았다.

## 계산 확인
스크립트 `rooms/researcher1/nt1.py` (networkx, 백트래킹 색칠). 계산은 아래 결정적인 예들의 확인에만 썼고, 전수 점검은 근거로 쓰지 않았다.

**예 1: $K_4=(K_4-uv)\cup K_2$** [계산 확인]
- 복원: $\Gamma/E_J\cong K_4$ ✓.
- $\chi(P_1)=3$, $\chi(P_2)=2$, $\chi(G)=4$.
- $\Pi_3(P_1,\{u,v\})=\{\{uv\}\}$ ($u,v$ 같은 색 강제), $\Pi_3(P_2)=\{\{u|v\}\}$ 로 교집합이 비어 3 이 불가능하다. $\Pi_4(P_1)=\{\{uv\},\{u|v\}\}$ 이므로 $q=4$ 에서 성립한다.
- 프로필만으로 계산한 값은 4 ✓, $\chi_{\rm mix}(\Gamma)=4$ ✓. 반면 보통 색칠수 $\chi(\Gamma)=3$ ✗.
- $\Gamma$ 가 $\chi$ 를 결정하는 것은 프로필을 통해서이고, $\Gamma$ 의 보통 색칠수를 통해서가 아니다.

**예 2: 굵은 데이터가 같은데 $\chi$ 가 다름** [계산 확인 + 증명]
- 두 설명서 모두 $P_1=K_4-uv$ 이고, 두 식별 간선 $u\!-\!u$, $v\!-\!v$ 를 쓴다.
  - $A$: $P_2=$ 다이아몬드$(u,a,b,w)$ $+\,wv$.
  - $B$: $P_2'=$ 다이아몬드$(u,a,b,v)$ $+$ 매달린 점 $z$.
- 두 $P_2$ 는 모두 평면이고, 5점 6변, $\chi=3$, $uv$ 는 간선이 아니다.
- $\Pi_3(P_2)=\{\{u|v\}\}$, $\Pi_3(P_2')=\{\{uv\}\}$ 다.
- 결과: $\chi(G_A)=4$, $\chi(G_B)=3$ 이다. 두 $G$ 는 모두 평면이고, 두 $\Gamma$ 는 보통 색칠수가 모두 3 이다.
- 증명: $A$ 에서는 $P_1$ 이 $c(u)=c(v)$ 를, $P_2$ 가 $c(u)\ne c(v)$ 를 강제하므로 3색이 불가능하다. $B$ 에서는 둘 다 같음을 강제하므로 3색이 가능하다.
- 차수열은 다르다 ($[1,2,3,3,3]$ 과 $[1,2,2,3,4]$). 차수열까지 맞춘 쌍은 만들지 않았다.

**예 3: 정리 3 의 가제트** [계산 확인] ($q=3$, $J=\{u,v\}$)
- $Q_{\{uv\}}$ 의 프로필은 $\{\{uv\}\}$, $Q_{\{u|v\}}$ 의 프로필은 $\{\{u|v\}\}$ 다.
- 다이아몬드와 붙이면 각각 가능/불가능, $A_2$ 와 붙이면 각각 불가능/가능이다. 프로필이 다른 두 조각을 가제트가 구별한다 ✓.

**예 4: 평면성** [계산 확인]
- $K_{3,3}-xy$ 와 (프리즘 $-$ 가로대) 는 둘 다 평면이고, 6점 8변, 차수열 $[2,2,3,3,3,3]$, $xy$ 는 간선이 아니다.
- $K_2$ 를 붙이면 앞의 것은 비평면, 뒤의 것은 평면이다 ✓.

## 자가 진단
가장 약한 고리부터 적는다.

1. **"결정된다"의 뜻이 미끄럽다 (가장 약함).** 정리 2 의 프로필 $\Pi_q(P_k,J_k)$ 는 사실상 "$P_k$ 를 $J_k$ 경계에서 색칠해 보는 계산"이다. 연구원2 는 이렇게 공격할 것이다. "그건 그래프적 정보(색칠수 같은 수)가 아니다. 결국 $G$ 를 조각마다 나눠 칠하는 것이니 STMT 의 정신('조각의 색칠수로 읽는다')은 거짓이다." 내 답: 정리 3 이 그보다 굵은 데이터로는 **불가능함을 증명**한다. 따라서 문주님 요구를 만족하는 가장 굵은 정보가 바로 프로필이다. 다만 이것이 "만족"인지 "불가능 판정"인지는 해석의 문제이고, 판정단이 정해야 한다.
2. **평면 세계에서의 최소성 (정리 3) 은 $q\le3$ 에서만 증명했다.** 평면 조각만 허락하면 $q=4$ 가제트가 비평면이 된다. 연구원2 는 "평면 조각 세계에서는 더 굵은 데이터로 충분하다" 또는 반대로 "평면 가제트로도 $\Pi_4$ 의 모든 차이를 구별한다"를 보이려 할 수 있다. 어느 쪽이든 내 진술의 그 부분은 열려 있다.
3. **조건 (W).** 식별류가 한 조각을 두 번 만나는 "접힌" 설명서를 허락하면 복원은 여전히 정의되지만, 고리가 생겨 $G$ 가 색칠 불가능해지거나 $\iota_k$ 가 단사가 아니게 된다. 공격 예상: "(W) 없이는 STMT 가 거짓". 맞다. 그래서 결론을 조건부로 했다.
4. **비유일성.** 같은 $G$ 에 서로 다른 $\Gamma$ 가 많다 (식별류 안의 경로냐 별이냐, 조각 분해 자체의 선택). "$\Gamma$ 의 그래프 불변량 (예: $\chi(\Gamma)$, $\Gamma$ 의 평면성) 이 $G$ 의 불변량이 아니다"는 공격은 맞다. 실제로 예 1 에서 $\chi(\Gamma)\ne\chi(G)$ 다. 그래서 나는 $\chi_{\rm mix}$ 와 프로필로 주장을 좁혔다. 명제 4a 의 역 ($G$ 평면 ⟹ 적당한 $\Gamma$ 평면?) 은 다루지 않았다. 고정된 $\Gamma$ 에서는 거짓일 것이다 [추측].
5. **예 2 는 차수열이 다르다.** "차수열까지 같으면 결정된다"는 공격은 약하다고 보지만, 같은 차수열의 쌍은 만들지 않았다.
6. **평면성 쪽은 부정적 결과(명제 4b)와 한 방향(4a)뿐이다.** 매장 프로필의 정리는 [추측] 이고, 2-합 판정 비트는 [기억-미검증] 이다.

## 후속연구 지점
1. **(우선 1) 평면 조각 세계에서 정리 3 ($q=4$).** 이유: 문주님 설정은 평면 조각이고, 이 세계에서 최소 데이터가 $\Pi_4$ 인지 더 굵은지가 STMT 의 정확한 답이다. 시작 방법: $|J|=2,3$ 에서 $\Pi_4$ 의 가능한 값들(평면 조각이 실현하는 것)을 연역으로 분류하고, 각 쌍을 구별하는 평면 가제트를 만든다 (R04 의 $K_{1,1,3}$ 잎, R05 의 R5 정리가 재료). 난점: 4색 정리 때문에 평면 가제트는 분할을 하나로 강제하지 못한다.
2. **(우선 2) 평면성의 매장 프로필 정리.** 이유: STMT 의 평면성 절반에 대한 정리 2 의 대응물이 없다. 시작 방법: 식별 구조가 나무인 경우부터 시작해, $\mathrm{Emb}(P,J)$ 를 "$J$ 의 면 배치 (어느 점들이 한 면에, 어떤 순환 순서로)"로 정의하고 2-합·3-합 고전 결과로 귀납한다. 사이클이 있는 경우는 R02 R2-A 의 $\varepsilon$ 을 $\Gamma$ 에서 읽는 번역부터 한다. 난점: 종수가 붙임 방식에서 생기므로 국소 조건으로 쪼개지지 않는다.
3. **(우선 3) 프로필의 압축.** 이유: $|J_k|$ 가 크면 $\Pi_q$ 는 거대하다. 시작 방법: $\Pi_q$ 를 "강제된 같음/다름" 쌍 그래프 (간선 비트의 확장: 같은 색 강제 $=$, 다른 색 강제 $\ne$) 로 근사하고, 근사가 정확해지는 조건 ($|J|\le2$ 이면 정확, $|J|=3$ 에서는 R03 E6 이 깨뜨림) 을 증명한다. 난점: $|J|=3$ 부터는 쌍별 정보로 분할 집합이 정해지지 않는다.
4. **(우선 4) 차수열까지 같은 예 2 쌍과, 명제 4a 의 역의 고정-$\Gamma$ 반례.** 시작 방법: 손으로 구성한다. 난점은 작다.
