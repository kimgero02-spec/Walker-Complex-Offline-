# [R09-researcher1] 접합 크기 $s\ge2$ 고리의 파티션 대수 채널 분해

- 작성자: researcher1 · 라운드 R09 · 역할: 연구원 (색칠수 쪽)
- 계산 코드 (모두 `rooms/researcher1/` 아래): `r09_channel.py` (S_q 등유형 사영으로 채널 값 계산, K4 3-고리 $q\le8$), `r09_m2.py` (m=2, 접합 크기 2 의 K4 분해), `r09_scan.py` (m=2, 접합 $\{1,2\},\{3,4\}$ 의 모든 간선 조합 스캔, $q=4,5$), `r09_fit.py` (C4 예의 채널 다항식 맞춤, $q=4..10$)
- 선행: R08 Prop 2 (트레이스 항등식), Prop 2' (판정), Thm 3 (접합 크기 1 의 닫힌 식), §6.1 (접합 크기 $\ge2$ 장애물).

## 요약
1. **채널 정리 (C1, C2).** 접합 크기 $s$ 인 고리에서 $P_G(q)=\sum_\lambda d_\lambda\,\mathrm{tr}\big(\rho_\lambda(N_1)\cdots\rho_\lambda(N_m)\big)$ 이다. 여기서 $\lambda$ 는 $S_q$ 의 기약표현 중 $V^{\otimes s}$ ($V=\mathbb C^q$) 에 나타나는 것, $d_\lambda=\dim S^\lambda$, $\rho_\lambda$ 는 교환자 대수 $\mathrm{End}_{S_q}(V^{\otimes s})\cong\bigoplus_\lambda\mathrm{End}(M_\lambda)$ 의 사영이다 `[증명]`. 이것이 R08 Thm 3 의 두 채널 분해를 일반 $s$ 로 옮긴 것이다. 다중도 $m_\lambda(s)=\sum_k S(s,k)K_{\lambda,(q-k,1^k)}$ 와 $\sum_\lambda m_\lambda^2=\mathrm{Bell}(2s)$ ($q\ge2s$) 를 증명했다 `[증명]`. $s=2$ 에서 채널은 $\mathrm{triv}\,(m=2)$, $\mathrm{std}\,(m=3)$, $(q-2,2)\,(m=1)$, $(q-2,1,1)\,(m=1)$ 이고 $2^2+3^2+1+1=15=\mathrm{Bell}(4)$ 이다.
2. **혼합 크기 (C3).** 고리의 접합 크기가 섞여 있으면, 가장 작은 접합 $c$ (크기 $t$) 에서 잘라 얻은 합성 $T_c\in\mathrm{End}_{S_q}(V^{\otimes t})$ 로 $P_G=\mathrm{Tr}\,T_c$ 를 쓴다 `[증명]`. 따라서 고리 전체의 채널은 **가장 작은 접합의 채널**로 제한된다. 크기 $\ge2$ 접합이 필요한 것은 모든 접합 크기가 $\ge2$ 일 때뿐이다.
3. **K4 3-고리 (최소 목표 달성).** 가장 작은 접합 $\{3\}$ (크기 1) 에서 자르면 $T_c=(\alpha-\beta)I+\beta J$, $\alpha=(q-1)(q-2)(q-3)$, $\beta=2(q-2)^2+(q-2)(q-3)^2$ 이고 $P=\big((q-1)(q-2)\big)^2-2(q-1)(q-2)=q(q-1)(q-2)(q-3)$ 이다 `[증명]`. 채널 값 (triv: $((q-1)(q-2))^2$, std: $-2(q-1)(q-2)$) 은 $q=1..8$ 전부 계산 결과와 일치한다 `[계산 확인]`. 접합 $\{1,2\}$ (크기 2) 에서 잘라도 $(q-2,2)$, $(q-2,1,1)$ 채널은 0 이다 `[계산 확인]`, 이유는 C3 의 채널 제한이다.
4. **R08 의 정정.** K4 3-고리는 P1 과 P2 를 합쳐 (K4−34, K2) 의 **m=2 고리 (접합 크기 1)** 로 바꿀 수 있다 `[증명]`. 그러면 R08 Thm 3 (m=2) 의 닫힌 식이 그대로 나온다. R08 §4 의 "닫힌 식 불가" 표기는 3-고리 분해에 한정된 말이었고, 고리의 참값에 대한 닫힌 식이 없다는 뜻은 아니다. $s\ge2$ 가 진짜로 필요한 예는 모든 접합이 크기 $\ge2$ 인 고리이고, 그 예로 m=2 C4 예 (§5) 를 얻었다.
5. **한계.** 채널 $\rho_\lambda(N)$ 을 파티션 대수의 생성원 (diagram) 으로 명시적으로 주는 공식은 아직 없다. 이 보고서의 $s=2$ 채널 값은 계산 (사영 + 다항식 맞춤) 으로 얻었다. 평면성은 여전히 식에 들어가지 않는다.

## 본문

### 0. 설정
R08 과 같다. $G=(V,E)$, 고리 설정 (점집합 $S_1,\dots,S_m$ 서로소, $S_{i-1}\cup S_i\subseteq V(P_i)$), $N_i(x,y)$ 는 접합 라벨 $x\in[q]^{S_{i-1}}$, $y\in[q]^{S_i}$ 에 대한 $P_i$ 사설 색칠 수. $V:=\mathbb C^q$ 에 $S_q$ 를 치환으로 작용시키고 $W_s:=V^{\otimes s}$ 로 둔다. 기저는 $[q]^s$ 의 원소 $x=(x_1,\dots,x_s)$ 이고, 작용은 $\sigma\cdot e_x=e_{\sigma x}$ 이다.

**보조 관찰 (S0).** $N_i$ 는 색 순열에 불변이다: $N_i(\sigma x,\sigma y)=N_i(x,y)$ (제약 $\{x_j\ne y_k\}$ 등이 치환에 불변). 따라서 행렬 $N_i$ (행 $[q]^{S_{i-1}}$, 열 $[q]^{S_i}$) 는 $S_q$-동변 사상 $W_{s_{i-1}}\to W_{s_i}$ 이다 `[증명]`. 표기 $A_s:=\mathrm{End}_{S_q}(W_s)$.

### 1. 채널 정의와 정리 C1 (교환자 분해)
$S_q$ 는 유한군이고 $\mathbb C$ 위에서 완전가약이다. 기약표현 $S^\lambda$ ($d_\lambda=\dim S^\lambda$) 에 대해

$$W_s\cong\bigoplus_\lambda S^\lambda\otimes M_\lambda,\qquad M_\lambda:=\mathrm{Hom}_{S_q}(S^\lambda,W_s)$$

이다 (Isotypic 분해). Schur 보조정리로 $\mathrm{End}_{S_q}(S^\lambda)=\mathbb C$ 이므로

$$A_s\cong\bigoplus_\lambda\mathrm{End}(M_\lambda),\qquad N\mapsto(\rho_\lambda(N))_\lambda,$$

이고 $\rho_\lambda$ 는 대수 준동형이다 (합성을 보존) `[증명]`. 각 $N\in A_s$ 는 $\bigoplus_\lambda 1_{S^\lambda}\otimes\rho_\lambda(N)$ 로 작용하므로

$$\mathrm{Tr}_{W_s}(N)=\sum_\lambda d_\lambda\,\mathrm{tr}_{M_\lambda}\rho_\lambda(N)\qquad(\ast)$$

이다 `[증명]`. 이를 **채널 분해** 라 부른다. 채널 $\lambda$ 의 기여는 $\mathrm{Tr}(N E_\lambda)$ 이고 $E_\lambda=\frac{d_\lambda}{q!}\sum_{\sigma}\chi_\lambda(\sigma)\,\sigma$ 는 등유형 사영이다. $T$ 가 $\sigma$-불변이면 $\mathrm{Tr}(TP(\sigma))$ 는 $\sigma$ 의 켤레류에만 의존하므로 (켤레 $\tau$ 에 대해 $P(\tau)$ 와 $T$ 가 교환) 류별로 합하면 된다 `[증명]`. 이 사실로 `r09_channel.py` 를 짰다.

**다중도 (C1a).** 치환 표현 $\mathbb C[[q]^s]$ 는 $S_q$-궤도의 합이다. 궤도는 "값이 나타나는 분할" 로 정해지고, 값이 정확히 $k$ 종인 궤도의 안정자는 $S_{q-k}$ 이므로 그 궤도의 치환 모듈은 $M^{(q-k,1^k)}$ 이다. 궤도 개수는 $S(s,k)$ (제2종 스털링 수) 이다. Young 규칙 (표준 사실 `[기억-미검증]`) 을 쓰면

$$m_\lambda(s)=\dim M_\lambda=\sum_{k=1}^{s}S(s,k)\,K_{\lambda,(q-k,1^k)}$$

이다 `[증명, Young 규칙 인용]`. 특히 $M^{(q-k,1^k)}\ni S^\lambda$ 이면 $\lambda_1\ge q-k\ge q-s$ 이므로 **채널은 $\lambda_1\ge q-s$ 인 $\lambda$ 뿐이다** `[증명]`. $\sum_\lambda m_\lambda^2=\dim A_s$ 이고 $\dim A_s$ 는 $[q]^{2s}$ 의 $S_q$-궤도 수 (Burnside/치환 모듈의 Hom 차원) 이므로 $q\ge2s$ 에서 $\mathrm{Bell}(2s)$ 이다 `[증명]`.

**$s=1,2$ 의 표.** ($q\ge4$ 에서 모든 채널이 존재.)

| $s$ | 채널 $\lambda$ | $d_\lambda$ | $m_\lambda$ | $\sum m^2$ |
|---|---|---|---|---|
| 1 | $(q)$ | $1$ | $1$ | |
| 1 | $(q-1,1)$ | $q-1$ | $1$ | $=2=\mathrm{Bell}(2)$ |
| 2 | $(q)$ | $1$ | $2$ | |
| 2 | $(q-1,1)$ | $q-1$ | $3$ | |
| 2 | $(q-2,2)$ | $q(q-3)/2$ | $1$ | |
| 2 | $(q-2,1,1)$ | $(q-1)(q-2)/2$ | $1$ | $=15=\mathrm{Bell}(4)$ |

$s=1$ 이 R08 Thm 3 의 두 채널 (상수 $I+$ $J$ 대수의 두 고유공간) 과 일치한다. 차원 검사: $2\cdot1+3(q-1)+\frac{q(q-3)}2+\frac{(q-1)(q-2)}2=q^2$ `[증명]`.

### 2. 정리 C2 (균일 접합 고리의 채널 공식)
모든 $|S_i|=s$ 이면

$$\boxed{\;P_G(q)=\sum_{\lambda:\ \lambda_1\ge q-s} d_\lambda\ \mathrm{tr}_{M_\lambda}\big(\rho_\lambda(N_1)\cdots\rho_\lambda(N_m)\big)\;}$$

*증명.* R08 Prop 2 에서 $P_G=\mathrm{Tr}(N_1\cdots N_m)$ 이고 $N_i\in A_s$ 이므로 $(\ast)$ 를 적용하면 된다. 곱은 $A_s$ 안에서 취하므로 $\rho_\lambda$ 가 곱을 보존한다. $\square$

$s=1$ 이면 $\mathrm{tr}$ 은 스칼라가 되고 R08 Thm 3 의 $a_i+(q-1)b_i$ (triv) 와 $a_i-b_i$ (std) 로 돌아간다 `[증명]`. $s=2$ 에서는 $\mathrm{triv}$ 와 $\mathrm{std}$ 의 $M_\lambda$ 가 2차원, 3차원이므로 채널 기여가 **행렬 트레이스** 이다. 이것이 Thm 3 과 다른 점이다.

### 3. 정리 C3 (혼합 접합 크기: 최소 접합에서 자르기)
고리의 한 접합 $c$ (크기 $t$) 를 잡고 $c$ 를 시작점으로 $T_c:=N_{c}N_{c+1}\cdots N_{c-1}$ 을 합성한다 (접합 사이 라벨은 합으로 소거). 그러면 $T_c\in A_t$ 이고

$$P_G(q)=\mathrm{Tr}_{W_t}(T_c)=\sum_{\lambda_1\ge q-t}d_\lambda\,\mathrm{tr}\,\rho_\lambda(T_c)\qquad(\ast\ast)$$

이다 `[증명]` (R08 Prop 2 의 $\mathrm{Tr}$ 는 순환 대칭이므로 시작점에 무관). 특히 **$t=\min_i|S_i|$ 인 접합으로 자르면** 채널은 $\lambda_1\ge q-t$ 로 제한된다. 따라서 $s\ge2$ 의 진짜 $P_2$ 채널 문제는 "모든 접합 크기가 $\ge2$" 인 고리에서만 나온다 `[증명]`.

### 4. K4 3-고리 (최소 목표)
R08 의 분해: $P_1=K_3$ on $\{1,2,3\}$, $P_2=$ 경로 $1\!-\!4\!-\!2$, $P_3=K_2$ on $\{3,4\}$. 접합 $\{1,2\}$ (크기 2), $\{4\}$ (크기 1), $\{3\}$ (크기 1). 최소 접합 $c=\{3\}$ 에서 자르면 ($x_3$ 과 $x_3'$ 는 두 번 나오는 라벨 $x_3$ 의 양쪽 복사):

$$T_c(x,x')=\#\{(x_1,x_2,x_4):\ x_1\ne x_2,\ x_1,x_2\ne x,\ x_4\notin\{x_1,x_2\},\ x_4\ne x'\}.$$

$T_c$ 는 $S_q$-불변이므로 $T_c=(\alpha-\beta)I+\beta J$ 이고 $\alpha=T_c(x,x)$, $\beta=T_c(x,x')$ ($x\ne x'$) 이다. 직접 세면 $\alpha=(q-1)(q-2)(q-3)$, $\beta=2(q-2)^2+(q-2)(q-3)^2$ `[증명]`. 채널 값 (C3 with $t=1$):

- $\mathrm{triv}$ ($d=1$): $\alpha+(q-1)\beta=\big((q-1)(q-2)\big)^2$.
- $\mathrm{std}$ ($d=q-1$): $(q-1)(\alpha-\beta)=-2(q-1)(q-2)$.

합은 $(q-1)^2(q-2)^2-2(q-1)(q-2)=q(q-1)(q-2)(q-3)$ `[증명]`. 계산 확인: `r09_channel.py` 가 $q=1..8$ 에서 트레이스 $0,0,0,24,120,360,840,1680$ 과 채널 값 (triv $0,\dots,36,144,400,900,1764$; std $\dots,-12,-24,-40,-60,-84$) 을 일치시켰다.

*대조.* 같은 K4 를 접합 $\{1,2\}$ (크기 2) 에서 자르면 `r09_m2.py` 의 $T$ 는 $\mathrm{triv}$ 채널 하나에만 값이 있고 (즉 $T$ 의 계수 행렬이 랭크 1 이다) 합은 같은 값이다. $(q-2,2)$ 와 $(q-2,1,1)$ 은 0 이다 `[계산 확인]`. 이것은 C3 과 일치한다 (고리의 채널은 최소 접합 $t=1$ 로 제한된다).

**K4 3-고리의 닫힌 식 (정정 포함).** P1 과 P2 를 합치면 $Q_1=K_4-34$ (접합 $\{3\},\{4\}$), $Q_2=K_2$ 인 $m=2$ 고리가 된다 (R08 Thm 3 의 $m=2$ 경우, Cor 4 의 삭제–축약과 같음) `[증명]`. $a_1=(q-1)(q-2)$, $b_1=(q-2)(q-3)$, $a_2=0$, $b_2=1$ 이므로 Thm 3 공식은 $(q-1)(q-1)(q-2)^2-(q-1)\cdot2(q-2)$ 를 준다. 즉 R08 §4 의 "닫힌 식 없음" 표기는 3-고리 분해 자체에 대한 말이었고, 참값 $q(q-1)(q-2)(q-3)$ 은 이미 접합 크기 1 의 닫힌 식으로 나온다 `[증명]`.

### 5. 진짜 $s=2$ 예: m=2, 모든 접합 크기 2
접합 $S_1=\{1,2\}$, $S_2=\{3,4\}$, 두 조각이 모두 4점을 포함하는 $m=2$ 고리. 여기서 $T=N_1N_2\in A_2$ 이므로 C2 를 $s=2$ 에 직접 적용한다 (C3 로 줄일 수 없다). 예: $P_1$ = 경로 $4\!-\!1\!-\!3\!-\!2$ (간선 $14,13,23$), $P_2=C_4$ ($13,14,23,24$), 합집합 $C_4$ (간선 $13,32,24,41$, $P=(q-1)^4+(q-1)=q^4-4q^3+6q^2-3q$).

채널 값 (`r09_fit.py`, $q=4..10$ 의 7 개 값에 맞춘 다항식, 고차 계수가 0 으로 나와 맞춤이 정확함을 뒷받침):

- $\mathrm{triv}$: $q^4-7q^3+21q^2-30q+17$
- $\mathrm{std}$: $3q^3-16q^2+30q-17$
- $(q-2,2)$: $q^2-3q$ (즉 $\mathrm{tr}\rho=2$)
- $(q-2,1,1)$: $0$

합은 $q^4-4q^3+6q^2-3q$ 이다 `[계산 확인]`. 이 예에서 $(q-2,2)$ 채널이 **실제로 0 이 아니다.** 그러므로 $s\ge2$ 의 비자명 채널은 존재하며, 기여는 2차원 $M_{\mathrm{triv}}$ 등 행렬 트레이스로 나타난다. (단, 이 예의 조각은 접합 4점 위의 그래프라 색칠 수 계산 자체는 쉽다. 목적은 채널 공식의 시험이다.)

`r09_scan.py` 로 $q=4$ 에서 $2^6\times2^6$ 간선 조합을 훑어 $(q-2,2)$ 또는 $(q-2,1,1)$ 채널이 0 이 아닌 조합이 여럿 있음을 확인했다 (`[계산 확인]`, 완전 열거가 아니라 존재 확인).

### 6. 장애물과 한계
1. **$\rho_\lambda(D_\pi)$ 의 명시적 공식이 없다.** $A_s$ 의 기저 (set partition $\pi\in\Pi_{2s}$ 의 diagram) 에서 $\rho_\lambda$ 를 쓰는 일은 파티션 대수 $P_s(q)$ 의 기약표현 (Martin, Halverson–Ram 류) 을 필요로 한다 `[기억-미검증]`. 이 보고서는 채널 값을 사영 계산으로 얻었고, 일반 $s$ 의 닫힌 식은 쓰지 못했다.
2. **$(q-2,1,1)$ 채널이 C4 예에서 0 인 이유를 모른다.** $\mathrm{sgn}$-형 (두 접합 점의 교환에 반대칭) 채널이 이 예에서 사라진다. 어떤 대칭 또는 구조 때문인지는 확인하지 못했다 `[추측]`.
3. **C3 의 제한은 고리에만 적용된다.** 고리 밖 (사이클 + 현, 여러 사이클) 에서는 한 접합으로 자른 합성이 여러 접합의 텐서 수축이 되어 채널 분해가 여러 $A_{s_i}$ 의 곱이 된다. 이 경우 $\mathrm{Tr}$ 은 여러 교환자 대수 위의 수축이며, 채널은 접합마다 따로 존재한다 `[추측]`.
4. **평면성 미사용.** $A_s$, $\rho_\lambda$, $m_\lambda$ 어디에도 평면성이 들어가지 않는다. 평면 조각이 $N_i$ 의 어떤 채널을 죽이는지는 아직 모른다 (R08 §6.4 와 같은 공백).

## 후속연구 지점
1. **(최우선) $s=2$ 채널 기여의 일반 공식.** 무엇: 파티션 대수 $P_2(q)$ 의 네 기약표현 ($\mathrm{triv}$ 2차원, $\mathrm{std}$ 3차원, $(q-2,2)$ 와 $(q-2,1,1)$ 1차원) 에서 diagram $D_\pi$ 의 값 $\chi_\lambda(D_\pi)$ 를 표로 만든다. 왜: 이것만 있으면 임의의 $m$, 모든 접합 크기 2 인 고리의 $P_G$ 를 채널 곱의 합으로 쓸 수 있다. 시작: $\chi_\lambda(D_\pi)=\mathrm{Tr}_{M_\lambda}$ 를 $\mathrm{Tr}_{W_2}(D_\pi E_\lambda)$ 로 계산하고, $q=4..8$ 에서 `r09_channel.py` 의 사영 값과 맞춘 뒤 다항식으로 보간. 난점: 1차원 채널은 쉽지만 2차원 $\mathrm{triv}$ 와 3차원 $\mathrm{std}$ 블록은 기저 선택이 필요하다.
2. **$(q-2,1,1)$ 채널 소멸 조건.** 무엇: §5 의 C4 예에서 $\mathrm{sgn}$-형 채널이 0 이 되는 조건 (두 접합 점을 바꾸는 대칭, 또는 간선 구조) 을 찾는다. 왜: 어떤 고리가 반대칭 채널을 살리는지 알아야 $s=2$ 의 비자명 기여를 설계할 수 있다. 시작: 스캔 결과 (`r09_scan.py` 출력) 에서 $(q-2,1,1)\ne0$ 인 조합과 $=0$ 인 조합을 나란히 놓고 간선 대칭을 비교. 난점: 표본이 $q=4$ 와 $q=5$ 뿐이라 일반화가 약하다.
3. **고리 밖 구조의 채널 분해 (수축 텐서망).** 무엇: 접합이 사이클 밖의 구조 (두 사이클, 현 붙은 사이클) 를 이룰 때 $\mathrm{Tr}$ 을 여러 $A_{s_i}$ 위의 채널로 나누는 틀. 왜: R08 §6.3 의 일반 $H$ 에 대한 답의 첫 단계이다. 시작: 두 접합이 한 조각을 공유하는 가장 작은 경우 (접합 $\{1\}$, $\{2\}$ 를 가진 큰 조각 + 나머지) 에서 $\mathrm{Tr}$ 이 $\mathrm{End}(V)\otimes\mathrm{End}(V)$ 의 채널 곱으로 쓰이는지 확인. 난점: 두 접합의 채널이 서로 얽힌다 (텐서 곱의 채널 분해가 필요).
4. **K4 의 $s=2$ 진짜 시험.** 무엇: 모든 접합 크기 $\ge2$ 이고 채널 $(q-2,1,1)$ 이 살아남는 K4 분해를 찾는다. 왜: K4 의 3-고리는 최소 접합 1 로 줄어들어 $s=2$ 를 시험하지 못했다 (§4). 시작: $r09_scan.py$ 에서 $\mathrm{sgn}$ 채널이 0 이 아닌 $m=2$ 분해를 K4 로 보이는 조합 (예: $\{13,24\}$ 를 두 조각이 공유하는 경우) 을 고르고 $q=4,5$ 에서 검산. 난점: K4 를 모든 접합 $\ge2$ 인 고리로 쓰는 방법이 $m=2$ 밖에 없을 가능성 (6 변, 4 점) — 이는 `[추측]`.
