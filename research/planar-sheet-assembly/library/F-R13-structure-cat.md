# [F-R13-structure-cat] 구조 조각가(F): 𝔐 의 코리밋·함자·자연변환 읽기

- 작성: 포메이션 F 구조 조각가 (혼자 수행). 다른 연구원 산출물은 열람하지 않았다.
- 기준 정의: `library/F-R12-A-rev.md` 의 튜플 𝔐 = (V_0, V_1, E_00, E_01, E_11). E_11 은 파생 성분으로 포함해 다룬다. 무효판 `F-R12-A.md` 에는 기대지 않았다. ∂ 는 일반층에 없다.
- 정의를 바꾸지 않았다. 아래 "보조 기호" 는 정의를 다시 쓴 것이 아니라 읽기 편의를 위한 파생 양이다.
- 태그: [증명] [계산 확인] [추측] [망상] [기억-미검증]. 작은 예는 손으로 확인한 것이며 전수 점검이 아니다.
- 커밋하지 않았다.

## 0. 핵심 요약

1. **조립은 코리밋이다** [증명]. G(𝔐) 는 조각들을 정점별로 붙인 쌍대극한이다. 정점 몫은 흰 별 블록에 의한 몫, 간선 몫은 조각 간선들의 합집합이고, 단순화 (simp) 는 평행 간선을 하나로 접는 좌수반 (left adjoint) 이다. 반사 단순 그래프의 범주 𝐑𝐆 에서 G = colim 이다.
2. **E_11 은 "두 조각 이상이 덮는 G 간선" 이다** [증명]. μ(e) := #{조각 k : e ∈ ε_k} 라 하면 E_11 ↔ {e ∈ E(G) : μ(e) ≥ 2}. 즉 E_11 은 코리밋 cocone 이 간선에서 단사가 아닌 자리, 곧 **조각 사이 간선 식별** 자리다. 이 세기는 간선 개수가 아니라 **조각 개수** 로 한다.
3. **E_11 은 G 의 함수가 아니다** [계산 확인]. K_2 한 조각과 K_2 두 조각 중첩은 같은 G 를 주지만 E_11 이 다르다.
4. **복사점 구성의 함자성** [증명/계산 확인].
   - 자유 부분 𝔐^fr = (V_0, V_1, E_00, E_01) 은 조각 사상 전체 𝐃 에서 함자이다.
   - E_11 포함 𝔐^full 은 **조각 지표 사상 ι 가 단사** 일 때만 함자이다. ι 가 두 조각을 한 조각으로 접으면 E_11 이 깨진다.
   - 흰 점 절단 (M1) 을 한 𝔐^tr 은 **각 적재 집합 N(v) 위에서 σ 가 단사** 일 때만 정의된다. σ 가 같은 적재점을 접으면 흰 점이 사라진다.
5. **자연 변환** [증명]. q: 𝔐^fr ⇒ G 가 존재하고 성분은 "복사점 ↦ 정점, 흰 점 ↦ 대응 정점" 이다. 이것은 코리밋의 cocone 이다. 역방향 G ⇒ 𝔐 는 일반적으로 없다. μ 는 ι 단사 아래 lax 자연 변환이고, 그 결과로 E_11 은 ι 단사 사상 아래 위로 보존된다.
6. **정리 A** [증명]. 𝔐^(t) (흰 점을 K_t ∨ \bar K_{N(w)} 로 치환한 것) 의 색칠 가능성은 자연 전사 Ψ: Hom(T_t𝔐, K_{t+1}) ↠ Hom(G𝔐, K_{t+1}) 에서 나온다. 섬유는 S_t 의 곱이다. 색칠수 읽기는 **호모모피 (Hom(−,K_s)) 층** 의 보존이다.
7. **마이너 읽기** [증명]. q 는 연결 부분그래프의 수축 (자연 에피) 이므로 마이너 닫힌 성질은 𝔐 에서 G 로 내려간다 (예: 평면성). 하지만 **χ 는 마이너 단조가 아니다** (C_4 → C_3). 따라서 색칠 읽기와 마이너 읽기는 서로 다른 함자적 원천을 가진다.
8. **(나) = 𝒢^N** 은 ι 단사 사상 아래 위로도 아래로도 닫히지 않는다 [계산 확인]. 따라서 (나) 는 함자적 부분범주가 아니라 객체 조건이다.
9. **정의와 불일치**: 발견하지 못했다 (§7). 해석상 주의 3건을 적었다.

## 1. 표기와 보조 양

**조각 설명서 (일반층 객체의 범주적 형태).** 튜플 𝔐 에서 조각은 (V_0, E_00) 의 연결 성분 P_K 이다. 아래에서는 조각 지표를 k ∈ I 로 쓰고, 조각을 P_k, 정점 적재 φ_k: V(P_k) → V(G) 로 쓴다. 여기서 φ_k(x) := [x] (블록 몫) 이다.

**보조 기호 (파생, 자유 데이터 아님).**
- 조각 간선상: ε_k := { φ_k(x)φ_k(y) : xy ∈ E(P_k) } ⊆ E(G).
- 조각 중복도: μ(e) := #{ k ∈ I : e ∈ ε_k } for e ∈ E(G).
- 평행 간선 개수: m(e) := #{ 간선 xy ∈ E_00 : {[x],[y]} = e }. 일반적으로 m(e) ≥ μ(e) 이다.

**보조 명제 0 (E_11 의 조각 표현)** [증명]. {w_v, w_{v'}} ∈ E_11 ⟺ μ({v,v'}) ≥ 2.
- 증명. K(w_v, w_{v'}) = {k : ∃x ∈ N(v)∩P_k, ∃x' ∈ N(v')∩P_k, xx' ∈ E_00} = {k : {v,v'} ∈ ε_k}. 따라서 |K(w_v,w_{v'})| = μ({v,v'}).
- 여기서 μ ≥ 2 인 e 는 자동으로 양 끝이 V_1 (적재 2 이상) 에 있다. 두 조각이 각각 v 의 복사점을 하나씩 가지기 때문이다. 따라서 E_11 = {e ∈ E(G): μ(e) ≥ 2} 로 쓸 수 있다.

**보조 명제 0′ (E_11 과 m 의 차이)** [증명]. 일반층에서 E_11 은 m 이 아니라 μ 로 정해진다. 예: 4-사이클 x–y–x'–y'–x 한 조각, φ(x)=φ(x')=v, φ(y)=φ(y')=u. 이때 G = K_2, m(uv) = 4, μ(uv) = 1 이므로 E_11 = ∅ 이다. §5.2 의 "m = |K|" 는 리본층 (R0) 아래에서만 성립한다.

## 2. 조립 G(𝔐) 는 코리밋이다

### 2.1 몫의 식 (집합 수준)

- **정점 몫.** V(G) = coeq( p_1, p_2 : R_V ⇉ V_0 ), 여기서 R_V := {(x,x',w) ∈ V_0×V_0×V_1 : (x,w),(x',w) ∈ E_01}, p_1(x,x',w)=x, p_2(x,x',w)=x'.
  - [증명] R_V 가 생성하는 동치관계의 류는 블록 N(w) (w ∈ V_1) 와 나머지 단독 점이다. 블록이 서로소이므로 (M1 두 번째 조건) 이것이 π 이다.
- **간선 몫.** E(G) = E_00 / (e ∼ e' ⟺ 같은 G-간선으로 상이 같음). 즉 E(G) = E_00 의 상 = 분해 E_00 ↠ E(G) ↪ binom(V(G),2) 의 전사 부분. [증명] 정의 그대로.
- **단순화.** 다중그래프 M 에 대해 simp(M) := (V(M), {끝점 쌍}). [증명] simp ⊣ 포함 (단순 그래프 ⊂ 고리 없는 다중그래프). 단순 그래프 H 로의 다중그래프 사상은 평행 간선을 같은 간선으로 보내야 하므로 Hom(M,H) = Hom(simp M, H). 좌수반은 콜림을 보존하므로, simp 는 다중그래프 콜림을 단순 콜림으로 옮긴다.

**요약 (범주론적 위치).**
- 정점 몫 = 콜림 (집합 수준 coequalizer).
- 간선 몫 = 다중그래프에서는 ⊔_k E(P_k) (간선은 식별되지 않는다), 단순 그래프에서는 그 상.
- simp = 다중도 정보를 지우는 좌수반.

### 2.2 정리 1 (G 는 조각들의 코리밋)

**정리 1.** 𝓘_D 를 다음 모양의 도식으로 둔다. 대상은 각 정점 v ∈ V 의 한 점 •_v 와 각 조각 P_k. 사상은 복사점 x ∈ N(v) ∩ V(P_k) 마다 •_v → P_k (점 ↦ x) 이다. 그러면 G(𝔐) 는 반사 단순 그래프 𝐑𝐆 에서 이 도식의 콜림이고, 콜림 cocone 은 (φ_k) 와 (v ↦ v) 이다. [증명]
- 정점: •_v 들의 사상이 같은 적재 집합을 한 점으로 모은다. 즉 정점 몫이 정확히 π 이다.
- 간선: 𝐑𝐆 에서 간선은 대칭 반사 관계의 원소이므로, 콜림의 간선은 조각 간선의 상이다. 보편성: 임의의 cocone (g_k: P_k → Z) 에 대해 정점 수준의 사상이 유일하고 간선을 보존한다.
- 고리가 생기지 않는다 (M3). 따라서 𝐑𝐆 에서 G 가 모든 간선을 가진다.

**따름정리 1.1.** 다중그래프 콜림 G^pre := (V(G), ⊔_k E(P_k)) 에 대해 G = simp(G^pre). [증명] 좌수반이 콜림을 보존한다.

**따름정리 1.2.** cocone (φ_k) 는 정점과 간선 모두에서 전사이다. [증명] 피복 조건 (D4) 과 정의에서 나온다.

### 2.3 E_11 은 코리밋 cocone 의 간선 비단사 자리이다

**정리 2.** E_11 = {e ∈ E(G) : μ(e) ≥ 2} (보조 명제 0). 또한 다중그래프 콜림 G^pre 에서 e 의 원상 ⊔_k E(P_k) → E(G) 의 섬유가 **두 개 이상의 조각 합 (summand) 에 걸치는 것** 과 같다. [증명]

**해석.** 단순화 simp 는 같은 간선 쌍을 가진 모든 원상을 한 간선으로 접는다. 그중 **서로 다른 조각에서 온** 평행 간선을 접는 것이 E_11 이다. 같은 조각 안의 평행 간선 (§1 보조 명제 0′ 의 4-사이클) 은 E_11 에 들어가지 않는다.

### 2.4 simp 가 지우는 것과 남기는 것

- simp 가 지우는 것: 평행 간선의 다중도 m (그리고 조각 귀속). [증명]
- G 에는 E_11 이 없다 (§3 의 E_11 무영향 증명과 일치). [증명]
- E_11 은 G 로부터 복원되지 않는다 [계산 확인]. 예: G_1 = G_2 = K_2 로 만든 중첩 (두 조각 u_1v_1, u_2v_2 가 적재 {u,v} 를 공유) 과 한 조각 K_2 는 둘 다 G = K_2 를 준다. 그러나 전자는 E_11 = {uv} 이고 후자는 E_11 = ∅ 이다.
  - 결론: E_11 은 G 의 함수가 아니라 𝔐 의 함수이다 (정의 그대로). 파생이지만 G 에 대해 "추가 정보" 이다.

## 3. 평면분해의 범주 𝐃 와 복사점 구성의 함자성

### 3.1 대상 (평면분해)

대상 D = (G; (P_k)_{k∈I}; (φ_k)_{k∈I}) 는 다음을 만족한다.
- (D1) G 는 유한 단순 그래프 (정점 V, 간선 E).
- (D2) 각 P_k 는 유한 연결 **평면** 단순 그래프 (M2 와 "조각 = 연결 성분" 을 반영).
- (D3) φ_k: V(P_k) → V 는 간선을 간선으로 보낸다: xy ∈ E(P_k) ⇒ φ_k(x)φ_k(y) ∈ E. 특히 φ_k(x) ≠ φ_k(y) (고리 금지, M3 의 흔적).
- (D4) 피복: ⋃_k φ_k(V(P_k)) = V 이고 ⋃_k ε_k = E.

일반층 객체 𝔐 ↦ D(𝔐) := (G(𝔐); (P_K); (φ_K)) 가 대응한다. (M1) 과 (M2) 의 일부는 D 에 있고, (M1) 의 |N(w)| ≥ 2 는 뒤의 절단 𝔐^tr 에서 다룬다. [증명] 역대응 𝔐(D) 는 V_1 = {v : |φ^{-1}(v)| ≥ 2} 로 정하면 된다.

### 3.2 사상

D = (G; P; φ) → D' = (G'; P'; φ') 의 사상은 삼중쌍 h = (f, ι, σ) 이다.
- f: V(G) → V(G') 정점 사상,
- ι: I → I' 조각 지표 사상,
- σ_k: V(P_k) → V(P'_{ι k}) 정점 사상 (k ∈ I),

이며 다음을 만족한다.
- (H1) φ'_{ιk} ∘ σ_k = f ∘ φ_k.
- (H2) xy ∈ E(P_k) ⇒ σ_k(x)σ_k(y) ∈ E(P'_{ιk}) (σ_k 는 간선을 간선으로 보낸다).

[증명] f 는 자동으로 G 의 간선을 G' 의 간선으로 보낸다 (피복 (D4) 과 (H1),(H2)). 합성과 항등이 잘 정의된다. 이것을 **𝐃** 라 한다.

**부분 범주.**
- 𝐃_ι: ι 가 단사인 사상.
- 𝐃_fib: 각 v 에 대해 σ|_{N(v)} 가 단사 (N(v) := φ^{-1}(v)).
- 𝐃_mono := 𝐃_ι ∩ 𝐃_fib.

(𝐃_mono 는 σ 가 전체적으로 단사인 경우를 포함하지만 더 넓다. 실제로 필요한 조건을 쓴 것이다.)

### 3.3 복사점 구성의 세 판

**(a) 자유 부분.** 𝔐^fr(D) := (V_0 = ⊔_k V(P_k), V_1 = V(G), E_00 = ⊔_k E(P_k), E_01 = {((k,x), φ_k(x))}) . 모든 정점 (fiber 1 포함) 을 흰 점으로 둔다. 사상은 (h_0, h_1) := (σ 의 합, f) 이다.
- 보조 명제 3.1 [증명]. 𝔐^fr 은 𝐃 전체에서 𝐌^- (자유 매뉴얼 그래프, 사상은 E_00 과 E_01 을 보존) 로의 함자이다.
  - 검사: (H2) 에서 E_00 이 보존된다. (H1) 에서 E_01 이 보존된다.

**(b) E_11 포함.** 𝔐^full(D) := 𝔐^fr(D) + E_11, 여기서 E_11 := {e ∈ E(G): μ(e) ≥ 2} (보조 명제 0 에 의해 정의 그대로).
- 보조 명제 3.2 [증명]. ι 가 단사이면 h 는 E_11 을 E_11' 으로 보낸다. 즉 𝔐^full 은 𝐃_ι → 𝐌 (E_11 을 보존하는 사상) 의 함자이다.
  - 증명. {v,v'} ∈ E_11 이면 μ(vv') ≥ 2 이므로 서로 다른 두 조각 k_1 ≠ k_2 가 vv' 을 덮는다. (H2) 에 의해 f(v)f(v') = φ'σ(x)φ'σ(x') 는 두 조각 ι k_1 ≠ ι k_2 에서 나온 간선이고 (ι 단사) 따라서 μ'(f(v)f(v')) ≥ 2. 또 f(v) ≠ f(v') 이다 ((D3) 에 의해 간선 끝점은 다르다). 따라서 f(vv') ∈ E_11'.
- 보조 명제 3.3 [계산 확인]. ι 가 단사가 아니면 보존이 깨진다 (X1 참고).
- 보조 명제 3.4 [증명]. 보존은 σ 가 단사인지와 무관하다. (ι 단사만 쓰였다.)

**(c) 절단 (실제 정의의 M1).** 𝔐^tr(D) := 𝔐^full(D) 에서 |N(v)| ≤ 1 인 흰 점 w_v 를 지운 것. 이것이 §1 의 𝔐 이다.
- 보조 명제 3.5 [증명]. 𝔐^tr 은 𝐃_mono → 𝐌 의 함자이다. 𝐃_mono 의 사상은 N(v) 의 크기를 줄이지 않으므로 살아남은 흰 점의 상도 살아남는다. 또 ι 단사이므로 E_11 도 보존된다 (3.2).
  - 주의: 흰 점 w_v 의 상 w_{f(v)} 의 적재 집합은 σ(N(v)) ⊆ N'(f(v)) 를 포함하므로 |N'(f v)| ≥ |N(v)| ≥ 2. [증명]

### 3.4 함자성 판정 (단사/비단사 표)

| 대상 | 𝐃 (전체) | 𝐃_ι (ι 단사) | 𝐃_fib (σ|N(v) 단사) | 𝐃_mono |
|---|---|---|---|---|
| 𝔐^fr (자유 부분) | 함자 [증명 3.1] | 함자 | 함자 | 함자 |
| 𝔐^full (E_11 포함) | **깨짐** [계산 확인 X1] | 함자 [3.2] | 깨짐 (X1 과 같은 예) | 함자 |
| 𝔐^tr (M1 절단) | 정의 불가 | **깨짐** (X2: σ 비단사) | 깨짐 (X1: E_11) | 함자 [3.5] |
| G (조립) | 함자 [증명 4.1] | 함자 | 함자 | 함자 |

**X1 (ι 접음으로 E_11 이 깨짐)** [계산 확인].
- D: 조각 P_1 = 간선 a_1b_1, P_2 = 간선 a_2b_2, φ(a_i) = a, φ(b_i) = b, G = K_2 (ab). N(a) = {a_1,a_2}, N(b) = {b_1,b_2}. μ(ab) = 2, E_11 = {w_a w_b}.
- D': 조각 P' = 경로 a'–b'–a''–b'' (φ'(a'),φ'(a'') = a, φ'(b'),φ'(b'') = b), G' = K_2. 사상 f = id, ι: I = {1,2} → {1} (접음), σ_1: a_1↦a', b_1↦b', σ_2: a_2↦a'', b_2↦b''.
- 확인: (H1),(H2) 성립. σ 단사 (fiber 단사도 성립, N'(a) = {a',a''}). μ'(ab) = 1 (P' 한 개) 이므로 E_11' = ∅. 그러나 E_11 ∋ w_a w_b. 즉 E_11 은 보존되지 않는다. 흰 점의 적재는 유지되므로 절단 𝔐^tr 은 정의되지만 E_11 때문에 𝐌 의 사상이 아니다.

**X2 (σ 접음으로 흰 점이 사라짐)** [계산 확인].
- D: 한 조각 P = 경로 a–b–c, φ(a) = φ(c) = v, φ(b) = u, G = K_2. N(v) = {a,c} 이므로 w_v 가 있다. (P 는 연결, 평면. 고리 없음.)
- D': 한 조각 P' = 간선 a'b', φ'(a') = v, φ'(b') = u. f = id, ι = id, σ: a,c ↦ a', b ↦ b' (간선 ab ↦ a'b', bc ↦ b'a' 모두 간선).
- 확인: (H1),(H2) 성립. ι 단사. 그러나 N'(v) = {a'} 이므로 𝔐^tr(D') 에는 w_v 가 없다. 따라서 w_v ↦ ? 가 정의되지 않는다. 절단 함자가 깨진다.
- 𝔐^full 에서는 w_v ↦ w_v (적재 1) 로 정의되고 E_11 은 비어 있어 문제없다.

**결론 (함자성).**
- 자유 부분은 𝐃 전체에서 함자.
- E_11 은 **ι 단사** 가 필요하다 (조각 지표가 단사여야 μ 의 합이 보존된다).
- 흰 점 절단은 **σ 가 각 N(v) 위에서 단사** 가 필요하다 (적재 크기가 줄지 않아야 M1 이 살아남는다).
- 두 조건의 교집합 𝐃_mono 에서 𝔐^tr 이 함자이다.

## 4. 자연 변환

### 4.1 q: 𝔐 ⇒ G (존재, 성분)

**정의.** 대상 D 에 대해 q_D: V_0 ⊔ V_1 → V(G) 를 다음으로 둔다.
- 복사점 x ∈ V_0 ↦ φ(x) = [x],
- 흰 점 w_v ↦ v.

이것은 간선에서 다음과 같다. E_00 의 간선은 G 의 간선으로 간다 (ε 의 정의). E_01 의 간선 (x, w_v) 는 한 점 φ(x) = v 로 접힌다 (별의 수축). E_11 의 간선 {w_v,w_{v'}} 는 G 의 간선 {v,v'} 로 간다 (보조 명제 0 에 의해 μ ≥ 2 이므로 간선이 존재). 따라서 q_D 는 반사 그래프의 사상이다.

**자연성 (4.1).** 사상 h = (f,ι,σ): D → D' (ι 단사 하에서 E_11 을 포함할 때) 에 대해 q_{D'} ∘ 𝔐(h) = G(f) ∘ q_D. [증명]
- 복사점: q_{D'}(ι k, σ x) = φ'(σ x) = f(φ x) = G(f)(q_D(k,x)) (H1).
- 흰 점: q_{D'}(w_{f v}) = f(v) = G(f)(v).

**성질 (4.1′).** q_D 는 정점과 간선 모두에서 전사이다 (따름정리 1.2). q_D 는 조각 cocone 을 인수분해하는 사상이다 (정리 1). 즉 q 는 **콜림 cocone 의 자연 집합** 이다. [증명] 𝔐^fr 의 정의에 따라 q 는 𝐃 전체에서 자연이다 (E_11 을 쓰지 않는 버전에서).

**해석.** q 는 "별 수축 + 단순화" 이다. 범주론적으로는 자연 **에피** 자연 변환 (성분 전사) 이며, 그 성분은 수축 사상이다.

### 4.2 역방향 G ⇒ 𝔐 는 일반적으로 없다

**명제 4.2.** E(G) 의 간선을 E_11 의 간선으로 보내는 자연 변환 s: G ⇒ 𝔐^full (정점 v ↦ w_v) 은 일반적으로 존재하지 않는다. [증명 스케치 + 계산 확인]
- 필요 조건: 모든 e = vv' ∈ E(G) 에 대해 μ(e) ≥ 2 여야 한다. 그러나 μ(e) = 1 인 간선이 있으면 실패한다.
- 예: §5.4 의 K_3 (A,B,C) 에서 AB 는 μ = 1 이다. 따라서 s 는 AB 를 E_11 간선으로 보낼 수 없다.
- 다른 방향 (정점 v 를 복사점 하나로 보내기) 도 적재 선택에 의존하므로 자연적이지 않다. [추측]

### 4.3 μ 는 ι 단사 아래 lax 자연 변환이다

**명제 4.3.** h = (f,ι,σ) ∈ 𝐃_ι 이면 e ∈ E(G) 에 대해 μ'(f(e)) ≥ μ(e). 여기서 f(e) = f(v)f(v') 이다. [증명]
- e ∈ ε_k ⇒ f(e) ∈ ε'_{ιk} (H1, H2). ι 가 단사이므로 서로 다른 k 는 서로 다른 ιk 로 간다. 따라서 μ'(f(e)) ≥ #{k: e ∈ ε_k} = μ(e).
- 따라서 E_11 은 𝐃_ι 사상 아래 **위로 보존** 된다 (E_11(D) ⊆ f^{-1} E_11(D')). 단 E_11 은 f 의 상에서 역상으로 되돌아오지 않는다 (§5.4 예: E_11' ⊋ f(E_11)). [계산 확인]
- ι 가 단사가 아니면 μ'(f(e)) < μ(e) 가 될 수 있다 (X1).

### 4.4 몫으로서의 자연성 요약

- q: 자연 에피 (수축).
- G: 𝐃 전체에서 함자.
- μ: ι 단사 아래 lax.
- E_11: μ ≥ 2 의 위쪽 집합, ι 단사 아래 위로 보존.

## 5. 특수 경우

### 5.1 자명 분해 (한 조각 = G)

D_0(G) := ({G}; (G, id)). 한 조각, 피복 자명, μ ≡ 1.
- 콜림: 한 대상의 도식이므로 콜림은 G 자신이다 (cocone = 항등). [증명]
- E_11(D_0) = ∅. [증명] μ ≡ 1.
- 𝔐^tr(D_0) = 𝔐_0(G) = (V, ∅, E, ∅) (§6.3 의 자명 설명서). 𝔐^fr(D_0) 는 모든 정점에 흰 점 (적재 1) 을 단 것이다.
- N1 (|I| ≥ 2) 가 깨진다. 따라서 D_0(G) ∉ 𝒢^N.
- 범주 위치: D_0 는 "한 조각" 대상이다. ι 단사 사상 D → D_0 은 |I_D| ≤ 1 을 요구하므로 D_0 은 𝐃_ι 의 종점이 아니다. [증명]

### 5.2 두 조각 중첩 G_1 ∪ G_2 (E_11 이 공유 간선에서 생기는지)

설정: G_1 = (V, E_1), G_2 = (V, E_2) 연결 평면 (V 공통). 조각 P_1 ≅ G_1 (복사점 v^1), P_2 ≅ G_2 (복사점 v^2), 적재 φ(v^i) = v. 흰 점 w_v, N(v) = {v^1, v^2}. (§6.4 의 중첩 설명서.)

- **콜림 (정리 1).** 반사 그래프 𝐑𝐆 에서 G = colim = G_1 ⊔_{\bar V} G_2 는 두 그래프를 같은 정점 집합 위에서 **밀어내기 (pushout over discrete graph)** 한 것이고, 간선은 E_1 ∪ E_2 이다. [증명] 정점은 v^1 ~ v^2 로 식별되고, 간선은 같은 끝점을 가진 것끼리 하나가 된다.
- **다중그래프 콜림.** G^pre = (V, E_1 ⊔ E_2): 공유 간선 uv ∈ E_1 ∩ E_2 는 평행한 두 간선으로 남는다.
- **E_11 (정리 2).** μ(uv) = [uv ∈ E_1] + [uv ∈ E_2]. 따라서 E_11 = E_1 ∩ E_2. [증명]
- **해석.** 공유 간선은 코리밋의 cocone 이 두 조각의 간선을 같은 것으로 식별하는 자리이다. 즉 E_11 은 **중첩에서 공유 간선이 생기는 곳** 이다. §6.4 의 D(𝔐_12) = {w_u w_v : uv ∈ E_1 ∩ E_2} 와 일치한다. [증명]
- **(N3) 조건.** ε_1 = E_1, ε_2 = E_2, E(G) = E_1 ∪ E_2 이므로 (N3) ⟺ E_1 ⊄ E_2 그리고 E_2 ⊄ E_1. 이것은 §8 표의 "서로 포함 안 함" 행과 일치한다. [증명]
- **G_1 = G_2 (특수).** E_11 = E, 모든 간선이 두 조각에서 온다. 그러나 (N3) 이 깨지므로 𝒢^N 밖이다 (중복). [증명]

### 5.3 (나) 에 해당하는 대상 = 𝒢^N

정정 판 §7 에 따라 (나) 는 정의된 일반층 설명서 전체 𝒢^N (N1–N3 을 만족하는 객체) 이다. 범주론적 표현:
- (N1) 콜림이 두 개 이상의 합 (조각) 을 가진다: |I| ≥ 2.
- (N2) 각 조각은 정점 3 개 이상.
- (N3) 어떤 조각도 G 의 모든 간선을 덮지 않는다: ε_k ≠ E(G).

**명제 5.3 (𝒢^N 은 𝐃_mono 아래 닫히지 않는다)** [계산 확인].
- (위쪽) 𝒢^N 의 대상 D (아래 §5.4 의 K_3 두 경로 예) 에서 사상 D → D' (D' = 삼각형 조각 + 경로 조각) 는 𝐃_mono 의 사상이다 (f = id, ι 단사, σ 단사). 그런데 D' 에서 ε'_1 = E(G') 이므로 (N3) 이 깨진다. 따라서 D' ∉ 𝒢^N.
- (아래쪽) 같은 D' 에 대해 D_0(K_3) (한 조각 삼각형) 에서 D' 로 가는 𝐃_mono 사상이 존재한다 (삼각형 조각을 첫 조각에 항등 매장). D_0(K_3) ∉ 𝒢^N (N1 실패). 따라서 𝒢^N 은 아래로도 닫히지 않는다.
- 결론: (나) 는 함자적 (닫힌) 부분범주가 아니라 객체 조건이다. 이 사실은 "(나) 가 사상으로 보존되는가" 라는 질문에 대해 "아니다" 라고 답한다.

### 5.4 K_3 실현 (𝒢^N 의 구체적 객체)

G = K_3 (정점 A,B,C). P_1 = 경로 A–B–C, P_2 = 경로 A–C–B (φ 는 자명한 이름 대응). 흰 점 w_A, w_B, w_C (각 적재 2).
- μ(AB) = 1, μ(BC) = 2, μ(AC) = 1. 따라서 E_11 = {BC}. [계산 확인]
- (N1) 2 조각, (N2) 각 3 정점, (N3) ε_1 = {AB,BC} ⊊ E, ε_2 = {AC,BC} ⊊ E. 따라서 𝒢^N 의 객체. [계산 확인]
- 같은 예는 §8 의 "K_3 실현" 과 같다 (a–b–c, a'–c'–x; 흰 점 {a,a'},{c,c'},{b,x}) .

## 6. 색칠수 읽기 (정리 A) 와 마이너 읽기

### 6.1 색칠 읽기는 Hom 층에서 나온다

**정의.** T_t := 𝔐^(t) 를 𝔐^fr 에 적용한 것. 각 흰 점 w 를 K_t ∨ \bar K_{N(w)} 로 치환한다. 즉 복사점 (w,i) (i ∈ [t]) 은 서로 완전 연결되고, 각 (w,i) 는 N(w) 의 모든 점과 연결된다. 간선 E_00 과 E_01 의 원래 간선은 그대로 둔다. E_11 은 넣지 않는다.

- 보조 명제 6.1 [증명]. D ↦ T_t(𝔐^fr(D)) 는 𝐃 전체에서 함자이다. 사상 h 는 (w,i) ↦ (f(w), i) 로 확장한다. 간선이 간선으로 가고 (w,i) ≠ (w,j) 의 상도 다르다.

**Ψ (자연 전사).** s := t+1 (t ≥ 1). 색칠 c: T_t(𝔐) → K_s 에 대해 Ψ(c)(v) := c(x) (x ∈ N(v) 아무거나).
- 보조 명제 6.2 [증명]. c 는 N(v) 위에서 상수이다. 이유: (w,i) 의 t 개는 서로 달라서 t 색을 쓰고, N(v) 의 각 점은 그 t 색과 모두 달라야 하므로 남은 한 색 c*(v) 로 강제된다. 따라서 Ψ(c) 는 잘 정의되고 G 의 색칠이다 (G 의 간선 xy 는 색이 달라야 한다).
- 보조 명제 6.3 [증명]. Ψ 는 전사이다. 임의의 G 의 색칠 c_G 에 대해, 흰 점 v 의 복사점 (v,·) 에는 [s] ∖ {c_G(v)} 를 전단사로 배정하고 N(v) 의 복사점에는 c_G(v) 를 준다. 이것은 T_t 의 색칠이고 Ψ 의 상이다.
- 보조 명제 6.4 [증명]. Ψ 는 자연이다. h 에 대해 Ψ_D(c'∘T_t(h)) = G(f)^*(Ψ_{D'}(c')). (정점 적재의 가환성.)
- 섬유: Ψ 의 섬유는 각 흰 점 v 마다 [t] → [s]∖{c(v)} 의 전단사들의 곱, 즉 S_t^{V_1} 의 토르소이다. [증명]

**정리 A (재증명).** 모든 t ≥ 1 과 s = t+1 에 대해: T_t(𝔐) 가 s-색칠 가능 ⟺ G(𝔐) 가 s-색칠 가능. 또 t = 0 (s = 1) 은 직접 확인 (간선 없음). 따라서 χ(G) = min{s : Hom(T_{s−1}𝔐, K_s) ≠ ∅}. [증명]
- 주의: fiber 1 인 흰 점에 대해서도 같은 논증이 된다 (N(v) = {x} 이면 x 의 색은 c*(v)). 따라서 𝔐^fr 과 𝔐^tr 의 색칠 가능성은 같다. [증명]

**해석.** 색칠 읽기는 다음 자연 전사이다: Hom(T_t(−), K_s) ↠ Hom(G(−), K_s) (S_t-토르소 섬유). "존재의 보존" 만 나오며 개수는 보존되지 않는다. 호모모피 층 (Hom(−,K_s)) 에서의 보존이다.

### 6.2 E_11 을 T_t 에 넣으면 깨진다

**계산 확인.** D: G = K_2, P_1 = u_1v_1, P_2 = u_2v_2. μ(uv) = 2, E_11 = {w_u w_v}. t = 2, s = 3.
- E_11 없이: u_1,u_2 는 같은 색 α, v_1,v_2 는 색 β (α ≠ β). (w_u,·) 는 {β,γ}, (w_v,·) 는 {α,γ} 를 쓴다. 충돌 없이 3-색칠 가능.
- E_11 을 넣으면 (w_u,i) ~ (w_v,j) 가 모든 i,j 에 대해 간선이다. 그러면 {β,γ} 와 {α,γ} 가 원소별로 서로소여야 하는데 γ 를 공유한다. 3-색칠 불가능. 그러나 G = K_2 는 2-색칠 가능하다.
- 따라서 E_11 을 넣으면 정리 A 가 깨진다. 이는 §4 [정정 E11] 의 주장과 일치한다. [계산 확인]
- 원인 (범주론적): E_11 을 넣으려면 흰 점 w 의 복사점 (w,i) 와 w' 의 복사점 (w',j) 를 짝짓는 **인덱스 대응** 이 필요한데, 자연적인 짝짓기가 없다. T_t 는 S_t 대칭을 가지므로 자연성이 깨진다. [추측]

### 6.3 마이너 읽기는 자연 에피 q 의 보존이다

**명제 6.5 (G 는 𝔐^fr 의 마이너).** [증명] 별 S_w = {w} ∪ N(w) 는 연결이고 서로소 (M1) 이다. 이것을 수축하면 블록 몫이 되고, 평행 간선을 지우면 (simp) 단순 그래프 G 가 된다. 수축과 간선 삭제만 쓰므로 G 는 𝔐^fr 의 마이너이다.

**따름정리 6.6.** 마이너 닫힌 성질 P 에 대해 P(𝔐^fr) ⇒ P(G). 특히 **𝔐-평면성 ⇒ G-평면성** (§6.2 와 일치). [증명]

**범주론적 원인.** q: 𝔐^fr ⇒ G 의 성분은 전사이고 수축이다 (§4.1). 마이너 순서는 "부분그래프 포함 + 수축 (자연 에피)" 의 합성이므로, 자연 에피 아래 닫힌 성질은 보존된다. [증명 스케치]

### 6.4 χ 는 마이너 단조가 아니다 (두 읽기의 분리)

**계산 확인.** C_4 = a–b–c–d–a 는 χ = 2 이다. 간선 ab 를 수축하면 삼각형 (χ = 3) 이 된다. 따라서 χ(G/e) > χ(G) 가능하다.

- 따라서 q 의 수축은 색칠수의 단조성을 주지 않는다. q 는 E_01 을 한 점으로 접으므로 색칠의 역상을 주지 않는다. [증명]
- 그래서 색칠 읽기는 q 가 아니라 **T_t 와 Ψ** (Hom 층, §6.1) 에서 나온다.
- 정리: 색칠 읽기 = Hom(−,K_s) 의 자연 전사 (호모모피 층). 마이너 읽기 = q 의 자연 에피 (몫 층). 두 함자 원천은 다르다.

### 6.5 평면성 읽기 (§6.2 와의 연결)

- 𝔐^♭-평면성 ⇒ 𝔐-평면성 (부분그래프). 𝔐-평면성 ⇒ G-평면성 (§6.3). 따라서 𝔐^♭-평면성 ⇒ G-평면성. [증명]
- 함자적 관점: 평면성은 마이너 닫힌 성질이므로 q 아래 보존된다. Y (분리) 판정은 𝔐^♭ 와 𝔐 의 차이이므로 q 로는 나오지 않는다 (𝔐^♭ 에서 E_11 이 필요). [추측]

**발견한 정의 불일치: 없음.** 다음 항목을 확인했다.
- §1 의 E_11 식 ↔ 보조 명제 0 (μ 기준): 일치.

- §4 의 𝔐^(t) 정의 ↔ §6.1 의 T_t: 일치. §4 의 정리 A 는 §6.1 로 재증명되었다.

**해석상 주의 (정의와 다르지 않음).**
1. **E_11 은 조각 개수 기준이다.** m (간선 개수) 기준이 아니다 (보조 명제 0′, 4-사이클 예). §5.2 의 m = |K| 는 (R0) 아래에서만 성립한다.

3. **조각의 연결성** 은 범주의 대상 조건 (D2) 으로 넣었다. 정의의 "조각 = 연결 성분" 과 일치하지만, 그렇지 않은 분해는 π_0 를 거쳐야 하므로 함자성이 자명하지 않다. [추측]

## 10. 후속연구 지점

1. **(우선 1) E_11 의 함자적 특성화 (ι 단사 아래 정확한 부분범주).**
   - 이유: §3.4 의 X1 은 E_11 이 ι 접음에서 깨짐을 보였다. E_11 이 쓰이는 곳 (정리 A 의 반례 §6.2, 분해 비교) 에서 함자성의 정확한 조건을 알아야 한다.
   - 시작 방법: μ 를 달린 G 의 범주 (G, μ) 를 정의하고, 사상 (f, ι) 에 대해 μ'(f_*e) ≥ μ(e) 가 함자성의 전부인지 확인한다. X1 에서 ι 접음이 μ 의 합을 어떻게 바꾸는지 세기.
   - 난점: μ 의 합 구조와 ι 의 접음 사이의 관계를 정확히 식으로 쓰는 것. μ' 의 하한 식이 상계를 주지 않을 수 있다.

2. **(우선 2) 정리 A 의 Hom 층 일반화 (목표 H 일반).**
   - 이유: 정리 A 는 K_s 에 대해서만 증명했다. 목표를 바꾸면 자연 전사 Ψ 가 살아남는지 알 수 없다.
   - 시작 방법: H 가 완전 그래프가 아닌 예 (C_5 등) 에서 T_t 의 흰 점 gadget 이 강제하는 색 집합을 계산한다. 강제가 K_s 의 대칭에 기대는지 확인.
   - 난점: 흰 점의 gadget 이 H 의 색을 강제하는 방식이 K_s 와 다르다. 이상적 (ideal) 전이가 필요할 수 있다.

3. **(우선 3) 𝒢^N 의 비닫힘을 함자적으로 정리 (최소 설명서).**
   - 이유: (나) 가 사상 아래 닫히지 않으므로 (나) 를 조건으로 쓰는 정리들의 범위가 불분명하다.
   - 시작 방법: 같은 G 를 주는 설명서들을 사상으로 정렬하고 최소 원소 (minimal) 가 있는지 확인. §5.3 의 D' 가 최소 설명서인지 판정.
   - 난점: 같은 G 를 주는 설명서 공간이 아주 클 수 있다 (조각 분할의 가능성).

4. **(우선 4) 설명서의 세분 (refinement) 과 G 의 보존.**
   - 이유: 두 설명서의 공통 세분을 구성하면 G 와 교환하는지 알 수 있다. 쌍대극한과 G 의 교환은 정리 1 의 자연스러운 따름정리이다.
   - 시작 방법: 두 설명서의 조각 쌍 (P_k ∩ P'_l) 을 취해 그 콜림을 계산. 여기서 μ 가 어떻게 바뀌는지 확인.
   - 난점: 교집합 조각의 연결성 (D2) 이 깨질 수 있다.

5. **(우선 5) Y 판정과 E_11 의 역할.**
   - 이유: Y 판정 (𝔐 평면 ∧ 𝔐^♭ 비평면) 은 E_11 을 필요로 하는데, q 의 마이너 읽기에서는 나오지 않는다. Y 의 최소 예 (미발견) 를 찾는 데 함자적 관점이 도움이 될 수 있다.
   - 시작 방법: E_11 이 평면성을 바꾸는 최소 예를 μ ≥ 2 간선 몇 개로 구성.
   - 난점: 평면성은 전역 성질이라 μ 의 국소 정보로 판정하기 어렵다.
