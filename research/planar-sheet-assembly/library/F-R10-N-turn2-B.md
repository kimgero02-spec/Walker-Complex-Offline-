## 0. 요약

1. **(가) 대조.** A 의 일반층 (D0)–(D5) 은 R9 요약과 대체로 맞는다. 리본층 (R0)–(R5) 에는 **두 가지 어긋남** 이 있다. (a) (R4) "∃!" 는 길이 3 이상의 호 (내부 흰 점을 가진 호) 를 금지한다. 원문 §2.1 의 "경로" 공유와 맞지 않는다. 2. **(나) 정정 수용.** $\partial=\varnothing$ 이 정확한 조건이다. "$E_{\circ\circ}=\varnothing$" 은 파생 성분을 자유 조건처럼 써서 생긴 잘못이다. 근거는 §3.
3. **(다) Y 예.** 최소 예는 찾지 못했다 [추측]. 대신 방향에 대한 정정을 증명했다. 두 평면성의 차이는 **𝔄-평면, 𝔅-비평면** 방향만 가능하다 (A 가 "또는 역" 으로 쓴 것은 불가능하다) [증명]. 차이가 나려면 파생 흰–흰 간선이 비평면을 만들어야 하고, 그 판정 조건을 §4 에 적었다.
4. **미합의 3항목.** (1) 리본 μ=2 와 단면 ∅ 금지는 동치 아님 (A 와 같은 판단). (2) 세 조각 접합 필요성은 미결, μ=∞ 유지 (A 와 같다). (3) Y 예는 미확인 (§4).

### 1.2 리본층 (R0)–(R5)

**어긋남 A-1: (R4) "∃!" 와 긴 호.**
- A: $\forall w\ \exists!\,w':\{w,w'\}\in D_\partial$. 흰 점마다 짝이 정확히 하나다.
- 그러면 호는 길이 2 (흰 점 두 개) 뿐이다. 길이 3 이상의 호에서는 내부 흰 점이 두 짝을 가진다 [증명].
- 내 F-R8 (R4): 링크 $L(w)$ 의 변 1 개 = 끝점, 변 2 개 = 내부점. 내부 점을 허용한다.
- 문제의 원문 §2.1 은 조각이 "경로" 를 따라 붙는다고 명시한다. 두 조각이 길이 3 이상의 경로를 공유하면 (R4) "∃!" 는 그 공유를 표현하지 못한다. 그래서 A 의 리본 판은 원문보다 좁다 [증명].
- 판단: **반대**. (R4) 를 내 판 (다중 링크) 으로 되돌린다. 이유: 경로 공유를 막으면 원문 "경로" 와 어긋난다. A 가 쓴 명제 2 "호가 정확히 하나" 도 내 판에서는 "호 = 짝의 연결성분" 으로 바뀐다.

**어긋남 A-2: 단면의 정의 (전역 σ 대 쌍별).**
- A: 단면 $\sigma(\mathfrak B)=\{w:\exists w',\{w,w'\}\in D\}$ (전역). "리본층에서 $\sigma=J$" (R3).
- 내 F-R8/F-R9: 단면은 쌍 $\{P,P'\}$ 별 (공유 흰 점 집합). "단면 ∅ 금지" 는 H 연결 (R7).
- A 의 $\sigma=J$ 는 "모든 흰 점이 짝을 가진다" 이고, 이것은 (R4) 와 같은 내용이다. 따라서 A 의 (R3) 은 (R4) 에서 이미 나온다. 그리고 $\sigma=J$ 는 $H$ 가 연결이라는 뜻이 아니다. 두 조각이 흰 점을 공유하지 않는 두 덩이로 나뉘어도 $\sigma=J$ 는 성립한다 [증명].
- 판단: **반대** (정의 수정 요청). 리본층 "단면 ∅ 금지" 는 H 연결로 쓴다. R9 의 문구가 전역 $\sigma$ 였는지 확인 바람.

**어긋남 A-3: (R2) 쌍 크기 $\{0,2\}$ 와 (R5) 의 $m$.**
- 두 조건은 맞다 [증명]: (R5) 에서 $m=|K_\partial|$ 이므로 한 조각이 같은 류 쌍에 간선을 두 개 내지 않는다. 내 (R5) 와 같다.
- 판단: **수용**.

**(R0), (R1) 확인.** $|N(w)|=2$, 서로 다른 조각, 포트는 사이클 위, $C_K$ 는 평면 매장의 바깥면 경계. 내 (R1)–(R2) 와 같다 [증명].

**누락: H 연결 (R7).** A 의 리본층에는 H 연결 조건이 없다. R9 의 "단면 ∅ 금지" 가 H 연결이었다면 누락이다. 내 판에서는 R7 로 명시했다.

### 1.3 조립과 평면성 이름

- $G(\mathfrak B)=G(U\mathfrak B)$ [증명, 내 보조정리 G1 과 같다].

## 2. (나) "$E_{\circ\circ}=\varnothing$ 이고 $\partial=\varnothing$" 에 대한 판단

**답: A 의 정정 ($\partial=\varnothing$) 을 수용한다. (가)**

이유 [증명]:
- $E_{\circ\circ}$ 는 파생 성분이다 (β3). 따라서 $E_{\circ\circ}=\varnothing$ 은 "파생이 비었다" 는 뜻이고, 그것은 공유 간선이 없는 $\mathfrak A$ 만 고른다. 나 (나) 의 의도 (모든 $\mathfrak A$ 를 포함하는 특수 경우) 와 맞지 않는다.
- $\{\mathfrak B:\partial=\varnothing\}$ 는 $\mathfrak A$ 와 일대일이다. 역사상 $\mathfrak A\mapsto(\mathfrak A,\varnothing)$. 파생 $E_{\circ\circ}$ 는 $\mathfrak A$ 에서 자동으로 정해진다.
- 내 F-R8 §6.2 와 F-R9 §3 의 $\iota$ 와 같은 구성이다 (내 현행판의 $\iota_{\beta_3}$ 는 $\partial=\varnothing$ 이었다).

방어 불필요. "$E_{\circ\circ}=\varnothing$" 을 특수화 조건으로 쓰는 것은 철회한다.

## 3. (다) Y 예의 판정

### 3.1 방향 정정 (증명)

$\mathfrak A\subseteq\mathfrak B^\flat$ 이므로 $\mathfrak B$-pl ⟹ $\mathfrak A$-pl. 따라서 **가능한 분리는 한 방향뿐**이다:

$$\mathfrak A\text{ 평면},\qquad \mathfrak B^\flat\text{ 비평면}.$$

A 의 §4.3 "$\mathfrak A$-평면이지만 $\mathfrak B$-비평면인 예 (또는 역)" 에서 "역" 은 불가능하다 [증명]. 

또 A 의 1턴 §3.2(iv) 의 "𝔅-평면성은 𝔄-평면성보다 강할 수 있다" 는 맞다.

### 3.2 최소 예: 발견 못함 [추측]

분리에는 다음이 필요하다 [증명]:
- $\mathfrak A$ 는 평면이어야 한다.
- 어떤 파생 쌍 $ww'$ 에 대해, $w,w'$ 가 $\mathfrak A$ 의 모든 평면 매장에서 같은 면에 놓이지 않아야 한다 (그렇지 않으면 $ww'$ 를 그 면에 그을 수 있다). 다중 파생 쌍이 있으면 더 복잡하다.

반례 후보 확인:
- E2 (두 사각형 0132, 0312 의 중첩, $G=K_4$): $\mathfrak A$ 가 비평면이므로 $\mathfrak B^\flat$ 도 비평면이다. **분리가 아니다** [증명].
- 프리즘 + 흰 삼각형 (세 조각 쌍): $\mathfrak B^\flat$ 는 평면이다 (흰 삼각형 변 $w_iw_j$ 를 프리즘의 사각면 $x_ix_jy_jy_i$ 에 그을 수 있다) [계산 확인 (손 계산)]. 분리가 아니다.

따라서 손으로 확인 가능한 최소 예는 아직 없다. 탐색 대상: 3-연결 평면 $\mathfrak A$ (매장 유일), 흰 점이 차수 2 인 세분 구조, 파생 쌍이 한 면을 공유하지 않는 경우. 세분 때문에 3-연결이 깨지는 것이 핵심 난점이다 [추측].

### 3.3 판정 기준 (정리 형태, 증명은 생략)

$\mathfrak A$ 가 평면이고 3-연결 (정규화 가정) 이라 하자. 그러면 매장은 유일하므로 (Whitney, [기억-미검증]),

$$\mathfrak B^\flat\text{ 평면}\iff\forall ww'\in D(\mathfrak B):\ w,w'\text{ 가 같은 면에 있다, 그리고 모든 파생 간선을 면 안에서 교차 없이 그을 수 있다.}$$

후자는 파생 간선들 사이의 교차 (같은 면에 여러 쌍이 있을 때) 가 문제다. 이것은 $\mathfrak A$ 의 면 구조로 쓸 수 있다 [추측].

## 후속연구 지점

1. **(우선 1) 리본 (R4) 의 긴 호 허용 여부 확정.** 이유: A 의 "∃!" 는 원문 "경로" 공유를 막는다. 다중 링크로 되돌리면 길이 3 이상 호의 $\chi$ 공식과 정리 Mix 의 호 분해가 다시 검사되어야 한다 (F-R6 F4, F-R7 F17 과 연결). 시작: 길이 3 호를 가진 최소 리본 예 (두 조각이 경로 3 개 점을 공유) 를 만들어 Mix 와 $\chi$ 공식을 손으로 확인한다. 난점: 내부 흰 점의 두 짝이 같은 쌍 표지를 가지므로 $\mathcal D$ 만으로 호를 가를 수 없을 수 있다.
2. **(우선 2) Y 예의 최소 반례 탐색 (분리 방향 $\mathfrak A$-pl, $\mathfrak B^\flat$-비pl).** 이유: 두 평면성 이름의 실질이 이 예로 정해진다. 시작: 3-연결 평면 $\mathfrak A$ 에서 파생 쌍이 같은 면을 공유하지 않는 경우를 찾는다. 세분 (차수 2 흰 점) 을 넣으면 3-연결이 깨지므로, 세분 없는 조각 구조부터 확인한다. 난점: 2-절단 때문에 매장이 여러 개가 되어 판정이 복잡하다.
3. **(우선 3) 단면 정의의 최종 문구 확인.** 이유: R9 원문이 전역 $\sigma$ 인지 쌍별인지에 따라 리본 판의 H 연결 조건이 있거나 없다. 시작: R9 원문과 대조하고, 쌍별 단면 + H 연결을 공식 문구로 확정한다.
4. **(우선 4) 세 조각 접합의 필요성 (A 후속 1 과 같은 문제).** 이유: μ=∞ 기본값의 근거. 시작: 명제 B1 을 $K_2$ 조각이 섞인 표현으로 넓힌다. 난점: 완전 탐색이 필요할 수 있다.
