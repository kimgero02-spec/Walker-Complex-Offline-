# [R03-researcher2] 색칠수 공격: 정규화한 나무형 2-합은 +1 에서 막히고, 3-합 나무는 +2 까지 간다

- 작성자: researcher2 · R03 · 반례꾼 (색칠수)
- 코드: `rooms/researcher2/r03_chi.py` (예제 전부), `r03_chi_planar.py`, `r03_planarQ.py`. 색칠수는 백트래킹 정확 계산, treewidth 는 부분집합 DP 정확 계산 (모두 17점 이하).

## 요약
- "간선 아닌 2-합이면 $\chi(G)\le\max+1$" 은 **정규화**(접합 집합 안의 $G$ 변을 그 집합을 품은 모든 조각이 가짐)와 **나무형 $H$** 를 둘 다 가정하면 참이다. 1-합·간선 2-합·비간선 2-합을 섞은 연쇄여도 그렇다. +1 은 평면 조각으로 도달된다 `[증명]`.
- 정규화가 없으면 나무형 2-합으로도 간극이 끝없이 커진다 (E2: 조각 $\chi\le3$, $\chi(G)=n+1$). $H$ 에 사이클이 있으면 1-합만으로도 그렇다 (E1) `[증명]`+`[계산 확인]`.
- **핵심 반례 E6**: 정규화한 나무형 **3-합**에서 조각 셋 모두 $\chi=3$, 접합 삼중쌍 둘은 $G$ 에서 독립인데 $\chi(G)=5=\max+2$ `[증명]`+`[계산 확인]`. 같은 조각을 **한** 삼중쌍에만 붙이면 +1 이하다 (정규화된 단일 접합, $s\le3$) `[증명]`. 간극은 접합 하나가 아니라 접합들이 **이어지는 방식**에서 나온다. 단 E6 의 가운데 조각 $Q$ 는 비평면이다.
- 일반 상한: 정규화한 나무형 $s$-합이면 $\chi(G)\le\max+s-1$ 이고, 접합 개수와 상관없이 쌓이지 않는다 `[증명]`. researcher1 의 "많은 접합에서 증가분이 쌓인다($K_n$)"는 **정규화하지 않은** 경우에만 맞다.
- 간선 공유 2-합(간선 유지)은 $\chi$ 를 보존한다. 간선을 지우는 (행렬식) 2-합은 보존하지 않는다 (E3b: $4\to3$). $\chi\le\mathrm{tw}+1$ 은 모든 예에서 성립하지만 평면 조각의 tw 는 제한이 없어 이 문제에는 약하다.

## 본문

### 0. 설정과 용어
- 조각 $P_1,\dots,P_n$, $G=\bigcup P_k$ (점과 변 모두 합집합). 설명서 $H$: 점 = 조각, 변 $kl$ 의 데이터 = 접합 집합 $S_{kl}=V(P_k)\cap V(P_l)$, 그리고 $S_{kl}$ 안의 쌍이 **각 조각에서** 간선인지.
- **나무형**: $H$ 가 나무이고 나무 분해 조건을 만족한다 (점 $x$ 를 품은 조각들이 $H$ 의 연결 부분나무를 이룬다).
- **정규화**: 모든 접합 $S_{kl}$ 에 대해 $P_k[S_{kl}]=P_l[S_{kl}]=G[S_{kl}]$. 설명서의 "간선 비트"를 각 조각에 반영한 것이다. 최소 예($K_4-uv$ 와 $K_2$)를 정규화하면 첫 조각이 $K_4$ 가 되어 간극이 사라진다.
- $m=\max_k\chi(P_k)$. $S$ 의 분할 $\pi$ 에 대해 $\chi_\pi(P)$ 는 $S$ 위의 색 분할이 정확히 $\pi$ 인 적정 색칠의 최소 색 수다 (researcher1 정리 1 의 표기).

### 1. 방어: 정규화한 나무형 합의 상한 (대상 A, B 의 올바른 판)

**보조정리 L (블록 새 색)** `[증명]`. $Q$ 를 $\chi(Q)$-색칠 $c$ 를 가진 그래프, $S\subseteq V(Q)$, $\pi$ 를 $Q[S]$ 에 대해 적정인(블록이 독립인) $S$ 의 분할이라 하자. 블록 수가 $t$ 일 때
$$\chi_\pi(Q)\le \chi(Q)+t-\mathbf 1[\pi\text{ 에 한원소 블록이 있음}]\le\chi(Q)+|S|-1 \quad(|S|\ge2).$$
*증명.* 한원소 블록 $\{w\}$ 가 있으면 $w$ 는 $c(w)$ 를 유지하고, 나머지 $t-1$ 개 블록에 서로 다른 새 색을 하나씩 준다. $S$ 밖의 점은 $c$ 를 유지한다. 새 색끼리 다르고 옛 색과도 다르며, 블록은 독립이므로 적정이다. 색 분할은 정확히 $\pi$ 다 ($w$ 의 옛 색은 새 색들과 다르다). 한원소 블록이 없으면 $t\le|S|/2$ 개 블록 모두에 새 색을 준다. $t\le s$ 이고 등호이면 모두 한원소이므로 $t-1\le s-1$ 이다. $s\ge2$ 이면 $s/2\le s-1$ 이다. $\square$

**정리 T (정규화 나무형 $s$-합)** `[증명]`. 정규화한 나무형 설명서에서 모든 접합의 크기가 $\le s$ 이면 $\chi(G)\le m+s-1$ 이다. 특히 $s\le2$ 이면 (1-합, 간선 2-합, 비간선 2-합을 어떻게 섞든) $\chi(G)\le m+1$ 이다.
*증명.* $H$ 의 뿌리 조각을 $\chi\le m$ 색으로 칠하고, 나무를 따라 내려가며 자식 조각 $Q$ 를 칠한다. $Q$ 가 부모와 공유하는 점은 접합 $S=S_{QP}$ 안에 있다 (나무 분해 조건). 이미 칠해진 다른 조각과 공유하는 점도 경로 위의 모든 조각, 특히 부모에 있으므로 $S$ 안에 있다. 부모의 색칠은 부모의 변을 존중하고, 정규화로 부모가 $G[S]$ 를 품으므로 $S$ 위의 분할 $\pi$ 는 $G[S]=Q[S]$ 에 적정이다. 보조정리 L 로 $Q$ 를 $\le m+s-1$ 색으로 분할 $\pi$ 를 갖게 칠한 뒤, 색 이름을 바꿔 $S$ 위에서 부모와 일치시킨다 ($m+s-1$ 색의 순열; 블록 → 색 대응은 단사). 모든 변은 어떤 조각 안에 있으므로 적정이다. $\square$
- 간선 2-합($uv\in G$)과 1-합에서는 $\pi$ 가 강제(이산)이므로 비용 0, 즉 클릭 합은 $\chi(G)=m$ 이다 (같은 증명. 대상 C).
- 핵심: 이 증명은 각 조각을 **한 번** 칠하므로 +$(s-1)$ 이 접합 개수만큼 쌓이지 않는다.

**정리 S1 (정규화된 단일 접합, $G[S]$ 가 분할 그래프)** `[증명]`. 모든 조각이 같은 $S$ 에서만 만나고 정규화되어 있으며, $S=I\sqcup C$ ($I$ 는 $G$ 에서 독립, $C$ 는 클릭) 로 나뉘면 $\chi(G)\le m+1$ 이다. $|S|\le3$ 이면 언제나 그렇다.
*증명.* $\pi=\{I\}\cup\{\{w\}:w\in C\}$ 로 둔다. 각 조각의 최적 색칠에서 $I$ 를 새 색 하나로 칠하면 $C$ 의 점들은 서로 인접하므로 이미 색이 다르고, 새 색과도 다르다. 그래서 모든 $k$ 에서 $\chi_\pi(P_k)\le m+1$ 이고, researcher1 정리 1 로 끝난다. $|S|\le3$ 인 그래프는 모두 분할 그래프다 (빈 그래프, $K_2+K_1$, $P_3$, $K_3$ 를 직접 확인). $\square$
- 따라서 researcher1 이 평면 조각으로 $s=3$ 에서 $+2$ 에 도달한 예($K_5=K_{1,1,3}\cup K_3$)는 정규화되지 않은 것이다. 정규화하면 $K_{1,1,3}$ 조각에 삼각형이 들어가 $K_5$ 가 되므로 간극은 0 이다.
- $|S|=4$ 에서 분할이 아닌 $G[S]\in\{2K_2, C_4\}$ 는 열려 있다 (후속 2).

### 2. 반례들

**E1 ($H$ 에 사이클, 1-합만)** `[증명]`+`[계산 확인]`. $K_5$ 의 변마다 조각 $K_2$ 하나씩, 10개를 둔다. 이웃 조각은 정점 하나를 공유하므로 모든 접합이 1-합(클릭)이고 정규화도 되어 있다. 그런데 $\chi(G)=5$, $m=2$. 나무형이 아니어서 정리 T 가 적용되지 않는다. 가장 작은 판은 $K_2$ 세 개로 만든 $K_3$ ($H=C_3$, $3>2$) 이다. researcher1 의 $C_5$ 예와 같은 기제다.

**E2 (나무형 2-합, 정규화 없음)** `[증명]`+`[계산 확인]`. 중심 조각 $K_{2,n}$ (작은 쪽 $\{a,b\}$, 큰 쪽 $S$) 에 대해 $S$ 의 쌍 $\{i,j\}$ 마다 잎 조각으로 삼각형 $i\,j\,w_{ij}$ 를 붙인다. $H$ 는 별이고, 접합은 모두 크기 2이며, 모든 조각이 평면이다 ($\chi$: 2와 3). $G\supseteq K_n\vee\{a\}$ 이므로 $\chi(G)\ge n+1$ 이고, $a=b$ 로 두면 $=n+1$ 이다. 계산: $n=4$ 에서 $5$, $n=5$ 에서 $6$. 간극은 $n-2$ 로 끝이 없다. 정규화하면 중심 조각이 $K_n\vee\overline{K_2}$ 가 되어 ($\chi=n+1$, 계산 확인) 간극이 0 이 된다. **결론**: "간선이 아닌 2-합" 은 "모든 조각에서(곧 $G$ 에서) 간선이 아님" 이어야 한다. 한 조각에서만 간선이 아닌 것으로는 안 된다.

**E3b (간선 삭제 2-합)** `[계산 확인]`. $K_4$ 두 개를 변 $uv$ 에서 붙이고 $uv$ 를 지우면 (매트로이드식 2-합) $\chi=3<4=m$ 이다. 일반적으로 $m-1\le\chi\le m$ 이다 ($G$ 는 클릭 합의 부분그래프이고, $P_k-uv\subseteq G$) `[증명]`. 연구원이 "2-합"이라고 쓸 때 간선을 남기는지 밝혀야 한다.

**E4 (+1 의 도달, 정규화 나무형 비간선 2-합)** `[증명]`+`[계산 확인]`.
- 3색판: $A=K_4-uv$ (3-색칠에서 $u=v$ 로 강제), $B=(K_4-wv)+uw$ (3-색칠에서 $w=v$ 이고 $u\ne w$ 이므로 $u\ne v$ 로 강제). $uv\notin G$, $\chi(A)=\chi(B)=3$, $\chi(G)=4$.
- 4색 평면판: $A=K_5-ce$. 적층 삼각분할로, $abd$ 면에 $e$ 를 쌓은 것이므로 $e$ 는 $a,b,d$ 와 달라야 하고 $c=e$ 로 강제된다. $B$ = 같은 꼴 $K_5-ce'$ (공유점은 $c$) 에 $e'e$ 변을 더한 것 ($e\ne e'=c$ 로 강제). 두 조각 모두 평면이고 $\chi=4$, $ce\notin G$, $\chi(G)=5$.

**E6 (핵심: 정규화 나무형 3-합에서 +2)** `[증명]`+`[계산 확인]`.
- 조각 $Q$ (9점 21변): 삼각형 $abc$. 귀 $x\sim b,c$, $y\sim a,c$, $z\sim a,b$. 그리고 $p\sim a,b,x,y$, $q\sim a,c,x,z$, $r\sim b,c,y,z$. $\chi(Q)=3$ ($a,b,c,x,y,z,p,q,r\mapsto1,2,3,1,2,3,3,2,1$).
- 조각 $K^{(1)}=K_{1,1,3}$ (서로 인접한 두 꼭짓점 $h_1,h_2$ 가 $x,y,z$ 와 모두 연결), $K^{(2)}=K_{1,1,3}$ ($k_1,k_2$ 가 $p,q,r$ 와 연결). 둘 다 평면이고 $\chi=3$.
- $H$ = 경로 $K^{(1)}-Q-K^{(2)}$. 접합 $T_1=\{x,y,z\}$, $T_2=\{p,q,r\}$ 은 $G$ 에서 독립이므로 정규화가 자명하게 성립한다. 나무 분해 조건도 성립한다 ($K^{(1)}\cap K^{(2)}=\varnothing$).
- **정리 E6.** $\chi(G)=5$, $m=3$.
*증명.* 4-색칠이 있다고 하자. $K^{(1)}$ 에서 $h_1,h_2$ 가 두 색을 쓰므로 $T_1$ 은 남은 두 색만 쓴다. 그래서 무지개(세 색 모두 다름)가 아니다. $Q$ 에서 $a,b,c$ 의 색을 $1,2,3$ 으로 두고 넷째 색을 $4$ 라 하자. 그러면 $x\in\{1,4\}$, $y\in\{2,4\}$, $z\in\{3,4\}$ 다. $T_1$ 이 무지개가 아니면 같은 색인 두 점이 있고, 그 공통 색은 $4$ 일 수밖에 없다. 그래서 $x,y,z$ 중 적어도 둘이 $4$ 다. 두 점짜리 부분집합은 모두 $\{x,y\}$, $\{x,z\}$, $\{y,z\}$ 각각과 만나므로, $p$ 는 이웃 $a,b$ 와 $x,y$ 중 하나에서 색 $1,2,4$ 를 보고 $p=3$ 이 된다. 같은 방법으로 $q=2$, $r=1$ 이다. 그러면 $T_2$ 가 무지개인데, $K^{(2)}$ 는 $T_2$ 를 두 색으로 제한한다. 모순이다. 따라서 $\chi(G)\ge5$ 이고, 정리 T ($s=3$) 로 $\le5$ 다. $\square$
- 계산 확인: $\chi(G)=5$ (13점 35변). $Q$ 의 4-색칠 432개에서 "$T_1$ 비무지개이고 $T_2$ 비무지개" 인 것이 0개로, 증명의 함의 단계와 일치한다. 대조군 E7: 같은 $Q$ 와 $K_{1,1,3}$ 두 개를 **같은** 삼중쌍 $T_1$ 에만 붙이면 $\chi=4$ 로, 정리 S1 과 일치한다.
- 해석 `[추측]`: (m+1)-색에서 조각이 줄 수 있는 제약은 "독립 삼중쌍이 무지개가 아니다"($K_{1,1,3}$)뿐이다. 그러나 $Q$ 처럼 "$T_1$ 비무지개 ⟹ $T_2$ 무지개" 인 **전달 장치**가 있으면 두 제약이 나무를 따라 충돌한다. 이것은 홀로노미가 아니라 나무 위의 제약 전파다.
- 한계: $Q$ 는 비평면이다 (networkx). $p,q,r$ 가 보는 귀 쌍을 바꾼 27가지 판도 모두 비평면이었다 (구성 탐색이며 근거로 쓰지 않음). 같은 $G$ 를 평면 조각으로 나누어 보았더니 ($W$, $W+p$ 꼴) 접합이 5점이 되고 정규화가 깨졌다. 평면 조각판은 열려 있다 (후속 1).

읽는 법: 정규화한 2-합에서 $\chi(G)$ 는 조각마다 "$u,v$ 의 형($=$/$\ne$)이 $m$ 색에서 강제되는가" 2비트로 정해진다 (researcher1 정리 3 과 일치). 간극은 0 또는 1 이다.

## 후속연구 지점
1. **(최우선) E6 의 평면 조각판.** 무엇: 정규화한 나무형 3-합에서 모든 조각이 평면이고 $\chi(G)=m+2$ 인 예를 찾거나, 평면이면 $+1$ 로 막힌다는 것을 증명한다. 왜: 주제가 "평면 조각"이고, E6 의 유일한 결함은 전달 장치 $Q$ 가 비평면이라는 점이다. 시작 방법: 함의 "$T_1$ 비무지개 ⟹ $T_2$ 무지개" 를 여러 평면 조각의 사슬로 나누어 구현한다 (중간 접합에 클릭이나 $P_3$ 를 써서 정규화를 유지). $m=4$ (적층 삼각분할 강제 장치) 판도 시도한다. 난점: $(m+1)$ 색에서는 강제 장치가 $\chi\ge m+1$ 을 요구하므로 (단일 쌍 장치는 불가능, 증명됨) 전달은 삼중쌍 이상에서만 가능하다. 평면성이 이것을 막는지는 모른다.
2. **(높음) 정규화된 단일 접합의 정확한 간극.** 무엇: $G[S]$ 가 분할 그래프가 아닐 때 ($|S|=4$: $2K_2$, $C_4$) $\chi(G)\le m+1$ 인가? 왜: 정리 S1 은 분할 그래프에서만 증명했다. 일반 상한은 $m+\theta$ ($\theta$ = $G[S]$ 의 정점을 독립 집합 $j$ 개와 클릭 하나로 덮는 최소 $j$) 로 보인다 `[추측]`. 시작 방법: $2K_2$ 에서 분할 $\{xz\mid yw\}$ 와 $\{xw\mid yz\}$ 의 비용을 두 조각이 엇갈리게 강제하는 장치를 구성하거나, 보조정리 L 을 다듬어 반증한다. 난점: 강제는 $(m+1)$ 색 수준에서 일어나야 한다.
3. **(높음) 나무형 설명서의 정확한 판정 = 제약 전파.** 무엇: 각 접합에 "$q$ 색에서 허용되는 분할 집합"을 레이블로 두고, 잎부터 줄이는 재귀로 $\chi(G)$ 를 계산하는 정리 (researcher1 후속 2 와 같은 목표). E6 은 레이블이 "비무지개"·"함의" 꼴일 때 충돌하는 가장 작은 예로 시험 사례가 된다. 시작 방법: 분할 격자 위의 관계 합성으로 정식화한다. 난점: 접합들이 겹칠 때의 분할 제한 연산.
4. **(중간) 정규화의 비용.** 무엇: 설명서의 간선 비트를 조각에 넣으면 (정규화) 조각이 평면에서 벗어날 수 있다. "평면 조각 + 간선 비트" 와 "정규화 조각" 중 어느 쪽을 이 주제의 표준 정의로 할지 정하고, 두 쪽 사이의 $\chi$ 간극을 잰다 (E2 는 무한). 시작 방법: 정규화한 조각의 $\chi$ 를 $\chi(P_k)+\beta$ (researcher1 정리 4) 로 묶고, 평면 조각 + 클릭 접합의 경우를 따로 다룬다. 난점: 정의 선택은 문주님 결정 사항일 수 있다.
5. **(낮음) 사이클 있는 $H$.** E1 처럼 1-합만으로 무엇이든 만들 수 있으므로 무조건 상한은 없다. 사이클의 "색 홀로노미" 틀 (researcher1 후속 1) 에서 정규화 + 접합 크기 1 + $H$ 가 길이 $\ge4$ 의 무현 사이클만 가질 때 같은 제한된 판정이 있는지 본다.
