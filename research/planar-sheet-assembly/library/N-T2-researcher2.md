## 반박 (반례 포함)

### 반박 1. (a) 조건 (W) 는 STMT 에 필요하지 않다. 결론을 "조건부"로 만든 근거 하나가 사라진다

T1 은 "(W) 가 깨지면 고리가 생기거나 조각이 접힌다. 그래서 조건부"라고 했다. 하지만 STMT 가 요구하는 것은 "$\Gamma$ 대로 조립하면 $G$ 가 나온다"와 "$\chi(G)$ 가 $\Gamma$ 의 데이터로 정해진다", 이 두 가지뿐이다. 조각이 $G$ 의 부분그래프로 들어가야 한다는 요구는 없다. 접힘(단사가 아닌 붙임)도 몫 그래프로서 잘 정의된 조립이다.

**명제 R1 [증명].** (W) 없이 정리 2 가 그대로 성립한다. 단, 고리가 생긴 $G$ 는 $\chi=\infty$ 로 둔다.

*증명.* $E_J$ 의 간선은 서로 다른 조각을 잇는다. 따라서 점이 둘 이상인 식별류는 반드시 두 조각 이상과 만나고 $\mathcal J$ 에 든다. 그러므로 $\mathcal J$ 밖의 식별류는 점 하나짜리다.
- (⟹) $G$ 의 $q$-색칠 $c$ 가 있으면 $c\circ[\cdot]$ 는 $P_k$ 의 올바른 색칠이다. $[\cdot]$ 이 단사가 아니어도 준동형이기만 하면 된다. 고리가 있으면 $G$ 는 색칠 불가능하고, 이때 조건도 실패한다. $xy\in E(P_k)$ 이고 $[x]=[y]$ 이면 $x,y$ 를 한 블록에 넣는 분할은 $\Pi_q(P_k)$ 에 없기 때문이다.
- (⟸) T1 의 구성과 같다. $\sigma_k\circ c_k=f\circ[\cdot]$ 가 $J_k$ 위에서 성립하므로, 같은 식별류의 여러 원소 (같은 조각 안의 두 점을 포함) 가 모두 같은 값 $f([x])$ 를 받는다. 따라서 $c$ 는 잘 정의된다. 나머지 점은 점 하나짜리 식별류다. $\square$

**계산 [계산 확인, nt2.py "(a)"]**
- F1: $P_1=C_5$ ($x\,a\,y\,b\,c$), $P_2=\{w\}$, $E_J=\{xw,yw\}$ 로 두면 식별류 $\{x,y,w\}$ 가 $P_1$ 을 두 번 만난다. $G$ 는 삼각형 $xbc$ 에 매달린 점 $a$ 가 붙은 꼴이고 $\chi(G)=3$ 이다. (W) 를 가정하지 않은 공식도 3 을 준다 ✓.
- F2: $P_1=K_2=xy$ 를 접으면 고리가 생긴다. 공식도 $\infty$ 를 준다 ✓.
- F3: 평면 조각 하나 ($K_{3,3}$ 의 점 $a_1$ 을 두 점 $s,t$ 로 쪼갠 것) 와 점 하나를 접어 붙이면 $G\cong K_{3,3}$ 이 된다. 접힘은 평면성 쪽에서도 정상적인 조립이다.

**결론.** (W) 는 "조각이 $G$ 의 부분그래프"라는 *해석*에만 필요하고, STMT 의 두 주장에는 필요하지 않다. 결론을 조건부로 만드는 이유가 (W) 라면 그 이유는 약하다. (T1 의 진짜 조건은 아래 반박 3 의 "읽는다"는 말의 뜻이다.)

덧붙일 점 [증명]. "사상 없이"에는 대가가 있다. $\Gamma$ 는 맨 그래프가 아니라 **변 2-색 그래프** ($E_P/E_J$ 표지) 여야 한다. 반례: 밑그래프가 같은 경로 $a\,b\,c\,d$ 라도 표지를 다르게 붙이면 $G$ 가 다르다.
- $E_J=\{bc\}$ 이고 조각이 $\{ab\},\{cd\}$ 이면 $G=P_3$ 이다.
- $E_J=\{ab,cd\}$ 이고 조각이 $\{a\},\{bc\},\{d\}$ 이면 $G=K_2$ 이다.

사상이 사라진 것이 아니라 변 표지로 옮겨 간 것이다. 이것은 T1 의 "재부호화" 해석과 맞는다. 다만 STMT 의 "그래프 $\Gamma$" 는 "변이 두 종류인 그래프"로 읽어야 한다.

### 반박 2. (b) T1 의 장애물 "$q\ge4$ 평면 가제트가 없다" 는 틀렸다. $q=4$ 에서 평면 가제트가 존재한다

T1 은 두 가지를 말했다. (i) $q=4$ 가제트에는 $K_{3,3}$ 이 들어 있어 비평면이다. (ii) 후속연구 1 의 난점으로 "4색 정리 때문에 평면 가제트는 분할을 하나로 강제하지 못한다". (i) 는 T1 의 특정 구성에 대해서는 맞다 (계산 확인: $Q_{\{uv\}}$ 는 비평면이다). 그러나 (ii) 는 **거짓**이다.

**명제 R2 [증명].** $q\in\{1,2,3,4\}$ 이고 $\pi$ 가 $J$ 의 분할이며 블록 수가 $q$ 이하이면, $\Pi_q(Q,J)=\{\pi\}$ 인 **평면** 그래프 $Q$ (와 $J$ 의 단사 배치) 가 있다. 따라서 T1 의 정리 3 은 상대 조각을 평면으로 제한해도 $q\le4$ 에서 성립한다.

*증명.*
- $q=4$: 쌓은 삼각분할(아폴로니우스 망)을 쓴다. $K_4$ 에서 시작해 면 안에 차수 3 점을 넣는 일을 되풀이한다. 이 그래프는 유일하게 4-색칠된다 (귀납: 새 점의 세 이웃은 삼각형이므로 세 색을 쓰고, 새 점의 색은 네 번째 색으로 강제된다). 색이 $\{i,j,k\}$ 인 면에 점을 넣으면 네 번째 색의 점이 하나 는다. 그래서 각 색 부류를 원하는 만큼 키울 수 있다. $\pi$ 의 블록 $B_i$ 의 점들을 색 $i$ 인 서로 다른 점에 배치하면 $\Pi_4(Q,J)=\{\pi\}$ 다.
- $q=3$: 2-나무 (삼각형을 변을 따라 이어 붙인 것) 는 평면이고 유일하게 3-색칠된다. 배치 방법은 같다.
- $q\le2$: 긴 경로를 쓰거나 점 하나에 모은다. $\square$

**계산 [계산 확인, nt2.py "(b)"].** $U$: $K_4\{a,b,c,d\}$ 에 $e$ 를 면 $abd$ 에 넣고 (색은 $c$ 와 같음), $f$ 를 면 $abe$ 에 넣는다 (색은 $d$ 와 같음). $U$ 는 평면이고 $df$, $cf$ 는 간선이 아니다.
- $\Pi_4(U,\{d,f\})=\{\{df\}\}$ 로 같음이 강제된다. $\Pi_4(U,\{c,f\})=\{\{c|f\}\}$ 로 다름이 강제된다. $\Pi_4(U,\{d,f,c\})=\{\{c|df\}\}$ 이므로, T1 의 구성에서는 $K_{3,3}$ 이 나왔던 블록 $\{uv\}$ 형태도 평면으로 강제된다.
- 결과: $P=U$ 를 $(c,f)$ 에서, $Q=U$ 를 $(d,f)$ 에서, 비간선 두 점으로 붙이면 $\chi(P)=\chi(Q)=4$, $\chi(G)=5$ 이다. 정리 2 의 공식도 5 를 준다. 대조로 $P'=$ 두 고립점과 같은 $Q$ 를 붙이면 $\chi=4$ 다.
- 이것은 **평면 조각 두 개를 두 점에서 붙였더니 $\chi=5$** 인 예다. 2-합 상한 $m+1$ (R03) 이 평면 조각에서도 실제로 달성된다.

**그래도 남는 것 ($q\ge5$) [증명 + 계산 확인].**
- *보조정리 L5 [증명].* $\chi(Q)\le4$, $q\ge5$ 이고 $x,y\in J$ 가 $Q$ 에서 비인접이면, $\Pi_q(Q,J)$ 에는 $x\sim y$ 인 분할과 $x\not\sim y$ 인 분할이 모두 있다.
  - 다름: 4-색칠에서 $c(x)=c(y)$ 이면 $y$ 를 색 5 로 바꾼다.
  - 같음: 점을 하나 합치면 색칠수는 많아야 1 늘어난다. 따라서 $\chi(Q/xy)\le5$ 다.

  따라서 평면 $Q$ 의 $\Pi_5$ 가 분할 하나뿐이려면 $J$ 가 $Q$ 의 클릭이어야 한다. **단일 분할을 강제하는 가제트로 증명하는 방법은 $q\ge5$ 평면 세계에서 원리적으로 막힌다.** T1 의 장애물은 $q=4$ 에 있는 것이 아니라 $q=5$ 로 옮겨 간다.
- 그렇다고 평면 세계에서 $q=5$ 프로필이 간선 비트로 줄어드는 것도 아니다. 반례 (nt2d.py): 바퀴 $W_5$ 와 테두리 $C_5$ 는 둘 다 평면이고, $J=$ 테두리 5점, $P[J]=C_5$ 로 같다. 그러나 $\Pi_5(W_5)$ 에는 이산 분할이 없고 (중심점이 칠해질 색이 없다) $\Pi_5(C_5)$ 에는 있다. 이 둘은 **평면** 상대 조각 (오각별 $C_5'$) 이 구별한다: $\chi(W_5\cup C_5')=\chi(K_6)=6$, $\chi(C_5\cup C_5')=\chi(K_5)=5$ 이다. 구별 방법은 단일 분할 강제가 아니라 "두 프로필의 교집합이 비는가" 이다.
- *일반 사실 [증명].* $q\ge\chi(P)+|J|$ 이면 $\Pi_q(P,J)=\{\pi:\ \pi \text{ 의 블록이 } P[J] \text{ 에서 독립}\}$ 이다. 블록마다 새 색을 주면 된다. 따라서 필요한 데이터는 유한하다: $P[J]$ 와 $\chi(P)\le q<\chi(P)+|J|$ 범위의 $\Pi_q$ 다.

**(b) 의 판정.** "정리 3 이 $q\le3$ 에서만 된다"는 사실은 문주님 요구를 **막지 않는다**. 이유는 두 가지다.
1. 요구에 필요한 것은 충분성 (정리 2) 이고 최소성이 아니다.
2. 최소성 자체도 평면 세계에서 $q\le4$ 까지 성립한다 (명제 R2).

열린 것은 "평면 세계, $q\ge5$ 에서 $\Pi_q$ 가 최소 데이터인가" 하나다.

### 반박 3. (c) 프로필은 '그래프적 정보' 다. 다만 "$E_J$ 의 구조" 쪽이 정보가 아니라 **계산 문제**로 남는다

T1 의 자가 진단 1 이 예상한 공격 ("프로필은 계산 정의다") 은 반만 맞다. 내 판정은 이렇다.

**명제 R3 [증명].** 프로필은 조각에서 만든 파생 그래프들의 색칠수로 정확히 표현된다. $J$ 의 분할 $\pi$ 에 대해 $P_\pi$ 를 다음과 같이 만든다: 블록마다 한 점으로 합치고, 합친 점들끼리 모두 잇는다. 그러면
$$\pi\in\Pi_q(P,J)\iff \chi(P_\pi)\le q .$$
따라서 $(\Pi_q)_q$ 는 **색칠수 벡터 $\bigl(\chi(P_\pi)\bigr)_{\pi}$** 와 같은 정보다. 정리 2 는 이렇게 다시 쓸 수 있다.
$$\chi(G)=\min_{\Pi\ \text{는 } \mathcal J \text{ 의 분할}}\ \max\Bigl(|\Pi|,\ \max_k \chi\bigl((P_k)_{\Pi|_{J_k}}\bigr)\Bigr).$$
이것은 "조각의 그래프적 정보 (색칠수) 로 읽는다"는 요구의 글자 그대로의 형태다. 다만 조각 하나에 색칠수 하나가 아니라, 접합 분할마다 색칠수가 하나씩 있다.

*증명.* $P$ 의 색칠 중 $J$ 위 분할이 정확히 $\pi$ 인 것은 $P_\pi$ 의 색칠과 일대일로 대응한다. 블록 안은 같은 색이고, 블록끼리는 다른 색이다 (클릭 간선이 강제한다). 공식의 ≤ 방향: $q=\max(\dots)$ 로 두면 $|\Pi|\le q$ 이므로 $f$ 를 단사로 정할 수 있고, 각 $\pi_k\in\Pi_q$ 다. ≥ 방향: $G$ 의 최적 색칠에서 $\Pi=\ker c|_{\mathcal J}$ 로 둔다. $\square$

계산 (nt2.py "(c)"):
- T1 예 2 의 $A_2$: $\chi(P_{uv})=4$, $\chi(P_{u|v})=3$.
- $B_2$: $\chi(P_{uv})=3$, $\chi(P_{u|v})=4$.

벡터가 서로 뒤집혀 있고, 이것이 $\chi(G)$ 의 차이를 만든다.

**그러나 반박할 부분 [증명].** 공식의 $\min_\Pi$ 와 $|\Pi|$ 항은 조각 정보가 아니라 **$E_J$ 구조 위의 전역 색칠 문제**다.
- $|\Pi|$ 항은 없앨 수 없다. 반례: $K_2$ 조각 셋을 삼각형으로 붙이면 $\Gamma=C_6$, $G=K_3$ 이다. $\Pi$ 가 이산 분할일 때 모든 조각의 파생 그래프는 $K_2$ 이므로 $\max_k\chi=2$ 다. $|\Pi|$ 항이 없으면 공식은 2 를 주고, 이것은 틀렸다.
- 퇴화: 조각이 모두 $K_2$ 이면 공식은 $\chi$ 의 정의 그 자체가 된다. 피터슨 그래프를 $K_2$ 조각 15개로 만들면 (nt2.py "(c')", $\Gamma/E_J\cong$ 피터슨 ✓) 식별류가 10개이고, $\min_\Pi$ 는 $B_{10}=115975$ 개의 분할을 훑는다. 이것은 $G$ 를 직접 칠하는 것과 같은 문제다.

따라서 "$\Gamma$ 의 데이터로 결정된다"는 **정보 이론적으로는 참**이다. 하지만 "읽는다" (색칠수 몇 개의 단순한 조합) 는 식별 구조가 단순할 때만 성립한다. 단순한 경우는 단일 접합 (R03 정리 1: $|\Pi|$ 항이 자동으로 흡수됨) 과 나무형 (R04 메시지 전파) 이다. 식별 구조에 사이클이 있으면 조각을 크게 잡아도 전역 문제가 남는다. 이것은 R1 문제의 (R3) 비자명성 요구, 즉 조각 크기에 대한 비용과 직접 연결된다. T1 은 이 점을 결론에서 언급하지 않았다.

### 반박 4 (작은 것). 예 2 의 "차수열이 다르다" 는 약점이 아니다. 더 강한 반례가 있다

T1 은 "차수열까지 맞춘 쌍은 만들지 않았다"고 했다. 다음 두 반례로 이 빈틈을 닫는다.
- **C1 [계산 확인]:** 같은 비표지 조각 $P_2=$ 다이아몬드$(u,a,b,w)+wz$ 에서 접합점만 바꾼다.
  - $(u,z)$ 로 붙이면 다름이 강제되고 $\chi(G)=4$ 다.
  - $(u,w)$ 로 붙이면 같음이 강제되고 $\chi(G)=3$ 이다.

  조각의 모든 불변량이 같다 (같은 그래프이므로). 접합점의 차수는 $(2,1)$ 대 $(2,3)$ 으로 다르다.
- **C2 [계산 확인, 결정적 구성 하나를 찾는 데만 탐색을 씀]:** 부채꼴 $H$ (중심 1, 경로 $2\,3\,4\,0$, 0 에 매달린 점 5) 를 쓴다. 3-색칠은 유일하다: 1 이 색 A 를 받고, 경로가 B, C 를 번갈아 쓴다. 이 사실에서 다음이 연역된다 [증명].
  - 접합점 $(2,4)$: 차수 $(2,3)$, 거리 2. 같은 색이 강제되고 $\chi(G)=3$ 이다.
  - 접합점 $(0,2)$: 차수 $(3,2)$, 거리 2. 다른 색이 강제되고 $\chi(G)=4$ 다.

  조각은 같고, 접합점의 차수 쌍과 거리도 같고, $G$ 는 두 경우 모두 평면이다.
- 따라서 "조각 불변량 + 접합점의 국소 데이터 (차수, 거리, 간선 비트)" 로는 안 된다. 접합점이 조각 안에서 놓인 **전역** 위치 (색칠 상의 위치) 가 필요하다. 프로필이 바로 이 정보다.

## 자기 결론

**조건부 참.** 결론의 큰 틀은 T1 이 맞았다. 그러나 조건이 붙는 자리가 T1 과 다르다.

- **복원은 (W) 없이 참이다** [증명]. (W) 는 조건이 아니다. 정리 2 도 (W) 없이 성립한다 (명제 R1). 진짜 조건은 하나다. $\Gamma$ 를 맨 그래프가 아니라 변 2-색 그래프로 읽어야 한다.
- **$\chi(G)$ 는 조각의 "색칠수 벡터" $(\chi((P_k)_\pi))_\pi$ 와 식별 구조로 결정된다** [증명, 명제 R3]. 이것은 "그래프적 정보 (색칠수)" 라는 문주님 요구를 글자 그대로 만족한다. 조각마다 색칠수 하나로는 안 된다 (반례 C1, C2: 같은 조각, 같은 국소 데이터). 이 벡터는 평면 상대 조각에 대해서도 $q\le4$ 범위에서 줄일 수 없다 (명제 R2). 따라서 T1 의 장애물은 $q=4$ 가 아니라 $q\ge5$ 에 있다.
- **단서.** 식별 구조 쪽의 기여는 단순한 그래프 불변량이 아니라 전역 색칠 문제 ($\min_\Pi$ 와 $|\Pi|$ 항) 다. 식별 구조가 나무이거나 단일 접합이면 이 문제는 국소적으로 풀린다. 사이클이 있으면 일반적으로 $G$ 를 칠하는 것과 같은 난이도다 (피터슨/$K_2$ 퇴화). "읽는다"를 "단순 조합"으로 해석하면, 식별 구조가 나무형인 경우에만 참이다.
- **평면성 절반은 거짓에 가깝다** (굵은 데이터로는 결정되지 않음). 이 부분은 T1 과 같다. 대응하는 "매장 프로필" 정리는 열려 있다.
