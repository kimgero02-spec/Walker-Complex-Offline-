## 요약
1. **정리 A (국소 제약).** $\chi(G)\le q$ 와 "각 조각 $P_k$ 에 $q$-색칠 $c_k$ 가 있고 조각끼리 공유점에서 값이 일치"하는 것이 동치다. 이를 매뉴얼 그래프 $M$ 로 옮기면 $E_{01}$ 은 "같음", $E_{00}\cup E_{11}$ 은 "다름" 제약이 된다 `[증명]`. 실질은 "조각은 자기 색칠 집합 $\mathrm{Col}_q(P_k)$ 만으로 기여하고, 설명서 $M$ 은 어느 점들이 같은 값을 받는지만 적는다"는 읽기 방식이다. 정의를 옮긴 것이므로 새 정리라고 주장하지 않는다.
2. **정리 B (단일 접합의 라벨 프로필).** 모든 조각이 한 접합 $S$ 에서만 만나면 $\chi(G)\le q \iff \bigcap_k \Phi_k(q)\ne\varnothing$ 이고, $\Phi_k(q)=\{c|_S : c\in\mathrm{Col}_q(P_k)\}$ 이다 `[증명]`. $S_q$-불변성으로 R03 정리 1 $\chi(G)=\min_\pi\max_k\chi_\pi(P_k)$ 를 다시 얻는다 `[증명]`.
3. **보조정리 C (축약 = 동일시).** $uv\in E(G)$ 이면 $\chi(G/uv)\le q \iff G-uv$ 에 $c(u)=c(v)$ 인 $q$-색칠이 있다 `[증명]`. 축약은 "다름" 제약을 "같음" 제약으로 바꾼다. 이것으로 명제 7.2 ($\chi(C_4/\{1,4\})=3>2=\chi(C_4)$) 를 설명한다 `[증명]`.
4. **예 검증.** $K_4$, $K_5$, $C_3$, $C_4$, $K_{3,3}$ 의 조각 분해에서 세 식이 모두 참값 $\chi=4,5,3,2,2$ 와 일치한다 `[계산 확인]`. $K_5$ 와 $C_3$ 의 핵심 단계는 손으로도 확인했다 `[증명]`.
5. **한계.** (a) 접합이 여럿이고 사이클을 이루면 정리 A 는 교집합이 아니라 제약 충족 문제로 남는다 (R03 §5 의 홀로노미). (b) 평면성은 $\mathrm{Col}_q(P_k)$ 를 정하지 않는다. 두 평면 조각으로 $\chi=5$ ($K_5$) 가 나오므로 "조각이 평면이면 $\chi\le 4$" 류의 공식은 없다. 따라서 "평면성만으로 읽는 공식"은 얻지 못했다.

## 본문

### 0. 설정과 표기
$G=(V,E)$, 평면분해 $(P_1,\dots,P_n)$, 매뉴얼 그래프 $M=(V_0,V_1,E_{00},E_{01},E_{11})$ (교재 정의 2.1, 2.3). 점 $v\in V$ 의 복사점 모임 $F(v)$, 흰 점 $w_v$ (있을 때). $q\in\mathbb N$ 에 대해
$$\mathrm{Col}_q(P)=\{c:V(P)\to[q] : \{x,y\}\in E(P)\Rightarrow c(x)\ne c(y)\}.$$
$\chi(G)=\min\{q:\mathrm{Col}_q(G)\neq\varnothing\}$ (정의 7.1). 분해 조건 (D2) 에서 $V=\bigcup_k V(P_k)$ 이고 $E=\bigcup_k E(P_k)$ 이다. 따라서 모든 점은 어떤 조각에 있고 모든 변도 어떤 조각에 있다.

### 1. 정리 A (국소 제약 재정식화)
**정리 A.** 임의의 $q$ 에 대해 다음은 동치다.
(i) $\chi(G)\le q$.
(ii) 함수 $f:V\to[q]$ 가 있어 모든 $k$ 에서 $f|_{V(P_k)}\in\mathrm{Col}_q(P_k)$.
(iii) 함수 $\kappa:V_0\sqcup V_1\to[q]$ 가 있어 (a) $x\in F(v)$ 이면 $\kappa(x)=\kappa(w_v)$ (E01 의 같음; $|F(v)|\ge2$ 인 $v$ 만), (b) $\{a,b\}\in E_{00}\cup E_{11}$ 이면 $\kappa(a)\ne\kappa(b)$.

*증명.* (i)⇔(ii): $c$ 가 $G$ 의 $q$-색칠이면 $c|_{V(P_k)}$ 는 $P_k$ 의 변을 모두 적정하게 칠하므로 (ii) 가 성립한다 ($f=c$). 역으로 $f$ 가 (ii) 를 만족하면 $G$ 의 변 $\{x,y\}$ 는 어떤 $P_k$ 의 변이므로 $f(x)\ne f(y)$ 이다. 따라서 $f$ 는 $G$ 의 $q$-색칠이다.

(ii)⇔(iii): (ii)$\Rightarrow$(iii). $f$ 가 주어지면 $\kappa(x):=f(v)$ ($x=(v,k)\in V_0$), $\kappa(w_v):=f(v)$ 로 둔다. (a) 는 정의에서 나온다. (b) 에서 $\{(u,k),(v,k)\}\in E_{00}$ 이면 $\{u,v\}\in E(P_k)$ 이므로 $f(u)\ne f(v)$ 이다. $\{w_v,w_{v'}\}\in E_{11}$ 이면 $\mu(\{v,v'\})\ge2$ 이므로 어떤 $k$ 에서 $\{v,v'\}\in E(P_k)$ 이고 $f(v)\ne f(v')$ 이다. (iii)$\Rightarrow$(ii). $\kappa$ 가 주어지면 명제 2.5(4) 에 의해 $N(w_v)=F(v)$ 이고 (a) 에 의해 $\kappa$ 는 $F(v)$ 위에서 상수이다. 그러므로 $f(v):=\kappa(w_v)$ ($|F(v)|\ge2$) 또는 $f(v):=\kappa((v,k))$ ($F(v)=\{(v,k)\}$) 로 잘 정의된다. 조각 $P_k$ 의 변 $\{u,v\}$ 에 대해 $\{(u,k),(v,k)\}\in E_{00}$ 이고 $f(u)=\kappa((u,k))$, $f(v)=\kappa((v,k))$ 이므로 (b) 에서 $f(u)\ne f(v)$ 이다. $\square$

**해석.** $E_{11}$ 의 제약은 $E_{00}$ 에서 이미 나오므로 중복이다 (정의 2.3 의 $\mu\ge2$ 는 교재의 $A(M)$ 조립이 맞게 되도록 기록하는 장치다). 설명서 $M$ 의 역할은 "$(v,k)$ 들이 같은 값을 받는다" 는 식별 정보만 준다. 색 제약 자체는 조각의 변이 준다.

### 2. 정리 B (단일 접합의 라벨 프로필)
모든 $k$ 와 $l\ne k$ 에 대해 $V(P_k)\cap V(P_l)\subseteq S$ 이고 $S\subseteq V(P_k)$ 라 하자. 라벨 프로필을
$$\Phi_k(q)=\{c|_S : c\in\mathrm{Col}_q(P_k)\}\subseteq[q]^S$$
로 정의한다.

**정리 B.** $\chi(G)\le q \iff \bigcap_{k=1}^n\Phi_k(q)\ne\varnothing$.

*증명.* ($\Rightarrow$) $f$ 가 $G$ 의 $q$-색칠이면 $g:=f|_S$ 는 모든 $k$ 에서 $f|_{V(P_k)}\in\mathrm{Col}_q(P_k)$ 의 제한이므로 $g\in\Phi_k(q)$ 이다.
($\Leftarrow$) $g\in\bigcap_k\Phi_k(q)$ 를 잡고 각 $k$ 에 $c_k\in\mathrm{Col}_q(P_k)$ 를 $c_k|_S=g$ 가 되도록 고른다. 사설 점 $V(P_k)\setminus S$ 는 서로소이다 (가정). 따라서 $f:=g$ (on $S$), $f:=c_k$ (on $V(P_k)\setminus S$) 가 잘 정의되고, $f|_{V(P_k)}=c_k$ 이다. 각 변은 어떤 $P_k$ 의 변이므로 $f$ 는 적정이다. $\square$

**계열 B'.** $\Phi_k(q)$ 는 $S_q$ (색 순열) 작용에 대해 불변이다. $\bigcap_k\Phi_k(q)\ne\varnothing$ 은 어떤 분할 $\pi$ 에 대해 모든 $k$ 에서 $\chi_\pi(P_k)\le q$ 인 것과 동치다. 이유: $g$ 의 핵 분할을 $\pi_g$ 라 하면 $\pi_g$ 가 $\pi$ 이다. 반대로 $\pi$ 가 $\chi_\pi(P_k)\le q$ 를 모든 $k$ 에서 만족하면, 각 $k$ 의 유도 색칠 $c_k$ 의 제한 $g_k=c_k|_S$ 는 핵이 $\pi$ 인 라벨이다. 두 라벨은 블록 사이의 전단사를 $[q]$ 의 순열 $\sigma_k$ 로 늘릴 수 있으므로 $\sigma_k\circ c_k$ 의 제한이 $g_1$ 과 같다. 따라서 $g_1\in\bigcap_k\Phi_k(q)$ 이다. 이 계열과 정리 B 를 합치면 R03 정리 1 $\chi(G)=\min_\pi\max_k\chi_\pi(P_k)$ 가 나온다 `[증명]`. 즉 정리 B 는 R03 정리 1 의 라벨 판이고, 색 교환 논법을 쓰지 않아도 된다.

### 3. 보조정리 C (축약은 동일시를 만든다)
**보조정리 C.** $uv\in E(G)$ 이고 $G/uv$ 는 $u,v$ 를 한 점 $z$ 로 합친 그래프이다 (합쳐서 생긴 중복 변은 하나로 본다). 그러면
$$\chi(G/uv)\le q \iff \exists\,c\in\mathrm{Col}_q(G-uv):\ c(u)=c(v).$$

*증명.* $G/uv$ 의 $q$-색칠 $d$ 에 대해 $c(u):=c(v):=d(z)$, 나머지는 $c=d$ 로 두면 $c\in\mathrm{Col}_q(G-uv)$ 이다. $G-uv$ 의 변 $\{u,x\}$ 나 $\{v,x\}$ 는 $G/uv$ 의 변 $\{z,x\}$ 이므로 $d(z)\ne d(x)$ 이다. 역으로 $c$ 가 주어지면 $d(z):=c(u)=c(v)$ 로 두면 $G/uv$ 의 각 변은 $G-uv$ 의 변에서 오므로 적정이다. $\square$

**결과.** $\chi(G-e)\le\chi(G)$ (부분그래프 단조성). 반면 축약은 $\chi(G/e)\le q$ 를 "$G-e$ 에서 끝점의 색이 같다" 는 제약으로 바꾼다. 이 제약은 $\chi(G)\le q$ 로부터 나오지 않는다.

**명제 7.2 의 설명.** $G=C_4$, $e=\{1,4\}$, $G/e\cong C_3$. $C_4-\{1,4\}$ 는 경로 $1\!-\!2\!-\!3\!-\!4$ 이다. $c(1)=c(4)$ 인 2-색칠은 없다 (경로의 색이 교대하므로 끝점 색이 같으려면 길이가 홀수여야 한다). 3-색칠 $1,2,3,1$ 은 있다. 따라서 $\chi(C_3)=3$ 이고, 이는 보조정리 C 와 일치한다 `[증명]`, `[계산 확인]`. 매뉴얼 언어로는 $C_4/\{1,4\}$ 가 $\{1,4\}$ 를 한 복사점 집합으로 만드는 "식별 $E_{01}$ 추가" 연산이다. 마이너 관계가 $\chi$ 를 옮기지 못하는 이유는 축약이 "다름" 을 "같음" 으로 바꾸기 때문이다.

### 4. 예 검증
모든 행은 정리 A/B 의 조건을 직접 계산한 결과이다. 최소 $q$ 는 $\chi$ 와 같아야 한다.

| $G$ | 조각 분해 (모두 평면) | 접합 $S$ | $\min\{q: \bigcap\Phi_k(q)\ne\varnothing\}$ 또는 정리 A 의 최소 $q$ | $\chi(G)$ |
|---|---|---|---|---|
| $K_4$ | $K_4-uv$ 와 $K_2=uv$ | $\{u,v\}$ | 4 | 4 |
| $K_4$ | 정사각형 두 장 (교재 예 1.3) | $V$ | 4 | 4 |
| $K_5$ | $K_{1,1,3}$ 과 $K_3$ | $\{a,b,c\}$ | 5 | 5 |
| $K_5$ | 오각형 두 장 (교재 예 1.5) | $V$ | 5 | 5 |
| $C_3$ | 경로 $1\!-\!2\!-\!3$ 과 변 $\{1,3\}$ | $\{1,3\}$ | 3 | 3 |
| $C_4$ | 경로 $1\!-\!2\!-\!3$ 과 경로 $3\!-\!4\!-\!1$ | $\{1,3\}$ | 2 | 2 |
| $K_{3,3}$ | $C_6$ 과 변 세 개 (각각 평면) | $V$ | 2 | 2 |

`[계산 확인]` (`r07_run.py`). 손 계산 `[증명]`:
- $K_4=(K_4-uv)\cup\{uv\}$: $\mathrm{Col}_3(K_4-uv)$ 에서 $x,y$ 는 두 색을 쓰고 $u,v$ 는 남은 한 색을 쓴다. 그래서 $\Phi_1(3)=\{(a,a)\}$ 이고 $\Phi_2(3)=\{(a,b):a\ne b\}$ 이므로 교집합이 비어 $\chi\ge4$ 이다. $q=4$ 에서는 $\Phi_1(4)\ni(1,2)$ 이므로 $\chi=4$.
- $K_5=K_{1,1,3}\cup K_3$ (접합 $\{a,b,c\}$): $\Phi_2(q)$ 는 서로 다른 세 색의 조합이고, $\Phi_1(q)$ 에서 $d,e$ 가 두 색을 쓰면 $a,b,c$ 는 나머지 $q-2$ 색 안에 있어야 한다. 따라서 $q=4$ 에서 $a,b,c$ 가 서로 다를 수 없어 교집합이 비고, $q=5$ 에서 $\chi=5$.
- $C_3$ 과 $C_4$: 위 표와 같다. $C_4$ 의 두 경로 조각은 $q=2$ 에서 $\Phi=\{(a,a)\}$ 로 같아진다.

### 5. 판정: 조각 평면성으로 읽을 수 있는가 (기준 (c))
- **읽는 법.** 설명서 $M$ 에서 $E_{01}$ 은 식별 (같은 값), $E_{00}\cup E_{11}$ 은 다름 (간선) 이다. 조각 $P_k$ 의 기여는 $\mathrm{Col}_q(P_k)$ (또는 그 접합 제한 $\Phi_k(q)$) 하나이다. 따라서 $\chi(G)$ 는 조각별 기여의 교집합이 비지 않는 가장 작은 $q$ 로 읽힌다. 이것은 조각 데이터와 $M$ 만으로 계산된다.
- **평면성은 들어가지 않는다.** $K_4$ 는 평면 조각 두 장으로 $\chi=4$, $K_5$ 는 평면 조각 두 장으로 $\chi=5$ 이다. 평면 조각은 4-색칠이 가능하다는 것 `[기억-미검증: 4색 정리]` 말고는 $\chi(G)$ 에 상한을 주지 않는다. 조각이 평면이라는 정보는 $\mathrm{Col}_q(P_k)$ 의 크기나 모양을 정하지 않는다.

### 6. 장애물
1. **다중 접합과 홀로노미.** 정리 A 는 $f$ 를 전역으로 찾는다. 정리 B 의 $S_q$-불변성 논법은 접합 하나에서만 색을 정렬할 수 있다. 접합들이 사이클을 이루면 색 순열들의 곱이 항등이 아닐 수 있다. 예: 조각 $K_2$ 다섯 개 $\{i,i+1\}$ ($i\in\mathbb Z_5$) 로 $C_5$ 를 만들면 각 조각은 2-색칠이 가능하지만 $\chi(C_5)=3$ 이다 `[증명]`. 이것은 R03 §5 와 같은 장애물이다.
2. **크기.** $\Phi_k(q)\subseteq[q]^S$ 의 원소 수는 $S$ 가 커지면 지수적이다. 정리 B 는 계산 공식이지 빠른 계산이 아니다.
3. **평면성 미사용.** 위 §5 의 이유로, 조각 평면성은 정리 A/B 에 쓰이지 않는다. 평면 조각의 $\Phi_k(q)$ 가 외곽면 위에서 특별한 모양을 갖는지는 증명하지 못했다.
4. **마이너 단조성.** 보조정리 C 가 설명하듯 마이너 연산 중 축약은 다름 제약을 같음 제약으로 바꾼다. 어떤 축약이 $\chi$ 를 보존하는지는 판정하지 못했다.

## 후속연구 지점
1. **(최우선) 한 고리 접합의 라벨 판정.** 무엇: $M$ 의 접합들이 $C_m$ 을 이룰 때 ($H$ 가 한 사이클) 정리 A 의 제약 충족 문제를 접합 관계 행렬들의 곱으로 바꾸어 $\chi(G)\le q$ 를 판정하는 틀. 왜: $C_5$ 예가 보이듯 사이클이 정리 B 가 못 다루는 최소 장애물이다. 시작법: 접합 $S_i$ 마다 $\Phi_{k}(q)$ 로 $[q]^{S_i}\times[q]^{S_{i+1}}$ 의 관계 행렬 $R_i$ 를 만들고, $\chi\le q$ 가 $\mathrm{tr}$ 이나 항등 원소 포함 여부와 같은지 확인한다. 난점: 관계 합성은 군이 아니어서 R03 의 색 교환 논법이 그대로 통하지 않는다.
2. **평면 조각의 경계 프로필.** 무엇: 평면 조각 $P$ 의 외곽 사이클 위의 색칠 프로필 $\Phi_P(q)$ 가 외곽 길이만으로 결정되는 조건을 찾는다. 왜: 정리 B 의 $\Phi_k$ 를 평면성으로 줄이려면 이 방향이 필요하다. 시작법: 3-연결 평면 조각에서 외곽 사이클 위 색칠 제한을 Kempe 체인과 연결해 보고, $K_4$ 와 $K_5$ 의 예 (§4) 로 검증한다. 난점: 4색 정리 수준의 깊이가 필요할 수 있다 `[추측]`.
3. **클릭 조건의 라벨판.** 무엇: R03 정리 5 (접합이 모든 조각에서 클릭이면 $\chi=\max\chi(P_k)$) 를 정리 B 의 프로필로 옮기고, 접합의 색 개수 $s$ 에 대한 평면 판을 찾는다. 왜: §4 의 $K_5$ 손 계산이 $s=3$ 에서 일반화되는지 궁금하다. 시작법: $\Phi_k(q)$ 가 "접합 쌍이 모두 다른 색" 을 강제하는지 조사하고, $s=4$ 에서 평면 조각으로 $\chi=7$ 이 가능한지 확인. 난점: R03 후속 3 과 같다.
4. **식별 보존 축약.** 무엇: 보조정리 C 를 이용해 어떤 마이너 연산이 $\chi$ 를 보존하는지, 또는 $\chi$ 가 $\Phi$ 의 포함 관계로 단조인 마이너 부분 관계가 있는지 찾는다. 왜: 명제 7.2 가 보인 비단조성의 정확한 경계를 알면 조각 기반 재정식화가 마이너 언어와 어디서 갈리는지 알 수 있다. 시작법: 축약 $e=uv$ 가 $\Phi$ 를 줄이는 조건 ($c(u)=c(v)$ 가 모든 최적 색칠에서 불가능한 경우) 을 증명. 난점: 전역 최적 색칠 개념이 필요하다.
5. **문헌 대조 (기억-미검증).** "=/≠ 강제 장치" 와 Hajós 류 구성, 조각 기반 색칠 분해 (perfect graph 의 분해, 2-합에 대한 색칠수 공식) 가 이미 알려져 있는지 확인이 필요하다. 인터넷이 막혀 있어 확인하지 못했다. 신규성은 주장하지 않는다.
