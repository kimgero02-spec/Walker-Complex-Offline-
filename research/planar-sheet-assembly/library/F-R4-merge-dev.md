# [F-R4-merge-dev] 나 ($\mathfrak A$) 는 다 ($\mathfrak B$) 의 특수한 경우다 (경계 표시가 빈 경우). 다는 나의 특수한 경우가 아니지만, 다가 더하는 경계 표시는 $G$·색칠수·마이너에 아무 정보도 더하지 않고, 평면성 읽기에서는 "허용되는 표시가 존재한다" 로만 쓰인다

연구원 (포메이션 F 라운드 4). 정의 표기는 재지시를 따른다. **가** = 리본 설명서 $H$, **나** = 접합 그래프 $\mathfrak A$, **다** = 병합 설명서 $\mathfrak B$.
읽은 것: `F-R3-researcher1.md`, `F-R3-researcher2.md`, `F-R3-merge-dev.md` (내 것). 가 의 사상 없는 형태를 확인하려고 `F-R1-researcher2.md` §1 과 `F-R2-researcher2.md` 앞부분도 읽었다.
"함의된다" 는 재지시대로 "한 정의가 다른 정의의 스페셜 케이스다" 로 읽는다. 다의 정의는 F-R2 의 정의 M′/R′ 이다. 곧 $\mathfrak B=(\mathfrak A,\ \partial)$ 이고, $\partial$ 는 검정 간선 일부에 붙인 경계 표시다. 흰–흰 간선은 데이터가 아니라 유도되는 기호다.

## 요약
1. **나 ⊂ 다** [증명]. 접합 그래프 $\mathfrak A$ 는 경계 표시가 빈 병합 설명서 $(\mathfrak A,\emptyset)$ 다. 조립과 정리 A 의 읽기는 그대로 같다.
   - 단서: 다의 (M1) 이 조각의 평면성을 요구한다. 그래서 정확한 포함은 "평면 조각 접합 그래프 ⊂ 다" 다.

2. **다 ⊄ 나** [증명: 예]. 다는 나에 경계 표시를 더한 것이다. 같은 $\mathfrak A$ 에 서로 다른 허용 표시 둘이 붙는 예가 있다 (§2.2).
   - 다만 표시는 $G$, $\chi(G)$, $P(G,q)$, $G$ 의 마이너 어느 것에도 정보를 더하지 않는다 [증명].

   - 다각형 조각과, 포트가 셋 이상인 3-연결 조각에서는 표시가 $\mathfrak A$ 에서 유일하게 정해진다 [증명].
   - 그러므로 다는 나의 **보존적 확장** 이다. 정보로는 "나 + 유한 선택" 이다.
3. **가 ⊂ 다** [증명, F-R1 명제 M0]. 리본 설명서는 리본 층 조건을 만족하는 병합 설명서와 일대일로 대응한다.
   - 가가 나에 들어가는 것은 경계 표시를 잊는 망각 $U$ 를 통해서뿐이다. 가 ⊂ 나 는 스페셜 케이스로는 성립하지 않는다.
4. **F-R3 결과들의 자리** [증명: 정의 비교]. F-R3 의 마이너 결과는 모두 나 의 데이터만 쓰므로 다 안에서도 그대로 성립한다.
   - 연구원1 M1·M4 와 연구원2 명제 1.3: 별 모양 마이너 모형, 별 존중 모형.

## 1. 나 ⊂ 다

**명제 4.1** [증명]. 평면 조각 접합 그래프 $\mathfrak A$ 에 대해 $(\mathfrak A,\emptyset)$ 은 F-R2 정의 M′ 의 병합 설명서이고, 다음이 성립한다.
$$G(\mathfrak A,\emptyset)=G(\mathfrak A).$$

*증명.*
- 조건 대조. 나의 사상 없는 특징화 (F-R3 연구원2 명제 1.1) 는 세 조건이다. (a) 흰 점은 독립, (b) 흰 점끼리 이웃 서로소, (c) 흰 점 차수 $\ge2$.
  - (a) 는 정의 M′ 에 흰–흰 간선이 데이터로 없다는 것과 같다.
  - (b)(c) 는 정의 M 의 (M2) 와 같다.
  - (M1) 의 "조각은 단순 평면" 은 나 쪽에서는 문제의 가정이다.
  - 경계 표시는 정의 M′ 에서 선택이므로 비워도 된다.
- 조립. 정의 M′ 의 조립은 $\operatorname{simp}(\mathfrak A/\text{흰 별})$ 이고, 나의 조립 $\mathfrak A/\text{흰 별}$ 과 겹친 간선만 다르다.
- 이로써 $\chi$, $P(G,q)$, 평면성, 마이너는 모두 같다. 고리는 둘 다 남기므로 고리 판정도 같다. $\square$

**따름.**
- 나에서 증명된 정리는 모두 다의 일반 층에서 성립한다 [증명: 명제 4.1].
  - 정리 A (색칠수 수열).
  - 정리 I.
  - F-R3 연구원1 의 M1, M4, 따름 M4a.
  - F-R3 연구원2 의 명제 1.1–1.3, 정리 S, 정리 M, 정리 W5.
- 정리 W5 는 기억-미검증 인용에 기댄다. 이 경우 "성립" 은 그 인용의 상태를 그대로 물려받는다는 뜻이다.

**평면성 단서.** 연구원1 의 정리 M2 와 명제 M2′ 은 비평면 조각을 갖는 접합 그래프를 쓴다 ($X=K_5$ 이면 조각 $C=K_5$). 다의 (M1) 을 그대로 두면 이 접합 그래프는 다에 들지 않는다.
- 제안: 다의 (M1) 을 "조각은 단순 그래프" 로 줄이고, "조각이 평면" 은 대상 문제의 가정으로 따로 둔다.
- 다의 증명 가운데 조각의 평면성을 쓰는 곳은 리본 층의 (R1) (원판 조각) 과, 정리 A(4) 의 결손 상한 $d(0)\le3$ 뿐이다 [증명: F-R1–F-R3 의 증명 점검].
- 따라서 이 변경은 어떤 결과도 깨지 않는다. 고친 뒤에는 **나 (일반) ⊂ 다 (일반)** 가 표시 없는 경우로 정확히 성립한다.

## 2. 다 ⊄ 나, 그러나 보존적 확장

### 2.1 다가 더하는 것은 경계 표시뿐이다
F-R2 명제 D1 에 의해, 리본 층의 흰–흰 간선 (호) 은 $(\mathfrak A,\partial)$ 에서 유도된다 [증명]. 그러므로 다와 나의 차이는 $\partial$ 하나다. 망각 $U(\mathfrak A,\partial)=\mathfrak A$ 에 대해 다음이 성립한다.
$$G(\mathfrak B)=\operatorname{simp}G(U\mathfrak B)$$
따라서 $\chi$, $P(\cdot,q)$, 그리고 모든 마이너 관계 ($F\preceq G$) 는 $U\mathfrak B$ 만의 함수다 [증명: F-R1 정리 M1, 따름정리 M2. 마이너는 겹친 간선에 무관].

### 2.2 같은 나 위의 서로 다른 허용 표시 (다가 나의 특수한 경우가 아닌 이유)
**예 4.2** [증명: 손 확인].
- 조각 $P_1$ 은 육각형 $1\,2\,3\,4\,5\,6$ 에 현 $14$ 를 더한 것이다. 2-연결 평면이고, 면은 $1234$, $1456$, $123456$ 이다.
- 조각 $P_2$ 는 정사각형 $1'\,4'\,x\,y$ 다.
- 류는 $\{1,1'\}$ 과 $\{4,4'\}$ 이고, 호는 간선 $14$ 하나다.
- 허용 표시 (R1) 로 $C_1=1234$ 와 $C_1'=1456$ 이 둘 다 가능하다. 둘 다 어떤 매장에서 바깥면이 되고, 호 간선 $14$ 를 품으며, (R2′)–(R5) 를 만족한다.
- 바깥 육각형 $123456$ 은 간선 $14$ 를 품지 않으므로 허용되지 않는다.
- 그러므로 $(\mathfrak A,C_1)\ne(\mathfrak A,C_1')$ 은 같은 나를 갖는 서로 다른 다이고, 다는 나의 특수한 경우가 아니다. $\square$
- 두 다의 $G$ 는 같다. 7점 9변, 평면 [증명: 같은 $\mathfrak A$].

### 2.3 그럼에도 평면성 판정은 표시와 무관하다
**명제 4.3** [증명]. 정리 D (F-R2 정리 U), 정리 E (R2-A), 정리 Mix (F-R3 §2) 는 각각 "가정을 만족하는 리본 표시 $\partial$ 하나" 에 대해 $G$ 의 평면성과 표시에서 계산한 값의 동치를 말한다. $G$ 는 $\partial$ 와 무관하다 (§2.1). 그러므로 같은 $\mathfrak A$ 위의 허용 표시 $\partial,\partial'$ 가 모두 가정을 만족하면, 두 표시가 주는 판정값은 같다.
따라서 이렇게 정의하면 잘 정의된다.
$$\text{판정}(\mathfrak A):=\text{판정}(\mathfrak A,\partial),\quad\partial\text{ 는 허용 표시 아무것}.$$
"허용 표시가 존재하는가" 와 "그중 하나 찾기" 는 유한 검사다. 조각마다 후보 사이클이 유한하기 때문이다 [증명]. $\square$

**명제 4.4 (표시가 유일한 경우)** [증명].
1. **다각형 조각.** $P_k$ 가 사이클이면 $C_k=P_k$ 다.
2. **3-연결 조각, 포트가 3개 이상.**
   - (R2′) 에 의해 포트는 모두 $C_k$ 위에 있다.
   - R02 보조정리 F [증명, R02 오케 검증] 에 의해 서로 다른 두 면은 많아야 두 점을 공유한다.
   - 그러므로 포트 셋 이상을 모두 품는 면은 많아야 하나다.
   - 3-연결 평면 그래프의 면 집합은 매장과 무관하다 [기억-미검증: Whitney 유일성]. 그러므로 $C_k$ 는 $\mathfrak A$ 에서 유일하게 정해진다.
   - Whitney 를 쓰지 않으려면 이렇게 할 수 있다. R02 보조정리 P 에 의해 허용되는 $C_k$ 는 모든 매장에서 면이다. 두 허용 사이클 $C,C'$ 가 같은 매장의 서로 다른 두 면이면, 보조정리 F 에 의해 포트 셋을 함께 품을 수 없다. 이 논법으로도 유일성이 나온다 [증명].
3. **3-연결 조각, 포트 2개 (호 하나가 간선 하나).** 간선 $xy$ 를 품는 면은 둘이므로 표시는 두 가지다. 명제 4.3 에 의해 판정에는 영향이 없다.
4. **일반 2-연결 조각.** 예 4.2 처럼 표시가 여러 개일 수 있다.

**결론 (다와 나의 관계).**
- 다 = 나 + 경계 표시이고, 다는 나의 보존적 확장이다.
- 지금 있는 모든 읽기 (색칠수, 마이너, 정리 D·E·Mix 의 평면성) 는 나 의 함수다. 평면성에서는 허용 표시의 존재 조건과 함께다.
- 표시는 정의 쪽 편의다. 아직 판정이 없는 일반 2-연결 조각에 대해, 앞으로의 판정이 표시마다 다른 답을 주지 않는지는 열려 있다. 판정이 참인 정리라면 표시와 무관할 수밖에 없지만, "표시에 의존하는 읽기 규칙" 을 만들면 어긋날 수 있다 [추측: 문제 없음].

## 3. 가와의 관계 (덧붙임)
- **가 ⊂ 다** [증명, F-R1 명제 M0(1)(2)]. 리본 설명서 (F-R1 연구원2 명제 1.1 의 사상 없는 형태: 부분경로 둘 + 부호 하나) 는 리본 층 조건을 만족하는 다 와 일대일로 대응한다. 가의 $(H,\rho,[\varepsilon])$ 는 다에서 계산된다 (F-R2 명제 M3).
- **가 ⊄ 나** [증명: 예 4.2 와 같은 논법]. 가는 경계 사이클과 호 선택을 데이터로 갖는다. 리본 설명서 $H$ 를 쓰는 방식이 여럿이라는 점은 F-R1 연구원2 의 호 쪼개기 보조정리 1.3 이 보였다. 그래서 가는 나의 특수한 경우가 아니라, 망각 $U$ 로 나에 사상된다.
- **층의 만남** [증명, F-R3 연구원2 정리 S 와 그 리본 문단].
  - 다각형 조각이면 가의 골격 $T$ 는 나의 칸 오므림 $\Sigma(\mathfrak A)$ 와 위상동형이다.
  - 3-연결 리본 조각이면 $\mathfrak A\subset X$ 다.
  - 즉 다 안에서 가 층의 평면성 도구가 나 층의 마이너 샌드위치 $\Sigma\le G\le\mathfrak A$ 의 양 끝 등호로 나타난다.

**F-R3 마이너 결과의 정합** [증명: 비교].
- 내 F-R3 명제 M1 은 연구원1 M1, 연구원2 명제 1.2 와 같다.
- 내 명제 M3 ($K_n$ 특수 경우) 은 연구원2 의 정리 M 과 결론이 같다. 차이는 연구원2 의 장애 문단 "(e) 를 조립 ⊆ $G$ 로 강하게 할 수 없다" 에 있다.
  - 그 장애는 조건 (Int) 아래에서 나온다.
  - 내 구성은 (Int) 대신 접합 배정 $\sigma$ (S1)(S2) 를 쓴다. 포트 $u_j$ 를 가지 나무 $T_j$ 안에 두고 $\sigma$ 로 $j$ 에 배정한다.
  - 그래서 세분 없이 $G(\mathfrak B)=G$ 를 얻는다. 두 결과는 모순되지 않는다. (Int) 은 $\sigma$ 의 특수한 경우 (모든 배정이 허용되는 핵 조건, 내 따름 M2′) 다.
- 연구원1 의 정리 M4 (별 존중 모형) 는 내 명제 M2 의 역방향을 일반화한 것이다. 내 $S$-모델의 $B_k^\sigma$ 는 조각 단위의 별 존중 모형이다.

   - 이유: 일반 2-연결 조각의 평면성 판정 (F-R2 연구원2 정리 F3·F4, 내 F-R3 후속 3) 이 표시에 의존하는 규칙으로 쓰이면 정의가 갈린다.
   - 시작 방법: 예 4.2 에서 두 표시의 $W$, $I$, 다리 분할을 각각 계산해, 판정 규칙이 같은 답을 주는지 손으로 본다.
   - 난점: 표시마다 $b$ 가 달라질 수 있다.
3. **(우선 3) 다 의 표시를 나 의 순수 그래프 조건으로 바꾸기.**
   - 이유: 명제 4.4 에 의해 대부분의 경우 표시가 유도된다. 모든 경우에 "허용 표시가 존재" 를 $\mathfrak A$ 의 조건으로 쓰면 다를 나의 부분 모임 (리본 접합 그래프) 으로 정의할 수 있다. 그러면 다 ⊂ 나 의 정보판이 된다.
   - 시작 방법: "$P_k$ 에 포트와 호 간선을 모두 품는 면 사이클이 있다" 를 원뿔 판정 (F-R1 충돌 11 의 [추측]) 과 함께 증명한다.
   - 난점: 2-연결 조각에서 원뿔 판정의 역방향.
4. **(우선 4) 가 층과 나 층의 등호 조건 일반화.** 연구원2 의 후속 1 ("다각형판에서 $\mathfrak A$ 평면 $\iff G$ 평면?") 과 내 정리 Mix 를 비교한다. 정리 Mix 의 "강체 경계가 면" 조건이 $\mathfrak A$ 의 평면성과 어떤 관계인지 본다 (뫼비우스 정사각형 2장: $\mathfrak A$ 비평면, $G$ 평면, 강체 없음).
