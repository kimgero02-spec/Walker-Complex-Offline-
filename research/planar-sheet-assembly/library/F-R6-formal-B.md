## 요약

1. **두 정의를 튜플로 고정했다.** $\mathfrak A=(V_\bullet,V_\circ,E_{\bullet\bullet},E_{\bullet\circ})$ 이고, $\mathfrak B=(V_\bullet,V_\circ,E_{\bullet\bullet},E_{\bullet\circ},E_{\circ\circ},\partial)$ 다. 미결정 선택은 매개변수로 남겼다. 조각 평면성은 $\alpha\in\{\mathrm{on},\mathrm{off}\}$, 흰–흰 간선은 $\beta\in\{\beta_1,\beta_2,\beta_3\}$ (일관 저장, 자유 저장, 유도). 리본 층에만 쓰는 선택은 $\pi$ (핀치 허용 여부), $\kappa$ (닫힌 호 허용 여부)로 따로 남겼다.
2. **발견 A: $\alpha$ 는 실현 가능한 $G$ 의 집합을 바꾸지 않는다** [증명]. 모든 단순 그래프 $G$ 는 조각을 $K_2$ 로 두는 $\mathfrak A$ 로 실현되고, 이 $K_2$ 조각들은 평면이다. $\alpha$ 가 바꾸는 것은 조각의 구조를 쓰는 정리 (F-R5 의 실현 정리 M2, 정리 W5) 뿐이다.
3. **발견 B: $\beta$ 는 $G(\mathfrak B)$ 와 색칠 읽기를 바꾸지 않는다** [증명]. 리본 층의 호 분해는 $\beta_2$ 에서만 모호해진다.
4. **발견 C: F-R2 의 (R4′) "링크는 경로" 는 길이 3 이상의 호의 내부점과 충돌한다** [증명]. F-R2 본문도 §2.2 ("같은 표지는 하나로 친다") 와 §2.3 (다중 링크로 읽는다) 이 서로 다르다. 수정안은 §3.5 의 (R4) 다.
5. **발견 D: F-R1 의 $\chi(X)=|V(H)|-|E(H)|$ 는 내부 핀치가 있으면 깨진다** [계산 확인]. E3 에서 세포 복합체의 $\chi$ 는 $0$ 인데 공식은 $-1$ 을 준다. 핀치가 없을 때만 증명 스케치가 된다 [증명 스케치].
6. **나 ⊆ 다** 는 §6 에 진술했다. $\mathcal A_\alpha\hookrightarrow\mathcal B_{\alpha,\beta}$ 는 단사이고 $U\circ\iota=\mathrm{id}$, $G\circ\iota=G$ 를 만족한다. 포함은 진부분집합이다. 증명은 하지 않았다.

## 0. 기호와 공통 규약

- $V_\bullet$ 검정 점, $V_\circ$ 흰 점. 검정–흰 간선은 "포트 관계" $x\in\alpha(w)$ 로 쓴다. 곧 $\alpha(w):=\{x\in V_\bullet : xw\in E_{\bullet\circ}\}$ 다 (F-R1 의 $\alpha$ 와 같다).
- 류 $p,q$ 는 류 (§2) 의 원소를 가리킨다. 색인 $\alpha$ 는 포트 함수 에만 쓴다 (F-R2-researcher1 은 $\alpha$ 를 류의 이름으로도 써서 충돌한다, 형식 검토 F13).
- 규약 S (단순): 두 설명서 모두 단순 그래프다. 곧 $E_{\bullet\bullet}\subseteq\binom{V_\bullet}{2}$ 등 [증명: 표기 규약].
- 규약 C (조각): 조각 $P_k$ 는 $(V_\bullet,E_{\bullet\bullet})$ 의 연결성분이다. F-R1 정규화 보조정리 (b) 와 같다 [증명: 정규화 보조정리 (b) 인용]. 문제 진술의 "조각 $P_1,\dots,P_n$" 과 개수가 다를 수 있다 (형식 검토 F10).

## 2. 나 $\mathfrak A$ (접합 그래프)

**정의 𝔄.** $\mathfrak A=(V_\bullet,V_\circ,E_{\bullet\bullet},E_{\bullet\circ})$. 여기서 $E_{\bullet\bullet}\subseteq\binom{V_\bullet}{2}$, $E_{\bullet\circ}\subseteq V_\bullet\times V_\circ$, $V_\bullet\cap V_\circ=\emptyset$ 다. 흰–흰 간선은 없다. 조건은 다음이다.

- (J1) 모든 $w\in V_\circ$ 에 대해 $|\alpha(w)|\ge2$. [증명: F-R1 (J1) 에서 "이웃은 모두 검정" 은 $E_{\bullet\circ}$ 의 정의로 자동]
- (J2) 모든 $x\in V_\bullet$ 에 대해 $|\{w\in V_\circ:x\in\alpha(w)\}|\le1$. 곧 포트 집합 $\alpha(w)$ 들은 서로소다. [증명: F-R1 (J2)]
- (J3$_\alpha$) $\alpha=\mathrm{on}$ 이면 $\mathfrak A[V_\bullet]=(V_\bullet,E_{\bullet\bullet})$ 의 모든 연결성분이 평면이다. $\alpha=\mathrm{off}$ 이면 조건이 없다. [증명: F-R1 (J3)]
- (J4) $x,y\in\alpha(w)$ 이면 $xy\notin E_{\bullet\bullet}$. 곧 고리가 없다. [증명: F-R1 (J4), 𝔄 에만 요구]

$\mathcal A_\alpha:=\{\mathfrak A:\ \text{(J1),(J2),(J3}_\alpha\text{),(J4)}\}$.

**류.** $\Pi(\mathfrak A):=\{\alpha(w):w\in V_\circ\}\ \cup\ \{\{x\}:\ x\in V_\bullet\setminus\bigcup_w\alpha(w)\}$. (J2) 에 의해 $\Pi$ 는 $V_\bullet$ 의 분할이다. 각 $x$ 의 류를 $[x]$ 로 쓴다. [증명]

**흰 별 축약 (Ĝ).** 흰 점 $w$ 의 별 $S_w$ 는 $w$ 와 $\alpha(w)$ 를 잇는 변들이다. (J2) 에 의해 별들은 서로소다. 별을 각각 축약하면 $w$ 와 $\alpha(w)$ 가 한 점 $[w]$ 가 되고, 나머지 검정–검정 변 $xy$ 는 $[x][y]$ 가 된다. 곧

$$\widehat G(\mathfrak A):=\mathfrak A/\{S_w\}\quad\text{는 정점 }\Pi,\ \text{변 }\{[x],[y]\}\ (xy\in E_{\bullet\bullet})\text{ 인 다중그래프.}$$

$G(\mathfrak A):=\operatorname{simp}\widehat G(\mathfrak A)$ 는 정점 $\Pi$, 변 $\{[x],[y]\}$ ($xy\in E_{\bullet\bullet}$, $[x]\neq[y]$) 인 단순 그래프다. 고리 $[x]$ (단 $[x]=[y]$, $xy\in E_{\bullet\bullet}$) 는 (J4) 때문에 없다. [증명: 축약의 정의]

**𝔄^{(t)} (색칠 읽기용).** 정점 $V_\bullet\sqcup\bigsqcup_{w\in V_\circ}K^w$ 이고 $|K^w|=t$ 다. 변은 $E_{\bullet\bullet}$, 각 $K^w$ 안의 모든 쌍, 그리고 $K^w\times\alpha(w)$ 다. 흰 점 $w$ 자체는 제거한다. [증명: 제거 규약은 $a_0=\chi(\bigsqcup P_k)$ 와 맞는다. F-R1 은 "흰 점마다 $K_t$ 를 넣는다" 고만 썼다. 형식 검토 F12 참조]

$a_t(\mathfrak A):=\chi(\mathfrak A^{(t)})$ 로 두면 $a_0=\max_k\chi(P_k)$ 다 [증명].

## 3. 다 $\mathfrak B$ (병합 설명서)

### 3.1 튜플

$$\mathfrak B=(V_\bullet,\ V_\circ,\ E_{\bullet\bullet},\ E_{\bullet\circ},\ E_{\circ\circ},\ \partial),$$

- $E_{\bullet\bullet}\subseteq\binom{V_\bullet}{2}$, $E_{\bullet\circ}\subseteq V_\bullet\times V_\circ$, $E_{\circ\circ}\subseteq\binom{V_\circ}{2}$ (흰–흰 간선, 매개변수 $\beta$ 에 따라 데이터이거나 유도), $\partial\subseteq E_{\bullet\bullet}$ (경계 표시).
- 포트, 류, 조각, $\widehat G$, $G$ 는 §2 와 같다.
- 조건 (M2): 모든 $w$ 에 $|\alpha(w)|\ge2$, $\alpha(w)$ 들은 서로소. [증명: (J1)+(J2) 와 같다. (J4) 는 빠진다]
- 고리는 허용한다. 고리가 있으면 $\chi=\infty$ 다 (형식 검토 F1).
- $U\mathfrak B:=(V_\bullet,V_\circ,E_{\bullet\bullet},E_{\bullet\circ})$ 는 흰–흰 간선과 $\partial$ 를 지운 것이다. $U\mathfrak B$ 가 §2 의 $\mathfrak A$ 꼴이다 (단 (J3),(J4) 는 조건으로 따로 본다). [증명]

### 3.2 매개변수 $\alpha$ (조각 평면성, M1)

- $\mathrm{(M1)}_{\mathrm{on}}$: 각 조각 $P_k$ 가 평면이다.
- $\mathrm{(M1)}_{\mathrm{off}}$: 조건 없음.
- 두 경우 모두 조각은 단순 그래프다 ($E_{\bullet\bullet}$ 가 $\binom{V_\bullet}{2}$ 의 부분집합이므로). [증명]
- 리본 층 (R1) 은 $P_k$ 가 평면임을 함의한다. 그래서 리본 판에서는 $\alpha$ 가 무의미하다 (§3.5 의 주석). [증명: (R1) 의 "$C_k$ 가 평면 매장의 바깥면 경계" 에서 바로]

### 3.3 매개변수 $\beta$ (흰–흰 간선, M3)

쌍 조각 집합을 다음으로 둔다.

$$D_{ww'}:=\bigl\{k:\ \exists\,x\in\alpha(w)\cap V(P_k),\ x'\in\alpha(w')\cap V(P_k),\ xx'\in E(P_k)\bigr\},\qquad \mathcal D(\mathfrak B):=\{ww'\in\tbinom{V_\circ}{2}: |D_{ww'}|\ge2\}.$$

$\mathcal D(\mathfrak B)$ 는 $E_{\bullet\bullet}$ 와 $E_{\bullet\circ}$ 만으로 정해진다. 흰–흰 간선 조건은 다음이다.

- (M3) 모든 $ww'\in E_{\circ\circ}$ 에 대해 $|D_{ww'}|\ge2$.

$\beta$ 의 세 선택.

- $\beta_1$ (데이터, 일관): $E_{\circ\circ}=\mathcal D(\mathfrak B)$. 흰–흰 간선을 저장하되 유도 값과 일치하도록 요구한다.
- $\beta_2$ (데이터, 자유): $E_{\circ\circ}\subseteq\mathcal D(\mathfrak B)$ 는 임의다 (M3 만 요구).
- $\beta_3$ (유도): $E_{\circ\circ}$ 를 저장하지 않는다. 필요할 때 $\mathcal D(\mathfrak B)$ 를 쓴다. 이때 $\mathfrak B=(V_\bullet,V_\circ,E_{\bullet\bullet},E_{\bullet\circ},\partial)$ 로 줄어든다.

**보조정리 G1 (흰–흰 간선은 $G$ 를 바꾸지 않는다).** (M3) 아래에서 $G(\mathfrak B)=G(U\mathfrak B)$ 다. [증명] $ww'\in E_{\circ\circ}$ 의 상 $\{[w],[w']\}$ 는 $|D_{ww'}|\ge2$ 이므로 어떤 조각 $k$ 의 간선 $xx'$ ($x\in\alpha(w)$, $x'\in\alpha(w')$) 의 상으로 이미 $\widehat G$ 의 변이다. 따라서 $\operatorname{simp}$ 가 그것을 지운다.

**주석 (리본 판에서 $\beta_2$ 의 쓰임).** 리본 층의 호는 $\mathcal D$ 로 정의된다 (§3.5). 그러므로 $\beta_2$ 에서 $E_{\circ\circ}\subsetneq\mathcal D$ 이면 "호" 가 데이터에 따라 달라진다. 리본 판에서는 $\beta_2$ 를 쓰려면 $E_{\circ\circ}=\mathcal D$ 를 추가로 요구해야 하고, 그러면 $\beta_1$ 과 같아진다. [증명]

### 3.4 조립 $G(\mathfrak B)$

$$G(\mathfrak B):=\operatorname{simp}\bigl(\mathfrak B/\{S_w\}\bigr).$$

명시적으로 쓰면 다음과 같다. 정점 집합은 $\Pi(\mathfrak B)$ (§2 와 같은 류), 변 집합은

$$E\bigl(G(\mathfrak B)\bigr)=\bigl\{\{[x],[y]\}:\ xy\in E_{\bullet\bullet},\ [x]\neq[y]\bigr\}\ \cup\ \bigl\{\{[w],[w']\}:\ ww'\in E_{\circ\circ}\bigr\}.$$

두 번째 집합은 보조정리 G1 에 의해 첫째 집합에 들어 있다. 고리 $[x]$ (단 $[x]=[y]$, $xy\in E_{\bullet\bullet}$) 가 있으면 $\chi(G(\mathfrak B))=\infty$ 로 둔다. [증명]

**색칠 읽기 (F-R1 따름정리 M2, 인용).** 고리가 없으면 $\chi(G(\mathfrak B))=\min\{t+1:\ a_{t}(U\mathfrak B)\le t+1\}$ 이고, $P(G,q)=P(U\mathfrak B^{(q-1)},q)/((q-1)!)^{|V_\circ|}$ 다. [증명: F-R1 M2 인용; 본 문서는 재증명하지 않음]. 이 읽기는 $U\mathfrak B$ 만 쓴다. 따라서 $\alpha$, $\beta$, $\partial$ 에 독립이다.

### 3.5 리본 층 $\mathcal R$ (평면성 판정용)

$\mathfrak B\in\mathcal R_{\alpha,\pi,\kappa}$ 는 다음을 만족한다. $\pi\in\{0,1\}$ (핀치 허용), $\kappa\in\{0,1\}$ (닫힌 호 허용).

- (R1) **원판 조각.** 각 $k$ 에 대해 $P_k$ 는 2-연결이고 $|V(P_k)|\ge3$ 이다. $\partial\cap E(P_k)=E(C_k)$ 인 사이클 $C_k$ 가 있고, $C_k$ 는 $P_k$ 의 어떤 평면 매장에서 바깥면의 경계다. [증명: 이 조건은 $P_k$ 가 평면임을 함의하므로 $\mathrm{(M1)}_{\mathrm{on}}$ 이 자동이다.] ($|V|\ge3$ 은 K_2 조각과 점 공유를 막는다. F-R1 충돌 10.)
- (R2) **포트.** 각 $w$ 에 대해 $\alpha(w)$ 의 원소들은 서로 다른 조각에 놓이고 (한 조각에 최대 하나), 모두 $\bigcup_k V(C_k)$ 위에 있다.
  - $\pi=0$ (핀치 없음): $|\alpha(w)|=2$ 를 요구한다.
  - $\pi=1$ (핀치 허용): $|\alpha(w)|\ge2$ 를 허용한다. 단 (R4) 에서 $|\alpha(w)|\ge3$ 인 $w$ 는 호의 끝점이어야 한다 (경계 위).
- (R3) **쌍과 호의 기본.** 모든 $ww'\in\mathcal D(\mathfrak B)$ 에 대해 $|D_{ww'}|=2$ 다 (정확히 둘). $D_{ww'}=\{i,j\}$ 일 때 $ww'$ 의 **쌍 표지** 는 $\{i,j\}$ 이다. 그리고 $x\in\alpha(w)\cap P_i$, $x'\in\alpha(w')\cap P_i$ 가 $xx'\in E(C_i)$ 인 것과, 같은 것을 $P_j$ 에서도 만족한다 (두 조각 모두에서 경계 간선). 각 흰 점은 $\mathcal D$ 의 간선을 적어도 하나 가진다.
- (R4) **링크.** 흰 점 $w$ 의 링크 $L(w)$ 는 다중그래프다. 정점은 $\alpha(w)$ 의 점들을 가진 조각들이고, $w$ 에 닿는 $\mathcal D$-간선 $ww'$ 마다 쌍 표지 $\{i,j\}$ 의 변 하나를 둔다 (같은 표지라도 간선이 여러 개면 여러 변). 다음을 요구한다.
  - $L(w)$ 는 연결이다.
  - $L(w)$ 의 모든 정점 차수는 $\le2$ 다. 이것은 (R1)(R2)(R3) 에서 자동으로 나온다. 조각 $i$ 의 포트 $x$ 는 $C_i$ 에서 이웃이 둘뿐이고, 각 이웃은 최대 한 흰 점의 포트다. [증명]
  - 따라서 $L(w)$ 는 경로 또는 사이클이다. **$w$ 는 호의 끝점 $\Leftrightarrow$ $L(w)$ 는 경로, $w$ 는 호의 내부점 $\Leftrightarrow$ $L(w)$ 는 사이클** (2-사이클, 곧 같은 쌍의 변 두 개 포함). [증명: 정의 + 명제 L 의 결과]
  - $\pi=0$ 이면 $|\alpha(w)|=2$ 이므로 $L(w)$ 는 두 정점 위의 변 1개 (끝점) 또는 변 2개 (내부점) 다. [증명]
  - $\pi=1$ 이면 $|\alpha(w)|\ge3$ 인 $w$ 에서는 $L(w)$ 가 경로여야 한다 (사이클이면 내부 핀치이므로 금지, F-R2 의 R02 (c)). [증명: R02 (c) 인용]
- (R5) **단순 colimit.** 모든 조각 $k$ 와 모든 류 $p\ne q$ 에 대해, $P_k$ 의 변 중 $[p]$ 와 $[q]$ 를 잇는 것은 많아야 하나다. 곧 단순화 전의 colimit 이 단순 그래프다. 이것이 F-R2 "(R5) 단순" 의 정식화다 (형식 검토 F11). [증명: 정의]
- (R6) **호는 경로 (κ).** $\kappa=0$ 이면 쌍 표지 $\{i,j\}$ 의 흰–흰 간선이 이루는 각 연결성분 (호) 은 경로다 (사이클이 아니다). $\kappa=1$ 이면 닫힌 호 (사이클) 를 허용한다. 닫힌 호는 두 조각이 전체 경계로 붙는 경우이고, 그 점들은 모두 내부점이다. [추측: $\kappa=1$ 의 닫힌 호 가 $X$ 에 닫힌 성분을 만드는지, F-R2 는 확인하지 않았다]
- 호의 정의. 호 $a$ 는 쌍 표지 $\{i,j\}$ 를 가진 $\mathcal D$-간선들의 연결성분이다. 그 점들을 $w_1,\dots,w_r$ 로 쓰면 $r\ge2$ 이고 (R6) 에 의해 경로다. 끝점 $w_1,w_r$, 내부점 $w_2,\dots,w_{r-1}$ 이다. 호의 쌍 표지는 $\{i,j\}$ 다. [증명: 정의]
  - $\pi=0$ 이면 각 흰 점은 정확히 한 호에 속한다 (끝점은 한 호, 내부점은 한 호). [증명]
  - $\pi=1$ 이면 핀치점은 두 호 이상의 끝점이다. "정확히 한 호" 는 깨진다. 그 경우 호는 쌍 표지의 연결성분으로 정하고, 핀치점은 여러 호에 속한다 (F-R1 충돌 7). [증명: 정의]

**리본 판의 데이터 (모두 $\mathfrak B$ 에서 계산된다).**

- 호 $a$ 의 쌍 표지 $\{i_a,j_a\}$, 끝점 집합 $\partial a$, 길이 $r_a$.
- 조각 그래프 $H(\mathfrak B)$: 정점은 조각, 변은 호다 (다중변 허용). (F-R1 의 $H$ 이고, 문제 진술의 "조각 그래프" 와 같다.)
- 경계 그래프 $K:=\bigcup_k C_k$ (그래프로서). 분해하면 $K=W_{\mathrm{free}}\cup\bigcup_a(\text{호의 간선들})$ 다. 여기서 $W_{\mathrm{free}}$ 는 어떤 호에도 들지 않는 경계 간선들이다. [증명]
  - 호의 간선은 서로 다른 두 조각의 경계 간선이 같은 두 류를 잇는 것이다. 조각 안에서는 서로 다른 간선이고, 조립에서 식별된다. (두 조각이 같은 검정 간선을 공유하지는 않는다, 곧 $E_{\bullet\bullet}$ 는 성분마다 한 번씩만 나온다.) [증명: 조각은 성분]

### 3.6 조립 곡면 $X$, $b$, $I$, $D_c(K)$ (선택에 독립)

- **$X$ 의 정의.** 각 $k$ 에 닫힌 원판 $D_k$ 와 한 동형 $\partial D_k\cong C_k$ 를 잡는다. $X:=\bigl(\bigsqcup_k D_k\bigr)/\!\sim$ 로 두고, 각 호 $a$ 의 두 조각 $i,j$ 에서 $w_m$ 에 대응하는 경계 점들을 식별한다 (흰 점 $w_m$ 의 두 포트 점). 이 식별은 흰 점으로 정해지므로 방향 선택이 필요 없다. [증명] 따라서 $X$ 는 $\mathfrak B$ 의 함수다. $\varepsilon$ (부호) 를 쓰지 않아도 된다 (F-R2 명제 W 와 같다).
- **$X$ 가 곡면인 조건.** $\pi=0$ 이면 $X$ 는 경계가 있는 곡면이다 (F-R2 명제 L 의 결과 (a)). [증명 스케치] $\pi=1$ 이면 핀치점에서 곡면이 아닐 수 있다.
- **$b$.** $X$ 의 경계 성분 수. $\pi=0$ 에서 $\partial X$ 는 $W_{\mathrm{free}}$ 와 호의 끝점들로 이루어진 2-정규 그래프이다. [증명: F-R2 명제 W 인용]
- **$\chi$ 공식 (정정).** $\pi=0$ 이면 $\chi(X)=|V(H)|-|E(H)|$ 다 [증명 스케치: 조각들의 쌍별 교집합은 호들의 합집합이고 세 조각의 교집합은 없으므로 포함–배제가 바로 나온다]. $\pi=1$ 이면 이 공식은 일반적으로 깨진다 (발견 D; E3 반례 §7 F7).
- **$b=1$ 의 $W$ 와 $I$.** $b=1$ 이면 $W=\partial X$ 는 한 사이클이다. 호의 끝점들은 모두 $W$ 위에 있다 (내부점은 $W$ 위에 있지 않다). $I$ 는 정점이 호들이고, 두 호 $a,b$ 가 $W$ 위에서 끝점이 번갈아 나오면 ($a$ 의 두 끝점이 $b$ 의 두 끝점을 separate 하면) 이웃이다. [증명: 정의]
- **$D_c(K)$.** $I$ 의 proper 2-색칠 $c$ 가 주어지면: $W$ 를 원으로 그리고, 색 $0$ 인 호는 원 안쪽에, 색 $1$ 인 호는 바깥쪽에, 서로 교차하지 않게 그린다 (호는 내부점을 갖는 경로로 그린다). 얻은 평면 그래프의 면 경계 집합을 $\mathrm{Face}(D_c(K))$ 로 쓴다. 색칠이 proper 이면 이런 그림이 존재하고, 면 경계 집합은 $c$ 에만 의존한다 (F-R2 의 귀납 논증, [증명]).
- **강체 / 유연.** 유연 $:\Leftrightarrow P_k=C_k$ (다각형). 강체 $:\Leftrightarrow P_k$ 가 3-연결이고 $C_k$ 가 면이다. 혼합 (그 밖의 2-연결 조각) 은 $\mathcal R$ 안에 있지만 판정이 없다. [증명: 정의 분할]

**발견 A의 증명 (실현 가능한 $G$ 는 $\alpha$ 와 무관).** $G$ 가 단순 그래프라고 하자. 각 정점 $v$ 에 대해 $\deg v\ge2$ 이면 흰 점 $w_v$ 를 두고 $\alpha(w_v)$ 를 $v$ 의 복사본들 (간선 $uv$ 마다 조각 $\{u_{uv},v_{uv}\}$ 의 점 $v_{uv}$) 로 둔다. $\deg v\le1$ 이면 복사본을 하나 두고 흰 점을 두지 않는다 (1원소 류). 각 간선 $uv$ 에 조각 $K_2=\{u_{uv},v_{uv}\}$ 를 둔다. 그러면 조각은 모두 평면 ($K_2$) 이고, (J1)(J2)(J4) 가 성립한다. (J4) 는 같은 조각의 두 점이 서로 다른 류 ($u\ne v$) 에 있으므로 성립한다. 축약하면 정점 $\Pi$ 는 $V(G)$, 변은 $uv$ 뿐이다. 따라서 $G(\mathfrak A)=G$ 다. [증명]

[계산 확인 (손 계산)] 또 $C_4\cup C_4=K_4$ 는 강체가 없으므로 평면이다 [계산 확인 (손 계산)].

## 6. 나 $\subseteq$ 다 (진술, 증명 생략)

**진술 S.** $\alpha\in\{\mathrm{on},\mathrm{off}\}$, $\beta\in\{\beta_1,\beta_2,\beta_3\}$ 에 대해 다음을 정의한다.

$$\iota_\beta:\ \mathcal A_\alpha\ \longrightarrow\ \mathcal B_{\alpha,\beta}:=\{\mathfrak B\ \text{가 } (\mathrm M0),(\mathrm M2),(\mathrm M1)_\alpha,(\mathrm M3)_\beta\text{ 를 만족}\},$$

$$\iota_\beta(\mathfrak A):=(V_\bullet,V_\circ,E_{\bullet\bullet},E_{\bullet\circ},\ E_{\circ\circ}:=\begin{cases}\mathcal D(\mathfrak A)&\beta=\beta_1\\\emptyset&\beta\in\{\beta_2,\beta_3\}\end{cases},\ \partial:=\emptyset).$$

이때 다음이 성립한다.

- (S1) $\iota_\beta$ 는 잘 정의되고 단사다. [증명] (M2 는 (J1)(J2) 에서 나오고, (M3) 는 $\beta_1$ 에서 $\mathcal D$ 로 정의되므로 자명하다.)
- (S2) $U\circ\iota_\beta=\mathrm{id}$ 이고 $G\circ\iota_\beta=G$ 다. 곧 $\iota_\beta(\mathfrak A)$ 의 조립은 $\mathfrak A$ 의 $G$ 와 같고, 색칠 읽기도 같다. [증명: G1 과 축약의 정의]
- (S3) $\iota_\beta$ 는 전사가 아니다. $\partial\ne\emptyset$ 인 $\mathfrak B$ 나 고리가 있는 $\mathfrak B$ 는 상에 없다. 따라서 포함은 진부분집합이다. [증명]
- (S4) $G$ 의 집합은 같다: $\{G(\mathfrak A):\mathfrak A\in\mathcal A_\alpha\}=\{G(\mathfrak B):\mathfrak B\in\mathcal B_{\alpha,\beta}\ \text{고리 없음}\}=\{\text{모든 단순 그래프}\}$. [증명: §4.1 의 발견 A 와 G1]
- (S5) 리본 층: $\mathcal R_{\alpha,\pi,\kappa}\subseteq\mathcal B_{\mathrm{on},\beta_1}$ 이고, $U:\mathcal R\to\mathcal A_{\mathrm{on}}$ 이다. [증명: (R1) 이 평면성을 함의하고, (R2) 의 포트가 같은 조각에 두 번 나오지 않으므로 고리가 없다]

**뜻.** "나 $\subseteq$ 다" 는 $\iota$ 로 나를 다에 넣는 단사이면서, 조립과 색칠 읽기를 보존하는 것이다. 그러나 $G$ 의 집합으로는 $\alpha$ 와 $\beta$ 에 독립이다. 차이는 리본 층 (평면성 읽기) 과 조각 구조에서만 생긴다.

## 7. 형식 검토 목록 (모호, 중복, 육하원칙 누락)

1. **F1. 고리 규약 비대칭 (모호).** 𝔄 는 (J4) 로 고리를 금지하고, 𝔅 는 고리를 허용한다 (F-R1 정의 M). 두 정의가 한 $\mathcal A\subseteq\mathcal B$ 관계를 이루려면 규약이 맞아야 한다. 권장: $\mathfrak B$ 에도 (J4) 를 두거나, 고리를 $\chi=\infty$ 규약으로 명시한다.
2. **F2. 류 정의 중복.** 𝔄 는 $N(w)$ 로, $\mathfrak B$ 는 M2 의 "혼자 한 류" 로 정의한다. 본 문서는 §2 의 $\Pi$ 한 가지로 통일했다.
3. **F3. "리본" 이름 중복.** F-R1 (R1)–(R4) 와 F-R2 $R'$ (R1, R2′, R3′, R4′, R5) 는 다른 공리계다. 같은 이름으로 불리면 혼동된다. 본 문서의 §3.5 가 유일한 리본 정의다. 이후 F-R2 의 (R4′) 를 쓰지 말고 §3.5 의 (R4) 를 쓴다.
4. **F4. (R4′) "경로" 와 내부점 모순.** 명제 L 은 내부점에서 링크가 사이클이라 하고, (R4′) 는 링크가 경로라고 요구한다. 호의 내부점은 2-사이클 링크를 가지므로 $r\ge3$ 인 호는 (R4′) 를 어긴다. 또 F-R2 §2.2 는 "같은 표지는 하나로 친다", §2.3 A1 은 "다중 링크로 읽는다" 고 써서 서로 다르다. 다중 링크로 읽어야 A1 이 성립한다 (같은 표지 두 간선이 내부점임을 잡는다). 수정: §3.5 (R4). [증명: 두 텍스트의 모순 확인]
5. **F5. 닫힌 호.** 쌍 표지가 같은 흰–흰 간선의 성분이 사이클이면 "호" 가 아니라 닫힌 성분이다. F-R1 (R3) 과 F-R2 (R3′) 모두 이것을 막지 않는다. 막을지 말지가 $\kappa$ 다.
6. **F6. 핀치 정의 불통일.** F-R1 은 "포트 둘" 을 핀치 없음으로, F-R2 는 $L\cong K_2$ 를 핀치 없음으로 쓴다. 본 문서는 핀치 $:\Leftrightarrow|\alpha(w)|\ge3$ 로 정하고 $\pi$ 로 허용을 나눈다.
7. **F7. $\chi(X)=|V(H)|-|E(H)|$ 는 $\pi=0$ 에서만.** E3 (중심 $e$ 를 삼각형 넷으로 쪼갠 $W_4\cup C_4=K_5$ 재구성) 에서 조각 4개 + $C_4$, 호 6개. 셀 복합체를 세면 $V=5$, $E=10$, $F=5$ 이므로 $\chi=0$ 이고, 공식은 $5-6=-1$ 을 준다. 따라서 공식은 내부 핀치에서 틀린다 [계산 확인, `scratchpad/e3chi.py`]. 경계 핀치 ($\pi=1$, 링크가 경로) 에서 공식이 성립하는지는 확인하지 않았다 [추측].
8. **F8. $\varepsilon$, $\rho$ 의 용도 불명.** F-R1 은 $\varepsilon$, $\rho$ 를 정의하지만 F-R2 의 Mix, 정리 D 는 쓰지 않는다 (명제 W). 두 데이터 족 (부호 있는 것, 경계만) 이 한 $\mathfrak B$ 에 섞여 있다. 본 문서는 $X$ 를 $\varepsilon$ 없이 정의했다 (§3.6). $\varepsilon$ 이 필요한 것은 R01 의 따름 8(a), 9 뿐이다 (F-R1 평면성 표 행 4, 5). 그 판정들은 본 문서 범위 밖에 둔다.
9. **F9. 용어 미정의.** "진짜 2-색칠" 은 proper 로 읽었다. "$D_c(K)$" 는 그림으로만 있었다. §3.6 에 정식화했다.
10. **F10. 조각의 규약과 문제 진술.** 문제 진술은 "평면 조각 $P_1,\dots,P_n$ 과 설명서 $H$" 를 데이터로 준다. 본 문서의 $\mathfrak B$ 는 조각을 따로 주지 않고 검정 성분으로 얻는다 (규약 C). $n$ 은 성분 수다. 연결되지 않은 조각을 한 조각으로 주면 $n$ 이 달라진다. 육하원칙상 "누가 조각을 정하는가" 는 $E_{\bullet\bullet}$ 가 정한다.
- **F10'. minor $\sqsubseteq$ 미정의.** F-R5 의 실현 정리와 W5 는 $\mathfrak A\sqsubseteq X$ 를 쓰지만 정의가 없다 (부분그래프 / 유도 부분그래프 / 조각 단위 포함). 결과가 어느 것이냐에 따라 참이 달라진다. 정의를 정해야 한다.
11. **F11. (R5) 단순성 의 말뜻.** F-R2 는 "겹친 간선은 흰–흰 간선이 식별하는 것뿐" 이라고만 썼다. 본 문서는 "조각당 한 간선" 으로 정식화했다 (R5). 이것이 F-R2 의 뜻과 같은지는 F-R2 저자가 확인해야 한다 [추측].
12. **F12. $\mathfrak A^{(t)}$ 에서 흰 점 제거 여부 모호.** F-R1 은 "흰 점마다 $K_t$ 를 넣는다" 고만 썼다. 흰 점을 남기면 $a_0$ 가 $\max\chi(P_k)$ 와 달라진다. 본 문서는 제거로 정했다 [증명: $a_0$ 의 일치].
13. **F13. 기호 $\alpha$ 의 이중 쓰임.** F-R1 에서 $\alpha(w)$ 는 포트 집합, F-R2-researcher1 에서 $\alpha$ 는 류의 이름이다. 본 문서는 포트에만 $\alpha$ 를 쓴다.
14. **F14. "정확히 한 호" 의 조건.** F-R1 (R3) 의 "모든 흰 점은 정확히 한 호에 속한다" 는 $\pi=0$ 에서만 성립한다 (§3.5). 전역 주장으로 쓰면 틀린다.
15. **F15. 육하원칙 누락 — 조각 쌍의 방향.** 호 식별에서 어느 조각의 어느 쪽 경계 방향이 어느 쪽에 대응하는지는 흰 점이 정한다. F-R1 은 $t^{(i)}_a$ 로 방향을 따로 정하고 있다. 본 문서의 $X$ 는 방향 선택이 필요 없지만, $X$ 의 가향성은 별도 질문이다 (미정). [추측]
16. **F16. 설명서의 "비자명성" 과 $K_2$ 퇴화.** 문제 진술의 비자명성 (조각이 $K_2$ 면 $H\approx G$ 로 모든 것이 설명됨) 은 $\alpha$ 로 막히지 않는다 (§4.1). 막는 것은 (R1)(R3) 뿐이다. 문제 진술과 정의가 맞는지 판단할 것. 본 문서는 판단하지 않는다.

## 9. 후속연구 지점

1. **(우선 1) 리본 정의 하나로 고정 (F3, F4, F5, F6).** 
   - 이유: 정리 D, E, Mix 는 모두 리본 정의에 기댄다. 지금은 F-R1 과 F-R2 의 공리계가 다르고, F-R2 (R4′) 는 내부 호점과 충돌한다.
   - 시작 방법: §3.5 의 (R1)–(R6) 를 하나의 공리계로 확정한다. $\pi=0,1$, $\kappa=0,1$ 의 네 판 중 어느 것을 본판으로 쓸지 정하고, 반례꾼에게 $r\ge3$ 호, 닫힌 호, E3 류 내부 핀치를 공격시킨다. 정의를 바꾸면 `problem.md` 에 이력을 남긴다.
   - 난점: 경계 핀치 ($\pi=1$) 의 $X$ 가 곡면인지 확인하는 것이 필요하다. R02 의 (a)(b)(c) 와 맞추어야 한다.
2. **(우선 2) $\chi(X)$ 공식의 정정과 경계 핀치의 경우 (F7).**
   - 이유: F-R1 의 $\chi$ 공식은 E3 에서 틀린다. 정리 E 의 $\chi$ 항을 쓰므로 영향이 있다.
   - 시작 방법: 세포 복합체로 $\chi(X)=\sum_k\chi(D_k)-\sum_a\chi(\text{호})+\text{(핀치 보정)}$ 을 쓰고, 핀치점의 링크 크기에 따른 보정을 구한다. E3 에서 보정이 $+1$ 임을 확인하고 일반식을 세운다.
   - 난점: 경계 핀치 (링크 경로, 3포트 이상) 와 내부 핀치 (링크 사이클) 의 보정이 다르다.
3. **(우선 3) $\alpha$ 가 $\mathrm{M2}$, $\mathrm{W5}$ 에 주는 영향의 확인 (§4.1 표의 [추측] 두 칸).**
   - 이유: F-R5 는 $\alpha=\mathrm{off}$ 에서 두 결과가 성립한다고 제안했을 뿐 확인하지 않았다. 이 확인이 "조각 평면성 $\alpha$" 결정의 실질적 근거가 된다.
   - 시작 방법: $\alpha=\mathrm{off}$ 에서 실현 정리를 다시 쓴다. 조각 $K_5$ 를 허용하면 실현 정리의 (⟹) 가 자명해지는지 확인하고, W5 는 $V_8$ 조각 한 개를 허용하면 $\le3$ 클릭 나무 판정이 맞는지 본다.
   - 난점: $\alpha=\mathrm{off}$ 에서 조각 단위 분해가 무의미해질 수 있다 (K_2 분해가 항상 가능, §4.1). 그러면 "분해 정리" 는 조각 크기를 제한하는 다른 조건이 필요하다.
4. **(우선 4) 나 $\subseteq$ 다 진술 (§6) 의 증명 (S1)–(S5) 과 $\mathcal G$ 의 특징화.**
   - 이유: 진술은 맞아 보이지만 증명은 하지 않았다. 특히 (S4) 는 $K_2$ 분해로 모든 $G$ 가 실현되므로, 집합 수준의 정보는 $\alpha$ 와 $\beta$ 에 독립이다. 이것이 문제 진술의 목적과 맞는지 판단할 근거다.
   - 시작 방법: (S1)–(S3) 는 정의 확인으로 끝난다. (S4) 는 §4.1 의 구성을 그대로 쓴다. 그다음 "$K_2$ 를 쓰지 않는 최소 분해" (예: 조각 최소 3 정점, 리본 조건) 의 실현 가능 $G$ 를 특징화하는 문제로 옮긴다.
   - 난점: 최소 분해를 정의하는 기준 (조각 수, 호 수, 조각 크기) 을 정해야 한다.
5. **(우선 5) 혼합 조각 (2-연결, 다각형 아님, 3-연결 아님) 의 판정 (F-R2 후속 1 과 연결).**
   - 이유: E3′ 처럼 강체를 쪼개면 혼합 조각이 나오고, Mix 가 적용되지 않는다. 판정 대상이 빠져 있다.
   - 시작 방법: 각 조각마다 "$C_k$ 의 어떤 점 집합이 어떤 평면 매장의 한 면에 함께 놓일 수 있는가" 를 기록하는 데이터를 정의한다. 3-연결이면 간선 쌍, 다각형이면 $C_k$ 전체. F-R2 의 후속 1 과 같은 방향이다.
   - 난점: SPQR 나무 (2-절단마다 뒤집기) 가 필요하다 [기억-미검증].
