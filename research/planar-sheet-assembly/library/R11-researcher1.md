## 요약
- **해석.** 정리 3.2 에 의해 $A(\mathfrak M)$ 은 분해된 그래프 자신이므로, 과제는 "**$K_N$ 의 평면분해 중 매뉴얼 그래프(또는 압축 그래프)가 주어진 $G$ 와 동형인 것을 찾아라**"이다. "$\mathfrak M=G$" 는 동형으로 읽는다 ($V(\mathfrak M)$ 의 원소는 순서쌍이라 글자 그대로의 등식은 뜻이 없다). $K_n$ 의 $n$ 이 조각 수인지 꼭짓점 수인지 모호하므로 꼭짓점 수를 $N$ 으로 따로 쓰고, $n=N$ 판은 3절에서 따로 푼다.
- **정리 C (별 군집 정리, 필요충분).** $G\cong\mathfrak M^\circ$ (어떤 $K_N$ 의 평면분해) $\iff$ $G$ 에 흰 점 집합 $W$ 가 있어 조건 (C1)–(C5) 가 성립한다. $G\cong\mathfrak M$ 은 (C1)–(C5) 에 $E_{11}$ 규칙 (C6) 을 더한 것과 동치이다. 증명은 양방향 구성적이며, 이것이 **방법론**이다 ($W$ 를 고르면 $N$, 조각, 분해가 모두 정해진다). [증명]
- **장애물.** (i) 흰 점이 없으면 $G=K_N$, $N\le4$. (ii) $K_N\preceq G$ 이므로 $G$ 평면 $\Rightarrow N\le4$. (iii) **지름 정리 D:** $G$ 가 2-연결이고 지름 $\le2$ 이면 $G\in\{K_3,K_4\}$ 뿐이다. 따라서 $K_m$ ($m\ge5$), $K_{3,3}$, 피터슨, $C_4$, $C_5$ 는 어느 쪽으로도 안 된다. (iv) 홑 섬유 한계: $N\ge6$ 이면 흰 점이 $N-2$ 개 이상. [증명]
- **예.** $C_m$: (나) $\iff m\in\{3,6,7,9\}$, (가) $\iff m\in\{3,7,9\}$. 모든 $N$ 에 대해 $K_N$ 의 3중 세분 (각 변을 길이 3 경로로) 은 (가)(나) 모두 된다. (가) 와 (나) 의 부류는 서로 포함하지 않는다 ($C_6$ 은 (나) 만, 예 8.4 의 $\mathfrak M_b$ (세타 그래프) 는 (가) 만). [증명] [계산 확인]
- **조각 수.** 최소 조각 수는 "충돌 그래프" $\Gamma$ 의 색칠수 $\chi(\Gamma)$ 이고, 빈 조각을 허용하지 않으면 가능한 조각 수는 정확히 $\chi(\Gamma)\le n\le c(G-W)$ 이다. [증명]

## 본문

### 0. 해석과 표기

**0.1 과제의 뜻.** 교재 정리 3.2 는 "평면분해 $(P_1,\dots,P_n)$ 이 $X$ 의 분해이면 $A(\mathfrak M)=X$" 이다. 따라서 $A(\mathfrak M)=K_N$ 은 "$(P_k)$ 가 $K_N$ 의 평면분해" 와 같다 [증명: 정리 3.2]. 과제는 다음 역문제이다.

> 주어진 $G$ 에 대해 $N$ 과 $K_N$ 의 평면분해 $(P_1,\dots,P_n)$ 을 찾아 (가) $(V(\mathfrak M),E(\mathfrak M))\cong G$, 또는 (나) $\mathfrak M^\circ\cong G$ 가 되게 하라.

**해석상 주의 (문주님 확인 필요).**
1. "$\mathfrak M=G$" 는 **동형**으로 읽었다. $V(\mathfrak M)=V_0\sqcup V_1$ 의 원소는 $(v,k)$, $(v,\star)$ 꼴이라 글자 그대로의 등식은 $G$ 의 점 이름을 그렇게 붙인 경우뿐이고 수학적 내용이 같다.
2. 다른 해석 "$(P_k)$ 는 $G$ 의 분해" 는 정리 3.2 때문에 $A(\mathfrak M)=G$ 가 되어 $G=K_n$ 일 때만 뜻이 있다. 그래서 버렸다.
3. $K_n$ 의 $n$ 이 **조각 수**라는 해석 ("조각 수 = 완전 그래프의 크기") 도 가능하다. 본문은 꼭짓점 수를 $N$, 조각 수를 $n$ 으로 나누어 쓰고, $n=N$ 을 요구하는 판은 3절 따름 3.3 에서 답한다.

**0.2 표기.** 그래프 $G$ 와 $W\subseteq V(G)$ 에 대해 $B:=V(G)\setminus W$ (검은 점), $H:=G-W=G[B]$, $N_B(w):=N_G(w)\cap B$. $c(H)$ 는 $H$ 의 연결 성분 수. 2-연결: $|V|\ge3$ 이고 모든 $x$ 에 대해 $G-x$ 가 연결.

### 1. 별 군집 자료와 정리 C

**정의 1.1 (별 군집 자료).** 그래프 $G$ 의 부분집합 $W$ 가 **(나)-자료**라는 것은 다음이 성립하는 것이다.
- (C0) $W$ 는 독립 집합이다.
- (C1) 모든 $w\in W$ 에 대해 $|N_B(w)|\ge2$.
- (C2) 모든 $x\in B$ 는 $W$ 에 이웃을 많아야 하나 가진다.
- (C3) 각 $w\in W$ 의 검은 이웃들은 $H$ 의 서로 다른 연결 성분에 있다.
- (C4) $H$ 의 각 연결 성분은 평면 그래프이다.
- (C5) **섬유**를 $\Phi_w:=N_B(w)$ ($w\in W$) 와 $\{x\}$ ($x\in B$, $W$ 에 이웃 없음, **홑 섬유**) 로 두면 ((C2) 에 의해 섬유들은 $B$ 의 분할이다), 서로 다른 두 섬유 사이에는 항상 $H$ 의 변이 있다.

**(가)-자료**는 (C0) 을 빼고 (C1)–(C5) 와 다음 (C6) 을 요구한다 ((C1) 의 $N_B$ 는 검은 이웃만 센다).
- (C6) 서로 다른 $w,w'\in W$ 에 대해 $\{w,w'\}\in E(G)\iff$ $\Phi_w$ 와 $\Phi_{w'}$ 사이의 $H$ 의 변이 2개 이상.

이때 $N(W):=|W|+s$ ($s$ = 홑 섬유 수) 는 섬유의 개수이다.

**정리 C (별 군집 정리).** [증명]
(나) $G\cong\mathfrak M^\circ$ 인 어떤 $K_N$ 의 평면분해가 있다 $\iff$ $G$ 가 (나)-자료 $W$ 를 갖는다. 이때 $N=N(W)$.
(가) $G\cong\mathfrak M$ 인 어떤 $K_N$ 의 평면분해가 있다 $\iff$ $G$ 가 (가)-자료 $W$ 를 갖는다. 이때 $N=N(W)$.
두 경우 모두 $W$ 는 $V_1$ (흰 점) 의 상이다.

*증명 ($\Leftarrow$, 구성 — 방법론의 본체).* $W$ 를 자료라 하자. $x\in B$ 의 섬유를 $f(x)$ 로 쓴다. $V^*:=\{$섬유$\}$, $K:=(V^*,\binom{V^*}2)\cong K_N$. $H$ 의 성분을 $C_1,\dots,C_n$ 으로 두고
$$P_k:=\bigl(f(C_k),\ \{\{f(a),f(b)\}:\{a,b\}\in E(H[C_k])\}\bigr).$$
(a) $f$ 는 각 $C_k$ 위에서 단사이다. 홑 섬유는 원소가 하나이고, $\Phi_w$ 의 두 원소는 (C3) 에 의해 다른 성분에 있기 때문이다. 따라서 $f|_{C_k}$ 는 $H[C_k]\to P_k$ 의 동형이고, $\{f(a),f(b)\}$ 는 두 원소 집합이다. (C4) 와 보조명제 0.1 에 의해 $P_k$ 는 평면 그래프이다 (D1).
(b) (D2): 모든 섬유는 비어 있지 않고 어떤 성분에 원소를 가지므로 $\bigcup_kV(P_k)=V^*$. $\bigcup_kE(P_k)\subseteq\binom{V^*}2$ 는 자명하고, 반대 포함은 (C5) 이다. 따라서 $(P_k)$ 는 $K$ 의 평면분해이고, 정리 3.2 에 의해 $A(\mathfrak M)=K\cong K_N$.
(c) $\mathfrak M$ 을 계산한다. $\beta:B\to V_0$, $\beta(x):=(f(x),k)$ ($x\in C_k$). (a) 에 의해 $\beta$ 는 전단사이다. $F(f)=\beta(f)$ 이므로 $|F(\Phi_w)|=|\Phi_w|\ge2$ ((C1)), 홑 섬유는 $|F|=1$. 따라서 $V_1=\{w_{\Phi_w}:w\in W\}$ 이고 $\beta(w):=w_{\Phi_w}$ 로 넓히면 $\beta:V(G)\to V(\mathfrak M)$ 는 전단사이다. 변을 비교한다.
 - $E_{00}$: $\{(f(a),k),(f(b),k)\}\in E_{00}\iff\{f(a),f(b)\}\in E(P_k)\iff\{a,b\}\in E(H[C_k])$ ((a) 의 동형). 즉 $E_{00}=\beta(E(H))$.
 - $E_{01}$: $\{\beta x,w_{\Phi_w}\}\in E_{01}\iff x\in\Phi_w=N_B(w)\iff\{x,w\}\in E(G)$. (C2) 에 의해 $W$–$B$ 사이의 $G$ 의 변은 이것뿐이다.
 - $E_{11}$: $\mu(\{\Phi_w,\Phi_{w'}\})$ 는 그 쌍을 변으로 갖는 조각 수이다. 각 조각은 각 섬유의 원소를 많아야 하나 가지므로 ((a)) 한 조각에는 $\Phi_w$–$\Phi_{w'}$ 변이 많아야 하나이고, 서로 다른 성분은 서로 다른 조각이다. 따라서 $\mu=$ ($\Phi_w$ 와 $\Phi_{w'}$ 사이의 $H$ 의 변 수). 홑 섬유가 끼면 $\mu\le1$ 이라 $E_{11}$ 에 안 들어간다 (보조명제 2.4 와도 맞다).
 (나): (C0) 에 의해 $G$ 에는 $W$–$W$ 변이 없으므로 $\beta$ 는 $G\cong\mathfrak M^\circ$ 이다. (가): (C6) 에 의해 $W$–$W$ 변이 정확히 $E_{11}$ 로 가므로 $\beta$ 는 $G\cong\mathfrak M$ 이다.

*증명 ($\Rightarrow$).* $\sigma:G\to\mathfrak M^\circ$ (또는 $\mathfrak M$) 를 동형이라 하고 $W:=\sigma^{-1}(V_1)$. $\mathfrak M$ 에서 확인하면 충분하다.
 - (C0) (나): $\mathfrak M^\circ$ 의 변은 $E_{00}\subseteq\binom{V_0}2$ 와 $E_{01}$ ($V_0$–$V_1$) 뿐이다.
 - (C1), (C2): 명제 2.5 (M1), (M2). 흰 점의 검은 이웃은 $E_{01}$ 로만 온다.
 - (C3): $E_{00}$ 의 변은 같은 층 $k$ 의 복사점끼리 잇는다 (보조명제 2.2 (4)). 따라서 $\mathfrak M-V_1$ 의 각 성분은 한 층 $\{(\cdot,k)\}$ 안에 있다. $N(w_v)=F(v)$ 의 원소는 서로 다른 층에 있다.
 - (C4): 층 $k$ 의 부분그래프는 $\varphi$ 에 의해 $P_k$ 와 동형이고, 각 성분은 그 부분그래프이다. 부분그래프는 삭제로 얻은 마이너이므로 (II) 에 의해 평면이다.
 - (C5): 섬유는 $F(v)$ ($v\in V(K_N)$) 와 같다. $\{u,v\}\in E(K_N)$ 이면 (D2) 에 의해 $\{u,v\}\in E(P_k)$ 인 $k$ 가 있고 $\{(u,k),(v,k)\}\in E_{00}$ 이다.
 - (C6) (가): 위 (c) 의 셈 $\mu=$ (섬유 사이의 $E_{00}$ 변 수) 는 어느 분해에서나 성립한다. 같은 이유로 $|F(v)|=1$ 인 점은 $E_{11}$ 에 끼지 않는다. $\square$

**따름 1.2 (방법론, 알고리즘 R).** 주어진 $G$ 에 대해:
1. $W$ 후보를 고른다. 아래 4절의 국소 장애물로 후보를 줄인다. 특히 (나) 에서 $W$ 는 서로 거리 $\ge3$ 인 점들이고 삼각형에 속하지 않는 점들이다.
2. $H=G-W$ 의 성분을 구하고 (C1)–(C4) 를 확인한다.
3. 섬유를 만들고 (C5) (몫이 완전 그래프인가) 를 확인한다. (가) 면 (C6) 을 확인한다.
4. 통과하면 정리 C ($\Leftarrow$) 의 공식으로 $N$, $K_N$, 조각 $P_k$ 를 출력한다.
정리 C 에 의해 알고리즘 R 이 어떤 $W$ 에서도 실패하면 $G$ 는 불가능하다. [증명] (복잡도는 열림. 1단계가 지수적일 수 있다.)

**비고 1.3 (마이너 모형으로 다시 쓰기).** (C1)–(C5) 는 "$G$ 의 모든 점을 덮는 $K_N$ 마이너 모형으로서 가지 집합이 모두 별 $K_{1,d}$ ($d\ge2$, 중심 = 흰 점) 또는 한 점이고, 중심에는 별 변 말고 다른 변이 없으며, 중심을 지운 그래프의 각 성분이 각 가지 집합을 많아야 한 번 만나고 평면인 것" 과 같다. 정리 3.6 의 증명이 수축하는 $T_v=F(v)\sqcup\{w_v\}$ 가 바로 이 별이다. [증명: 정의를 옮긴 것]

### 2. 조각 수 $n$ 과 정규형

**보조명제 2.1 (서로소 합의 평면성).** 서로소인 평면 그래프 둘의 합은 평면이다. [증명] 각 그림의 상은 유한 개의 콤팩트 집합 (점과 곡선 상) 의 합이라 유계이다. 한 그림을 충분히 멀리 평행이동해 두 상이 서로 다른 원판 안에 있게 하면 (P1)–(P3) 은 각 그림 안에서는 그대로이고, 두 그림 사이에서는 상이 서로소라 공허하게 성립한다. $\square$

**정리 2.2 (조각 수).** (가)-자료 또는 (나)-자료 $W$ 를 고정하자. $H$ 의 성분들 위의 **충돌 그래프** $\Gamma$ 를 "두 성분이 어떤 흰 점의 검은 이웃을 각각 가지면 인접" 으로 정의한다. 그러면 이 $W$ 로 실현되는 분해 (빈 조각 없음) 의 조각 수 $n$ 의 집합은 정확히 $\{n:\chi(\Gamma)\le n\le c(H)\}$ 이다. [증명]
*증명.* 정리 C ($\Rightarrow$) 의 증명에서 각 성분은 한 층에 있으므로 조각은 성분들의 합이다. 같은 조각의 두 성분은 같은 $v$ 의 복사점을 둘 가질 수 없으므로 충돌하지 않는다. 따라서 조각들은 $\Gamma$ 의 적절한 색칠의 색 부류이고, 빈 조각이 없으면 $\chi(\Gamma)\le n\le c(H)$. 역으로 $\Gamma$ 의 $n$-색칠 (모든 색을 쓰는 것, $\chi(\Gamma)\le n\le c(H)$ 이면 있다) 의 색 부류를 조각으로 합치면 보조명제 2.1 에 의해 조각은 평면이고, 정리 C ($\Leftarrow$) 의 (a)–(c) 가 그대로 성립한다 (같은 조각 안에서도 $f$ 가 단사이고, $\mu$ 의 셈은 변이 놓인 조각만 센다). $\mathfrak M$ 은 이름만 바뀐다. $\square$

**비고 2.3 (빈 조각).** 교재 정의상 $(\varnothing,\varnothing)$ 도 평면 그래프이고 (조건이 공허), 빈 조각은 $V_0$, $\mathfrak M$ 을 바꾸지 않는다. 빈 조각을 허용하면 $n\ge\chi(\Gamma)$ 인 모든 $n$ 이 가능하다. [증명] 빈 조각을 막으려면 조건 (N2) 같은 것이 필요하다.

**따름 2.4 ($n=N$ 판).** "$K_n$ 의 $n$ 이 조각 수" 해석에서는 정리 C 의 조건에 $\chi(\Gamma)\le N(W)\le c(H)$ (빈 조각 금지) 또는 $\chi(\Gamma)\le N(W)$ (허용) 를 더하면 된다. [증명]

### 3. 예 (작은 수로 정선)

**예 3.1 ($G=K_m$).** (가)(나) 모두 $\iff m\le4$, 이때 자명 분해 $(K_m)$, $N=m$, $n=1$. [증명] 흰 점 $w$ 의 검은 이웃 둘은 (M3) 에 의해 인접하지 않는데 $K_m$ 에서는 모두 인접하므로 $W=\varnothing$. 그러면 모든 섬유가 홑이고 $H=G$ 는 연결이라 조각이 하나뿐이고, 이것이 평면이어야 한다. $K_m$ ($m\ge5$) 은 $K_5$ 를 부분그래프로 갖고 $K_5$ 는 (I) 에 의해 비평면 ($10>9$) 이므로 (II) 로 비평면 이고 $K_4$ 는 (III). [계산 확인: `r11_inverse.py`, $m\le6$]

**예 3.2 ($G=C_m$).** (나) $\iff m\in\{3,6,7,9\}$; (가) $\iff m\in\{3,7,9\}$. [증명]
*증명.* $W=\varnothing$ 이면 $G$ 가 완전이어야 하므로 $m=3$. $W\ne\varnothing$ 이면 흰 점의 차수는 2 이고 (C3) 때문에 $|W|\ge2$ ($|W|=1$ 이면 $H$ 는 경로 하나라 두 이웃이 같은 성분). $H$ 는 이웃한 흰 점 사이의 경로들이고, 꼭짓점 하나짜리 경로는 흰 이웃이 둘이라 (C2) 위반이다. 따라서 각 경로는 점이 2개 이상이고 $m\ge3|W|$. 별 $\{x,w,y\}$ 를 수축한 몫은 길이 $N=m-2|W|$ 의 순환 (또는 $N\le2$ 이면 $K_N$) 이고, 완전이려면 $N\le3$. $N=3$: $|W|\le3$ 이므로 $(m,|W|)=(7,2),(9,3)$. $N=2$: $m=2|W|+2\ge3|W|$ 이므로 $(m,|W|)=(6,2)$. $N=1$: $m=2|W|+1\ge3|W|$ 이면 $|W|\le1$ 이라 모순. 각 경우의 구성은 실제로 (C1)–(C5) 를 만족한다 ($C_7$: $K_3$ 를 변 하나 + 길이 2 경로로; $C_9$: $K_3$ 를 변 셋으로; $C_6$: $K_2$ 를 $(K_2,K_2)$ 로). (가): 순환에서 흰 점이 흰 이웃을 가지면 검은 이웃이 하나뿐이라 (C1) 위반이므로 $W$ 는 독립이고 (나) 의 분석이 그대로이다. $C_6$ 에서는 $\mu=2$ 라 (C6) 이 두 흰 점 사이의 변을 요구하는데 $C_6$ 에는 없다. $C_7$, $C_9$ 는 $\mu=1$. $\square$
조각 수 (정리 2.2): $C_9$ 는 $\Gamma=K_3$, $c(H)=3$ 이라 $n=3=N$ 이 된다. $C_7$ 은 $\chi(\Gamma)=c(H)=2<N=3$ 이라 빈 조각 없이는 $n=N$ 불가. [증명] [계산 확인: $3\le m\le11$]

**예 3.4 ($K_N$ 의 3중 세분 $K_N^{(3)}$, 모든 $N\ge3$).** 각 변 $uv$ 를 경로 $h_u-a_{uv}-b_{uv}-h_v$ 로 바꾼 그래프. $W=\{h_u\}$ 로 두면 $H$ 는 서로소인 변 $\binom N2$ 개, 섬유 $\Phi_{h_u}=\{a_{uv}\}_v$ (크기 $N-1\ge2$), 두 섬유 사이의 변은 정확히 하나 ($\mu=1$) 이다. ### 4. 장애물 (불변량)

**보조명제 4.1 (연결성).** 실현 가능한 $G$ 는 연결이다. [증명] 섬유별 별 (흰 점 + 섬유) 은 연결이고, 그 몫 $K_N$ 은 연결이다. 변 하나로 이어진 두 가지 집합의 합은 연결이다.

**보조명제 4.2 (국소 장애물).** $\mathfrak M$ 에서 [증명]
(a) 흰 점은 검은 점을 포함하는 삼각형에 속하지 않는다 (검은 두 점 $x,y\in F(v)$ 는 (M3) 으로 비인접; 흰 점 둘과 검은 점 하나는 (M2) 위반).
(b) 흰 점을 지나는 모든 사이클은 다른 흰 점을 지난다 ((C3) 의 바꿔 말하기: $x-w-y$ 를 포함한 사이클이 $W\setminus\{w\}$ 를 피하면 $x,y$ 가 $H$ 의 같은 성분).
(c) (나) 에서 서로 다른 흰 점은 거리 $\ge3$ 이다 (인접 불가 (C0), 공통 이웃이 검은 점이면 (C2) 위반, 흰 점이면 (C0) 위반).
(d) (가) 에서도 $E_{11}$ 변 $\{w_v,w_{v'}\}$ 이 있으면 지름 $\ge3$ 이다. $\mu\ge2$ 이므로 서로 다른 층 $k_1\ne k_2$ 에 변 $(v,k_1)(v',k_1)$, $(v,k_2)(v',k_2)$ 이 있다. $x=(v,k_1)$ 과 $y=(v',k_2)$ 는 다른 층의 검은 점이라 인접하지 않고, 공통 검은 이웃은 두 층에 동시에 있어야 하며, 공통 흰 이웃은 $w_v=w_{v'}$ 를 요구한다. 따라서 $d(x,y)\ge3$.

**정리 D (지름 장애물).** $G$ 가 2-연결이고 지름이 2 이하이면, $G$ 가 (가) 또는 (나) 로 실현 가능한 것은 $G\in\{K_3,K_4\}$ 일 때뿐이다. [증명]
*증명.* (가) 이면 4.2 (d) 에 의해 $E_{11}=\varnothing$, 곧 $\mathfrak M=\mathfrak M^\circ$ 라 (나) 로 줄어든다. (나) 에서 4.2 (c) 와 지름 $\le2$ 에 의해 $|W|\le1$. $|W|=1$ 이면 $G-w$ 가 연결 (2-연결) 이라 $w$ 의 두 검은 이웃 ((C1)) 이 $H$ 의 같은 성분에 있어 (C3) 위반. $W=\varnothing$ 이면 섬유가 모두 홑이고 (C5) 는 $G$ 가 완전임을, (C4) 는 $G$ 가 평면임을 말하므로 $G=K_N$, $N\le4$ ((I) 로 $K_5$ 비평면). 2-연결이므로 $N\in\{3,4\}$. $\square$
적용: $K_m$ ($m\ge5$), $K_{3,3}$, 피터슨, $C_4$, $C_5$, $K_{a,b}$ ($a,b\ge2$) 는 불가능 (모두 2-연결이고 지름 2). "작은 지름 + 높은 연결도" 가 막는다. $K_3,K_4$ 가 아닌 2-연결 실현 그래프는 반드시 **길쭉하다** (거리 $\ge3$ 의 점 쌍을 갖는다).

**명제 4.3 (흰 점이 하나 이하인 경우의 분류).** [증명]
- $|W|=0$: $G=K_N$, $N\le4$.
- $|W|=1$: $G$ 는 다음 둘 중 하나이다. (i) 별 $K_{1,d}$ ($d\ge2$; $N=1$, 조각 = 고립점 $d$ 개). (ii) $K_N$ ($2\le N\le4$) 의 한 점 $x_1$ 에 새 점 $w$ 를 잇고 $w$ 에 잎 $d-1\ge1$ 개를 붙인 그래프 ($N$ 은 $K_N$ 의 크기).
*증명.* $\Phi_w=\{x_1,\dots,x_d\}$ 는 서로 다른 성분 $C_1,\dots,C_d$ 에 있고, $G$ 가 연결이므로 $H$ 의 모든 성분은 어떤 $x_i$ 를 포함한다. 다른 점은 모두 홑 섬유이고 (C5) 에 의해 서로 인접하므로 한 성분, 예컨대 $C_1$ 에 모인다. 그러면 $C_i=\{x_i\}$ ($i\ge2$) 이고, (C5) 는 $C_1$ 의 몫 (그대로 $C_1$) 이 완전임을, (C4) 는 평면임을 말한다. $\square$

**명제 4.4 (홑 섬유 한계).** $K_N$ 의 평면분해에서 $|F(v)|=1$ 인 점 (홑 섬유) 의 수를 $s$ 라 하면, $N\ge6$ 이면 $s\le2$ (따라서 $|W|\ge N-2$), $N=5$ 이면 $s\le3$ 이다. [증명]
*증명.* $u$ 가 홑이면 $u$ 는 한 조각 $P(u)$ 에만 있으므로 $u$ 의 변 $N-1$ 개가 모두 $P(u)$ 에 있다. 두 홑 점 $u,u'$ 의 변 $uu'$ 는 둘을 포함하는 조각에 있어야 하므로 $P(u)=P(u')=:P$. $P$ 는 홑 점 집합 $S$ 에 닿는 모든 변을 가진다. $|S|\ge4$ 이고 $N\ge5$ 이면 $S$ 의 넷과 다른 한 점이 $K_5$ 를 이루고, $|S|=3$ 이고 $N-3\ge3$ 이면 $S$ 와 다른 세 점이 $K_{3,3}$ 을 부분그래프로 준다. 둘 다 (I) 로 비평면 (예 6.2 의 논증), 부분그래프는 마이너이므로 (II) 로 모순. $\square$
예: $N=5$, $s=3$ 은 실제로 된다 ($K_5=(K_5-e)+K_2$, 9점 실현) [계산 확인]. 따라서 4.4 의 $N=5$ 경계는 날카롭다.

**명제 4.5 (셈 한계).** 실현에서 $|B|=\sum_{w}|N_B(w)|+s$, $\binom N2\le|E(H)|\le3|B|$. 특히 $|V(G)|\ge|B|\ge N(N-1)/6$. [증명] (C5) 는 섬유 쌍마다 $H$ 의 변을 하나 이상 요구하고, (C4) 와 (I) 은 점이 3개 이상인 성분에서 $|E|\le3|C|-6$, 작은 성분에서 $|E|\le|C|$ 를 준다.

**명제 4.6 (평면성과의 얽힘).** 정리 3.6 에 의해 $K_N\preceq G$. 따라서 $G$ 가 평면이면 $N\le4$ 이다. 역은 거짓: $N=4$ 에서도 $G=\mathfrak M^\circ$ 가 비평면일 수 있다 (예 6.2). 즉 $G$ 의 비평면성은 $N\ge5$ 를 강제하지 않는다. $N\ge5$ 이면 실현 $G$ 는 반드시 비평면이다. [증명]

### 5. 증명 시도와 막힌 곳

- **$W$ 없이 $G$ 만으로 쓰는 특징짓기.** 정리 C 는 $W$ 의 존재로 특징짓는다. $W$ 를 지우고 $G$ 의 불변량만으로 쓰려 했으나, $C_7$ 처럼 $W$ 가 여러 개 (회전 7개) 인 경우가 있어 "흰 점 = 어떤 국소 모양의 점" 같은 규칙이 바로 나오지 않는다. 장애물은 국소 조건 (4.2) 과 지름 (정리 D) 까지이다.
- **$N$ 의 유일성.** 같은 $G$ 의 두 자료 $W,W'$ 가 다른 $N$ 을 줄 수 있는가? 증명하지 못했다. $|W|\le1$ 인 경우 (명제 4.3) 와 순환에서는 $N$ 이 유일하다 [증명]. 7점 이하 연결 그래프에서는 다른 $N$ 을 주는 예를 찾지 못했다 (탐색 결과일 뿐, 근거 아님). [추측: $N$ 은 $G$ 로 정해진다]
- **복잡도.** 알고리즘 R 의 1단계는 지수적이다. (나) 에서 $W$ 는 $G^2$ 의 독립 집합이어야 하므로 후보가 줄지만, 다항 시간 판정은 모른다. [추측: NP-완전일 수 있다; 근거 없음]

## 문주님께 요청
1. **해석 확인 (긴급도 중).** (가) "$\mathfrak M=G$" 를 동형으로, $K_n$ 의 $n$ 을 완전 그래프의 꼭짓점 수로 읽었다. $n$ 이 조각 수를 뜻한다면 따름 2.4 와 정리 2.2 ($\chi(\Gamma)\le N\le c(H)$) 가 답이다. 빈 조각을 허용할지도 정해 주시면 좋다 (비고 2.3). 없을 때의 대안: 본 보고서처럼 두 해석을 모두 적는다.

## 후속연구 지점
1. **$N$ 의 유일성 (우선순위 상).** 무엇을: (가)/(나)-자료 $W,W'$ 가 같은 $N$ 을 주는지 증명 또는 반례. 왜: 유일하면 "$G$ 가 실현하는 완전 그래프" 가 $G$ 의 불변량이 되어 역문제의 답이 하나로 정해진다. 시작 방법: 비고 1.3 의 별 마이너 모형 둘을 겹쳐, 한 모형의 흰 점이 다른 모형에서 검은 점일 때 (C2)·(C3) 이 무엇을 강제하는지 본다. $|W|=2$ 부터. 난점: 두 모형의 가지 집합이 서로 엇갈릴 수 있다.
2. **최소 실현과 두께 (우선순위 상).** 무엇을: 주어진 $N$ 에 대해 $|V(\mathfrak M^\circ)|$ 최소인 실현. 왜: $|V(\mathfrak M^\circ)|=\sum_k|V(P_k)|+|W|$ 이므로 이것은 "점 반복이 적은 평면분해" 문제이고, 두께 (최소 조각 수) 와 직접 이어진다. 명제 4.4 ($|W|\ge N-2$) 와 4.5 가 하한의 출발점이다. 시작 방법: $N=5,6$ 에서 하한을 증명하고 예 (9점 실현) 와 맞춘다. 난점: 조각 수와 점 반복이 서로 거래된다.
3. **$W$ 없는 특징짓기 / 판정 복잡도 (우선순위 중).** 무엇을: 정리 C 의 $W$ 존재를 $G$ 의 내재적 성질 (예: 거리 3 쌍의 구조, 블록 구조) 로 바꾸기, 또는 판정 문제의 NP-난도 증명. 왜: 방법론의 1단계가 현재 지수 탐색이다. 시작 방법: 흰 점의 국소 모양 (4.2: 삼각형 없음, 모든 사이클이 다른 흰 점을 지남) 을 블록-절단점 나무에서 해석한다. 난점: $C_7$ 처럼 자료가 대칭적으로 여러 개 있다.
4. **(가) 와 (나) 의 변환 (우선순위 중).** 무엇을: (나)-실현에서 $\mu\ge2$ 인 쌍을 없애는 정련 (R08 연구원3 의 정련 사상) 으로 (가)-실현을 얻는 조건. 왜: 두 부류가 서로 포함하지 않는데 (예 3.6), 차이는 $E_{11}$ 하나뿐이다. 시작 방법: $C_6$ 과 $\Theta$ 를 정련 범주 안에서 비교한다. 난점: 정련은 $G$ (여기서는 $\mathfrak M$) 의 모양을 바꾼다.
5. **조각 수 판의 색칠 해석 (우선순위 하).** 무엇을: 정리 2.2 의 $\chi(\Gamma)$ 를 팀의 색칠수 결과 (나무 공식, 수열 읽기) 와 연결. 왜: $n=N$ 판의 존재가 충돌 그래프 색칠로 정해진다. 시작 방법: $K_N^{(3)}$ 에서 $\Gamma=L(K_N)$ 인 것을 일반화해, 분해의 모양에서 $\Gamma$ 를 읽는다. 난점: $\Gamma$ 는 $W$ 에 의존한다.
