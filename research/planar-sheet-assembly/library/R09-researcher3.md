## 요약
- **(1) 함자가 되는 올림 규약은 전체 정련 범주에 존재하지 않는다.** 분해 4개 (모두 $K_2$ 위의 조각) 로 된 가환 그림 하나가 반례이다. 같은 정련 $\pi$ 의 두 인수분해가 흰 점 $w_u$ 의 상을 $w_u$ 와 $(u,P_1)$ 로 각각 강제한다. 이것은 R08 따름 R8-2 의 "선택 규칙이 필요하다" 보다 강하다: 어떤 규칙을 택해도 함자가 될 수 없다. [증명] [계산 확인]
- **(2) 함자가 되는 두 제한.** (a) 단사 정련 범주 위에서 "모든 흰 점을 흰 점으로" 올리는 규약은 유일한 올림을 주며 엄밀한 함자이다. (b) 조각 대신 **연결 성분(블록)** 수준의 복사점 사상은 흰 점 선택 없이 전체 정련 범주에서 엄밀한 함자이다. 집합값 올림 $\mathcal L$ 은 lax (포함만 성립) 이고 엄밀하지 않다. [증명] [계산 확인]
- **(3) Ψ 사상의 분류.** Ψ 의 사상은 (블록 사상) + (복사점→흰 점 블록) + (흰 점 선택 $p_v$) 의 데이터로 완전히 기술되고, 그 조건은 명시된 4개 조건이다. [증명]
- **(4) 정련+올림의 합성으로 쓰이지 않는 사상이 실제로 있다.** 성분 분할 사상 (조각 $ab\sqcup cd$ 를 두 조각으로 쪼개는 방향 — 정련이 아님) 과 복사점을 흰 점으로 보내는 자기사상 (예: $\mathfrak M(D_b)$ 의 자기사상 17개 중 3개) 이 있다. [증명] [계산 확인]
- R08 정리 R8-1 은 이 분류에서 "사상이 정련의 올림인 경우" 의 흰 점 조건에 해당한다 (§2.4).

## 본문

### 0. 규약과 기호

- $D=(P_k)_{k\in[n]}$, $D'=(P'_j)_{j\in[m]}$ 는 $G$ 의 평면분해. $M=\mathfrak M(D)$, $M'=\mathfrak M(D')$ (교재 정의 2.3). 흰 점 $w_v$ ($|F_D(v)|\ge2$), 복사점 $(v,k)$.
- **정련** $\sigma:D'\to D$: $V(P'_j)\subseteq V(P_{\sigma j})$, $E(P'_j)\subseteq E(P_{\sigma j})$ (R08 §0 과 같다). 정련들의 범주를 $\mathbf{Ref}$ 라 한다. 합성은 함수의 합성이다.
- **블록.** $D$ 의 블록은 짝 $(k,C)$ 이고 $C$ 는 $P_k$ 의 연결 성분이다 (고립점도 성분). $\mathcal B(D)$ 로 쓴다.
  **보조 사실 0.1 [증명].** $(V_0,E_{00})$ 의 연결 성분은 정확히 $\{(v,k): v\in V(C)\}$ 꼴 (블록) 이다. $E_{00}$ 의 변은 같은 $k$ 의 $P_k$ 변이기 때문이다 (교재 정의 2.1).
- $D^{cc}$: $D$ 의 모든 블록을 조각으로 가진 분해. 평면 조각의 부분그래프이므로 평면이고, 조각들의 합은 $G$ 이다. [증명]
- **Ψ(M',M).** $\rho$-호환 RG 사상 $\Phi:M'\to M$ ($\rho\Phi=\rho'$) 전체. 이것은 R07 의 $\Psi$ 의 사상 집합이다.
- **σ-올림.** $\sigma\in\mathbf{Ref}(D',D)$ 에 대해 $L(\sigma):=\{\Phi\in\Psi(M',M):\ \Phi(v,j)=(v,\sigma j)\ \forall (v,j)\in V'_0\}$. 복사점은 항상 복사점으로 간다. 흰 점 $p_v:=\Phi(w'_v)$ 만 자유롭다. R08 의 $\varphi_\sigma$ 의 확장 집합이 $L(\sigma)$ 이다.

### 1. 올림의 함자성 (질문 1)

#### 1.1 불가능성 정리

**예 1.0 (반례 그림).** $G=K_2$ ($V=\{u,v\}$, 변 $uv$). 모든 조각은 $K_2$ (점 $u,v$, 변 $uv$) 이다.
- $D_2=(R_1,R_2)$ (두 조각), $D_3=(Q_1,Q_2,Q_3)$ (세 조각), $D_1=(P_1,P_2)$ (두 조각), $D_0=(S_1)$ (한 조각).
- 정련: $\tau:D_2\to D_3$, $\tau(1)=1,\tau(2)=2$. $\sigma:D_3\to D_1$, $\sigma=(1,1,2)$. $\tau'':D_2\to D_0$, $\tau''=(1,1)$. $\sigma'':D_0\to D_1$, $\sigma''=(1)$.
- 합성: $\sigma\tau=(1,1)=\sigma''\tau''$. 두 인수분해가 같은 정련 $\pi:=\sigma\tau=\sigma''\tau''$ 를 준다.
- 흰 점: $|\Pi_{D_2}(u)|=2$, $|\Pi_{D_3}(u)|=3$, $|\Pi_{D_1}(u)|=2$, $|\Pi_{D_0}(u)|=1$. 따라서 $w^{(2)}_u,w^{(3)}_u,w^{(1)}_u$ 는 있고 $D_0$ 에서는 흰 점 $w_u$ 가 없다.

**명제 1.1 (함자 올림의 불가능성).** 예 1.0 의 $\pi$ 에 대해 $L(\tau)$, $L(\sigma)$, $L(\tau'')$, $L(\sigma'')$ 는 모두 원소 하나이고, $L(\pi)$ 의 두 원소 $\Phi:=\Lambda(\sigma)\Lambda(\tau)$, $\Phi':=\Lambda(\sigma'')\Lambda(\tau'')$ 는
$$\Phi(w^{(2)}_u)=w^{(1)}_u\quad\text{이고}\quad\Phi'(w^{(2)}_u)=(u,P_1)$$
을 만족한다. 이 값들은 각 단계의 강제에서 나온다. 따라서 $\Lambda(\pi)$ 를 두 값과 동시에 같게 할 수 없다. 즉 $\mathbf{Ref}\to\Psi$ 의 함자 $\Lambda$ (각 $\sigma$ 에 $L(\sigma)$ 의 원소를 대응) 는 존재하지 않는다. 같은 결론이 압축 그래프 $M^\circ$ 에서도 성립한다.

*증명.* 흰 점의 강제를 세 단계로 본다. 기호: $\bar u:=w^{(2)}_u$, 각 블록의 복사점은 $(u,\cdot)$.
(i) $\Phi\in L(\tau)$: $\bar u$ 는 복사점 $(u,R_1)$, $(u,R_2)$ 와 $E_{01}$ 로 이어진다. 이들의 상은 $(u,Q_1)$, $(u,Q_2)$. $\Phi(\bar u)$ 는 이 둘과 같거나 인접해야 한다. 같은 점 $u$ 의 서로 다른 두 복사점은 인접하지 않으므로 $\Phi(\bar u)=(u,Q_1)$ 이면 $(u,Q_2)$ 와 같지도 인접하지도 않아 모순이다. 따라서 $\Phi(\bar u)=w^{(3)}_u$ 가 강제된다 (교재 정의 2.1 의 $E_{00}$ 는 같은 점의 복사점을 잇지 않는다).
(ii) $\Phi\in L(\sigma)$: $w^{(3)}_u$ 는 $(u,Q_1),(u,Q_2),(u,Q_3)$ 와 이어지고 상은 $(u,P_1),(u,P_1),(u,P_2)$ 이다. $\Phi(w^{(3)}_u)$ 는 이 셋과 모두 같거나 인접해야 한다. $(u,P_1)$ 은 $(u,P_2)$ 와 인접하지 않으므로 복사점은 불가능하고, 흰 점 $w^{(1)}_u$ 만 된다 (그 차수 $|F_{D_1}(u)|=2$ 이므로 존재한다).
(iii) $\Phi\in L(\tau'')$: $D_0$ 에서 $u$ 의 복사점은 $(u,S_1)$ 하나이고 흰 점은 없다. $\bar u$ 의 상은 $(u,S_1)$ 이고, 두 복사점 $(u,R_1),(u,R_2)$ 의 상도 $(u,S_1)$ 이므로 조건을 만족한다.
(iv) $\Phi\in L(\sigma'')$: $(u,S_1)\mapsto(u,P_1)$ 이 정의에 의해 강제된다.
따라서 $\Lambda(\sigma)\Lambda(\tau)(\bar u)=w^{(1)}_u$ 이고 $\Lambda(\sigma'')\Lambda(\tau'')(\bar u)=(u,P_1)$ 이다. 그런데 함자성은 두 값이 $\Lambda(\pi)(\bar u)$ 와 같아야 함을 요구하므로 $w^{(1)}_u\ne(u,P_1)$ 이 모순이다. 압축 그래프에서는 (i)–(iv) 가 $E_{00}$ 와 $E_{01}$ 만 쓰므로 그대로 성립한다. □

**계산 확인.** $|L(\tau)|=|L(\sigma)|=|L(\tau'')|=|L(\sigma'')|=1$, $|L(\pi)|=2$ 이고 $L(\pi)$ 의 두 원소는 $\bar u$ 의 상이 $w_u$ 와 $(u,P_1)$ 인 것이다. [계산 확인] (r09_nogo.py)

**해석.** 흰 점 $\bar u$ 의 상은 "$\sigma$ 의 국소 상" $\{$ 복사점 $\}$ 이 한 점인지 두 점 이상인지에 따라 강제된다. 인수분해마다 중간 단계의 국소 상이 달라서 (3 조각 중간, 1 조각 중간) 서로 다른 흰 점 판정이 나온다. 이것은 R08 따름 R8-2 의 "올림이 두 개" 현상이 아니다. R08 의 $L(\pi)$ 는 두 원소이지만, 문제는 **인수분해에 따라 강제되는 원소가 다르다**는 것이다.

#### 1.2 함자가 되는 제한 (정리 A, 정리 B, 집합값 관찰)

**명제 1.2 (단사 정련 위의 모두-흰 올림은 엄밀한 함자).** $\mathbf{Ref}_{\mathrm{inj}}\subseteq\mathbf{Ref}$ 를 단사 정련들의 부분범주라 하자. $\sigma$ 가 단사이면 $L(\sigma)$ 는 원소 하나 $\Lambda(\sigma)$ 이며, $\Lambda(\sigma)(v,j)=(v,\sigma j)$, $\Lambda(\sigma)(w'_v)=w_v$ 로 정의된다. $\Lambda:\mathbf{Ref}_{\mathrm{inj}}\to\Psi$ 는 엄밀한 함자이다.

*증명.* (존재) $\sigma$ 단사이면 $\Pi'(v)\to\Pi(v)$ 가 단사이므로 $|F_D(v)|\ge|\Pi'(v)|\ge2$ (w'_v 가 있으면). 따라서 $w_v$ 가 존재한다. 모든 $v\in W'$ 는 불순이므로 (R08 보조명제 1.3 (b)) 흰 점 $w_v$ 가 강제된다. 변 조건: $\mu'(e)\ge2$ 인 $\Gamma'$ 변 $vv'$ 에 대해 $\mu_D(vv')\ge|\sigma(J_e)|=|J_e|=\mu'(e)\ge2$ 이다 (단사이므로 $J_e\to\{k:e\in E(P_k)\}$ 가 단사). 그러므로 $\{w_v,w_{v'}\}\in E_{11}$ 이다. $\rho$-호환과 RG 조건은 보조명제 1.1 과 같은 방식으로 확인된다. (유일성) 위 강제에 의해 $L(\sigma)$ 는 한 원소이다. (함자성) $\Lambda(\sigma)\Lambda(\tau)$ 는 $\mathbf{Ref}$ 의 합성 $\sigma\tau$ 에 대한 $L(\sigma\tau)$ 의 원소이다 (복사점은 $(v,j)\mapsto(v,\tau j)\mapsto(v,\sigma\tau j)$, 흰 점은 $w_v\mapsto w_v$). $\sigma\tau$ 도 단사이므로 $L(\sigma\tau)=\{\Lambda(\sigma\tau)\}$ 이고 두 원소가 같다. 항등 $\mathrm{id}$ 는 단사이고 $\Lambda(\mathrm{id})=\mathrm{id}$ 이다. □

**계산 확인.** 단사 $\sigma=\mathrm{id}$ 와 $\sigma=(0,2)$ 에서 $|L(\sigma)|=1$ (흰 점 모두 흰 점으로), 비단사 $\sigma=(0,0)$ 에서 $|L(\sigma)|=2$. [계산 확인] (r09_inj.py)

**명제 1.3 (블록 수준의 엄밀한 함자).** 블록 정련 범주 $\mathbf{Blk}$ 를 대상 $\mathcal B$-분해 (즉 $D^{cc}$) 와 사상 "블록 사상" ($\beta'\mapsto\beta$, $V(\beta')\subseteq V(\beta)$, $E(\beta')\subseteq E(\beta)$) 으로 정의한다. 정련 $\sigma$ 는 $\theta_\sigma:(j,C')\mapsto(\sigma j,\,C_\sigma)$ 를 준다. 여기서 $C_\sigma$ 는 $P_{\sigma j}$ 에서 $C'$ 를 포함하는 성분이다. 그러면 $\theta_{\sigma\tau}=\theta_\sigma\theta_\tau$ 이고 $\theta_{\mathrm{id}}=\mathrm{id}$ 이다. 즉 $\sigma\mapsto\theta_\sigma$ 는 엄밀한 함자 $\mathbf{Ref}\to\mathbf{Blk}$ 이다. 흰 점 선택은 필요 없다.

*증명.* $C'\subseteq P'_j\subseteq P_{\sigma j}$ 이고 $C'$ 는 연결이므로 $P_{\sigma j}$ 의 한 성분 $C_\sigma$ 에 들어간다. $\theta_\tau(j'',C'')=(\tau j'',C_\tau)$ 에서 $C_\tau\supseteq C''$ 이고, $\theta_\sigma(\tau j'',C_\tau)$ 는 $C_\tau$ 를 포함하는 $P_{\sigma\tau j''}$ 의 성분이다. 그것은 $C''$ 를 포함하는 성분이므로 $\theta_{\sigma\tau}(j'',C'')$ 와 같다. □

**따름 1.4 (올림과 $A$).** $A$ (R07 정리 1) 는 $E_{01}$, $E_{11}$ 을 무시하므로 $A(\Lambda(\sigma))=\mathrm{id}_G$ 이다. 그러므로 함자성 문제는 $A$ 에 아무 영향을 주지 않는다. [증명] (R07 따름 2.1 과 R08 정리 R8-3 에 의해. 블록 사상은 $A$ 를 정의할 필요가 없다.)

**명제 1.5 (집합값 올림은 lax 일 뿐이다).** $\mathcal L(\sigma):=L(\sigma)$ 로 두면 항상 $\mathcal L(\sigma)\circ\mathcal L(\tau)\subseteq\mathcal L(\sigma\tau)$ 이다. 그러나 예 1.0 에서 포함은 진부분집합이다: $\mathcal L(\sigma)\circ\mathcal L(\tau)=\{\Lambda(\sigma)\Lambda(\tau)\}$ 는 흰 점 $w_u$ 만 주고, $\mathcal L(\sigma'')\circ\mathcal L(\tau'')$ 는 $(u,P_1)$ 만 준다. [증명] (포함) 와 [계산 확인] ($|\mathcal L(\pi)|=2$)

**답 (질문 1).** 올림을 함자로 고르는 규약은 전체 $\mathbf{Ref}$ 에 없다 (명제 1.1). R08 이 제안한 "정련 범주 전체에서 올림을 함자로 고르는 규칙" 은 존재하지 않는다. 함자가 되는 정확한 대안은 두 가지다: 단사 정련 위의 모두-흰 올림 (명제 1.2), 또는 흰 점을 버린 블록 수준의 함자 (명제 1.3). 집합값 $\mathcal L$ 은 lax 이다 (명제 1.5).

### 2. Ψ 사상의 분류 (질문 2)

설정: $\Phi\in\Psi(M',M)$, $p_v:=\Phi(w'_v)$ (|Π'(v)|≥2 인 $v$). $\Phi$ 는 $\rho$-호환이므로 $p_v\in\{w_v\}\cup\{(v,k):k\in\Pi_D(v)\}$.

**보조명제 2.1 (블록 보존).** $\beta'=(j,C')$ 를 $D'$ 의 블록, $xy\in E_{00}'$ 를 그 변이라 하자 ($x=(u,j)$, $y=(v,j)$, $uv\in E(C')$). 그러면 $\Phi(\beta')$ 는 다음 중 하나이다.
- **(복사형)** $\Phi(\beta')$ 가 모두 복사점이고 한 인덱스 $k$ 를 가진다. 즉 $\Phi(u,j)=(u,k)$ 가 모든 $u\in V(C')$ 에 대해 성립한다.
- **(흰형)** $\Phi(\beta')$ 가 모두 흰 점이다. 이때 모든 $v\in V(C')$ 에 $|F_D(v)|\ge2$, 모든 $uv\in E(C')$ 에 $\mu_D(uv)\ge2$ 이다.
(단 $C'$ 가 고립점이면 복사형/흰형 중 하나로 독립하게 정할 수 있다.)

*증명.* $\rho\Phi=\rho'$ 이므로 $\rho(\Phi x)=u$, $\rho(\Phi y)=v$ 이고 $u\ne v$. 따라서 $\Phi x\neq\Phi y$ 이고 이 둘은 $E_{00}\cup E_{01}\cup E_{11}$ 의 변으로 이어져야 한다 ($\rho$ 값이 다르므로 $E_{01}$ 은 제외). $E_{01}$ 은 같은 $\rho$ 값만 잇으므로 제외된다. 따라서 $\Phi x,\Phi y$ 는 둘 다 복사점 (같은 인덱스, $E_{00}$) 이거나 둘 다 흰 점 ($E_{11}$) 이다. 연결 성분 안에서 유형이 전파되므로 블록 전체가 하나의 형을 갖는다. 흰형의 조건은 $E_{11}$ 의 정의 (정의 2.3) 에서 나온다. □

**보조명제 2.2 (복사형 블록의 포함).** 복사형 블록 $\beta'=(j,C')$ 의 상은 $D$ 의 한 블록 $\beta=(k,C)$ 안에 있고, $V(C')\subseteq V(C)$, $E(C')\subseteq E(C)$ 이다. 즉 $\theta(\beta'):=\beta$ 는 블록 사상 $\mathcal B(D')\supseteq\{\text{복사형}\}\to\mathcal B(D)$ 이다.

*증명.* 보조명제 2.1 에서 $\Phi(\beta')\subseteq\{(u,k)\}$ 이고 $E'_{00}$ 변 $\{(u,j),(v,j)\}$ 의 상 $\{(u,k),(v,k)\}$ 는 $E_{00}$ 의 변이므로 $uv\in E(P_k)$ 이다. $C'$ 가 연결이므로 $C'$ 의 모든 점과 변은 $P_k$ 의 한 성분 $C$ 에 든다. $\rho$-호환이므로 $V(C')\subseteq V(C)$ 는 점의 이름이 그대로 보존됨을 뜻한다. □

**보조명제 2.3 (흰 점 조건).** $|\Pi'(v)|\ge2$ 인 $v$ 에 대해 $K_v:=\{k:\ \exists$ 복사형 블록의 복사점 $(v,j)$ 와 $\Phi(v,j)=(v,k)\}$ 라 하자. 그러면 $p_v$ 는 다음을 만족한다.
- (H1) $|K_v|\ge2$ 이면 $p_v=w_v$.
- (H2) $K_v=\{k\}$ 이면 $p_v\in\{(v,k)\}\cup\{w_v\}$, 단 $w_v$ 는 $|F_D(v)|\ge2$ 일 때만.
- (H3) $K_v=\varnothing$ (모든 복사점이 흰형) 이면 $p_v\in\{w_v\}\cup\{(v,k):k\in\Pi_D(v)\}$.
- (H4) $\mu'(vv')\ge2$ 인 $\Gamma'$ 의 변에 대해: $p_v=(v,k)$, $p_{v'}=(v',k)$, $vv'\in E(P_k)$ 이거나, $p_v=w_v$, $p_{v'}=w_{v'}$, $\mu_D(vv')\ge2$ 이다. 혼합 (한쪽 복사점, 한쪽 흰 점) 은 불가능하다.

*증명.* (H1), (H2): 변 $\{(v,j),w'_v\}\in E'_{01}$ 의 상은 $\{\Phi(v,j),p_v\}$ 이고 이것은 같거나 $E(M)$ 의 변이어야 한다. $\Phi(v,j)=(v,k_j)$ (복사형) 이면 $p_v=(v,k)$ 일 때 $k_j=k$ 가 필요하다 (같은 점의 서로 다른 복사점은 인접하지 않음). $p_v=w_v$ 는 $\{(v,k_j),w_v\}\in E_{01}$ 이므로 $|F_D(v)|\ge2$ 이면 된다. (H3): $\Phi(v,j)=w_v$ 이면 $p_v=(v,k)$ 는 $\{w_v,(v,k)\}\in E_{01}$ 이므로 허용되고, $p_v=w_v$ 도 같거나 인접하다. (H4): $E'_{11}$ 변 $\{w'_v,w'_{v'}\}$ 의 상은 같거나 인접해야 하며 $\rho$ 값이 달라 같을 수 없다. 혼합은 보조명제 1.3 (a) (R08) 과 같은 이유로 $E(M)$ 에 없다. 두 복사점이면 같은 인덱스 $k$ 이고 $E_{00}$ 변이어야 한다. 두 흰 점이면 $E_{11}$ 변이어야 하므로 $\mu_D\ge2$. □

**정리 2.4 (Ψ 분류).** 다음이 성립한다.
(a) 각 $\Phi\in\Psi(M',M)$ 은 (복사형 블록의 블록 사상 $\theta$) + (흰형 블록의 집합) + (흰 점 선택 $p$) 로 정해지고, 이 데이터는 보조명제 2.1–2.3 의 조건을 만족한다.
(b) 역으로 위 조건을 만족하는 데이터 $(\theta,\text{흰형 집합},p)$ 는 정확히 하나의 $\Phi\in\Psi(M',M)$ 을 정한다. 그 $\Phi$ 는 $\Phi(j,C',v)=(v,\theta(j,C'))$ (복사형), $\Phi(v,j)=w_v$ (흰형), $\Phi(w'_v)=p_v$ 이다.

*증명.* (a) 보조명제 2.1–2.3 의 직접 결과. (b) 모든 $E(M')$ 의 변 유형을 확인한다. $E'_{00}$ 의 복사형 변은 $\theta$ 의 포함에 의해 $E_{00}$ 로 간다 (보조명제 2.2 의 역). 흰형 변은 $\mu_D\ge2$ 로 $E_{11}$ 로 간다. $E'_{01}$ 의 변은 (H1)–(H3) 에 의해 같거나 인접하다. $E'_{11}$ 은 (H4). $\rho$-호환은 정의상 성립한다. □

**계 2.5 (σ-올림의 특성).** $\Phi\in\Psi(M',M)$ 가 어떤 $\sigma\in\mathbf{Ref}$ 의 올림 (즉 $\Phi\in L(\sigma)$) 이기 위한 필요충분조건은 (i) 흰형 블록이 없고, (ii) $\theta$ 가 조각 단위 상수, 즉 $\theta(j,C')$ 의 인덱스가 $j$ 에만 의존하는 것이다 (그 인덱스가 $\sigma j$). [증명] (ii) 는 $V(P'_j)=\bigcup_{C'}V(C')\subseteq V(P_{\sigma j})$ 와 같다. 그리고 (H1)–(H4) 는 $\Pi'(v)$ 가 $\sigma$ 에서 상수인지에 따라 R08 정리 R8-1 의 (α)/(β) 판정을 준다. (α) 는 $K_v$ 가 한 원소인 경우, (β) 는 흰 점을 쓰는 경우에 해당한다. □

**예 2.6 (블록 사상이 정련이 아닌 예: 성분 분할).** $G=\{ab\}\sqcup\{cd\}$ (두 변, 네 점). $D'=(Q_1)$, $Q_1=\{ab,cd\}$ (한 조각), $D=(P_1,P_2)$, $P_1=\{ab\}$, $P_2=\{cd\}$. 
- $\mathbf{Ref}(D',D)$ 는 비어 있다. $V(Q_1)=\{a,b,c,d\}\not\subseteq V(P_k)$ 이기 때문이다.
- 그러나 $\Phi:(a,1)\mapsto(a,1),\ (b,1)\mapsto(b,1),\ (c,1)\mapsto(c,2),\ (d,1)\mapsto(d,2)$ 는 $\Psi(M',M)$ 의 원소이다. 흰 점이 없으므로 (H) 조건이 자명하다. [증명]
- 이 $\Phi$ 는 $D'^{cc}=D$ 로 가는 성분 분할 사상이다. 정련이 아니며 (조각 $Q_1$ 이 한 조각 $P_k$ 에 들어가지 않음), 블록 사상 $\theta$ 는 조각 단위 상수가 아니다. 계 2.5 의 (ii) 가 깨진다. [증명]

**예 2.7 (복사점 → 흰 점 사상: $\mathfrak M(D_b)$ 의 자기사상).** $D_b=(P_1,P_2)$, $P_1=P_2=K_2$ (예 8.4 의 $\mathfrak M_b$). 
- 흰형 블록 $\{(u,1),(v,1)\}$ 와 $\{(u,2),(v,2)\}$ 를 모두 흰점으로 보내는 $\Phi$ 를 생각한다: $(u,j)\mapsto w_u$, $(v,j)\mapsto w_v$ ($j=1,2$), $w_u\mapsto w_u$, $w_v\mapsto w_v$. 복사 변 $\{(u,j),(v,j)\}\mapsto\{w_u,w_v\}\in E_{11}$ ($\mu=2$). $E_{01}$ 변은 collapse. $E_{11}$ 변은 그대로. RG 이고 $\rho$-호환이다. [증명]
- 계산으로 $|\mathrm{End}_\Psi(\mathfrak M_b)|=17$ 이고 그중 복사점을 흰 점으로 보내는 것이 3개이다 (위 $\Phi$ 포함). 이 3개는 $\mathbf{Ref}$ 의 어떤 올림에도 속하지 않는다 (계 2.5 (i)). [계산 확인] (r09_full.py)

**답 (질문 2).** $\Psi$ 의 사상은 정련+복사점 사상의 합성으로 모두 쓰이지 않는다. 정리 2.4 가 분류이다. 예 2.6 (성분 분할) 과 예 2.7 (흰형 블록) 이 정련 올림이 아닌 사상의 실제 예이다. 특히 **$\bigcup_\sigma L(\sigma)$ 는 $\Psi$ 의 진부분집합이다** (예 2.6 은 어떤 $\sigma$ 도 없고, 예 2.7 의 흰형 자기사상은 어떤 $L(\sigma)$ 에도 없다). 이 둘이 생성하는 부분범주가 $\Psi$ 와 같은지는 미확인이다 (후속 2).

#### 2.4 R08 과의 대응

- R08 정리 R8-1 은 정리 2.4 와 계 2.5 를 $\sigma$ 가 주어진 경우로 제한한 것이다. R08 의 (α) 는 $K_v$ 가 한 원소인 점 (순수 점, (H2)의 복사 선택), (β) 는 흰 점 선택 (H2 의 $w_v$, H4 의 흰 쪽) 이다.
- R08 이 "성분마다 (α) 또는 (β)" 를 얻은 것은 (H4) 가 $\Gamma'$ 의 변을 따라 유형을 전파하기 때문이다. 이 점은 맞다.
- R08 따름 R8-2 는 정확하지만 불완전하다: 선택 규칙이 있어도 함자가 되지 않는다 (명제 1.1). R08 따름 R8-5 (합성) 는 "합성이 올림 가능하다" 는 존재만 말하며 함자성을 말하지 않는다.

### 3. 장애물 (정직하게)

- **O1 (생성원 문제 미해결).** $\Psi$ 가 어떤 원소로 생성되는지 모른다. 예 2.6, 2.7 은 정련 올림 밖의 원소이다. 흰형 자기사상의 합성이 정련 올림 또는 블록 사상과 어떻게 얽히는지 확인하지 않았다.
- **O2 (흰 점 장애의 차수).** 명제 1.1 의 실패는 "인수분해에 따라 강제값이 다름" 이다. 이것을 R07 O5 (고차 장애) 와 연결하려면 흰 점 선택을 torsor 가 아닌 집합 위의 데이터로 보고 그 합성 불일치를 코사이클로 재기술해야 한다. 아직 하지 않았다.
- **O3 (블록 함자와 평면성·색칠수).** 명제 1.3 의 블록 함자는 $D^{cc}$ 로 $\chi$ 와 평면성이 전달되는지 알 수 없다. 블록 사상은 조각의 연결 성분을 잇기 때문에 R08 의 수축 상계 (계 R8-8) 가 적용되는지 미확인.
- **O4 (교재 밖 의존).** 없음. 모든 증명은 교재 정의 2.1–2.3, 3.1, 8.1–8.2 와 보조명제 2.2, 2.4 만 쓴다.

## 후속연구 지점

1. **흰 점 선택의 합성 불일치를 장애 (코사이클) 로 재기술.** 무엇을: 명제 1.1 의 실패를 "$\mathbf{Ref}$ 의 각 인수분해에 대한 흰 점 강제값의 차이" 로 정식화하고, 그 차이를 $H^1$ 형 장애 (또는 Čech 2-코사이클) 로 읽을 수 있는지 확인. 왜: 이것이 R07 O5 (고차 장애) 에 대한 첫 구체적 대상이다. 시작 방법: 예 1.0 의 $\bar u$ 에서 두 강제값의 차이를 기록하고, 3-조각 정련 $\sigma$ 의 흰 점을 쌓아 가는 2-단계 사상에 대해 같은 계산을 반복. 난점: 올림 집합이 torsor 가 아니라 (명제 1.5) 일반 집합 위의 장애를 정의해야 한다.
2. **Ψ 의 생성원과 자기사상 분류.** 무엇을: 작은 $D$ (예: $\mathfrak M(D_b)$, $\mathfrak M(K_3)$ 계열) 에 대해 $\mathrm{End}_\Psi$ 를 정리 2.4 의 데이터로 전수 기술하고, 흰형 블록 사상이 어떤 정련 올림의 합성으로 얻어지는지 (또는 얻어지지 않는지) 판정. 왜: 예 2.7 의 3 개 자기사상 중 하나가 정련 올림의 합성인지가 "Ψ 가 정련 올림으로 생성되는가" 의 핵심이다. 시작 방법: r09_full.py 를 확장해 $\mathrm{End}_\Psi(\mathfrak M(D))$ 를 $D$ 의 조각 수 2–3 에 대해 세고, 정리 2.4 의 흰형 집합을 따로 기록. 난점: 흰형 블록은 $\mu_D\ge2$ 와 $|F_D|\ge2$ 를 요구하므로, 조건을 만족하는 $D$ 의 종류가 제한적이다.
3. **블록 함자 $\theta$ 의 평면성·색칠수 전달.** 무엇을: 명제 1.3 의 블록 사상 $\theta_\sigma$ 가 $\chi$ 와 평면성 판정 (R03–R06) 에 대해 어떤 부등식을 주는지 확인. 왜: 블록 수준은 흰 점이 없으므로 $\chi$ 의 $\mathrm{Gr}_s$ 해석 (R07 정리 5.1) 과 직접 맞물릴 수 있다. 시작 방법: 예 2.6 (ab|cd) 와 $K_4=C_4\cup C_4$ (R07 예) 를 블록 수준으로 쪼개고, 블록 사상의 색칠 전달 (블록 $\mathrm{Col}_q$ 의 극한) 을 계산. 난점: 블록 사상은 조각을 연결 성분으로 쪼개므로 평면성 자체가 블록 단위로 바뀌지 않는지 확인해야 한다 (블록은 평면 조각의 부분그래프이므로 평면이다 — 이 부분은 증명됨).
4. **단사 정련 범주의 흰 점 함자를 확장할 조건.** 무엇을: 명제 1.2 를 "각 정점 $v$ 에서 $\Pi'(v)\to\Pi(v)$ 가 단사" 같은 국소 조건으로 약화하고, 그 조건에서도 흰 점 강제가 유일하며 함자인지 판정. 왜: 단사 조건은 너무 강하다 (예 3.3 의 삼각형 정련은 단사가 아니다). 시작 방법: 명제 1.2 의 증명에서 쓴 단사성의 실제 사용처 ($|F_D(v)|\ge|\Pi'(v)|$ 와 $\mu_D\ge\mu'$) 를 따로 떼어 국소 조건으로 쓴다. 난점: $\mu_D\ge\mu'$ 가 국소 조건으로 가능한지 불분명하다 (두 조각이 같은 변을 가질 때 인덱스 충돌이 생긴다).
