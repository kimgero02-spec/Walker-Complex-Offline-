## 설정 (공통 가정 $\mathcal A$)
리본 설명서(R01 정의 3)에서 **핀치 허용**: 한 조각 경계 위 두 호가 끝점 하나를 공유해도 된다. 대신 다음을 가정한다. 조립 2-복합체 $X$ 가 곡면이고, 경계 $\partial X$ 가 골격 $K=\bigcup_k C_k$ 안의 **단순 사이클 하나** $W$ 이다($b=1$). 서로 다른 조각은 호와 핀치 정점에서만 만난다. $m=|E(H)|$(호 수), $n$ = 조각 수.
- **엇갈림 그래프 $I$**: 점 = 호. 두 호의 끝점 4개가 서로 다르고 $W$ 위에서 번갈아 나오면 변으로 잇는다(끝점 공유 = 엇갈리지 않음).
- **행렬 $Q$** ($\mathbb Z_2$, $m\times m$): 비대각 성분 = 섭동 엇갈림 $A_{ef}$ (핀치 끝점은 $W$ 를 걸을 때 들어오는 조각 쪽 호를 먼저 놓아 떼어 냄; 핀치가 없으면 $A$ = $I$ 의 인접행렬). 대각 성분 $Q_{ee}=w_1(\gamma_e)$. 여기서 $\gamma_e$ = 호 $\alpha_e$ + $W$ 위에서 그 두 끝점 사이 구간을 안으로 민 닫힌 곡선이고, $w_1(\gamma_e)$ 는 $\gamma_e$ 가 지나는 $H$-보행의 $\varepsilon$ 곱이다.

## 정리 U (골격 판정) `[증명]`
$\mathcal A$ 아래에서 $K=W\cup\{\alpha_e\}$ 는 평면 ⟺ $I$ 가 이분 그래프. 따라서 (i) 조각이 다각형($P_k=C_k$)이면 $G$ 평면 ⟺ $I$ 이분, (ii) 조각이 일반 원판이면 $I$ 비이분 ⟹ $G$ 비평면 (조각 내부와 무관).
*증명.* 호의 내부 정점은 두 조각에만 속하고 $W$ 에 없다. 그러므로 $K$ 는 사이클 $W$ 에 내부가 서로소인 경로(현) $m$ 개를 붙인 것이다. 끝점을 공유하는 두 현은 skew 도 아니고 공통 부착점 3개도 없다. 따라서 $W$-다리의 겹침 그래프가 정확히 $I$ 이다. 사이클 + 현의 평면성 ⟺ 겹침 그래프 이분(R01 r2 보조정리 B2, 같은 증명). (ii)는 $G\supseteq K$ 에서 나온다. ∎
- **따름** `[증명]`: r2 정리 B = $X$ 가 뫼비우스 띠인 경우($I$ = 끝점공유 그래프의 여그래프). r1 정리 D = 핀치 없는 뫼비우스 띠: $I=K_n$ 이므로 $n\ge3$ 에서 비이분. $K_4$ 예외 = $K_2$ 는 이분. r3 의 $K_5$(삼각형 5개)도 핀치 뫼비우스 띠이며 $I=C_5$ 로 비이분이다 `[계산 확인]`.
- **홀로노미의 자리**: 홀로노미는 "$W$ 가 어떻게 감기는가"를 통해서만 $I$ 에 들어간다. 판정자는 $I$ 의 이분성이다.

## 정리 R (교차형식) `[증명, 고전 사실 2개 사용: Lefschetz 쌍대성(Z₂), Wu 공식 $x\cdot x=\langle w_1,x\rangle$ — `[기억-미검증]` 이지만 표준]`
$\mathcal A$ 아래에서 $\operatorname{rank}_{\mathbb Z_2}Q=\dim H_1(X;\mathbb Z_2)=1-\chi(X)=m-n+1$ 이다. 특히 $X$ 가 가향이면 $Q=A$ 이고 $\operatorname{rank}A=2g(X)$ 이다.
*증명.* $Q$ 는 $\{\gamma_e\}$ 의 교차형식 Gram 행렬이다. 비대각 성분이 맞는 이유: $\gamma_f$ 의 상대류는 $[\alpha_f]$ 이고, 민 구간은 $\alpha_f$ 의 끝점마다 한 번씩 $\alpha_f$ 를 가로지른다. 대각 성분은 Wu 공식에서 나온다. $b=1$ 이면 $H_1(X)\to H_1(X,\partial X)$ 가 동형이고($[W]=\partial X=0$), $\gamma_e\mapsto[\alpha_e]$ 이다. 또 $[\alpha_e]$ 들은 $H_1(X,\partial X)\cong\mathrm{Hom}(Z(H),\mathbb Z_2)$ 의 좌표 범함수들이므로 전체를 생성한다. 그러므로 $\gamma_e$ 들은 $H_1(X)$ 를 생성하고, 형식이 비퇴화이므로 Gram 행렬의 rank 는 $\dim H_1$ 이다. ∎
- `[계산 확인]` 7개 예에서 $\operatorname{rank}Q=m-n+1$. 뫼비우스 띠 $k=3,4$: $Q=J$(전부 1) 로 rank 1 인데 **대각을 뺀 $A$ 는 rank 2, 4**. 즉 대각 보정 $w_1$ 이 꼭 필요하다. 엇갈림 토러스(R01): rank 2 = $2g$.
- **det/rank 질문에 대한 답(초안)**: $\operatorname{rank}Q$ 는 $X$ 의 위상(종수)을 잰다. 평면성은 rank 가 아니라 **$\mathbb Z_2$ 선형계의 해 존재**로 잰다: $x_e+x_f=1$ ($ef\in E(I)$) 이 풀린다 ⟺ $I$ 이분. 두 양은 독립적이다. 엇갈림 토러스는 $\operatorname{rank}Q=2$ 인데 $G$ 가 평면이고, 뫼비우스 $k=3$ 은 rank 1 인데 비평면이다.

## 정리 N2 ($n=2$ 뫼비우스 띠) `[증명; 다리 동시 매장 보조정리는 고전 (기억-미검증)]`
원판 조각 2개, 서로소 호 $\alpha,\beta$ 를 공유하고 $P_1\cap P_2=\alpha\cup\beta$, 홀로노미 $-1$ 이라 하자. 그러면 $K=C_1\cup C_2$ 는 $TK_4$ 이고, 평면 그림의 면은 정확히 4개의 "삼각형" $T_F$ 이다(Euler: $F=4$, 둘레 합 12). 각 면은 (호 하나, $P_1$ 레일 하나, $P_2$ 레일 하나) 로 이루어진다. 이때
$G$ 평면 ⟺ $P_k$ 의 각 $C_k$-다리 $B$ 를 면 $F(B)$ 에 배정해서 (i) 부착점 $S_B\subseteq T_{F(B)}\cap C_k$ = $C_k$ 의 **모서리 경로**(이웃한 두 변의 합)가 되게 하고, (ii) 같은 면에 놓인 $P_1$-다리와 $P_2$-다리가 $T_F$ 에 대해 겹치지 않게(skew 이거나 공통 부착점 3개인 경우가 없게) 할 수 있다.
같은 조각의 다리끼리는 자동으로 겹치지 않는다(모서리 경로가 $C_k$ 와 $T_F$ 의 공통 부분경로이기 때문).
- 따름 `[증명]`: 다리가 두 레일 내부에 닿으면(R01 보조정리 6), **두 호 내부에 닿으면**(피터슨: 현 $5\!-\!8$), 또는 분기점 4개 모두에 닿으면($K_5$: 중심) 비평면이다. 한 조각이 다각형이면 조건 (i)만 남는다.
- `[계산 확인]` $K_4$, $K_5=W_4\cup C_4$, 피터슨 2조각, 그리고 결정적 쌍(현 $p\!-\!s$ | $q\!-\!t$ 는 같은 면에서 skew 이므로 비평면, $q\!-\!s$ | $p\!-\!t$ 는 평면)에서 판정과 실제 평면성이 일치. 이 쌍은 (i)만으로는 부족하고 (ii)가 필요함을 보인다.

## 공격 요청
