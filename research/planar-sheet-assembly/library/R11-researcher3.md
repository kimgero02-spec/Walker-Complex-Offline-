## 요약
- **(1) ω 는 장애의 1차 항일 뿐이다.** 함자 올림의 존재를 정확히 판정하는 **폐포 위계** $S^{(1)}\subseteq S^{(2)}\subseteq\cdots$ 를 정의했다. 함자가 있다 ⟺ $S^{(\infty)}$ 가 죽임 강제 사상과 만나지 않는다 (정리 1.3). 있으면 $S^{(\infty)}$ 의 지표가 **최소 함자**이다. R10 의 $\omega$ 는 1단계 충돌과 정확히 같다. [증명]
- **(2) 위계는 엄밀하다.** 모든 $k\ge2$ 에 대해, 1단계부터 $k-1$ 단계까지는 충돌이 없고 ($\omega\equiv0$ 포함) $k$ 단계에서 처음 충돌하는 $\mathcal R_{\rm adm}$ 의 부분범주가 있다. 고립점 6개 ($k=2$) 의 그래프 위에 "사각형 사슬" 로 짓는다 (정리 1.5). 이것으로 R10 장애물 O2 ("ω≡0 이면 충분한가") 는 **아니오**로 닫힌다. [증명] [계산 확인 $k=2,3,4$]
- **(3) 살림 강제는 인수에 유전된다** (보조명제 1.2). 그래서 충돌은 언제나 "자유로운 중간 사상" 을 거쳐 전파된다. 위계의 단계 수는 강제 정보가 자유 사각형을 몇 번 건너야 하는지를 센다. [증명]
- **(4) 접착 사이클 불변량** $\rho(G):=\min_D r(D)$ (모든 평면분해에 대한 최솟값). $\rho(G)=0\iff G$ 평면, $\gamma(G)\le\rho(G)\le\mathrm{sk}(G)$ (종수, 비틀림수 = 평면으로 만들려고 지울 변의 최소 수), 부분그래프 단조, $\chi(G)\le\min_D(b(D)+r(D))$. 오일러형 하계 $\rho(G)\ge\lceil(|E|-3|V|+3c+4)/3\rceil$ (비평면일 때) 와 삼각형 없는 판 $2\rho\ge|E|-2|V|+2c+2$ 를 얻었다. $3\le\rho(K_7)\le4<6=\mathrm{sk}(K_7)$. [증명, 오일러 변 상계·곡면 사실은 기억-미검증] [계산 확인]

## 본문

### 0. 규약 (R10 과 같음)
- $\mathcal C\subseteq\mathcal R_{\rm adm}$ 는 부분범주. 점 $v$ 와 사상 $f:D'\to D$ 에 대해 $f$ 의 $v$ 에서의 상태는 **강제 1** (v 의 $\Gamma'$-성분에 불순 점이 있음), **강제 0** (성분이 (β) 를 어기거나 $v\notin W(D)$), **자유** 중 하나이다 (R10 정리 1.1). "$v$ 에서 허용" = 강제 0 이 아님.
- 함자 올림 ⟺ 각 $v$ 마다 집합 $S_v\subseteq\mathrm{Mor}\,\mathcal C$ ($\varepsilon(f)(v)=1$ 인 사상들) 가 다음을 만족하는 것 (R10 따름 1.2b 를 다시 쓴 것):
  (F1) 강제 1 ⊆ $S_v$, 강제 0 ∩ $S_v=\varnothing$;
  (F2) **소 부분범주**: $gf\in S_v\iff f\in S_v$ 이고 $g\in S_v$;
  (F3) **결합**: $f:D'\to D$ 이고 $v,v'$ 가 $\Gamma'$ 의 같은 성분이면 $f\in S_v\iff f\in S_{v'}$.
  [증명] (F2) 는 AND 규칙 $\varepsilon(gf)=\varepsilon(f)\wedge\tilde\varepsilon(g)$ 그대로이다. $v\notin W(D')$ 인 경우, 즉 $\tilde\varepsilon(g)(v)=0$ 인 경우는 $f$ 가 $v$ 에서 강제 0 이므로 (F1) 에 의해 $f\notin S_v$ 이다. (F3) 은 정리 1.1 의 "성분 상수" 이다.

### 1. 흰 점 장애의 완전한 위계 (R10 후속 1)

#### 1.1 허용과 강제의 합성 성질

**보조명제 1.1 (허용은 합성에 닫혀 있다).** $f:D''\to D'$, $g:D'\to D$ 가 $v$ 에서 허용이면 $gf$ 도 $v$ 에서 허용이다.
*증명.* $f$ 가 허용이면 $v$ 의 $\Gamma''$-성분 $K$ 가 $f$ 에 대해 (β) 를 만족하거나 모두 순수이다.
(i) $K$ 가 $f$ 에 대해 (β) 를 만족하는 경우: $K$ 의 변 $e$ 는 $\mu'(e)\ge2$ 이므로 $\Gamma'$ 의 변이고, $K$ 의 점은 $W(D')$ 에 있다. 그러므로 $K$ 는 $v$ 의 $\Gamma'$-성분 $K'$ 안에 있다. $g$ 가 허용이면 (흰 점 선택이 가능하다는 뜻이므로) $K'$ 는 $g$ 에 대해 (β) 를 만족한다. 따라서 $K$ 의 점은 $|F_D|\ge2$, 변은 $\mu_D\ge2$ 이다.
(ii) 허용을 "흰 점 값이 가능" 으로 읽으면 (i) 만 필요하다. 허용이 강제 0 의 부정, 즉 (β) 만족이므로 (i) 로 충분하다. □
(정확히는 "허용 ⟺ $K$ 가 (β) 만족" 이다. 모두 순수이면서 (β) 를 어기면 강제 0 이기 때문이다.)

**보조명제 1.2 (살림 강제는 인수에 유전된다).** $\pi=gf$ 가 $v$ 에서 강제 1 이면 $f$ 와 $g$ 도 $v$ 에서 강제 1 이다.
*증명.* $\pi$ 의 $\Gamma''$-성분 $K\ni v$ 에 $\pi$-불순 점 $x$ 가 있다. $f$ 가 $\Pi''(x)$ 위에서 상수이면 $\pi$ 도 상수이므로, $x$ 는 $f$-불순이다. 그러므로 $f$ 는 $v$ 에서 강제 1 이다 ($\Gamma''$ 는 $f$ 와 $\pi$ 에 공통). $f\in\mathcal R_{\rm adm}$ 이므로 불순 점이 있는 성분 $K$ 는 $f$ 에 대해 (β) 를 만족한다 (R8-1). 따라서 $K\subseteq K'$ ($v$ 의 $\Gamma'$-성분) 이다 (보조명제 1.1 의 (i)). $\pi$ 가 $\Pi''(x)$ 위에서 상수가 아니므로 $g$ 는 $f(\Pi''(x))\subseteq\Pi'(x)$ 위에서 상수가 아니다. 즉 $x$ 는 $g$-불순이고 $x\in K'$ 이므로 $g$ 는 $v$ 에서 강제 1 이다. □

역은 거짓이다: R09 예 1.0 의 $\sigma\tau$ 는 두 인자가 강제 1 인데 합성은 자유이다. 이 비대칭이 아래 위계의 원천이다. [증명]

#### 1.2 폐포 위계

$\mathcal S=(S_v)_v$ 에 대해 다음 세 연산을 정의한다. $\mathrm{Comp}$ = 합성 닫힘 ($f,g\in S_v$, $gf$ 정의됨 ⟹ $gf\in S_v$), $\mathrm{Fact}$ = 인수 닫힘 ($gf\in S_v$ ⟹ $f,g\in S_v$, $\mathcal C$ 안의 모든 인수분해에 대해), $\mathrm{Coup}$ = (F3) 닫힘.
- $S^{(1)}:=\mathrm{Comp}(\text{강제 1}\cup\text{항등})$.
- $S^{(k+1)}:=\mathrm{Comp}\bigl(\mathrm{Coup}(\mathrm{Fact}(S^{(k)}))\bigr)$.
- $S^{(\infty)}:=\bigcup_kS^{(k)}$.
- **$k$ 단계 충돌**: $\mathrm{Fact}(S^{(k)})_v$ 안에 $v$ 에서 강제 0 인 사상이 있는 것.

**보조명제 1.2b (충돌은 Fact 단계에서만 생긴다).** $\mathrm{Fact}(S^{(j)})$ 에 충돌이 없으면 $S^{(j+1)}$ 의 모든 원소는 허용이다. [증명] 허용은 성분 단위의 성질이라 Coup 가 보존하고, 합성에도 닫혀 있다 (보조명제 1.1). $S^{(1)}$ 은 허용인 강제 1 사상들의 합성이므로 허용이다.

**명제 1.2a.** 1단계 충돌의 존재 ⟺ R10 의 $\omega\not\equiv0$. [증명] $S^{(1)}_v$ 는 정확히 "강제 1 사상들의 합성" 이므로 $\alpha(\pi)(v)=1\iff\pi\in S^{(1)}_v$ 이다 (R10 보조명제 1.3a). 또 $\zeta(\pi)(v)=1\iff\pi$ 의 어떤 인수분해에 $v$ 에서 강제 0 인 인자가 있다. 그러므로 $\omega(\pi)(v)=1$ ⟺ $\pi\in S^{(1)}_v$ 의 어떤 인수가 강제 0 ⟺ $\mathrm{Fact}(S^{(1)})_v$ 에 강제 0 이 있다. □

**정리 1.3 (완전 판정).** $\mathcal C$ (유한) 위에 함자 올림이 있다 ⟺ 어떤 단계에서도 충돌이 없다. 이때 $\varepsilon(f)(v):=[f\in S^{(\infty)}_v]$ 가 함자이고, 모든 함자 $\Lambda$ 에 대해 $S^{(\infty)}_v\subseteq S^\Lambda_v$ 이다 (**최소 함자**).
*증명.* (⟹) 함자 $\Lambda$ 의 $S^\Lambda$ 는 (F1)–(F3) 을 만족하므로 강제 1 과 항등을 포함하고 Comp, Fact, Coup 에 닫혀 있다. 귀납으로 $S^{(k)}\subseteq S^\Lambda$ 이다. $S^\Lambda$ 는 강제 0 과 만나지 않으므로 충돌이 없다. (⟸) $\mathcal C$ 가 유한이면 위계는 어떤 단계에서 멈추고, $S^{(\infty)}$ 는 세 연산에 닫혀 있다 (특히 $\mathrm{Fact}(S^{(\infty)})=S^{(\infty)}$ 이므로 "충돌 없음" 은 $S^{(\infty)}$ 가 강제 0 과 만나지 않음과 같다). 그러면 (F2) 와 (F3) 이 성립한다. (F1) 의 앞쪽은 정의에서, 뒤쪽은 충돌이 없다는 가정에서 나온다. 정리 1.1 의 상 조건을 확인한다. 성분 상수는 Coup 에서, 강제 1 ⟹ 1 은 정의에서, 강제 0 ⟹ 0 은 충돌 없음에서 나오고, 나머지는 자유이다. 최소성은 (⟹) 의 귀납이다. □
R10 정리 1.5 의 (P*) 는 $S^{(1)}$ 이 이미 Fact 에 닫혀 있다 (즉 $S^{(2)}=S^{(1)}$) 는 조건이다. 무한 $\mathcal C$ 에서는 $S^{(\infty)}$ 가 합집합이고 세 연산이 유한 조건이므로 같은 증명이 된다. [증명]

**뜻.** 장애는 하나의 값 $\omega$ 가 아니라 **전파 과정**이다. 살림 강제 정보는 합성으로 퍼진다. 인수로 내려갈 때에는 자유 사상이 $S$ 에 끌려 들어온다 (보조명제 1.2 의 역이 거짓이기 때문). 그 자유 사상이 다른 사상과 합성되어 새 사각형으로 넘어간다. 충돌이 날 때까지 건넌 사각형의 수가 장애의 차수이다.

#### 1.3 위계의 엄밀성: 사각형 사슬

**구성 1.4 ($k$ 단계 사슬).** $G$ := 점 $u$ 와 꼬리표 점 $a_\ell,b_\ell$ ($\ell$ = 아래 하층 대상마다 한 쌍) 로 된 고립점 그래프. 각 대상은 ($u$ 의 $K_1$ 조각 $n_u$ 개) + (꼬리표 분할: 꼬리표 점들을 $K_1$ 조각 또는 $\{a_\ell,b_\ell\}$ 조각으로 묶은 것) 이다. 꼬리표 점은 늘 한 조각에만 있어 흰 점이 되지 않는다. 하층 대상 $D_3,X_1,\dots,X_{k-1},Z$ 는 자기 쌍 하나만 묶고, 상층 대상 $D_1,Y_1,\dots,Y_{k-1}$ 은 아래에 놓일 대상들의 쌍을 묶는다. $D_2$ 는 아무것도 묶지 않는다. 그러면 필요한 꼬리표 정련이 존재하고 유일하며, 대상들은 모두 다르다. $u$ 부분의 사상 (조각 번호의 함수) 은 다음과 같다.
$$\tau:D_2\to D_3=(1,2),\quad \sigma:D_3\to D_1=(1,1,2),\quad p_i:D_2\to X_i=(1,1),$$
$$q_1:X_1\to D_1=(1,2),\quad q_{i+1}:X_{i+1}\to Y_i=(1,2),\quad h_i:X_i\to Y_i=(1,2),\quad t:D_2\to Z=(1,1),\quad s:Z\to Y_{k-1}=(1).$$
$n_u$: $D_2,X_i,D_1,Y_i$ 는 2, $D_3$ 는 3, $Z$ 는 1. 사각형:
$$\sigma\tau=q_1p_1,\qquad h_ip_i=q_{i+1}p_{i+1}\ (1\le i\le k-2),\qquad h_{k-1}p_{k-1}=st.$$
$\mathcal C_k$ := 이 사상들이 생성하는 부분범주.

**정리 1.5.** $\mathcal C_k$ 에서 $1,\dots,k-1$ 단계 충돌은 없고 ($\omega\equiv0$ 포함) $k$ 단계에서 충돌한다. 따라서 $\mathcal C_k$ 위에 함자 올림은 없다.
*증명.* (조합 구조) 대상이 모두 다르므로 합성 가능한 쌍은 $(\sigma,\tau)$, $(q_1,p_1)$, $(h_i,p_i)$, $(q_{i+1},p_{i+1})$, $(s,t)$ 뿐이다. 합성 사상은 사각형의 대각선 $\pi_0:=\sigma\tau$, $\kappa_i:=h_ip_i$ 뿐이다. 모든 조각이 변이 없어 $\Gamma$ 가 비어 있다. 그러므로 결합 (F3) 은 자명하고 모든 정련이 올림 가능하다 (R08 계 (ii)). 유일한 흰 점은 $u$ 이다.
(상태) $\tau,\sigma,q_i,h_i$ 는 $u$ 에서 비상수이므로 강제 1. $p_i,t$ 는 상수이다. $p_i$ 는 $X_i$ 에 $u$ 복사가 둘이라 자유, $t$ 는 $Z$ 에 하나뿐이라 강제 0. $s$ 는 원천에 흰 점이 없다. 대각선 $\pi_0,\kappa_i$ 는 상수 사상이고 목표에 복사가 둘이므로 자유.
(위계) $S^{(1)}=\{\text{항등},\tau,\sigma,q_i,h_i,\pi_0\}$ (강제 1 끼리의 합성은 $\sigma\tau=\pi_0$ 뿐). $\mathrm{Fact}(S^{(1)})$ 은 $\pi_0$ 의 인수분해 $(q_1,p_1)$ 에서 자유인 $p_1$ 을 더할 뿐이므로 1단계 충돌이 없고, $S^{(2)}$ 에는 합성 $\kappa_1=h_1p_1$ 이 들어온다. 귀납: $j\le k-1$ 에서 $S^{(j)}\ni\kappa_{j-1}$ 이다 ($\kappa_0:=\pi_0$). $j\le k-1$ 이면 $\mathrm{Fact}(S^{(j)})$ 는 $\kappa_{j-1}$ 의 인수분해 $(q_j,p_j)$ 에서 자유인 $p_j$ 를 더하므로 충돌이 없고, $S^{(j+1)}$ 에는 $\kappa_j=h_jp_j$ 가 들어온다. $j=k$ 에서는 $\mathrm{Fact}(S^{(k)})$ 가 $\kappa_{k-1}=st$ 의 인수 $t$ 를 더하는데, $t$ 는 강제 0 이다. 이것이 $k$ 단계 충돌이다.
($\omega\equiv0$) R10 의 $\omega$ 는 각 사각형에서 두 인수분해의 강제값만 본다. $\pi_0$ 에서는 (σ,τ) 가 살림 강제이지만 $(q_1,p_1)$ 은 강제가 없다 ($p_1$ 자유). $\kappa_i$ ($i\le k-2$) 에서는 두 인수분해 모두 강제가 없다. $\kappa_{k-1}$ 에서는 $(s,t)$ 가 죽임 강제이지만 $(h_{k-1},p_{k-1})$ 은 강제가 없다. 따라서 어떤 사상에서도 살림 강제와 죽임 강제가 동시에 일어나지 않는다. □

손으로 따라가면 모순은 이렇다: $\varepsilon(\pi_0)=1$ ⟹ $\varepsilon(p_1)=1$ ⟹ $\varepsilon(\kappa_1)=1$ ⟹ $\varepsilon(p_2)=1$ ⟹ $\cdots$ ⟹ $\varepsilon(\kappa_{k-1})=1$, 그런데 $\varepsilon(\kappa_{k-1})=\varepsilon(t)\wedge\cdot=0$.

[계산 확인] $k=2,3,4$ 에서 실제 매뉴얼 그래프 위의 $L$ 집합으로 모든 선택을 열거했다. 함자적 선택의 수는 0 이고, 각 사각형의 두 인수분해 상은 위의 강제 패턴과 일치한다 ($k=2$: $\pi_0$ 에서 $\{w\}$ 대 $\{c,w\}$, $\kappa_1$ 에서 $\{c,w\}$ 대 $\{c\}$). (r11_lvl2.py, r11_lvlk.py)

**해석.** "평탄 접속" 의 비유 (R10 §1.3) 로 말하면, $\omega$ 는 사각형 하나의 곡률이다. 정리 1.5 는 각 사각형의 곡률이 0 이어도 사각형 사슬을 따라 홀로노미가 쌓이는 경우가 있다는 것이다. 군 값 홀로노미와 다른 점은, 자유 사상에서는 값이 정해지지 않고 **전파되기만** 한다는 것이다.

### 2. 접착 사이클 불변량 $\rho(G)$ (R10 후속 3)

#### 2.1 정의와 기본 성질

$\rho(G):=\min\{r(D): D\text{ 는 }G\text{ 의 평면분해}\}$. $r(D)=\beta_1(I(D))$ (R10 §2.0).

**명제 2.1.** [증명]
(a) $\rho(G)=0\iff G$ 평면. (⟸: $D=(G)$ 는 허브가 없다. ⟹: R10 명제 2.4. 1-합 보조 사실은 [기억-미검증].)
(b) $\chi(G)\le\min_D\bigl(b(D)+r(D)\bigr)$ (R10 정리 2.5). 4색정리를 쓰면 $\chi(G)\le4+\rho(G)$ [기억-미검증: 4색정리].
(c) **부분그래프 단조**: $H\subseteq G$ 이면 $\rho(H)\le\rho(G)$.
(d) $\rho(G)\le\mathrm{sk}(G)$. 여기서 $\mathrm{sk}$ 는 $G-F$ 가 평면이 되는 변 집합 $F$ 의 최소 크기이다.

*증명 (c).* 변 하나를 지우는 경우와 점 하나를 지우는 경우만 보면 된다. 변 $e$ 를 모든 조각에서 지우면 조각은 평면으로 남는다. $e$ 를 가진 블록은 다음 둘 중 하나가 된다. (i) $\beta_1$ 이 1 줄고 점 집합이 그대로이면 $I$ 는 변하지 않는다. (ii) 두 블록으로 쪼개지면 $I$ 의 블록 점 하나가 둘로 갈라지고, 그 점의 허브 접속이 둘로 나뉜다 (새 허브는 생기지 않는다). 점을 가르면 $|E(I)|$ 는 그대로, $|V(I)|$ 는 1 늘고, $c(I)$ 는 많아야 1 늘므로 $\beta_1(I)$ 는 늘지 않는다. 점 $v$ 를 지우면 $I$ 에서 허브 $v$ (차수 $d$) 를 지운다. 이때 $\beta_1$ 의 변화는 $-d+1+(c'-c)\le0$ 이다 ($c'-c\le d-1$). 그 밖에 블록 점이 갈라지거나 (위와 같이 비증가) $K_1$ 블록이 사라진다 (잎 또는 고립점을 지우므로 $\beta_1$ 불변). □
*증명 (d).* $G-F$ 를 한 조각, $F$ 의 변 각각을 $K_2$ 조각으로 둔다. 블록 $K_2$ 마다 $I$ 의 변이 많아야 2 개 늘고 점은 1 개 는다. 그러므로 $r\le|F|$ 이다. □

#### 2.2 하계: 오일러형

**정리 2.2.** $G$ 가 고립점 없이 연결이고 비평면이라 하자. 그러면 모든 평면분해 $D$ 에 대해
$$3\,r(D)\ \ge\ |E|-3|V|+3+2B,\qquad B:=\#\{\text{점이 2개 이상인 블록}\}\ge2.$$
따라서 $\rho(G)\ge\lceil(|E|-3|V|+7)/3\rceil$. $G$ 에 삼각형이 없으면 $2\,r(D)\ge|E|-2|V|+2+B$, 따라서 $\rho(G)\ge\lceil(|E|-2|V|+4)/2\rceil$.

*증명.* $K_1$ 블록 $\{v\}$ 를 지운다. 고립점이 없으므로 $v$ 는 다른 블록에도 있고, 지워지는 것은 $I$ 의 잎이므로 $r$ 은 그대로이다. 남은 블록은 점이 2개 이상인 연결 평면 그래프이다.
평면 단순 그래프에서 $|E|\le3|V|-6$ ($|V|\ge3$) [기억-미검증: 오일러 공식의 귀결] 이므로, 점이 2개 이상인 블록마다 $\beta_1(\beta)\le2|V(\beta)|-4$ 이다 ($|V|=2$ 이면 $0\le0$).
R10 보조명제 2.3 의 계산에서 $\sum_\beta|V(\beta)|=|V|+|E(I)|-|W_B|$ 이고 $r=|E(I)|-|W_B|-B+1$ 이다. 그러므로
$$\sum\beta_1(\beta)\le2(|V|+|E(I)|-|W_B|)-4B=2|V|+2(r+B-1)-4B.$$
또 $\beta_1(G)\le\beta_1(G^\sharp)=r+\sum\beta_1(\beta)$ 이므로 $|E|-|V|+1\le3r+2|V|-2B-2$ 이고, 이것이 첫 부등식이다.
$B\ge2$ 인 이유: $B=1$ 이면 모든 변이 한 블록에 있어 $G$ 가 평면이다.
삼각형이 없으면 블록도 삼각형이 없다 (부분그래프). 그러면 $|E|\le2|V|-4$ [기억-미검증] 이므로 $\beta_1(\beta)\le|V(\beta)|-2$ 이고, 같은 계산이 둘째 부등식을 준다. □

**예 2.3.** [증명: 정리 2.2] [계산 확인: 상계]
- $K_5$: 하계 $\lceil 2/3\rceil=1$, 분해 $(K_5-e,K_2)$ 가 $r=1$ 이므로 $\rho=1$.
- $K_{3,3}$: 삼각형 없는 판의 하계 $\lceil1/2\rceil=1$, $(K_{3,3}-e,K_2)$ 로 $\rho=1$.
- $K_7$: 하계 $\lceil7/3\rceil=3$. 상계는 두 조각 분해 (극대 평면 $P_1$ 15변, 나머지 6변 $H$; $H$ 는 점 5개, 차수 $3,3,2,2,2$ 로 연결) 의 $r=|V(H)|-c(H)=4$ 이다 (r11_k7.py: 이 형태의 두 조각 분해에서 가능한 $r$ 은 $4,5,6$ 뿐). 따라서 $3\le\rho(K_7)\le4<6=\mathrm{sk}(K_7)$ ($\mathrm{sk}=21-15$ [증명: 극대 평면 변 수 $3\cdot7-6$, 기억-미검증]).
- $K_{4,4}$: 하계 $\lceil4/2\rceil=2$.
- $K_n$: $\rho(K_n)\ge(n^2-7n+14)/6$. 비틀림수는 $\binom n2-3n+6$ 이므로 둘 다 $n^2$ 차수이고, 상수 비는 $1/6$ 대 $1/2$ 이다.

**$\chi$ 와의 비교.** $K_n$ 에서 $\chi=n\le b+r$ 이 주는 하계 $r\ge n-b$ 는 선형이다. 정리 2.2 의 하계는 이차이므로 훨씬 강하다. 즉 $K_n$ 에서 $\chi\le b+r$ 은 $r$ 쪽에서 크게 느슨하다. 정리 2.2 를 통한 $\chi$ 의 상계는 이 방향에서 쓸모가 없고, $\chi\le b+r$ 이 날카로운 영역은 $r$ 이 작은 경우 (R10 예 2.9: 한 쌍 접합) 이다. [증명]

#### 2.3 종수 상계

**정리 2.4.** 모든 평면분해 $D$ 에 대해 $\gamma(G)\le r(D)$ 이다 ($\gamma$ = 가향 종수). 따라서 $\gamma(G)\le\rho(G)$.
*증명.* $T$ 를 $I(D)$ 의 생성 숲이라 하자. 블록들을 $T$ 의 접속만으로 붙인 그래프 $G_0$ 를 만든다. 즉 허브 $v$ 의 복사들 가운데 $T$ 의 변으로 $v$ 에 이어진 블록의 복사만 하나로 묶는다. $T$ 가 숲이므로 $G_0$ 는 반복된 1-합이고 평면이다 [기억-미검증: 1-합 보조 사실].
$T$ 에 없는 $I$ 의 변 $(v,\beta)$ 는 정확히 $r(D)$ 개이고, 각각은 $G_0$ 에서 따로 남은 복사 $(v,\beta)$ 하나를 $v$ 의 묶음과 합치는 일이다. 합칠 두 점은 같은 연결 성분에 있다 ($T$ 의 생성성). 종수 $g$ 곡면에 그려진 그래프에서 같은 성분의 두 점을 합치려면 손잡이 하나를 붙이고, 그 손잡이를 지나는 변을 그린 뒤, 그 변을 수축하면 된다. 그러면 종수 $g+1$ 곡면에 그려진다 [기억-미검증: 손잡이 추가와 변 수축이 그림을 보존한다는 곡면 사실].
$r$ 번 합치면 $G^\sharp$ (R10 보조명제 2.3) 가 종수 $\le r$ 곡면에 그려지고, 평행변을 지우면 $G$ 가 된다. 합치는 두 점은 $G$ 의 같은 점의 서로 다른 복사이므로, 그 사이에 변이 없어 고리가 생기지 않는다. □
**관계 정리.** $\gamma(G)\le\rho(G)\le\mathrm{sk}(G)$. 그리고 $\rho(K_7)\ge3>1=\gamma(K_7)$ [기억-미검증: $\gamma(K_7)=1$] 이므로 첫 부등식은 엄밀할 수 있다. $\rho(K_7)\le4<6$ 이므로 둘째도 엄밀할 수 있다. [증명 (기억-미검증 사실 조건부)] [계산 확인]

### 3. 장애물 (정직하게)

- **O1 (위계의 계산 비용).** 정리 1.3 은 판정이지만, $\mathcal R_{\rm adm}(G)$ 전체는 무한 범주이다 (조각 반복이 무제한). 그 위에서는 R10 정리 1.6 에 의해 1단계에서 이미 충돌한다. 위계가 쓸모 있는 것은 유한 부분범주에서이다. 어떤 **자연스러운** 부분범주 (예: 조각 수 상한, 반복 금지) 에서 위계가 몇 단계에서 멈추는지는 모른다.
- **O2 (Γ 결합이 있는 경우).** 구성 1.4 는 변이 없는 그래프만 쓴다. 결합 (F3) 이 위계를 앞당기는지 (충돌 차수를 낮추는지), 또는 결합만으로 새 충돌이 생기는지는 확인하지 않았다.
- **O3 ($\rho$ 의 마이너 단조).** 변 수축은 같은 두 점을 변 없이 가진 조각에서 점 동일시를 일으켜 평면성을 깰 수 있다. 그래서 수축 단조성을 증명하지 못했다.
- **O4 (기억-미검증 사실).** 오일러 변 상계, 1-합 평면성, 곡면 손잡이 추가, $\gamma(K_7)=1$, 4색정리. 정리 2.2·2.4 의 증명은 이 사실들에 조건부이다. 위계 (§1) 는 교재 정의와 R08–R10 만 쓴다.

## 후속연구 지점

1. **자연 부분범주에서의 위계 길이.** 무엇을: "조각 수 $\le N$" 또는 "같은 조각 반복 금지" 로 자른 유한 부분범주 $\mathcal R^{\le N}_{\rm adm}(G)$ 에서 충돌이 처음 나는 단계를 정한다. 왜: 정리 1.5 의 사슬은 손으로 고른 부분범주이므로, 실제 설명서 범주에서 장애가 1차 ($\omega$) 로 충분한지가 중요하다. 시작 방법: $G=K_1$ (모형 = 유한집합 $[1..N]$ 과 함수) 에서 $S^{(k)}$ 를 손으로 계산한다. 이 모형에서 강제 1 = 비상수 함수, 강제 0 = 목표 크기 1 이다. 난점: 반복 금지 아래에서는 $K_1$ 모형이 퇴화하므로 변이 있는 $G$ 가 필요하다.
2. **위계와 분해 체계 (R10 후속 2) 의 연결.** 무엇을: 보조명제 1.2 (살림 강제는 인수에 유전) 를 써서, 모든 사상이 "포화 ∘ 순수" 로 쓰이는지와 그 유일성을 판정한다. 그 판정이 위계를 1단계에서 멈추게 하는지 본다. 왜: 분해 체계가 있으면 설명서의 함자적 정의가 생긴다. 시작 방법: 구성 1.4 의 $\pi_0$ 를 두 방식으로 나눠 직교성 (들어올림 성질) 을 확인한다. 난점: 순수 사상 쪽에 항등이 없다.
3. **$\rho(K_7)$ 과 $\rho(K_n)$ 의 정확한 값.** 무엇을: 세 조각 이상의 분해까지 포함해 $\rho(K_7)\in\{3,4\}$ 를 정하고, $K_n$ 에서 하계 $(n^2-7n+14)/6$ 의 차수가 맞는지 상계 구성으로 확인한다. 왜: $\rho$ 가 종수 ($\sim n^2/12$) 와 비틀림수 ($\sim n^2/2$) 사이 어디에 있는지가 "접착 복잡도" 의 크기를 정한다. 시작 방법: 정리 2.2 의 등호 조건 (모든 블록이 극대 평면, $\mu\equiv1$, 블록 수 최소) 을 만족하는 분해를 두께 2 분해에서 찾는다. 난점: 등호에는 블록들이 거의 모든 점을 공유하지 않아야 하는데, 이는 $r$ 을 키운다. 두 효과의 균형을 찾아야 한다.
4. **$\rho$ 의 마이너 단조성 또는 반례.** 무엇을: 장애물 O3 의 판정. 왜: 마이너 단조이면 $\rho\le k$ 인 그래프족이 마이너 닫힘이 되어, 금지 마이너로 특징지어진다. 시작 방법: 변 $xy$ 를 수축할 때, $x,y$ 를 변 없이 함께 가진 조각에서 $y$ 를 지우고 $y$ 의 변들을 새 $K_2$ 조각으로 옮기는 수정을 하고, $r$ 의 증가를 센다. 난점: 옮긴 $K_2$ 조각이 새 사이클을 만들어 $r$ 이 늘 수 있다.
5. **$\chi\le b+r$ 의 날카로운 영역.** 무엇을: 간극 $\chi-b$ 가 $r$ 과 같은 분해들의 특징짓기 (R10 예 2.9 의 한 쌍 접합, $K_4$ 의 $D'''$). 왜: 등호 영역에서는 설명서의 사이클 하나하나가 색 하나를 더하므로, 색칠수의 "접착 기여" 가 정확히 읽힌다. 시작 방법: $r=1$ 인 분해 (두 블록이 두 점을 공유) 에서 간극이 1 인 필요충분조건을 R03 의 2-합 결과 ($\chi\in\{m,m+1\}$) 로 쓴다. 난점: $r\ge2$ 에서는 사이클들이 독립이 아니어서 기여가 더해지지 않을 수 있다.
