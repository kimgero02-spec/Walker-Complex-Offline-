## 3. 판정의 핵심 충돌
1. **연구원1 정리 N vs 병합 평면성 읽기.** 연구원1은 𝔄 (치환 플래그) 로는 평면성이 읽히지 않는다고 했다. 병합 𝔅 는 리본 조건을 더하면 평면성을 부분적으로 읽는다고 했다. 두 결론은 서로 다른 설명서에 대한 것이라 바로 모순은 아니다. 하지만 **𝔅 에 리본 조건을 더한 경우가 𝔄 의 정리 N 쌍 E3/E4 를 피하는지** 는 확인이 필요하다. 다음 라운드의 1번 과제.
2. **중간 영역 한계.** 연구원2는 2-연결 조각에서 리본 데이터만으로는 평면성이 안 읽힌다고 했다 (R4). 병합 정리 E/D 는 3-연결과 b=1 다각형에서만 필요충분이라 했다. 두 보고서가 같은 영역을 가리키는지 확인해야 한다.
3. **고리 판.** 연구원2의 정리 2.1 고리 판은 [추측]. 병합 보고서도 충돌 1·7 에서 단순화 전후 조건과 핀치 판의 호 분해를 확인 거리로 남겼다.

## 4. 오케스트레이터 결론
- **정의:** 사상 없는 설명서 그래프 𝔅 (또는 𝔄) 와 조각 + 호 데이터 (연구원2) 는 세 독립 판 모두에서 복원을 준다. 채택 후보.
- **색칠수 읽기:** 흰–흰 간선을 지운 𝔄 의 정리 A 수열이 가장 강한 결과. 고원 정리 B 는 새 결과 후보. 일반 증명 검증이 우선.
- **평면성 읽기:** 열린 상태. 다각형 조각 + 리본 설명서에서는 샌드위치 (연구원2) 가 가장 유력하고, 3-연결에서는 정리 E. 2-연결 중간 영역과 핀치 판은 미해결.
- **정규화 질문 (문주님 결정 대기):** 여전히 열림 (STATUS 참조).
