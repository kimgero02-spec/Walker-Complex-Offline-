## 요약

1. **자명 분해.** $G$ 가 연결 평면 단순 그래프면 조각 하나 $P_1=G$, 흰 점 없음, 흰–흰 간선 없음, 경계 없음으로 쓴다. 그러면 $\mathfrak A=(V(G),\varnothing,E(G),\varnothing)$ 이고 $\mathfrak B=(V(G),\varnothing,E(G),\varnothing,\varnothing,\varnothing)$ 다. $\alpha$ 와 $\beta$ 에 독립이다 [증명]. 리본 판에는 $G$ 가 2-연결일 때만 들어간다 [증명].
2. **같은 이름 중첩.** $G_1=(V,E_1)$, $G_2=(V,E_2)$ 를 같은 정점 이름끼리 겹치면 결과는 **$G_1\cup G_2$** 다 (정점 $V$, 변 $E_1\cup E_2$) [증명]. 이 합집합은 평면이라는 보장이 없다 (예: $C_5\cup\text{오각별}=K_5$ [계산 확인 (손 계산)]).
   - 검정 복사본 $V\times\{1,2\}$ 를 그대로 두고, 공유 정점 $v$ 마다 흰 점 $w_v$ 를 두어 포트를 $(v,1),(v,2)$ 로 준다.
   - 공유 간선 $uv\in E_1\cap E_2$ 마다 흰–흰 간선 $w_uw_v$ 를 둔다. 한쪽에만 있는 간선에는 흰–흰 간선이 없다 [증명].
3. **특수 경우.** $G_1=G_2=H$ 면 모든 간선이 공유되어 $E_{\circ\circ}\cong E(H)$ 이다. 리본 판에 들어가려면 $H$ 가 사이클이어야 하고, 그때 호는 닫힌 호가 된다 [증명]. 또 $E_1\cap E_2=\varnothing$ (점만 공유) 면 흰–흰 간선이 하나도 없다 [증명].
4. **검산.** $E_2$ (F-R1): 두 사각형 $0132$, $0312$ 를 같은 이름끼리 겹치면 $K_4$ 이고, $\mathfrak A$ 는 비평면이다 [F-R1, 계산 확인]. 같은 설명서를 리본으로 읽으면 $X$ 는 뫼비우스 띠 ($\chi=0$, $b=1$), $I=K_2$ 이고 정리 D 가 평면을 준다. 결과가 정의에서 바로 읽힌다 [계산 확인 (손 계산)].
5. **발견 (정정).** 닫힌 호가 있으면 $\chi(X)=|V(H)|-|E(H)|$ 가 또 깨진다. $G_1=G_2=C_n$ 이면 $X=S^2$ 인데 공식은 $1$ 을 준다 [계산 확인 (손 계산)]. F-R6 의 "핀치 없음이면 공식 성립" 은 **닫힌 호가 없을 때만** 성립한다로 고쳐야 한다 (§4, 형식 검토 F17).

## 0. 공통 규약

- 조각 = 검정 부분그래프의 연결성분 (규약 C, F-R6). 입력 $G_i$ 의 복사본들도 연결성분마다 조각이 된다. 고립점이 복사된 것은 $K_1$ 조각이다.
- 류 $\Pi$, 포트 $\alpha(w)$, $\widehat G=\mathfrak A/\{S_w\}$, $G=\operatorname{simp}\widehat G$ 는 F-R6 §2 와 같다.
- $\mathcal D_{ww'}$ 는 F-R6 §3.3 과 같다: 쌍 $ww'$ 에서 두 포트가 어떤 조각의 간선으로 이어지는 조각들의 집합.

## 1. 경우 (1): 자명 분해

### 1.1 가정

$G=(V,E)$ 는 연결 평면 단순 그래프다. 연결이 아니면 성분마다 같은 절차를 쓴다 (조각이 성분 수만큼 생긴다). [증명: 규약 C]

### 1.2 튜플 성분 (모든 성분을 적는다)

조각은 $P_1=G$ 하나다.

| 성분 | 값 | 근거 |
|---|---|---|
| $V_\bullet$ | $V(G)$ | 모든 점이 검정 |
| $V_\circ$ | $\varnothing$ | 흰 점 없음 (포트가 필요 없다) |
| $E_{\bullet\bullet}$ | $E(G)$ | 조각 $P_1=G$ 의 간선 전체 |
| $E_{\bullet\circ}$ | $\varnothing$ | 흰 점이 없으므로 포트 간선도 없다 |
| $E_{\circ\circ}$ | $\varnothing$ | 흰 점이 없으므로 흰–흰 간선도 없다 |
| $\partial$ | $\varnothing$ (일반 층) | 리본이 아니므로 경계 표시가 필요 없다 |

- 조건 확인: (M2) 는 빈 조건이다. (M1$_{\mathrm{on}}$) 는 $G$ 가 평면이라는 가정 그대로다. (M3) 도 빈 조건이다. [증명]
- $\mathfrak A=U\mathfrak B=(V(G),\varnothing,E(G),\varnothing)$. (J1), (J2), (J4) 는 빈 조건이고 (J3$_{\mathrm{on}}$) 는 $G$ 가 평면이라는 가정이다. 따라서 $\mathfrak A\in\mathcal A_{\mathrm{on}}$ 이다. [증명]
- 류는 모두 한 원소짜리다: $\Pi=\{\{v\}:v\in V\}$. 그래서 $\widehat G(\mathfrak A)=\mathfrak A=G$ 이고 $G(\mathfrak A)=G$ 다. [증명]

### 1.3 선택에 독립

- $\alpha=\mathrm{off}$ 여도 같은 튜플이다 (조건이 더 약할 뿐이다).
- $\beta_1$: $E_{\circ\circ}=\mathcal D(\mathfrak B)=\varnothing$ 이다. $\beta_2$: $\varnothing\subseteq\mathcal D$ 이므로 같다. $\beta_3$: 저장할 것이 없어 같다. [증명]
- 따라서 세 $\beta$ 와 두 $\alpha$ 가 모두 같은 $\mathfrak B$ 를 준다.

### 1.4 리본 판 (선택적)

$\mathfrak B\in\mathcal R_{\alpha,\pi,\kappa}$ 가 되려면 (R1) 이 필요하다: $G$ 가 2-연결이고 $|V|\ge3$ 이며, $\partial=E(C)$ 가 $G$ 의 어떤 평면 매장의 바깥면 경계 사이클 $C$ 여야 한다. 흰 점이 없으므로 (R2)–(R6) 는 빈 조건이다. 따라서

$$\mathfrak B_{\mathrm{ribbon}}=(V,\varnothing,E,\varnothing,\varnothing,E(C))\in\mathcal R\iff G\ \text{는 2-연결 평면 그래프}.$$

[증명: 2-연결 평면 그래프의 각 면 경계는 사이클이다 (표준)]. 이 경우 $X=D$ (원판), $b=1$, $H$ 는 점 하나짜리 그래프, $I$ 는 빈 그래프다. 그러면 Mix 의 조건이 자명하게 성립하여 평면이 읽힌다. [증명]

### 1.5 읽기 (정의에서 바로)

- $U\mathfrak B=\mathfrak A$ 이므로 $a_t(\mathfrak A)=\chi(\mathfrak A^{(t)})=\chi(G)$ 가 모든 $t$ 에 대해 성립한다 (흰 점이 없어 $\mathfrak A^{(t)}=\mathfrak A$). 따라서 $t^*=0$ 이고, 정리 A 의 문턱은 $\chi(G)$ 다. [증명]
- 평면성: $\mathfrak A$ 평면 $\iff$ $G$ 평면 (자명). [증명]
- 이 분해는 $G$ 가 평면이든 아니든 정의가 된다. 다만 $G$ 가 평면이 아니면 (J3$_{\mathrm{on}}$) 때문에 $\alpha=\mathrm{on}$ 에서는 허용되지 않는다. $\alpha=\mathrm{off}$ 에서는 허용된다 (F-R6 §4.1, $K_5$ 조각).

## 2. 경우 (2): 같은 이름의 점끼리 중첩

### 2.1 입력

- 공통 정점 집합 $V$ 위의 단순 그래프 $G_1=(V,E_1)$, $G_2=(V,E_2)$. 두 그래프 모두 평면이라고 가정한다 (조각을 평면으로 두기 위해). 두 그래프의 연결성분을 각각 조각으로 쓴다.
- 목표: 결과 그래프 $G$ 와 설명서 $\mathfrak B$.

### 2.2 튜플 (일반 경우 $E_1\ne E_2$ 허용)

- 검정 점: $V_\bullet=V\times\{1,2\}$. 점 $(v,i)$ 는 $G_i$ 의 점 $v$ 의 복사본이다.
- 흰 점: $V_\circ=\{w_v:v\in V\}$, 점 하나당 흰 점 하나.
- 검정–검정 간선: $E_{\bullet\bullet}=\{(u,i)(v,i):\ uv\in E_i,\ i\in\{1,2\}\}$. 복사본 사이에는 간선이 없다.
- 포트 간선: $E_{\bullet\circ}=\{(v,1)w_v,\ (v,2)w_v:\ v\in V\}$. 따라서 $\alpha(w_v)=\{(v,1),(v,2)\}$ 다.
- 흰–흰 간선 ($\beta_1$, 공유 간선 규칙):
  $$E_{\circ\circ}=\{w_uw_v:\ uv\in E_1\cap E_2\}.$$
- 경계: 일반 층에서는 $\partial=\varnothing$ (또는 임의의 부분집합). 리본 판에서는 §2.6 의 조건을 따른다.
- 조각: $G_1$ 의 연결성분들과 $G_2$ 의 연결성분들. 서로 다른 복사본은 서로소다.

**왜 검정 점을 합치지 않고 흰 점으로 잇는가.** 검정 점끼리 합치면 조각이 서로소가 아니게 되어 (J2) 와 "조각 = 성분" 규약이 깨진다. 흰 점은 "같은 이름" 을 기록하는 장치다. 포트 두 개가 한 류를 이룬다.

### 2.3 조건 검증 [증명]

- (M2): 모든 $w_v$ 는 $|\alpha(w_v)|=2$ 이고 포트들은 $v$ 마다 서로소다. 같은 검정 점이 두 류에 들지 않는다.
- (M1$_{\mathrm{on}}$): 각 조각은 $G_i$ 의 성분이므로 평면이다.
- (J4): $\alpha(w_v)$ 의 두 점 $(v,1),(v,2)$ 는 서로 다른 복사본이므로 간선으로 이어지지 않는다. 고리가 없다.
- $\mathcal D$ 의 계산: $w_uw_v$ 에 대해 $D_{w_uw_v}$ 는 "$(u,i)(v,i)\in E_{\bullet\bullet}$ 를 가진 조각" 들의 집합이다. 이것은 $uv\in E_i$ 인 $i$ 들의 집합 (조각은 $i$ 로 구분된다) 이다. 따라서 $|D_{w_uw_v}|=|\{i: uv\in E_i\}|$ 다. 이 값은 $uv\in E_1\cap E_2$ 일 때만 2 다. 그러므로 $\mathcal D(\mathfrak B)=\{w_uw_v: uv\in E_1\cap E_2\}$ 이고, $\beta_1$ 의 $E_{\circ\circ}$ 와 같다. [증명]
- 따라서 $U\mathfrak B=\mathfrak A\in\mathcal A_{\mathrm{on}}$ 이다 (J3 는 $G_i$ 의 평면성).

### 2.4 결과 그래프 (정의에서 바로)

**명제 2.4.** $G(\mathfrak B)=G_1\cup G_2$ 다. [증명]

- 정점: 류 $\{(v,1),(v,2)\}$ 가 $v$ 에 대응한다. 정점 집합은 $V$ 다.
- 간선: $uv\in E_1$ 이면 조각 $1$ 의 간선 $(u,1)(v,1)$ 이 $\{[u],[v]\}=\{u,v\}$ 를 준다. $uv\in E_2$ 도 같다. 따라서 $E(G(\mathfrak B))\supseteq E_1\cup E_2$.
- 반대로 $G(\mathfrak B)$ 의 간선은 모두 어떤 조각 간선의 상이다. 따라서 $E(G(\mathfrak B))=E_1\cup E_2$.
- 고리는 없다 (§2.3).
- 흰–흰 간선 $w_uw_v$ 의 상 $\{u,v\}$ 는 이미 $E_1\cap E_2$ 에서 나오므로 $\operatorname{simp}$ 가 중복을 지운다 (보조정리 G1).

**따라서 결과는 $G_1\cup G_2$ 다.** 이것은 $G_1\cup G_2$ 가 평면인지와 무관하다. $G_1\cup G_2$ 가 평면이면 $G$ 가 평면이다.

**$G_1\cup G_2$ 가 비평면일 수 있다.** $V=\{0,\dots,4\}$, $G_1=C_5$ (간선 $i,i{+}1$), $G_2=$ 오각별 (간선 $i,i{+}2$) 면 두 그래프가 평면이고 공유 간선이 없어 $E_{\circ\circ}=\varnothing$ 다. $G=K_5$ 이다 [계산 확인 (손 계산), F-R1 E5 와 같은 종류]. 이 경우 $\mathfrak B$ 에는 흰–흰 간선이 없다.

### 2.5 공유 간선 규칙 (정리)

- **규칙 S.** 공유 간선 $uv\in E_1\cap E_2$ 마다 흰–흰 간선 $w_uw_v$ 가 정확히 하나 있다. 비공유 간선 (한쪽에만 있는 것) 에는 흰–흰 간선이 없다. [증명: §2.3]
- 이 규칙은 $\beta_1$ 이다. $\beta_2$ 에서는 공유 간선의 부분집합만 적어도 된다. $\beta_3$ 에서는 저장하지 않는다.
- 세 $\beta$ 가 $G(\mathfrak B)$ 와 색칠 읽기를 바꾸지 않는다 (보조정리 G1). 바꾸는 것은 리본 판의 호 분해뿐이다 (F-R6 §3.3 주석).

### 2.6 하위 경우

**(2a) 점만 공유 ($E_1\cap E_2=\varnothing$).** $E_{\circ\circ}=\varnothing$. 조각은 $G_1$ 과 $G_2$ 의 성분들이고, 서로 점 (흰 점) 을 통해서만 만난다. 리본 판에는 들어가지 않는다. 리본 조건 (R3) 은 $|D|=2$ 인 흰–흰 간선을 요구하기 때문이다 [증명]. 예: $C_5\cup$ 오각별 $=K_5$ (§2.4).

**(2b) 일반 ($E_1\cap E_2\ne\varnothing$, $E_1\ne E_2$).** 공유 간선마다 흰–흰 간선이 있다. 리본 판에 들어가려면 다음이 필요하다 [증명]:
- 모든 $v$ 가 두 조각 모두에서 경계 사이클 위에 있어야 한다 (R2). 곧 $G_i$ 의 각 성분이 $v$ 를 지나는 경계 사이클을 가져야 하고, 그 성분에 $v$ 가 들어 있어야 한다. 고립점은 $K_1$ 이라 리본에 못 들어간다.
- 모든 공유 간선이 두 경계 사이클의 간선이어야 한다 (R3).
- 호는 공유 간선으로 이루어진 경로들이고 (R6, $\kappa=0$), 각 흰 점은 한 호에 속한다 ($\pi=0$, $|\alpha(w_v)|=2$ 이므로 자동).

**(2c) 특수 경우 $G_1=G_2=H$.** 모든 간선이 공유되므로 $E_{\circ\circ}\cong E(H)$ 다. 결과 $G(\mathfrak B)=H$ 다. [증명]
- 리본 판: 모든 간선이 경계 사이클 $C$ 의 간선이어야 하므로 $E(H)=E(C)$, 곧 $H$ 가 사이클 $C_n$ 이어야 한다. [증명]
- $H=C_n$ 이면 두 원판이 경계 전체로 붙어 $X=S^2$ 이다. 호는 하나이고 닫힌 호 (사이클) 다. 그래서 $\kappa=1$ 이 필요하다. [증명]
- $H=C_n$ 이 아니면 리본 판에 들어가지 않는다. 일반 층에서는 $\mathfrak A$ 가 $H$ 의 두 복사본을 쌍으로 있는 (꼬리 부분이 세분된) 그래프 $H\,\square\,K_2$ 꼴이다. 그 평면성은 $H$ 에 따라 다르다. 예: $H=K_4$ 이면 $\mathfrak A$ 는 비평면이고 $G=K_4$ 는 평면이다 [기억-미검증: $K_4\,\square\,K_2$ 비평면]. 이것은 "G 평면 $\Rightarrow$ $\mathfrak A$ 평면" 이 성립하지 않음을 보여준다 (F-R1 따름 P1 의 방향만 성립).

**(2d) 세분 허용: $V(G_2)\subsetneq V(G_1)$.** 이름이 $V_1\cap V_2$ 에만 흰 점을 둔다. 한쪽에만 있는 점은 흰 점이 없다. 예: $G_1=W_4$ (중심 $e$ 포함), $G_2=C_4$ (중심 없음) 이면 $G_1\cup G_2=K_5$ 이다. 공유 간선 $ab$, $cd$ 에 흰–흰 간선 두 개가 생기고, 중심 $e$ 는 흰 점 없이 조각 $G_1$ 안에만 있다. 이것은 F-R2 의 E4 와 같은 설명서다 [계산 확인 (손 계산)].

### 2.7 검산 예: $E_2$ (F-R1), $G=K_4$

- $G_1$: 사각형 $0\text{-}1\text{-}3\text{-}2\text{-}0$ (간선 $01,13,32,20$), $G_2$: 사각형 $0\text{-}3\text{-}1\text{-}2\text{-}0$ (간선 $03,31,12,20$).
- $G_1\cup G_2=K_4$ (간선 6개) [계산 확인 (손 계산)].
- 공유 간선: $13$ (두 번째 사각형에도 있음), $20$ (= $02$). $E_{\circ\circ}=\{w_1w_3,\ w_0w_2\}$.
- 리본 판: 두 조각 모두 4-사이클 (다각형, 경계 전체), 모든 정점이 두 경계 위에 있다 (R1, R2). 공유 간선 $13$, $02$ 는 두 경계의 간선이다 (R3). 호는 $\{w_0,w_2\}$ 와 $\{w_1,w_3\}$ 두 개다, 각각 경로 $r=2$ (R4, R6 충족).
- $X$: 두 원판을 두 개의 서로소인 간선에서 붙인 곡면. $\chi=2-2=0$ [계산 확인 (손 계산)]. 경계 $\partial X$ 는 자유 간선 $01,12,23,30$ 의 한 사이클이므로 $b=1$. 따라서 뫼비우스 띠다 [계산 확인 (손 계산)].
- $W=0\text{-}1\text{-}2\text{-}3\text{-}0$. 호 $\{0,2\}$ 와 $\{1,3\}$ 의 끝점은 $W$ 위에서 번갈아 나온다. $I=K_2$ 이고 이분이다 [계산 확인 (손 계산)].
- 조각이 모두 다각형이므로 정리 D 가 적용된다: $G$ 평면 $\iff$ $I$ 이분. 따라서 $G=K_4$ 는 평면이다 (정답과 일치) [계산 확인 (손 계산)].
- 같은 $\mathfrak A$ 는 비평면이다 (F-R1 E2, 계산 확인). 이것은 "$G$ 평면이어도 $\mathfrak A$ 는 비평면일 수 있다" 는 예다. 정리 P 의 한 방향만 성립하는 것과 맞는다 [증명: F-R1 P1, 계산 확인].

## 4. 형식 검토 (추가 항목)

- **F17. 닫힌 호와 $\chi$ 공식.** F-R6 §3.6 의 $\chi(X)=|V(H)|-|E(H)|$ 는 **닫힌 호가 없고 핀치가 없을 때만** 성립한다. $G_1=G_2=C_n$ 에서 $X=S^2$ 이지만 공식은 $1$ 을 준다 [계산 확인 (손 계산)]. 호가 경로가 아니면 포함–배제에서 $\chi(\text{호})=1$ 이 아니게 된다 (닫힌 호는 $\chi=0$). 수정: $\chi(X)$ 에 닫힌 호 보정을 넣거나, $\kappa=0$ 을 정의에 고정한다. F-R6 의 $\kappa$ 기본값 추천 ($\kappa=0$) 이 이것으로 더 강해진다.
- **F18. 공유 간선의 식별 방식.** §2.2 에서 공유 간선은 두 **검정** 간선 (서로 다른 조각) 이 $w_uw_v$ 를 통해 식별된다. 이 식별은 흰–흰 간선으로 기록되지만, 흰–흰 간선이 없어도 $G$ 는 같다 (보조정리 G1). 즉 식별은 $G$ 에 보이지 않고, $X$ 에만 보인다. 이 점을 문서에 명시해야 한다 (F-R1 충돌 1 과 같은 문제).
- **F19. 이름 일치 규칙.** "같은 이름" 은 $V$ 의 원소 같음이다. 두 그래프의 점 이름이 우연히 같은 경우와 구별하지 않는다. 이름이 같은 점을 겹치는 것은 정의상의 선택이다 (육하원칙: 무엇을 겹치는가 = 이름, 어떻게 = 흰 점, 언제 = 항상).

## 6. 후속연구 지점

1. **(우선 1) 닫힌 호 보정이 들어간 $\chi(X)$ 공식 (F17).**
   - 이유: (2c) 와 F-R6 의 $\kappa$ 판이 같은 공식을 쓰는데, 닫힌 호에서 틀린다. 정리 E 의 $\chi$ 항과 Mix 의 $b$ 계산이 여기에 기댄다.
   - 시작 방법: 호 종류 (경로 / 닫힌 호) 와 핀치점별로 $\chi$ 보정을 세우고, $G_1=G_2=C_n$ 과 $E_2$ 를 검산 예로 쓴다.
   - 난점: 경계 핀치의 보정이 F-R6 우선 2 와 같은 질문이다.
2. **(우선 2) 같은 이름 중첩의 평면성 판정 (2b).**
   - 이유: 중첩 결과 $G_1\cup G_2$ 가 평면인지를 $\mathfrak B$ 의 데이터로 읽는 것이 이 경우의 핵심이다. $E_2$ 에서는 정리 D 가 맞았다. 일반 $(G_1,G_2)$ 에서 확인되지 않았다.
   - 시작 방법: 리본 판 (두 경계 사이클, 공유 간선 = 경계 간선) 에서 $I$ 와 Mix 를 쓰고, $G_1\cup G_2$ 평면 여부와 비교하는 작은 예 (K_4 류, 입방 그래프 류) 를 만든다.
   - 난점: 공유 간선이 경계 위에 있다는 조건은 $G_i$ 의 평면 매장에 의존한다 (3-연결이면 매장이 유일하다).
3. **(우선 3) 호 분해의 유일성 (2c, 공유 간선이 많을 때).**
   - 이유: $G_1=G_2$ 이면 모든 흰–흰 간선이 쌍 $\{1,2\}$ 에 있어 호가 한 덩어리로 붙는다. 호 분해가 $\mathfrak B$ 에서 유일한지 F-R2 A1 의 조건을 다시 확인해야 한다.
   - 시작 방법: 쌍 표지가 같고 공유 간선의 연결성분이 여러 개인 경우 (호가 여러 개) 를 $H=C_n$ 과 $H=$ 경로로 나눠 본다.
   - 난점: 여러 호가 같은 쌍을 가지면 $\mathcal D$ 만으로 호를 가를 수 없다. 이때 F-R6 의 (R4) 가 필요한지 확인한다.
4. **(우선 4) (2d) 세분 허용의 정식화.**
   - 이유: E4 $=W_4\cup C_4$ 는 (2d) 의 특수 경우다. 점 집합이 다른 두 그래프의 중첩을 일반 정의로 쓰면 F-R2 의 E3/E4 재구성 질문에 답이 된다.
   - 시작 방법: $V_1\cap V_2$ 에만 흰 점을 두고 나머지 점은 한 조각에만 두는 규칙을 명문화하고, E4 와 E3 를 이 규칙으로 다시 구성한다.
   - 난점: 한 조각에만 있는 점이 경계 위에 있어야 하는지 (R2) 를 정해야 한다. 정하지 않으면 리본 판의 조건이 달라진다.
