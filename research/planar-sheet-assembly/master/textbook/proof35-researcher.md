## 0. 규약과 정의에서 그대로 쓰는 것

**0.1 그래프.** 그래프 `X` 는 `(V(X), E(X))` 이고 `E(X) ⊆ binom(V(X),2)` 이다. `X[T] := (T, {f ∈ E(X) : f ⊆ T})` 이다.

**0.2 연결.** 그래프 `H` 가 연결이라 함은 `V(H) ≠ ∅` 이고 `H` 의 임의의 두 점이 `H` 의 경로로 이어지는 것이다. (표준 정의이며 결과가 아니다. 한 점짜리 그래프는 연결이다.)

**0.3 조작.** 정의 3.3의 마이너 조작은 점 삭제 `X-x`, 변 삭제 `X-e`, 변 수축 `X/{a,b}` (`{a,b} ∈ E(X)`) 이다. 일반 집합 `T` 의 수축 `X/T` 는 조작 목록에 없다. 그래서 `X/T ⪯ X` 는 따로 증명해야 한다 (보조명제 A).

**0.4 정의 3.3의 세 성질 (그대로 사용).**
- (T0) `X ⪯ X`.
- (T1) `H ⪯ X` 이고 `X ⪯ Y` 이면 `H ⪯ Y`.
- (T3) `H ≅ H'` 이고 `H ⪯ X` 이면 `H' ⪯ X`.

교재는 (T1)을 "두 적용열을 이어 붙인다"로만 정당화한다. 이 설명은 `X ≅ R` 인 `R` 위의 적용열을 `X` 위로 옮기는 단계를 암묵적으로 쓴다. 이 옮김은 아래 보조명제 T로 증명한다. 따라서 (T1)은 정의 3.3의 것을 그대로 쓰되, 그 근거가 빠진 부분은 보조명제 T로 채운다.

**0.5 수축의 기호.** `z ∉ V(X)` 에 대해 `ρ_T : V(X) → (V(X)∖T) ⊔ {z}` 는 `ρ_T(x) = z` (`x∈T`), `ρ_T(x) = x` (`x∉T`) 이다. 정의 3.3의 `X/_zT` 의 점집합은 `(V(X)∖T) ⊔ {z}`, 변집합은 `{{ρ_T(a),ρ_T(b)} : {a,b}∈E(X), ρ_T(a)≠ρ_T(b)}` 이다.

## 1. 증명할 명제

**명제 A (보조명제 3.4의 재정식화).** 임의의 유한 그래프 `X`, 임의의 `z ∉ V(X)`, 임의의 연결 집합 `∅ ≠ T ⊆ V(X)` (`X[T]` 가 연결)에 대해 `X/_zT ⪯ X`.

**명제 B (연속 수축).** `X` 를 유한 그래프, `T_1,…,T_r ⊆ V(X)` 를 서로소인 비어 있지 않은 집합, 각 `X[T_k]` 가 연결이라 하자. 서로 다른 새 기호 `z_1,…,z_r ∉ V(X)` 를 고정한다. `X_0 := X`, `X_i := X_{i-1}/_{z_i}T_i` 로 둔다. 그러면 모든 `0≤i≤r` 에 대해 명제 S(i) (아래 4절 참조)가 성립한다.

**명제 C (정리 3.5).** `G ⪯ 𝔐^{-1}` 이고 `G ⪯ 𝔐` 이다.

## 2. 보조 명제와 증명

### 보조명제 T (동형 옮김)

`σ : Y → Z` 가 동형이고 `Y` 위의 조작열 `o_1,…,o_s` 의 결과가 `Y_s` 라 하자. `σ` 를 따라 옮긴 조작열 (`x ↦ σ(x)`, `{a,b} ↦ {σa,σb}`, 수축 기호는 `Z` 에서 새 기호로 교체)을 `Z` 에 적용한 결과 `Z_s` 는 `Y_s` 와 동형이다.

**증명.** `s` 에 대한 귀납이다. `s=0` 이면 `Z_0 = Z ≅ Y`. 한 조작을 보자.

- 점 삭제: `σ` 를 `V(Y)∖{x}` 위로 제한하면 `V(Y)∖{x} → V(Z)∖{σx}` 는 전단사이고, `f ∈ E(Y)`, `x ∉ f` 와 `σ(f) ∈ E(Z)`, `σx ∉ σ(f)` 가 같다. 따라서 동형이다.
- 변 삭제: `σ` 는 `E(Y)∖{e}` 를 `E(Z)∖{σe}` 로 옮긴다. 따라서 동형이다.
- 변 수축 `Y/_w{a,b}` (`w` 는 `Z` 에서 `V(Z)` 밖의 새 기호, `z` 는 `Y` 쪽 기호): `τ : V(Y/_w{a,b}) → V(Z/_w{σa,σb})` 를 `τ(p) := σ(p)` (`p ∈ V(Y)∖{a,b}`), `τ(z) := w` 로 둔다. `ρ` 를 `Y` 쪽 수축 사상, `ρ'` 를 `Z` 쪽 수축 사상이라 하면 `τ∘ρ = ρ'∘σ` 가 성립한다. 실제로 `p∈{a,b}` 이면 양쪽 모두 `w` 이고, `p∉{a,b}` 이면 `τρ(p) = σ(p) = ρ'σ(p)` 이다. `E(Z/_w{σa,σb}) = {{ρ'(s),ρ'(t)}: {s,t}∈E(Z), ρ'(s)≠ρ'(t)}` 에서 `s=σp, t=σq` 로 두면 `{p,q}∈E(Y)` 이고 `ρ'(σp) ≠ ρ'(σq)` 와 `ρp ≠ ρq` 는 같다. 따라서 `τ` 는 두 변집합을 대응시키는 전단사이다.

각 단계가 동형을 보존하므로 귀납이 끝난다. `□`

**주석.** 이것으로 (T1)의 교재 설명이 완전해진다. `H ⪯ X`, `X ⪯ Y` 이면 `X ≅ R` (`R` 은 `Y` 위 조작열의 결과)이고, `H ≅` (`X` 위 조작열의 결과)이다. 보조명제 T로 `X` 위 조작열을 `R` 위로 옮기면 `H ⪯ Y` 가 된다. (T3)는 정의 그대로 쓴다.

### 보조명제 1 (수축의 합성: `ρ_{T'} ∘ ρ_e = ρ_T`)

`X` 를 그래프, `e = {a,b} ∈ E(X)`, `T ⊆ V(X)` 이고 `a,b ∈ T` 라 하자. `z_e` 와 `z` 는 `V(X)` 밖의 서로 다른 기호이다. 다음으로 둔다.

- `X' := X/_{z_e}{a,b}`, `ρ_e := ρ_{\{a,b\}}` (`V(X) → V(X')`),
- `T' := (T∖{a,b}) ⊔ {z_e}`.

그러면 `T' ⊆ V(X')`, `|T'| = |T| − 1` 이고, `z ∉ V(X')` 이며, 다음이 성립한다.

(i) `ρ_e(T) = T'`.
(ii) `ρ_{T'} ∘ ρ_e = ρ_T` (`V(X) → (V(X)∖T) ⊔ {z}` 위). 여기서 `ρ_{T'}` 는 `X'` 에서 `z` 를 새 기호로 하여 정의한 사상이다.

**증명.** `V(X') = (V(X)∖{a,b}) ⊔ {z_e}` 이므로 `T' ⊆ V(X')` 이고 `|T'| = |T|−1` 이다. `z ∉ V(X')` 는 `z ∉ V(X)` 와 `z ≠ z_e` 에서 나온다.

(i) `ρ_e(a) = ρ_e(b) = z_e`. `t ∈ T∖{a,b}` 이면 `ρ_e(t) = t`. 따라서 `ρ_e(T) = (T∖{a,b}) ∪ {z_e} = T'`.

(ii) 세 경우를 본다.
- `x ∈ {a,b}`: `ρ_e(x) = z_e ∈ T'` 이므로 `ρ_{T'}(ρ_e(x)) = z = ρ_T(x)`.
- `x ∈ T∖{a,b}`: `ρ_e(x) = x ∈ T'` 이므로 `ρ_{T'}(x) = z = ρ_T(x)`.
- `x ∉ T`: `x ∉ {a,b}` 이므로 `ρ_e(x) = x`. `x ≠ z_e` 이고 `x ∉ T∖{a,b}` 이므로 `x ∉ T'`. 따라서 `ρ_{T'}(x) = x = ρ_T(x)`.

`□`

### 보조명제 2 (수축 후 연결 보존)

보조명제 1의 기호에서 `X[T]` 가 연결이면 `X'[T']` 도 연결이다.

**증명.** `T'` 가 비어 있지 않음은 `|T| ≥ 2` 에서 나온다. `x, y ∈ T'` 를 잡자. (i)에 의해 `x = ρ_e(x̃)`, `y = ρ_e(ỹ)` (`x̃, ỹ ∈ T`) 이다. `X[T]` 가 연결이므로 `x̃ = p_0, p_1, …, p_s = ỹ` 인 경로 (`{p_{i-1},p_i} ∈ E(X)`, `p_i ∈ T`)가 있다. `q_i := ρ_e(p_i) ∈ T'` 로 둔다. 각 `i` 에 대해 다음 중 하나가 성립한다.
- `q_{i-1} = q_i` 이다.
- `q_{i-1} ≠ q_i` 이면 `{p_{i-1},p_i}` 는 `E(X)` 의 변이고 `ρ_e(p_{i-1}) ≠ ρ_e(p_i)` 이므로 `{q_{i-1},q_i} ∈ E(X')`이다. `q_{i-1}, q_i ∈ T'` 이므로 `{q_{i-1},q_i} ∈ E(X'[T'])` 이다.

따라서 `(q_0,…,q_s)` 에서 연속된 중복을 지우면 `X'[T']` 안의 걷기가 되고, 걷기는 경로를 포함한다. 그러므로 `x` 와 `y` 는 `X'[T']` 안에서 이어진다. `□`

### 보조명제 3 (수축의 가환: `X'/_zT' = X/_zT`)

보조명제 1의 기호에서 `z` 를 `X'/T'` 의 새 점으로 쓰면 `X'/_zT' = X/_zT` 가 **등호로** 성립한다.

**증명.** 점집합: `V(X'/_zT') = (V(X')∖T') ⊔ {z}`. 그런데 `V(X')∖T' = ((V(X)∖{a,b}) ⊔ {z_e}) ∖ ((T∖{a,b}) ⊔ {z_e}) = V(X)∖T`. 따라서 `V(X'/_zT') = (V(X)∖T) ⊔ {z} = V(X/_zT)`.

변집합: 기호 `σ_1 := ρ_{T'}` (`X'` 위), `ρ_e` 는 보조명제 1의 것이라 하자. `X'/_zT'` 의 변은 `{ρ_{T'}(s),ρ_{T'}(t)}` (`{s,t} ∈ E(X')`, `ρ_{T'}(s)≠ρ_{T'}(t)`) 이고, `E(X') = {{ρ_e p, ρ_e q}: {p,q}∈E(X), ρ_e p ≠ ρ_e q}` 이다.

- (⊆) `X'/_zT'` 의 변을 잡는다. `{s,t} = {ρ_e p, ρ_e q}` (`{p,q} ∈ E(X)`, `ρ_e p ≠ ρ_e q`) 로 쓰면 보조명제 1 (ii)에 의해 `ρ_{T'}(s) = ρ_T(p)`, `ρ_{T'}(t) = ρ_T(q)` 이다. 그러므로 `{ρ_{T'}(s),ρ_{T'}(t)} = {ρ_T(p),ρ_T(q)}` 이고 `ρ_T(p) = ρ_{T'}(s) ≠ ρ_{T'}(t) = ρ_T(q)` 이다. 따라서 `X/_zT` 의 변이다.
- (⊇) `X/_zT` 의 변 `{ρ_T(p),ρ_T(q)}` (`{p,q}∈E(X)`, `ρ_T(p)≠ρ_T(q)`) 를 잡는다. `ρ_e p ≠ ρ_e q` 이다. 실제로 `ρ_e p = ρ_e q` 이면 보조명제 1 (ii)에 의해 `ρ_T(p) = ρ_T(q)` 가 되어 모순이다. 따라서 `{ρ_e p, ρ_e q} ∈ E(X')` 이고, `ρ_{T'}(ρ_e p) = ρ_T(p) ≠ ρ_T(q) = ρ_{T'}(ρ_e q)` 이므로 `{ρ_T(p),ρ_T(q)}` 는 `X'/_zT'` 의 변이다.

따라서 두 변집합이 같다. `□`

### 보조명제 0 (`|T|=1` 인 경우)

`T = {t}` 이면 `X/_zT ≅ X` 이다. 따라서 (T0)와 (T3)에 의해 `X/_zT ⪯ X` 이다.

**증명.** `σ : V(X) → V(X/_zT)` 를 `σ(t) := z`, `σ(x) := x` (`x≠t`) 로 둔다. 전단사이다. `{a,b} ∈ E(X)` 이면 `a≠b` 이고 `T` 는 한 점이므로 `ρ_T(a) ≠ ρ_T(b)` 이다. 따라서 `E(X/_zT) = {{ρ_T a, ρ_T b}: {a,b}∈E(X)} = {{σa,σb}: {a,b}∈E(X)}` 이다. 그러므로 `σ` 는 동형이다. `X ⪯ X` (T0) 이고 `X ≅ X/_zT` 이므로 (T3)에 의해 `X/_zT ⪯ X` 이다. `□`

### 명제 A의 증명 (보조명제 3.4의 재정식화)

`m := |T|` 에 대한 귀납으로 다음 `P(m)` 을 증명한다.

> `P(m)`: 임의의 유한 그래프 `X`, 임의의 `z ∉ V(X)`, 그리고 `X[T]` 가 연결인 임의의 `T ⊆ V(X)` (`|T| = m`) 에 대해 `X/_zT ⪯ X` 이다.

**`m = 1`:** 보조명제 0.

**`m ≥ 2`:** `P(m−1)` 이 성립한다고 가정한다. `X[T]` 가 연결이고 `|T| ≥ 2` 이므로 `T` 의 서로 다른 두 점 `x,y` 를 잡아 `X[T]` 안의 경로를 취하면, 그 첫 변은 `E(X)` 의 변 `e = {a,b}` 이고 `a,b ∈ T` 이다.

`z_e ∉ V(X) ∪ {z}` 를 잡고 `X' := X/_{z_e}e` 로 둔다. 보조명제 1에서 `T' := (T∖{a,b}) ⊔ {z_e}` 이고 `|T'| = m−1` 이다.

- 보조명제 2에 의해 `X'[T']` 는 연결이다.
- `z ∉ V(X')` 이므로 `P(m−1)` 을 `(X', z, T')` 에 적용하면 `X'/_zT' ⪯ X'` 이다.
- 보조명제 3에 의해 `X/_zT = X'/_zT'` 이다. 따라서 `X/_zT ⪯ X'` 이다.
- `X' = X/_{z_e}{a,b}` 는 `X` 에 변 수축 한 번을 적용한 결과이므로 `X' ⪯ X` 이다 (정의 3.3, 조작 한 번; 동형 옮김 불필요).
- (T1)에 의해 `X/_zT ⪯ X` 이다.

`□`

## 3. 명제 B (연속 수축의 귀납)

**설정.** `X` 는 유한 그래프, `T_1,…,T_r ⊆ V(X)` 는 서로소이고 비어 있지 않으며 각 `X[T_k]` 가 연결이다. `z_1,…,z_r` 은 서로 다르고 `V(X)` 밖의 기호이다. `X_0 := X`, `X_i := X_{i-1}/_{z_i}T_i` 로 둔다 (`i ≥ 1`). 각 `0 ≤ i ≤ r` 에 대해 `π_i : V(X) → ` (`V(X_i)`로 정의되는 사상) 을 다음으로 정의한다.

> `π_i(p) := z_k` (`p ∈ T_k`, `k ≤ i`), `π_i(p) := p` (그 밖의 `p`).

서로소이므로 잘 정의된다.

**귀납 대상.** 고정된 `X` 와 고정된 족 `(T_1,…,T_r)` 위에서, 지표 `i ∈ {0,…,r}` 에 대한 명제 S(i)를 귀납한다.

> **S(i)**: 다음 (a)–(d)가 성립한다.
> (a) `V(X_i) = (V(X)∖(T_1∪⋯∪T_i)) ⊔ {z_1,…,z_i}`.
> (b) `E(X_i) = {{π_i(p), π_i(q)} : {p,q} ∈ E(X), π_i(p) ≠ π_i(q)}`.
> (c) `X_i ⪯ X`.
> (d) `j > i` 인 모든 `j` 에 대해 `T_j ⊆ V(X_i)` 이고 `X_i[T_j] = X[T_j]` (두 그래프가 같다).

**S(0)의 증명.** `X_0 = X` 이고 `π_0` 은 `V(X)` 위의 항등 사상이다 (`T_1∪⋯∪T_0 = ∅`, 합집합이 비어 있다). (a)의 우변은 `V(X)∖∅ ⊔ ∅ = V(X)` 이므로 (a)가 성립한다. (b)의 우변은 `{{p,q} : {p,q}∈E(X)}` 이므로 (b)가 성립한다. (c)는 (T0)이다. (d)는 `X_0[T_j] = X[T_j]` 이므로 성립한다.

**S(i−1) ⇒ S(i) (`i ≥ 1`).**

*준비.* S(i−1)의 (d)에 `j = i` 를 적용하면 `T_i ⊆ V(X_{i−1})` 이고 `X_{i−1}[T_i] = X[T_i]` 가 연결이다. 따라서 `X_i = X_{i−1}/_{z_i}T_i` 가 명제 A의 전제를 만족하고 잘 정의된다. 또 `ρ := ρ_{T_i}` (`V(X_{i−1}) → V(X_i)`, 기호 `z_i`) 라 한다.

*(0) `ρ ∘ π_{i−1} = π_i` (`V(X)` 위).* 세 경우를 본다.
- `p ∈ T_k`, `k < i`: `π_{i−1}(p) = z_k`. `z_k ∈ V(X_{i−1})` 이고 `z_k ∉ V(X) ⊇ T_i` 이므로 `ρ(z_k) = z_k` 이다. 또 `π_i(p) = z_k`. 같다.
- `p ∈ T_i`: `π_{i−1}(p) = p`, `ρ(p) = z_i = π_i(p)`.
- `p ∉ T_1∪⋯∪T_i`: `π_{i−1}(p) = p`, `ρ(p) = p` (`p ∉ T_i`), `π_i(p) = p`.

*(a).* S(i−1)(a)에 의해 `V(X_{i−1}) = (V(X)∖(T_1∪⋯∪T_{i−1})) ⊔ {z_1,…,z_{i−1}}` 이다. `ρ_{T_i}` 의 정의에 의해 `V(X_i) = (V(X_{i−1})∖T_i) ⊔ {z_i}`. `T_i ⊆ V(X)∖(T_1∪⋯∪T_{i−1})` 이므로 `V(X_i) = (V(X)∖(T_1∪⋯∪T_i)) ⊔ {z_1,…,z_i}` 이다.

*(b).* (⊆) `X_i` 의 변 `{ρs, ρt}` (`{s,t} ∈ E(X_{i−1})`, `ρs ≠ ρt`)를 잡는다. S(i−1)(b)에 의해 `{s,t} = {π_{i−1}p, π_{i−1}q}` (`{p,q} ∈ E(X)`, `π_{i−1}p ≠ π_{i−1}q`) 이다. (0)에 의해 `{ρs,ρt} = {π_i p, π_i q}` 이고 `π_i p ≠ π_i q` 이다.
(⊇) `{p,q} ∈ E(X)` 이고 `π_i p ≠ π_i q` 라 하자. `π_{i−1} p ≠ π_{i−1} q` 이다 (같다면 (0)에 의해 `π_i p = ρ π_{i−1} p = ρ π_{i−1} q = π_i q` 이다). 따라서 S(i−1)(b)에 의해 `{π_{i−1}p, π_{i−1}q} ∈ E(X_{i−1})` 이고, `ρ` 를 적용하면 `{π_i p, π_i q} ∈ E(X_i)` 이다.

*(c).* S(i−1)(c)에 의해 `X_{i−1} ⪯ X`. 명제 A와 `X_{i−1}[T_i]` 의 연결성에 의해 `X_i = X_{i−1}/_{z_i}T_i ⪯ X_{i−1}`. (T1)에 의해 `X_i ⪯ X`.

*(d).* `j > i` 라 하자. (a)에 의해 `T_j ⊆ V(X)∖(T_1∪⋯∪T_i) ⊆ V(X_i)` 이다. `X_i[T_j]` 와 `X[T_j]` 가 같음을 보인다. 점집합은 같다. 변을 보자.
- `π_i` 는 `T_j` 위에서 항등이다. 실제로 `p ∈ T_j` 이면 `p ∉ T_1∪⋯∪T_i` 이다.
- (⊆) `{π_i a, π_i b} ∈ E(X_i)` 이고 `π_i a, π_i b ∈ T_j` 라 하자. 만약 `a ∈ T_k` (`k ≤ i`)이면 `π_i a = z_k ∉ V(X) ⊇ T_j` 이므로 모순이다. 따라서 `π_i a = a`, 같은 방법으로 `π_i b = b`. 그러므로 `{a,b} = {π_i a, π_i b} ⊆ T_j` 이고 `{a,b} ∈ E(X)` 이다. 따라서 `{a,b} ∈ E(X[T_j])`.
- (⊇) `f = {a,b} ∈ E(X[T_j])` 이면 `a, b ∈ T_j` 이고 `π_i a = a`, `π_i b = b` 이므로 (b)에 의해 `f ∈ E(X_i)` 이며 `f ⊆ T_j`. 따라서 `f ∈ E(X_i[T_j])`.

`□`

**따름 (명제 B의 결론).** `X_r ⪯ X` 이고, `V(X_r)`, `E(X_r)` 는 위 (a), (b)로 주어지며, `π_r` 는 위 정의이다.

## 4. 정리 3.5 증명

### 4.1 기호와 그래프임

`𝔐 = (V_0, V_1, E_00, E_01, E_11)`, `V(𝔐) = V_0 ⊔ V_1`, `E(𝔐) = E_00 ⊔ E_01 ⊔ E_11`. `X := 𝔐^{-1} = (V_0 ⊔ V_1, E_00 ⊔ E_01)`.

`𝔐` 과 `X` 가 그래프임을 확인한다. `E_00 ⊆ binom(V_0,2)` (보조명제 2.2 (1)). `E_01` 의 원소는 `V_0` 의 점 `x` 와 `V_1` 의 점 `w_v` 의 쌍이므로 두 점이 서로 다르다 (`V_0 ∩ V_1 = ∅`). `E_11` 의 원소는 `w_v ≠ w_{v'}` (`v ≠ v'`) 의 쌍이다. 따라서 `E(𝔐) ⊆ binom(V(𝔐),2)`, `E(X) ⊆ binom(V(X),2)` 이다.

### 4.2 기호 집합 `𝒱` 와 `T_v`

`𝒱 := {v ∈ V : |C(v)| ≥ 2}`, `r := |𝒱|` (`r = 0` 도 허용), `𝒱 = {v_1,…,v_r}`. 정의 2.3에 의해 `V_1 = {w_v : v ∈ 𝒱}` 이다.

각 `v ∈ 𝒱` 에 대해 `T_v := C(v) ⊔ {w_v}` 로 둔다 (`C(v) ⊆ V_0`, `w_v ∈ V_1`, `V_0 ∩ V_1 = ∅`). `T_k := T_{v_k}` 로 쓴다.

**(T-a) 비어 있지 않고 `X[T_v]` 가 연결.** `|C(v)| ≥ 2` 이므로 `T_v ≠ ∅`. 정의 2.3에 의해 `x ∈ C(v)` 이면 `{x, w_v} ∈ E_01 ⊆ E(X)` 이다. 따라서 `w_v` 는 `X[T_v]` 에서 `C(v)` 의 모든 점과 이어진다. `C(v)` 의 임의의 두 점은 `w_v` 를 거쳐 이어진다. 따라서 `X[T_v]` 는 연결이다.

**(T-b) 서로소.** `v ≠ v'` 이면 `C(v) ∩ C(v') = ∅` (보조명제 2.2 (2)). `w_v ≠ w_{v'}` (정의 2.3). `w_v ∉ C(v')` (`C(v') ⊆ V_0`, `w_v ∈ V_1`, `V_0 ∩ V_1 = ∅`). 또 `w_{v'} ∉ C(v)` 는 같은 이유로 성립한다. 여기서 `w_{v'} ∈ V_1` 이고 `C(v) ⊆ V_0` 이므로 `w_{v'} ∉ C(v)` 이다. 따라서 `T_v ∩ T_{v'} = ∅`.

### 4.3 명제 B 적용과 `X_r` 의 계산

명제 B를 `X = 𝔐^{-1}` 과 족 `(T_1,…,T_r)` 에 적용한다. 전제는 (T-a), (T-b)로 충족된다. 기호 `z_k` 는 `V(X)` 밖의 서로 다른 기호로 고정한다. `z_k` 를 `z_{v_k}` 라고도 쓴다.

`V(X_r) = (V(X) ∖ ⋃_{v∈𝒱} T_v) ⊔ {z_v : v∈𝒱}` (명제 B(a)). 여기서

`V(X) ∖ ⋃_{v∈𝒱} T_v = (V_0 ∖ ⋃_{v∈𝒱} C(v)) ⊔ (V_1 ∖ {w_v : v∈𝒱}) = V_0 ∖ ⋃_{v∈𝒱} C(v)`

이다. 두 번째 등식은 `V_1 = {w_v : v∈𝒱}` 에서 나온다. 보조명제 2.2 (2)에 의해 `V_0 = ⊔_{u∈V} C(u)`, `C(u) ≠ ∅` 이므로 `u ∉ 𝒱` 이면 `|C(u)| = 1` 이다. 그러므로 `V_0 ∖ ⋃_{v∈𝒱} C(v) = ⊔_{u∈V∖𝒱} C(u)` 이다. `u ∉ 𝒱` 에 대해 `C(u) = {(u,k_u)}` 로 두면

> `V(X_r) = {(u,k_u) : u ∈ V∖𝒱} ⊔ {z_v : v ∈ 𝒱}`.

`E(X_r)` 는 명제 B(b)에 의해 `{{π(p),π(q)} : {p,q}∈E(X), π(p)≠π(q)}` 이다. 여기서 `π := π_r`, 즉 `π(x) = z_v` (`x ∈ C(v)`, `v∈𝒱`), `π(w_v) = z_v` (`v∈𝒱`), `π(x) = x` (`x ∈ C(u)`, `u∉𝒱`) 이다.

### 4.4 동형 사상 `ι : V → V(X_r)`

`ι(u) := (u,k_u)` (`u ∈ V∖𝒱`), `ι(v) := z_v` (`v ∈ 𝒱`) 로 정의한다.

- `ι` 는 전단사이다. 4.3의 `V(X_r)` 계산에서 `V(X_r)` 의 원소는 정확히 한 번씩 나온다 (`(u,k_u)` 는 `u` 로, `z_v` 는 `v` 로 복원된다).
- **보조 항등식 (I1).** 모든 `x ∈ V_0` 에 대해 `π(x) = ι(φ(x))` 이다. 증명: `x ∈ C(u)`. `u ∈ 𝒱` 이면 `x ∈ C(u) ⊆ T_u` 이므로 `π(x) = z_u = ι(u) = ι(φ(x))`. `u ∉ 𝒱` 이면 `x = (u,k_u)` 이므로 `π(x) = x = ι(u) = ι(φ(x))`. `□`
- **보조 항등식 (I2).** `v ∈ 𝒱` 에 대해 `π(w_v) = z_v = ι(v)`.

**변 계산.** `E(X) = E_00 ⊔ E_01`.

- `{a,b} ∈ E_01` 이면 `{a,b} = {x, w_v}` (`v ∈ 𝒱`, `x ∈ C(v)`) 이다. `π(x) = z_v = π(w_v)` 이므로 이 변은 `E(X_r)` 을 만드는 조건 `π(a)≠π(b)` 를 만족하지 않는다. 기여가 없다.
- `{a,b} ∈ E_00` 이면 `a = (u,k)`, `b = (u',k)`, `{u,u'} ∈ E(P_k)` 이다. (I1)에 의해 `π(a) = ι(u)`, `π(b) = ι(u')` 이다.

따라서

> `E(X_r) = {{ι(u), ι(u')} : ∃k, {u,u'} ∈ E(P_k), ι(u) ≠ ι(u')}`.

`ι` 는 단사이므로 `ι(u)≠ι(u')` 는 `u≠u'` 와 같다. 정의 1.1 (D2)에 의해 `E = ⋃_k E(P_k)` 이다. 따라서

> `E(X_r) = {{ι(u), ι(u')} : {u,u'} ∈ E}`.

(`⊆`: `{u,u'}∈E(P_k)⊆E`. `⊇`: `{u,u'}∈E` 이면 (D2)에 의해 `{u,u'}∈E(P_k)` 인 `k` 가 있고, `u,u' ∈ V(P_k)` 이므로 `(u,k),(u',k) ∈ V_0` 이고 `{(u,k),(u',k)} ∈ E_00` 이다.)

**결론 (동형).** `ι : V → V(X_r)` 는 전단사이고 `{u,u'} ∈ E ⇔ {ι u, ι u'} ∈ E(X_r)` 이다. (`⇐`: `{ιu,ιu'} = {ιs,ιs'}` 인 `{s,s'} ∈ E` 가 있으면 `ι` 의 단사성에 의해 `{u,u'} = {s,s'} ∈ E`.) 따라서 `ι` 는 `G` 에서 `X_r` 로의 동형이다.

**`A(𝔐) = G` 와의 관계.** 정리 3.2에 의해 `A(𝔐) = G` 이다. 정의 3.1의 `ρ` 에 대해 `ι ∘ ρ = π` 가 `V(𝔐)` 위에서 성립한다 (`V_0` 위는 (I1), `V_1` 위는 (I2)와 `ρ(w_v) = v`). 따라서 `ι` 는 `A(𝔐) → X_r` 의 동형 사상이고, `ι` 는 조립 사상 `ρ` 를 `π` 로 끌어올린 것이다. 역사상은 `ι^{-1}(z_v) = v` (`v∈𝒱`), `ι^{-1}((u,k_u)) = u` (`u∉𝒱`) 이다.

### 4.5 `G ⪯ 𝔐^{-1}`

명제 B에서 `X_r ⪯ X` 이다. 4.4에서 `G ≅ X_r` 이다. (T3)를 `H := X_r`, `H' := G` 에 적용하면 `G ⪯ X = 𝔐^{-1}` 이다.

### 4.6 `G ⪯ 𝔐`

`E_11 = {e_1,…,e_s}` (유한, `s ≥ 0`) 라 한다. `𝔐` 에서 변 `e_1, …, e_s` 를 차례로 삭제하면 점집합 `V_0 ⊔ V_1` 은 그대로이고 변집합은 `E(𝔐) ∖ E_11 = E_00 ⊔ E_01 = E(X)` 가 된다. 따라서 `𝔐^{-1}` 은 `𝔐` 에 변 삭제를 `s` 번 적용한 결과 그 자체이고, `𝔐^{-1} ⪯ 𝔐` 이다. (`s = 0` 이면 `𝔐^{-1} = 𝔐` 이고 (T0).) (T1)에 의해 `G ⪯ 𝔐^{-1}` 과 `𝔐^{-1} ⪯ 𝔐` 로부터 `G ⪯ 𝔐` 이다.

`□` (정리 3.5)

- 수축 기호 `z` 의 선택: 모든 보조명제는 임의의 `z ∉ V(X)` 에 대해 성립하도록 서술되었다. 보조명제 3은 `z` 를 공유하여 등호를 얻는다. 그 외의 곳에서 기호 선택에 의존하는 결론은 없다.

**교재 점검 사항 (정리 3.5 증명 밖이나 이 증명과 관련).**
1. 보조명제 3.4 증명은 "`X'/T' ≅ X/T`" 라고 쓴 뒤 마지막에 "`X/T = X'/T'`" 라고 쓴다. 기호 `z` 를 공유하면 등호가 성립한다 (보조명제 3). 교재는 `≅` 와 `=` 를 혼용하고 있다.
2. 정의 3.3의 (T1) 정당화 "두 적용열을 이어 붙인다"는 조작의 동형 옮김을 쓴다. 보조명제 T가 이를 채운다.
3. 정리 3.5 증명은 `X_r` 과 `G` 의 동형 사상을 명시하지 않는다. 이 문서의 4.4가 명시한다.
4. 정리 3.5 증명은 `X_r` 의 변집합을 `ρ` (조립 사상)로 쓰고 있는데, 실제로 필요한 사상은 `π = ι∘ρ` (수축 사상의 합성)이다. 결론은 같다.
5. 명제 2.5는 항목을 (M1)–(M3)로 적었고, 증명은 (1)–(4)로 쓴다. 정리 3.5가 인용하는 "명제 2.5 (4)" 는 (4)라는 이름이 진술에 없는 마지막 등식 `N(w_v)=C(v)` 이다.
6. 보조명제 2.4 뒤에 "증명." 단락이 두 번 나온다 (두 번째는 첫 번째의 축약 중복). 내용은 같다.
