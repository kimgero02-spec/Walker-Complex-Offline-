- 핵심 논리 골격은 따라갈 수 있었다. 정리 3.2(조립은 G이다), 정리 3.5(G는 접합 그래프의 마이너), 정리 6.1, 예 6.2(역은 성립하지 않는다)는 교재만으로 끝까지 읽을 수 있었다.

  1. 𝒟 를 족으로 읽는지 집합으로 읽는지 표기가 충돌한다. 예 8.4 는 이 충돌에 기대고 있어서, 집합으로 읽으면 예 8.4 가 거짓이 된다.
  2. 𝔐(𝒟) 가 5-순서쌍인지 그래프인지 정해지지 않았다.
  3. 머리말이 표준 용어로 인정하는 것은 "평면 그래프"와 "마이너"뿐인데, 사이클, 연결, 부분그래프, 경로, 점 삭제 등 여러 용어가 정의 없이 쓰인다.
  4. 보조명제 3.4 와 정리 3.5 에서 귀납법의 전칭 양화, 마이너 관계의 추이성, "같은 논증" 같은 생략이 있다.

  6. 매뉴얼, 접합, 흰 점, U, 조건 (N) 등 핵심 용어의 동기가 본문에 없다. 조건 (N) 은 본문 어디에서도 쓰이지 않는다.

**Q4. 정의 2.3 / 정의 3.1 / 명제 8.5 (𝔐 의 신분)**

- 필요한 정보: 𝔐 를 그래프 (V(𝔐),E(𝔐)) 로 부를지, 5-튜플에 다른 이름을 줄지 결정하고, E(𝔐) 가 2-부분집합 족이라는 확인 한 문장.

**Q13. 정의 3.3 (마이너 관계 ⪯ 의 추이성과 동형 불변성)**

**Q15. 보조명제 3.4 (증명의 첫 줄 "|T|에 대한 귀납법")**
- 문장: "|T|에 대한 귀납법을 쓴다."
- 막힌 점: 귀납 가정을 X/e 에 적용한다. X/e 는 X 와 다른 그래프이므로, 귀납 명제가 "모든 그래프 X 와 모든 연결 집합 T"에 대한 전칭이어야 한다. 교재는 이를 말하지 않는다.
- 필요한 정보: 명제를 "임의의 X 와 연결 T 에 대해 X/T ⪯ X" 로 다시 쓰고, 귀납을 |T| 에 대해 한다고 명시.

**Q16. 보조명제 3.4 (2) ((X/e)[T'] 가 연결)**
- 문장: "ρ_e 는 X[T] 의 점을 (X/e)[T'] 위로 전사적으로 보내고, 변은 변이거나 한 점으로 줄어든다. 연결된 그래프의 이런 상은 연결이다."
- 막힌 점: 상이 연결임은 맞지만, 상의 변 집합이 (X/e)[T'] 의 변 집합 전체와 같은지 확인하지 않는다. 역방향이 필요하다. 즉 T' 안의 X/e 변은 X 에서 T 안의 변에서 왔는가. 이 확인은 ρ_e^{-1}(T') = T 한 줄로 된다.
- 필요한 정보: ρ_e^{-1}(T') = T 와 그 결과.

**Q17. 보조명제 3.4 (3) ((X/e)/T' = X/T 의 변 집합)**
- 문장: "두 변 집합은 같다. 단 {a,b} 자신은 두 그래프 모두에서 한 점으로 줄어든다."
- 막힌 점: 같다는 이유가 암시만 되어 있다. 두 방향 포함을 각각 보여야 한다. 한쪽은 ρ_{T'}∘ρ_e = ρ_T 에서 나오고, 다른 쪽은 X/T 의 변이 수축되지 않은 X 의 변이라는 것, 즉 ρ_T(x)≠ρ_T(y) 이면 ρ_e(x)≠ρ_e(y) 라는 점에서 나온다.
- 필요한 정보: 위 두 방향을 적은 두 줄.

**Q18. 보조명제 3.4 (ρ_e 의 정의)**
- 문장: "ρ_e 는 {a,b} 를 z_e 로 보내는 X 에서 X/e 로의 함수이다."
- 막힌 점: 정의 3.3 의 ρ_T 에서 T = {a,b} 인 경우라는 것이 명시되지 않았다. 기호로 따로 정의된 것처럼 보인다.
- 필요한 정보: "ρ_e := ρ_{\{a,b\}}" 한 줄.

**Q19. 정리 3.5 (마지막 단락의 "C(v) 가 한 점으로 줄어들고")**
- 문장: "각 v 에 대해 C(v) (또는 |C(v)|=1 이면 그 한 점)가 한 점으로 줄어들고."
- 막힌 점: 부정확하다. |C(v)|≥2 일 때 한 점으로 줄어드는 것은 T_v = C(v) ∪ {w_v} 이다. C(v) 만으로는 w_v 가 남는다.

**Q20. 정리 3.5 (E 와 같다는 논증)**

## (4) 연습 결과

### (i) 정리 3.2 의 F ⊆ E 와 E ⊆ F 증명 (교재만 사용)

F 는 조립 G(𝔐) 의 변 집합, E 는 G 의 변 집합이다.

**F ⊆ E.** {a,b} ∈ E(𝔐), ρ(a) ≠ ρ(b) 라 하자. E(𝔐) = E_00 ⊔ E_01 ⊔ E_11 이므로 세 경우이다.
- E_00 인 경우: a, b ∈ V_0 이므로 ρ = φ 이다. 보조명제 2.2 (3) 에 의해 {φ(a),φ(b)} ∈ E 이다.
- E_01 인 경우: 한쪽은 w_v, 다른 쪽은 C(v) 의 원소 x 이다. ρ(x) = v = ρ(w_v) 이므로 ρ(a) ≠ ρ(b) 에 모순이다. 따라서 이 경우는 없다.
- E_11 인 경우: a = w_v, b = w_{v'}, v ≠ v', μ({v,v'}) ≥ 2 이다. 보조명제 2.4 에 의해 {v,v'} ∈ E 이고, ρ(a)=v, ρ(b)=v' 이므로 {ρ(a),ρ(b)} ∈ E 이다.

**E ⊆ F.** {u,v} ∈ E 라 하자. (D3) 에 의해 {u,v} ∈ E_k 인 k 가 있다. 그래프 규약 (E_k ⊆ binom(V_k,2)) 에 의해 u, v ∈ V_k, u ≠ v 이다. 따라서 (u,k), (v,k) ∈ V_0 이고 {(u,k),(v,k)} ∈ E_00 이다. ρ((u,k)) = u ≠ v = ρ((v,k)) 이므로 {u,v} ∈ F 이다.

**막힌 곳.** 막히지는 않았다. 다만 두 군데에서 교재에 없는 규약을 끌어와야 했다. 하나는 "E_k 의 끝점은 V_k 에 있고 서로 다르다"는 그래프 규약이고 (E ⊆ F 에서 u ≠ v 와 u, v ∈ V_k), 다른 하나는 E(𝔐) 의 원소 두 점이 서로 다르다는 사실이다 (E_01 의 경우 분류). 둘 다 머리말 규약에서 나오므로 증명에 한 문장씩 적으면 완결된다 (Q4 와 관련).

### (ii) 명제 8.5 의 증명

명제: ρ: V(𝔐) → V 가 RG 의 사상 ρ: 𝔐 → G(𝔐) 이다.

**증명.**
1. ρ 가 함수인가. V(𝔐) = V_0 ⊔ W 이고 V_0 ∩ W = ∅ 이므로 ρ 를 V_0 와 W 에서 따로 정의해도 충돌이 없다. ρ(w_v) = v 는 w_v 가 v 를 유일하게 정하므로 잘 정의된다.
2. 𝔐 가 그래프인가 (E(𝔐) ⊆ binom(V(𝔐),2)). E_00 은 2.2 (1) 에 의해 V_0 의 2-부분집합이다. E_01 의 원소 {x, w_v} 는 x ∈ V_0, w_v ∈ W 이므로 서로 다른 두 점이다. E_11 의 원소 {w_v, w_{v'}} 는 v ≠ v' 이므로 서로 다른 두 점이다.
3. 사상 조건. {a,b} ∈ E(𝔐) 이면, ρ(a) = ρ(b) 이거나 {ρ(a), ρ(b)} 가 G(𝔐) 의 변이다. 후자는 정의 3.1 에서 바로 나온다. 정의 8.1 은 ρ(a)=ρ(b) 를 허용하므로 ρ 는 사상이다. ∎

**막힌 곳.** 증명은 짧고 막히는 곳이 없다. 다만 2 번 (𝔐 가 그래프라는 확인) 이 교재 어디에도 명시되어 있지 않다. 이것은 Q4 의 신분 문제와 같은 원인이다. 또 3 번의 "정의 3.1 에서 바로 나온다"는 정의 3.1 이 ρ(a)≠ρ(b) 인 변만 남긴다는 사실로 충분하다.

### (iii) 보조명제 3.4 의 (1) 항 증명: ρ_{T'} ∘ ρ_e = ρ_T

설정. X = (V_X, E_X), e = {a,b} ∈ E_X, T ⊆ V_X 이고 a, b ∈ T 이다. ρ_e := ρ_{\{a,b\}} : V_X → (V_X∖{a,b}) ⊔ {z_e} 는 a, b 를 z_e 로 보내고 나머지는 그대로 둔다. T' := (T∖{a,b}) ⊔ {z_e}. ρ_{T'} 의 새 기호는 z 이며, z ∉ V(X/e) 이므로 z ≠ z_e 이다.

**증명.** x ∈ V_X 에 대해 세 경우로 나눈다.
- (a) x ∈ {a,b}: ρ_e(x) = z_e ∈ T' 이므로 ρ_{T'}(ρ_e(x)) = z. 또 x ∈ T 이므로 ρ_T(x) = z. 같다.
- (b) x ∈ T∖{a,b}: ρ_e(x) = x ∈ T∖{a,b} ⊆ T' 이므로 ρ_{T'}(ρ_e(x)) = z. 또 ρ_T(x) = z. 같다.
- (c) x ∉ T: 이때 x ∉ {a,b} 이므로 ρ_e(x) = x 이다. x ∉ T' 인 이유는 T' ⊆ (T∖{a,b}) ∪ {z_e} 이고 x ∉ T 이며 x ≠ z_e (z_e ∉ V_X) 이기 때문이다. 따라서 ρ_{T'}(x) = x = ρ_T(x). 같다.
세 경우에서 두 함수의 값이 같으므로 ρ_{T'} ∘ ρ_e = ρ_T 이다. ∎

**막힌 곳.** 막힌 곳은 없었다. 다만 다음 세 가지를 교재에서 찾아 보충해야 했다.
1. ρ_e 가 ρ_{\{a,b\}} 라는 정의 (Q18).
2. z ≠ z_e 라는 규약. 이것이 없으면 (c) 에서 x ≠ z_e 를 보장할 수 없다 (Q14).
3. (c) 에서 z_e ∉ V_X 라는 사실. 교재는 z 에 대해서만 z ∉ V_X 라고 쓰고 z_e 에 대해서는 쓰지 않았다.
