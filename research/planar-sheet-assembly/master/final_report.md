# 최종 보고 — planar-sheet-assembly (2026-10-16, R01–R06)

**상태:** 무인 정책 상한 R06 도달로 종료. 표준 정의(정규화 vs 평면 조각 + 간선 비트)는 문주님 결정 대기이며, 아래 결과는 두 규약에 공통으로 성립하거나 규약을 명시한 것만 적는다.

## 1. 주제의 두 단계
- **1단계 (R01–R02, 평면성 도구):** 조각 + 접합 설명서 H 로 G 의 평면성을 판정. 3-연결 조각은 가향성과 오일러 지표로 (정리 E, 증명 완료). 다각형 조각 + 경계 하나는 엇갈림 그래프 이분성으로 (정리 D, 증명 완료). 이 단계의 주장은 판정 도구를 세운 것이고, 색칠수로 넘어가는 다리 역할을 했다.
- **2단계 (R03–R06, 색칠수 — 주 목표):** 빈틈의 실체는 "쌍이 각 조각에서 간선인가"이다. 최소 예 $K_4-uv$ (χ=3) + $K_2$ (χ=2) → $K_4$ (χ=4).

## 3. 답이 확정된 질문
- **문주님 원 질문 "평면성을 det/rank 로 재는가":** 아니다. 경계가 하나면 행렬식은 항상 1이다. 평면성은 엇갈림 그래프의 이분성, 곧 $\mathbb Z_2$ 연립방정식 $x_e+x_f=1$ 의 해 존재로 정해진다. rank 는 종수를 잰다 (정리 D, 명제 C).
- **평면 조각은 +1 로 막히지 않는다.** R03 가설("평면 조각이면 +1") 은 기각. 최소 반례 C9 (잎 8개) 와 잎 셋 판 (k0=3).
- **평면 가운데 조각 + 잎 둘로는 +2 불가** (정리 2L, 증명 주장). 따라서 최소 잎 수 $k_0=3$ (하한은 확인, 상한 미확인).
- **평면 조각 + 나무형 $s\le3$ 의 최댓값:** 추측 R5 가 참이면 $\chi\le5$ 이고 P9 로 5 도달. 따라서 최댓값 5 (추측 R5 의 증명 주장에 의존).

## 4. 답이 안 된 질문 / 한계
1. **표준 정의 결정 (문주님).** 정규화 (접합 변을 양쪽 조각이 모두 가짐) vs 평면 조각 + 간선 비트. 상한 $m+s-1$ 과 E2 간극의 해석이 이 선택에 따라 갈린다.
2. **사이클 설명서의 색칠수.** 위상 하한은 홀로노미 부호만 보는 추측 (Σ*) 이 일반판에서 거짓. 사이클 $H$ 에서의 정확한 판정은 열림.
3. **$m=4$ 판, $s\ge4$ 평면판.** 열림. $K_{1,1,4}$ 는 독립 4점 무지개를 막지 못해 R5 류 논법이 $s=4$ 로 안 옮겨짐.
4. **$k_0$ 상한과 잎 셋 판의 최소 $Q$.** 열림.
5. **기억-미검증 표준 사실:** Csorba ($B(G)\simeq\mathrm{Hom}(K_2,G)$), Wu 공식, Lefschetz 쌍대성, Hom 복합체의 $S_c$ 작용, 접기 보조정리. 정리 N 과 위상 판정이 기댄다.
6. **재검증 상태:** 추측 R5 는 같은 팀 재검증 1회. 외부 검토 전까지 "증명 주장"으로 취급. 정리 2L 과 판정 E·Σ* 반례도 독립 확인이 끝나지 않았다.

## 5. 문헌 상태
인터넷 접근이 없어 문헌 대조를 하지 못했다. 신규성은 주장하지 않는다. 관련 문헌 후보: 트리 분해 (SPQR, 2-합), 리본 그래프, 색칠 위상 하한 (이웃 복합체, Hom 복합체), Kempe 체인, 평면 5-색칠의 목록 확장. 문주님이 요청한 자료 (Matoušek 5장, Csorba, Kozlov 접기 보조정리) 는 REQUESTS.md 에 있다.
