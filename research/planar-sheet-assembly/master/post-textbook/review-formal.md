## 판정

**수정 후 공개 가능.** 필수 문제 **5건**, 권장 문제 12건.

문서 구조(머리말의 표기 규약, 기호표, 라운드별 결과표, 기각 목록, 열린 문제, 외부 사실 목록)는 잘 짜여 있다. 확인한 출처 ID와 번호는 모두 실제 보고서에 있었다. 필수 문제는 모두 국소적인 문제다. 조건 하나가 잘못 압축되었거나, 대상 집합이 빠졌거나, 표의 같은 칸에서 자기모순이 생겼거나, 라벨이 충돌하거나, 문서가 스스로 정한 조건부 표기를 지키지 않은 경우다. 문서를 다시 쓸 필요는 없다.

## 필수 문제

**F1. 1.5절 자료 $W$ 의 조건 (C5): 진술 오류와 정의 누락** (종류: 정의/진술)
- 본문: "(C5) 섬유 $\Phi_w=N_B(w)$ 와 홑 섬유 $\{x\}$ 사이에 쌍마다 $H$ 의 변".
- 원문 (R11-1 정의 1.1): 섬유는 $\Phi_w$ ($w\in W$) 와 $\{x\}$ ($x\in B$ 가 $W$ 에 이웃이 없을 때, 이것을 홑 섬유라 한다) 이고, (C2) 에 의해 섬유들은 $B$ 의 분할이다. 조건은 "**서로 다른 두 섬유 사이에는 항상** $H$ 의 변이 있다" 이다.
- 문제: 본문은 "$\Phi_w$ 와 홑 섬유 사이" 로만 읽힌다. 그러면 $\Phi_w$–$\Phi_{w'}$ 쌍과 홑–홑 쌍이 빠진다. 이 조건은 정리 C (인식 정리, 2.5절 첫 행) 의 핵심 조건이므로 오해를 낳는다. "홑 섬유" 는 쓰이기 전에 정의되지 않았다. $N(W)=|W|+s$ 의 $s$ 도 이 정의에 기댄다.
- 수정안: "(C5) 섬유를 $\Phi_w:=N_B(w)$ ($w\in W$) 와 $\{x\}$ ($x\in B$, $N(x)\cap W=\varnothing$; **홑 섬유**) 로 둔다 ((C2) 에 의해 $B$ 의 분할). 서로 다른 두 섬유 사이에는 항상 $H$ 의 변이 있다."

**F2. 1.1·1.6절: 분해의 대상 집합이 명시되지 않음 ($\rho$ 정의)** (종류: 정의)
- 본문: "$\rho(G):=\min_D r(D)$ (R11-3 §2)". 1.1절의 $b(D)$, $r(D)$, $I(D)$ 와 1.7절의 $\kappa_D$ 도 "분해 $D$" 를 범위로 쓰지만, $D$ 가 $G$ 의 **평면분해** (교재 정의 1.1, (D1)(D2)) 를 도는지 적혀 있지 않다.
- 원문 (R11-3 §2.1): $\rho(G):=\min\{r(D): D\text{ 는 }G\text{ 의 평면분해}\}$.
- 문제: 조각에 평면성을 요구하지 않으면 자명 분해 $(G)$ 로 모든 $G$ 에서 $\rho(G)=0$ 이 된다. 그러면 2.5절 "$\rho=0\iff$ 평면" 이 거짓으로 읽힌다.
- 수정안: 1절 첫 문단에 다음 한 줄을 넣는다. "이하 '분해' 는 교재 정의 1.1 의 평면분해 ((D1) 조각마다 평면, (D2) …) 이다." 그리고 $\rho$ 정의에 "$D$ 는 $G$ 의 평면분해" 를 적는다.

**F3. 2.4절 R10-2 행: 같은 표 안의 자기모순 ("후보는 거짓" 대 "S 는 동어반복")** (종류: 진술)
- 본문 (2.4절): "R09 의 특성화 후보 '위험 ⟺ T4∨T5∨S' 는 거짓". 바로 다음 행 주석 1.1 은 "분리 S 는 $|T|$ 에 제한이 없으면 동어반복이다" 라고 한다.
- 문제: S 에 제한이 없으면 S 만으로 "위험" 과 동치이다. 그러면 후보는 **참** (동어반복) 이고 거짓이 아니다. R10-2 원문 (요약 첫 두 항목) 이 반증하는 것은 $|T|\le3$ 으로 제한한 판 $\mathrm{T4}\vee\mathrm{T5}\vee\mathrm{S}_{\le3}$ 이다. 3절 표는 이것을 바르게 적었다.
- 수정안: "후보 '위험 ⟺ T4∨T5∨S$_{\le3}$' 는 거짓 (S 에 제한이 없으면 동어반복, 주석 1.1)".

**F4. 2.7절 R13-3 정리 3.1 행: 장애물 라벨 "R07 장애물 O1" 의 충돌** (종류: 출처/기호)
- 본문 2.1절은 O1–O5 를 R07-2 의 장애물로 쓴다 (O1 = $C_4/e\cong C_3$). 그런데 2.7절의 "R07 장애물 O1 ('$A(f)=\mathrm{id}$') 은 $G^\sharp$ 로 바꾸면 사라진다" 에서 O1 은 **R07-3** 의 장애물 O1 ("사상이 빈약하다", R07-3 장애물 절) 이다. R13-3 원문 31·97행도 이것을 뜻한다.
- 문제: 독자는 2.1절의 O1 (수축 비단조성) 이 $G^\sharp$ 로 해소된다고 잘못 읽는다.
- 수정안: "R07-3 장애물 O1 ($A(f)=\mathrm{id}$, 2.1절 R07-3 §3 행의 '충실하지 않다')" 로 쓴다. 문서 전체에서 장애물 라벨은 보고서 ID 를 붙여 쓴다 (R07-2 O1, R07-3 O1, R14-3 O2, R16-3 O2 등).

**F5. 증명 상태 칸: 문서 자신의 "[증명, 조건부]" 규약을 일관되게 쓰지 않음** (종류: 표기)
- 머리말 규약: "[증명, 조건부] = 증명이 [기억-미검증] 사실 (5절) 에 기대는 것. 기대는 사실을 괄호 안에 적는다." 일부 행은 이 규약을 따르지만 (R10-3 명제 2.4, R11-3 정리 2.2·2.4, R12-3 정리 3.5, R17-3) 다음 행들은 상태 칸이 맨 [증명] 이다. 의존 사실은 괄호 설명에만 있거나 5절에만 있다.
  - 2.3 채널 정리 C1·C2: "[증명] (다중도는 Young 규칙 인용, [기억-미검증])". 규약대로면 [증명, 조건부: Young 규칙] 이다.
  - 2.4 Prop 4: 상태는 [증명] 인데, 5절 끝 문단은 이 증명이 표시 없이 Jordan 곡선 정리를 쓴다고 밝힌다 (R10-1 99행에서 확인). 상태 칸만 읽는 독자에게는 무조건 증명으로 보인다.
  - 2.4 정리 2.5 의 "비평면이면 모든 분해에서 $r\ge1$": R10-3 150행에 따르면 이것은 명제 2.4 (평면 부분) 의 대우이다. 따라서 같은 표에서 명제 2.4 에 붙인 1-합 조건이 여기서는 빠져 있다.
  - 2.6 R12-2 정리 S, R12-3 정리 2.1, R12-1 정리 3.3 (d): 조건이 괄호 안에만 있다. 정리 3.3 (d) 의 ETH 는 5절에도 없다.
- 수정안: 위 행의 상태 칸을 "[증명, 조건부: …]" 형식으로 바꾼다 (예: Prop 4 → [증명, 조건부: Jordan 곡선]; 정리 2.5 → "$\chi$ 상계 [증명]; 비평면 귀결 [증명, 조건부: 1-합]"). ETH 는 5절 표에 추가한다 (권장 R9 참조).

## 권장 문제

**R1. 기호 중복이 많음** (1절 전체, 정의). 같은 글자가 서로 다른 뜻으로 여러 번 쓰인다.
- $\Phi$: 라벨 프로필 $\Phi_k(q)$, 올림 $\Phi\in L(\sigma)$, 섬유 $\Phi_w$, 흐름 다항식 $\Phi_{(W,F)}$, R17 의 $\Phi(m)$, $\Phi_P(q)$.
- $\varepsilon$: 꼬임 부호, 흰 점 지표 $\varepsilon_\Phi$, 초과량 $\varepsilon(D)$.
- $\sigma$: 정련, 순열, 세분 지수 $\sigma(G)$.
- $\rho$: $\rho$-호환, $\rho_\lambda$, $\rho(G)$.
- $N$: $K_N$, 계수 행렬 $N_i$, $N_\beta(c)$, $N_\beta(b)$, $N(W)$, 이웃 $N_B(w)$.
- $W$: 허브 $W(D)$, 자료 $W$, $W_s=V^{\otimes s}$, 바퀴 $W_4,W_9$, R07-2 의 그래프 $W$.
- $\beta$: 블록, $\beta_1$, 조건 (β).
- $\kappa$: 1.2절의 색 함수 $\kappa$, $\kappa_D$, $\kappa_H(u,v)$.
- $B$: $V\setminus W$, $B(D)$, 행렬 $B$, $\mathbb B$, $B_0(G)$.
- $k$: 머리말은 "조각 수를 $k$ 로 쓴다" 고 하지만 $k$ 는 조각 지표 $P_k$, 위계 단계, $\circ_k$ 에도 쓰인다. 교재는 조각 수를 $n$ 으로 쓴다.

수정안: 1.1절 앞에 "중복 기호 주의" 표를 하나 둔다. 적어도 같은 절 안의 충돌은 피한다 (예: 1.5절 $\Phi_w$ → $F_w$, R17 의 $\Phi(m)$ → $\Phi_{\rm R17}$). 머리말의 "조각 수 $k$" 는 "조각 수를 $|D|$ (교재의 $n$)" 로 고친다.

**R2. 쓰이기 전에 정의되지 않은 용어** (정의). 다음 용어를 1절에 한 줄씩 넣거나 출처 절을 적는다.
- $g_G$ (2.8 명제 5.1. R14-3 109행의 정의는 $g_G(q)=P_G(q)/q^{|V|}$)
- $V_1(D_G)$ (2.11 정리 3.1)
- "$x+K_3$", "평면 + 삼각형" 의 "+" (같은 점 집합 위의 변 합집합)
- 2-핵심, 강체 블록, $H_\beta$, $\delta\beta$, $w_\beta(S)$, $\Gamma_D$
- 1.4절의 Comp/Coup/Fact, "인수분해", 2.3절의 "흰형 블록", $\mathbf{Blk}$, $\mathbf{MGr}/V$

**R3. 정리 이름 중복** (출처). "정리 E" 는 세 번 나온다 (0절 R01–R06, R12-1 짧은 사이클, R12-2 매장 이전). 2.6절에서는 두 개가 한 표에 있다. "정리 C" 도 두 번 (R11-1 별 군집, R11-2 3-정칙), "정리 D" 도 두 번 (0절, R11-1 지름) 나온다. 3절 "정리 E (짧은 사이클) 가 (가) 로도 성립" 처럼 본문에서 부를 때는 항상 "R12-1 정리 E" 처럼 보고서 ID 를 붙인다.

**R4. 2.6 R12-2 정리 S 의 등호 예 $q=1$ ($C_9$)** (진술). 정리는 "$\Delta\ge3$ 에서 등호 ⟺ …" 인데, 첫 예 $C_9$ 는 $\Delta=2$ 이다. R12-2 44행은 $\Delta=2$ 를 따로 다룬다 ($C_7$ 도 등호이지만 포화가 아니고, 포화 해는 $C_9$). 수정안: "$q=1$ ($\Delta=2$, 포화 해 $C_9$; 이 경우는 특성화 밖)".

**R5. 2.4 Prop 4 와 1.2절 꼬임 부호의 가정** (진술). R10-1 원문의 가정은 "네 접합 점이 한 면 경계에 놓이고 **각 접합의 두 점이 이웃**" 이다. "곧은/꼬인 띠 순서" 가 이 가정을 포함한다는 것을 적는다.

**R6. 2.5 R11-2 §4 "$\mathrm{Aut}$ 가 날카롭게 3-추이적"** (진술). 어떤 집합 위의 작용인지 적는다 (매뉴얼 구조 8개 위; $336=8\cdot7\cdot6$).

**R7. 1.8절 $\sigma(G)$ 의 정의역** (정의). $\sigma(G)\in\{0,1,2\}$ 는 정의가 아니라 R17-2 정리 Σ 의 귀결이다 ($h_M(\mathrm{sub}^2G)=h(G)$ 이므로 최소가 존재한다). "정리 Σ 에 의해 잘 정의되고 $\le2$" 로 적는다.

**R8. 머리말 범위의 역할 서술** (출처). "연구원(researcher1·3), 망상꾼(R11·R12·R17 의 researcher2), 구조 조각가(researcher3)" 에는 R07–R10 의 researcher2 (마이너·안전 수축) 의 역할이 없다. 또 researcher3 이 두 역할에 이름을 올린다. 부록 표와 맞춰 고친다.

**R9. 5절 외부 사실 목록의 누락** (외부사실).
- ETH (R12-1 정리 3.3 (d)): 가정이므로 목록에 넣는다.
- $\dim\mathrm{End}_{S_q}(V^{\otimes s})=\mathrm{Bell}(2s)$ ($q\ge2s$, 2.3절): Young 규칙 행에 함께 적는다.

**R10. 2.11 $\nu(N)$ 하계의 출처 구분** (출처/표기). R17-1 은 $\max(3N-4,\ N(N-1)/6+N-2)$ 를 "맞는지 모른다" 고 적었다 (R17-1 164행, 후속 지점). 증명된 하계 $N(N-1)/6+N+4/3$ 은 R17-2 정리 Φ (b) 의 것이다. 본문 괄호 "(R17-1 은 …$+N-2$)" 를 "R17-1 은 $+N-2$ 형태를 추측으로 남김" 으로 고쳐, 그 형태가 증명된 하계로 오해되지 않게 한다.

**R11. 2.4 R10-1 Cor 3b, 2.9 R15-3 정리 2.1 의 [기억-미검증]** (표기). 기억에 기대는 것은 "알려진 공식과 같다" 는 동일시뿐이고, 증명 자체는 기대지 않는다. 지금 표기도 맞지만, "(문헌상 같은 공식인지는 [기억-미검증]; 증명은 독립)" 처럼 뜻을 분명히 하면 F5 의 조건부와 구별된다.

**R12. 2.5 R11-3 정리 2.2 의 가정** (진술). 원문의 가정은 "고립점 없이 연결이고 비평면" 이다. 연결이면 자동이지만 원문 그대로 적는 것이 안전하다.
