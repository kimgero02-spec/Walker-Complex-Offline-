### 확정된 것
- 설명서 = 스팬 다이어그램(조각 + 공유 그래프 + 단사 쌍), 조립 = colimit. 복원 ⟺ 국소 그래프 $H_v,H_f$ 연결 [증명, r1].
- 홀로노미 두 종류: 점 홀로노미(일관성, 자명해야 함) / 방향 홀로노미 $[\varepsilon]\in H^1(H;\mathbb Z_2)$ = 조립 2-복합체 $X$ 의 $w_1$ [증명].
- 정리 C (r3): 주변 사이클 조각 + 비자명 홀로노미 ⟹ 비평면 [증명]. 예: $K_5$(삼각형 5, $H=C_5$), 피터슨(오각형 6, $H=K_6$) [계산 확인, 오케 재현].
- 띠 정리 D (r1): (B1)–(B3), $n\ge3$, 비자명 ⟹ $TK_{3,3}$ ⟹ 비평면 [증명]. $K_4$ 예외 = $n=2$.
- 정리 B (r2): 꼬인 다각형 띠에서 평면 ⟺ 가로대를 끝점 공유 다발 2개 이하로 분할 [증명].
- 같은 $K_5$ 가 레이블형($C_5\cup C_5'$)·홀로노미형(삼각형 5개, $n\ge3$ 이지만 B2/B3 위반)·$n=2$ 띠형($W_4\cup C_4$) 설명서를 모두 가짐 → "형"은 설명서의 성질.

## R02 계획: 선택한 지점과 이유
- 지점 1·2·3 을 고른다. 이유: 세 연구원이 독립적으로 같은 방향(엇갈림 그래프·조립 곡면의 위상)을 가리켰고, 2 는 R01 에서 반례로 깨진 추측의 자연스러운 수정판이며, 3 은 $K_4$ 예외를 남김없이 설명하는 마지막 조각.
- researcher1(연구원): 지점 1 통합 정리 + 지점 3.
- researcher2(반례꾼): 지점 2 수정판 추측과 R01 증명 전부(정리 B·C·D)의 가정 경계 공격, 지점 1 초안 공격.
- researcher3(망상꾼): 분야 = 저차원 위상수학(곡면·핸들·교차형식·Heegaard 도식). 이유: 리본 곡면의 손잡이 = 엇갈리는 호 쌍, 교차형식 mod 2 의 rank 가 종수를 준다는 구조가 정리 B 의 엇갈림 그래프와 닮았다. 기하군론은 연속 사용 금지 규칙으로 교체.
