# Team MAD 라운드 규칙 (방법 1)

모든 연구원은 라운드마다 아래를 반드시 지킨다.

1. 보고서를 `<주제>/library/R<라운드 2자리>-<연구원>.md` 로 제출한다. (요약 + 본문)
2. **같은 보고서의 PDF를 직접 만든다.**
   `python3 research/tools/make_pdf.py <주제>/library/R01-researcher1.md`
   → 같은 폴더에 `R01-researcher1.pdf` 가 생긴다. 한글과 수식($...$)이 지원된다.
3. 만든 PDF를 열어 한글·수식이 깨지지 않았는지 확인하고, 깨졌으면 마크다운을 고쳐 다시 만든다.

오케스트레이터는 라운드를 끝내기 전에 반드시 점검한다.
`python3 research/tools/check_round.py <주제 폴더> <라운드>`
- 실패(종료 코드 1)면 해당 연구원에게 다시 지시한다. 통과하기 전에는 다음 라운드나 최종 보고로 넘어가지 않는다.
- 재지시 후에도 PDF가 없으면 `--fix` 로 대신 생성하고 최종 보고서에 "시스템 생성"이라고 밝힌다.
