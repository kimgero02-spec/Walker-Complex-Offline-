# STATUS — graph-field-hom (R01 종료, 포메이션 I 분담 모드, 연구원 모델 sonnet 5.5)

## 확정된 것 (오케스트레이터 독립 재검증 포함)
- [증명] 모든 G 에서 Hom(G,F) 가 F-벡터공간 ⟺ 간선 규칙 R 이 F²의 부분공간. 무방향이면 R ∈ {0, a=b, a+b=0, F²} (char 2 에서는 두 직선이 합쳐짐). (R1: researcher1·3 일치)
- [증명] 차원: R=0 → 간선 없는 고립점 수, a=b → 연결성분 수, a+b=0 → 이분 성분 수(char≠2), F² → |V|.
- [증명] 방향 + 이득 λ: dim = #{성분 C : ord(λ) | ω(C)} (ω = 닫힌 걸음 감김수의 gcd). 방향 사이클 $\vec C_n$ 은 ord(λ)|n 일 때만 1. (researcher2; Z₅,λ=2 의 C₃,C₄,C₈, 혼합 삼각형 오케스트레이터 재확인)
- [증명] 기존 규칙의 정보는 a=b 규칙에서 파생: b(G)=c(G×K₂)−c(G) (researcher1; 5개 예 재확인).
- [증명] 무방향 4규칙은 합쳐도 (i,c,b,n) 만 본다. C₆ 와 K₃,₃ 구분 불가 (재확인).
- [증명] 정수 계수 규칙 R_{a,b}: F^G = Hom_Z(A_G,F), A_G=Z^V/⟨a·u+b·v⟩, dim = rank A_G + (char 가 나누는 비틀림 인자 수). 체 사상에 대해 공변·F^G⊗F′≅F′^G. 소체 사이 일관된 규칙 = 정수 계수 [a:b]∈P¹(Q). 퇴화는 p | ab. (researcher3; V-트리 0→2←1, λ=2: A_G=Z⊕Z/2 재확인 → F₂ 에서 dim 2)
- [계산 확인] 방향 C_n, λ=2: A_G=Z/(2ⁿ−1), n=3,4,5 재확인 (일반 n 의 순환성 증명은 미완).
- [계산 확인] 라플라시안 스미스 꼴: P₅ [], C₆ [6], Q₃ [2,8,24], K₃,₃ [3,3,9] (알려진 임계군과 일치). 비이분이면 L 과 Q 가 다를 수 있음.

## 정정·주의
- 유한체에서 ker BᵀB ⊋ ker B 가 일어난다(해석 (b)). 예: Z₅, λ=2, $\vec C_4$ 에서 1 대 2 (재확인). 연산자 BᵀB 로는 F^G 를 못 읽는다.
- researcher1 보고서의 "K₅ over Z₅, L=−J, 핵 4 대 1" 은 a=b 규칙의 라플라시안 L=D−A 에 대한 것(부호 없는 D+A 는 가역 → 핵 0). 규칙을 명시해서 읽을 것. 부호 없는 Q 의 예는 K₄ over Z₃ (핵에 **1** 포함, 재확인).
- F₄ 의 Frobenius 꼬임 규칙 {(a,a²)} 는 대칭이나 F₂-공간일 뿐 F₄-부분공간이 아님 → 문주님 정의 밖.
- 방향이 주어진 dim 은 다항시간, k=3 에서 균형 방향 찾기는 3-채색(NP-완전, researcher2 [기억-미검증 수준의 복잡도 서술]).
