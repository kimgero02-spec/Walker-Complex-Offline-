# 연구 과제 (대수검존)

그래프 G에서 체 F로 가는 그래프 준동형 모음 F^G 의 구조를, **F 위의 간선 규칙을 바꿔 가며** 비교한다.
어떤 규칙이 가장 나은지(풍부한 구조·함자성·계산 가능성)를 판정하는 것이 최종 목표다.

## 문주님의 정의 (사용자 확정 — 다시 증명하지 말 것)
- F 가 체이고 G 가 그래프일 때, F 를 그래프로 본다. 정점은 F 의 원소, 간선 관계는 "합이 0" (a ~ b ⟺ a+b=0).
- F^G := {G→F 그래프 준동형 전체}. 이것은 벡터공간이다. 원소를 **G-matrix over F** 라 부른다.
- F^G 는 F-벡터공간이다. (−)^G 는 (체 F 에 대해) 공변함자, F^(−) 는 (그래프 G 에 대해) 반변함자이다. (문주님이 이미 증명하심)

## 오케스트레이터의 예비 정리 (아래 [증명] 은 손으로 한 한 줄 논증이며 연구원이 독립 재확인할 것)
일반 틀: 간선 규칙을 R ⊂ F×F 로 두면 Hom(G,F) = {φ:V→F | 모든 간선 uv 에서 (φ(u),φ(v)) ∈ R}.
1. [증명] 모든 G 에서 Hom(G,F) 가 F-벡터공간 ⟺ R 이 F-부분공간. (G=K₂ 이면 Hom = R.)
2. [증명] 무방향(R 대칭)이면 R ∈ {0, ⟨(1,1)⟩, ⟨(1,−1)⟩, F²} (char≠2). 직선 ⟨(1,λ)⟩ 이 대칭 ⟺ λ²=1.
3. [증명] 기존 규칙 a+b=0 에서 char F≠2 이면 dim F^G = G 의 이분 연결성분 수 (루프·홀수 닫힌 걷기가 2φ(r)=0 을 강제). rank(비부호 결합행렬) = n − (이분 성분 수). 이것은 고전 사실일 가능성이 높다 [기억-미검증].
4. [계산 확인] F=Z₅, 25개 소형 그래프에서 위와 일치. 호모 개수 = 5^dim 도 소수 예에서 일치. (이 점검은 근거로 쓰지 않는다.)
5. [증명 스케치] 방향 그래프 + 이득 λ∈F^× (간선 u→v 는 φ(v)=λφ(u)): 연결성분의 기여 = 1 (모든 닫힌 걷기의 정방향−역방향 간선수가 ord(λ) 의 배수) 또는 0. Z₅ 의 λ=2 이면 F 는 {0 의 루프} ⊔ 방향 4-사이클(1→2→4→3→1).
6. [증명 스케치] λ=0 퇴화형: R=⟨(1,0)⟩ ⟹ φ(head)=0, dim = (들어오는 간선 없는 정점 수); R=⟨(0,1)⟩ ⟹ φ(tail)=0, dim = (나가는 간선 없는 정점 수).
7. 함자성 관찰 [증명 스케치]: F^(−) 는 R 이 무엇이든 반변. (−)^G 가 체 사상 σ:F→F′ 에 대해 공변이려면 σ×σ(R_F) ⊂ R_F′ 필요. R 이 정수 계수 ax+by=0 이면 자동. λ∈F 로 정의하면 σ(λ)=λ′ 필요. 이 판단은 검증 대상이다.
8. 관찰: 기존 규칙의 F^G 는 "이분 성분 수"만 기억해 P₅, C₆, Q₃, K₃,₃ 을 구분하지 못한다(약한 불변량). 새 규칙들이 정말 더 많은 정보를 주는지가 쟁점.

## 연구할 양 (각 규칙마다 같은 항목을 채워 비교 가능하게 할 것)
1. **차원** dim F^G (일반 공식 또는 필요충분조건; 왜 그런지 증명 시도).
2. **랭크**: 제약행렬 B_R (간선×정점)의 랭크, 그리고 F^G 가 G 에서 H 로 가는 호모 f 에 대해 만드는 당김 f*:F^H→F^G 의 랭크·단사/전사 조건.
3. **고유벡터**: 다음 두 가지를 모두 다룰 것(해석이 모호하면 어느 해석인지 밝히고 둘 다 시도).
   (a) Aut(G) 가 F^G 에 작용한다(σ·φ=φ∘σ⁻¹). F^G 를 Aut(G) 표현으로 보고 고유벡터·고유값(특히 사이클/경로 대칭의 고유값)을 구한다.
   (b) 정점 공간 F^V 위의 연산자 B_Rᵀ B_R (또는 규칙에 맞는 라플라시안형 연산자) 의 고유구조와 F^G=ker 의 관계. 유한체라 스펙트럼 대신 특성다항식·최소다항식·가약성으로 본다.
4. **함자성**: F^(−) 반변성, (−)^G 공변성(체 사상 σ:F→F′ 에 대한 조건), 그 규칙이 모든 체에서 일관되게 정의되는가, 자연변환·곱·합(분리합 G⊔H, 곱그래프 등)과의 호환성(F^{G⊔H} 등).
5. **예제**: 최소 8~10개의 정선된 그래프(경로, 사이클 Cₙ 여러 n, 완전그래프, 완전이분, 방향 사이클, 혼합 방향 삼각형, 나무, 루프/다중간선이 있는 것, 분리합)에서 손/최소 계산으로 값을 구하고 **공통 패턴과 공통 장애물**을 뽑아 이론으로 구조화한다. (전수 점검 금지.)
6. **판정 자료**: 이 규칙은 기존 규칙(a+b=0) 대비 무엇이 더 풍부하고 무엇이 나쁜가? 한 문단 이상으로 쓸 것.

## 정의 확장 이력 (문주님 승인)
- R2 부터 체 F 대신 가환환 R 도 허용한다. 이때 F^G(=R^G) 는 R-가군이며, 간선 규칙 S 가 R×R 의 R-부분가군일 때 모든 G 에서 가군이 된다. 차원 대신 가군 구조(자유 계수, 비틀림, 위수)를 본다. 체 부분은 R1 의 결과가 그대로 유효하다.
