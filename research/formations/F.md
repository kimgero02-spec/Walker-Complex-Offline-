# 포메이션 F (프리 포메이션) — 문주가 직접 선정한 자유 포메이션

**용도**: 주제와 막힌 지점에 따라 연구원 역할을 골라 조합한다. 고정된 인원이나 순서가 없다. 각 역할은 아래 "역할 목록"에서 가져온다.

## 역할 목록

| 역할 | ID 예시 | 하는 일 |
|---|---|---|
| **연구원** | researcher* | 주제에 대해 예제 계산 → 패턴·장애물 추출 → 정리·증명 시도. (기존) |
| **망상꾼** | researcher* | 다른 분야의 학자로서 그 분야의 정리·기법을 가져와 반증 가능한 예측을 만든다. 모든 산출물 [망상]. (기존) |
| **반례꾼** | researcher* | 주장을 깨뜨린다. 반례는 직접 계산해 제시. 공격이 실패하면 어떤 불변량이 막는지 기록. (기존) |
| **논검객** | researcher* | 포메이션 N 에서 수행하는 역할. 상대에게 기술을 전수하고 조언한다. 두 논검객이 **대화 형식**으로 번갈아 주장과 반론을 주고받아 주제를 발전시킨다. (기존/신규) |
| **구조 조각가** | researcher* | 주제나 대상을 추상화하고, 구조적으로 다룰 수 있는 방법론(범주·합성·그래프 분해·대수적 구조 등)을 전담한다. 예제보다 구조의 정식화를 우선. (신규) |
| **형식주의자** | researcher* | 도서관의 서술이 mathematical formal statement 인지 검토하고 지적·보완한다. 육하원칙이 깨진 서술, 어디에 속하는지 불명확한 대상, 정의가 없는 용어, 용어 중복 등을 찾아 **description 의 ambiguity 를 차단**한다. (신규) |
| **병합마스터** | researcher* | 둘 이상의 아이디어, 주제, 대상, 이론을 하나의 틀로 합친다. 합칠 때 생기는 충돌(정의 불일치, 표기 차이)을 명시한다. (신규) |
| **학생** | researcher* | 호기심이 많고 영리하고 열정적이다. 질문하기를 좋아한다. 지능은 학부 3학년 수준이다. 주어진 글(정의, 정리, 교재)을 읽고, 이해가 안 되는 곳, 생략된 단계, 정의되지 않은 용어를 질문으로 적는다. 질문마다 어느 줄의 무엇이 막히는지 명시한다. (신규) |

## 조합 규칙
- **턴 개념은 포메이션 N 전용이다.** 포메이션 F 에는 턴이 없다. 선택된 역할들은 **동시에 독립적으로** 실행하고, 서로의 산출물을 읽지 않는다 (블라인드). 산출물이 모두 나온 뒤 오케스트레이터가 판정한다.
- 최소 1명, 최대 제한 없음 (인원은 주제에 맞춘다). 같은 역할을 여러 명 둘 수 있다 (예: 논검객 둘).
- 형식주의자는 다른 역할의 산출물이 나온 뒤 검토하는 **사후** 역할로 쓰는 것을 기본으로 한다. 이 경우 한 라운드는 두 단계 (독립 산출 → 형식 검토) 로 돈다. 이것도 턴 개념이 아니라 단계 구분이다.
- 병합마스터는 독립 산출물 두 개 이상이 있을 때 쓴다.

## 실행 (오케스트레이터)
1. 주제와 막힌 지점을 정하고, 필요한 역할을 고른다. 선택 이유를 STATUS.md 에 적는다.
2. 각 역할의 프롬프트에 COMMON.md 를 앞에 붙이고, 역할 설명은 위 표에서 가져온다.
3. 라운드 끝에 판정표를 만들고, 쟁점을 문주님께 올린다.
4. 칸막이 규칙 (다른 주제 폴더 금지, check_isolation.py) 은 그대로 적용한다.
