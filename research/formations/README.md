# 포메이션 모음 — 사용법

사용자가 "**포메이션 T 로 <주제> 시작**" 처럼 말하면 오케스트레이터는:
1. `python3 research/new_topic.py <슬러그> "<과제>"` 로 칸막이를 만들고 problem.md 를 쓴다(정의는 `[기억-미검증]` 표시).
2. 해당 포메이션 파일의 프롬프트 템플릿 + COMMON.md 로 연구원들을 띄운다.
3. 라운드 중 Monitor 로 도서관을 감시하고 새 소식을 중계한다.

| 이름 | 파일 | 구성 | 상태 |
|---|---|---|---|
| **I** | I.md | 독립 연구원 3명 (기본형, 교차 재현) | 초안 (확인 대기) |
| **T** | T.md | 연구원 · 반례꾼 · 망상꾼 | 사용 중 (hadwiger-coindex) |
| **N** | N.md | 삼인 논검: 독립 입론 → 교차 공격 → 방어 → 판정 | 초안 (확인 대기) |

새 포메이션은 `formations/<이름>.md` 로 추가하고 이 표에 한 줄 더한다.
