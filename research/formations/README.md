# 포메이션 모음 — 사용법

사용자가 "**포메이션 T 로 <주제> 시작**" 처럼 말하면 오케스트레이터는:
1. `python3 research/new_topic.py <슬러그> "<과제>"` 로 칸막이를 만들고 problem.md 를 쓴다(정의는 `[기억-미검증]` 표시).
2. 해당 포메이션 파일의 프롬프트 템플릿 + COMMON.md 로 연구원들을 띄운다.
3. 라운드 중 Monitor 로 도서관을 감시하고 새 소식을 중계한다.

| 이름 | 파일 | 구성 | 상태 |
|---|---|---|---|
| **I** | I.md | 독립 연구원 3명 (기본형, 교차 재현) | 초안 (확인 대기) |
| **T** | T.md | 연구원 · 반례꾼 · 망상꾼(다른 분야의 학자) | 사용 중 (hadwiger-coindex). 망상꾼 분야 배정은 2026-10 에 추가 |
| **N** | N.md | 이인 핑퐁 논검: 논검객1 결론 → 논검객2 검토·결론 → 논검객1 … 왕복 후 판정 | 사용자 정정 반영 (2026-10-16) |

| **F** | F.md | 프리 포메이션: 문주가 역할을 골라 조합 (연구원·망상꾼·반례꾼·논검객·구조 조각가·형식주의자·병합마스터) | 문주 선정 (2026-10-17) |

새 포메이션은 `formations/<이름>.md` 로 추가하고 이 표에 한 줄 더한다.

| **검수팀 (2인)** | 형식주의자 + 학생 | 교재나 정의 문서를 검수한다. 형식주의자는 정의의 포멀성과 증명의 정확성을, 학생은 교재만으로 공부가 되는지를 본다. (신규) |
