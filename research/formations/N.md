# 포메이션 N (이인 핑퐁 논검)

> 사용자 정정(2026-10-16): 연구원 2명이 **차례로 생각하고 결론을 넘겨 주고받는** 형식. 연구원1이 먼저 생각해 결론을 내고, 연구원2에게 넘긴다. 연구원2가 그 결론을 검토해 자기 결론을 내고 연구원1에게 넘긴다. 이 왕복을 정해진 턴 수만큼 반복한다.

**용도**: 진술 하나(정리의 증명, 정의의 선택, 반례의 유효성)를 두 시각이 서로 검증하며 좁혀 가고 싶을 때. 한쪽이 놓친 것을 다른 쪽이 잡는다.

| 자리 | ID | 역할 |
|---|---|---|
| 논검객 갑 | researcher1 | 먼저 생각. 턴 홀수에서 결론을 내고, 상대에게 기술을 전수·조언한다 |
| 논검객 을 | researcher2 | 갑의 결론을 받아 검토. 턴 짝수에서 결론을 내고, 상대에게 기술을 전수·조언한다 |
| 판관 | 오케스트레이터 | 턴 배정, 전달, 최종 판정, 독립 재검증, 요약 |

유파는 두 논객이 서로 다르게 잡는다 (예: 증명 중심 / 반례 중심). 같은 접근이면 서로의 오류를 잡지 못한다.

## 진행 (턴 단위, 순차)
- **턴 1 (researcher1, 블라인드)**: 진술 {STMT} 에 대해 결론(참/거짓/조건부)과 근거(증명 또는 구성 또는 반례)를 쓴다. 산출: library/N-T1-researcher1.md.
- **턴 2 (researcher2)**: N-T1 을 읽고, (a) 틀린 단계나 빠진 가정을 지적하거나 결론에 동의하는 이유를 쓴다. (b) 자기 결론을 낸다. 반박은 재현 가능해야 한다. 산출: library/N-T2-researcher2.md.
- **턴 3 (researcher1)**: N-T2 를 읽고 같은 형식으로 응답한다. 산출: library/N-T3-researcher1.md.
- 두 논검객은 **대화 형식**으로 번갈아 주장과 반론을 주고받아 주제를 발전시킨다. 매 턴은 상대에게 기술 (방법, 보조정리, 계산 도구) 을 전수하고 조언을 덧붙인다.
- 턴은 정해진 수 K 까지 간다 (기본 K=4, 즉 researcher1 2번, researcher2 2번). 두 논객이 같은 결론에 도달하고 서로 반박할 것이 없으면 조기 종료.
- **판정 (오케스트레이터)**: 각 턴의 주장을 `살아남음 / 반박됨 / 미결` 로 표에 정리하고, 핵심 주장은 독립 계산으로 재검증한다. 마지막 결론이 갈리면 쟁점을 명시한다. 최종 요약은 채팅, 기록은 master/final_report.md.

## 실행 규칙
- 턴마다 **다른 쪽의 직전 산출물만** 읽는다. 그 이전 턴은 요약본으로 받는다.
- 각 턴의 에이전트는 SendMessage 로 이어 부르거나, 새 에이전트에 직전 산출물 경로를 준다. 턴 사이는 순차다. 한 턴이 끝나야 다음 턴이 시작된다.
- 공격은 재현 가능해야 한다. 반례는 직접 계산해 제시한다.
- 칸막이 규칙은 그대로 적용한다 (작업 주제 폴더 밖 금지, git 커밋은 오케스트레이터가 한다).

## 프롬프트 템플릿 (COMMON.md 를 앞에 붙인다. {STMT}=판정할 진술, {PREV}=직전 산출물 경로)
### 턴 1 (researcher1)
[역할: 논객 갑] 진술 {STMT} 의 참·거짓·조건부를 독립적으로 판단하라. 결론, 근거(증명 또는 구성 또는 반례), 자가 진단(약점) 을 쓴다. 산출: N-T1-researcher1.md.
### 턴 2 (researcher2)
[역할: 논객 을] {PREV} 를 읽고 검토하라. (a) 틀렸거나 빠진 가정을 짚는다. 동의하면 이유를 쓴다. (b) 당신의 결론과 근거를 쓴다. 산출: N-T2-researcher2.md.
### 턴 3 이후 (교대)
[역할: 논객 갑 또는 을] {PREV} 를 읽고 응답하라. 상대의 결론 중 받아들이는 것, 반박하는 것을 나눠 쓰고, 자기 결론을 갱신하라. 산출: N-T{k}-{ID}.md.
