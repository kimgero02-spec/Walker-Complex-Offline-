# 포메이션 N (삼인 논검)   — ⚠ 초안: 사용자 확인 대기

> "논검"을 **세 명이 같은 문제에 각자의 방식으로 도전하고 서로 칼(반박)을 겨루는 형식**으로 해석한 초안이다.
> 사용자가 역할·절차를 정정하면 이 문서를 고친다.

**용도**: 맞는지 틀린지 갈리는 *진술 하나*(정리의 증명, 명제의 참/거짓 판정)를 가장 믿을 수 있게 가려내고 싶을 때. 같은 모델의 오류 상관을 줄이려고 세 명이 **서로 다른 유파(접근법)**를 쓴다.

| 자리 | ID | 역할 |
|---|---|---|
| 논객 갑 | researcher1 | 유파 1로 독립 입론 |
| 논객 을 | researcher2 | 유파 2로 독립 입론 |
| 논객 병 | researcher3 | 유파 3으로 독립 입론 |
| 판관 | 오케스트레이터 | 유파 배정, 판정, 독립 재검증, 요약 |

유파는 오케스트레이터가 문제에 맞게 정한다. 예: (대수적/조합적/위상적), (구성적 증명/귀류법/계산 탐색), (반례 중심/증명 중심/구조 중심).

## 진행 (초식 단위. 초식 안은 병렬, 초식 사이는 순차)
1. **제1초식 – 독립 입론 (블라인드)**: 각자 자기 유파로 결론(참/거짓/조건부)과 근거를 쓴다. **다른 논객의 파일을 읽지 않는다.** 산출: library/N1-{ID}.md (결론 · 증명 또는 구성 · 약점 자가 진단).
2. **제2초식 – 교차 공격**: 각자 나머지 두 명의 입론을 읽고, 구체적이고 검증 가능한 반박을 쓴다(반례, 논리 빈틈, 가정 누락, 계산 오류). 산출: library/N2-{ID}-vs-{상대}.md 2개. 공격은 *재현 가능한 형태*여야 한다.
3. **제3초식 – 방어·수정**: 자신에게 온 공격 2개에 대해 인정(수정) 또는 반박(증거)한다. 산출: library/N3-{ID}.md (수정된 입장, 인정한 것, 끝까지 지킨 것과 근거).
4. **판정 (오케스트레이터)**: 주장별로 `살아남음 / 반박됨 / 미결` 표를 만들고, 핵심 주장은 독립 계산으로 재검증한다. 세 명의 결론이 갈리면 갈린 지점(쟁점)을 명시한다. 채팅으로 사용자에게 요약, 최종은 master/final_report.md.

초식 사이에는 SendMessage 로 같은 에이전트를 이어 부르거나 새 에이전트에 이전 산출물을 읽게 한다.

## 프롬프트 템플릿 (COMMON.md 를 앞에 붙인다. {SCHOOL}=배정된 유파, {STMT}=판정할 진술)
### 제1초식 (REPORT=N1-{ID})
[역할: 논객, 유파: {SCHOOL}] 진술 {STMT} 이 참인지 거짓인지 당신의 유파 방식으로 독립적으로 판단하라. **도서관의 다른 논객 파일을 읽지 마라.** 결론과 근거(증명 또는 구성 또는 반례), 약점 자가 진단을 쓴다.
### 제2초식 (REPORT=N2-{ID}-vs-{상대})
[역할: 논객] library/N1-{상대}.md 를 읽고 공격하라. 반박은 구체적이고 재현 가능해야 한다(반례는 직접 계산해 제시). 공격이 실패하면 어디가 견고한지도 적어라. 상대 2명 각각에 대해 1개씩 보고서.
### 제3초식 (REPORT=N3-{ID})
[역할: 논객] 당신의 입론(N1-{ID})에 온 공격(N2-*-vs-{ID})을 읽고, 인정할 것은 인정해 수정하고 반박할 것은 증거로 반박하라. 수정된 최종 입장을 제시.
